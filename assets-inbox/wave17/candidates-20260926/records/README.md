# Wave 17 — 2장 「전쟁의 그늘」 후보

1318–1347년 잉글랜드 남부 해안 시장도시의 징발·징집·군자금·해안 습격·석벽 선택 재료다. 게임에는 설치하지 않았다.

## 납품 구성
- 후보 PNG 57개(신규53·재사용 분리레이어4): 워커6, 손 소품16, 양모 행렬3레이어, 피란민 재사용 소품2, 세계 그림8, 삽화22.
- 확인 그림3개: `proofs/01_workers_convoy.png`, `02_coastal_raid.png`, `03_illustrations_cards.png`.
- `assets.csv`: 57개 후보의 크기, 셀·프레임, 발판 크기, 배율, 출처, 전체 프롬프트, SHA256, 역사 메모.
- `worker-overlap.csv`: 6워커×8프레임 실제 겹치기 결과.
- `worker_prop_attachments.csv`, `prop_anchors.csv`, `frame_pivots.csv`: 분리 소품 장착과 프레임별 기준 좌표.
- `HISTORICAL_NOTES.md`, `QA_CHECKLIST.md`: 고증 범위와 실제 검수 결과.
- `reference/`, `records/`: 참조·좌표·생성 및 검수 근거. 참조 PNG와 기록용 PNG는 신규 후보 57개에 포함하지 않는다.

## 표시·조립 계약
게임 줌1.0은 소스의50%, 줌0.6은 소스의30%다. 확인그림의 실제 크기 영역은 이 배율로 작성했다. 별도의 확대 진단 영역은 배율을 표시했다.

워커는74×74셀, 4열 NE/SE/SW/NW, 2행 f0/f1. 파일럿2의 P4(남), P5(여), P1(상인) 정규화 템플릿을 사용했다. 셀을 재중앙정렬하지 않는다. CSV의 발 좌표는 측정값이며 임의로 발을 맞추어 다시 옮기라는 지시가 아니다. 원래 손·팔·발 자세를 유지했다.

손 소품은32×32. 장궁·빌은 장착 시2배(약60px길이), 장부·횃불은1배다. 장착 left=손x−grip_x×배율, top=손y−grip_y×배율. 프레임별 수치는 `worker_prop_attachments.csv`를 따른다. 피란민은 본체→등짐(0,0)→아이(+17,0)로 조립한다.

`herd/wool_sack_convoy-v1.png`는 **양모·깃발 적재물 레이어만** 담는다. 소(`animal_walk/ox-v1.png`), 차체(`cart/ox_cart_body-v1.png`), 운전 워커는 별도다. 좌표와 앞쪽 수레채 가림 순서는 `records/convoy/assembly.json`을 따른다. 새 화물 원점은 차체와같은(0,0); 기존 곡물화물용 offset을 추가하지 않는다. 전체 조합은128×96 차체셀 밖까지 펼쳐지므로 통째로 그 셀에 잘라 넣으면 안 된다. 소의2프레임은 다리만 바뀌고, 화물은f0/f1 완전동일하다. 차체의 기존 바퀴2프레임은 그대로 재사용했다.

봉화 평시·점화는128×160으로 같은 위치의 본체를 사용한다. `raid_burning_quay-v1.png`는256×128 투명 오버레이이며 참조 `quay-v1.png`와 원점(0,0)으로 합성한다. 이전 확정본의 피벗(68,119), 의도 발판2×2를 그대로 잇는다. 연기512×192는128×192셀4개를 가로로 놓은4프레임이다. 새 후보 앵커는 셀(64,186).

석벽 비계는 기존 `stone_face_a` 계열의512×128 벽면 띠 규격이다. 등각 개별 건물 PNG가 아니다. 설치 시 벽면 매핑을 따르며 끝의 비계 기둥은 이어붙임에 맞게 겹친다. 무한반복 seam이나 엔진 충돌을 검증한 자료는 아니다.

삽화는 사건960×540×8, 결정640×480×5, 연대기384×384×8, 장전환1920×1080×1. 원본에는 UI틀·제목 글자가 없다. 세 번째 확인 그림에서만 제공된 카드틀과 조합했다.

## 제작·검수 범위
새 원화는 내장 imagegen으로 제작했다. 정규화·정밀 위치등록·알파 정리·확인 합성은 로컬 Sharp로 수행했다. 전체 프롬프트와 선택·수정 이력은CSV및기록에 보존했다. 생성 원화의 로컬 경로와 해시를 기록했으며 모든 대형 생성 원화를 패키지에 중복 수록한 것은 아니다.

검수는 납품 PNG의 정적 합성·픽셀·크기·ZIP 무결성에 대한 것이다. 게임 설치, 이동/충돌, 애니메이션 재생 속도, 렌더러의 실제 피벗 해석과 성능은 검증하지 않았다. 작은 장궁의 현·사자 문장의 세부는 줌0.6에서 식별하기 어렵고, 형태·색과 행렬 구성이 주 신호다.
