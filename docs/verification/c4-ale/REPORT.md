# C4 보고서 — 에일 사슬(보리·엿기름·에일, 가내 슬롯의 첫 제품)

지시서: C4 에일 사슬(엔진 세션, 6시간). 명세 [ale-chain.md](../../design/ale-chain.md) AL-1~AL-9, 결정 AL1~AL13. 사용자 판정: 2026-09-27(멈춤, RES-REG 뒤 재개), 2026-09-28(가마 UI 줄, 봇 명령, C+B 규칙, BLD-REG 병합). 검증은 DGX.

## 1. 만든 것
- **자원 세 줄**(AL-1): `resourceCatalog.ts`에 보리(원자재·곡창), 엿기름(가공품·곡창), 에일(음료·창고). 장부 분류는 다섯이고, 홉은 없다.
- **작물 선택**(AL-2): 게임 명령 `set_farmstead_crop`(`setFarmsteadCrop(state, barnId, crop)`).
  - 플레이어와 봇이 같은 명령을 쓴다.
  - 보리 띠의 수확은 밀의 1.25배다.
  - 보리는 헛간에 두면 가마가 가져간다. 곡창으로는 나르지 않는다.
- **엿기름 가마**(AL-3): 2×2, 일꾼 2, 목재 40, 보리 1 → 엿기름 1에 20틱, 수레 12(방앗간과 같게).
- **가내 양조**(AL-4, `crafts/brew_ale.json`)
  - 등급 1 이상이고 14세 이상 여성이 있는 집이 첫 슬롯에서 빚는다.
  - 엿기름은 도시의 가장 가까운 창고에서 가져온다.
- **에일집과 마시기**(AL-5)
  - 에일집은 등급 2 이상의 양조 집이다.
  - 계절마다 제 에일부터 마시고, 없으면 16칸 안의 에일집에서 산다.
  - 에일집은 판 몫에 좌판세를 낸다.
- **승급**(AL-6): 에일은 승급을 **막지 않고 늦춘다**. 에일이 없는 집은 등급 2 이상으로 가는 대기가 150 %다. 1장은 상관없고, 내려가지도 않는다.
- **봇**(AL-8): 내줄 수 있는 헛간 옆 도로 6칸 안에 가마를 짓고(자리가 없으면 8·10칸), 그 헛간을 보리로 바꾼다.
- **저장 v23**: 모양 무변화(선택 필드 `Building.crop`·`House.aleUntilTick`, 슬롯).
- **목록 병합**
  - BLD-REG 뒤 가마 화면 줄은 `buildingCatalog.ts`·`.ko.ts` 두 줄이다(AL6).
  - 공사장의 종류 switch는 `BUILDING_CONFIG_BY_KIND` 조회로 바꿨다(AL10). 새 건물에 엔진이 손댈 곳이 종류·규칙·건축 틱·해금 단계로 줄었다.

## 3. 탐침(`scripts/aleBottleneckProbe.ts`, 450,000틱)
- **멈춘 곳의 병목**(막는 규칙, 300k~320k)
  - seed 2·3·5 모두 가마가 가동 시간의 79~89 %를 보리 없이 놀았다. 헛간에는 보리가 309~979 있었다.
  - 에일은 한 계절 8~18통이 나왔는데, 집은 24채다.
  - 도달 범위 밖 집 0, 다른 조건 때문에 막힌 집 0이었다. 에일 때문에 막힌 집은 8·8·2채였다.
- **대안**
  - A(L3부터 요구)는 그대로 멈췄다.
  - B(늦추기)는 5/5였지만 seed 2가 413,800틱이었다.
  - 공급 쪽 C(수레 12, 헛간 옆 가마)를 더한 C+B가 아래와 같다. 결과는 [probe-32a1da2.json](probe-32a1da2.json)·[probe-bf6b097.json](probe-bf6b097.json).
