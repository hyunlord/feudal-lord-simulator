# 독립 후보 검수

판정: 파일럿 후보 전달 가능. 사용자 미술 승인이나 실제 제품 UI 검증을 뜻하지 않는다.

검수 입력: 의뢰서, 딥리서치 UI 발췌, DESIGN.md, 최종 자산 12개, 확인 그림 3개. 실제 PNG를 직접 열어 확인했다. 생성 및 합성 담당과 별도로 검토했으며 게임 파일은 변경하지 않았다.

| 항목 | 관찰 | 판정 |
|---|---|---|
| C안 80% 기능 / 20% 장식 | 밝고 어두운 패널 중앙은 단색. 얇은 모서리 선·상단 장식·작은 인장만 남아 있다. 큰 정보 면에 나뭇결이나 얼룩이 없다. | 적합 |
| 금지 요소 | 자산에 글자·숫자·bar 내부·선택 사각형·하이라이트가 보이지 않는다. 달력은 글자 없는 칸, 상태는 도형 기호다. 확인판 글자는 별도 합성 레이어다. | 적합 |
| 자원 6개 | 사람 묶음·빵·통나무·돌·동전·달력의 큰 윤곽이 구분된다. | 적합 |
| 건설 분류 6개 | 집+우물, 길, 곡물+낫, 자루+창고, 예배당, 목책 순서다. 24px에서 생활과 저장유통은 자루의 큰 모양으로 구분되며 작은 우물 세부는 약하다. | 조건부 적합 |
| 층위 3개 | 손+망치, 붓+땅, 두루마리+인장이 분리된다. 구역을 건설 분류에 섞지 않았다. | 적합 |
| 상태 8개 | 말풍선·원/체크·종·팔각/X·마름모·삼각·자물쇠·반짝임으로 구분한다. 초록과 청회색은 상태에만 쓰인다. | 적합 |
| 커서 4개 | 선택, 체크, X, 작은 길 기호가 분리된다. 런타임 핫스폿이나 가리키기 정확도는 검수하지 않았다. | 후보 적합 |
| 9-slice | 200×80 및 600×400에서 모서리 장식 크기가 유지되고 중앙은 늘어난다. 조언자 원형 슬롯도 찌그러지지 않는다. | 적합 |
| 조언자 렌더 계약 | 원형 슬롯은 일반 9-slice 중앙에 포함시키지 않고 고정 48px 삽입물로 처리했다. 이 보조 계약 없이 PNG 전체를 단순 9-slice 하면 같은 결과를 보장하지 않는다. | 명시 필요 |
| HUD 합성 | 제공된 기존 화면 위에 합성했다. 상단 우측 시간·속도·설정, 우측 목표 2개, 좌측 정보·조언자, 하단 층위 3개와 분류 6개가 보인다. | 적합 |
| HUD 수정 확인 | 초기 목표 카드 사이에 남았던 원본 글자 조각은 최종판에서 불투명 밑판으로 가려졌다. | 해결 |
| 세계와의 관계 | 양피지·oak·붉은 인장 팔레트는 세계와 이어진다. 아이콘 윤곽은 건물보다 굵고 선명하다. 기능 가독성을 위한 선택으로 보인다. | 후보 적합 |

## 한계

- 24px 평가는 직접 시각 검토이며 처음 보는 사용자의 무라벨 식별 실험은 아니다. 집 안의 우물, 작은 낫과 인장 같은 부속 세부까지 모두 읽힌다는 뜻이 아니다.
- 조언자 슬롯은 별도 고정 합성 방식이 필요하다. 일반 9-slice PNG 한 장만으로 모든 내용물이 자동 보존되는 계약이 아니다.
- HUD 수치·문구는 시안용이며 게임 상태를 검증한 값이 아니다. 합성판의 목표 24/24와 인구 12도 제품 상태 일관성의 증빙으로 쓰지 않는다.
- 해상도 대응, 접근성, 클릭·호버·선택, 실제 정보량, 프레임 비용, 런타임 통합은 검수 범위 밖이다.
