## 1. 규격 (모든 Wave 공통)

- **제작 크기 = 표시 크기 기준**. 타일 1칸 = 128×64px(DPR2 기준 1×). 큰 원본을 만들었으면 축소 후 **줌 1.0·0.6에서 형태가 읽히는지** 확인 그림 필수.
- 건물: 2:1 등각, **SW 고정 방향**, 피벗 = footprint 남쪽 꼭짓점, 알파 여백 8px. 1×1은 폭 128, 2×1은 256, 2×2는 256×(높이). 원본은 표시 2배까지만.
- 스트립: 평면, 좌우 seamless(여백 없음), 위아래 알파 페이드.
- 데칼·소품: 등각, 아래 가운데 접지, 사방 8px 여백, 긴 그림자 없음.
- 지면 반복 무늬: 표시 밀도 기준, 반복 단위 4×4칸 이상, 최소 형태 크기 ≥ 6px(줌 1.0).
- 광원 좌상단, 채도 낮은 자연색, 아트 바이블 재료 규칙(굴뚝 통·유리·슬레이트·S기와 금지, 성밖 초가/성내 평기와).
- **변형 세트는 실루엣이 달라야 한다.** 색만 바꾼 변형은 인정하지 않는다(지붕선·부속 건물·문 위치·마당 소품이 달라야 함).
- 모든 장에 생성 기록 CSV 1행(프롬프트 전문, 참조는 프로젝트 파일만, 수작업 수정).
- 참조 이미지는 **기존 게임 그림만**. 외부 작품 금지.
