## 다시 확인하기

Python3와 이미 설치된 `jsonschema`가 있는 환경에서 ZIP을 풀고 `sh validate.sh`를 실행한다. 이 세션에서는 의존성을 새로 설치하지 않았다. SHA256SUMS가 있으면 파일 해시도 함께 확인한다.

JSON 구조를 통과해도 문자열 조건이 자동으로 등록기 predicate가 되지는 않는다. 소스 대조는 `graft` 탐색 뒤 실제 파일 구간 확인으로 수행했다. 노출 빈도·행동 결과·저장/복원·복합 명령의 원자성은 엔진 통합 때 검증해야 한다.
