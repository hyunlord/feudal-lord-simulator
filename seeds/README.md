# 자동 성장 기준선

`baseline-7db9df85.json`은 소스 커밋 `7db9df85ee0b87e1dd8d99930abb328bace3ee95`의 seed 1~5 최종 결과를 고정한다. `sourceExecutionSummarySha256`과 seed별 `summarySha256`·`finalStateSha256`은 보관된 원본 결과를 가리킨다. 숫자는 이번 작업의 결과를 역산해 만든 것이 아니다.

새 검증은 기준선보다 L4 도달, 서비스 공급, 행동 가능한 성장 상태가 나빠지지 않았는지 검사한다. 유휴 노동 5~25%는 현재 합격 조건에서 제외된 **C3 관문 후보**다. 방앗간 재고 0 비율은 안정 구간에서 한 방앗간이 **2,400틱 연속** 밀 0인지 관측한 뒤 계산한다. 파일의 `legacyFinalInstantZeroWheatMillRatio`는 당시 마지막 한 틱의 기록이며 새 지표와 비교하지 않는다. 기준선은 격리된 `7db9df85` 소스에서 같은 관측기로 seed 1~5를 다시 실행했다. 각 최종 상태 SHA-256·종료 틱·안정 구간이 보관 결과와 일치했고, `chronicZeroWheatMillRatio`는 모두 0이다. 관측 기록이 없는 새 결과는 미판정(통과 아님)이며, 비교 가능한 비율이 기준선보다 20퍼센트포인트를 초과해 악화할 때만 회귀로 본다.

## C1c-2 기준선 (`baseline-5b138e0.json`)

밀밭이 경작지 띠와 헛간으로 바뀐 뒤(C1c-2)의 seed 1~5 결과다. 소스 커밋 `5b138e0`, 격리 worktree에서 다섯 seed를 동시에 돌렸다. 가드레일 판정(`scripts/growthGuardrail.ts`)은 L4·서비스 공백·교착·밀 0 방앗간을 계속 `baseline-7db9df85`와 비교한다. 이 파일은 시설 수(헛간·경작지 칸·방앗간)와 안정 구간 빵 비율·원료 부족 비율을 다음 작업의 비교 기준으로 남긴다. 경작지 칸/필지 상한 9.6은 이 실행의 최댓값 8.0 × 1.2다.
