## 검증과 한계

- 집중 시험: 실행 후 실제 결과 기재.
- 자연 관측: DGX 20년 판 seed1·2·3 결과 대기. 사건이 발생하지 않았다면 0건으로 기록하며 준비 상태 시험을 자연 발생으로 세지 않는다.
- Mac `npm run eventart:auto`: 실행 후 캡처·출처·설치 장부를 함께 기록.
- 게시 관문: 정확한 최종 트리의 `test:changed`, `check:merge`, 필요한 경우 변경 줄 기하 감사. 완료 전 게시 통과를 주장하지 않는다.
- P-M1/P-C: 현존 인물·영지·공사·물자·세율에서 읽고, 응답 때 같은 원인을 재검사한다.
- P-D5/P-T3: 권한 변경은 영주, 작은 운영은 상시 방침; 큰돈·결렬은 기존 동적 예외를 따른다.
- P-T1/GP-7: 영주에게 도착한 무거운 결정과 전체 명령·청지기 처리·연대기 변화를 구분해 보고한다. 20년 관측을 150년 전체 분포로 일반화하지 않는다.
- 저장 구조·코어 틱·물류·인구·공용 관문 규칙은 변경하지 않는다.
