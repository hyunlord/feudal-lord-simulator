## 새 발견

### QA-012 · 계절 외형의 한 샘플 교체와 달력 불일치 (중간)

재현: 원본1380도시 로드 → 정상5배속 → 카메라 고정 → 가을부터 봄까지100ms 목표 연속 촬영. 나무 잎·지붕 눈이 약100ms 사이 한꺼번에 교체된다. 겨울 첫 화면 다음 샘플에서 지면 표현이 추가로 바뀌고, 봄에서는 달력 표시가 한 샘플 늦다. [가을→겨울 GIF](evidence/clips/season-autumn-winter.gif), [겨울→봄 GIF](evidence/clips/season-winter-spring.gif).

기대: 계절의 교체 의도가 명확하고 같은 시점의 세계와 달력은 일치한다. 보간 자체가 필수라는 제품 규칙은 확인하지 않았다. 실제 렌더 프레임 수·100ms 미만 보간·원인 코드 확정은 하지 않았다. GIF 루프 점프와 실제 계절 경계를 혼동하지 않는다. 원본220프레임과 실제 촬영 간격은 별도 보존했다.

### QA-013 · 목표 패널이 현재 사건 칩을 덮음 (중간)

재현: 실제1316여름의 대기근·젖은 여름이 표시된 상태 → 목표 조건 펼침 → 오른쪽 사건 칩 선택. 목표 패널이 칩의 이름과 클릭 영역을 덮는다. 정상 클릭은 goal-slot의 가림으로 실패했고, 목표 패널을 닫은 뒤 같은 사건을 정상적으로 열었다. [열림](evidence/19-goal-obscures-event.jpg) / [닫힘](evidence/20-famine-access-after-goal-close.jpg). 화면 좌표 대략 x1250–1590,y65–262.

기대: 진행 목표를 읽으면서 새 사건에 접근할 수 있다. 우회는 목표 패널 닫기. 영구적인 진행 불가나 다른 모든 접근 경로 부재로 과장하지 않는다. 원인 확정·코드 수정 없음.

## 새 종류를 찾았지만 결함 확정하지 않은 것

- **날씨**: 1380가을 비의 가는 사선·고리 파문·갈색 안개 같은 화면 톤을 연속 촬영했다. 이 표본에서 HUD 읽기를 막는 불투명 덮임은 보지 못했다. 비/일시정지 클립은 있지만 안개와 먼지의 독립 발생 조건을 모두 재현한 것은 아니다. 계절 색 변화와 날씨를 별도 판정한다.
- **밤낮**: 여러 해·계절이 지나도 일주기 밤으로 보이는 화면은 관찰하지 못했다. 일 단위 생활보다 계절 경영으로 읽혔으며, 이 사실만으로 결함을 등록하지 않았다. 존재하지 않는 밤 장면을 추정해 만들지 않는다.
- **운송**: [1배속](evidence/clips/cart-animal-1x.gif)·[3배속](evidence/clips/cart-animal-3x.gif)·[5배속](evidence/clips/cart-animal-5x.gif)에서 사람과 손수레의 이동은 확인. 낮은 해상도의 다리에서 교대/지면 접촉은 확정할 수 없었다. 고정 양 무리를 움직이는 말/소와 혼동하지 않는다. 동물 보행의 슬라이딩 결함은 미확인.
- **장 전환**: 실제1장 결산 →2장 소개 →세계 복귀와1342년2장 결산 →3장 소개 →세계 복귀를 화면 버튼으로 진행했다. 소개에는3장1348–1364라 쓰여 있지만 현재1342년에도 조기 전환된다. 이것이 의도한 조기 달성인지 별도 명세 확인 없이 결함으로 세지 않았다. 전환과 모달은 캡처했으나 보상 중복 같은 내부 결함을 판정하지 않았다.

## 측정·재현 경계

- 본선 pull 후 QA 체크아웃·서버·HEAD를 확인. 브라우저에 증명 인자 없음. 제품 코드·아트 변경 없음.
- 잠금 존재 시 관찰/인코딩을 대기했고 실행 중에도 감시했다. 타인의 측정·잠금 파일은 건드리지 않았다.
- QA 정보 오버레이는 이HEAD에 없어 개별 프레임 tick·월드 카메라 좌표·선택 개체 상태는 미수집. 정확한 tick은 정상 저장/장 종료 기록이 있는 시점만 적는다.
- 시작 화면으로 돌아온 두 탭, 잘못된locator, Esc로 열린 메뉴, 계절 결산 모달이 낀 표본은 [하네스 기록](repro/method.md)에 분리했다. 환경 이상을 제품 결함으로 추가하지 않았다.
- `frameWorkMs`·FPS·전체 정지율은 측정하지 않았으며 추정값으로 채우지 않았다. JPEG/GIF만으로 경로·충돌·행동 원인 확정은 하지 않는다.
