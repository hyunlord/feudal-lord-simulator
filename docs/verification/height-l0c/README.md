# RB-HEIGHT-L0C — 긴 박공지붕 초가집의 문

기존 c형 선택을 유지하면서 완성 본체1장과 전용 fresh·weathered·boarded·snow4장을 설치했다. 그림 원본과 runtime PNG는 바이트가 같다. 다른 집 묶음, 선택 가중치, 1350/1400 시대 경계와 엔진 저장 형식은 바꾸지 않았다. 원래 Wave26 그림은 로딩/화재 경로의 참조이므로 제거하지 않았다.

## 측정과 한계

닫힌 문짝은 native45×19px, 차원 불확실성±2px이다. 표시 배율0.49957049486461247에서 높이21.48–23.48world px이며 성인17.6 기준이다. 문틀에 가려진 실제 유효 개구부를 직접 측정한 값은 아니다. 그림 전체 확대 없이 지붕 능선이 원본보다41native px 높아졌다. 같은153² 캔버스·바닥 피벗(77.3541,139.5789)·1×1발판을 사용하되 세 바닥점 잔차는2,1,2.236px이고 좌표 불확실성±2px다. 정확한 등각 투영 인증으로 읽으면 안 된다.

본체 최상단 경계에는 최대alpha4/255의 매우 희미한 픽셀이 있다. 다른 경계와 네 층 경계는0이다. 전체 등록 시 offcanvas 비영 알파 소실0이라는 별도 측정과 구분했다. 눈은 수동 지붕 영역 기준 가중70.78%, alpha32 이진78.10%로 측정했고 영역 불확실성1–2px다. 눈1픽셀이 본체 밖에 있으나1px 이내다. 생성 실패 body01–05, weathered01, snow01과 정확한 프롬프트를 전체 ZIP에 보존한다.

## 같은 저장 검증

기존 town 저장 세 개를 정규 로더로 이주시킨 뒤, 기존 집의 level/builtLevel을0으로 준비했다. 자연 성장 장면이라는 주장은 하지 않는다. 신선한 집23은 tick13000 저장, 풍화한 집8은 tick9000 저장이며 서로 다른 집이다. 겨울/해빙은 tick11000 저장의 집8과 실제 보행자를 유지하고 tick11500/12150으로 바꿨다. boarded 두 사본만 거주자와 가구원0·abandonedTick을 기록했다. 모든 필드 전후 값은 migrations-full 및 fixtures에 보존한다.

18개 전후 비교는6상태×줌1/.6/3이다. 같은 seed·tick·카메라·고정 프레임 시각·배우 상태를 비교한다. 부분 해빙 준비값0.4302164893을 실제 draw alpha로 별도 확인한다. 신선/풍화가 한 건물의 시간 경과라는 주장은 하지 않는다. fire/burn은 기존 원형 fallback 경로를 유지하므로 불탄 집의 새 실루엣 일치까지 해결한 작업은 아니다.

## 실제 화면 판정

전후18쌍의 상태·seed·tick·카메라·시각·보행자 등12항목 및72개 이미지 SHA가 일치했다. 정확한 집 world rect에서 본체와 해당 층의 draw를18/18 확인했고 다섯 runtime URL 모두 양성이다. 해빙 눈 draw alpha는0.43021648930679457이다. pageError0, 네트워크 중단25건은 모두 비그림 telemetry sample의 ERR_ABORTED이며 원시 로그에 보존했다.

겨울 확대3배에서 집8 왼쪽 길의 실제 성인 carter는 화면 약52–56px(수동독해±2px), 문짝은 선언 등록과45±2native 치수로 약64–70px이다. 실제 사람 옆에서 문이 더 높게 읽힌다. 이는 닫힌 문짝 비교이고 유효 개구부 인증은 아니다. 저줌0.6은 기존 사람 가독성 최소크기 보정을 받으므로 동일비율 실측으로 합치지 않았다.

줌1/.6에서는 긴 박공지붕 집의 높이 차이가 보이며 바닥 접지와 snow/boarded의 부착은 유지된다. 새 높은 지붕과 기존 이웃 풍차 날개가 확대판에서 더 겹친다. 기존 풍차 위치·깊이순서는 바꾸지 않았고 이 겹침을 해결했다고 주장하지 않는다. 신선한 집23 가까이에는 비교 성인이 없으므로 해당 뷰는 층 정합과 필지 경계만 판정했다. 신선층은 밝은 흰 회칠 세 군데로 확대판에서 두드러지고 풍화층은 작은 얼룩이라 보통 줌에서 미세하다.

## 실행과 관문

공식 실행 `astra-HEIGHT-L0C-before-dc881bb`, `astra-HEIGHT-L0C-after-09ddf12`를 판정에 사용했다. 전체 원본 JPEG·저장·측정·실패 생성물은 ZIP에, 세계 PNG는 해당 로컬 output 및 DGX _kept 실행에 보존하고 SHA를 원시 result에 남겼다. 새 계약 회귀는 적색 후 관련10/10 통과, 타입·lint 통과. 변경입력 기하 `astra-HEIGHT-L0C-geometry-09ddf12`는4행80조건 실패0·미개방0으로 통과했다. 최종트리 변경시험·병합검사·본선 SHA는 게시 영수증에 기록한다.
