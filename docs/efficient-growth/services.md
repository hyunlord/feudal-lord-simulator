# 효율 자동 성장: 공공시설 배치

기준 `bbc0c523` · 독립 브랜치 `codex/efficient-autogrowth` · 제품/main 미반영.

**변경.** 우물·시장·교회는 접근 가능한 후보 집합을 받아 실제 서비스 배분을 재계산한다. 새로 공급되는 미충족 **필지** 수가 최대인 위치, 동률이면 기존 자재 공급 건물의 도로 접점에서 후보 접점까지의 최단 도로 간선 수, 마지막으로 y/x 순서를 사용한다. 선택 함수는 격자·지형을 순회하지 않는다. 점유·성벽·자재 공사 경로·기존 서비스 공간 보호는 격자 어댑터가 검사한다. 연결 후보가 없으면 합법적인 지면의 잠재 도로를 평가하고 기존 도로 건설기를 통해 실제 연결을 먼저 만든다. 잠재 경로를 현재 통행 가능한 경로로 보고하지 않는다.

시장 `ceil(필지/24)+1`, 교회 `ceil(필지/32)+1` 상한은 완공·예정 건물을 함께 센다. 기존 시설의 여유 수용량과 연결을 재사용하며, 시장 인력은 현재 유휴 인력과 완공·예정 시설의 전체 인력 약속을 모두 검사한다. `worker_shortage`·`facility_limit`은 실제 조언 호출의 진단 수집기와 실행 영수증으로 전달한다. 인구·경제·서비스 거리·기본 8필지·D24 계약은 변경하지 않는다.

식량 담당자와 조정해 `autoplay.ts`의 `농장 수 × 5/3` 주택 상한만 제거했다. 실측 식량 정책이 실제 수요 증가를 관측하기 전에 4필지에서 영구 정지하는 순환 제약이었다. 기존 빵 재고 20, 인구 충족, 유휴 인력, 공사 대기, 정책 필지 상한은 유지한다. 이 변경의 실측 식량 회귀는 식량 작업 단위가 소유한다.

**검증.** 기존 제3 시장 건설을 재현하는 시험은 변경 전 실패했다. 관련 자동 성장·서비스·우물·자재 우선순위 50개와 진단 영수증 비간섭 8개 시험 통과. 신규 검사는 공급 필지 최대화, 용량 12, 도로 단절 배제, 입력 순서 독립성, 도로 거리 동률, 기존 용량 재사용, 예정 인력 부족, 서로 떨어진 두 지역의 교회 2개 공급을 포함한다. 기존 우물 좌표 시험 3개는 승인된 새 동률 규칙에 맞췄다. 자재 진입로는 종전 4→12 대신 4→8로 짧아졌으며 실제 reducer 도로 건설 후 합법적인 우물 건설을 확인한다. 전체 회귀·8필지·5개 seed·캡처는 최종 실행 검증에서 별도로 판정한다.

**seed1 반증.** 원본 v14 tick1,200,000 상태를 변경 없이 읽었다. 기존 교회(45,44) 밖 13필지는 모두 `outside`이며 단순 호수 횡단 판정 오류를 입증하지 못했다. 이 13필지를 하나 이상 덮는 후보 1,247곳 중 점유679/지형215/벽 간격108/지도 밖27/자동 배치 간격43/공사 경로118곳이 탈락하고 57곳이 남았다. 두 번째 교회의 최대 추가 공급은 6필지다. 모든 24필지를 대상으로 기존 점유와 도로를 보존하면 개별 합법·연결 후보 100곳의 어떤 두 후보도 합집합 상한이 18필지다. 두 건물의 동시 배치 가능성을 추가 검증한 수치가 아니라 낙관적 상한이다. 이는 **고정된 v14 배치와 현재 도로**에 한정하며, 새 도로·새 자연 성장 도시의 교회 2개 가능성을 부정하지 않는다. 새 seed1의 성공은 아직 주장하지 않는다.
