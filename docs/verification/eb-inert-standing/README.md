## 3 MiB 게시 한도에 맞춘 포장

125년 전체 strict archive는 `.remote-runs/eb-inert-standing-cohort-strict.tar.gz`에 보존하고, 게시에는 판정·범주·연도/사건별 표·원본 manifest의 무손실 gzip을 남겼다. 누락된 원자료는 같은 kept 실행을 fetch해 기존 archive.mjs로 다시 검증한다. 비영주 전체 strict archive는 `native/official/strict-archive.tar.gz`에 포함했다. 두 원래 SHA256SUMS는 전체 archive 기준이므로 축약 게시 디렉터리에 직접 실행하지 않는다. 게시 파일별 해시와 전체 archive 해시는 `publication-manifest.json`에 있다. 원래 manifest·README·판정의 바이트는 보존했다.
