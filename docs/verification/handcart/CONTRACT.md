# RB-HANDCART: 같은 운반자의 손·짐에 맞추는 손수레 계약

승인된 Wave 13 완성 시트 한 장을 `core-wave13-handcart` 팩 묶음의 `walker-transport` 네 방향 항목으로 읽는다. 원본은 384×148이며 각 칸은 96×74, 윗줄·아랫줄은 실제 보행 자세의 0·1 프레임이다. 별도 시계나 운반자를 만들지 않는다. 새 로더나 의존성 없이 기존 그림 계약 등록기·로더·축소 그리기를 사용한다.

## 좌표

`frames[].pivot`은 칸 내부의 손잡이 중점이며 바닥 피벗이 아니다. `mountOffset`은 키 17.6인 어른의 발에서 손잡이까지 세계 좌표다. 인물 크기가 바뀌면 이 변위와 수레를 같은 비율로 확대한다. 방향을 뒤집거나 비균일 확대하지 않는다. 두 자세는 같은 손잡이·짐 접점을 쓴다.

| 방향 | 손잡이 피벗: 원본 px | 발에서 변위: 세계 px | 짐 접점: 원본 px |
|---|---|---|---|
| NE | 72.5, 10.5 | 0.562, -8.860 | 39.5, 36.5 |
| SE | 70, 63 | -0.060, -8.669 | 43.25, 31 |
| SW | 25.5, 63 | -0.374, -8.956 | 47.75, 32.25 |
| NW | 23, 9.5 | -0.948, -8.715 | 56.75, 36 |

그림 비율은 17.6/71이다. 투명 여백을 포함한 96px 칸 너비로 짐 크기를 정하지 않는다. `payloadWidth` 39.05에 같은 비율을 적용하면 9.68 세계 px로 기존 짐 크기를 유지한다. 옛 수레로 돌아갈 때는 기존 사각형 중점과 너비의 55%를 같은 짐 접점 형식으로 변환한다.

## 소비자와 경계

합성 인물과 기존 배우 경로 모두 실제 `WalkerPresentation` 방향·보행 프레임을 사용한다. 인물 그림이 없으면 수레만 먼저 나타나지 않는다. 새 수레가 아직 없으면 기존 수레로 돌아간다. SE/SW는 수레·짐 뒤에 인물, NE/NW는 인물 뒤에 수레·짐을 그린다. 화물은 실제 carter.cargo를 사용하며 수량·운반 경로는 바꾸지 않는다. 줌 0.8 미만에서는 기존과 같이 짐 그림을 생략한다.

계약은 sourceRect·피벗의 범위, 네 방향, 두 가지 서로 다른 gaitFrame, 양수 확대율·기준 키, 짐 접점·폭과 계산 오버플로를 검사한다. 계약 전체가 유효할 때만 등록한다. 집중 시험 116개와 타입·변경 파일 린트는 제품 커밋 62e4a720에서 통과했다. 실제 화면과 게시 관문 결과는 별도 보고서에서 판정한다.

## 남겨 둔 측정 한계

손잡이와 짐 접점은 수동 그림 측정이며 손잡이 ±2·짐 접점 ±3 원본 px 정도 불확실성이 있다. 준비판의 남성 손 최대 잔차는 3.43 세계 px다. 이는 실제 화면 접촉 검증의 대체물이 아니다. 기존 인물의 손 소품과 손잡이 겹침, 건물 가림, 작은 줌의 바퀴 회전 판독은 실제 화면 판정에 남긴다. 원본 두 번째 줄은 바퀴 안쪽 무늬만 18도 회전한 것이며 바퀴 바깥 픽셀은 같다는 제작 기록이 있다.
