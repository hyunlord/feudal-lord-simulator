# 재현율 회차 계획

1. 완료: QA 기록에서 고정된 결함·정상 시험 항목, 원래 커밋·저장·카메라를 복원한다. 현재 본선은 원격 HEAD를 다시 확인한다.
2. 완료: 독립 detached worktree에서 과거/현재 일반 게임을 실행하고, 결함 실제 재현 여부를 직접 판정해 정답 ROI를 검출 전에 고정한다.
3. 완료: 기존 검출기의 TP/FP/FN 기준선 측정. 바위 마름모 누락을 회귀 시험으로 고정하고 이미지 검출기만 수정한다.
4. 완료: 같은 시험지 전후 비교 및 별도 정상/변형 장면 검증. 각 검출기 재현율·정밀도·표본/미재현 한계 보고.
5. 완료: 소스·시험지·결과·대표 JPEG·SHA256SUMS 경량 ZIP 검증, 4470 서버 종료.

기존 게임 코드 변경·커밋·푸시 금지. 도구/보고서만 변경. 정답은 QA 문서만 믿지 않고 실행 이미지에서 확인한다. 흰 도형 LOD는 여섯 분류와 의미가 다르면 별도 보조검출로 표기한다. 양성 표본 없는 검출기는 목표를 입증했다고 하지 않는다.

검증 상태: QA005는 정확한 카메라의 프레임16에서 재현되었고 이동 인물·성벽 보조검사를 추가했다. 98개 테스트, Ruff, Basedpyright 통과. 최종 통합 재실행·의미상 오탐 거부 적용 채점과 ZIP 검증 완료. 목표 달성 여부와 별개로 미달/FN을 남긴다. 서버4470 종료 확인.
