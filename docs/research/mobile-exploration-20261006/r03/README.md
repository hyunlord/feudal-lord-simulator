# R03 — 실제 엔진 기술 탐사

2026-10-06. 다섯 단계 중 세 번째 납품. 시제품과 최종 사업 판단은 아직 완료하지 않았다.

## 핵심 발견

1. 실제 advanceTick을 두 사례에서 총440회 실행했다(예열40+측정400). 초기 영주 평균1.562ms지만 최대164.020ms가 관측되어 UI 스레드 직접 실행을 권하지 않는다. 성숙768명 사례는 자율성/협상이 없어 성숙 영주 성능으로 일반화할 수 없다.
2. 정책→가구 후보→비용→이유 영수증 구조는 재사용 가치가 있다. 현재4방침을8축으로 확장하는 규칙, 일반 교역 계약, 공간 전투, 독립 서버 factory는 추가 작업이다. 다음 시제품은 별도 단순화 모델이며 원 PC 엔진 이식 완료를 뜻하지 않는다.
3. 웹부터 검증하고 계산은 서버 worker로 분리하는 방향이다. 공식 VM 단가를 붙인 조건부 compute 예시는 월$42~4,494로 틱 빈도/계정 수에 크게 좌우된다. 실제 용량·총 운영비·휴대폰 전력/열은 미측정이다.

## 파일 안내

- TECHNICAL_FEASIBILITY.md: 소스 재사용 경계, 실제 측정, Android 추정 한계, 따라잡기.
- DEPLOYMENT_AND_SERVER.md: 배포 선택과 최소 서버 역할.
- PLATFORM_RESEARCH.md: 공식 플랫폼 자료와 단순화 edge 산식.
- SERVER_COST_UPDATE.md: 원본 tick 기반 용량 민감도와 공식 VM 가격 예시. edge 산식과 혼용 금지.
- RUN.md, scripts/engine-bench.ts: 측정 재현법과 실제 harness.
- evidence/: 원시 측정 JSON, 측정 보고, 소스 지도, clone 기록, 독립 검토.
- SHA256SUMS: 본 파일을 제외한 전체 납품 파일의 SHA256.

독립 검토의 wall time 표현과 누락된 비용 문서를 수정했다. 공식 VM 가격 예시는 검토 이후 추가한 명시적 가정이며 독립 가격 감사가 아니다. 실제 휴대폰/클라우드 배포, 장기 catchup, 연례 부하를 검증했다고 주장하지 않는다. 본 저장소 수정·커밋·푸시·DGX 사용은 하지 않았다.
