# S8 자동 성장 자재·밀 운송 복구

## S8-F2 / R-8 밀 운송 막힘

A⁵-1 seed 1 원본(tick 1,200,000)은 곡창 7개로 상한에 도달했고 먼 곡창 여럿에 밀 100·빵 0이 쌓였다. 방앗간 7개는 모두 원료가 있지만 최근 2,400틱의 원료 부족 시간은 1,814/16,800, 빵 생산 501·요청 481·판매 17이었다. 이 상태에서 곡창만 추가하려는 기존 복구는 항상 `none`이었다.

1. 기존 경로 복구·곡창 복구를 먼저 유지한다.
2. 완전한 2,400틱 실측 창에서 원료 부족 시간이 있고 빵 여유가 부족하면, 밀 재고가 한 짐 이상인 곡창에서 가까우면서 빵이 빈 주택까지의 실경로가 짧은 방앗간 자리를 최대 24개 검사한다.
3. 기존 방앗간 하나라도 밀 0이면 증설 금지, 방앗간≤밀밭, 반복 실패 억제·인력·자재·성벽·서비스 공간 검사를 모두 유지한다.
4. 선택 조치를 진단 `transport_capacity_selected`와 실제 건물·좌표로 남긴다. 건설·생산·운송 수치나 게임 규칙은 바꾸지 않는다.

원본 gzip fixture는 `tests/fixtures/autoplay-recovery/`에 SHA와 출처를 보존한다. 수정 전 원인/조치 없음 재현 → 행동 테스트 실패 → 복구 구현 순서로 진행했다. 실제 엔진 24,000틱에서 처음 모든 집에 빵이 생긴 시점은 +751틱, 최종 빵 0 집 0개였다. 이 시험은 자동 성장 자연 상태의 재생이며 화면 플레이가 아니다.
