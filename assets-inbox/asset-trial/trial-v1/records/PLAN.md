# Astra image asset trial

Scope: compare one cottage, oak and grass candidate against Phase 14 assets. Existing product assets and publication remain unchanged.

- [x] Inspect current game art and manifest/render contracts.
- [x] Generate three reference-guided PNG candidates with the built-in image tool.
- [x] Normalize candidate dimensions and alpha to the existing asset contract; preserve raw outputs.
- [x] Capture baseline and candidates in the same actual game scene and inspect seams/transparency.
- [x] Record independent visual review, decisions and reproducible artifacts.

Acceptance: readable at actual game scale, compatible camera/light/style, no opaque sprite backgrounds, unobtrusive repeating terrain. This is a comparison experiment, not release authorization.
