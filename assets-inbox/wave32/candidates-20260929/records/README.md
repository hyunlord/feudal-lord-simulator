# Wave32 곡창 후보

기본형3 + 변형별 상태6종(18) + 분리 소품5 = PNG26장. 확인 그림2·CSV26행·검수표. 게임 설치 없음.

- a: 받침돌 위 목조·초가
- b: 받침돌 위 다른 목골조·평기와
- c: 두꺼운 석조·부벽·작은 환기창·돌판

공통 소품은 도르래 보, 밧줄/갈고리, 낱자루, 작은 자루 더미, 큰 자루 더미다. 제목의 약30장은 명시된 상태21장과 이 분리소품5장으로 구성했다. 게임 자원이나 기능은 추가하지 않았다.

## 규격

건물과 상태 PNG는 모두160×144 RGBA, 피벗(80,128). 제품의 원래 barn.png와 첨부 원본이 SHA256 일치한다. 기존renderScale0.4888888889와 점유2×2는 바꾸지 않는다. 원본 지면 접촉 띠를 픽셀 그대로 복원했다. 자동으로 알파 경계를 잘라 다시 중앙정렬하면 피벗이 달라지므로 하지 않는다. 소품은 별도 캔버스·피벗으로 CSV에 구분했다.

목조 받침돌은 쥐·습기를 피하는 버섯 형태로, 석조형은 같은 발판 영역에 기단과 부벽을 맞췄다. 굴뚝·사람·글자는 에셋에 넣지 않았다. 최신 의뢰서가 요구한 돌판을 석조 지붕에 사용했다.

## 상태 기준

|상태|시각 기준|
|---|---|
|full|높고 좁은 문 열림, 문 안과 앞 플랫폼에 많은 자루|
|half|문 열림, 내부와 앞의 자루가 full보다 적음|
|empty|문 닫힘, 자루 없음|
|snow|보이는 지붕면60~80% 눈, 남은 재료가 군데군데 보임|
|boarded|문/개구부 교차 판자|
|weathered|목재·석재의 얼룩/마모|

full·half·empty는 서로 대체해서 쓰는 그림이다. 명칭은 시각 단계이며 게임의 재고량 백분율·전환 임계값을 정한 것이 아니다. 확인판은 기본형+상태 하나씩이다. full/half 자루는 기존 플랫폼 영역 안에서 기본형의 투명한 틈으로 확장할 수 있다. 따라서 비축 상태에는 base-alpha 전체 클리핑을 하지 않고 접지·캔버스를 보호한다. 그 밖 상태는 기본형 실루엣 안에 제한한다.

## 확인 그림

1. Wave30 승인 합성의 곡창6곳을 후보로 교체한 두 줌의 오프라인 비교. Wave30 주택은 유지한다. 화면에서 위치/크기를 추정한 합성이며 실제 엔진 적용 또는 저장상태 재생이 아니다.
2. 기본형·6상태·분리 소품 비교. 비축단계가 문/자루로 읽히는지 실제 크기와 축소에서 검수한다.

## 측정·보존

눈 분모는 눈을 보기 전에 기본 지붕에서 지정한 독립 다각형이다. 최종 피복률은 roof-mask 알파128 이상 중 snow-mask와 최종 눈 레이어 모두 알파128 이상인 픽셀 비율. 마스크·픽셀수·원본 프롬프트·후처리는 records/에 보존한다. 모델 세부 버전과 seed는 도구가 노출하지 않았다.

경량 ZIP은 최종PNG, 확인JPEG, CSV, 검수·프롬프트·원본참조·측정마스크·스크립트·해시를 포함한다. 큰 생성 원본은 별도 astra-raw/wave32-20260929/에 보관하고 raw-inventory.json에서 경로와 해시를 확인한다. 기존 승인 이미지와 게임 파일을 덮어쓰지 않았다.
