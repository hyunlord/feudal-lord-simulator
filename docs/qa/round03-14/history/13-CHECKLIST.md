# QA ROUND 13 — 누적 검토 항목

누적 문서의 과거 사례·“이번” 수치는 해당 회차 이력이다. 13회차 실측과 판정은 REGRESSION.md를 기준으로 한다. 아래 12회차까지의 사례는 이력이다. 과거 파일명·수치는 이전 회차의 근거이며13회차 재관측 결과가 아니다.

1~3회차의 누적 기준을 유지한다. **검토 기준 추가는 결함 확정이 아니다.** 관찰 결과는 REGRESSION.md (이전 회차 출처: REGRESSION.md)에 분리한다. 사용자 확정 결함은 같은 재현으로 수정 여부를 검증하기 전 닫지 않는다.

공통: 원본 저장·SHA·커밋·화면 연도·틱·카메라·줌·속도·조작을 기록한다. 없는 값은 미수집. 같은 카메라100ms 목표 간격20프레임과 실제 타이밍을 보존하고, 반복 GIF의 루프 점프를 순간이동으로 세지 않는다. UI 스크롤 영역의 초반 잘림과 접근 불능을 구분한다.
