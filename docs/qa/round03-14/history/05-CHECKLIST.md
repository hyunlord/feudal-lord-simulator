# QA ROUND 05 — 누적 검토 항목

1~3회차의 누적 기준을 유지한다. **검토 기준 추가는 결함 확정이 아니다.** 관찰 결과는 REGRESSION.md (원문 경로: REGRESSION.md)에 분리한다. 사용자 확정 결함은 같은 재현으로 수정 여부를 검증하기 전 닫지 않는다.

공통: 원본 저장·SHA·커밋·화면 연도·틱·카메라·줌·속도·조작을 기록한다. 없는 값은 미수집. 같은 카메라100ms 목표 간격20프레임과 실제 타이밍을 보존하고, 반복 GIF의 루프 점프를 순간이동으로 세지 않는다. UI 스크롤 영역의 초반 잘림과 접근 불능을 구분한다.

## 3회차 이후 전체 범위
- UI-02: 인물 카드·전기·가계도·결말·설정의 실제 긴 이름/큰 수치를 읽고 스크롤·접기·되돌아가기. 텍스트가 틀 밖으로 넘거나 다른 조작부와 겹쳐 읽거나 누르지 못하면 실패. 합성 스트레스 상태는 정상 저장과 별도 표기.
- 세계-01: 줌0.5~2, 네 계절,1~5장, 정상 선택 가능한 새 땅의 빛·크기·반복·계절 재료를 같은카메라 비교. 대상이 분간 안 되거나 계절 변경에 발판/피벗이 튀면 실패.
- 움직임-03: 나무20프레임 모두에서 줄기 중간이 누락되는 프레임을 확인. 동일 계절/고정 카메라에서 수관과 밑동 사이 실제 틈이 생기면 실패.

- UI-03: QA정보 켠 채 큰 패널/전체화면을 열고 다시 닫아,오버레이가 조작부를 덮거나 선택 좌표 수집을 방해하는지 확인. 패널의 조작 경로를 가려 복구 불가하면 실패.
- 인물-02 /014: 결정 발신자(국왕·귀족·상인)의 카드→전기에서 직함을 읽는다. 내부 영문 역할 키가 한국어 직함 대신 보이면 실패.
- UI-04 /015: 인물 전기의 기록 없음/긴 기록을 원본 크기로 보고 초상-본문 사이 장식선을 비교. 글자가 선 위에 겹치거나 틀 바깥을 넘으면 실패.
- UI-05 /016: 긴 설명·청원자 카드가 있는 결정창을 1600×1100·1280×720에서 연다. 모든 선택지와 보류 버튼의 경계가 분리되는지 확인; 보류 버튼이 선택지 본문/경계 위에 겹치면 실패. 클릭 실패 여부는 따로 실제 조작으로 확인한다.

- 계보-01: 연대기 책 가문 계보와 가계도에서 부모 이름이 명시된 자녀 행을 비교한다. 모자/부자 관계와 세대·들여쓰기가 모순되거나 기준 설명 없이 동일 단계로 읽히면 가독성 검토 후보. 실제 혈통 계산 결함은 별도 확인한다.

- UI-06 /017: 정상 캠페인 건설→생업을 열고1600×1100→768×900→375×812로 변경한다. 닫기·재열기·상단 스크롤 후 분류와 모든 항목에 접근하는지 확인. 창 밖으로 밀린 조작부가 복구되지 않으면 실패;375 fresh start와 resize는 별도 기록.

- UI-07 /018: 설정 상단을1600×1100·1280×720에서 열고 튜토리얼 설명과 음량 제목을 읽는다. 줄 영역이 겹쳐 글자가 포개지면 실패. 하단 저장은 스크롤 접근 여부를 별도 확인하며 단순 초기 잘림은 실패가 아님.

- 계보-02: 실제 가계도에서 동일 이름·초상·생몰년 노드와 고리/자녀 연결을 추적한다. 같은 인물이 중복됐는지, 어느 배우자/부모에 연결됐는지 화면으로 분간할 수 없으면 관계 가독성 후보로 남기고 개별 전기·다른 저장 재현으로 확정한다. 데이터 오류와 단순 패닝 범위는 구분한다.

- UI-08: 계절 결산 카드 상단 장면/증감 배지를 두 계절 이상 비교한다. 내용이 없는 장식 슬롯이 남아 무엇을 뜻하는지 읽히지 않으면 시각 검토 후보로 기록한다. 누락 데이터/수입 계산 오류와는 구분한다.

- UI-09 /019: 월드 상단 속도·설정 조작부를1600×1100·1280×720·좁은화면에서확인한다. summary/button의보이는글자와44px표적전체가뷰포트안인지보고 실제마우스로연다. 글자나조작부일부가화면밖으로잘리면실패;남은부분의클릭성공은별도기록.

## 4회차 새 검토 기준(후보는 결함 확정과 구분)
- 지면-01: 도시 동남쪽 생울타리 안 이랑 지면을 줌1.3/2에서 보고 나무 밑동까지 추적한다. 수관이 가장자리에서 덮이는 것과 밑동이 이랑 내부에 놓인 것을 구분한다. 숲/경작지 표현이 겹쳐 땅의 용도가 읽히지 않으면 시각 개선 후보; 실제 시설을 선택하지 못하면 논리적 밀밭 점유 오류로 단정하지 않는다. 원본1380→1396, 칸61,37, camera(-531,-2438).
- 청원자-01: 청원의 인물 상태와 전기 사망 연도·계절을 비교한다. 현재 신규 발신인지 과거 발신 후 보류된 청원인지 먼저 구분한다. 현재 활동 중이라는 설명과 이미 사망한 상태가 모순될 때 실패; 같은 계절만 표시되어 선후를 모르면 미검증. 단순 고인 표시만으로 실패 아님.
- 기록-01: 정상 UI에서 새로 선택한 결정명과 그 직후 생성된 연대기 관계 사유·결정명을 비교한다. 서로 다른 선택을 한 것처럼 읽히면 내용 후보; 과거 저장의 이전 문자열은 신규 선택 재현과 구분한다.
- UI-10 /020: 정상1407 가계도에서 자손8명을 펼쳐 ‘나이 든 조앤/윌리엄’처럼 두 줄 이름의 아래 글자를1600/1280에서 본다. 정착 후에도 두 번째 줄의 글자 하단이 잘리면 실패. 수평 스크롤의 화면 가장자리 잘림과 구별하며 클릭 전기에서 전체 이름을 읽을 수 있는지도 별도 기록한다.
- UI-11 /021: 건물 상세창의 닫기 버튼을 마우스 밖/호버/키보드 초점에서 비교한다.44px 버튼이 있어도 기본 상태에서 기호를 알아볼 수 없고 호버에 의존하면 실패. 실제 닫기 조작 성공과 식별성을 별도로 기록한다. 곡창2개(61,44)/(52,37),1600/1280 재현; 모든 시설 일반화는 추가 확인.
