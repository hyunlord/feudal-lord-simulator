## 수정 반복

1. 첫 후보: 숲 풀덤이 저배율에서 낙엽 바닥에 묻힘. 확인 그림에서 잔디·고랑 배치 오프셋 확인.
2. 수정: 숲 A/B를 더 큰 단순 풀덤과 적은 잎으로 재생성, 확인 그림 위치 수정.
3. 최종: 숲 실루엣 가독성은 개선. A/B 반복 리듬과 잔디 저배율 가독성은 미달로 남음. 합격 점수를 임의로 올리지 않고 후보 상태로 제출.

## 설치 단계에서 구분해서 볼 것

- S자 합성 양 끝의 평평한 절단은 확인 그림의 경로 종료 처리다. 스트립 좌우 반복 접합과 다른 문제다.
- 숲 배경의 직사각형 윗변·옆변은 `forest_floor.png` 비교 배경을 자른 선이다. 데칼 자체의 불투명 사각 테두리가 아니다.
- 밀밭 공유 변 고랑은 작은 면적과 밀밭 그림에 겹쳐 읽힘이 제한된다. D1에서 실제 피벗·가림을 검증해야 한다.
- Canvas 2D 확인 그림은 런타임 통합·성능·곡선 매핑 품질의 증거가 아니다.
