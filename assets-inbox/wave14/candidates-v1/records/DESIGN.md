# Wave14 후보 제작 기준

- 원본: 첨부 P0/Wave8. 잉글랜드 1300–1450 프로젝트 자체 자료만 사용.
- 기능 80%, 시대 장식 20%. 따뜻한 양피지, 짙은 oak, 붉은 끈/밀랍. 중앙 내용 면적을 확보하며 모서리 장식 절제.
- 자산에는 글자·숫자 없음. 확인 그림의 설명만 허용.
- 문장 A 및 표식 B는 색이 구워지지 않은 흑백 RGBA. 색은 합성기가 입힌다.
- 방패 3개는 한 PNG에 흰 채움+검은 외곽선, 투명 바깥을 담는다. 실제 채널 계약은 제작 메타데이터 참조.
- C 도시 인장은 빈 글자 띠, 역사적 실제 도시 인장 복제 금지.
- 9-slice는 고정 모서리·늘어나는 변·내용 영역을 수치로 기록하고 확대 검사.
- 후보만 납품. 제품 게임 설치·새 UI 구현·런타임 성능 검증은 범위 밖.
