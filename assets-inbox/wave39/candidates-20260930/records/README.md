# Wave 39 — 세계 날씨 입자·데칼 후보

PNG 58장, 확인 그림3장, 생성 기록 CSV, 검수표. 게임에 설치하지 않았습니다.

## 표시 기준

이번 의뢰의 줌1.0은 타일128×64px입니다. PNG 셀 전체 크기와 실제 그려진 입자 크기는 다릅니다. 빗줄기는 실제 높이 최대10px이며 사람보다 작게 표시합니다. 배율이 낮아지면 가는 비 일부가 안 보이는 것이 정상입니다. 잘 보이게 하려고 사람 크기로 확대하지 않습니다.

## 렌더 인계

- **비:** 세계 좌표에서 생성하고 높이·바람에 따라 이동합니다. 구름 그림자의 이동 범위 안에 강수량을 집중합니다. 그림을 화면 전체 격자로 반복하지 않습니다.
- **접촉:** 입자가 지면·지붕에 닿을 때 해당 표면 튐 시트를 재생합니다. 지붕·건물 뒤 입자는 가림 대상입니다. 물 위 파문은 기존 Wave29를 재사용합니다.
- **젖음·웅덩이:** 표면 마스크 안에만 적용합니다. 구름 그림자는 넓은 영역 한 장으로 배치하고, 젖음 톤 마스크만 반복합니다. 웅덩이는 길·낮은 땅에 드물게 배치하며 벽·수관·실내에 찍지 않습니다.
- **낙엽:** 해당 수종 수관에서 생성해 프레임을 바꾸며 내려오고, 지면 접촉 뒤 공중 입자를 없애고 나무 밑·길가 누적 데칼로 표현합니다. 잎 무리를 반복 영상 필터로 쓰지 않습니다.
- **눈:** 작은 눈송이·바람 시트는 세계 입자이며 발자국 데칼은 지면에 고정합니다.
- **시트:** 프레임 좌표·피벗·권장 알파·속도·바람 기울기는 CSV와 생성 manifest를 기준으로 합니다. 수치는 초기 권장값이며 엔진 구현·성능 측정 결과가 아닙니다.

## 확인 그림

1. 사용자 스크린샷 구도의 기존 비와 새 재료를 합성한 비 비교. 원본에 박힌 긴 빗줄기를 제거한 바탕은 생성 편집 재구성이며 실제 게임 실행 화면이 아닙니다.
2. 가을 나무에서 떨어지는 잎과 나무 밑·길가의 누적 낙엽.
3. 사람·집·타일과 입자 및 데칼 크기 비교. 확대 인셋과 실제 표시 크기를 구분합니다.

## 범위와 기록

`records/SCOPE.md`에 약60장→58장 산정과 세부 항목 해석을 기록했습니다. 생성 중간 고해상도 파일과 참조 원본 중복은 ZIP에서 제외합니다. 원본 경로·해시·실제 프롬프트는 생성 기록에 있습니다. 후보 검수는 PNG와 오프라인 합성 범위이며 실제 깊이 정렬·가림·애니메이션·성능은 렌더 설치 단계에서 검증해야 합니다.
