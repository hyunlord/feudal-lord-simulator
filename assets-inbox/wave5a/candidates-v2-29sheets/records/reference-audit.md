## 1. 수량 불일치

의뢰서 본문 표는 노동 5 + 장인 4 + 직물 3 + 부유 상인 4 + 젠트리 2 + 하인 4 + 사제/수도사 2 + 수녀 1 + 빈민 2 + 농촌 방문객 2 = **29**다. 남 15, 여 14도 실제로 29다. 사제 1과 베네딕토 수도사 1은 역사 설명상 서로 다른 역할이므로 산술 중복이 아니다. 제목·최신 사용자 요청·CSV54행(28+24+2)은 28을 지시한다. 제작 책임자가 한 변형을 통합 또는 보류하는 수량 결정을 별도 기록해야 하며, 29장 제작을 28장이라고 보고하면 안 된다. 본 감사에서는 임의로 누락 항목을 결정하지 않았다.

현재 Wave5a ZIP의 '기존 주민 11종'은 실제로 **actor 9종 + cart 2종**이다. actor는 builder, carter, civilian_man, civilian_woman, cleric, farmer, guard, logger, merchant. 아이·노인 몸을 추측해 추가하지 않는다.

## 3. 색·염료 기준

첨부 `딥리서치_인물초상화_워커.md`의 '색·염료와 계급' 절 기준.

| 색군 | 이번 후보의 적용 규칙 |
|---|---|
| 자연 회갈·회색·크림 | 무염색 양모/린넨. 모든 계층 가능. 빈민 전부를 이 색으로 고정하지 않는다. |
| 저·중채도 파랑 | 대청. 평민도 사용. 회청·퇴색 남색 등 구분. 귀족 전용색으로 취급 금지. |
| 벽돌적색·적갈색 | 꼭두서니. 노동·장인의 주력 빨강. 원색 scarlet로 치환 금지. |
| 황색·황록 | weld/식물 염색 결과색. 황토를 '대표 중세 염료'라고 기록하지 않는다. |
| 녹색 | 청+황 복합 염색. 평민에게 금지하지 않으며 장인·상인 비중을 높일 수 있다. |
| scarlet/crimson | 고급 모직·케르메스 사치성. 강한 빨강 전체복은 부유 상인/상층으로 제한. |
| 자주·보라 | 균일하고 깊은 자주는 상층. 저채도 plum은 드문 상인/젠트리. 왕실 절대 독점이라고 설명 금지. |
| charcoal/brown-black | 천연 암색 양모와 rich black을 구분. 빈민=검정 또는 성직자=검정 일률화 금지. |
| 흰색 린넨 | 따뜻한 미색. coif/veil/apron에 널리 사용, 눈부신 순백을 기본으로 쓰지 않는다. |

같은 계급 안에서 주색뿐 아니라 머리쓰개 형태도 비교한다. 단순한 전역 색상 이동으로 피부·가죽·금속까지 옷색으로 물들이지 않는다. 사치법의 역사적 경향과 이번 산출물의 색 배정 계약을 구별한다. 본 배치는 위 색 제한을 지키되 이를 1300–1450년 사람 전체에 대한 법적 절대금지라고 주장하지 않는다.

## 4. 역사·제작 금지 검수 목록

아래는 첨부 문서에 있는 금지/단순화 주의를 검수 가능한 항목으로 옮긴 것이다. 아직 결과 이미지 검수 통과를 선언하지 않는다.

1. 평민·빈민을 전부 갈색 누더기 또는 색 없는 옷으로 만들지 않는다. 수선·퇴색·맞음새로 상태를 나타낸다.
2. 장인=누더기, 하인=빈민으로 통합하지 않는다. 청결한 실용복과 좋은 옷도 가능하다.
3. 평민 전체복에 선명한 scarlet, 균일한 고급 자주, rich black을 무분별하게 쓰지 않는다.
4. 사제는 tonsure + 긴 세속 성직자 gown. 수도사 habit/cowl과 구분하며 예배 제의를 일상 보행복으로 넣지 않는다.
5. 수도사는 이번 명세의 베네딕토회 검은 habit/cowl. 수녀는 검은 habit+흰 wimple. 여성 종교인을 교구 사제로 표기하지 않는다.
6. 성인 여성 전원에게 동일한 흰 wimple을 쓰지 않는다. coif, veil, headcloth의 형태 차이를 둔다.
7. 과부=검정, 노인=지팡이, 미혼=긴 머리 풀기 같은 일률적 신호를 사용하지 않는다. 이번 배치에 별도 노인/아동 몸 추가 금지.
8. 피부톤·체형을 계급·직업·도덕성과 연결하지 않는다. 필사본 피부색을 인구통계 표본처럼 해석하지 않는다.
9. 소지품을 몸 시트에 굽지 않는다. 도끼/망치/짐/저울을 모든 직업 프레임의 영구 의상으로 만들지 않는다.
10. 겨울은 외투·후드 레이어만. 새로운 몸이나 별도 겨울 시대복으로 재설계하지 않는다.
11. 방향마다 모자·의복·짐 방향이 바뀌지 않도록 원본 승인 4방향을 고정한다. 자유 인물 생성 금지.
12. 밝은 순원색·진한 픽셀아트 외곽선 대신 저채도 손그림 색면, 부드러운 좌상광을 유지한다.
13. 금속·가죽은 재료별 색을 유지한다. 직물과 함께 자유 hue shift하지 않는다.
14. 1463·1483년 사치법을 1450년 이전에 소급 적용하지 않는다.
15. 합성 거리 장면·파일 겹치기·정적 방향 검사를 실제 게임 합성기/애니메이션 통합 검증으로 부르지 않는다.

## 5. 검수의 한계

원문에는 시대 일반 금지 목록(예: 모든 현대 장식·재단의 세부 목록)이 별도의 완결 표로 들어 있지 않다. 위 목록을 임의로 '학술적으로 완전한 역사 금지 규칙'이라고 확장하지 않았다. 비율·팔 각도·머리 이동·발 픽셀·소지품 잔존은 최종 이미지별 검사에서 별도로 판정해야 한다.
