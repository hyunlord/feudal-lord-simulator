# 간판 파일럿 검수

상태: candidate, 설치하지 않음. 완성 그림 8장. 빵·에일·대장간·직물 × 1300/1420. 모두 RGBA PNG 137×137이며 내장 image_gen 도구로 각각 생성했다. 원본 생성은 1280×1280, sips로 한 번 137×137 축소했다. 생성 원본 경로·해시·전문 프롬프트는 generation.json에 보존했다. 경량 묶음에는 원본 대형 생성물을 중복 포함하지 않는다.

## 참조와 그림 방식

프로젝트 Wave36 실험의 sign_bread/ale/smith/textile.png는 작은 업종 소품이었다. 이 원본의 작은 바구니를 완성 간판이라고 재사용하지 않았다. 재료·업종 참조로만 삼아 전체 걸이와 간판을 하나의 완성 그림으로 생성했다. 기존 파일은 변경하지 않았다. 간판 얼굴과 걸이를 코드로 붙인 부품 조립은 없다. 1420판은 1300 완성 그림을 참조한 전체 이미지 편집이다.

빵 1300은 원본 빵 소품을 재료 참조로 사용. 에일 1300은 원본 ale-stake를 개념 참조로 사용. 대장간·직물 1300은 생성된 빵 1300판의 구조와 해당 원본 소품을 참조. 각 1420판은 해당 업종의 1300 생성판 하나를 직접 편집했다.

## 검증

- 실제 137px 비교판을 눈으로 확인했다. 네 업종이 식별되고, 1420판은 같은 걸이·간판으로 읽힌다. 빵·대장간·직물의 낮은 돋을새김과 안쪽 테두리, 에일의 보수된 접합과 칠을 비교한다.
- 흑색 외곽 스트로크·문자·현대 로고·홉·산업 도구가 없다. 좌상광과 따뜻한 참나무를 사용한다.
- 동일 캔버스, 동일 제안 anchor (27,27)을 CSV에 명시했다. 이는 새 파일럿의 쌍별 등록 기준이며 Wave36의 원본 피벗을 보존했다고 주장하지 않는다. 실제 벽 설치 피벗은 렌더러 통합 때 조정해야 한다.
- 알파 실루엣 IoU(alpha>127): 빵 0.98037, 에일 0.95391, 대장간 0.99442, 직물 0.98864. 픽셀 동일 알파는 네 쌍 모두 아니다. geometry.json에 실측 경계·투명 픽셀 수를 보존했다. 동일 캔버스 검사는 통과하지만 엄격한 픽셀동일 실루엣 게이트는 통과하지 않았다.
- proof는 정적 합성이다. 실제 게임의 벽 부착·저줌 판독·가림·그림자 검증은 수행하지 않았다.

## 역사 해석 한계

이 네 표식의 차이는 1420년에 색칠·조각·철물·염색이 발명되었다는 주장이 아니다. 같은 가게가 부유해져 간판을 다시 주문하거나 수리한 게임상의 변형이다. 이전 시대에도 염색·장식·철물은 있었다. 에일은 두 시대 모두 가지 표식을 유지한다. 간판 하나만으로 1300과1420을 안정적으로 판별할 수 있다고 주장하지 않는다. 시대 눈가림 검사는 사람의 복식과 건물의 복합 단서가 있는 거리 장면에서 평가해야 한다.

경량 묶음의 확인 그림 정본은 `proofs/`에 있다. 같은 그림의 records 사본은 중복 용량을 줄이기 위해 묶음에서 제외했다.
