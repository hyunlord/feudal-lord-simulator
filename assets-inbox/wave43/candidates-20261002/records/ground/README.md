후처리: fill은 원본에서 최종크기로1회축소. strip은 생성기가 추가한 큰 상하 투명여백만 실측 alpha>127 bbox로 제거한 뒤1회축소, 원래 strip알파를 복원했다. 마지막으로 X양끝16px를 대칭혼합해 경계일치; fill은 Y10px도 동일처리했다. alpha0 RGB는0으로 정리했다. 모든 절차는 `scripts/finalize.mjs`에 보존했다. 경계수정은 내부재료를 유지하며 방향별 반복끝만 정합한다.

검증: 최종PNG를 다시 읽어8장 크기, 지정축 반대편 RGBA MAE0, alpha0 RGB0을 확인했다. fill5는 완전불투명. `records/QA.json` 참조. 각 자산2×2 반복으로 겨울→봄→여름 비교판을1.0/0.6배로 만들었다. 왼쪽 겨울, 가운데 봄, 오른쪽 여름이다. 원본 강가 여름은256×256이라 비교판에서만256×128로 맞추었고 이는 원본규격이같다는뜻이아니다. 밭겨울은 휴경proxy이지 같은새싹의겨울상태가아니다.
