## QA020 — 기존 두 줄 이름 잘림 해소 확인

03회차 `normal-ui-1407` 원본, 1407년 가을 430090틱 정지. 직전 QA01은 줌 2, 카메라 (544, -2277)이며 가계도 전체 화면에서는 QA가 표시되지 않는다. 장부 → 권리 → 나이 든 존 → 전기 → 가계도 → ‘월터의 자손 8명 펼치기’를 실제 입력했다.

[1600×1100](../evidence/ui15-03-tree-expanded1600.jpg), [1280×720](../evidence/ui15-04-tree1280.jpg), [1024×768](../evidence/ui15-05-tree1024.jpg) 모두 ‘나이 든 조앤 드 포콩발’, ‘나이 든 윌리엄 드 포콩발’의 둘째 줄 전체가 읽히고 생몰 행과 분리된다. 과거 `/tmp/QA_ROUND_08/evidence/ui8-07-tree1600.jpg`를 직접 열어 같은 카드의 둘째 줄 하단 누락과 비교했다. 이번 판정은 단순 말줄임표와 원래 두 줄 잘림을 혼동한 것이 아니다. **같은 표본에서 수정 확인.** 1024 화면의 오른쪽 도표 노드 일부가 창 밖인 것은 카드 내부 이름 잘림과 별개다.

## QA015 — 재현

04회차 `normal-ui-1384-before-tax` 원본 336292틱에서 사건 카드 일시정지 ON, 계절 결산 OFF로 바꾼 뒤 실제 5배속 진행하여 1384년 여름 337160틱 과세 사건에 도달했다.

주의: ui15-07~09 파일명은 tax를 포함하지만 실제 사진은 왕 인물 카드다. 결정 빈 화면 근거로 사용하지 않는다.

## 긴급 QA034 — 결정 본문·선택지 비표시

[최초 1600](../evidence/ui15-06-tax.jpg), [정착 1024](../evidence/ui15-10-tax-settled1024.jpg), [정착 1280](../evidence/ui15-11-tax-settled1280.jpg), [1600 재복귀](../evidence/ui15-12-tax-settled1600.jpg)에서 결정 제목·본문·선택지·보류 버튼이 보이지 않고 양피지·문장·초상만 보였다. 12에서는 초상에 마우스를 올린 발신자 칸은 표시되나 결정 내용은 여전히 없다. 원인은 미확정이다.

모든 조작이 막혔다고 단정하지 않는다. 초상 실제 클릭은 성공했고 전기 → Esc → 결정 → Esc로 [세계 복귀](../evidence/ui15-17-decision-escape.jpg)도 확인했다. 보이지 않는 선택지를 강제 클릭하거나 좌표를 추정해 누르지 않았다. 과세는 Esc로 닫은 상태이며 선택 결과를 만든 것이 아니다.

`urgent/README.md`와 `/tmp/fls-qa-round15-urgent-decision.zip`으로 사진 4장, 대응 메타데이터, 출처를 전달했다. ZIP 무결성 검사 10파일 통과, 약543KB. **016의 기존 겹침은 내용 소실 때문에 안 보인다고 해소 처리하지 않는다.**

## QA016 — 미검증, 종결 보류

과세 창을 Esc로 닫고 실제 5배속으로 진행했다. 1384년 가을 338102틱에 정지하여 Esc 설정에서 사건 카드 일시정지를 OFF로 바꿨다. 계절 결산은 OFF 유지, 자동 발전 상태는 변경하지 않았다. 1394 길드 사건에는 도달하지 않았다. 리더의 bounded 마감 지시에 따라 1388년 겨울 355082틱에서 실제 정지하고 ui15-18-stop-progress.jpg로 마지막 상태를 보존했다. 줌2, 카메라(544,-2277),1600×1100. 과세 결정 본문 소실 QA034로 기존016 겹침을 읽을 수 없으며, 다른 길드 사건까지 억지로 진행하거나 보이지 않는 선택지를 누르지 않았다. **016은 수정 확인이 아닌 미검증으로 유지한다.**
