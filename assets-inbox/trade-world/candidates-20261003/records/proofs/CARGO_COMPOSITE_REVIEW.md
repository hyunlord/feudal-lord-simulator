# Cargo 정적 합성 독립 검토

**최종 판정: 10종 정적 합성 수용. 작은 통 접점 문제는 재합성 검토로 해결.** 10개 JPG를 직접 열어 2 gait × 4방향, 총 80개 합성을 검토했다. 기존 74px 몸체에 화물을 덧붙인 정적 proof이며 엔진 설치, 실제 보행 또는 실제 LOD 검증이 아니다.

## CARGO-GRIP-001 — 작은 통 지지 방식 (정적 proof 해결)

`cargo_small_cask_NE`, `cargo_small_cask_SE`, `cargo_small_cask_SW`, `cargo_small_cask_NW`의 두 gait가 해당된다. 통에는 보이는 손잡이가 없는데 현재 위쪽 가장자리가 손에 놓여 통이 윗면에 매달린 인상을 준다. 이 초기 결함은 좌표상 접촉 실패보다는 지지 방식의 시각적 문제였다. 밑면을 손바닥으로 받치는 배치가 더 자연스럽다.

32×32 화물 캔버스의 좌상단을 (0,0)으로 하는 권고 접점은 다음과 같다. 실제 PNG를 직접 보고 중심 열의 불투명 하단 경계도 확인했으며, 접점은 외곽보다 약 1px 안쪽에 둔다.

| ID | 권고 grip (x,y) | role |
|---|---|---|
| cargo_small_cask_NE | (16, 26) | underside_support |
| cargo_small_cask_SE | (16, 25) | underside_support |
| cargo_small_cask_SW | (16, 26) | underside_support |
| cargo_small_cask_NW | (16, 26) | underside_support |

`prop_scale=0.65`를 유지한다. 기존 y≈8 접점에서 위 좌표로 옮기면 통은 손 위로 몸체 좌표 약 11–12px 올라간다. 수정된 통 proof를 다시 직접 열어 8개 합성을 모두 확인했다. 통이 손 위에 놓이는 지지 방식으로 개선되었고, NE/SE 손은 하단·안쪽에 닿는 것으로 읽히며 얼굴·발 침범은 없다. SW/NW 몸체 뒤 배치도 유지된다. 기존 손 포즈를 이용한 정적 근사라는 한계는 남지만 추가적인 명백한 결함은 발견하지 못했다. `provenance/CARGO_ANCHOR_REVISIONS.json`에 기록된 4개 접점 변경을 확인했다. 검토자는 원본 그림이나 합성 코드를 수정하지 않았다.

## 작은 preview의 한계

H16에서는 바퀴의 큰 원형, 붉은 천, 밝은 자루 등 일부 실루엣·색 덩어리가 남지만 10종을 안정적으로 식별할 수 없다. 0.6 proxy는 더 작아 손 접촉·종류·깊이를 판정할 근거가 부족하다. 이 축소본으로 실제 LOD 통과를 선언하지 않는다. 두 gait 정지 이미지는 연속 보행의 흔들림이나 프레임 사이 손 분리를 검증하지 않는다.

검토 시점 proof SHA-256과 10종별 판정은 `cargo-composite-review.json`에 기록했다. 실제 보행, 엔진 깊이 정렬, 카메라/DPR, 실제 LOD 임계점은 모두 미검증이다.

SHA-256은 최종 파일 기준이다. 최초 해시 수집은 병행된 통 재생성 이후에 이루어졌으므로 수정 전 통 proof 해시는 본 검토자가 보존하지 못했다. 최종 확인 시 JSON의 10개 해시가 실제 파일과 모두 일치했다.
