## 사슬 캡처를 Mac에서 돈 이유
- **방식:** 도시 전체가 한 화면에 들어오는 줌 0.8에서 보면서, 고리의 화면 좌표(`tileClientPoint`)로 잘라 고리를 두른다.
- **DGX 결과:** 같은 스크립트를 DGX에서 돌리면 시작 카메라가 동쪽으로 치우쳤다. 고리 6개 중 4개의 좌표가 화면 밖(x ≤ 2)으로 나왔다(`.remote-runs/render-I7-a6f4417/`).
- **판단:** 원인(DGX Chromium의 시작 카메라)은 캐내지 않았다. 사슬 관문만 Mac 실행 결과를 증빙으로 쓴다(`captures.json`의 `source`). 나머지 전·후 캡처는 모두 DGX 결과다.

## 결정
- **IN7-D1:** 줌 LOD 기준은 수레 적재물·소품 0.8, 장식 0.6이다. 설계서 8절에 LOD 표가 없어 가시성 설계 D5에 맞춰 정했다.
- **IN7-D2:** 들일 소품은 달력으로 고른다(봄 전반 쟁기·후반 씨앗, 가을 낫). 밭 줄 단계 대신 쓴 것은 워커가 줄을 알지 못해서다.
- **IN7-D3:** 지붕 눈·판자는 단독 필지 L0~L4만 한다. 쌍집·시설은 Wave 7 층이 없어서다. 변형 집은 같은 틀이라 기본 층을 쓴다.
- **IN7-D4:** S4 연기 없는 집에서 F0-A 떠날 준비·황폐를 떼어 S12·빈집 신호로 옮겼다. 강조 우선순위는 끊긴 길 > 연기 없는 집 > 짐 진 가족 > 빈집 > 빗장 > 빈 좌판 > 빈 필지다.
- **IN7-D5:** 볏단은 "헛간 운반 대기량"을 수확된 줄의 칸 수(4칸마다 한 단)로 읽는다. 엔진에 볏단 재고가 따로 없다.

## 남은 것
- 쌍집·시설의 지붕 눈·판자 층(Astra 후보).
- 판재 적재물은 0.6에서 층수가 읽히지 않는다(Astra 검수와 같음). 그래서 0.8 미만은 숨긴다.
- DGX 시작 카메라의 치우침(사슬 스크립트).
