# Wave22 지도 유형별 지면 후보

에셋 **51 PNG**: 지면 fill 15, 전이·해안·갈대 띠 16, 소품 데칼 20. 확인 그림 3장, 생성 기록 CSV 51행, 자체 검수표를 함께 제출합니다. 전부 `candidate`이며 게임에 설치하지 않았습니다.

## 역할·크기·반복

| 종류 | 원본 크기 | 반복·알파 |
|---|---|---|
| 유형별 여름·가을·겨울 fill | 256×128 | XY 반복, 불투명 |
| 풀밭↔백악·히스·습지·해안 전이 | 512×64 | X만 반복, Y 투명 가장자리 |
| 모래·자갈·염습지 해안, 갈대 띠 | 512×96 | X만 반복, Y 투명 가장자리 |
| 소품 데칼 | 64×48~128×96 | 반복 없음, 투명 RGBA, 사방 8px 여백 |

fill만 네 변을 이어 붙입니다. 띠를 세로로 반복하거나 데칼을 면 무늬처럼 이어 붙이는 방식은 이 에셋의 계약이 아닙니다. 띠는 왼쪽·오른쪽 끝까지 사용하며, 위쪽은 기존 풀밭/육지, 아래쪽은 유형 지면/물 쪽입니다. 실제 배치 방향은 각 생성 기록의 orientation도 함께 참조하십시오.

## 확인 그림

1. `checks/01-fill-seasons.png`: 유형 5 × 계절 3, 3×3 반복 및 줌 1.0·0.6 비교.
2. `checks/02-archetype-scenes.png`: 같은 기존 나무·건물과 각 유형의 지면·전이·소품을 조합한 작은 장면 5개. 톤 연속성과 유형 구분을 확인합니다.
3. `checks/03-coastal-comparison.png`: 모래·자갈·염습지 해안과 기존 물가·물 그림의 비교 및 반복 확인.

검수 그림은 실제 납품 픽셀을 배치한 정적 합성이며 게임 실행 화면이 아닙니다. 새 지면/띠/데칼은 줌 1.0에서 원본 0.5배, 줌 0.6에서 0.3배를 기준으로 합니다. 기존 나무·건물은 해당 프로젝트의 렌더 배율·피벗을 따릅니다. 비교를 위해 유형별 그림을 임의로 확대하지 않습니다.

장면 합성의 fill UV는 2×2 논리 칸을 덮는다는 가정입니다. 실제 엔진의 UV·경계 변형·가림과 동일한지는 게임 설치 단계에서 확인해야 합니다. 돌담은 대각 발자국이므로 캔버스 하단 중앙 anchor와 중앙 돌의 바닥 높이가 다릅니다. 자세한 측정값은 `records/upland-QA.md`에 있습니다.

## 생성 기록

`assets.csv`는 기존 20열 양식입니다. 실제 프롬프트 전문, 참조, 생성 시각, 채택·불채택 후보, 크기·알파·접합 후처리, 파일 해시를 기록합니다. `records/`에는 상세 이력과 검증 근거가 있습니다. 모든 아트 참조는 이 프로젝트 그림이며 외부 작품을 사용하지 않았습니다.

기계적인 끝점 일치와 장면의 시각 검수는 별도로 판정합니다. 반복 원본 하나의 특성이 지도 전체에서 전혀 보이지 않는다는 보장은 하지 않습니다. 최종 판단과 제한은 `QA.md`를 참조하십시오.
