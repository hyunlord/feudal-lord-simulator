# A 방향·보행 일관성표

모든 시트는296×148 RGBA, 열 NE·SE·SW·NW, 행 프레임0·1이다. 셀74×74, 공통 접지 경계 y67, 불투명 밑창 행66±1px. 아이 키42px는 기준 성인64–65px의 약0.65이다.

| 노인 여 | 미확인 | 미확인 | 미확인 | 미확인 | 드러난 신발의 화면 위치는 바뀌지만 해부학적 왼발·오른발 교대 확인 불가 |

**세 시트 모두 보행 합격으로 제출하지 않는다.** 단순 픽셀 차이·보폭 차이·화면 왼쪽과 오른쪽 신발 위치 변화는 해부학적 앞발 교대의 증명이 아니다. 확인 그림의 원은 검수한 신발 끝을 표시하며, `screen left/right`는 화면 위치를 뜻한다.

## 요청된 재시도

`attempts/`에 최초 실패 결과와 발 수정 결과를 보존했다. 추가로 **프레임0 행을 프레임1 행에 픽셀 그대로 복제한 입력 → 발만 다시 그리도록 요청한 생성 결과**를 세 인물 모두 첨부했다. 이 엄격 재시도도 앞발 교대에 실패했다. 모델이 요청 밖 상체를 조금 바꾼 경우 역시 기록했다.

기계적 좌우 반전이나 발의 임의 복사로 보행 성공을 꾸미지 않았다. 최종 시트는 상대적으로 나은 후보를 선택했고, 재시도 실패를 숨기지 않았다. 실제 프롬프트·선택 사유·발 좌표는 `../records/generation-history.json` 및 인물별 `*-gait.json`을 참조한다.

기존 `held_staff`는 `../reused/`에4방향 원본 그대로 포함했으며 몸에 합성하지 않았다. grip 좌표는 원래 후보 기록을 보존했다.
