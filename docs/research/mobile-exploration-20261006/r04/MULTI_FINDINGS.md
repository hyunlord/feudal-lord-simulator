# 다자전: 분포가 퍼져도 독주는 남는다

4도시19,800경기 전체의 정확한 예정 ID·원자료SHA·소스·좌석/명령순서·V 정산 검증을 통과했다. 각 전략6,600회 참가, 기본12전략의 모든4개 조합·5지형·2seed·4좌석 순환이다.2seed는 독립 세계 표본이 좁다는 한계를 가진다.

농업은 참가6,600경기에서 모두 우승했다. 군사는 분할 우승률0%, 외교0.08%, 학문0.05%다. 농업+외교51.26%, 제작+학문49.66%, 해상42.79%, 제작30.22%는 농업이 없는 편성의 결과도 포함한다. 이는1:1의 회복 뒤V 승점률과 다른 모집단/측정이다.4인 균등 우승 기대25%를 기준으로 읽으며,1:1의60%선을 그대로 적용하지 않는다.

상위25%(각 판1위,동률 분할)의 주된축 정규화 Shannon entropy는0.7925, 전체 참가 축은1.0000이다. 숫자만 보면 여러 축이 이기는 듯하나 농업은 전체 판의1/3에만 참가한다. **농업이 나오면 항상 이긴다는 조건부 성적**과 함께 보면 지배 전략 없음은 실패다. 편성에서 강한 전략이 빠진 효과를 맞수 구조로 착각하면 안 된다.

다자전950,400회 대외기회에서 실제 출정456,663, 비출정433,420, 유상 평화 유지60,317이었다. 실제 선택된 전투는 전부 약탈, 목표 확보100%, 공격 사망0이다. 공성은 선택되지 않았다. 양수 수익 예측/북쪽 진입에 한정된 봇 선택 편향과 약한 군사 긴장을1:1과 마찬가지로 드러낸다.

목적함수9재가중에서도 농업 참가당 우승100%다. 이 자료로 ‘완벽한 대칭은 아니지만 대략 균형’이라고 결론내릴 수 없다. 구체적인 층별/전략별 성적, 전체 정책벡터 분포, 시설/공간/흐름 거리, 성장→대외→회복 값은 league-analysis/multi-analysis.json에 있다.
