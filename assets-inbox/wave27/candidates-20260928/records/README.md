# Wave27 — 집 뒷마당 직업·형편 데칼 후보

직업별 12종 × A/B 24장, 형편·상태 6종 × A/B 12장, 공용 4장: 총 40 PNG입니다. 게임 미설치 후보입니다.

## 파일
- assets/yards/: 최종 PNG 40장. 직업·상태 256×128, 공용 128×64, RGBA 투명.
- proofs/01_twelve_occupations_zoom10.png: 같은 집 12채의 직업별 뒷마당. 아래 번호별 정답표 포함.
- proofs/02_same_parcels_four_states.png: 같은 12필지의 넉넉함 → 빠듯함 → 굶주림 → 빈집, 2×2 비교.
- assets.csv: 한글 구분명·직업·상태·크기·배치 기준점·의도한 발판·표시 배율·전체 프롬프트·해시.
- qa/: 파일 검증 및 직업 판독 결과, 이름을 가린 판독용 그림.
- provenance/: 실제 내장 image_gen 생성 기록·선택 원본 해시·후처리 스크립트.

## 표시와 배치
확인 그림은 PNG를 100%로 볼 때 게임 줌 1.0을 가정한 원본 0.5배입니다. 집은 약 70px 높이의 같은 기존 L1 그림이며, 직업을 집의 등급이나 외형으로 맞히지 않도록 통일했습니다. 12필지 장면은 첨부의 길 앞 집 / 안쪽 마당 구성을 따라 만든 오프라인 재구성입니다. 실제 게임 캡처나 설치 결과가 아닙니다.

새 데칼 배치 기준점은 256×128에서 (128,104), 128×64에서 (64,52)로 정했습니다. 이는 마당 캔버스의 앞쪽 지상 기준점입니다. CSV의 전체 캔버스와 기준점을 유지하여 배치하고, 알파 경계로 자동 크롭하지 마십시오. 의도한 발판은 직업·상태 2×1칸, 공용 1×1칸입니다. 런타임의 좌표계·소품 표시 배율은 설치할 때 맞춰야 합니다. 생성물은 가로·세로 동일 비율로 축소했고, 작은 소품 하나만 임의로 키우지 않았습니다.

직업과 상태는 별도 후보 그림입니다. 함께 적용할 때는 흙 패치와 소품의 겹침·그리기 순서를 확인하십시오. 직업·등급·굶주림·빈집 데이터의 선택 규칙은 게임에 구현하지 않았습니다.

## 가독성 판정
직업명을 가린 실제 크기 12필지 장면을 새 검수 맥락에서 한 번 판독한 결과 12/12가 의도와 일치했습니다. 검수자에게 가능한 12개 직업 목록은 제공했고, 배치 정답표·프롬프트·원본 이름은 제공하지 않았습니다. 빵집은 확신도 0.75로 상대적으로 낮았습니다. 밀가루 자루는 곡물 상인, 양털은 양모 작업과도 읽힐 수 있으므로 일반 사용자 모두가 정확한 직업명을 알아본다는 보장은 아닙니다. 각 직업의 대표 변형 하나를 배치한 결과이며 24장 전부에 대한 블라인드 판독은 아닙니다.

형편은 꽃·과실수·벌통의 풍성함, 성긴 채소·잡초, 빈 이랑·쓰러진 울타리, 무성한 잡초·부서진 문으로 분리했습니다. 새 입주와 겨울도 별도 A/B 후보가 있습니다. 작은 벌통·동물·소품의 세부 판독은 축소하면 제한됩니다.

## 경량 납품
고해상도 생성 원본과 중간 실패 시안은 ZIP에서 제외했습니다. 선택 원본 경로와 SHA-256, 전체 프롬프트, 후처리 기록은 포함했으며 원본 작업 자료는 로컬 /tmp/astra-wave27-work/lanes/에 남겨 두었습니다. QA는 오프라인 PNG·합성·해시 검증이며 실제 게임의 가림·필지 충돌·렌더러 통합 검증은 포함하지 않습니다.
