# Wave42 그루터기 검수

범위: 4형태 × 여름/겨울 = 8개. 원본 승인 자산은 참조만 하고 변경하지 않았다. 게임 미설치 candidate.

- 큰 참나무: 넓은 뿌리, 갓 벤 밝은 나이테 / 오래되어 패이고 이끼 낀 단면.
- 작은 물푸레나무: 가는 회갈색 줄기, 밝은 단면 / 부서진 윗부분과 이끼.
- 여름 4개 개별 생성 후 각각의 원본을 대상으로 겨울 4개 개별 편집. 수종·크기·신선/노후가 각기 읽힌다.
- 128×128 RGBA, 접지 피벗 (64,108), 큰형 폭70px, 작은형 폭50px. 최종 PNG에 메타데이터를 추가하지 않았다.
- 원본 alpha>8 경계로 미세 투명 잡음이 있는 바깥 여백만 제외하고 한 번 축소. 그림을 좌우 반전·회전하지 않았다. 실제 alpha min/max, 경계 alpha, bbox와 SHA는 `stumps-metrics.json` 참조.
- 좌상광, 검정 외곽선 없음, 긴 투사그림자 없음. 목재는 따뜻한 갈색, 이끼는 탁한 올리브색. 겨울에는 단면 상태를 가리지 않는 얇고 끊긴 적설.
- `../proofs/stumps-actual-size.png`는 실제128px 캔버스를 밝은 양피지색·짙은 녹색에 합성한 검수판. 확대가 필요하면 원본을 보되 실제크기 판독을 우선한다.
- 본체 통교체형 계절 자산이다. 눈만 별도 추출하여 픽셀 정합 오버레이로 사용하도록 검증한 것은 아니다.
- 엔진 런타임 비율·충돌·0.5/1.0/1.4 줌은 게임 미설치 범위라 미검증. 오프라인 크기·알파·방향·시즌 판독 검수와 구별한다.

생성 도구: 내장 image_gen.imagegen. 도구가 model/seed를 노출하지 않아 null 기록. CLI 우회 없음. 원시 파일은 raw/에 보존하며 경량 ZIP에서는 제외한다.
