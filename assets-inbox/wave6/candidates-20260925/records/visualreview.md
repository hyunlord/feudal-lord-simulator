# Wave 6 확인 그림 검수

상태: candidate. 이 문서는 오프라인 합성 검수이며 게임 설치·실행 결과가 아니다.

## 01 공사·자재·우물

- 공급된 공사 아트의 실제 등록 비율을 읽고 1×1 필지의 54px span에 적용했다. 공사 원본 512×256을 그대로 0.5배로 늘어놓는 방식은 쓰지 않았다.
- 기존 실제 단계는 plot → foundation → frame → roof이다. `construction_wall`은 코드에서 reserved이므로 단계로 끼우지 않았다. plot의 선·말뚝은 합성용 도식이다.
- 자재 더미는 96×64 공통 캔버스·피벗(48,56), 간판은 (16,56), 동일 표시 배율이다. 낮음/중간/높음의 양 차이가 남는다. 줌 0.6의 저량 목재는 작은 막대 군집으로만 읽히고 중량/고량 차이는 주로 높이로 판독한다.
- 우물 3셀과 기존 우물은 같은 (36,64) 기준선, 같은 0.72×zoom 변환이다. 구덩이/돌벽/지붕틀 실루엣 차이를 확인했다.
- 초가틀은 기존 지붕틀과 같은 등록에서 표현했으며 시각적으로 촘촘한 수평재가 남는다. 실제 L0/L1/헛간 선택 로직은 검증하지 않았다.

## 02 작업 소품·상체

- builder 83×83 frame0 네 방향에 도구별 손잡이 좌표를 맞췄다. 소품을 그린 뒤 원래 4×5 손 부분을 복원한다. 지게는 전체를 뒤에, 근측 절반을 앞에 둔다.
- 큰 검사에서 삽/망치/낫과 밀다발/자루 지게의 종류가 구분된다. 0.3 source에서 삽과 지게는 작업 상태 실루엣은 보이나 도구 세부 판독은 제한된다. 이 표시배율은 현재 워커 렌더 배율을 검증한 것이 아니다.
- 삽날은 보행 중 발 접지선에 비해 일부 방향에서 약 4px 위에 있다. 손 접속은 우선 보존했다. 고정 삽질 동작을 구현한 것으로 주장하지 않는다.
- 상체를 단순 source-over 하면 원래 내려간 팔이 남아 네 팔이 된다. 이 방식은 **미달**이다.
- 원래 torso 사각영역 (18,21,35,23)을 지운 뒤 상체를 올린 별도 실험은 두 팔을 보여준다. 이 교정에는 렌더러의 부분 교체가 필요하며 후보 PNG 한 장만 얹어서 해결되는 것이 아니다.

## 03 효과

- 연기 A/B·먼지·말뚝을 기초 단계 옆에 배치하고, 불 2크기와 완공 3프레임을 같은 밀도로 비교했다. 효과 바깥 투명 영역에는 합성 배경색이 보인다.
- 불꽃은 줌 0.6에서도 불로 읽힌다. 먼지와 망치 먼지는 작은 밝은 접지 얼룩으로 읽히며, 세부 파편은 식별되지 않는다. 말뚝의 리본 세부도 낮은 배율에서는 작다.
- 연기 A/B는 원본 크기에서 굴곡 차이가 있으나 줌 0.6에서 비슷한 수직 연기로 읽힌다. 장면에서는 굴뚝이 아닌 공사장 옆 효과 위치를 시연했으며, 실제 굴뚝 소켓에 붙인 검증이 아니다.
- 완공 3셀은 팽창과 소멸하는 형태의 차이가 있으나 시간 보간·애니메이션 연속성은 시험하지 않았다.

## 공통 한계

확인 그림의 바탕색·체크판·등록선·텍스트는 검토 도식이다. 실제 게임의 지형 아트나 새 에셋 일부가 아니다. 애니메이션, 프레임1 소품 손 좌표, 가림 정렬, 효과 발생 조건, 통행·클릭·성능은 검증하지 않았다.
