[설계서 12·13.0·14절](../design/DESIGN_MASTER.md), [로드맵 결정 기록](../design/ROADMAP.md)(v2.3에서 옮김)과 [콘텐츠 설계서 9절](../design/CONTENT_DESIGN.md)의 색인이다. 세부 근거는 원문을 읽는다. 확정·권고·보류를 일괄 승인으로 바꾸지 않는다. **이관은 후속 코드 변경 승인이 아니다.**

## R1-fix 확정 규칙

- **R-1 / S2.R6**: 먼저 지어진 주택의 서비스를 우선한다. 시작 주택, 저장된 건설 서수, ID 순이며 기존 주택의 서비스를 유지하는 범위에서만 빈 시설로 재배정한다. [명세·재현](../design/rule-repairs/S2-services.md). 저장 필드 추가 없음.
- **R-4 / S4-F1**: 석벽도 경로 있는 구간부터 병렬 진행한다. 같은 구간의 목책 완공 후 석벽 교체 의존성은 유지한다. A⁵ 벽 운반은 석벽에 이미 적용됨을 R-T9로 재확인한다. [명세](../design/rule-repairs/S4-construction.md). 저장 형식 변화 없음.
- **R-2 / S5-F1**: 성벽 예약은 기존 시대 비율과 자재 준비·시공 가능 부지 수요 중 작은 값이다. 대기 부지는 예약하지 않으며 목표판에는 실제 배정 수를 쓴다. [명세](../design/rule-repairs/S5-labour.md). 저장 형식 변화 없음.
- **R-6 / S6-F1**: 시장 판매에서 모든 공사장의 미배송·미예약 자재 수요를 보호한다. 기존 미배치 교회 예산과 목책 시대 석재 보호는 유지하며 가격·경제 수치는 바꾸지 않는다. [명세](../design/rule-repairs/S6-market-reserve.md). 저장 형식 변화 없음.
- **R-3 / S5-F2**: 가동 중지/재개는 생산·서비스·일꾼 수요를 함께 멈춘다. 준비된 공사에는 가용 인력20%(최소3, 수요 이하)를 보장하며, R-T5의 핵심 식량·목재 사슬을 유지한 뒤 중복 식량 시설을 배정한다. [명세](../design/rule-repairs/S5-labour.md). `Building.operationPaused`를 저장하는 스키마v3와 v2→v3 이행을 함께 적용한다.
- **R-5 / S6-F5**: 취소 공사 화물은 가장 가까운 접근 가능 창고에 한도 초과라도 하역한다. 초과 재고는 파생 `넘침` 원인으로 표시하며 일반 입고의 공유 한도와 출고는 유지한다. [명세](../design/rule-repairs/S6-cancellation.md). 저장 필드 추가 없음.
- **R-8 / S8-R8 추가 조항**: 관측된 밀 운송 정체가 기존 도로·곡창 조치로 풀리지 않으면, 비축 밀과 굶는 주택 양쪽에 실제 운송 가능한 방앗간 후보를 검사한다. 빈 방앗간 금지·반복 억제·시설 상한은 유지하고 선택을 진단에 남긴다. [명세](../design/rule-repairs/S8-recovery.md). 게임 경제·저장 형식 변화 없음.
  R-3 보완: 중지 곡창은 L3 근접 서비스에서 제외하고 같은 원인으로 표시한다. 저장 경계에서 `operationPaused`의 불리언 형식을 검사한다.

- **R-7 / S8-F1**: 공사 목재 부족을 2,400틱 연속 관측한 뒤 실제 인력·재고·창고 여유에 따라 생산 시설 한 곳을 확장하고 완공 후 다시 관측한다. 새로운 시설 비율을 만들지 않는다. [명세](../design/rule-repairs/S8-recovery.md). 선택 관측 필드와 스키마v4·v3→v4·자연 상태 지문을 함께 적용한다.

- **R-9 / S8-R9 추가 조항**: 자동 조언 분야별 결정론적 검사 예산을 두고 완료된 후보만 채택한다. 불완전 공동 서비스 탐색은 불가능 판정으로 저장하지 않는다. 자동 목책 후보는 유한하게 검사하고 수동 추천은 기존 탐색을 유지한다. [명세](../design/rule-repairs/S8-search-budget.md). 저장 형식 변화 없음.

- **R-7·R-8 후속 반례**: 목재 확장의 여유 원목은 창고 미예약 재고에서 기존 제재소 투입 부족분을 공제한다. 실패한 농장이 실제 생산·배송했더라도 단순 여유 부족만으로 재증설하지 않으며, 현재 완전한 관측창에서 밀 생산이 소비보다 적고 기존 인력·경로 판정이 실제 밀 부족일 때 재판단한다. 과거 실패 이력·경제 수치·시설 상한은 보존한다. [자연 상태 반례와 경계 테스트](../design/rule-repairs/S8-recovery.md).

- **R-8 반입 시점 재판단**: 무조치 뒤 실제 밀 반입으로 기존 방앗간 모두의 원료가 양수가 되고 실측 운송 정체가 지속되면 UI·headless가 같은 함수로 조언을 다시 평가한다. 실행한 행동 간 최소120틱과 빈 방앗간·인력·자재·시설 상한은 유지한다. 일반 무조치는 기존120틱 주기이며 저장 필드는 추가하지 않는다. [반례·검증](../design/rule-repairs/S8-recovery.md).

- **R-8 배급 진입로·저장 후속**: 반복 배급 부족 가구는 기존 운영 곡창보다 실제 거리를 줄이는 새 진입로를 전체 투영·서비스 자리 검사 후 한 명령씩 건설한다. 상한7개·배급 범위40·벽 규칙은 유지한다. 석조 조건을 막은 완성 석재의 창고 입고 포화는 기존 합법 창고 건설로 해소한다. 일반 저장 목표1000을 게임 용량 상한으로 해석하지 않는다. [배급 명세](../design/rule-repairs/S8-distribution-roads.md), [저장 명세](../design/rule-repairs/S8-storage-recovery.md).
- **R-9 경로 재사용**: 도로→건물 실제 BFS 결과는 불변 타일 참조·지도 크기·도로 변경 번호·완공 성벽/성문·출발점·건물 ID/종류/위치/점유를 키로 한다. 그래프별 최대2048개, 음성 결과 포함, FIFO 제거. 재고·일꾼·틱은 경로 판정 입력이 아니다. 전체 상태 동등성과 전후 측정을 [기록](../design/rule-repairs/R9-road-route-cache.md)한다. 저장 경로 캐시나 게임 규칙을 바꾸지 않는다.
