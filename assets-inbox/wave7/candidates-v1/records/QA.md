# Wave 7 검수표

판정은 후보 제작·정적 합성에 대한 자체/독립 AI 시각 검수입니다. **줌 0.6에서 모든 종류가 구분된다는 일괄 합격 판정은 하지 않습니다.** 실제 게임 설치·플레이 검증과 구분합니다.

| 항목 | 판정 | 근거·한계 |
|---|---|---|
| 집 연기 발생 위치 | 확인 | 사슬 그림은 L2 용마루, 겨울 그림은 L1 용마루에 연기 프레임의 하단 기준점을 놓음. 굴뚝 없음 |
| 방앗간 | 확인 | 프로젝트 `mill-v2.png` 기둥풍차+공동 빵 화덕 사용. 화덕 쪽에 진한 연기 배치 |
| 눈·판자 정합 | 확인 | 5개 원본과 같은 캔버스, 같은 피벗 상속, 오프셋(0,0). 실제 원본 합성 10장 육안 검수. 지정 마스크 밖 불투명 픽셀 0 |

| 공사 지붕틀 | 정적 확인 | 소·중·대·석조 대형의 열린 구조. 실제 건물별 점유·가림·공사 단계 연결 미검증 |

## 배율과 판정 범위

새 소품의 원본128×64 1칸은 줌1.0에서64×32, 줌0.6에서38.4×19.2입니다. 검사판 02·04와 사슬 하단은 이 엄격한 원본0.3배입니다. 첨부 주택과 주민/수레는 이미 작은 런타임 PNG여서 사슬/거리 합성의 몸체 배율은 별도로 표시했습니다. 수레 적재물·손 소품을 부착 비례에 맞춰 확대한 합성만으로 엄격한0.3배 판정을 대신하지 않았습니다.

픽셀 등록은 원본 지붕/개구부를 직접 읽어 설정한 좌표에 대한 검수입니다. 제3자가 제공한 공식 semantic mask가 있는 것은 아닙니다. 원본을 변형하거나 집 전체를 다시 그린 결과를 오버레이로 납품하지 않았습니다.

세부 근거: `records/independent-review.md`, `records/overlay-independent-check.json`, 각 family의 QA·처리 기록. 기술 집계는 `records/technical-validation.json`, CSV 검사는 `records/csv-validation.json`에서 확인합니다.
