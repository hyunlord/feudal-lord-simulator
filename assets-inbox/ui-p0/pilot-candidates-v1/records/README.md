## 납품 자산

`assets/ui/`에 밝은 패널·어두운 패널·목표·조언자 프레임, 기본 버튼·아이콘 버튼, 옅은 양피지 질감, 자원·건설 분류·층위·상태 아이콘 시트, 커서 시트가 있습니다. 각 파일은 의뢰서의 @2× 규격입니다. 아이콘 시트별 순서는 `records/icons.json`에 기록했습니다.

패널 중앙은 단색이며 필사본 장식은 가장자리에 한정했습니다. 일반 강조는 인장 빨강이며, 청회색·이끼 녹색은 상태 구분에 사용했습니다. 본문 텍스트·숫자·진행 막대 내부·선택 사각형·하이라이트는 납품 PNG에 넣지 않습니다.

## 확인 그림의 의미

확인 1은 첨부 01 게임 화면을 배경으로 새 부품을 Canvas에서 합성한 1280×800 이미지입니다. 배경 세계를 새로 생성한 화면이 아니며, 새 자산이 설치된 실제 게임 캡처도 아닙니다. 임시 문구와 숫자는 확인판 코드가 별도 레이어로 그립니다. 초상은 첨부 P1을 임시 조언자 슬롯에 넣었습니다. 시간·속도·설정은 상단 우측, 구역은 직접/구역/방향 층위 전환에 배치했습니다.

확인 2는 자원6·건설분류6·층위3·상태8 아이콘을 세 크기로 보여 줍니다. 작은 아이콘의 의미는 라벨·툴팁과 함께 전달해야 하며, 이번 검수는 시각 판독성이지 사용자 이해도 실험이 아닙니다.

확인 3은 모서리를 보존하는 9-slice 합성입니다. 조언자의 원형 초상 틀은 고정 크기로 따로 합성해야 원형을 유지합니다. 구체적인 cap·합성 방식은 `records/frames.json`과 재현 도구에 기록했습니다. 이를 임의의 엔진에 PNG 하나만 늘려도 된다는 뜻으로 해석하지 않습니다.

## 출처·한계

`references/`는 제공받은 프로젝트 자료, `sources/`는 생성 원본, `records/`는 정확한 프롬프트·참조·후처리·검수 기록입니다. 모델 버전과 seed가 도구에 없으면 null로 남겼습니다. 폰트 파일은 재배포하지 않으며 확인판 글자는 시스템 폰트입니다.

실제 게임 통합, 반응형 레이아웃, 클릭/키보드/터치 동작, DPR별 런타임 가독성·성능은 이번 범위 밖입니다. 12장 파일럿만 제작했으며 P0 전체 카탈로그로 확장하지 않았습니다. 무결성은 `SHA256SUMS.txt`와 `records/package-validation.json`에서 확인할 수 있습니다.

## 검수 결과

- 12개 PNG 규격과 CSV 12행 일치. 확인 그림은 정확히 3장입니다.
- 5종 프레임의 두 크기 비교에서 각 모서리 픽셀 일치, 양피지 질감 X/Y 양끝 차이 0을 확인했습니다.
- 24px에서는 큰 실루엣을 구별할 수 있으나 작은 우물·자루·낫의 세부는 약합니다. 아이콘 외곽선은 세계 건물보다 또렷한 기능적 표현입니다.
- 커서 hotspot 정합은 실제 적용 시 확인해야 합니다.
