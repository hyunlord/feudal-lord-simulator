# UI 상태 설계 (UX-3 수정본 1차, 조사 15)

헌장 3절 "화면 원칙"의 구현 명세. 근거: UX-3 수정본 지시서(조사 15 Claude·Gemini), [설계서 12절 M12-C10 UI 원칙](DESIGN_MASTER.md).
코드: `src/ui/uiStateMachine.ts`(상태), `src/ui/hud/`(상시 HUD·장부 서랍·일시정지 메뉴), `src/styles/hudShell.css`(배치),
`src/render/placementTileMarks.ts`·`placementTileOverlay.ts`(배치 칸 판정·그림), `src/ui/placementChip.ts`(커서 칩).
관문: `scripts/measureHudCoverage.ts`(상태별 면적), `scripts/ux3Verification.sh`(DGX 회귀 묶음).

## US-1 상태 기계 (코드로 강제)

| 상태 | 화면 | 들어가기 | Esc 1회 |
|---|---|---|---|
| S-20 평소 | 상태 알약 · 속도 · 목표 카드 1장 · 층위 전환 · 행동 도크 · 위기 아이콘(있을 때만) | — | 일시정지 메뉴(S-29) |
| S-21 건설 서랍 | 하단 가운데 서랍(분류 탭 6 + 건물 카드) | 도크 [건설] · B | 평소 |
| S-22 배치(건물) | 고스트 발판 + 1칸 테두리 · 커서 칩 · 범위 원 | 서랍에서 건물 고르기(서랍은 즉시 닫힘) | 건설 서랍 |
| S-23 배치(선) | 길·목책 미리보기 | 길 분류 · 목책 긋기 | 건설 서랍 |
| S-24 구역 | 구역 종류 칩(필지·경작지·목초지·과수원·지우개) | 층위 전환 [구역] | 평소 |
| S-25 선택 | 오른쪽 312 × 400 카드(지도 선택 카드 또는 위기 아이콘의 inspector) | 지도의 건물·일꾼·공사장 누르기 | 평소 |
| S-26 장부 서랍 | 자원 × 저장소 표 · 알림 · 보기(겹쳐보기) · 지도 탭 | 도크 [장부] · L · 알약의 식량·돈 | 평소 |
| 인구 · 목표 기록 | 같은 슬롯 | 알약의 인구 · 목표 카드의 기록 단추 | 평소 |
| S-27~29 모달 | 사건 · 계절 결산 · 일시정지 메뉴 | 스택 push | pop(아래 상태로 복귀) |

- **패널 슬롯 하나**(S-30): 건설 서랍·장부·선택 카드·인구·목표 기록은 한 자리를 쓴다. 새로 열면 이전 것이 닫힌다(`panelSlot`).
- **Esc 한 단계**(S-31, `escapeOnce`): 우클릭 한 번도 같다(지도 위 우클릭은 그 자리 공사장 취소를 겸함).
- **모달**(S-32): `push_modal`은 아래 상태를 기억하고 `pop_modal`이 그대로 되돌린다. 모달이 있는 동안 다른 사건은 아래 상태를 못 바꾼다. 모달이 하나라도 있으면 시간이 멈추고, 마지막 모달이 닫히면 그 전 속도로 돌아간다(`timeStopped`).
- **Space**(S-34)는 상태를 바꾸지 않고 시간만 멈춘다. **H**(S-35)는 HUD 전체를 숨긴다/보인다(US-D2).
- 상태별 보이는 것(`hudVisibility`): 배치·선 상태에서는 층위 전환·도크·위기 아이콘이 빠지고, 구역에서는 도크가 빠진다. 목표 카드는 평소 상태에만 — 단, **진행 중인 튜토리얼의 카드는 그 단계가 부른 건설·배치·구역 상태에도 남는다**(US-D5).

## US-2 상시 HUD

- 상태 알약(왼쪽 위, 높이 44): 날짜·계절 / 인구(누르면 인구 기록) / **식량 버팀 N일**(밀·빵 합산의 보유 틱을 달력 날로, 1년 360일) / 돈. 식량·돈은 장부 서랍을 연다. 버팀 14일 미만이면 붉게.
- 속도 4(오른쪽 위) + 설정(저장·자동 발전·그림 설정; US-D4).
- 목표 카드 1장(알약 아래, 240 × 44): 제목·개수·버튼 하나. 이유·도움말은 목표 기록(슬롯)에.
- 층위 전환 `[직접|구역🔒|방향🔒]`(왼쪽 아래): 처음부터 보이고, 잠긴 층위는 자물쇠 + 누르면 이유 한 줄.
- 행동 도크 `[건설][장부][청지기]`(오른쪽 아래): 청지기는 말할 게 있을 때 버튼 위 말풍선. 되돌릴 공사장이 있으면 [되돌리기]가 앞에 붙는다.
- 위기 아이콘(속도 아래, 최대 3): 누르면 대상으로 카메라가 가고 inspector가 슬롯에 뜬다. 목록 전체는 장부의 알림 탭.
- 없앤 것: 상단 자원 막대, 하단 206px 명령대(분류 6 상시), 겹쳐보기 막대, 미니맵 상시, 경고 목록 창, 조작 안내 줄.

## US-3 배치 피드백

- **판정 범위**: 고스트 발판 + 1칸 테두리만(`buildingTileMarks`). 화면 전체를 칠하지 않는다.
- **발판 칸**: 가능 = 밝은 초록 채움(색약 모드 = 밝은 파랑), 불가 = 주색(vermilion) + 45° 사선 + 칸 가운데 이유 그림. 칸 자체의 이유(건물·공사장 / 길 / 물 / 영지 밖)는 그 칸마다, 건물 전체의 이유(길에 안 닿음·숲 옆 아님·성벽 간격·자재·구역·잠김)는 가운데 칸 하나에 그린다. 한 칸만 부딪히면 나머지 칸은 가능으로 보인다.
- **테두리 칸**: 윤곽선만. 건물이 닿는 길(길 필요 건물)·숲(벌목소)은 옅게 채우고, 닿아야 할 것이 없거나 성벽 간격이 부족하면 테두리 전체에 옅은 사선.
- **색만으로 전하지 않는다**: 흑백에서도 사선·그림으로 구분된다(증거 `captures/placement-*-grey.jpg`). 색약 모드는 설정(일시정지 메뉴·설정 팝오버)의 [색약 모드], URL `?colorblind=1`.
- **커서 칩**(발판 오른쪽 모서리 옆, 232px, 3줄): ① 건물 · 비용 ② "목재 10 / 보유 120 · 배치 후 110"(부족하면 붉게 "N 부족 — 배치 불가") ③ 가장 중요한 불가 이유 1개 + "+N", 서비스 건물은 "집 N채 도달". 보유량은 배치 판정과 같은 "쓸 수 있는 양"(예약·공사장 미배달분 제외).
- **연속 배치**: 놓은 뒤에도 같은 건물 고스트가 남는다(Shift 불필요). Esc/우클릭 1회 = 건설 서랍.
- **자동 오버레이**(S-51): 우물을 고르면 물 범위 겹쳐보기가 켜지고, 도구를 내려놓으면 전의 겹쳐보기로 돌아간다.
- **도구 선택 전**: 배치 안내 마름모·네모 0개. 튜토리얼 목표는 이름표만(도구를 고르면 그 자리 마름모가 나온다).

## US-4 면적 예산 (관문, 1280 × 800 / 1920 × 1080 / 1180 × 820 태블릿)

| 상태 | PC | 태블릿 |
|---|---|---|
| 평소 | ≤ 6 % | ≤ 8 % |
| 건설 서랍 | ≤ 15 % | ≤ 20 % |
| 배치 | ≤ 6 % | ≤ 9 % |
| 구역 | ≤ 8 % | ≤ 12 % |
| 선택 | ≤ 18 % | ≤ 24 % |
| 장부 서랍 | ≤ 25 % | ≤ 30 % |
| 모달·결산 | 예외(시간 정지) | 예외 |

측정: 보이는 대로 찍은 화면과, 캔버스 외 DOM을 모두 숨긴 화면의 차이 중 ① 두 번 찍은 보이는 화면에서 같은(움직이지 않는) 픽셀이고 ② 보이는 DOM 요소 상자 안(화면 절반보다 큰 틀·정지 장막 제외)인 것. 게임은 1배속으로 돈다(정지 장막은 HUD가 아님). 커서는 빈 풀밭 위(화면 끝이면 지도가 밀리고, 건물 위면 호버 카드가 뜬다).

## 결정

- **US-D1 나무는 배치 불가 이유가 아니다**: 엔진 배치 규칙에서 숲 칸은 지을 수 있는 땅이다(`isBuildableTerrain`은 물만 막는다). 이유 그림은 건물·공사장 / 길 / 물 / 영지 밖 / 성벽 / 길 필요 / 숲 필요 / 자재 / 구역 / 잠김.
- **US-D2 HUD 숨김은 H**: 지시서의 `]`는 구역 붓 크기 키(`BracketRight`)라 겹친다.
- **US-D3 R 회전 없음**: 확정 결정 M12-C03(카메라·건물 회전 없음). 발판은 엔진의 폭 × 높이 그대로다.
- **US-D4 설정은 속도 옆에 남긴다**: 설정 팝오버에 저장·불러오기·자동 발전·그림 설정이 있고(검증 스크립트가 쓴다), 44px 한 칸이다. 일시정지 메뉴에는 튜토리얼·소리·색약 모드.
- **US-D5 튜토리얼 카드는 자기 단계와 함께 남는다**: 13단계 재생은 카드 버튼만 누르고, 두 번째 누름("표시한 자리에 우물 놓기")이 배치 상태에서 일어난다. 다른 목표 카드는 평소에만.
- **US-D6 팔레트 안의 색만**: 색 리터럴은 `content/palette.ts`에만 둔다(원천 검사). 지시서의 #0072B2·#D55E00 대신 물 램프의 밝은 파랑·팔레트 주색을 쓰고, 구분은 사선·그림이 맡는다.
- **US-D7 자재 부족은 "배치 불가"**: 엔진이 자재가 모자란 배치를 거절한다(`insufficient_materials`). 조사 15의 "공사장 대기 예상"은 이 게임 규칙과 맞지 않아 쓰지 않는다.
- **US-D8 길·목책의 클릭-클릭 선 도구는 2차로**: 지금 길은 끌어 놓기(한 칸 누르면 놓기·지우기)이고, B9 입력 회귀는 본선과 같은 결과를 요구한다. 입력을 바꾸면 기준이 바뀌므로 2차에서 따로 관문을 세운다. 1차에서 길 미리보기는 실패 시 사선, 칩은 "길 · 목재 N".
