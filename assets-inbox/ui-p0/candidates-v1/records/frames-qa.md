# A 틀·버튼·질감 후보 검수

- 표의 세부 수량 합계인 23 PNG. 23개 모두 기존 파일럿 참조를 입력한 imagegen 편집 원본을 보존했다.
- 파일럿보다 모서리를 줄여 단순 테두리·작은 점 중심으로 구성했다. 텍스트·숫자·bar 내부·아이콘은 없다.
- 생성 원본 일부는 가운데가 투명하거나 질감이 강했다. 파일럿과 같은 생산 정규화로 불투명 단색 읽기 영역을 만들고 생성 테두리·모서리를 유지했다. 원본과 후처리 코드 모두 포함한다.
- 18개 9-slice 자산을 200×80 / 600×400, native cap의 0.5배로 렌더했다. 네 모서리 픽셀 동일 18/18. 원형 초상 틀은 192×192 별도 RGBA이며 9-slice 대상이 아니다.
- 목표 3상태는 같은 normal 몸체에 생성된 인장·잉크 흔적만 고정 모서리 안에 등록했다. banner 인장은 32×32로 (8,8)에 배치해 48px 고정 영역을 벗어나지 않는다.
- vellum 2개는 맞은편 끝 행·열 최대 RGBA 차이 0. divider 2개는 가로 끝 열 차이 0.
- 미검증: 게임 설치·클릭 영역·키보드·실제 DPR 성능. 작은 프레임 테두리는 의도적으로 저대비이므로 실제 상태·포커스 표시는 코드에서 제공해야 한다.
- 재현: `node records/frames-process.cjs`, `node records/frames-review.cjs`. 라이브러리는 작업 환경의 기존 sharp / canvas 절대 경로를 사용한다.
