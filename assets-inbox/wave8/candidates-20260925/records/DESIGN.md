# Wave8 후보 디자인 계약

## 1. 목적
UI P0 재작업본과 동일한 게임의 추가 화면. C안80%기능20%장식. 후보만 제작, 설치 없음.
## 2. 출처
첨부P0프레임·배너·아이콘·양피지와 게임세계 캡처만 참조. 웹 브랜드·외부작품 불사용.
## 3. 색
P0 frame_modal/objective 중앙 실제RGBA(222,205,168,255), vellum(226,210,175,255). 미세한갈색선·따뜻한목재·탁한적색인장. 독립적금박/보석장식 금지.
## 4. 형태
결산=좌우말림+3장면자리. 연대기=세로필사본+좌장식띠. 청원=접힌서류+초상자리+인장. 목표=좁고긴서랍. 이름없이구분.
## 5. 크기와 배율
명시된@2x 원본유지. 아이콘96→24px에서색없이실루엣검수. 모든fixed장식은9slice실제XY변형방향고려해보호. 크기·insets·최소크기·contentrect는framescontract로명시.
## 6. 내용
새에셋에는텍스트·숫자·워터마크·로고글자 없음. 코드가내용을추가할영역은비움. 엠블럼은방패·벽탑·밀이삭만. 키아트는절제된중세영국시장도시; 게임세계의붓질·규모감과동일.
## 7. 검수
37에셋PNG+3확인PNG. 틀역할,24px색/실루엣,9slice1x/1.5x,키아트세계화풍,알파·크기·CSV전문·압축무결성. 게임런타임미검증과시각한계는분리기록.
