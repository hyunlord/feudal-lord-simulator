전체 후보 **81 PNG**와 확인 그림 3장, 생성 기록 CSV, 검수표를 담는다. 게임에는 설치하지 않았다.

## 파일 계약

- 새 fill: `terrain/{type}_{season}_{a,b}-v2.png`, 256×128, 불투명, XY 반복. 형태가 있는 특징은 빼고 바탕 색조와 작은 저대비 붓결만 남겼다.
- 새 데칼: `decals/{chalk_exposure,heath_patch,fen_pool,coastal_sand,woodland_litter}_{a,b,c}-v1.png`. a=64×48, b=96×64, c=128×96. 실제 알파, 사방 8px 여백, 피벗=(폭/2,높이−8). 같은 형상의 단순 크기 변경이 아니라 각기 다른 조각이다.
- 수정 해안: `shore/sand_beach_a-v2.png`, 512×96, X 반복만, Y 8px 투명 여백. 기존 `sand_beach_b-v1.png`는 그대로다.
- 기존 `terrain/*_{summer,autumn,winter}-v1.png` 15장과 `shore/sand_beach_a-v1.png`는 이 묶음에서 제외했다. 파일명 대응은 `records/replacement-map.json` 참조.

이번 사용자의 수정 지시에 따라 fill의 작은 붓결을 허용한다. 이전 큰 형태 제한을 fill에 적용해 큰 얼룩을 다시 만들지 않는다. 특징 식별은 별도 데칼이 담당한다.

## 확인 그림과 결정론 배치

01은 fill 30장 각각의 4×4 반복을 기존 풀밭 4×4와 같은 UV·배율로 비교한다. 02는 a/b 청크 혼합과 고정 시드 특징 데칼을 기존 나무·주택과 합성한 다섯 유형 장면이다. 03은 새 모래 해안 A와 통과한 B·기존 물가를 비교한다.

결정론 배치는 **확인 그림용 오프라인 코드**에 구현했다. 게임 코드를 수정하거나 설치하지 않았다. 배치 계약·시드·좌표·재현 검사는 records에 포함한다. 실제 엔진의 경계 마스크, 지면 UV, 가림, 성능은 별도 통합 검증 대상이다.

CSV 81행 중 35행은 이전 생성 기록을 유지하고 이번 변경이 없음을 명시했다. 나머지 46행에는 실제 생성 프롬프트와 후처리를 기록했다. 상태는 전부 `candidate`이며, 사용자 통과 여부는 보존 기록에서 별도로 표시한다.
