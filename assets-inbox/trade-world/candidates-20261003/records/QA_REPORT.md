# 납품 검증

후보 128 PNG를 제작했다. 마당48·집앞20·짐40·거리20이다. 여름/겨울 24쌍, 워커 짐10종의 네 방향을 포함한다. 설치·게임 코드 수정·커밋·푸시는 하지 않았다.

- 독립 익명 판독: 57/61=93.4%. 마당90.5%, 집앞95%, 거리95%. 중립 지원물은 별도1/3. [판독 상세](proofs/RECOGNITION.md).
- 도시 합성: 실제1380년 도시 원본에 60개 후보 배치를 10장으로 나눠 검수. 건물/밭/나무와 닿는 초기 위치는 수정했다. [독립 도시 검수](proofs/CITY_VISUAL_REVIEW.md).
- 워커 합성: 10종×4방향×2보행 프레임=80. 작은 통은 밑면 지지 파지점으로 수정. [독립 짐 검수](proofs/CARGO_COMPOSITE_REVIEW.md).
- 대장간4장은 천막을 기와 지붕으로 수정했고 여름2장은 새 독립 검수에서2/2 직업을 맞혔다. 초기 판독 점수는 유지하며 별도 재검수로 기록했다.
- 기존 화풍·2:1 지면·좌상광·독립 지지대·문자 없음·좌우 반전 없음은 제작자 전체 접촉판 검수와 독립 합성 검수로 확인했다. 이는 광학적 자동 증명이나 모든 역사 도구의 기계적 복원 검증은 아니다.

기계 검사는 [ASSET_CHECKS.json](proofs/ASSET_CHECKS.json), 패키지 링크 검사는 [LINK_CLOSURE.json](proofs/LINK_CLOSURE.json)에 있다. 128개 PNG·CSV 해시·투명도·치수·기준점 범위·고유 픽셀·정확한 거울 복제 부재와 생성 원본 SHA를 검사한다. 24쌍의 계절 알파 IoU는 차이 크기의 보조 지표이며 판독 성공이나 완전 픽셀 정렬로 해석하지 않는다.

## 남은 한계

네 가지 직업 혼동과 중립 지원물2개 오분류를 남긴다. 0.6에서는 작은 표지/짐의 세부 직업을 읽기 어렵지만 분산 배치가 지저분한 점 군집으로 보이지 않는지 확인했다. 이0.6은 정적 축소 모사다. 실제 엔진 LOD·가림·사람 이동·충돌·물길 연결은 미검증이다. 물가/수력 여름 마당4종은 현재 도시 캡처에 유효한 물가 자리를 확보하지 못해 전체 접촉판으로만 검토했다.

상세 기계 구조는 해석적이다. 통장이 조임 장치의 구체적 방식과 수력 축융 장치 동력 연결을 역사·엔진 구현 근거로 사용해서는 안 된다. 수레장이 예비 바퀴통 일부는 작은 통처럼 읽힐 수 있다. 지붕/목재/금속의 밝기와 크기는 기존 도시 캡처와 정적 합성에서 맞춘 후보값이다.

현재 클론872cc612와 재확인 원격d15ed728에는 요청된 LM-E6a 직업 정의를 찾지 못해 의뢰의20직업·12원형을 임시 납품 ID로 사용했다. 실제 캡처는 이전d6ae1549 소스 계열이며 당시 사람 약19px, 현재H16 차이를 CSV에 분리했다.

## 재실행

고해상도 원본이 working/raw에 있는 제작 폴더에서 normalize_assets.py → write_manifest.py → make_proofs.py → walker_proofs.py 순서로 실행한다. ZIP에는 용량을 줄이기 위해 원본 대신 정확한 프롬프트·참조·원본 SHA를 넣었다. 따라서 압축 파일만으로 이미지 생성 없이 고해상도 정규화를 재실행할 수는 없다. 최종 PNG와 SHA 검증은 ZIP 단독으로 가능하다. tools/audit_package.py는 제작 폴더에서 원본 SHA까지 확인하고 ZIP을 만든다.
