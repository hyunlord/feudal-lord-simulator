## 수량과 규격 결정

의뢰서 상세 표를 모두 제작했습니다. A 제목에는 14장이라고 쓰였으나 행 합계는 **23장**입니다. B는 57개 아이콘을 **11개 시트**로, C는 개별 커서 **6장**, D는 초상 **3장**으로 납품하므로 최종 PNG는 **43장**, CSV는 **43행**입니다. 약 60장이라는 요약에 맞추기 위한 임의 추가나 표 항목 삭제는 하지 않았습니다. 원본·참조·검사판 PNG는 납품 자산 수와 별도입니다.

최신 의뢰서 B의 ‘각 셀 96px’에 맞춰 건설 분류·층위 아이콘도 96px 셀입니다. 파일럿의 128px 셀과 다릅니다. 별도 폭이 없는 A 자산의 결정값 및 각 cap은 `records/frames.json`에, 시트 셀 순서와 커서 hotspot은 `records/icons.json` 및 CSV에 있습니다.

## 0절 반영

일반 아이콘은 파일럿의 진한 외곽선과 주황·금빛을 줄여 황토·oak·회갈색으로 맞췄습니다. 계절은 봄 가지·여름 해·가을 잎·겨울 눈송이이며 현대식 달력 격자가 없습니다. 모서리는 한 선·점 수준으로 절제하고 본문 중심은 단색입니다. 녹색·청색은 상태 구분용입니다.

납품 자산에는 문자·숫자·bar 내부·선택 사각형·하이라이트를 넣지 않았습니다. 2배·3배 속도는 삼각형 두 개·세 개로 표현했습니다. 확인판 문구·숫자는 별도 합성 코드 레이어입니다.

## 조언자와 9-slice

청지기는 모자 없는 40대 남성 한 명이며 지갑과 열쇠가 달린 소박한 관리 복장입니다. 동일 중립 원본에서 걱정·성공 표정만 편집했습니다. `records/portraits-alignment.md`의 눈선·어깨 좌표는 육안 판독과 불확실성을 구분합니다.

조언자 본문 normal/warn은 순수 9-slice, **원형 초상 틀은 별도 192×192 파일**입니다. 본문을 늘릴 때 원형을 함께 늘리지 않습니다. 작은 원형에서 걱정/중립 차이는 약하므로 상태 문구를 함께 사용하는 것이 좋습니다.

## 확인 그림의 범위

확인 1은 파일럿과 같은 첨부 게임 장면 위에 합성했습니다. 데스크톱·태블릿 화면을 각각 실제 픽셀 크기로 보존해 한 비교판에 담았습니다. 태블릿 배경은 가로 중앙 크롭이며 세계 그림을 재생성하거나 찌그러뜨리지 않았습니다. A·B·D를 사용하는 장면과 상태별 추가 비교를 나눴으며 모든 상태를 한 화면에 동시에 노출하는 실제 UX를 제안한 것은 아닙니다.

확인 2는 57개 아이콘을 문자 없는 실제 자산에서 24px로 축소한 검사입니다. 라벨은 확인판의 외부 설명입니다. 별도의 기술 검사에는 32/48px와 모서리·반복 경계 확인을 포함했습니다.

실제 게임 통합·반응형 구현·클릭/키보드/터치·DPR·성능은 검증하지 않았습니다. 커서 hotspot 역시 정적 자산의 위치 기록이며 엔진에 연결한 클릭 정확도 인증이 아닙니다.

## 생성 기록과 무결성

`references/`는 제공 자료, `sources/`는 생성 원본, `records/`는 실제 프롬프트·참조·처리·검수 기록입니다. 모델 버전/seed가 반환되지 않은 경우 임의 값을 쓰지 않았습니다. 승인 파일럿과 원본을 덮어쓰지 않았습니다. 시스템 폰트 파일은 포함하지 않았습니다. `SHA256SUMS.txt`로 압축 해제된 파일을 대조할 수 있습니다.

## 최종 검수 결과

- 43개 PNG의 규격과 CSV43행·12열을 대조했습니다. 전체 시트 셀은57개, 커서6개의 hotspot 좌표를 CSV에 포함했습니다.
- 18개 9-slice의 네 모서리가 200×80/600×400 비교에서 동일했습니다. 양피지2종의 X/Y 경계와 구분선2종의 X 경계 RGBA 최대 차이는0입니다.
- 파일럿 대비 빵·동전의 평균 HSV 채도가 감소했습니다. 이 값은 형태가 다른 두 자산의 불투명 픽셀 비교로, 외곽선 두께 측정값이 아닙니다.
- 독립 정적 시각 검수에서 전달 가능한 후보로 판정했습니다. 24px 건물의 부속 세부, 작은 청지기 neutral/concern 구분은 라벨·상태 문구의 보조가 필요합니다.
- CSV는 artifact-tool로 작성 후 다시 읽어 ID·SHA·생성 프롬프트 JSON 보존을 확인했습니다. 아카이브는 CRC와 압축 전 파일 바이트를 대조했습니다.
