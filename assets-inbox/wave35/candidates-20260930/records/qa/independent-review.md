# Wave 35 최종 시각 검수

검수 범위: PNG 50개 존재 확인, `qa/assets-contact.jpg`의 49개 썸네일과 별도 `assets/C_promises/ledger_spine.png`, 확인 그림 2개, `records/nine-slice.json`, 확인 그림 조립 스크립트. 직책 32px는 확대 연락판 대신 `raw/insignia-small-review-final.png`의 실제 크기도 확인했다. D 직책·방침·공고문은 이 검수자가 제작한 것으로 해당 부분은 독립 심사가 아닌 자가 검수다. 나머지 자산과 조립은 별도 제작자의 산출물이다.

판정: 검토한 오프라인 후보 그림에서 제출을 막는 시각 결함은 발견하지 않았다. 런타임 적용·임의 크기의 9-slice·상호작용 검증은 하지 않았다.

## 확인 결과

- 생성 자산에 문자·숫자·가짜 필기 흔적을 발견하지 않았다. 확인 그림의 한글은 조립용 임시 글자이며 자산에 새겨진 글자가 아니다.
- 영지 8종은 해자·방앗간·교회·사냥 숲·빈곤/쇠락 등의 장면 차이가 보인다. 작은 풍경의 역사적 세부 전부를 판정한 것은 아니다.
- 협상 그림은 좌우 조항, 변경 강조, 거절 취소선, 이유 칩 5개, 저울 5단, 문장 자리 2개, 봉랍 자리 2개가 보인다. 확장된 틀과 조항 줄에서 뚜렷한 접합 균열이나 잘린 모서리를 발견하지 않았다.
- 최초 treaty_frame 단독에는 중앙 구분선이 없었지만 `treaty_divider` 별도 자산과 확인 그림의 중앙 배치로 보완됐다. 틀 단독 사용으로 같은 결과를 얻는다고 표현하면 안 된다.
- ledger_book 단독은 중앙 이음새 없는 바탕이며 `ledger_spine` 별도 자산을 겹친 최종 확인 그림에서는 펼친 장부로 읽힌다. 약속 네 상태의 매듭·봉랍·파손·모래시계가 구분된다.
- 직책 32px는 열쇠 묶음/막대/두 탈리 막대/주머니/깃펜으로 구분된다. 탈리 홈의 세부는 작아지지만 두 막대 형태는 남는다. 서기 초기 원본의 금속 펜촉은 교정본에서 자연 깃대 끝으로 바뀌었다.
- 영수증의 상단 그림 자리, 이유 본문, 하단 결정 구획이 최종 확인 그림에서 유지된다. 9-slice 하단 여백은 최종 스크립트와 명세 모두 110px로 맞아 있다.

## 남는 한계

- 확인한 9-slice 결과는 협상 1200×730, 장부 824×244, 영수증 384×702 및 해당 줄/칩 조합이다. 소송 트랙의 임의 폭 확장과 최소 크기 경계 전체를 시각 검증한 것은 아니다.
- 최종 확인 그림 2의 영수증 그림 자리는 영지 풍경을 임시로 사용한다. 실제 건물 초상 및 실제 원장 데이터와의 연결 증거가 아니다.
- 32px의 미세 재질·탈리 홈은 줄어든다. 작은 화면에서 설명문 없이 직책 의미를 학습할 수 있는지 사용자 사용성 검사는 미실시다.
- 이 검수 시점 연락판·pixel-audit는 49개였고 디스크에는 50개가 존재했다. 추가 ledger_spine은 개별 PNG와 최종 확인 그림에서 직접 확인했다. 최종 패키징 시 연락판/수량 기록을 50개로 갱신해야 한다.
