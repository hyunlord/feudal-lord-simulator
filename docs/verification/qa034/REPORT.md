## 원인
- 청원 카드(`PetitionModal`, `src/ui/hud/StoryModals.tsx`)는 틀을 **틀 층**으로 그린다. 틀 층은 카드의 첫 자식 `span.petition-frame`이다. 절대 위치이고, 9-slice가 양피지 가운데까지 채운다(`fill`).
- UI-AUDIT-1 fix A(`272952a8`, "청원이 줄 수만큼 자란다")가 본문 `.petition-body`를 절대 위치 칸에서 **보통 흐름**으로 옮겼다.
  - CSS 칠 순서에서 위치 지정 안 된 요소는 앞 형제라도 위치 지정된 요소 **밑에** 칠해진다.
  - 그래서 제목·본문·선택지·나중에 버튼이 모두 틀 층 밑에 깔렸다. 둥근 문장·초상·밀랍 인장은 제 위치 지정이 있어 보였다.
- 기하 감사는 상자의 위치·크기만 쟀다. 상자는 다 제자리에 있었으므로 통과했다. 칠해졌는지는 보지 않았다(→ 감사 규칙은 별도 작업 UIAUDIT-R15).

## 고침
- `src/styles/hudShell.css`: `.petition-body { position: relative; … }`. 본문이 틀 층 뒤에 칠해진다. 배치·크기는 그대로다.
- 같은 구조인 계절 결산 카드는 틀 층 가운데가 비어 가려지지 않았다(탐침 0/12). 연대기 쪽·결말·연대기 책은 본문이 절대 위치라 해당 없다.
- 시험 `tests/frameLayerPaintOrder.test.ts`: 틀 층이 절대 위치일 때 본문이 위치 지정돼 있는지 CSS를 고정한다.
