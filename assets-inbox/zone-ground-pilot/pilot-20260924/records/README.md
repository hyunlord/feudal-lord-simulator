## 검토 결과와 한계

목초지는 세 지면 중 반복이 가장 자연스럽다. 띠 경작지는 흙·싹·밀·휴경 풀과 얕은 고랑의 차이가 읽힌다. 텃밭은 작은 혼합 이랑으로 구분된다. 참조와 같은 따뜻한 갈색·올리브·절제된 밀색을 사용한다. 신규 그림에는 건물·울타리·사람·동물·현대 물체를 넣지 않았다. 기존 캡처와 기존 목초지의 울타리는 비교 자료의 일부다.

검토 배율에서 뚜렷한 사각 이음선은 관찰되지 않았지만, **경작지 띠와 싹의 규칙성, 텃밭 양배추·파의 반복 모양은 남아 있다.** “반복 도장이 전혀 보이지 않음” 기준을 완전히 충족했다고 판정하지 않는다. 양산용 seamless 인증이 아닌 스타일·방식 검토 후보이며, 가장자리 RGB 차이 수치도 `records/technical-qa.json`에 그대로 남겼다. 가장자리 값이 수학적으로 동일한 텍스처는 아니다.

0.6배에서 경작지 띠는 읽히지만 텃밭·목초지의 세부는 미세한 질감으로 합쳐진다. 텃밭은 기존 채소밭보다 조밀하며, 나무 잎은 지면과 색이 가까워 저배율에서 눈에 덜 띈다. 나무는 기존 참조보다 줄기·가지 노출이 크다. 사과는 넓고 배는 더 세로로 긴 수형이다. 잎 대비·이랑 밀도·반복 단위 크기는 본 제작 방식 결정 시 검토할 항목이다.

## 미리보기의 정확한 의미

기존 캡처는 프로젝트에 보관된 실제 게임 화면을 원래 1280×720 크기로 붙인 것이다. 신규 에셋이 게임에서 실행된 캡처가 아니다. 캡처 원본 경로와 SHA256은 `records/reference-manifest.json`에 있다.

합성은 64×32px 논리 타일의 2:1 등각 투영이며 각 영역은 6×4칸이다. 지면 한 반복은 2×2칸에 대응한다. 직사각형 필지를 투영하므로 네 변 길이가 모두 같은 마름모는 아니며, 양 지면축은 ±26.565°다. 확대판은 2배, 작은 비교는 0.6·1.0·1.35배 오프라인 시뮬레이션이다. 실제 엔진 필터링·줌 동작·곡선 경계·전이 방식은 검증하지 않았다.

텃밭에 사과 2그루와 배 1그루를 배치했다. zoom 1.0에서 사과의 보이는 폭은 40px(기존 orchard의 displayWidth 기준), 배는 폭 28px로 정해 세로로 조금 긴 비례를 유지했다. 검토용 배치이며 런타임 anchor 계약은 아니다.

## 생성·수정 기록

`assets.csv`는 찾은 프로젝트 `assets.template.csv`의 20개 열을 그대로 사용하며 이미지마다 한 줄, 총 7줄이다. 생성 5종은 도구에 전달한 **실제 프롬프트 전문**을 prompt 셀에 담았다. 합성 2종은 생성 모델을 쓰지 않았으므로 그 사실과 합성 절차를 기록했다. 모델 버전·seed는 도구가 제공하지 않아 추정하지 않았다.

각 생성 에셋은 후보 1개를 생성해 1개를 선택했다. 선택 사유, 원본 파일 경로·해시·해상도, 참조 이미지, 수정 사항, 출력 해시를 기록했다. 참조는 이 프로젝트 그림만 사용했다.

지면은 생성 원본 1254×1254를 1024×1024로 축소했다. 텃밭은 생성기가 붙인 불필요한 반투명 알파를 제거해 원래 RGB를 불투명 지면으로 저장했다. 나무는 생성된 실제 알파를 보존하고 비율 유지 축소·여백 정렬로 512×512를 맞췄다. 새로 그리는 수작업이나 경계 픽셀 봉합은 하지 않았다. 생성 원본은 생성 도구의 기존 저장 위치에 보존했고 PNG 7장 제한 때문에 압축본에 중복하지 않았다.

적용 문서: `ASTRA_ART_DIRECTION_v1.md`, 프로필 `S_England_1300_1450_v1`, 기준 `AB_2026-09-19_v1`. 문서와 참조의 실제 경로·SHA256은 reference-manifest에 기록했다. CSV의 runtimePath/runtimeSha256은 미설치이므로 비워 두었다.
