# 최종 출처 검사

- 계약 22개 ID마다 선택 원본 정확히 1개. 총 생성 28회, 원본 경로·프롬프트 누락 0.
- 편집 대상과 생성된 보조 참조의 실제 파일명도 CSV에 포함했다.
- 물 계열의 생성 참조 ID는 선택 원본 PNG 파일명과 ID로 연결했다.
- 소품 담당자가 실제 참조 입력 경로를 보완했고, CSV는 `referenceInputPaths`와 `supportingGeneratedReference`를 함께 읽는다.
- 수작업 수정 기록은 에셋 ID별 정규화 레코드로 분리한다.
- CSV 20열·22행 전체 문자열 왕복 검증을 수행한다. 최종 결과는 `csv-validation.json` 참조.
- 도구에서 모델·시드를 표시하지 않았으므로 `not exposed`로 기록했다. 생성 시각은 담당 기록을 우선하고 없을 때 선택 원본 수정 시각 UTC를 사용한다.
- 생성 프롬프트 및 선택되지 않은 시도까지 `generation-history.json`에 보존했다. 생성 원본은 CSV의 로컬 경로·SHA256으로 추적하며 납품 PNG 수에 추가하지 않았다.
