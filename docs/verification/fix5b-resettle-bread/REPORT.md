# FIX-5b 보고서 — 재정착민의 빵과 결산 힌트

지시서: FIX-5 판정(사용자 2026-09-27). 엔진 세션, 검증 DGX. 결정 FL16. UI는 사용자 허락으로 상태 분기 예외(`seasonLedgerCopy.ko.ts` 1줄, `seasonLedgerCard.ts` 3줄: 가져오기·분류·분기).

## 만든 것
- **재정착 빵**(`resettleTown`)
  - 이주 가구마다 배급량으로 한 계절분 빵을 가져온다.
  - 가동 중인 첫 곡창의 빈자리에 먼저 넣고, 남으면 가구 재고에 넣는다.
  - 수레가 나를 한 끼(400틱) 동안은 굶지 않는다. 원래 두던 한 계절 굶지 않음은 이 빵으로 바꿨다.
- **결산 힌트** `resettled_food`: 재정착이 있던 계절의 결산이 빵이 떨어지는 계절을 싣는다(`SeasonLedger.resettledFood`). 카드 문구는 "다음: 재정착민의 식량은 ○○까지"다(`PRESSURE_COPY.resettledFood`).
- **시험 F12**: 빵의 양(곡창 + 가구 = 한 계절분)을 본다. 곡창이 없으면 가구 재고로 간다. 결산 힌트의 계절과 카드 문구를 본다.

## 순환 (결정 FL16의 근거)
- 식량 생산이 없는 판(시험 `autoplayPhase12Part5`): 가문 교체 간격이 2,250틱에서 약 2,850틱이 됐다. 판정대로 다시 굶게 두었다.
- 밭·방앗간이 있는 24채 도시를 비웠을 때(빵·곡창도 비움): 한 번 재정착(24명)한 뒤 8,000틱 동안 364명까지 자랐고, 가문은 더 바뀌지 않았다.
