# Wave19 연대기·전기·세력 UI 후보

**53 PNG + 확인 그림 3장 + CSV 53행.** 게임 설치·코드 변경 없음. 모두 candidate이며 사용자 채택 전입니다.

## 구성

| 분류 | PNG | 규격 |
|---|---:|---|
| 타임라인 | 9 | 띠1024×64, 나머지96×96 마스터 |
| 기록 카드 | 6 | 320×160, 9-slice |
| 전기·세력·지도·관계 | 9 | 페이지640×800, 지도160/320, 선32×256, 척도256×24, 점·끝·핀96 |
| 결정 기록 | 5 | 비교 틀512×240, 아이콘96×96 |
| 결산 장면 | 24 | 96×96, 24px 비교 |

의뢰서 제목의 ‘약55’와 소제목 산술 대신 명시된 파일·변형을 전부 집계했습니다. A는9, C는9, D는5파일입니다. 지도160은320과 같은 그림의 크기 변형이며 별도 생성했다고 기록하지 않습니다.

모두 오프라인 합성입니다. 글자·숫자는 확인 그림에만 임시로 올렸고, PNG 자산에는 넣지 않았습니다. 예시 이름·날짜·상태는 실제 시뮬레이션 기록이 아닙니다.

## 9-slice 사용 계약

`records/metadata-*.json`의 `nineSlice`에 고정 inset·최소 크기를 기록했습니다. `records/nine-slice-check.json`은 독립 모서리 픽셀 검사입니다. 9-slice는 고정 모서리+늘어나는 변/중앙을 뜻하며 전체 이미지를 비례 없이 확대하는 방식이 아닙니다.

전기·세력의 원형 초상·문장과 구획선은 큰 고정 영역에 들어갑니다. `records/pages-layout.json`의 원본 기준 슬롯을 사용하고, 확대 시 고정 모서리의 이동을 반영해야 합니다. 임의 크기 반응형 UI까지 검증한 것은 아닙니다. 큰 확대에서는 중앙 양피지 결이 길어지므로 원본 크기를 우선 권장합니다. 지도 틀 내부는 투명합니다.

인물 기록 카드는 처음 중앙 늘림 영역이2px뿐이어서 장식 길이를 줄인 v2로 교정했습니다. 수정 전후 원본을 raw에 보존했습니다.

## 가독성 판정 범위

- 카드6종: 인장 자리·붉은 귀퉁이·굵은 oak·금선·원형 초상 자리·장부 눈금으로 분류.
- 아이콘24종: 24px에서 그림의 기본 실루엣과 쌍별 차이를 검토. 인구 위/아래 화살표, 문과 가족의 좌우 배치, 빈/찬 그릇, 시장 차양 상태가 구분 기준.
- 부족/완공 보조기호와 작은 새싹, ‘대기근’의 심각도·‘겨울 넘김’의 시간적 의미는 문맥이 유익합니다. 모든 아이콘이 설명 없이 완전한 문장을 전달한다는 판정은 하지 않습니다.
- 실제 제품의 클릭·툴팁·키보드·스크롤·모든 줌·지형·성능은 이번 아트 후보 검수 범위가 아닙니다.
