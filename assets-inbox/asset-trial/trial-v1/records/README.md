## 생성 및 에셋 규격

내장 `image_gen` 도구 사용. Astra는 참조 이미지 선택, 프롬프트, 비교와 검증을 담당했다. 도구의 실제 이미지 생성 모델명은 반환값에 없어 특정 GPT Image 버전으로 단정하지 않는다. 최종 프롬프트는 [prompts.json](prompts.json)에 그대로 보관했다.

- 원본: `raw/house.png`, `raw/oak.png`, `raw/grass.png` (각 1254×1254).
- 비교용: `candidates/house_l0.png` (96×112), `candidates/tree_oak_large.png` (88×112), `candidates/grass.png` (256×256).
- 집/나무는 생성된 투명 알파를 보존했다. 색상 재매핑 없이 여백을 잘라 기존 불투명 영역 안에 종횡비를 유지해 축소하고 하단 기준점을 맞췄다. 기존 manifest와 renderScale은 그대로 사용했다.
- 생성 원본의 내부 알파는 대부분 252–253/255다. 이를 불투명 255로 강제하지 않았으며 작은 투명도 차이는 남는다.
- 잔디는 전체 불투명이다. 경계 평균 RGB 차이는 가로 6.63, 세로 7.28/255로 기존의 0/0과 달리 픽셀 단위 완전 일치는 아니다. 내부 인접 픽셀 차이 9.61보다 작지만 이것만으로 모든 확대율의 무봉제성을 보장하지 않는다. 3×3 반복 이미지와 실제 게임에서 함께 확인했다.

## 실제 브라우저 검증

제품 기준: `251f397`, `phase14-scale-occlusion-performance` 작업 트리. 로컬 Vite와 설치된 Chrome/Playwright 사용. 후보 화면은 초기 이미지 요청 세 개만 `page.route`로 교체했다. 게임 화면을 생성 이미지로 덮거나 게임 상태를 조작하지 않았다.

- 1440×900, 768×1024, 375×812 각각 기존/후보 캡처.
- 모든 비교에서 tick=0, simulation snapshot 동일, 카메라 zoom과 같은 타일의 화면 좌표 동일.
- 후보별 세 요청 모두 교체된 것을 기록. 에셋 준비 완료 확인, house/oak 실제 그리기 진단은 [browser-proof.json](evidence/browser-proof.json)에 포함.
- 모든 캡처에서 브라우저 console/page 오류 0, 문서 가로 넘침 없음.
- 데스크톱에서 `O` 윤곽 전환 및 커서 겹침 캡처도 보관. 기존 동작을 캡처한 것이며 완전한 상호작용 회귀 테스트는 아니다.
- 이미지 diff: 동일 해상도, 변경 픽셀 34.99%, 알파 보존. 이미지 교체 실험이므로 유사도 점수를 품질 합격 기준으로 사용하지 않았다.
- 비교 도중 포인터를 화면 모서리에 두면 카메라가 움직이는 문제를 캡처 도구에서 해결. 동일 좌표 검증을 통과한 최종 캡처만 비교 이미지에 사용했다.

`normalize.mjs`, `capture.mjs`, `compare.mjs`는 Node 구문 검사와 실제 실행을 통과했다. 제품 소스 변경이 없어 전체 게임 테스트/타입 검사/빌드를 재실행하지 않았다. 모션·장시간 성능·공개 배포는 이번 비교 범위가 아니다.

## 재현

이 환경의 설치된 Sharp/Playwright를 사용하므로 추가 의존성 설치는 없다. 스크립트의 제품 및 도구 경로는 이 컴퓨터의 절대 경로다.

1. Phase 14 작업 트리에서 `npm run dev -- --host 127.0.0.1 --port 3201 --strictPort` 실행.
2. 이 폴더에서 `node normalize.mjs`, `node capture.mjs`, `node compare.mjs` 순서로 실행.
3. 다른 포트는 `TRIAL_URL=http://127.0.0.1:PORT/ node capture.mjs`로 지정.

프롬프트·원본·축소본·SHA256·브라우저 상태·스크린샷을 함께 보관했다. 독립 검토 A/B는 모두 비교 실험 PASS. 결과는 [무결성 검토](evidence/review-integrity.md), [시각 검토](evidence/review-visual.md)에 기록했다. 이 판정은 제품 교체 승인과 구분한다.
