# 효율 성장 판정·최종 도시 캡처

기준 `bbc0c523`; 제품 기본 8필지·경제·저장 버전·아트·D24 정책 변경 없음. 이 보고서는 검증 도구 구현 단위이며 도시 성장 성공 보고서가 아니다.

**변경:** 기존 성장 드라이버에 선택적 최종 효율 판정을 붙였다. 기존 CLI는 유지하며, 새 실행기는 24,000틱 연속 안정 이후에도 효율 미달이면 원래 틱 상한까지 진행한다. 방앗간≤밀밭, 곡창≤ceil(필지/4)+1, 시장≤ceil(필지/24)+1, 교회≤ceil(필지/32)+1, 최근 2,400틱 실제 원료 부족/가동 가능 방앗간 시간<20%, 경고 건물<10%, 유휴 인구≥5%를 검사한다. 순간 밀 0 비율과 유휴 25% 초과는 진단이다. 관측 미완료·불명·분모 0은 실패다.

**캡처:** 제품 `renderFrame`과 실제 에셋을 사용하며 저장된 최종 상태를 진행하지 않는다. 1600×1100·DPR 1·줌 0.9, 모든 완공 건물 점유 경계의 중심이다. 실제 렌더 큐에서 각 건물을 별도로 그려 화면에 잘린 픽셀이 있는 ID를 센다. 경고는 제품과 같은 판정·앵커를 사용한다. 겹쳐 가려진 건물도 세며 경고는 가림 전 수로 보수적으로 계산한다. 에셋 로딩 실패·캡처 누락·화면 경고 10% 이상은 최종 실패다. 제품에서 비활성화한 주민 원본은 로딩 대상이 아니다.

**실행:** 같은 최종 커밋에서 아래 명령을 사용한다. Vite는 해당 작업트리에서 실행한다. 기존 디렉터리와 캡처는 덮어쓰지 않는다.

```sh
npx tsx scripts/efficientGrowthRun.ts 24 1200000 OUTPUT SEED
npx vite --host 127.0.0.1 --port 3281 --strictPort
npx tsx scripts/efficientGrowthCaptureCli.ts OUTPUT http://127.0.0.1:3281 9371
```

새 성장 명령의 성공은 시뮬레이션 판정이며 최종 통과는 `acceptance.json`이다. `summary.json`은 캡처 전 결과를 보존한다. 원시 상태는 seed별 `final-state.json`만 생성한다. 시뮬레이션 요약·JPEG·상태의 SHA256을 결합하며 캡처 시각의 상태가 다르면 거부한다. Chrome 임시 프로필과 프로세스는 명령이 정리한다. Vite 종료는 실행 검증 담당자가 수행한다.

**확인:** 효율 경계·캡처 누락·기존 짧은 실행 동등성 및 기존 성장 지표 시험 24개 통과, TypeScript·diff 검사 통과. 정상 초기 상태 1틱의 도구 개발 시험에서 JPEG를 직접 확인했다. 화면 8건물/4경고·활성 에셋 로딩 완료·상태 무변경이며 올바르게 실패했다. 개발 시험은 `/tmp/efficient-growth-capture-smoke-v5-20260922/`에 있고 자연 성장 성공 증거가 아니다. 기존 비활성 아트 오판과 최초 CDP 페이지 이동 경쟁은 수정했다.

**v14 대조:** 기존 최종 상태 5개 모두 시설 상한으로 실패한다. 경고 수/완공 건물은 seed 순서대로 38/128, 25/120, 55/149, 40/135, 39/122다. v14에 없는 새 2,400틱 관측 기록은 미관측으로 표시하며 소급 생성하지 않는다.

**남은 검증·전달:** 최종 코드 리뷰 1개 및 실행 검증 1개에서 8필지 회귀·seed 5개·최종 전체 회귀/빌드를 수행한다. 최종 보고서 첫 페이지에 효율표와 JPEG 5장, 압축 증빙 3MB 이하. `capture-result.json`의 중복 JPEG base64는 전달 묶음에서 제외하고 `final.jpg`, `acceptance.json`, `summary.json`, `final-state.json`만 포함한다. 소스는 커밋 해시로 전달하며 스냅샷·배포·main 병합은 없다.
