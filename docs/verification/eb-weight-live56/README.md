## 고정 기준

각 실행은 공식 FAIR-LINE 실험 한 판이며, 종료를 확인한 뒤 다음 사례를 제출한다. 실제 새로운 결과의 답ID·종류·대상을 확인하고, 장부의 비영 전기/목재 주문 감소/소송 상태 전이/감사 실제 결과 객체를 대조한다. 처리 기록만으로 통과하지 않는다. 갱신된 칩은 정확한 N과 가림 없는 노출, 결과 카드 항목은 정확히 하나·노출, 탐색 전후는 일시정지 상태 SHA 일치를 요구한다. JPEG도 따로 확인한다.

결과 관측이 없으면 정본 조건 미충족/관측 범위와 구분한다. 도구가 다른 실질 결정을 만난 경우 자동으로 답하거나 화면 결함으로 분류하지 않는다. 실제 효과 증거 부족과 화면 노출 실패도 별도로 분류한다. 결과 카드 자동 열림은 요구하지 않고 수동 열기와 자동 칩 집계를 구분한다.
