# Wave34 — 여울·습지 배수 공사 후보

게임 미설치. 26 PNG + 확인 그림 2장 + CSV + 검수표.

## 수량과 계절

의뢰서의 ‘약24장’은 근사치로 보고, 여울 폭2·3·4 × 두 방향 × 여름/겨울 12장, 물튀김2장, 배수단계1~3 × 여름/겨울6장, 완료배수띠2계절, 공사소품4장을 포함한다. 계절 차이는 얇은 얼음 테·서리이며 수로는 열려 있다.

## 사용 계약

- 여울: 512×256, 중심 피벗(256,128). 원본 기준 타일128×64. ne는 화면 오른쪽 위로, nw는 오른쪽 아래로 뻗는 교차 축이다. 폭2·3·4는 강물 횡단 구간의 논리 칸 수다. 양쪽 경사로는 그 밖의 둑에 붙인다. 임의 전체확대로 강 폭을 조정하면 돌·수레길 크기도 변한다.
- 배수 단계: 128×64 등각 마름모, 피벗(64,32). 격자 이동벡터는(64,32),(-64,32)이다. 직사각형 XY 반복 텍스처가 아니다.
- 완료 도랑 띠: 512×64, X축만 반복. 위아래8px투명 여백. 주변 경계에 투영해 쓰는 재질 띠다.
- 공사 소품/물튀김: CSV에 개별 크기·피벗, 사방8px투명 여백. 물튀김은 별도 정적 소품이다.
- 물 흐름 합성 순서: 기존 물 → 여울의 얕은 물·자갈 → Wave29 흐름. 돌·둑 위로 흐름이 올라오지 않도록 실제 통합에서 물 마스크를 적용해야 한다. 이 묶음은 효과 재생/통행 구현을 포함하지 않는다.

## 확인 그림과 참조

첨부 새 지형은 미니맵 모음이다. 확인 그림1은 첨부 강 지형을 바탕으로 한 로컬 등각 재구성이며 실제 엔진 캡처가 아니다. 원본 미니맵 출처를 함께 표시한다. 확인 그림2는 같은5×5구역의 배수1→2→3→완료를 비교한다.

경량 제출을 위해 고해상도 생성 원본과 중간 QA 그림을 제외한다. 실제 프롬프트·참조·후처리·해시·규격은 CSV와 records에 남긴다. 생성 원본 위치는 이 컴퓨터의 로컬 경로로 기록한다. 프로젝트 참조만 사용했으며 전달된 원본은 변경하지 않았다.
