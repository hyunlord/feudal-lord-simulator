# C 아이콘 재작업 검수

- 재출력: 3시트(672×96, 384×96, 288×96), 실제 교체 5셀. 각 셀 96×96.
- 접근: 가로 통나무로 막힌 바퀴 자국 길. 기존 튜닉처럼 보이던 갈림길 실루엣을 제거.
- 노동: 일꾼 두 명과 큰 삽. 망치 모티프를 제거.
- 권리: 접힌 평면 문서와 인장. 두루마리 모티프를 제거.
- 열기: 열린 문과 오른쪽 화살표. 망치 모티프를 제거.
- 도움말: 원형 물음표 배지. 책 모티프를 제거. 물음표는 이번 명시 지시의 예외.
- 층위 직접(망치), 층위 방향(두루마리), 목표 도움(책+촛불)은 기존 파일 그대로 유지.

## 실제 검사

`icons-process.cjs`는 새 생성 아이콘의 알파 경계만 자르고 종횡비를 유지해 최대84px로 Lanczos3 축소했다. 지정96px셀만 RGBA 버퍼에 교체했다. 수정하지 않은 9셀 전부 기존 디코딩 RGBA와 바이트 동일. `icons-cell-checks.json`에 변경 여부와 셀별 SHA256을 기록.

`proofs/03-changed-icons.png`에서 48px와24px를 육안 확인했다. 5개 기본 실루엣은 서로 구분되며, 중복 망치·두루마리·책은 교체된5셀에 없다. 24px에서 일꾼 표정·문서 접힘·길의 세밀한 바퀴 자국은 약해지나 두 머리+삽, 평면 종이+인장, 가로막은 통나무의 큰 형태는 남는다. 사용자 대상 의미 인지 시험을 수행한 것은 아니다.

원본은 내장 imagegen으로 셀별 편집 생성. 코드로 새 그림을 그리거나 색을 바꾸지 않았다. 원본5장과 입력5장을 sources/icons에 보존하고 전체 프롬프트는 icons.json에 포함. 게임 설치·입력·접근성·런타임 검증 없음.
