# Wave 38 · UI 조작 부품 후보

버튼4종×4상태16장과 기타조작24장, 총40장의 투명 PNG입니다. 그림 파일에는 글자가 없고 X·체크·라디오 표시·선택 화살표 등 조작 기호만 있습니다. 확인 그림의 임시 한국어는15px입니다.

## 사용 규격
- 기본 버튼128×40, 아이콘 버튼48×48. 보통·올림·눌림·꺼짐은 같은 캔버스와 같은9-slice여백.
- assets.csv의 slice_top/right/bottom/left는 원본 픽셀 단위입니다. 모서리는 고정하고 변과 가운데만 늘립니다. text_safe는[x,y,width,height]입니다.
- 버튼·탭·입력칸은 글자 가독성을 위해 최소높이40px 권장. 작은 칩 높이28px, 선택상자 높이40px 고정. 닫기·체크상자·라디오·토글·아이콘 버튼·슬라이더 손잡이는 기본 크기로 사용합니다.
- 선택상자 오른쪽26px은 화살표 보호 영역입니다. 세로 확대하지 않습니다. 슬라이더 홈은 가로, 스크롤바 홈·손잡이는 세로만 늘립니다.
- 눌림 상태의 임시 글자는1px 아래로 배치하는 것을 권장합니다. 가운데는 무늬 없는 불투명 단색으로 정리했고, 생성된 나무·놋쇠·봉랍 테는 보존했습니다.
- 상태 이미지는 내장 image_gen으로 각각 생성하고 정확한 캔버스·투명 여백·평평한 글자 영역을 정규화했습니다. 큰 생성 원본은 ZIP에서 제외했으며 프롬프트·원본 경로·SHA256·처리 기록을 포함했습니다.

## 확인 그림
1. 40종 전체 상태와15px 임시 글자, 실제9-slice 최소/기준/가로·세로 확대 예시.
2. 제공 인물 카드의 기존/후보 비교와 하단2배 확대. 기존 초상·이름·내용을 보존하고 기존 버튼에 가린 양피지와 나무 테를 원본 조각으로 복원했습니다. 버튼은 양피지 안쪽에 배치했습니다. 비교 크기를 일정하게 하려고3456px 캡처를1920px 폭으로 정규화한 뒤 카드544×312를 사용했습니다.

게임 미설치 후보입니다. 브라우저에서 실제 PNG를9-slice로 조립해 검사했으며 게임 코드·이벤트 연결은 포함하지 않습니다.
