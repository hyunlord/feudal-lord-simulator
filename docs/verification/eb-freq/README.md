## 실제 등록기 관문과 남은 계측

`registryV4.ts:301`은 바인딩/문맥/조건과64조합 상한, `:339`는 실명령의 실행 가능성, `:392`는 일회성 속도 조절, `:402`는 후보 필터를 담당한다. `registry.ts:35`의 철1·해2 예산과`:405`의 단일 가중 추첨도 마지막 선택에 작용한다. 유효 후보였지만 선택되지 않은 사건과 사실 전제가 없던 사건을 구별해야 한다.
