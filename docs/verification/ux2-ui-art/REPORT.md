## 한 일
- **설치:**
  - 받은 43장의 `caBX`를 빼면 29장은 P0 대장, 14장은 재작업 대장 SHA와 같다.
  - 스크립트가 칸별 Lanczos 아이콘 24/32/48/64 사본, 커서 32 px, 초상 96 px을 한 번 만든다.
  - 대장 97행, 프롬프트 43개. `npm run verify:provenance` 기준 461/461, 누락·불일치 0.
- **토큰:** 양피지·참나무·잉크·도장 빨강(강조 1색), 상태 4색은 예측 아이콘 색이다. 간격은 8 px 배수, 글자 크기, 9-slice 폭(원본 여백 ÷ 2)을 둔다.
- **9-slice 자리:** 상·하단 strip, 시간 묶음, 밝은·어두운 패널, 목표 카드 3상태, 청지기 두루마리(우려 톤은 주의 틀), 원형 초상 틀, 툴팁, 모달, 해금 배너, 토스트(일시정지 문구판·경고 줄·상태 줄)다. 버튼·탭·chip 바탕은 따로 두고, 상태는 코드로 그린다.
- **아이콘 57개 자리:**
  - 자원 5와 계절 4(날짜 옆), 분류 6, 층위 3.
  - 첫 세션 건물: 그림 없는 도구의 카드(길·헛간·필지·경작지·목책).
  - 예측 4(예측 판·완료 표시·목책 우선순위).
  - 원인 7(범례·지도 마커·상태 줄), 경고 3.
  - 시간 4(속도 단추·일시정지 문구판).
  - 목표 행동 4(위치 보기·목표 기록·상세·펼침).
  - 잠김·새로 열림·도움말, 지도 마커 2.
- **커서 6개:** 선택, 건물 위 살펴보기, 길 긋기, 구역 붓, 배치 가능과 불가다. 불가는 프레임이 판정이 바뀔 때만 `data-placement`로 쓴다.
- **청지기:** 대사마다 `tone`이 있고 초상 3표정과 틀이 따른다. 글자 "청"은 없앴다.
- **글꼴:** 본문은 Noto Sans KR, 제목·청지기·날짜·표지판은 Noto Serif KR이다.
- **양피지 질감:** 큰 패널(inspector·서랍·상세·카탈로그·팝오버·모달) 바탕에만 옅게 깐다.
- **DPR 2:** 틀은 2x 원본이 1:1로 보이고, 아이콘·커서·초상은 `image-set` 1x·2x로 고른다.

## 필수 조건
- 마지막 커밋의 전체 회귀, typecheck, build, 깨끗한 클론은 병합 커밋에서 다시 잰다(STATUS에 해시와 수를 적는다).
- 작업 중 결과: 전체 2,900/2,900(`925827a`), typecheck 0, build 통과.
- 글꼴이 들어가 빌드가 커졌다. `dist`는 49 MB이고, woff2·woff 분할 파일이 744개다. 브라우저는 쓴 글자의 구간만 받는다.

## 넘길 것(Astra 후보)
- **새 아이콘:**
  - 되돌리기: 지금은 글자 단추다.
  - 정보 "i": 지금은 목표 기록 책을 빌려 쓴다.
  - 지우개: 지금은 가위표를 빌려 쓴다.
  - 목초지·과수원: 지금은 지면 썸네일이다.
- **24 px 실루엣이 겹치는 쌍:** 헛간~창고, 인구~빵, 저장~방어·생활. 실루엣부터 달라야 한다.
- **16 px 사본:** 잠김 배지와 펼침 화살표가 24 px 사본을 줄여 쓴다(`transform`).
- **켬/끔 스위치 그림:** 지금은 보조 단추 + 도장색 선이다.
- **inspector 머리띠 그림:** 지금은 구분선이다.
- **지도 마커 묶음 숫자 chip:** 지금은 벡터로 그린다.
- **자원 원목·밀·원석:** P0 시트에 없어 옛 `runtime-icons-v1`을 쓴다. 인구·빵·목재·석재·재정 5종의 옛 파일은 대장에 남아 있지만 화면에서는 쓰지 않는다.
- **생략한 것:** 경고 줄 즉시·주의는 같은 토스트 틀에 왼쪽 3 px 색띠와 아이콘으로만 가른다. 따로 틀이 있으면 더 좋다.
