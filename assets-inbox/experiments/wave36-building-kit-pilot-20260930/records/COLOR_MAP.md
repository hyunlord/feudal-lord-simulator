# 벽색 지도 — 후보, 적용 미승인

원본 캔버스137×137을 바꾸지 않는다. `masks/wall_body_{vertical,square,curved}.png`만 색을 입힌다. 생성 몸체의 alpha>250, RGB 최소값>118, RGB 최대-최소<48 영역을 벽 후보로 분류한 뒤 Rec709 명도로 중립화했다. 따라서 임의 밝은 창·장식 오분류 가능성이 있고 의미 마스크 검증은 아직 없다.

기준 회색값220에 대해 `outRGB = clamp(gray * targetRGB / 220, 0, 255)`를 적용한다. 흰(230,228,221), 황토(217,191,147), 연분홍(217,184,178), 회색(179,182,174). 알파와 마스크 밖 픽셀은 보존한다. 상수 단색으로 덮는 방식이 아니다.

허용 검수 범위는 원본 결 고주파 RMS의80% 이상, 비벽 변경0px. 임의 RGB 편차를 새 합격 기준으로 만들지 않았다. 이번 실제 결과는 회색3개와 세로 몸체 황토에서80% 미만이므로 실패다. `records/color-map.json`, `renders/tinted/`와 자동 측정표에 정확한 입력·결과가 있다. 중립 회백 원본은 명도 결을 갖고 있어 모든 픽셀이220인 단색이 아니다.
