# F2-A 2장 사건 보고서 — 전쟁 1337

지시서: F2-A 2장 사건(사용자 지시 2026-09-27, 엔진 2장 작업 둘째, 6시간). 명세: [2장 사건](../../design/chapter-two-war.md) WR-1~WR-10. 결정: WR1~WR12.
- 엔진 세션이다. 렌더·UI 0줄, 검증은 DGX에서 했다.
- 순서: 사용자 판정(2026-09-27)으로 C4를 미루고 F2-A를 먼저 했다. 자원 전수 표 23개 파일이 막아서다. 양모 현물 납부는 C4 뒤에 현물로 바꾼다(결정 WR5).

## 만든 것
- **전쟁 순서(WR-1)**: 전쟁 시대(1337) 첫 계절에 국왕의 전령이 온다. 이어서 계절 1 양모 공납 → 4 징집 → 6 전쟁 보조세 → 봉화 → 해안 습격(1339 또는 1340 여름, seed) → 피란민 → 회복(조달 면허·석벽 대 시장) 순이다.
  - 시대 효과: `wool_price × 1.5`(데이터).
  - 1340년 뒤에 전쟁 시대를 처음 만난 옛 저장은 전쟁을 놓친다.
  - API `warForecast`.
- **결정 다섯 = 청원(WR1)**: `wool_payment`·`levy_response`·`war_funding`·`refugee_admission`·`wall_or_market`(Wave 17 카드 id, 청원자 `crown`·`refugees`·`townsfolk`).
  - 플레이어는 지금의 청원 카드로, 봇은 `petition_response`로 답한다. 한 계절 무응답은 거절이다.
  - 왕실 요구를 거절하면 신임을 잃고, 조달 면허와 성벽세가 없다.
  - 청구서를 못 내면 미납 줄(`category`)이 되어 기간 마감에서 갚는다. 실패 사다리의 미납(FL-3)에도 든다.
- **금액**: 1337년 봇 도시(금고 7,800~13,600d, 집 24채)를 DGX에서 재어 정했다(`scripts/chapterTwoProbe.ts`).
  - 양모: 집당 20d. 현물(환산)은 125 %를 4계절에, 현금은 100 %, 거절하면 150 %를 가져간다.
  - 보조세: 금고의 1/10. 상인 차입(120 %를 8계절에, 상인 게이지 +10) 또는 세금 인상(지대 +50 %를 4계절, 계절마다 1/3 확률로 한 가구 이탈).
  - 징집: 어른 20명에 1명, 2계절 일하지 않음(`labourPool`), 5명에 1명 돌아오지 못함. 면제금은 1명에 20d.
- **습격(WR-5)**: 닫힌 고리의 방어(석재 1,000 · 목재 600 ‰)로 노출을 정한다.
  - 노출된 집 8채 × 노출이 불탄다. 불탄 집은 화재와 같은 상태라 재건·봇 재건이 그대로 쓰인다.
  - 창고 30 % × 노출, 금고 20 % × 노출(최대 2,000d)을 빼앗긴다.
  - 미리보기 API `raidLosses(state, defence)`.
- **피란민(WR-6)**: 네 가구. 빈 집부터 들고, 그다음 여유 자리에 든다. 절반만 받으면 가구당 10d를 받는다.
- **회복(WR-7·WR-8)**
  - 조달 면허: 8계절 동안 곡창 밀의 10 %를 시장가로 산다.
  - 석벽 대 시장: 석벽 / 성벽세 석벽(통행세 × 2, 신임이 있을 때) / 시장 확장(좌판세 × 2, 석벽 포기).
- **2장 끝(WR-9)**: 회복 뒤 시장 선택 또는 석벽 완공, 늦어도 1348이다.
  - 연대기 쪽 `stats.war`, 같은 틱에 3장이 시작한다.
  - `chapterGoals`에 2장 `wall_or_market`이 더해진다.
- **봇(WR-10, 결정 WR9)**: 현금이 있으면 양모·면제금을 현금으로 낸다. 보조세는 상인 차입, 피란민은 자리만큼 받는다. 석벽은 사업을 지금 선포할 수 있을 때만, 아니면 시장이다.
- **원장**: `war.messenger`·`war.beacon`·`war.raid`(256² 지도)·`war.conscripts_left/returned`·`war.favour_lost`·`war.licence`·`war.unanswered`, 결정 문장은 결정마다 다르다(`historyCopy.ko.ts`).
- **저장 v20**: `GameState.war`, 청원자 셋, 전쟁 청원 다섯, 미납 줄 `category`. 지문 `c89d70cb`, v20 저장 픽스처 9개.

## 렌더가 넘겨받을 API
- **결정 카드 다섯**: `openPetitions(state)`의 `defId`가 Wave 17 카드 id다(`wool_payment`·`levy_response`·`war_funding`·`refugee_admission`·`wall_or_market`).
  - 지금 청원 카드는 시장권 문구·인장만 보여 준다. 답 셋의 뜻과 금액은 명세 WR-2~WR-8 표와 `warDecisionForecast`에 있다.

  - `conscriptsAway`(빈 작업장 `empty_workshop`), `raidLosses(state, defence)`(성벽 미리보기).
