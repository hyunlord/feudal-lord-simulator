## 탭 영역·글자 실측 (1280×800, 12개 상태)

| | 전 | 후 |
|---|---|---|
| 44px 미만 컨트롤(상태별 합계 / 고유) | 186 / 40 | 0 / 0 |
| 12px 미만 글자(실측 상태 안) | 0 | 0 |
| 12px 미만 선언(정적 검사) | CSS 6곳(`--font-badge` 11px 사용처 5, `.cause-legend small` 11px), 캔버스 2곳(원인 아이콘 배지 11px, 목책 성문 기호 11px) | 0 |
| 지도 원인 아이콘 탭 영역 | 반경 15px(지름 30) | 반경 22px(지름 44). 가장 가까운 아이콘을 고른다. |

실측 상태:
- 시작 화면, HUD, 건설 메뉴 펼침, 구역 붓 선택, 재정 장부, 인구 기록;
- 자원 상세, 도시 발전, 지도, 보기, 설정, 주택 선택 카드.

실측에서 12px 미만 글자가 0인 이유: 11px 배지를 쓰는 요소(시장 목적 줄·부족 줄·원인 범례 등)가 측정한 상태에서 화면에 나오지 않았다. 그래서 정적 검사로 막는다.

고친 방법:
- **탭 영역:** `uiBoundaries.css`에 44px 바닥 규칙을 두었다(`.app-shell`의 button·summary·role=button/tab·a·select·input, 최소값만 올림).
- **장부 목록:** 각 행이 44px로 커졌다.
- **좁은 화면 명령줄:** 900px 이하에서 명령줄 둘째 줄을 34px에서 44px로 늘렸다(명령줄 높이 140px → 150px). Part7 브라우저 검증에서 넘침이 생겨서 고쳤다.
- **자원 상세 버튼:** 높이 44px로 커져서 오른쪽 정보 칸 시작을 22px 내렸다.

캡처(`captures/`, 1280×800·1600×1100):
- 건설 메뉴, 장부, 주택 카드의 전·후;
- 못 짓는 카드를 탭했을 때 고정된 줄(후).
