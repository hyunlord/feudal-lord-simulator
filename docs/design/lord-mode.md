## 0. 한 문장
플레이어는 건물을 놓지 않는다. **권리·약속·사람·돈의 조건**을 만들고, 도시의 가구·가문·공동체가 그 조건에 **이유 있게** 반응해 도시를 짓는다. 모든 결과는 **누가 왜**로 되짚을 수 있다.

## 1. 기둥 다섯 (모든 기능은 하나 이상을 강화해야 한다)
1. **인과가 읽힌다** — 무엇이 생기든 "왜 여기에, 누구의 결정 때문에"를 누르면 볼 수 있다.
2. **사람에게 귀속된다** — 수치보다 "네가 특권을 준 FitzAlan 가문이 상점을 냈다".
3. **권리는 묶음이고 권원과 점유는 다르다** — 문서로 가진 것과 실제로 쥔 것이 다를 수 있다.
4. **시간이 이야기가 된다** — 긴 결정은 중간 사건으로 쪼개진다. 진행 막대 하나로 버티지 않는다.
5. **커질수록 결정이 커진다** — 영지가 늘면 작은 결정은 대리인에게 가고 플레이어는 배분·인사·위기를 결정한다.

## 2. 플레이어의 동사 (여덟)
| 종류 | 예 | 화면 | 시뮬레이션이 받는 방식 |
|---|---|---|---|
| 명령 | 청원 판결, 장부 조사 | 카드 | 즉시 상태 변경 + 세력 기억 |
| 정책 | 영지 방침(성장·세입·안정·방어), 시장 부담(좌판세·통행세) | 슬롯·토글 | 자율 성장·가구 판단의 가중치 |
| 투자 | 사업 장려금(예: 제빵 정착 £10), 장려 구역 | 공고 카드 + 지도 영역 | 가구·가문이 수익성으로 **입찰**해 짓는다 |
| 계약 | 통행세 면제 ↔ 연 £6 | 조항 창 | 기간·이행·위반을 추적 |
| 협상 | 혼인 계약(첫 버전 유일) | 조항 창 + 이유 합계 + 역제안 | 수락 점수 = 이유의 합 |
| 거래 | 권리 매각, 융자 | 장부 | 자산 이동 |
| 소송 | 권리 확인·회수·상속 청구 | 진행 트랙 + 단계 사건 | 증거·후원·비용으로 단계별 판정 |
| 인사 | 청지기·집사 임명 | 인물 카드 + 직책 | 대리인의 능력·성향·이해관계가 자동 결정에 스며듦 |
+ **명령 핀**(남기는 공간 행동): 시장 확장 방향(구역), 공공사업(다리·성문·시장 십자가·영주관 — 후보지 2~4곳 중 선택), 장려 구역, 재난 시 폐쇄·대피.

## 3. 새 시스템
### 3.1 자율 성장(Town Agency) — 가장 먼저, 가장 중요
- 지금의 봇(`engine/autoplay*` 약 70파일)은 **시험용 대리 플레이어**다. 영주 모드에서 도시를 짓는 주체는 **도시의 행위자들**(가구·상인 가문·길드·공동체·교회)이어야 한다.
- 구조: 매 주(게임 시계) **사업 제안**을 만든다 — `{누가(행위자), 무엇(건물·확장·구역 입주), 어디(후보지), 점수 = Σ이유(수요·접근·권리 비용·장려금·땅값·영지 방침·세력 관계), 돈(행위자 자산·대출)}` → 점수와 자금이 되는 것부터 착수. 봇의 검증된 계획 함수(필지·도로·물류·식량)는 **이유 점수를 내는 부품**으로 재사용.
- 모든 착수는 **영수증**을 남긴다(이유 상위 5개 + 관련된 영주 결정 id). 원장에 `agency.project_started`.
- 시험용 봇은 그대로 두되, 영주 모드 봇은 "영주 역할"(정책·장려금·판결)만 하고 도시는 자율 성장이 짓는다.

### 3.2 영지와 권리 모델
- `Estate { 법적 명의자, 실제 수익자, 점유자, 생애권자, 잔여상속인, 후원자, 청지기, 수입관리인, 연간 가치, 부담(채무·기존 지대·수선), 청구자들[], 권원 강도, 점유 강도 }` — 장원 수와 연간 가치 분리.
- 기존 권리 등록부를 이 모델 아래로 옮김(좌판세·통행세·방앗간 = 권리 조각). 이행: 옛 저장은 명의자 = 점유자 = 플레이어.
- 확장 흐름: `청구 → 협상 → 문서 → 권원 → 점유 → 관리 → 감사 → 상속`.

### 3.3 협상·약속
- 수락 점수 `A = 기본 태도 + 관계 + 물질적 가치 + 정치적 가치 + 신뢰 + 긴급성 + 양보`. 내부 확률 σ((A−θ)/s), 화면은 5단계 + 상위 이유 3~5.
- 역제안: 부족분 계산 → 상대의 원하는 것 가치순 → 레드라인 제외 → **수락선 바로 위 최소 요구 묶음** + 성격별 욕심.
- 조항(혼인 첫 버전): 지참금 · 연금 · 특정 권리 · 정치적 지원 약속 · 채무 인수 ↔ 혼인 동의 · 상속 기대권 불침해 · 배우자 거주 · 토지 일부 사용수익 · 후견 합의. 역사 기준값: 지참금 £200, 최소 연수입 £40(Paston 1444).
- **약속 장부**: `Promise { 대상, 내용, 기한, 목격자, 담보(신뢰·기억·수락 보정) , 상태 }`. 기한에 안 하면 어김. 돈으로 완전 상쇄 불가인 이유(선례·신분·상속 위험) 존재.

### 3.4 위임·주의력·감사
- **주의력**: 영주가 직접 보는 영지 수 한도(첫 판 2). 넘으면 직접(청원 지연·장부 오류) 또는 청지기 위임.
- 청지기: 능력·충성·성향(상인 친화/농민 친화/탐욕)·연줄. 위임된 영지의 청원·작은 분쟁·세율을 **성향대로** 처리. 예외 규칙("£5 이상·권리 변경은 나에게").
- **연례 감사**(미카엘마스): 장부 누락·부패가 여기서 드러남. 직접 방문·감사 행동은 다른 영지의 주의력을 뺏음.

### 3.5 시간과 멈춤
시계 셋(도시 틱 / 정치 주~계절 / 왕조 해~세대). 자동 일시정지: 역제안 도착·주요 인물 사망/상속·판결·권리 상실 위험 청원·영지급 위기·영지 획득/상실. 집 완공·상점 개업은 멈추지 않는다. 긴 결정은 **중간 사건 2~5개**로.

### 3.6 인과 영수증 (가장 중요한 화면)
건물·필지·가구·세력 변화에 "왜?" — 이유 점수 상위 5, 관련된 영주 결정(날짜·링크), 소유 가구, 현재 영향. 원장과 연대기가 이걸 모아 "당신의 결정이 만든 것" 쪽.

## 4. 남기는 것과 바뀌는 것
- **유지**: 1300–1450 5장 캠페인, 사건·청원·세력·혈통·연대기, 지도 5종, 보이는 시뮬레이션·자연스러움·끊김 기준, 모든 그림.
- **바뀜**: 기본 모드에서 건설 서랍은 "명령 핀"(공공사업 후보·구역)으로 축소. 일반 건물 배치는 **샌드박스 모드의 직접 도구**로 이동.
- **튜토리얼**: "우물을 놓으세요"가 아니라 "첫 청원을 판결하세요 → 결과가 도시에 나타나는 걸 보세요".

## 5. 수직 조각 (LM-VS) — 검증할 질문 하나
**"집을 하나도 직접 놓지 않고 12~20년 뒤 도시를 봤을 때, 이 모습이 내 결정 때문이라고 느끼는가?"**
- 판: 직할 장원 + 시장도시 1, 이웃 영지 3(**지도 밖 영지 카드**: 영주·가족·재정·관계·권리), 세력 4~5. 이웃 하나는 시험 장치로 **늙은 영주·딸만·비슷한 신분·재정 곤란**.
- 행동 열: 청원 판결 · 권리 확인 · 권리 회수 · 영지 방침 · 사업 장려금 · 시장 부담 조정 · 청지기 임명 · 장부 조사 · 권리 소송 · **혼인 계약**.
- 확장 경로 하나: **혼인 → 기대권 → 상속으로 이웃 영지 획득**(지도 밖 카드가 내 영지 카드가 됨, 두 번째 영지는 청지기 위임으로 굴러감).
- 성공 기준: 사용자 플레이(G-LM) — 20년 뒤 "왜?" 영수증을 다섯 곳 눌러 봤을 때 셋 이상이 자기 결정으로 이어짐, 지루한 반복 결정 없음.

## 7. 열린 질문 (진행하며 정함)
- 이웃 영지를 언제 실제 지도로 만들지(수직 조각 뒤 판정).
- 캠페인 5장과 영주 모드의 결합 방식(캠페인 사건이 영주 모드에서 그대로 오는지) — 수직 조각은 샌드박스로 먼저.
- 돈 단위: 게임은 페니(d), 협상 화면은 파운드·마르크 병기 여부.
