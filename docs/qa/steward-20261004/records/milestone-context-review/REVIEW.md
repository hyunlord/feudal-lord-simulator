# 이정표 원고 부모 독립 검수

10개 중9개 조건부 초안 통과, `milestone.market_town.r06stage.stone` 1개는 기본 사실행과의 시점 조합 보류다. 정본이나 원고를 변경하지 않았다.

작성자의 검사기를 별도 replay 복사본에서 실행했다. 116 합성 fixture 및 chapter3 기본형 복귀 확인, 원본4파일 SHA·인용구간 검증이 통과했다. 조건 selector는 실제 후보의 op/value를 해석하며 typed 입력 가드를 먼저 적용한다. strict schema는 제안 원고 형식에 적용되고 캡처 입력은 별도 명시적 키/타입 검사다. 전체 JSON Schema 표준 또는 엔진 선택기를 검증한 것은 아니다.

- chapter 시작/종료4개는 기록의 chapter값으로 분기한다. 마지막 장 이후 다음 장 없음은 politics.endChapterFive 소스로 뒷받침된다. 세계 내부 인물의 감정·가문 단절을 덧붙이지 않는다.
- first_l4 2개는 기록 시점의 L4 수를 말한다. 여러 집 동시 승급이나 한 집의 실제 최초 승급 tick을 단정하지 않는다.

- market_town.market는 기록시점 단계와 기존 사실행이 일치한다. stone 후보는 이미 석벽 도시일 때도 이정표 생산이 가능하다는 코드 분기에는 맞지만, retainFactLine의 ‘시장도시가 되었다’와 함께 읽으면 현재 단계 변화로 오인할 수 있다. 기존 사실행을 ‘시장도시 이정표가 기록되었다’로 중립화하는 별도 검토 전 조합 출력을 보류한다. 엔진에 적용하지 않았다.
