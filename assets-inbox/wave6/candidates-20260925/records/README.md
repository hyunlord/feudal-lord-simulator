게임 설치·코드 변경 없이 검토용으로 제작한 에셋입니다. 모두 `candidate`이며 본 제작 승격을 뜻하지 않습니다.

## 구성

- A 11장: 목재3·석재3·간판1·초가 지붕틀1·우물3단계 시트1·완공3프레임 시트1·망치 먼지1.
- B 5장: 작업 소품4종의 4방향 시트4·상체 오버레이1.
- C 6장: 연기2·먼지1·불2·빈 필지 말뚝1.
- 확인 그림3, `assets.csv` 22행·20열, 실제 프롬프트·선택/거절 이력·등록 좌표·검수 기록.

의뢰서의 총22장에 맞춰 B는 종류별 128×32 PNG에32×32셀4개를 수록했습니다. 방향 순서는 NE, SE, SW, NW입니다. C의 실제 목록은6장입니다. 우물은216×80(72×80셀3개), 완공효과는384×128(128×128셀3개)입니다.

## 좌표와 사용 범위

- 우물은 셀별 피벗(36,64). 원본과 같은72×80 셀 및 기존 표시비율0.72로 비교합니다.
- 지붕틀은 기존512×256 캔버스 등록을 유지합니다. 512px 전체를 단순0.5배 표시하는 것이 기존 게임의 건설 레이어 크기를 뜻하지 않습니다. 확인 그림은 별도 기록된 기존 레이어 배치 규칙을 적용합니다.
- 작업 소품은 건설 워커332×166의83px셀, frame0 손·어깨를 기준으로 등록했습니다. `records/worktools-registration.json`에 손잡이 피벗과 앞뒤 가림 규칙이 있습니다. 보행 frame1과 실제 작업 애니메이션은 검증하지 않았습니다.
- 상체 오버레이는 성인 남294×147 시트의 SE셀을74×74로 등록했습니다. 단순 source-over는 기존의 내려간 팔이 남아 미달입니다. 확인 그림에는 원본 덧그리기와 원래 상체 영역을 가린 실험을 모두 보여 줍니다. 후자는 통합 코드가 필요하며 게임에는 적용하지 않았습니다.
- 32px 효과를0.3배로 표시하면 약10px입니다. 세부 재료보다 발생 신호로 읽히는 한계가 있습니다. 최종 항목별 판정은 검수표를 확인해 주세요.

## 제작 기록

그림은 첨부 프로젝트 참조로 네이티브 image_gen에서 생성/편집했습니다. 출력 모델명은 노출되지 않았습니다. 생성 후 크롭·한 번 축소·셀 등록·알파 정리·RGB 확장 등 실제 수정은 CSV와 개별 기록에 있습니다. 생성 원본 PNG는 추가 에셋 수에 포함하지 않고 로컬 경로·해시로 추적합니다.

이미지 파일 검증과 오프라인 합성은 게임 통합·클릭·피벗 적용·성능·런타임 애니메이션 검증을 대신하지 않습니다.
