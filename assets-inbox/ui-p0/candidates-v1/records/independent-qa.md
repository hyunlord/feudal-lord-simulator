# UI P0 독립 후보 검수

판정: **후보 전달 가능**. 사용자 미술 승인이나 제품 설치·사용성 검증을 뜻하지 않는다.

생성 담당과 분리해 의뢰서·DESIGN·딥리서치 카탈로그·파일럿 원본, 최종 43 PNG와 확인 그림 3개를 검토했다. 24/48px 아이콘 판, 커서 핫스폿 판, 패널 전체 판, 초상 192px 나열, 데스크톱 1280×800·태블릿 1180×820 합성을 직접 열어 확인했다.

|검사|관찰·판정|
|---|---|
|수량|상세 표 기준 A23+B11시트+C6+D3=43 PNG. B는 57셀. 제목의 A14/약60과 다른 계산을 명시하고 임의 추가하지 않음.|
|0절 윤곽·채도|파일럿보다 부드럽고 얇은 갈색 윤곽. 빵의 오렌지·동전의 밝은 노랑이 황토/갈색으로 낮아짐. 일반 분류·시설의 녹색 바닥도 황토로 교정됨.|

|모서리|잎 장식 대신 작은 선·점. 목표 완료 인장과 경고 얼룩은 모서리에 국한되고 읽기 면은 단색.|
|문자 금지|납품 자산에 읽히는 문자·숫자·bar 내부·선택 사각·하이라이트 없음. 속도는 겹 꺾쇠, 정보·도움은 말풍선/책으로 표현. 확인판 문구와 숫자는 별도 합성층.|
|57셀 24px|큰 실루엣은 구분됨. 시설 안의 작은 도구·곡물과 필지 모서리 세부는 약함. 생활/헛간/저장유통 같은 건축 계열은 라벨을 함께 써야 함.|

## 채도 비교 보조 측정

파일럿과 P0의 96px 자원 셀에서 알파≥200 픽셀의 평균 HSV S를 계산했다. 빵 **0.722→0.524**, 돈 **0.772→0.614**. max(R,G,B)<80의 어두운 픽셀 비율은 빵13.8→12.7%, 돈25.8→20.6%. 도형과 점유 면적이 달라 어두운 비율을 정확한 외곽선 두께 측정으로 해석하지 않는다. 채도 감소의 보조 근거이며 미술 판단을 대체하지 않는다.

## 한계

- 작은 HUD 초상에서는 neutral/concern 차이가 약하다. 문구·상태 표시를 대체하는 유일한 신호로 쓰지 않는다.
- 24px 판독은 정적 시각 검토다. 처음 보는 사용자의 무라벨 식별 시험이 아니다.
- 초상 정렬 좌표는 육안 근사값이다. 얼굴 표정 변화 픽셀의 동일성을 주장하지 않는다.
- 9-slice 수치·반복끝 수치는 생산 검수 기록을 확인한 것이며 독립 재실행한 수치는 아니다.
- 게임 코드·자산 설치·실제 반응형·입력·DPR·접근성·프레임 성능은 이번 범위 밖이다.
