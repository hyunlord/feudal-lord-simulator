L0 153×153 / L1 139×139 / L2 137×137 / L3 142×142 / L4 161×161. 발판은 전부 **1×1칸**입니다. 피벗은 현재 게임의1254 원본 crop 좌표를 실제 PNG 좌표로 환산한 분수 값을 그대로 사용했습니다. `REFERENCE_CONTRACT.md`에 코드 근거와 수치가 있습니다. 재크롭·재중앙정렬·등급별 배율 재계산을 하지 마세요.

## 오버레이 및 판독

첨부 묶음에는 오버레이가 없어 로컬 Wave7 재작업 ZIP의 최신 v2를 찾았습니다. 원본 해시를 보존한 기준 파일이며, 이전 승인 여부를 새로 단정하지 않습니다. 눈·빈집 판자를 모두 `(0,0)`, 배율1로 합성해 호환됨을 확인하여 **새 오버레이는0장**입니다. 지붕 다각형은 원본 픽셀을 유지하고, 가동/겨울 상태를 본체에 굽지 않았습니다.

줌0.6 그림은 원본 PNG를 약30%로 표시합니다. L2~L4는 굵은 규칙적 골조·돌출층 띠, 1400 상위 등급은 작은 유리창·문 위 캐노피·허용된 굴뚝으로 구별합니다. L0·L1은 의뢰서대로 변화를 절제했으므로, 축소된 한 채만 보고 정확한 연대를 판독하는 표식으로는 쓰지 않습니다. 세 시대의 거리 전체와 같은 등급의 쌍을 비교하는 자료입니다.

검수는 납품 PNG의 오프라인 합성·픽셀·CSV·ZIP 검증입니다. 게임 설치, 실제 플레이 화면, 충돌·가림·캐시·성능 검증은 포함하지 않습니다.
