# Wave34 확인 그림 재현 계약

- 실제 게임 실행·설치 결과가 아닌, 납품 PNG와 기존 프로젝트 그림을 합성한 오프라인 검토 그림이다.
- 첨부 `새땅_지형.jpg`는 5×3 미니맵 모음이다. 확인1의 inset은 2행 4열 원본 크롭(396,132,128,128)이다. 등각 본 장면은 해당 강 유형을 폭 2·3·4칸으로 재구성한 로컬 테스트 장면이며 원본 화면인 것처럼 제시하지 않는다.
- 표시 배율 1.0: 논리 타일 64×32px. 소스 타일 128×64px에 0.5 배율, 줌 0.6은 소스 0.3 배율이다.
- 여울 배치 중심은 source 256,128. 강 횡단 축은 (64,-32), 흐름 축은 (64,32). 강 폭은 횡단 축의 논리 셀 단위로 정의한다. 너비 변화는 연속 smoothstep, 중심선은 낮은 진폭 사인 곡선이다. 각 여울 앵커에서는 정확히 2·3·4칸이다.
- 기존 다리는 첨부 atlas 중 가운데 열 deck/뒤 난간/앞 난간의 각각 연결된 alpha 성분을 추출하여 합성한다. atlas 전체를 단일 스프라이트로 쓰지 않는다.
- Wave29 흐름은 기존 `current_arrows_se_sheet.png` 첫 128×64 프레임으로 합성한다.
- 확인2는 동일한 5×5칸 필지를 단계마다 유지한다. 단계 1~3의 바탕은 기존 승인 Wave22 `fen_{summer,winter}_a-v2.png` 원본 그대로이며 위에 신규 128×64 오버레이를 얹는다. 단계1은 둘레 16칸만 표시하고 다른 축 가장자리는 좌우 반전한다. 단계2는 5칸 길이 도랑 2줄(10장), 단계3은 새로 편집된 낮은 대비의 연속 젖은 흙 오버레이를 25칸 모두에 채운다. 128×64 원본 크기에서 25칸을 먼저 합성한 뒤 전체 필지를 한 번 축소하여 개별 타일 필터링의 알파 틈을 피한다. 실제 엔진 구현을 의미하지 않는 오프라인 합성 계약이다. 반복 검수용 25칸 일괄 배열과 실제 장면의 배치는 구분한다.
- 기존 fen_pool b/c 데칼은 단계1 5개, 단계2 3개(70% 크기), 단계3 0개로 줄인다. 이는 배수 엔진의 물 감소를 표현하는 합성 입력이며 신규 단계 이미지 자체가 기존 웅덩이 픽셀을 삭제한다고 주장하지 않는다.
- 완료 상태만 기존 여름 grass / 겨울 grass_fill을 쓰며 신규 배수 띠를 4변에 투영한다. 겨울 얇은 얼음/눈은 신규 겨울 오버레이가 담당한다.
- 외부 참조 없음. 모든 입력의 절대 경로·SHA256·납품 내 최소 입력 복사본은 `proofs-provenance-all.json`에 기록한다. 작업 원본은 변경하지 않는다.
