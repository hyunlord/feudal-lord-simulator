# 초상 연결과 필요한 얼굴

초기138명 전원에 실제 저장소 PNG ID·경로·해시를 연결했다. 53명은 연령대 부족 또는 다른 인물과 동일 얼굴을 공유하는 **임시 대역**으로 신규 얼굴이 필요하다. 연결되었다는 사실이 최종 미술 승인을 뜻하지 않는다. 코드의 portraitIdentity는 기존 identity이고, 특정 연령 파일 선택은 proposals.personProfiles[].portrait에 명시했다. 상세 경로·SHA·노화 사슬은 records/portrait-bindings.json과 hundred.json에 있다.

담비는 백작가 h18에만 허용했다. 플레이어 존은 L3_101_mature(45세, 담비 없는 지주층)다. 혈통 원화의 부모 ID는 원화 메타데이터이지 새 고을의 부모 ID가 아니다. 서로 다른 가문이 L3·L7 원화 혈통을 공유해 실제 화면에서 친족처럼 닮는 경우가 있다. 독립 가문별 얼굴 다양성과 새 가계의 닮음은 최종가계도 검수가 필요하며 같은 identity의 노화 단계는 서로 다른 얼굴로 세지 않았다. 피부색·체형으로 성격·도덕·능력을 정하지 않았다.

## 후속 세대 범위

1301~1450 출생자는 시험 연대기의 별도 인물이며 이 초기138명용 연결만으로 미술이 완비되었다고 주장하지 않는다. 새 인물은 existing-face-free-slot → 연령 적합 확인 → 가계도 닮음 검수 → 부족 요청 순서로 처리한다. 하나의 노화 사슬을 여러 동시대 사람에게 자동 복제하지 않는다. 후기 복식 전환도 이번 초상풀에서 검증하지 않았다. 새 그림은 이번 작업에서 만들지 않았다.
