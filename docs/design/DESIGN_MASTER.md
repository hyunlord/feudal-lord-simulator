## 1. 한 문장

> 영주가 되어 강가의 작은 촌락을 성곽 시장도시로 키우되, 건물을 하나씩 놓는 것부터 구역을 그리고 권리를 주고받는 것까지 **세부와 포괄을 오가며** 방향을 잡고, 그 결과가 **원인과 함께 읽히는** 도시 건설 게임.

정체성 세 가지:
1. **인과가 읽힌다** — 모든 문제·예측·수입·불만이 원인까지 거슬러 올라간다 (Caesar III의 계보)
2. **유기적인 땅** — 구역·길·성벽·물가가 사각 타일의 집합으로 보이지 않는다 (Manor Lords·Foundation 계보)
3. **권리가 곧 정치** — 돈은 점수가 아니라 권리·의무·공공사업을 잇는 매체이고, 권리를 주고받는 것이 정치가 된다 (중세 잉글랜드 1300–1450)

## 2. 세계와 아트 [확정]

- **잉글랜드 남부·남동부 시장도시, 약 1300–1450년**.
- 주택 발전은 재료 사다리(초가→기와→슬레이트→석조)가 아니라 **층수·돌출층·가게 전면·관리 상태**로 표현. L0 오두막 / L1 소가옥 / L2 장인가옥 / L3 상인가옥 / L4 도시 대가옥.
- 굴뚝 통·푸른 유리·슬레이트·S형 기와 금지. 성벽 밖 초가, 성벽 안 평기와. 참나무 목골조, 석회 도장, 잡석 기단.
- 지도 **64×64 타일**, 타일 화면 크기 64×32px(줌 1). 고정 SW 방향 2:1 등각, 카메라·건물 회전 없음 **[확정]**. 방향별 건물 전면은 곡선 2단계 캡처 후 재검토 **[확정: 당분간 SW 고정]**. 가림은 선택 윤곽 → 앞 건물 페이드 → 지붕 숨김 순으로 해결.
- 영감 이미지(루리웹 게시 9장 연작)는 Shabazik의 판타지 도시 'Alfdreim', 마지막 장은 1636년 뮌스터 조감도 참고. 성장 연속성 원리만 차용, 근세 별모양 요새는 만들지 않음.
- 세부 규칙: `ASTRA_ART_DIRECTION_v1.md`.

## 3. 게임 모드와 한 판

| 항목 | 결정 |
|---|---|
| 모드 | **목표 달성형(60–90분 목표, 실패 가능)과 샌드박스 둘 다** [확정]. 승리·실패 조건은 시나리오 데이터 |
| 위기 | **초기엔 가끔(화재·흉작), 시나리오별로 확장** [확정]. 사건은 데이터 정의 |
| 돈 | **점수가 아니라 권리·의무·공공사업을 잇는 매체** [확정]. 유지비·세금·교역이 모두 가능한 장부 |
| 실패 | 목표형에서 soft failure: 체납 → 개입 → 압류 → 권리 위기, 인구 이탈 [권고] |
| 일시정지 중 건설 | 허용 [확정] |
| 되돌리기 | 마지막 건설 1회, 전액 환불 [확정] |
| 한 판 실제 시간 | **사람 플레이 측정 후 조정** [보류] |

**한 판의 흐름(목표형, 추천안 기준)**
- 0–10분: 길·집·우물·경작지·방앗간. 영주 직영.
- 10–30분: 필지 구역, 시장·교회. 첫 화재로 초가 밀집의 위험을 배움.
- 30–60분: 목책 → murage 청원 → 석벽. 도시 공동체가 요구를 내밈. 통행세 징수를 도시에 맡길지 선택.
- 60–90분: 자치 특허 여부, 상인 엘리트의 성장, L4 주택 → 번영하는 성곽 도시.

## 4. 세 조작 층 [확정]

| 층 | 플레이어가 하는 것 | 예 |
|---|---|---|
| **세부 (micro)** | 건물·길 직접 배치 | 교회를 이 자리에 |
| **구역 (meso)** | 모양이 자유로운 구역을 그리면 시스템이 안을 채움 | 강가 굽은 땅은 필지, 성밖은 경작지 |
| **방향 (macro)** | 조례·청원·권리 부여·회수 | 성벽 안 초가 제한, murage 청원, 통행세 징수를 도시에 임대 |

**소유권 우선순위** [권고]: 직접 배치·보호 > 구역 자동 생성 > 정책에 의한 규칙 변조 > 일반 AI 선호.
- 직접 지은 건물은 구역이 재개발하지 않음. 명시적 재개발 토글 때만 [권고].
- 정책은 건물을 즉시 지우지 않음: 유예 → 준수 수요 → 전환.
- 구역 경계 편집은 신규 성장만 바꿈.

진행하면서 무게가 옮겨간다: 초반 세부 → 중반 구역 → 특허 이후 방향.

## 5. 구역 [권고]

**표현**: 보이는 경계는 유기적, 판정은 결정론적 타일. 그린 획을 `zone.strokes`에 보존하고 64×64 지도 격자로 래스터화한 `membership`만 시뮬레이션이 읽음. 화면 외곽선은 membership에서 경계층(15절)으로 파생. 구역 도입은 곡선 3단계 = 로드맵 C1과 한 작업 **[확정 D4]**, 저장은 B8 틀 안의 v1→v2 마이그레이션.

**구역 = 허용 + 선호 + 형태 + 성장 예산**
| 속성 | 예 |
|---|---|
| 허용 | 필지 구역: 집·가게·공방 가능, 대형 밀밭 불가 |
| 선호 | 강가 주거: 집+텃밭 선호 |
| 형태 | frontage 2–4칸, 깊이 3–7칸, 빈터 15% |

**유기성은 난수가 아니라 frontage에서**: 필지는 굽은 도로·성벽·물가를 따라 생성.

**초기 구역 어휘**: 필지(burgage), 경작지(open field, 성밖 기본, 성내 대형 밀밭 금지·텃밭·과수원만). 이후 시장 광장(광장은 플레이어, 좌판은 자동), 공방, 공유지. 교구는 칠하는 구역이 아니라 교회·거리·수용량에서 자동 추론되는 관할 오버레이.

**입력**: 브러시 + 자동 윤곽 [권고]. **건축 속도**: 시간에 따라 자동 [권고].

**C1a 적용(B5+C1a, 2026-09-25)**: 데이터·액션·규칙·필지 파생을 구현했다([구역 명세](zones.md)). 그리기 UI는 C1b다.
- 구역 종류는 6개(필지·경작지·목초지·건초지·숲·공유림·과수원)이고, 규칙은 필지·경작지만 있다.
- 겹침은 나중에 칠한 쪽이 가진다(결정 Z1). 성내 경작지는 그리기부터 거부한다.
- 필지 깊이는 이번에 3.2칸(v3-A 탐침값)으로 두었다. 위 표의 "깊이 3–7칸"은 필지 변형(뒤뜰·텃밭) 단계에서 다시 본다.
- 저장은 v6(`zones`·`nextZoneOrdinal`)이다.

## 7. 경제 [권고, 장부 구조는 확정]

**원칙**: 돈은 권리·의무·공공사업을 연결한다. 권리는 수입과 의무를 동시에 만든다.

**가장 큰 수정**: 시장 판매대금 전액이 금고로 들어오는 현재 구조는 틀렸다. 상품은 주민·상인 소유이고 금고에는 **통행세·좌판세**만. 직영 재고(영주 곡창 등)를 팔 때만 판매대금이 금고로.

**장부**: `LedgerEntry = {tick, category, amount, account, sourceRefs}`
- 계정 4종: **일반 현금 / 목적 기금**(murage·pontage) **/ 미납 의무**(fee farm·국왕세·미지급 임금) **/ 현물 의무**
- 금고 = 장부 파생값. 내부 단위 페니. 화폐 명칭 "금화" → "돈"
- 교역은 둘로: 민간 교역량(주민 경제 지표) / 금고 교역 수입(직영 재고만)

**초기 항목과 상대 규모(밸런싱 시작값)**: 필지 지대 1.0 · 시장 통행세·좌판세 0.5–1.0 · 법정·허가·벌금 0.1–0.4 · fee farm·영주 상납 0.7–1.5(고정) · 유지비·임금 · 공공 재고 판매(기본 0) · 특별·목적 기금(사건 때).

**노동**: 유휴 31%는 실업이 아니라 직업 모델이 건물 중심이라 생긴 것. 인구를 정규직 / 가내 생산 / 일용 노동 / 계절 농업 / 부양가족으로 나누고 주택 L1–L3에 **가내 공예 슬롯**, 건설·운송 **일용 노동 풀**.

**방앗간 독점(제분 의무·제분료)**: 영주 시나리오 기본 ON [권고]. 공동 화덕 독점은 특정 시나리오만.

**성벽 = 재정 프로젝트**: 목책 → 위협·규모 증가 → 석벽 결의 → 국왕에 murage 청원 → N년 허가 → 교역 관세가 성벽 기금으로 → 공사 → 만료 시 재청원. murage는 외부 상인 거래비용을 올려 시장 매력도와 상충. 건설 허가(licence to crenellate)는 별개, 문루·위신과 연결.

## 8. 권리와 정치 [권고, 플레이어 정체성은 확정]

**플레이어 = 영주** [확정]. 도시에 자치 특허(권리 묶음)를 부분적으로 내주는 것이 진행 선택지. 권리 회수, 상인 권력의 성장과 영주 견제까지 포함한 **내부적으로 복잡한 정치** [확정].

### 8.1 자산과 권리를 분리
- **자산(asset)**: 영주가 손에 쥔 땅·건물·재고. 성채, 직영지, 방앗간 건물, 직영 곡창.
- **권리(right)**: 무엇을 할 수 있는가. 시장, 통행세 징수, 제분 의무, 하급 법정, 치안 법정, 관리 임명, 관리 선출, 조례 제정, 길드 인정, 공유지 이용, murage 징수 (초기 어휘 11개).
- **권원(authority)**: 각 권리가 어디서 왔나. 국왕 특허 / 영주 특허 / 관습 / 시효 / 임차 / 판결 / 강제 점유. 별도 "층"이 아니라 권리마다 붙는 연쇄.
- 한 건물 위에 자산과 여러 권리가 겹칠 수 있다(방앗간 건물 + 제분 의무).
- 영주는 자기가 가진 것 이상은 줄 수 없다. 시장 개설권 같은 국왕 특권은 새로 만들어 줄 수 없음.

### 8.2 권리 보유의 핵심 필드
- **법적 보유자 / 운영자 / 수익자** 분리 (영주가 시장권을 쥔 채 통행세 징수만 도시에 임대)
- 범위, 근거 문서, 권원 연쇄, 기한, 의무, 종료 조항, 반환 대상
- 상태: 활성 / 정지 / 압류 / 분쟁 / 만료
- 행위자별 인정 상태(인정·분쟁·미정), 법적 강도, **집행 가능성**(흑사병 이후 하락)
- **fee farm은 권리가 아니라 특허 문서의 대가(의무)**

### 8.3 행위자
| 행위자 | 자원 | 도입 |
|---|---|---|
| 영주 (플레이어) | 권위, 특허 신뢰도, 국왕과의 관계 | 처음부터 |
| 도시 공동체 | 신뢰, 결속, 자치 이해 | C단계 (유일한 AI 행위자) |
| 상인 엘리트 | 신용 여력, **관직 장악**, 신뢰 | E단계, 하나의 합성 행위자로 시작 |
| 평민·소작 | 생계 압력, 관습 원한, 동원력 | 평시엔 인구, 원한이 쌓이면 **운동**으로 생성 |
| 국왕 | 권원 제공, 심판, 과세, 위기 개입 | E단계, **지도 밖 심판자** |
| 교회·수도원 | 영주 또는 공동 영주 | 수도원 도시 시나리오에서만 |

도시 공동체와 상인 엘리트는 **분리** [권고]: 권리는 도시가 쥐고, 상인은 도시 관직을 장악해 사실상 통제(과두정).

행위자 고정 필드(`MerchantInfluence` 등)를 게임 상태에 박지 않는다. 확장 가능한 개체.

### 8.4 기억 세 종류
- **현재 태도**: 세금·식량에 대한 즉각 반응
- **원한 기록**: 원인(SourceRef)이 남는 사건 기록. 일부는 오래 감
- **평판**: 공개 `특허 신뢰도` 하나 [권고]

### 8.5 회수 경로
기한 만료·반환 / 위반 근거 정지 / 협상 반환 / 국왕 판결 / 일방 압류 / 무력.
- **정당한 사유** = 위반이 있고 + 그 위반이 해당 특허에 관한 것이고 + 문서에 구제 조항이 있고 + 유예·판결 요건 충족. 체납 한 번으로 관리 선출권까지 몰수할 수 없음.
- **부당한 회수를 금지하지 않음** [권고]: 실제 압류로 처리되고 법적 주장과 정치 비용이 남음.
- 압류는 권리 소멸이 아님: 정지 → 관리인 → 수입·통제 전환 → 복구·확인 협상 (런던 1285–1299).

### 8.6 견제 사다리
불만 → 개별 청원 → 관직을 통한 집단 요구 → 신용 조건 악화·투자 축소 → 국왕 청원·소송 → 집단 불복·체납 → 폭동.
준비도 ≈ 원한 심각도 × 조직 역량 × 쟁점 이해관계 × 성공 가능성 인식.
소도시 상인의 대출 회수 압박은 **게임적 외삽**, 드문 압력 행동으로.

### 8.7 특허 UI
패키지 선택(제한·넓음·완전 특허), 내부는 개별 권리 [권고]. 예: 제한 특허 = 통행세 운영 + 내부 조례 + 집행관 지명을 도시에, 시장권·상급 법정·제분 의무는 영주가 유지, 도시는 연간 fee farm.

## 9. 사건 [권고]

사건은 데이터 정의(발생 조건, 효과, 해결 조건, UI 메타), 시나리오가 켬. 시드 기반 결정론.
- 초기: **화재**(초가·밀집·우물 반경, 초가 조례와 인과), **흉작**
- 이후: 대기근 연쇄(곡창 = 충격을 시간으로 미루는 보험), 흑사병(인구↓ → 빈 필지 → 임금↑ → 이주민 유치, 권리 집행 가능성↓), 국왕 과세, 징발, 해안 습격(→ murage 청원), 경쟁 시장
- 정치 사건 문법: 요구 / 청원 / 위반 / 체납 / 회수 / 확인 / 집단 불복. 이벤트 수가 아니라 권리·경제·기억의 조합이 복잡성의 원천.

## 14. 곡선 세계: 경계층 (Fable 설계안 v1 채택)

원문: Fable 설계안 v1, 설계 v3-A(Claude Code, 탐침 근거), 설계 v3-B(저장·편집 계약). **채택 기준은 `ORGANIC_WORLD_SYNTHESIS.md`** — 세 설계가 갈린 곳은 통합안이 우선한다. 요지: 저장은 `zones[]`만(v2), 도로 렌더는 셀 체인 → 이동평균5+Chaikin2(노드 고정), 도로 4-연결·맨해튼 비용, 성벽은 차단·운반 동치가 하드 게이트, 건물은 footprint 전체가 구역 안, 도로 변경 시 기존 집 불변, 서비스 배정은 먼저 지어진 집 우선(Q11), 1단계는 D1a 렌더 전용 / D1b 도로 입력 / C1 구역으로 분할.

**원칙 [확정 D1]**: 논리는 정수 격자, 경계는 격자 꼭짓점 위의 **공유 폴리라인**, 화면은 그 폴리라인을 매끈하게 그린다. 둥근 것은 지형·길·성벽·구획의 윤곽, 각진 것은 건물. 어긋남은 타일의 1/4까지.
- **새 논리 진실을 만들지 않는다.** 진실은 `tile.terrain`, `tile.hasRoad`/`buildingId`, `palisade.segments[].edgePath`. 경계층 `BoundaryGraph = f(tiles, palisade, buildings, zones)`은 파생·비저장·결정적.
- 경계 데이터는 **타일 변이 소유**(`edgeKey`), 꼭짓점 변위는 꼭짓점 키 hash(±0.12타일, 지도 끝 0). 지형 경계는 꼭짓점 기준 marching squares + Chaikin 2회. 도로는 **중심선 파생 그래프**(`roadCenterlineGraph`) + Catmull-Rom, 교차로·막다른 끝·성문은 고정점. 성벽은 기존 폴리라인 위에 압출 띠 + 꼭짓점 내각 규칙(90° 탑, 135° 기둥, T 문루). 밭은 무리 단위 외곽선.
- **허용 오차 [잠정 D5]**: 지형 경계 0.25타일, 도로 중심선 0.25, 성벽 0.15, 워커 오프셋 0.25, 클릭 0, 성문 개구부 ≥ 1.6타일. 1단계 측정 후 확정.
- **성능**: 지면 패스를 8×8타일 **청크 래스터 캐시**로(1단계, 측정 동반). 중앙값 악화 없음, p95 ≤ 110%.
- **1~2단계는 렌더 전용**, 기능 플래그 `RENDER_BOUNDARY_V2` 뒤. 게임 상태·저장·경로 무변경. 그래서 로드맵 B단계와 병렬 가능.
- **도로 입력 [확정 D2]**: L자·대각 드래그 허용, 논리는 계단 타일열.
- **에셋 규격**: 타일 1칸 = 128×64로 제작(DPR 2 기준 1×), 스트립 좌우 seamless, 알파 여백 8px, 표시 크기 기준. 1단계 신규 5장, 전체 약 17장.
- **착수 조건 = 0단계 [확정 D7]**: 깨끗한 클론에서 전체 테스트 통과, 최신 커밋 기준 seed 1~5 기준선 교체, 생산시설 밀도 지표, `TileEdgePoint` 통일, 64×64에서 48필지 가능성 측정 **[D6]**.
- 구역의 유기성은 곡선만으로 부족: **frontage 필지 생성**(굽은 도로·성벽·물가를 따라 필지 생성)은 C1 명세에서 별도로.

## 15. 원칙과 위험

- **완료 판정은 깨끗한 클론 기준.** 테스트·스크립트는 저장소 밖 절대경로와 `output/` 증빙 폴더에 의존하지 않는다. (2026-09-24 Fable 검토에서 전체 회귀가 사용자 Mac에서만 통과함을 확인)
- **규칙은 명세와 시나리오 테스트가 관문, 화면 플레이는 마지막 확인.** 코드 근거 없는 판단 금지.
- **작업 브랜치는 그 작업이 끝나면 본선에 합친다.**

- **뼈대는 규칙을 바꾸지 않고 먼저**, 규칙은 작은 수직 시제품으로 켠다.
- **정치는 핵심 루프를 덮지 않는다.** Manor Lords처럼 정치 없이도 도시 건설 루프가 성립해야 하고, 정치는 도시가 커져 직접 운영이 버거워질 때 등장.
- **가장 큰 위험: 사람이 아직 한 판도 끝까지 해 보지 않았다.** 깊은 시스템 설계보다 기준선 플레이가 먼저. UI-3 직후 기준선 플레이, C단계 관문에 사람 플레이 3회.
- 복잡도가 좌절을 만드는 지점은 계산이 많을 때가 아니라 **인과 사슬이 끊길 때**. 모든 수치에 SourceRef.

## 16. R1-fix 엔진 규칙 정정

사용자 지시서 [R1-fix](rule-repairs/WORK_ORDER.md)가 이번 수정의 범위와 관문이다. [결정 목록](../decisions/README.md)의 R1-fix 항목과 해당 S명세가 이전 감사 시점 설명보다 우선한다. R-1은 먼저 지어진 주택의 서비스 우선권을 기존 시작 주택/건설 서수로 결정하며, 기존 주택을 탈락시키지 않는 재배정만 허용한다.

R-8의 자동 조언은 기본120틱 주기를 유지하되, 무조치 후 실제 밀 반입으로 기존 방앗간 전체의 원료가 양수가 되는 운송 정체 전환을 재평가한다. 실행한 행동 사이에는 여전히 최소120틱을 둔다. 이 관측은 UI·headless가 공유하는 런타임 상태이며 저장 스키마나 게임 경제 규칙을 바꾸지 않는다.

반복 배급 부족의 도로 보강은 기존 운영 곡창 최단거리보다 엄격히 짧은 실제 경로를 증명한 경우만 허용한다. 새 곡창·경제 수치·벽 통행 예외로 대신하지 않는다. 창고 포화가 석조 조건의 실제 석재 입고를 막으면 기존 합법 창고 확장을 사용한다. [배급](rule-repairs/S8-distribution-roads.md)·[저장](rule-repairs/S8-storage-recovery.md) 반례와 제한을 각각 보존한다.

## 17. 콘텐츠 설계 반영 (콘텐츠 설계서 v1.1)

콘텐츠의 폭은 [콘텐츠 설계서 v1.1](CONTENT_DESIGN.md)을 따른다. 근거 조사는 [콘텐츠 카탈로그](../research/2026-09-24-content-catalog.md)이고 에셋 순서는 [에셋 계획 v1](ASSET_PLAN.md)이다. 다양성은 건물 수보다 사슬·땅의 어휘·시대 아크·지도 archetype에서 나온다. 결정 번호는 [결정 목록](../decisions/README.md)의 K1~K12다.

- **K2 [확정]**: 직물은 7단계 전부 자원으로 노출한다. 가내 단계는 집 안 재고로 두고, 분류 체계·창고·UI를 함께 설계한다. K11(중간재 노출)도 이에 따라 노출로 바뀌며 에일은 보리→말트→에일 3단계다.
- **K4 [확정]**: 석벽은 선택 프로젝트다. 시대 진행과 승리는 번영·전문화로 판정하고 흐름은 `촌락→조밀한 시장도시→[조건부] 요새 석조 도시`다. B2에서 번영 승리의 석벽 완공 요구를 제거했다(아래 K4-1).
- **K4-1 적용(B2)**: 시나리오 데이터(`src/content/scenario/`, [명세](scenario-era.md))가 정착 단계·해금·승리·실패를 정한다. 교회는 시장도시 단계에서 해금되고, 석조 선포는 전제조건이 있는 선택 석벽 프로젝트가 되며, 번영 승리는 석조 시대·석벽 완공을 요구하지 않는다(석벽 완공은 승리 화면 보너스). 목책 선포는 시장도시 진입 방식 그대로이고 L4의 '완성된 성벽 안' 조건도 유지한다. 목책까지 선택화하는 K4-2는 C1에서 한다.
- 나머지 K1·K3·K5~K12는 권고이며 이의가 없으면 그대로 진행한다. 설계서 11절의 공통 계약(`SourceRef`·`EffectSpec`·`PredictionLine`)이 새 사슬·사건·권리의 원인과 예측을 나르는 통로다.
