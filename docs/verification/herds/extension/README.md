# 기존 목초지에 정적 목축군 세 장 추가

제품 `ed483f09`는 양 b·소·돼지 PNG 세 장과 계약 데이터만 더한다. 양 a 제품 `001a4873`의 소비자를 재사용하며 전체 설치는 4장이다. 각 PNG는 네 방향의 정적 그림이며, 보행이나 동물 AI를 추가하지 않았다. 보이는 몸통 수 변화(양 b 3→5, 소 2→3, 돼지 2→4)는 그림의 변화이고 경제 가축 수 변화가 아니다.

## 실제 저장과 실행

상위 보고서의 정상 명령 재생으로 만든 여름 1500·겨울 3500 저장을 바이트 그대로 썼다. 새 소품이나 배치를 만들지 않고 기존 양 b(42,12), 소(43,7), 돼지(35.3,8)를 카메라로 바라봤다. 각 계절·대상별 줌 1.0·0.6·3.0, 18개 전후 쌍의 저장·전체 상태·소품·tick·카메라·줌이 같았다. 양쪽 pageerror와 network failure는 0이고, 의도한 PNG가 실제 world draw로 소비됨을 확인했다. 상세는 comparisons.json이다.

|실행 이름|역할|명령 시간|결과|
|---|---|---:|---|
|astra-HERDS-ext-before-8936a46|기준선 18뷰|149.8초|종료 0|
|astra-HERDS-ext-after-ed483f0|설치 뒤 18뷰|151.7초|종료 0|

분류는 `docs/REMOTE_RUNS.md`의 browser·짧은 probe에 해당하는 `--light`다. 단일 Chrome에서 정지 저장 18뷰를 순차 촬영했으며 장기 시뮬레이션·기하 반복·성능 부하 시험이 아니다. 공식 run.sh의 nice 10, MemoryMax 48G, CPUQuota 1200% 제한과 공용 fls-runs.slice 안에서 실행했다. 무거운 시험·기하 관문을 light로 바꾸지 않았다. 실행 원본 JPEG·JSON과 저장·하니스는 전달 ZIP에 남긴다.

## 화면 판정과 한계

부모 검수자는 summer-sheep-b-z3, summer-cattle-z3, winter-cattle-z0.6 원본 JPEG를 직접 확인했다. 근접에서는 양 5마리와 소 3마리, 발끝 접지와 개체 분리가 읽히고 이 표본에서 명백한 잘림이나 울타리 바깥으로 튀는 모습은 없었다. 동물 윤곽은 주변 땅·풀보다 더 선명하고 소의 보행 자세는 정적으로 멈춰 보인다. 자연스러운 이동이나 풍경과의 완전한 일체감으로 판정하지 않는다. 겨울 줌 0.6에서는 무리 색점이 보이지만 개체 수·방향을 판독할 수 없다.

첫 돼지 초점 (35.3,8)은 나무에 가려졌다. 이 18뷰의 draw 호출만으로 돼지 네 몸통의 가시성을 통과시켰다고 주장하지 않는다. 기존 다른 돼지 위치로 카메라만 옮긴 추가 확인은 아래 별도 기록한다.

실제 확장 18뷰의 근접 원본 crop은 양 b SE, 소 SE/SW, 돼지 SE를 포함했다. 모든 방향을 실제 화면에서 확인했다는 주장은 하지 않는다. 네 방향 계약·크기·pivot·원본 해시는 자동 시험으로만 확인한다.

## 코드와 계약 검사

Mac 집중 시험 102/102, TypeScript 검사·변경 시험 파일 ESLint·diff 검사 통과. 데이터 추가 전에 새 세 회귀 사례가 실패함을 확인했다. 원본 바이트, 셀 crop/pivot, 네 방향 선택, 공통 동물 배율, 기존 fallback과 봄 bounds 시험을 포함한다. 최종 게시 관문 결과는 전체 보고서와 ZIP에 따로 기록한다.

## 돼지 가림을 피한 기존 위치 확인

기존 돼지 세 위치 (30.5,14.8), (22.8,32.5), (26.2,4.5)를 여름·겨울 줌 3.0에서 추가로 촬영했다. `astra-HERDS-pig-before-8936a46` 50.1초, `astra-HERDS-pig-after-ed483f0` 50.5초, 두 실행 모두 같은 짧은 순차 browser probe `--light`이며 종료 0이다. 추가 6/6쌍의 저장·상태·소품·카메라가 같고 page/network 오류는 0이다(pig-comparisons.json). 최초 위치를 지우거나 돼지를 옮기지 않았다.

실행자는 south 여름·겨울 및 north 여름 원본을 열었다. south의 네 몸통은 숲 가장자리 땅 위에 서로 분리되어 읽히며, 새 시트가 기존 두 마리보다 작고 선명한 모습도 그대로 남는다. 북쪽 표본은 아래쪽 수풀과 가깝고 첫 초점은 나무에 가려져 있다. 어떤 위치에서도 항상 모든 몸통이 읽힌다고 주장하지 않는다. 추가 draw 기록에는 NE/SE/NW가 있으나 돼지 SW의 실제 노출은 미판정이다. 정지 자세는 이동 증거가 아니다.

부모 검수자도 south 여름·겨울 원본을 직접 확인했다. 네 몸통의 분리·접지, 오른쪽 풀의 일부 가림, 이 두 표본에서 새로운 큰 겹침이나 잘림이 없음을 기록했다. 전체 방향·이동·0.6줌 개체 수 판정으로 확대하지 않는다(visual-verdict.json).

저장소 대표 JPEG 다섯 장은 크기·구도를 유지한 quality 45 재압축 파생본이다. derived-images.json에 원본/파생 SHA256을 구분했고, 원본 JPEG·PNG는 실행 결과에 보존한다. 전달 ZIP에는 모든 전후 원본 JPEG를 넣는다.
