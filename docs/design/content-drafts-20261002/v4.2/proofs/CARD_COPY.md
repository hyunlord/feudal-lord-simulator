# 수정 카드 읽기판

실제 카드가 소비하는 제목·본문·선택지 이름·대가 문구. 브라우저 캡처가 아니다.

## ck_evt_002 가을 장부에 없는 곡물 자루

먼 영지의 곡물 장부와 보고가 맞지 않습니다. 미카엘마스에 직접 찾아가 감출 틈을 줄일지, 장부는 받아 보되 오늘부터 일상 결재를 영주가 맡을지 정해야 합니다. 방문은 다음 감사 때, 직접 감독은 지금부터 적용됩니다.

- **b 미카엘마스부터 해마다 방문 감사한다** — 청지기에게 일상 결재를 맡긴 채 감사의 적발 가능성을 높인다. 방문 뒤 한 해 동안 다른 영지를 직접 살필 여력이 줄 수 있다. 장부 감사로 바꾸기 전까지 매년 방문한다.
- **c 일상 결재를 가져오고 장부 감사를 유지한다** — 청지기의 일상 재량을 줄이는 대신 영주의 업무를 늘린다. 직접 관리 한도를 넘으면 청원과 장부 처리가 늦어지고 오류 위험이 커지며 방문 감사의 높은 적발률은 얻지 못한다.

## ck_evt_005 빈 좌판 곁의 세금 장부

빈 좌판을 가리키며 상인들은 앞으로의 장날마다 떼는 몫을 줄여 달라고 합니다. 수입관리인은 영주의 다음 지출을 걱정합니다. 이번 결정은 한 좌판이 아니라 도시 전체 시장 좌판세 배율로 계속 적용됩니다.

- **a 시장 좌판세 배율을 750‰로 낮춘다** — 장날 거래에서 상인이 남길 몫을 늘리는 대신 영주가 거둘 몫을 줄인다. 새 상인이나 좌판이 곧 늘어난다는 보장은 없다. 다시 바꾸기 전까지 유지된다.
- **b 시장 좌판세 배율을 1250‰로 높인다** — 거래당 영주 몫을 키우는 대신 상인에게 남는 자금과 다음 사업의 여지를 줄인다. 거래가 없으면 세입도 생기지 않는다. 다시 바꾸기 전까지 유지된다.
- **c 기존 세율을 지키며 다음 거래를 지켜본다** — 현재 금고와 설정을 지키지만 답을 미룬 대가로 첫째 상인 가문의 관계가2 낮아진다. 기존 사업·거래의 시간은 계속 흐르며 자동 재심은 예약하지 않는다.

- **c 남은 기한 동안 혼담의 지출을 검토한다** — 지금 조건을 확정하지 않지만 남은 협상 시간을 써 버리고 다른 혼담도 시작할 수 없다. 늦으면 이 역제안은 철회된다.

## ck_evt_038 판결 뒤에도 닫힌 문
