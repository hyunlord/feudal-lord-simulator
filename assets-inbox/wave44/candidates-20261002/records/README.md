경량 ZIP은 고해상도 originals/를 제외한다. 모든 생성 원본은 이 작업 폴더 originals/에 별도 보존. 기록의 original_local은 로컬 보존 경로이며 ZIP 동봉 경로가 아니다. reference_pack은 ZIP에서 열 수 있는 참조본 경로다. 수정 참조 JPEG는 시각 확인용 파생본이며 원본과 바이트 동일하지 않다. 원본 SHA와 해상도는 generations.json 참조.
