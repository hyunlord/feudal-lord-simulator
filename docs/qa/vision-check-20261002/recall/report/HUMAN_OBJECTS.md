# 소품 정답 판독

판독자는 검출 목록·점수·주석 이미지를 열지 않고 `prenat1/raw/prenat1-city/00.png` 원본 및 원본 확대만 직접 보았다. 현재 도시의 잘못된 카메라 메타데이터는 사용하지 않았다. 좌표는 화면 원점 기준이며 원본 이미지는 1600×1100이다.

## 고정한 정답

| ID | 판정 | 근거 |
|---|---|---|
| OBJ-YARN-01 | 반복 밀도 양성 군집 1개 | 인접 중앙/호숫가 주택 문 앞에 같은 흰 고리 실타래가 연속 반복. 개별 고리를 독립 결함으로 부풀리지 않는다. docs/STATUS.md:98–100의 NAT-1 완료 기록은 거리 줄마다 같은 것 둘까지, 절반 빈자리, 한 가지 몫 16.7% 이하를 명시한다. |

| OBJ-BARREL-02 | 크기 양성 1개 | 오른쪽 물통 몸통 약28px / 성인17.6px. 일반 통 기준에 비해 명백히 크다. 승인된 대형통 예외가 확인되면 정답을 재심해야 한다. |

| 정상 반복 ROI (5,665,330,300) | 반복 음성 | 성 밖 작은 녹지 일부. 소수의 서로 다른 나무·풀·꽃이 보이며 인접 같은 소품 과밀 군집이 없다. |

비율 기준: docs/design/art-bible.md:30 통0.45–0.65H, :33 성인17.6 world px. 저장 장면 줌1에서 사람과의 직접 시각 대조도 수행했다. 역사적 불가능을 판정한 것이 아니라 프로젝트 미술 규약 판정이다. 넓은 곡물통, 가려진 소품, 합당한 규모 판단이 어려운 수레는 정답에 넣지 않았다.

`truth-objects-frozen.json`은 benchmark.Annotation 배열이며 검출 출력과 대조하기 전에 SHA256을 기록했다. 정밀도는 명시한 regions 안에서만 평가한다. 그 밖의 건물·소품은 음성으로 간주하지 않는다. HUMAN_OBJECTS-contact.jpg의 빨강은 양성 정답, 초록은 음성 ROI다.
