# 시각 검수 기록

실행 위치: Mac, 오프라인 실제960×540 JPG와320px 모아보기. 게임 설치·렌더·실제 카드 UI 검증은 하지 않았다.

제작자들은 각 생성 원본을 확인했고, 책임자는35장 모아보기로 화풍·장소·행동을 대조했다. 독립 검수자 events_final_visual_qa는 제작 문서와35장 모아보기, 의심 항목24장 원본(002,004,005,010,015,018,019,024,025,027,028,030,034,035,037,042,049,050,051,052,053,057,058,059)을 확인했다. 이 검수자는 눈가림 정답표를 보지 않았다.

독립 판정: 명백한 해부학 오류·금지 문자·원문 모순·식별 가능한 일반 주택 굴뚝·3회 초과 장소·강한 화풍 이탈을 발견하지 못함. 002 좌상단 약(12,10)의 희미한 고리 표식을 워터마크 가능성으로 보류(중간 신뢰도). 책임자는 이를 제거 대상으로 채택했다. 생성 수정 이력은 개별 records에 보존한다.

이는 전 픽셀 무결점 보증이나 역사 사료로서의 인증이 아니다. 역사 제한은 제공된 아트 바이블과 사건 등장 기간에 따른 제작 규약 검수다.

최종 수정 확인: 책임자가 실제960×540의002를 열어 고리 표식 제거를 확인했다.031의 장부 형태와059의 후보 손짓도 실제크기에서 다시 확인했다.057은 원경의 여분 얼굴을 제거한 최신본이다.
