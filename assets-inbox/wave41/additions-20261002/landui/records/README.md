# Wave41 추가분 — LAND-UI 후보6장

바이블v2 기준 숲 가장자리 전이 띠 A/B2장과 폭1 여울 NE/NW×여름/겨울4장이다. 사용자 승인된 기존29장은 보존했다.

- `forest/assets/`: woodland_edge_a/b, 512×64 RGBA, pivot(0,0), X반복. 위 초지/아래 숲 바닥. A는 넓고 완만한 전이, B는 완만한 만입 변주.
- `ford/assets/`: ford_w1_{ne,nw}_{summer,winter}, 512×256 RGBA, pivot(256,128), 렌더배율0.5. 중앙 한 칸 물구간을 기준으로 세 돌과 짧은 흙 경사로를 배치했다. NE/NW는 물흐름이 아닌 횡단 방향이다.
- `forest/proofs/`, `ford/proofs/`: 실제 참조 지면 합성, 반복·밝고 어두운 배경·기하·세 줌의 **오프라인** 검수판.
- 각 그룹 `records/`: 전체 생성 프롬프트, 원시 생성물 위치·SHA, 참조와 후처리 내역. `references/`: 프로젝트 참조 사본. 내부 상대경로는 각 그룹 폴더 기준이다.
- `assets.csv`, `SHA256SUMS`, `records/package-QA.json`: 최종6장 규격·해시·검사 결과.

내장 image_gen으로 개별 생성했다. 숲A의 초기 흐린 전이는 재생성하여 주변 지면 질감과 맞췄다. 반복 끝 RGBA를 맞추고 위아래 alpha를 부드럽게 연결했다. 여울은 기존폭2를 축소하지 않고 새폭1 그림을 생성한 다음 좌표 정합했다. 겨울은 대응 여름의 alpha를 그대로 사용한다. 새 자산이므로 기존폭2 실루엣과의 동일성을 주장하지 않는다.

경량 ZIP에는 고해상도 raw를 제외했다. raw 원본은 작업폴더 `output/astra-wave41-landui-20261002/{forest,ford}/raw/`와 기록된 생성 경로에 보존했다. ZIP 내 프롬프트/참조/최종PNG/검수판은 자체 포함이다.

## 통합 시 확인할 점

현재 렌더러는 w1을 자동 선택하지 않고 woodland 경계 매핑도 없다. 코드 연결은 별도 작업이다. 본 작업은 설치하지 않았으며 게임의 강둑·도로 가림, 청크 경계 및 실제세줌 동작을 검증한 결과가 아니다. 기존폭2와 돌 크기는 완전히 동일하지 않으며 NE돌은 다소 작다. 최저줌에서는 자갈 세부보다 세 돌·횡단 방향으로 판독한다.

숲띠는 지정이 없던 수량을 기존계약에 맞춰 A/B2장으로 정했다. 동일종만 길게 반복하면 패턴을 알아볼 수 있으므로 A/B 혼합을 권장한다. 겨울 전용 숲띠는 이 요청에서 제작하지 않았다.
