# Wave 6 시각 검수

검수 범위: 에셋 제작과 분리하여 목재·석재 더미, 지붕틀·우물, 소품, 효과 및 확인 그림을 검토한다. 검수자는 `work_pose_overlay_m`의 제작자이므로 해당 1장의 판정은 독립 검수가 아닌 자기 검수이다. 모든 결과는 `candidate`, 오프라인 PNG/Canvas 합성 검증이다.

## 확인한 사항

| 항목 | 판정 | 근거·제한 |
|---|---|---|
| 목재 3단계 | 통과 | 2개 납작한 목재 → 낮은 2단 적층 → 높은 적층. 동일 0.5/0.3 배율에서도 높이와 부피 증가가 구별됨. |
| 석재 3단계 | 통과 | 낮은 작은 군집 → 작은 피라미드 → 넓은 피라미드. 0.3 배율에서도 외곽 차이가 남음. |
| 자재 종류 | 통과 | 따뜻한 갈색 긴 목재와 회백색 덩어리 돌이 구별됨. 저배율은 결·줄눈보다 색과 형태로 판독함. |
| 간판 | 통과 | 투명 배경의 말뚝+빈 판자. 진행 bar는 그리지 않음. |
| 초가 지붕틀 | 통과 | 기존 512×256 캔버스, 열린 서까래와 낮은 초가 단이 구별됨. 완성 지붕이 아님. |
| 우물 3단계 | 통과 | 72×80×3 시트. 구덩이·석재 고리·열린 지붕틀 구별. 기준 well.png 최하단 유효 알파 y64를 직접 확인했고, 후보도 같은 접지선에 표시됨. 명목 피벗 (36,64), 게임 실행 검증은 하지 않음. |
| 작업 소품 4종×4방향 | 조건부 통과 | 확인 그림 2에서 정지 프레임 0 손/어깨 장착이 연결됨. 손 4×5 재합성 및 지게 앞뒤 레이어 규칙이 필요함. 삽 SE는 몸에 부분 가림. 망치질·삽질 동작이나 프레임 1 연결을 입증하지 않음. |
| 저배율 소품 | 조건부 통과 | 50%에서 종류가 읽히며 30%에서는 망치·밀 다발 형태가 더 잘 남음. 삽·지게는 작은 실루엣으로 읽힘. 이 배율 표는 실제 워커 런타임 배율이라고 주장하지 않음. |
| 상체 오버레이 시험 | 순수 덧그리기 미달 | 자기 검수: 원래 내린 팔이 남아 팔 4개로 보임. 원본 상체 영역 clearRect(18,21,35,23) 후 덧그리면 두 팔이 되며 머리·다리는 유지됨. 마스크 처리 없는 설치를 합격으로 간주하지 않음. |

확인 그림 1은 공사 4단계+재료+간판, 줌 1/0.6, 우물 공통 접지선, 초가 지붕틀을 보여준다. 확인 그림 2는 네 방향 소품과 상체 시험의 실패/마스크 대안을 나란히 제시한다.

## 범위의 한계

게임 설치·애니메이션·가림 큐·런타임 성능 검증은 하지 않았다. PNG 외형·좌표 계약·오프라인 합성만 검증했다. 새 상체 마스크는 시제품의 제안이며 게임 코드에 적용되지 않았다.

## 최종 효과·투명도 검수

- 최종 확인 그림 3을 직접 확인했다. 연기 2종, 흙먼지, 작은/큰 불, 빈 필지 말뚝, 망치 먼지, 완공 효과 3프레임이 모두 표시된다.
- 효과의 바깥은 실제 alpha=0이며 바탕 사각형이나 체크 무늬가 이미지에 들어 있지 않다. 22개 에셋 전부 PNG 픽셀을 독립적으로 읽어 투명 픽셀의 존재를 확인했다. 상세는 `independent-alpha-scan.json`.
- 연기는 곡선 실루엣, 먼지는 낮은 밝은 덩어리, 불은 주황/노랑의 세로 실루엣으로 읽힌다. 큰 불은 단순히 작은 불을 확대한 것이 아니라 여러 갈래의 폭 넓은 형태다. 말뚝의 리본은 원본 크기에서 읽히며 줌0.6에서는 말뚝 기표 중심으로 읽힌다.
- 연기 A/B는 같은 색과 굽음 계열이며 아래쪽 덩어리 폭·위상이 조금 다르다. 차이는 크지 않아 다수 굴뚝의 반복 은폐까지 통과했다고 주장하지 않는다.
- 먼지·완공 효과는 자연스러운 부분 투명도를 유지한다. 완공 3프레임의 퍼짐→부피 증가→소멸 실루엣은 구분되지만 재생 시간·루프·시뮬레이션 사건 연결은 검증하지 않았다.
- 효과가 놓인 확인 그림은 배치 연구용으로, 연기 배출구나 망치 타격점이 실제 게임에서 자동 정합된 결과가 아니다.

## 종합 판정

**후보 제출 가능, 시험 한계 포함.** 22개 에셋 중 상체 오버레이 1장은 순수 source-over 방식이 실패했고 마스크 선처리 대안을 함께 보여준다. 나머지 21개의 독립 시각 검수에서 즉시 재제작을 요구할 결함은 발견하지 않았다. 조건부 항목은 정지 소품 장착·저배율 세부·효과 변형의 차이·실제 게임 미검증이다. 에셋22장+확인그림3장의 파일 수는 확인했으며 CSV·압축 무결성은 주 담당 검증에 맡긴다.
