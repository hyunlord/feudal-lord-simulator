# Wave37 후보 사용 안내

게임에는 설치하지 않은 집 앞 직업·형편 표지32종이다. 직업12종은 a/b 두 가지 구조로 그렸으며 좌우 반전으로 만들지 않았다. 형편 목록의 일곱 유형을 여덟 장으로 맞추기 위해 새 입주 수레를 두 구조로 만들었다.

- `assets.csv`: 직업·형편, 캔버스, 발 기준점, 판독 불확도, 기록 링크, SHA256.
- `records/trades-*.json`, `records/conditions.json`: 실제 생성 프롬프트·참조·원본·후처리 기록. 도구가 제공하지 않은 모델 버전·생성seed는 기록하지 않는다.
- `proofs/`: ①첨부 도시 오프라인 합성 ②같은 집12채 앞의 이름 없는 직업 표지 ③줌0.6. ②의 슬롯 번호는 답안 연결용이며 직업 이름이 아니다.
- `qa/`: 규격 및 독립 판독 검수. 판독 시험 답안이 고정되기 전 검수자에게 정답표를 보여 주지 않는다.
- `raw/`: 생성 원본은 로컬에 보존하지만 경량 ZIP에는 제외. RAW_INDEX.csv에 경로와 해시를 제공한다.

모든 소품의 지지부는 독립적이다. 몸체나 벽과 합성할 접합면이 없다. CSV의 발 기준점은 그림 속 지지부를 육안으로 읽은 배치 기준이며 실제 엔진 피벗의 승인값이 아니다. 확대·축소할 때 `(screenX - footX*scale, screenY - footY*scale)`로 그릴 수 있다. 다리가 여러 개면 기록된 대표 접점을 기준으로 삼고 나머지 접점도 같은 지면에 놓아야 한다.

세계 배율은 엔진 규격이 첨부에 없어 시험값을 공개했다. 같은 집137px와 소품 원본0.45배를 줌1로, 줌0.6에서는 장면 전체를0.6배로 줄였다. 도시 캡처는 첨부 설명상 줌1.4이지만 파일이 축소된 상태다. 화면의 같은 급 집 폭 약60px와 참조 집 폭114px를 대조해 소품은0.45×60/114≈0.24배로 얹었다. 명목 줌1.4를 다시 곱하지 않았다. 작아도 알아보이게 하려고 직업마다 임의 배율을 바꾸지 않았다. 실제 설치 때는 집 크기와 사람 키를 함께 대조해야 한다.

이미지의 왼쪽 위 광원을 유지하려면 소품을 좌우 뒤집지 않는다. 선택한 형편 표지는 서로 포개지 않는다. 실제 길·주민 통행 공간, 선택 경계, 깊이 정렬은 이번 후보 그림 검수 범위 밖이다.
