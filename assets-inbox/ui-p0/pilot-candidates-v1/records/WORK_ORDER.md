## 0. 방향 — C안 "80% 기능, 20% 시대 장식"
- 패널 중앙은 깨끗한 단색/반투명. **모서리·구분선·배너에만** 필사본·양피지 질감. 나뭇결·얼룩을 본문 뒤에 두지 않는다.
- 세계 그림(손그림 저채도 중세)과 같은 팔레트: 따뜻한 off-white(양피지), oak brown, 잉크 짙은 갈색, 붉은 인장(강조 1색), 초록·파랑은 상태색으로만.
- 아이콘은 **실루엣 우선**, 손그림 붓질, 24px에서 읽히게(원본 96px). 텍스트·숫자·진행 bar 내부·선택 사각형·하이라이트는 **만들지 않는다**(코드가 그림).

## 2. 확인 그림 (3장)
1. **HUD 합성**: 첨부 현재 화면 위에 1~7번으로 상단 자원바·하단 건설 bar·우측 목표 카드 2장·좌측 inspector·조언자 말풍선을 오프라인으로 얹은 모습(1280×800). 텍스트는 임시로 검정 글자로 채워도 됨. 딥리서치 HUD 재배치안 배치(시간·속도·설정 상단 우측, 구역은 층위 전환)를 따른다.
2. **아이콘 3크기**: 8~11번 아이콘을 96/32/24px로 나열 — 24px에서 실루엣이 구분되는지
3. **9-slice 검사**: 1~5번을 작은 크기(200×80)와 큰 크기(600×400)로 늘린 것 — 모서리 왜곡 없음

## 3. 제출물·검수
PNG 12 + 확인 3 + CSV 12행 + 검수표. 기준: 세계 그림 옆에서 같은 게임으로 보임(첨부 03·04), 24px 아이콘 실루엣 구분, 9-slice 늘려도 장식이 모서리에만 남음, 텍스트·숫자·bar 내부 없음, 채도 규칙(강조는 인장 빨강 1색).
