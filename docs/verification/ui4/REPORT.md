## 과정에서 바로잡은 것
- **렌더 원천 검사:** 비 시트를 프레임별로 잘라 캔버스에 옮기던 `drawImage`가 "스프라이트 blit 경계" 검사에 걸렸다. 시트 전체를 반복 패턴으로 쓰고 옮겨서 내리게 바꿨다. `renderer.ts` 순수 줄 수는 한도(250)를 넘지 않게 호출을 한 줄로 두고, 가져오기는 `worldSigns` 재수출로 옮겼다.
- **연대기 캡처:** 늘린 지연에서는 연대기의 시작 시각이 환영 화면이 닫힌 뒤에 잡혀 칩보다 늦게 떴다. 캡처가 순간마다 기대하는 UI(칩·모달·연대기)를 기다리게 했다.
- **성능 측정의 청원 카드:** pop176 세이브의 열린 청원이 측정 중에 모달로 떠 시간을 멈췄다(첫 쌍 38 %). 벤치마크가 세계 먼저 지연을 측정 창보다 길게 잡게 했다.
- **워크트리 node_modules 링크:** 링크된 node_modules를 Vite가 루트 밖으로 막아(403) 글꼴이 안 실렸다. 워크트리에 `npm ci`로 바꿨다.
