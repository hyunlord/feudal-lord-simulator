# Wave34 확인 그림 자체 검수

## 확인1 — 여울·다리

- 통과: 여울 3개는 같은 강의 폭 2·3·4칸 위치에 서로 다른 실제 길이로 놓였다. 줌 1.0과 0.6 모두 디딤돌 줄·둑 경사로가 강을 잇는 것으로 보인다.
- 통과: 여울의 물 영역 아래 기존 물결이 비치며 Wave29 흐름 프레임을 위에 합성할 수 있다. 밑그림 위 별도 물 흐름을 합성한 정지 프레임 검사이며 애니메이션 실행 검사는 아니다.
- 통과: 기존 나무 다리는 atlas의 deck와 두 난간을 분리하여 재결합했다. 추출은 연결 alpha 성분을 사용해 인접 행 조각이 섞이지 않도록 했다. 접지 끝은 양쪽 강둑을 약 0.2칸 겹친다.
- 출처 구분: 첨부는 실제 플레이 화면이 아닌 5×3 미니맵 모음이다. 2행 4열을 inset으로 보이고 본 장면에는 offline isometric reconstruction 표시를 넣었다. 강폭과 앵커를 검토하기 위한 재구성이며 게임 설치나 지형 엔진 실행을 뜻하지 않는다.
- 한계: 확인1은 대표 여름 NE 3종의 장면이다. 나머지 NW·겨울 에셋은 별도 개별 에셋 검수표 대상이다.

## 확인2 — 배수 단계

- 통과: 동일한 5×5 영역에서 둘레 말뚝·줄 → 2줄 도랑과 줄어든 웅덩이 → 젖은 진흙·풀 → 풀밭·외곽 도랑의 단계가 1.0과 0.6에서 구별된다.
- 통과: 여름과 겨울 2행 모두 같은 위치와 단계 구성을 유지했다. 바탕은 승인 Wave22 fen 원본, 완료 상태는 기존 grass 원본을 사용했다.
- 통과: 단계1은 둘레 16칸에만 오버레이, 단계2는 5칸 도랑 2줄, 단계3은 낮은 대비의 연속 젖은 흙 오버레이 25칸이다. 단계1 다른 축의 변만 좌우 반전하여 경계 방향을 맞췄다.
- 통과: 흙수레·흙더미·수문·널다리를 올바른 크기로 배치했다. 완료 널다리는 도랑을 실제 가로지르도록 접지 위치를 보정했다.
- 통과: 단계3의 이전 녹색 사각 구멍과 등간격 큰 패치 반복이 제거되었다. 원본 크기로 25셀 합성한 뒤 전체를 한 번 축소하였으며 1.0·0.6 모두 연속 젖은 흙 바탕으로 읽힌다. 이전 18셀 시도는 미채택 기록으로 분리하였다.
- 물 감소는 기존 pool 데칼 5개 → 3개(축소) → 0개로 합성했다. 이는 엔진의 배수 상태 변화가 제공해야 하는 입력이다. 신규 오버레이가 기존 물 픽셀을 자체 삭제한다고 주장하지 않는다.

## 납품 경계

- 출력: 확인 PNG 2장만 `checks/`에 저장했다.
- 소스 입력·해시·배치값: `proofs-provenance-all.json`, `proofs-contract.md`.
- 프로젝트 원본 및 게임 코드는 변경하지 않았다. 후보 PNG의 오프라인 합성 결과만 검수했다.
