# R08 현재 인계 상태

이 문서는 바이트를 보존한 과거 초안·검수 문서의 당시 상태와 현재 상태를 구분한다.

- D 사건200개·Astra24답변은 작성 범위를 충족한다. 현재 등록기와 같은 ID가 일부 있다는 이유로 원고 전체가 설치됐다고 읽지 않는다. 사건단위 보류61개/전선택 미지원60개, sidecar enabled0을 유지한다.
- E history182종·원장46분류의 원고882개는 정본650+문맥212+당시나이20이다. 현재 타입 누락/ID중복0. 과거 README의 ‘품질 감사 진행 중’은 당시 기록이며 현재 범위 감사는 records/de-coverage-current/REVIEW.md를 따른다. 모든 상태 조합 검증이나 formatter·capture·UI 설치를 의미하지 않는다.
- 사실행·조합 HOLD30 및 역사 근거 제한은 그대로다. 검증된 params.age 또는 별도 채택한 당시 나이 계약을 사용하고 현재 인물 나이를 과거 사건에 대입하지 않는다. 이름은 FIX-12 읽기 시점 해석을 유지한다.
- 필요한 근거605파일의 source/destination SHA를 확인했다. 원본 records/registry-invalid-review/RESULT.json의 옛 review주소는 파일 기준으로 records를 중복한다. 올바른 패키지 경로는 records/registry-invalid-review/REVIEW.md다. 원본 수정 대신 이 경로표를 제공한다.
- 과거 CHANGES의 모든 역사 링크나 실행 스크립트의 옛 절대경로까지 독립 재실행 환경으로 묶은 것은 아니다. 현재 원고·schema·capture·selector·fixture·독립검수 패키지의 필수 상대링크를 보존했다.
