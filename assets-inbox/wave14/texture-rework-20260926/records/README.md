# Wave14 질감 재작업 후보

교체 대상은 기존 방패 표면 질감 1종이며, multiply·screen 두 장으로 나눴습니다. 상인 표식용 잉크·각인 질감 두 장을 추가해 **최종 PNG 4장 + 확인 그림 2장 + CSV 4행**을 납품합니다. 이 ZIP은 수정·추가분 묶음입니다. 기존 Wave14 원본을 덮어쓰거나 게임에 설치하지 않았습니다.

## 방패

- `shield_surface_texture_multiply.png`, 256×256: 과슈 붓질·가죽/나무 결·아래쪽 그늘·닳은 가장자리.
- `shield_surface_texture_screen.png`, 256×256: 위·좌상단의 밝은 붓질과 긁힌 결.
- 두 PNG는 흑백 **불투명 블렌드 데이터**입니다. 흰색이 multiply의 중립, 검정이 screen의 중립입니다. 일반 source-over로 덮는 투명 장식물이 아닙니다.
- 기존 색을 합성한 뒤 multiply 강도 0.80, screen 강도 0.48 순으로 적용합니다. 세 방패의 내부 좌표에 맞춰 질감을 배치하고 채움 영역으로 자릅니다. 원본 외곽선과 실루엣 알파는 보존합니다.
- 구형 `shield_surface_texture.png`를 동시에 얹지 않습니다. 상세 수식·색공간·재현 방법은 [합성 계약](records/SHIELD_TEXTURE_COMPOSITION.md)을 따릅니다.

## 상인 표식

- `merchant_ink_stamp_texture.png`, 128×128: 잉크가 남거나 끊기는 커버리지 데이터입니다. 표식 마스크와 곱해 쓰며 천·양피지에 적용합니다.
- `merchant_carved_texture.png`, 128×128: 나무의 각인 홈과 그늘에 사용할 표면 데이터입니다. 표식 형태는 기존 마스크가 정합니다.
- 실제 채널 해석·번짐·음영 처리와 강도는 `records/metadata-merchants.json` 및 재현 스크립트에 기록했습니다. 두 질감을 일반 불투명 그림처럼 그대로 올리지 않습니다.

1. 기존 seed140926의 문장 24개를 동일한 색·도형으로 재합성했습니다. 256px·96px를 함께 볼 수 있습니다. `records/shield-before-after.png`에는 처음 6개 전후 비교도 있습니다.
2. 같은 상인 표식 16개를 자루·나무 문·양피지에 각각 적용했습니다. 소재별 효과와 축소 판독을 비교합니다.

`assets.csv`에는 실제 생성 프롬프트·원본·후처리·합성 계약을 기록했습니다. `raw/`에 생성 원본과 반려 원본을 보존하고, `references/`에는 합성 재현에 필요한 기존 그림·마스크를 복사했습니다. 복사본은 신규 납품 자산 수에 포함하지 않습니다.
