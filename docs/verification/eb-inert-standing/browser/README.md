# 상시 묵인 화면 검증

판정: 변경 범위 PASS. 실제 Chrome 실행의 세 폭 기능 검사와 두 독립 시각 검토를 합쳤다. `result.json`은 원본 그대로이며 그 안의 pending visualReview 값은 실행 당시 상태다. 이후 검토는 `review.json`에 분리했다.

375/768/1280 × 보고·철 손실·장부·방침 활성·철회 후 15장. 준비 저장은 실제 reducer/계절/감사 처리로 만들고 정상 시간 버튼 및 철회 버튼으로 검증했다. 자연 발생 조건·125년 경제 관문·실제 터치 기기 검증을 대신하지 않는다. 기존 375px 지도 HUD 잘림은 남아 있다.

`reference/`는 수리 전 결함 이미지이고 승인된 목표가 아니다. 진단 픽셀 차이는 의도적 재배치와 지도 배경 차이를 포함하므로 합격률로 해석하지 않는다.
