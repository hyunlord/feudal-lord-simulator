# 지역 지도20장 검수

## 구도 차이

전체 그림 생성20회로 제작했다. 같은 그림의 좌우 반전·회전·크롭을 네 가지 지도라고 세지 않았다. 숲과 능선을 따로 흩뿌리지 않고 수계와 골짜기, 길과 들판이 이어진 한 장의 지형으로 생성했다.

| 땅 |01 |02 |03 |04 |
|---|---|---|---|---|
| 강가 |중앙 S자 사행천, 북쪽 지류 |서쪽 대곡류와 동쪽 테라스 |두 하천의 Y형 합류, 중앙 하간지 |남쪽 횡단 강, 북쪽 농경 대지 |
| 해안 |서쪽 하구·삼각주 |북쪽 초승달 만 |북서 사주 뒤 염습지 |서쪽 백악 절벽·내륙 계곡 |
| 백악 |대각 연속 능선 |동서 건곡과 양쪽 구릉 |말굽 분지와 출구 개울 |평행 구릉·남쪽 하천 |
| 숲 |북서 숲과 남동 개간 전선 |동서 개방 계곡 양쪽 숲 |중앙 숲 능선을 감싸는 개방지 |가지형 숲 능선·여러 분지 |
| 습지 |동쪽 분기 하천·서남 마른 땅 |대각 습지 회랑·높은 길 |북쪽 큰 수면·남쪽 유출천 |북쪽 큰 하중도·남쪽 대지 |

제작 담당자가 각 최종 지도와 슬롯 사각형 합성판을 직접 확인했다. 루트는5개 유형별 비교판과20장 전체판, 강가4장,18영지 합성판, 대표 슬롯 검수판을 확인했다. 제작에 참여하지 않은 새 컨텍스트의 독립 검수도5개 가족 모두 구도 차이를 확인했다. 상세는 `provenance/INDEPENDENT-REVIEW.md` 및 가족별 `*-review.md`.

공통 색·시점·해칭·수관 결은 원본과 가까우며, 원본보다 필지와 잔수목이 조밀한 경향이 있다. 해안의 만/사주/절벽은 서로 구분된다. 백악01·04는 구릉 모티프가 비슷하지만 하천과 능선 관계가 다르다. 습지는 인공적으로 배수된 땅보다 자연 습지·분류 하천으로 읽힌다. 토지별 게임규칙 비율을 실측 구현한 그림은 아니다.

## 빈 자리 검수와 수정

처음24개씩 제안한 후보를 사각형으로 얹어 검수했다. 접지점 하나만 비었어도 그림의 윗부분이 수관·길에 걸리는 후보가 있었고,35×25처럼 작은 후보도 나타났다. 지도를 변형하지 않고 후보를 이동하거나 제거하여 지도당20~23개로 확정했다. 모든 슬롯은60×45이상이며, 넓은 후보에는100×60~70을 기록했다. 일부 작은 후보는 빈 경작지 무늬 위이고 수풀 붓터치에 근접한다. 미세 식생까지 완전히 비워진 마스크라고 주장하지 않는다.

최종 자동 검사에서 습지01의s08/s09 사각형이 겹친 것을 발견해s09를 제거했다. 해당 지도는21곳이고 전체415곳이다. 모든 슬롯 사각형은 캔버스 안, 서로 비중첩, 중심 간90px 이상이다. 용도 호환을 확인해 강가01에18영지를 모두 다른 슬롯에 배치했다.

## 거점 없는 바탕과 표지 재사용

검수 범위에서 maps20장에 건물·취락·깃발·문자 미발견. 도하 맥락을 보여 주는 소형 교량·여울은 남겼다. 바탕 지도와 표지를 합친18영지 예시는별도proof이며 바탕 파일을 덮어쓰지 않았다.

기존 키트의 직할·위임·이웃·적대 깃발, 경계 붓질, 빈 지명 띠6개는 바이트 그대로 복사했다. 모두SHA256이 일치하며 기존 피벗/알파 정보도 남겼다. 표지 견본에서6종을 겹쳐 확인했고,18영지 예시는 직할/이웃 깃발과 이름띠를 사용한다. 실제 영토 경계나 적대관계를 만들어내지 않았다.

## 확인한 것 / 확인하지 않은 것

- 확인:20JPEG1600×1000,20JSON,5×4구성, 같은 땅의4구도 차이,415슬롯 치수·범위·유일성·간격·비중첩,18가문/영지ID와 종류 보존, 표지6개 원본 해시, ZIP 무결성.
- 원본 크기:생성PNG는20장 모두1586×992였다. 최종1600×1000으로 약0.9% 한 번 확대 정규화했다. 작은 원본을 새 고해상도 원본으로 바꿔 등록하지 않았으며 실제 원본 크기와 해시는 별도 기록했다.
- 그림상 개연성:연속 수로·계곡·숲·길 관계와 원본 화풍을 육안 검수했다.30쌍의 축소 픽셀 차이도 보조 증거로 기록했으나 그 수치 자체로 구도 품질을 판정하지 않았다.
- 미검증:물리 수문/고도장, 정확한 통행 그래프, 게임 런타임 접지·클릭 영역·성능, 큰 거점과 긴 한글 지명 표시. 슬롯의landmarkRefs는 이동 가능성 증명이 아니다.
- 이번에 눈가림 시험은 수행하지 않았다. 이전 조립기의100% 맞힘률을 새 지도 품질 수치로 옮기거나 개선 맞힘률을 추정하지 않는다.

최종 상태는 검토용candidate. 원본 저장소와 기존 키트 파일은 보존했다.
