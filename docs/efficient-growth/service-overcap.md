# 기존 초과 시설을 정상 예산으로 판정하던 예외 수정

같은 코드 검토자가 `07db609`의 공동 서비스 계획에서 발견한 예외를 수정한다. 이미 모든 집을 공급하는 구형 상태에서는 시설 수가 상한을 넘어도 탐색 성공 분기가 먼저 실행돼 새 주택의 예산 검사까지 통과할 수 있었다.

시장·교회의 완공 및 계획 시설을 뺀 남은 슬롯이 음수이면 성공 분기에 들어가기 전에 거부한다. 기존 불가능한 상태에서 관련 없는 도로 복구를 허용하는 바깥쪽 규칙은 유지한다. 시설 삭제·이전, 경제 수치·상한·기본 필지 수 변경은 없다.

완전 공급 상태에 시장 또는 교회가 각각 상한을 초과한 회귀를 추가했다. 수정 전 시장 사례에서 기대 `false`에 실제 `true`로 실패했으며, 수정 후 두 종류 모두 새 주택을 거부하고 기존 도로 복구는 허용한다. 기존 집중 검사 포함 **33개 통과**, typecheck·diff 검사 통과. 로그: `/tmp/efficient-service-overcap-red.log`, `/tmp/efficient-service-overcap-green.log`.

보존된 120만 틱 최종 상태를 변경 없이 한 번씩 읽은 공동 계획 검사 시간은 seed 1(17가구) 29.77ms, seed 4(16가구) 13.05ms, seed 5(16가구) 14.72ms였다. 모두 시장 슬롯 소진으로 불가능 판정이며, 남은 슬롯의 조합을 오래 탐색하는 어려운 배치에 대한 상한 증거는 아니다. 원시 상태나 스냅샷은 추가하지 않았다.

최종 5개 seed 성장·효율, 8가구 장기 안정성, 전체 회귀 검증은 동일 검토·실행 담당자의 통합 검증으로 남는다. 이번 수정과 짧은 실행을 최종 통과로 보고하지 않는다.
