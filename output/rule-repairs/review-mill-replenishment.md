# R8 밀 공급 후 none 재관측 검토

판정: 지정한 변경에서 병합을 막는 확정 결함 없음. 정적 검토만 했으며 테스트를 재실행하지 않았다.

- 같은 방앗간 집합, 증가한 틱, 이전 밀 0 및 현재 모든 방앗간 밀 양수, 이전/현재 실제 식량 진단의 wheat_transport_blocked를 모두 요구한다. 새 시설·일꾼 부족·관측창 없음으로 생긴 상태를 이 재시도 사유로 받아들이지 않는다.
- UI의 none 결정만 무효화하고 pending/이미 선택된 행동은 교체하지 않는다. headless 역시 none 뒤 같은 helper로 재관측한다. 실제 dispatch는 기존 120틱 lastActionTick 조건을 유지한다. 새로운 저장 필드나 영속 캐시는 없다.
- measuredFoodDecision은 기존 읽기용 판정이며 resolveBuildingRoute는 새 pathCache를 반환하고 입력을 변경하지 않는다. 추가 판정은 값싼 밀 재고/ID 전이 검사 뒤에만 실행된다. 새 진단 receipt는 재관측 시 기존 경로로 발행된다.
- 자연 fixture 테스트는 324000→324001 공급 전이의 UI 캐시/헤드리스 판단, 119틱 동안 추가 행동 없음, false positive/pending 보호를 직접 다룬다.

증빙 한계: 두 소비자가 같은 전후 상태를 관측할 때 재시도 조건이 같다는 것은 확인했다. fixedTickLoop는 한 프레임에 최대 5틱을 묶어 commit하므로, 브라우저가 중간의 짧은 전이를 관측하지 못하는 경우까지 헤드리스와 동일한 행동 시점을 보장하는 테스트는 없다. 기존의 UI 표시/dispatch 지연도 남는다. 이 변경을 프레임 스케줄과 무관한 전체 실행 동등성으로 설명하지 말 것. 성능 측정은 이 검토에서 하지 않았다.
