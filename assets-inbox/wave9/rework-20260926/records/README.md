# Wave 9 재작업 · 교체/추가 후보 팩

요청한 **PNG8개 + 확인 그림1개 + CSV**입니다. 기존 통과분은 포함하지 않는 변경분 전용 팩입니다. 게임이나 이전 납품 파일은 수정하지 않았습니다.

## 변경 사항

| 구분 | 파일 | 반영 |
|---|---|---|
| 교체3 | event/plague_shut_l1~l3-v1 | 문 표식 제거. 두껍고 어두운 판재와3px 목재 보강대. 원본 창 좌표에 고정 |
| 교체2 | prop/bier_shroud_ne/nw-v1 | 관 대신 열린 나무 운구대와 흰 수의 한 구. 각64×32 |

기존 동일ID를 대체하는 파일은 파일명을 유지했습니다. CSV의 `revision=wave9-rework-r1`와 SHA256으로 이전 버전과 구분합니다.

## 폐기할 기존 ID

- `event/plague_door_mark-v1`: 폐기. 대체 그림 없음.
- `prop/coffin_ne-v1`: 폐기, `prop/bier_shroud_ne-v1`로 교체.
- `prop/coffin_nw-v1`: 폐기, `prop/bier_shroud_nw-v1`로 교체.

기계 판독용 삭제/교체 목록은 `records/retired_assets.json`입니다. 이 팩에는 폐기된PNG가 없습니다. 이전 납품 ZIP은 원본 보존을 위해 그대로 두었으며, 나머지 에셋을 다시 제작하거나 수정하지 않았습니다.

## 캔버스·피벗

덧창L1은139×139, L2는137×137, L3는142×142로 원본과 같습니다. 각 오버레이를 원본의 좌상단 `(0,0)`에 합성하며 **기존 원본과 같은 피벗**을 그대로 사용합니다. 첨부 원본에 숫자 피벗 메타데이터는 없으므로 임의의 피벗 값을 만들지 않았습니다. 원본 창 다각형은 생성 기록에 포함했습니다.

문 영역의 오버레이 알파는 세 파일 모두0입니다. 창의 가로·대각 보강대는 목재 구조물이며 문에 칠한 표식이 아닙니다. 새 무덤의 작은 나무 십자가는 요청한 묘지 소품입니다.

## 확인 그림

`checks/01_plague_street_rework.png`는 최종PNG로 재합성한 역병 거리입니다.

- 위: 닫힌 집·새 무덤·수의 들것을 어깨에 멘 기존 장례 워커,1.0배.
- 중간: 같은 장면0.6배.
- 비교 줄: L1~L3 정상집 / **OLD 이전 납품 오버레이** / REVISED 새 덧창을 각각0.6배로 표시.
- 아래: 들것·대각 줄·새 무덤의2배 최근접 확대.

OLD 칸은 수정 전후 비교 자료이며 새 후보 에셋이 아닙니다. 거리 장면의 집에는 문 표식이 없습니다. 워커는 통과한 기존PNG에서 프레임을 가져왔으며 원본 시트를 변경하지 않았습니다. 확인 그림은 정적 조립 자료이며 게임 실행 스크린샷이 아닙니다.

## 검사

- 후보8개 및 확인1개 수량과 정확한ID 검사.
- PNG규격·투명배경·alpha0 영역의RGB잔색0 검사.
- 주택3개 캔버스 일치, 문 영역alpha0 확인.
- 이전 납품 에셋40개 전체를 전후SHA256으로 비교하여 모두 동일함 확인. 요청한 통과분도 이 안에서 보존됨.
- 독립 시각 검토에서0.6의 폐쇄 가독성을 확인하고 보강대 대비를 재조정함.
- CSV에는 실제 생성 프롬프트와 로컬 정렬·규격화·목재 보강 후처리를 구분하여 기록.
- 게임 설치·엔진 피벗 실행·이동 애니메이션·성능은 시험하지 않음.

모든 결과는 `candidate`입니다. 내장 `image_gen`을 사용했으며 도구가 모델명을 노출하지 않아 임의로 특정하지 않았습니다.
