1. 단계마다 **관문**을 통과해야 다음으로. 관문 = 수치 + 캡처 + (A′·C부터) 사람 플레이.

4. 결정이 필요한 곳은 구현 전에 멈춘다.
5. 커밋은 작업 단위, 증빙 3MB 이하, 최종 변경 뒤 전체 회귀 1회.
