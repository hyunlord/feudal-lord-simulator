# RB-HEIGHT-DOORS — 성인 키에 맞춘 두 집의 출입구

제품 `acc20e8c`: 기본 L0와 Wave26 L1d 완성 몸체 2장, 전용 눈·판자·새집·풍화층 6장, 합계 8 PNG를 core 그림 계약으로 설치했다. 집 전체를 확대하거나 성인 17.6px를 줄이지 않고 벽과 문을 높였다. 원본 캔버스·발판 1×1·바닥 피벗·세계 배율은 유지했다. 기존 원본은 덮어쓰지 않았다.

이 게시 단위는 원래 23몸체 중 두 종류만 끝낸다. 나머지 21몸체와 연결층, 운구 접점은 여전히 별도 잔무다. 시대 집 8종이나 모든 문을 해결했다고 세지 않는다.

## 실제 화면에서 확인한 범위

같은 저장·정규화 상태·틱·카메라·줌·4000ms 시계의 전후 **21쌍, 42뷰**를 실제 게임 렌더러에서 비교했다. 줌은 1.0·0.6·3.0이다. `runtime-summary.json`은 각 JPG/원본 PNG SHA와 실제 새 그림 draw를 보존한다. 8장 모두 실제 소비됐다. 대표 9장의 확대 JPG만 저장소에 넣고 전체 42장과 하네스·저장·원본은 보고 ZIP에 보존한다.

- 정상 새 게임 seed2의 84틱 L0: 오른쪽 길의 성인 운반자와 문을 함께 확인했다. 문이 성인보다 높고 바닥 끝과 우물과의 거리는 유지됐다.
- 정상 13000틱 L1d: 새집 층. 21000틱 L1d: 풍화층. 23450틱 L1d: 풍화+눈. 같은 화면의 다른 집이 가진 층과 대상 집의 층을 구분해야 한다. fresh/weathered는 같은 집에 함께 그리지 않는다.
- 준비 저장의 L0 겨울·겨울 빈집, L1d 겨울 빈집: 눈·판자와 풍화층의 부착을 확인했다. L1d 문의 아랫부분은 앞집 지붕에 가려지므로 문 전체가 보였다고 하지 않는다.

겨울 L0는 자연 seed2 진행 중 모두 승급해 사라졌다. 원본 저장을 보존한 별도 QA 복사본에서 tick, 대상 집의 abandonedTick/residents/members만 준비했다. 정확한 수정 전후와 SHA는 `qa-prepared-state-fields.json`에 있다. 인구·인물 장부는 다시 계산하지 않았고 정지 렌더러 부착 시험에만 썼다. 정상 성장·빈집 발생 빈도·경제 상태의 증거가 아니다.

before는 원래 커밋으로 돌아간 캡처가 아니라 **같은 빌드에서 새 계약 몸체와 지붕점 소비만 끈 제어 기준**이다. 기존 원래 커밋의 동일 L1d 여름 저장과 세계 draw 기하가 같은 것을 `baseline-equivalence.json`으로 확인했다. 카메라가 달라 스크린샷 자체의 동일성을 주장하지 않는다.

페이지 오류 0, 그림 요청 실패 0. 종료 중 telemetry 요청 `ERR_ABORTED` 4건은 보존했다. 초기 두 하네스 치환 실패와 L0 선택 실패도 남겼다. L0는 로더가 붙인 `/assets/` URL을 논리 키로 사용한 것이 원인이었으며 원본 manifest 논리 URL로 고쳤다. `/game/` 배포 접두사 회귀도 포함했다.

## 크기와 접합

| 몸체 | 캔버스 | 세계 배율 | 문 높이 | 문 너비 | 바닥 3점 잔차(native px) |

| L1d | 139² | 0.49862173 | 47±2 → 23.44±1.00 | 17±2 → 8.48±1.00 | 1, 0, 0 |

문 개구부 기준이며 캔버스 높이 비율이 아니다. 성인 정본에 대한 문 높이 목표는 20.24–24.64px, 폭은 7.92–11.44px다. L1d 폭의 중앙값은 범위 안이지만 수동 측정 불확실성 하한은 범위 밖이다. 이를 완전 수치 통과로 과장하지 않는다. L1d 원본부터의 축 기울기 약 0.545/0.568은 남아 있으며 엄밀 2:1 투영 통과가 아니다.

완성 그림 전체의 X/Y 등록 계수와 이동량은 원본 기록에 있다. L1d 몸체·각 층 및 L0 눈은 비균일 등록을 사용했다. 원본 바닥 픽셀을 모두 같게 만든 것이 아니라 승인된 바닥 등록과 발판을 보존했다. full-canvas crop으로 높아진 지붕을 자르지 않는다. 연기·지붕 새의 접점은 실제 준비된 계약 몸체의 지붕점에서 읽고 눈·서리 영역도 각 몸체 눈층에서 재생성했다. 모든 새 자세나 날씨 단계를 실화면으로 검증한 것은 아니다.

L0 눈 덮임은 제작자 지붕 마스크 기준 72.26%, L1d는 본 보고 수동 지붕 다각형 기준 76.56%다. 서로 다른 마스크의 수치를 직접 비교하지 않는다. L0 눈의 몸체 밖 25px는 처마 돌출로 남겼다. 두 눈층의 가로 띠가 규칙적인 한계가 있다. 0.6줌에서 개구부 세부 판독은 어렵다. L1d 풍화층은 처음의 지나치게 깨끗한 몸체를 주변 집과 이어 주지만 화풍 완전 동일을 주장하지 않는다.

## 계약·회귀·출처

기존에 고른 정확한 본체 URL에서 `legacyBodyUrl`을 파생한다. 엔진/저장 fact를 추가하지 않는다. 1350년 이후 시대 계약 우선순위, 다른 Wave2/Wave26 종류, 본체 또는 필요한 층 준비 실패 시 기존 원자적 fallback을 유지한다. fresh/weathered는 기존 집 나이 정책을 재사용한다. 공용 로더에 L0 특수 분기를 넣지 않는다.
