## 2. 사슬 아이콘 분리 (CL10)
- 직물 일곱(양털·실·생베·축융한 베·염료·물들인 베·완성 직물)에 Wave 3 자원 사슬 시트 칸(4~10번째). 결산 카드는 사슬 칸이 있는 물건을 모두 에일로 읽었다 → 에일 줄은 보리·엿기름·에일 셋, 직물 줄은 일곱 중 도시가 가진 것만(일곱이 다 서면 카드 아래로 넘쳤다).
- 저장소·배치 칩은 이미 사슬 칸을 읽어 일곱에 아이콘이 붙었다(창고 카드 캡처).

## 3. 장부·결산의 직물 줄
- 장부 서랍 재고 탭 "도시의 직물"(`townCloth`): 양 144마리 · 목초지 72칸, 실 잣는 집 24채, 사슬 건물 수, 이 계절 직물 수입(직물 인장세 +24d · 축융 방앗간 사용료 +33d — 장부 분류 이름 그대로). 결산 카드에 직물 줄과 같은 수입 줄.

## 4. 집 뒤뜰 물레·텐터의 베
- 실 잣는 집(`spinningSlot`)은 문 앞에 실타래(Wave 3 `yarn_skeins_1`). 엔진은 400틱마다 한 번에 가져와 잣고 가져가므로 슬롯이 늘 비어 있어, 실을 잣는 동안 줄곧 둔다.
- Wave 27 직조 판(실타래 광주리·감개)은 INSTALL-27이 실잣기에 이미 이어 두었지만 뒤 칸 둘이 비어야 서서, 재생 도시의 실 잣는 집 24채 가운데 2채뿐이었다 → 문 앞 실타래로 모든 집에서 보인다(둘 다 캡처).
- 텐터의 베는 한 그림(`tenter_frames_dyed`, 파랑·분홍·흰 베)이다. 엔진이 베마다 염료(대청·꼭두서니·목서초)를 기록하지 않아 "색은 염료대로"는 지금 할 수 없다(엔진 넘김).
