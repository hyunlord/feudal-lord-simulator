# P5/P6 제작자 육안 검수

- 입력은 승인된 여성 주민 시트의 방향별 두 셀이다. 자유 생성은 사용하지 않았다. 초상은 색·머리쓰개 보조 입력이다.
- 방향별 1회씩 총 8번 편집했다. P6 SE/SW에서 앞치마 형태가 남아 국소 의상 편집 2회로 제거했다. P5 SW/NW의 앞치마 어깨끈이 빠져 국소 편집 2회로 보완했다. 12회 원본과 정확한 프롬프트를 보존했다.
- 최종 셀은 원본 템플릿의 불투명 bbox로 등록하고, 편집 RGB를 템플릿 alpha 안에 합성했다. 원래 신발을 포함하는 하단 13.5%와 바깥 손의 밝은 피부 픽셀을 보존한다. 불투명 편집 영역이 부족한 가장자리는 가장 가까운 편집 RGB로 채운다. 따라서 alpha 위치 일치는 합성의 결과이며 원시 모델 출력의 보행 보존 성공이라고 주장하지 않는다.
- 손 보존 마스크가 갈색 소매까지 복사한 첫 합성은 반려했다. 피부의 밝기·색 조건과 세로 범위를 좁힌 후 다시 합성했다. `P5-foot-detail.png`는 수정 전 내부 진단 이력이며 최종 그림이 아니다.
- 최종 P5: 대청 파랑, 흰 coif, 얼룩 앞치마와 어깨끈을 4방향에서 확인했다. P6: 회청 gown, 윔플·베일, 앞치마 없음, 정면 노년 얼굴을 확인했다. 뒷면은 얼굴 나이 판정 불가.
- 템플릿 전체 alpha를 보존하므로 coif 주변 일부 면적은 머리쓰개/색이 연장된 영역이다. 엄밀한 내부 머리 중심과 두 신발 중심의 수치 검수는 별도의 루트 겹치기 검수에서 판정해야 한다.
- 74px 최종 크기에서는 주색·앞치마·목 감싼 윔플 구별이 유지된다. 미세한 얼룩·주름·연령 표시는 약하다.

## 독립 검수 후 수정

- 하단 13.5% 일괄 보존이 붉은 갈색 옛 옷자락과 P6 NE의 밝은 앞치마 끝을 되살리는 원인이었다. 새 그림 생성 없이 합성 보호 영역을 축소했다.
- `P5-original-feet-grid.png` 확대 좌표판에서 앞 신발의 사각 영역만 방향·프레임별로 지정해 원본 픽셀을 보존한다. 머리/몸의 기존 등록과 편집 색은 변경하지 않았다.
- 뒤 신발은 편집 결과의 색이 남으며, 템플릿 alpha 윤곽을 따른다. 모든 신발의 모든 RGB가 원본과 같다는 주장은 하지 않는다.
- 수정 후 P5/P6 마스터 재열람: 갈색 띠가 사라지고 P6 NE의 밝은 앞치마 끝도 제거됨. 최종 합성은 기존 생성 의상 RGB를 사용하며 새 해부학적 그림을 코드로 만들지 않았다.
