## 교체·오버레이 계약
등급별 캔버스는 첨부 원본과 같은 L0 153², L1 139², L2 137², L3 142², L4 161². 파일명은 `house_lN_c-v1.png`, 대응 상태는 `house_lN_c_weathered-v1.png` 등이다. 상태를 같은 등급의 다른 변형에 공용으로 얹지 않는다. 기반 변형과 같은 좌표(0,0), 같은 크기로 source-over 합성한다. weathered/fresh는 둘 중 하나를 선택하고, snow/boarded는 별도 상태로 얹을 수 있다. 다중 상태 조합 전체는 이번 검수 범위가 아니다.

첨부에는 수치형 엔진 피벗이 없다. 새 피벗을 발명하지 않고 **원본 캔버스 좌표계를 그대로 상속**했다. CSV의 contact_anchor는 원본 알파에서 측정한 접지점으로, 엔진 피벗이라고 주장하지 않는다. 등록 후 원본 하단 접지 윤곽의 좁은 띠를 보존하고 외부 픽셀을 제거했다. 최종 공통 마스크 검사에서 발판 원본 RGBA 차이0, 상태의 접지선/건물 외부 알파0을 요구한다. 이 검사는 실제 게임 충돌·지형 접지·가림 검증을 대신하지 않는다.

생성 도구는 한 부품마다 별도 호출했다. 상태는 생성한 효과 또는 편집된 상태 그림에서 정합·색/알파 차이를 추출한 투명 레이어다. 상태 원본 전체를 새 집 그림으로 납품하지 않았다. 공통 기술 후처리와 변경 픽셀 수는 `records/contact-normalization.json`, 실제 프롬프트·참조·개별 추출 방식은 `records/l0.json`~`l4.json`에 있다. 모델 버전·seed는 미제공.

## 확인 그림2의 범위
첨부960×600 캡처에서 주택24자리와 보이는 등급을 수작업으로 주석했다. 해당 위치의 집을 새 후보로 교체했다. 생성한 빈 부지 배경은 주석된 주택 교체 영역 안에서만 사용했고 나머지 원본 배경·시설·호수·목책·UI를 유지했다. 가려졌던 배경의 복원은 추정이며, 실제 저장 상태의 재렌더가 아니다. 캡처에 나온 기존 집이 첨부1300 원본과 완전히 같은 시대 변형인지도 확인할 상태 데이터가 없다.

1.0은 첨부 캡처 픽셀 크기,0.6은 그 판의60% 축소다. 실제 게임 줌 조작 시험이 아니다. 원본JPEG보다 새PNG가 선명하게 보이는 차이가 있다. 전후 차이를 아트 변화 외의 실제 성능·정확한 런타임 크기 일치의 증거로 쓰지 않는다.
