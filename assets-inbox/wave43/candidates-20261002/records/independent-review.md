# Wave43 봄 자산 독립 검수

검수자는 이 세션의 생성 담당과 분리하여 실제 PNG, 계절 비교판, 밝음/어두움 배경판을 직접 열고 알파·규격·반복 수치를 별도로 계산했다. 생성 담당의 PASS 문구는 판정 근거로 사용하지 않았다. 이 문서는 오프라인 검수이며 게임 설치 검증이 아니다.

최종 판정: 24종 모두 오프라인 후보 납품 적합. woodland attempt3와 침엽수 attempt2 수정본, 최종 contact-24.jpg 및 same-scene-z1.0.jpg/z0.6.jpg까지 직접 확인했다. 낮은 줌에서 미세 소품의 의미 판독은 아래 한계를 유지한다.

## 확인한 사실

- 일반 나무6은 잠금 여름 참조가 krill 설치원본과 바이트 일치. 전6 canvas 일치·alpha 전픽셀 불일치0·alpha0 RGB잔여0. pivot은 설치 manifest의 oak_large(44,112), oak_small(32,80), birch(30,96), pine_tall(32,120), pine_short(28,88), dead(28,80)와 일치한다. pivot은 PNG에 내장된 실행 의미가 아니므로 선언 및 형상 위치를 확인한 것이다.
- 활엽3은 연두 봄잎과 여름의 차이가 보인다. 침엽2의 첫 결과는 실제 1x/0.6x에서 거의 여름과 같아 재작업을 요청했다. 재시도는 가지 끝 황연두 새순이 더 선명하며 1x에서 개선됐다. 최종 침엽2 alpha 불일치0을 재실측했다. 고사목은 무잎·죽은 가지를 유지해 약한 목질 색차를 허용한다.
- 과수4 실제 PNG256×256, 각 여름 기하템플릿과 alpha 불일치0, alpha0 RGB잔여0. 사과/배 흰꽃, 자두/벚 분홍꽃이 보이며 가지·접지 위치가 유지된다. 벚은 plum_j의 여름/겨울 기하 프록시를 사용한 신규종으로, 기존 벚 원본을 찾았다는 의미가 아니다. 현재 manifest pivot(128,242)을 따르며 초기 discovery의 사과d 제안과 혼동하면 안 된다.
- 과수 authored1.0/0.6 비교판은256px 원본 비율이며 실제 worlddisplayWidth43의43px/26px 검수를 대신하지 않는다. 최종 scene에서43px/약26px 상태를 별도로 확인했다. 두 줌 모두 여름 녹색 수관과 봄의 밝은 개화 수관이 구별된다. 0.6에서 개별 꽃잎이나 사과/배의 식물학적 구별까지 주장하지 않는다.
- 지면5는256×128 완전불투명, 모든 XY 끝열 RGBA 최대차0. 밭3은512×64, X 끝열 RGBA 최대차0, 투명RGB0. 끝열 일치만으로 반복 자연스러움을 보장하지 않아 실제 반복 계절판을 함께 봤다. 강가 여름256×256은 재질참조이고, 밭 겨울은 휴경 프록시이지 동일 작물 상태의 겨울판이 아니다.
- 밭3은 갓 간 젖은 흙과 새 쌍떡잎을 구별할 수 있으며 X이음에서 끊김이 보이지 않았다. 강가·해안·백악·습지 봄fill은 여름과 구별된다. woodland 첫 결과는 갈색 낙엽과 밝은꽃/녹색고리 단위가 커서 반복 격자와 가을 인상을 강화해 수정 요청했다.
- 소품6은 실제 PNG와 actual-size-bright/dark·detail2x·산사3회반복판을 직접 확인. 두 양 변주는 어미와 어린양을 구별할 수 있다. 개울가·산사흰꽃·둥지와새·빨래마당의 동작/재료가 읽힌다. 현대 물건이나 검은 만화 테두리, 심한 밝은 테두리를 확인하지 못했다. 산사띠512×64 X 끝열 RGBA차0, 전6 투명RGB0. 신규 소품의 겨울/여름 동형 원본은 없으므로 장면에서 부재로 나타낸다.

## 최종 수정본과 장면 검수

- woodland attempt3 SHA256 `fd4ae287c638ecfac47ef70ead2790cc61ba1baf84149007efb5f65ae4697152`를 독립 확인. 이전 큰 갈색 낙엽·녹색 고리 반복이 사라지고 낮은 대비의 숲 흙/가느다란 낙엽 바탕이 됐다. 단독256×128 및 계절 반복판에서 선형 이음은 보이지 않으며 XY끝열 RGBA 최대차0. 꽃·이끼는 약하고 봄 구별은 다른 초지/새잎/꽃핀 나무와 함께 읽힌다.
- 마지막 전체24 PNG 재실측: manifest 크기 불일치0, alpha0 비영 RGB픽셀0, 일반나무6+과수4 여름기하템플릿 alpha불일치0. 이는 독립 계산이며 생성 담당 validator 출력을 옮긴 수치가 아니다.
- 최종 두 줌 계절 장면은 같은 배치와 배율의 오프라인 비교임을 판 내에 표시한다. 봄의 활엽 새잎·과수 개화·젖은밭/싹과 겨울·여름 차이가 보인다. 소나무 새순은 활엽수보다 미묘하지만 최초 결과보다 밝은 끝이 구별된다.
- props 추천 canvas worldwidth 반영을 scene-layout에서 확인했다. 양28px, 둥지9px, 빨래40px, 산사256px, 개울128px. 마당의 밝은 빨래·개울 물·산사 흰꽃은 장면에서도 읽힌다. 양의 어미/새끼 자세 디테일은0.6에서 매우 작고 둥지는9px canvas(0.6에서약5px)라 독립적으로 새·알을 구별하기 어렵다. 이것은 원본 결함으로 확정하지 않으며 실제 통합에서 저줌 표시/상호작용 요구가 있다면 별도 가독성 검토 대상이다.
- 벚 최종기하 프록시는plum_j, pivot(128,242)로 확정. 겨울/여름은 벚의 식물학적 계절 원본이 아니라 프록시라는 표기를 확인했다.

## 미검증 경계

실제 엔진 NAT-3 대상별 전환·가림·충돌·지도 배치·카메라 줌·DPR·성능은 검증하지 않았다. 합성 계절판을 게임 캡처로 부르지 않는다. 새 소품의 suggested world width는 설치 승인이 아니며 실제 렌더러 비율 조정이 필요할 수 있다. 원본/기존 승인물은 수정하지 않았다.
