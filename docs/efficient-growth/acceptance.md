# 자동 성장 가드레일과 최종 도시 캡처

현재 기준선은 `seeds/baseline-7db9df85.json`이다. 이전 효율 성장 판정(`bbc0c523`)의 유휴 노동 5~25%, 마지막 순간 밀 재고 0 방앗간 <20%, 원료 부족 시간 <20%를 독립 합격 목표로 적용하지 않는다. 유휴 노동 5~25%는 **C3 관문 후보**다.

seed 1~5마다 24필지, 최대 1,200,000틱을 실행한다. 기존 엄격 성장 조건인 목표 필지, 승리, 모든 집 L4·서비스 공급·공사 없음·인구 수용량의 24,000틱 연속 안정, 정상 실행을 유지한다. 가드레일은 기준선에서 달성한 L4 24/24 미도달, 기준선보다 많은 최종 서비스 공백, 성장 정지와 조언 `no_action`의 동시 발생, 방앗간>밀밭, 곡창>ceil(필지/4)+1, 시장>ceil(필지/24)+1, 교회>ceil(필지/32)+1, 경고 건물 비율 ≥10%를 실패로 기록한다. 최근 2,400틱 식량 관측창과 방앗간 활동이 없는 결과도 판정 불가로 실패한다.

밀 재고 0 방앗간 비율은 **안정 구간에서 같은 완공 방앗간의 재고가 2,400개 연속 완료 틱 동안 0이었던 경우**만 센다. 마지막 한 틱의 재고가 0인 방앗간을 세지 않는다. 안정 구간이 끊기거나 관측 틱이 빠지면 연속 기록을 초기화한다. 기준선 `7db9df85`를 같은 관측기로 격리 재실행했고 5개 seed의 최종 상태 SHA-256·종료 틱·안정 구간이 보관된 결과와 모두 일치했다. 연속 재고 0 방앗간은 seed 1~5 모두 0개였다. 비교 대상의 연속 기록이 없으면 결과는 `indeterminate`로 남고 가드레일은 통과하지 않는다. 비교 가능한 경우 기준선보다 **20퍼센트포인트를 초과**하는 악화를 회귀로 판정한다. 승리 틱, 안정 지속 시간, 유휴 노동 비율, 원료 부족 시간 비율과 이 연속 재고 0 비율은 보고값으로 보존한다.

제품 `renderFrame`과 실제 에셋을 사용해 최종 상태를 진행하지 않고 1600×1100·DPR 1·줌 0.9 JPEG를 찍는다. 캡처 누락, 에셋 실패, 화면에 보이는 건물의 경고 비율 ≥10%, 상태 SHA256 불일치는 최종 실패다. 화면 밖 건물은 화면 비율의 분모에 넣지 않는다.

```sh
node --import tsx scripts/efficientGrowthRun.ts 24 1200000 OUTPUT SEED
npx vite --host 127.0.0.1 --port 3281 --strictPort
node --import tsx scripts/efficientGrowthCaptureCli.ts OUTPUT http://127.0.0.1:3281 9371
```

실행 디렉터리는 비어 있어야 한다. 성장 명령은 `summary.json`과 원시 `final-state.json` 하나만 만들며, 캡처 후 최종 판정은 `acceptance.json`에 기록한다. 각 seed의 가드레일·캡처를 확인한 뒤에만 A‴ 기준선을 새 결과로 교체한다. 원본 `7db9df85` 기준선은 이력으로 보존한다.
