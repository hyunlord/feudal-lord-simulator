# 검증 전제 교정: 연결된 주택과 공간 보존

대상: `64f2db76` 전체 시험에서 발견한 주택·조언 주기·서비스 자리·성벽 시험의 오래된 전제. **런타임 변경 없음.** 전체 시험의 실제 인구 감소 문제는 별도 식량 수정이며 이 커밋에서 합격 조건을 낮추지 않는다.

**원인과 변경.** 과거 주택 시험은 서로 끊긴 도로와 5가구일 때 출구가 완전히 막힌 주택을 준비하면서 즉시 주택/밀밭 건설을 기대했다. 이제 실제 공급 경로 복구가 먼저 선택되는 것이 맞다. 두 파일의 중복 준비 코드를 하나의 연결된 4~5가구 준비 상태로 교체했다. 가구 정원·빵 재고·공공시설·곡창 접근을 갖추며 생산 이력은 만들지 않는다. 실측 관측 대기, 정상 주택 1채 공사, 공사 중 식량망의 주택 증설 차단, 기본/명시적 8필지 동등성, 4필지 상한, 후기 시대 확장을 각각 검증한다. 실제 reducer로 정상 식량 공사를 시작한 대기 상태를 사용해 119틱 무행동·120틱 첫 행동의 기존 주기 검증도 유지한다.

seed3의 원래 2400틱 구간에는 제재소(0), 밀밭(120), 방앗간(1440), 예배당(1800)의 실제 공사 4개가 있었다. 모든 공사의 성벽 제안 및 최종 검증은 이미 통과했지만, 과거 시험은 **다섯 번째 공사와 2280틱의 추가 방앗간**까지 요구했다. 이를 네 핵심 시설의 실제 공사 확인과 실제 방앗간 대체 위치 확인으로 바꿨다. 매 공사마다 동일한 성벽 제안·검증을 계속 실행하며, 위험 좌표(15,6)의 완공/공사 중/지형 변경 회귀도 보존했다. 실행 구간을 늘리지 않았다.

97560틱 원본 저장 상태는 새 2400틱 실측 이력이 없어 `observation_warmup`으로 대기한다. 이를 명시적으로 검사하고, 공간 보존 회귀를 불필요한 자동 증설 의무와 분리했다. 원래 위험 곡창(61,40)은 거부되며, 대안(61,41)은 실제 도로 계획→도로 reducer→공사 접근성·배치 가능 검사→건설 reducer를 거친다. 각 단계에서 마지막 시장 자리와 주택의 짝지어진 서비스 통행 증인을 보존한다. 이 위치는 역사적 실패 재현 시험에만 있으며 제품의 seed/좌표 특례가 아니다.

**검증:** 해당 5개 시험 파일 21개 통과, diff 검사 통과. 시험 삭제/skip/인구·급식·성벽·통행 기준 완화·가짜 생산 이력·틱 예산 확대 없음. 원래 실패 로그는 보존한다. 최종 전체 회귀와 8필지/5seed 실행은 기존 실행 검증 담당자가 수정 커밋을 포함해 갱신한다.
