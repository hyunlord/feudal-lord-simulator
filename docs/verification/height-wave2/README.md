# RB-HEIGHT-WAVE2 — 다섯 집 계열의 문 높이와 전용 상태층

Wave2의 L0 정원집·우리집과 L1 공방집·정원집·기와집에 완성 본체 및 전용 상태 그림 33장을 등록했습니다. 기존 기본 L1에서 검증한 상태층 소비자를 그대로 사용하며 엔진 상태, 집 선택 확률, 원본 그림과 이전 39개 묶음은 보존했습니다. L0 strained 2장은 현재 소비 조건이 없어 데이터만 준비했습니다. 실제 대상에서 관찰한 그림 수는 별도 draw 영수증에 기록합니다.

## 같은 저장 비교

게시된 a666482c를 전으로, Wave2 통합 제품을 후로 사용했습니다. 준비 저장 41개를 줌 1.0·0.6으로 비교하고 다섯 계열의 눈 없는 계절·겨울 10개를 줌 3으로 추가했습니다. 총 92쌍이며 원본 저장·준비 저장·전체 변경 필드·카메라·고정 시각·실제 보행자 기록을 보존합니다. 시간을 진행하거나 가짜 인물을 추가하지 않습니다.

L0 정원은 seed 1, L0 우리는 seed 4, L1 공방은 seed 69, L1 정원은 seed 1, L1 기와는 seed 23으로 실제 선택자를 사용합니다. seed 변경은 주변 장식에도 영향을 주므로 서로 다른 seed 사이를 전후로 비교하지 않습니다. 준비된 condition·vacancy·plague·tick 변경은 자연 성장 관찰이 아니며 각 fixture의 전체 diff에 공개합니다. L0 원본 진단은 봄, L1 공방·기와는 여름, L1 정원 maintained는 가을입니다. L1 정원 original 저장은 이미 눈이 보이는 상태이며 여름으로 세지 않습니다. 계절 이름은 저장의 실제 화면 표시에 따릅니다.

L0 두 계열의 초기 자연 저장은 실제 walkerLooks가 0명입니다. 따라서 L0에 성인이 직접 나란히 서 있는 비교를 했다고 주장하지 않습니다. 문짝 원시 측정×world 배율과 L1 장면의 실제 17.6px 성인 비교를 구분합니다. 인물을 주입하거나 추가 저장을 만들어 이 한계를 감추지 않았습니다.

## 엔진 저장 상태와 화면 표현 상태

92뷰 중 46뷰에서 준비 저장의 상태 SHA와 browser proof.state() SHA가 달랐습니다. 실제 proof 포트는 엔진 저장에 주민 보행자를 더한 presentedState를 반환합니다. 동일 저장에 기존 presentedState 함수를 적용하자 browser SHA가 92/92 일치했고 원본은 바뀌지 않았습니다. 변경 최상위 필드는 walkers뿐이며 실제 주민 보행자 ID·수를 영수증에 남겼습니다. 이는 QA가 인물을 주입한 것이 아닙니다. 전후 비교는 동일한 엔진 저장과 동일한 표현 상태 SHA를 각각 확인합니다. 초기 codec/버튼 닫기 가설의 반증 기록도 보존합니다.

## 장부와 출처

기존 3행의 installed_by 셀만 제자리 변경했습니다. 모든 기존 행 순서·CRLF·나머지 바이트를 보존했습니다. 새 47행은 등록 그림 33장과 미설치 원시 그림 14장입니다. 새 행은 정본 파일명 순서에 삽입했으며 raw 14장을 설치 수로 세지 않습니다. 원본·실패 시도·정확한 프롬프트·전체 등록 변환은 전체 ZIP에 보존합니다.

## 실제 화면에서 확인한 것

다섯 계열의 눈 없는 진단·겨울 확대판, 정상 줌1 및 겨울 줌0.6, 일반 판자·역병봉쇄·부분해빙 대표 장면을 직접 열었습니다. 본체의 문과 벽은 높아졌고 다섯 눈 층은 해당 지붕에 붙어 보입니다. L1 공방·기와의 문 하단은 앞 작업장에 일부 가려집니다. L1 정원은 겨울에도 그림에 포함된 녹색 텃밭이 남습니다. 줌0.6에서는 지붕 눈과 본체 실루엣이 문짝·작은 상태 표시보다 잘 읽힙니다. 주변 UI 툴팁·버튼 문구까지 픽셀 동일하다는 주장은 하지 않습니다.

전후92쌍의 저장·표현 상태·카메라·고정 시간·보행자와 draw transform 집합이 일치했습니다. 실제 대상 사각형의 본체→상태층→판자→눈 순서 및 alpha를 모든 render cycle에서 검증했고 31장 양성·L0 strained2장 데이터 전용을 확인했습니다. page error0, 네트워크 실패19건은 모두 telemetry ERR_ABORTED이며 자산 로드 실패로 분류하지 않습니다.
