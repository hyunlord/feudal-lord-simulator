- 기존 256×320 캔버스, 피벗 (127,268), worldScale 0.147368421 유지.

## 동일 장면 비교

`proofs/01-same-corner-comparison.jpg`는 **같은 실제 캡처 / 기존 여름 v1 / 수정 여름 v2 / 수정 겨울 v2** 순서다.

기존에 사용한 `ch5-gate-51-38-zoom1.4.jpg`의 왼쪽 원본 영역, 같은 원본 좌표 (244,180), 같은 배율 0.206315789를 사용했다. 확대 부분도 동일 좌표를 잘랐다. 배경의 색이나 명도를 바꾸지 않았다.

`proofs/02-material-alpha-scale.jpg`에는 v1·v2 여름·겨울, 밝은 배경·어두운 배경, 축소 확인을 담았다.

명도 참고값: alpha≥200인 여름 조각 전체의 sRGB 가중 휘도 중앙값은 v1 130.96 → v2 99.63(약 24% 감소)이다. 중앙 RGB는 (148,128,103) → (105,99,90)으로 바뀌었다. 이 값은 이미지의 변화량 확인용이며, 서로 면 방향·조명이 다른 성문 참조와 수치상 동일하다는 뜻은 아니다. 최종 조화는 동일 장면 합성으로 확인했다.

기존 성문 그림 `stone_gate_v3_nwse-v1.png`와 실제 성벽 띠를 함께 참조했다. 몸체의 큰 장방형 돌을 잘게 나눴으며 상부·모서리의 구조 윤곽은 유지했다.

## 재현·보존

- 전체 프롬프트, 참조 경로, 원본 생성물 해시는 records/*-generation.json에 있다.
- 원본 생성물 2장과 축소 중간물 2장을 모두 동봉했다. 원본 도구 보관 파일도 보존했다.
- 생성 시 생긴 약간의 위치·크기 오차는 records/register-material.m으로 기존 실루엣에 등록했다. 여름 재질의 색은 생성 결과를 사용했다. 겨울은 눈색 픽셀을 상부에 합성하고 나머지 몸체를 여름판과 공유한다.
- manifest.csv / manifest.json에 파일별 해시와 전체 프롬프트가 있다.
- 승인된 5장은 원래 패키지에서 그대로 사용하면 된다. 이번 ZIP의 references에 들어 있는 석벽 v1은 비교용이며 설치 후보가 아니다.
- SHA256SUMS는 자기 자신을 제외한 ZIP의 모든 파일을 검사한다.

고정 캡처 합성 검수만 수행했다. 게임 설치·렌더 순서·동적 가림 검증이나 코드 수정은 하지 않았다.
