# 기록된 인물 사망의 연간 분포

정본화된 사망 보존 감사 자료에서 세 판×150년의 **450행**을 만들었다. 0건인 해도1300~1449 모두 포함한다. 각 판은 독립 ID namespace이며 세계 전체 사망이나 주민 사망률을 뜻하지 않는다.

- N02 굶주림 기록2059건은 대기근 기간에 한정되지 않고 여러 세대에 걸쳐 나타난다. 연간 최대는1343년83건이다.
- N03 굶주림98건은1313년52건이 최대다. N04는293건 중1305년86건이 최대이며 후반에도 드문 기록이 있다.
- 흑사병 기록은1348~1349년 및1361년에 집중된다. 연간 최대는 N02 1348년122건, N03 1348년141건, N04 1349년272건이다.
- `famine_year`는13/14/13건으로, 굶주림(`famine`)과 분리했다. `age`는 유아·이주 후 사망도 포함하는 통상 사망 원인이므로 “노령 사망”으로 번역하지 않았다.

이 차이를 성장·안정 정책의 효과라고 단정하지 않는다. 인구 규모·땅·사건 시점 등 조건도 다르며 분모를 보정하지 않은 기록 건수다.

## 자료와 검산

`ANNUAL_CAUSES.csv/.json`: run/year와5개 원인·합계·정확 history tick이 있는 사망 수. `SUMMARY.json`: 원인별 합계·tick 연결 건수·최대 연도. 총계5440/2167/3083이 동결 inventory와 정확히 일치한다. history tick 연결은3795/1988/2903이며 famine/famine_year/plague/fire는 전원 연결돼 있다. 나머지age는 연도만으로 집계했다.

`EVENT_WINDOWS.json`은 자연 최종 저장의 대기근 arrival/end 및 흑사병 first/second arrival/end를 인용하고, 같은 도착tick의 기존 history ID를 연결했다. 대기근은 N02 76450–85500, N03 80000–89500, N04 80000–93500틱. 흑사병 첫 파동은 N02/N03 194000–198000, N04 195000–199000; 두 번째는 모두244000–246000틱이다. 그래프 회색 띠는 이 저장된 활동기간이다. 가격 여파·회복기간 전체라고 확대 해석하지 않는다.

그래프 `../../graphs/recorded-deaths-r07.svg`는 독립 SVG이며5원인×3판 작은 그래프로 구성했다. 같은 행은 공통 Y축(연간 건수), 서로 다른 원인의 행은 각각 축이 다르다. 공통1300~1449 X축이며 한국어 시스템 글꼴을 사용한다. macOS Quick Look으로 PNG 미리보기를 만들고 세 열·다섯 행·각 축·주석이 잘리지 않는 것을 확인했다. 게임 렌더·브라우저는 실행하지 않았다.

450연도 연속·중복0, CSV↔JSON 값 일치, 원인별합계↔inventory 일치, SVG XML 파싱을 검증했다. 입력SHA·그래프SHA는 검증 파일에 남긴다. 이 집계는 보존된 기록의 분포이며 개별 사망의 음식·가격·가구 상태 인과를 검증하지 않는다. 새 시뮬레이션·의존성 설치·소스 수정 없음.
