# Wave 4e 물가·다리 검수

- 산출물: 물가 띠 2장(512×96), 교대 2장과 나루 1장(256×192), 확인 그림 `proofs/02-water.png`.
- 제작: 기존 물가와 `deep_a`를 입력한 편집으로 A를 만들고, A를 확인한 뒤 B를 제작했다. 모듈은 각각 흑백 위상 마스크를 먼저 만들고 기존 프로젝트 교대 그림을 화풍 참조로 편집했다. SW/NW는 픽셀 반전으로 만들지 않았다.
- 후처리: 원본을 보존하고 알파 경계를 잘라 한 번 축소했다. 물가의 X 양끝 20px 구간을 맞추고 Y 양끝에 12px 알파 페이드를 적용했다. RGB를 알파로 나눠 생기는 밝은 띠를 중간 검수에서 발견해 RGBA 저장 경로를 수정했다. 최종 확인 그림에는 밝은 테두리가 없다.
- 수치: 물가 A/B의 좌우 첫·마지막 열 RGBA 최대 차이 0. 위·아래 마지막 행 알파 0. 나루는 기둥 2개, 판자 데크, 배 없음.
- 시각 확인: 깊은 물 3×3, 새 물가 두 단면, X 4회 반복, 모듈 0.6/1.0/1.35 줌에 대응하는 0.3/0.5/0.675 축소를 확인했다. 축소 시 나루의 두 기둥과 교대의 방향 차이가 보인다.
- 한계: 반복 이음 수치가 0이어도 동일한 둑 리듬은 반복된다. 런타임에서 변형 교대·곡률 매핑이 필요하다. 소켓·점유 다각형은 생성 전 마스크의 목표값이며, 생성 결과의 모서리 픽셀과 통행 포털의 정확한 일치는 인증하지 않았다. 게임 설치·충돌·가림·DPR·성능은 검사하지 않았다. 후보 상태다.
