## 참조와 수정 기록
- forest_fringe_a/b/c, grass_edge, pasture_a, ridge_fallow_a, soil_a는 Wave15 ZIP 원본.
- terrain grass는 Wave15 ZIP 누락. 리더가 지정한 프로젝트 이전 Wave4 원본 `/tmp/astra-wave4-work-20260925/astra-wave4-reference-files/grass.png` 참조. repo의 오래된 bladegrass는 사용하지 않음.
- terrain2 두번째시도에는 첨부 pasture_a를 형태크기 보조참조로 사용. 별도 외부그림 없음.
- native1회/에셋, terrain만4회. 실제 프롬프트와 채택/불채택 경로 ground-sources.json. pasture 첫 호출은401로 실패했으나 재시도 성공; 실패 호출은 생성 후보 없음.
- 모든 그림 실제 native imagegen 편집. JS는1회 크기맞춤/알파·RGB가장자리 정리/반복접합/합성검사만 수행.
- 반복 이음새0은 기계적 경계 검증이며 모든 대형 지도에서 반복감 없음이나 런타임 성능 통과를 뜻하지 않음.
