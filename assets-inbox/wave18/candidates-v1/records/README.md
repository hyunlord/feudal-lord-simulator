# Wave18 최소 HUD 후보

납품: **신규 37 PNG + 기존 계절 재사용 4 PNG = 41파일**, 확인 그림 3장, assets.csv 41행. 게임 설치·코드 변경 없음. 모두 candidate이며 사용자 최종 채택 전입니다.

의뢰서의 명시된 파일 목록을 기준으로 집계했습니다. pulse_ring은 96×96 셀 3개를 가로로 묶은 288×96 시트 한 장입니다. 계절 4종은 P0 원본 셀을 무변형 추출했습니다.

## 확인 그림

- [01 크기·P0 비교](proofs/01-icons-scale-comparison.png): 24/32/48px 비교. 원본 자산에는 글자·숫자가 없으며 검사판 라벨만 별도로 합성했습니다.
- [02 최소 HUD 합성](proofs/02-minimal-hud-pc-tablet.png): PC 1280×800와 태블릿 1180×820. 첨부 화면의 기존 UI를 이미지 편집으로 제거·재구성한 전체 배경에 새 HUD를 얹은 **오프라인 합성**입니다. 기존 지도 픽셀 동일성·실제 제품 실행 화면을 의미하지 않습니다. 예시 수치는 시뮬레이션 산출값이 아닙니다.
- [03 배치 컬러·흑백](proofs/03-placement-colour-grayscale.png): 같은 합성의 RGB를 흑백 변환. 가능=점, 불가=사선/교차선+원인 아이콘이 색 없이도 구분됩니다. 표시한 지형·크기에서의 내부 판정이며 모든 지형·줌 검증은 아닙니다.

합성 02의 UI 사각형 면적 합은 PC 5.99%, 태블릿 6.34%입니다. 이는 오프라인 배치 계산이며 실제 UX-3 구현 관문이나 성능 결과가 아닙니다. 합성 버튼·pill은 높이 48px 이상, 배치 확인/취소는 56px입니다.

## 규격과 사용

- 일반 아이콘: 96×96 RGBA. 패턴 3종: 64×32 등각 마름모, 서비스 경계: 128×16. 모두 투명 배경.
- pulse_ring: 좌→우 지름 48/66/84px, 목표 불투명도 0.8/0.55/0.28. 실제 타이밍은 제품에서 지정.
- 신규 아이콘은 망치·두루마리·인장 문서·장비를 든 일꾼 둘의 예약 모티프를 피했습니다. 인구는 도구 없는 시민 둘입니다. 체크·X·자물쇠는 요청된 공통 기호이며 P0와 완전히 다른 모티프라는 주장은 하지 않습니다.
- 패턴은 생성한 붓질 재료에 정확한 반복 기하·알파를 구성했습니다. 원본을 그대로 축소한 결과가 아닙니다. 후처리와 실제 프롬프트는 CSV·records·scripts에 있습니다.
- 24px에서는 구역 금지의 경계, 중복 건물의 X, 지우기 도구의 정확한 이름이 문맥/원인 문구를 필요로 합니다. 유지비 위기는 요청 크기인 36/48px를 권장합니다. 서비스 경계는 실제 지형 위 대비를 통합 단계에서 조정해야 합니다.
