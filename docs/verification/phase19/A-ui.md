- 커밋: `591efdf` (8파일)+`304d575` 대비 보정(2파일; 원본 `19e3ea7`·`098ca27`).
- 바뀐 것: 본문13px·메타11px·배지10px 기준을 적용하고 정보 영역을 재배치했다. 긴 목표·건물 설명은 각 영역에서 끝까지 스크롤할 수 있다. 이미지·게임 규칙·렌더러는 변경하지 않았다.

- 테스트: 담당자 집중21개·타입검사·기존4뷰포트 메뉴 검증 통과. 독립6조건의 computed style에서10px 미만0개이며, 작은 글씨는 완료 배지10px·자동 발전 메타11px다. 독립 검수에서 최소 대비5.43:1·잘림 없음·카테고리/키보드·스크롤 끝 도달 통과(A-independent-qa.json). 처음 발견한 현재 목표 제목4.46:1은 잉크색으로 보정하고 다시 검수했다. 통합 최종 검증은 별도 기록한다.
- 확인 못 한 것: `.onboarding-task-flourish` 10px는 배지 예외로 작은 화면과 실제125% 조건에서 관찰됐다. 화면 재배치에 대한 미적 최종 평가는 사용자에게 남긴다.
