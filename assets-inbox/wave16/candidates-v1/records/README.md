# Wave 16 — 사건·결정·연대기 삽화 후보

첨부 의뢰서의 명시 목록대로 삽화 35장과 확인 그림 3장을 제작했습니다. 게임 설치·제품 코드 변경은 하지 않았습니다. 사용자 검토 전 후보입니다.

## 구성

| 묶음 | 수량 | 납품 크기 |
|---|---:|---|
| 사건 카드 | 12 | 960×540 |
| 대기근 결정 카드 | 5 | 640×480 |
| 연대기 삽화 | 16 | 384×384 |
| 장 끝·장 시작 | 2 | 1920×1080 |

`index.html`은 개별 파일을 여는 갤러리, `IMAGE_LINKS.md`는 전체 이미지 링크입니다. `assets.csv`에는 35행의 장면·등장인물·역사 메모·생성 프롬프트·참조·원본·후처리·검수 기록이 있습니다. 제공되지 않은 모델 버전과 seed는 추정하지 않았습니다.

## 확인 그림

- [사건 카드 12장](proofs/01-event-cards.png): 첨부 목표 카드 틀을 확장한 오프라인 합성.
- [대기근 결정 카드 5장](proofs/02-decision-modals.png): 첨부 모달 틀, 하단 선택 영역은 비움.
- [연대기 4쪽](proofs/03-chronicle-pages.png): 첨부 연대기 틀에 각 4장.

확인 그림에도 제목·설명·숫자를 넣지 않았습니다. 배치 순서는 `records/proof-layout.json`에 별도로 기록했습니다. 실제 게임 화면이나 런타임 통합 검증은 아닙니다.

## 제작·검수 범위

1300–1318년 잉글랜드 남부를 기준으로 저채도 회화, 무굴뚝 주택, 기둥풍차, 수작업 공사·농업을 사용했습니다. 연대기는 얕은 공간감과 약한 필사본 채식 느낌을 더했습니다. 문에 그린 표식·홉·관·흑사병 장면·선명한 원색·문자·숫자를 검사했습니다. 장면 속 시장 십자가와 교회 십자가는 금지된 문 표식과 구분합니다.

원본 생성 결과는 `raw/`, 실제 생성 기록과 수정 이력은 `records/metadata-*.json`에 보존했습니다. 고정 납품 크기로 비례 리사이즈·필요한 가장자리 크롭을 했으며, 장 끝·시작은 생성 원본보다 확대된 납품본입니다. 이미지별 원본 크기와 처리는 CSV에 기록했습니다.

`검수표.md`에 글 없는 장면 판독과 한계를 구분합니다. 제작자와 독립 검수 에이전트의 시각 판정이며 실제 초보 플레이어 대상 인지 실험은 아닙니다. 역사 금지사항 검사는 학술적 완전성 인증을 뜻하지 않습니다.
