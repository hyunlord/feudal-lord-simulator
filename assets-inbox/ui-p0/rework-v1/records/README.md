# UI P0 재작업 후보

게임에 설치하지 않았습니다. 지정된 틀·초상·아이콘만 교정했고 기존 P0 디렉터리와 원본은 덮어쓰지 않았습니다.

## 수량

의뢰서 요약16장과 상세파일수가 다릅니다. A는 변경7+유지tooltip1=8, B는 변경2+유지neutral1=3, C의 재출력 대상은5개 셀을 포함하는3시트입니다. 상세 항목은 총14개 납품파일입니다. 이14개에 포함되지 않는29개는 `retained/ui/`에 바이트 그대로 보존합니다. 실제 변경파일은12개, 전체43개 중31개는 이전과 같습니다. 사용자 확인에 따라 명시된14장·CSV14행으로 확정했습니다. 임의의2장을 추가하지 않았습니다.

## 교정 내용

- 목표: 이중선·작은 잉크꽃을 기본으로, 완료 금선/인장과 경고 적갈선/번짐을 구분했습니다.
- 조언자: 좌우 말린 두루마리. 모달: 굵은oak와상단띠. 밝은패널: 툴팁보다 명확한선. 본문중앙은 단색입니다.
- 청지기: neutral은그대로. concern은숙인고개·미간·처진입, success는고개들기·열린입웃음으로 교정했습니다. 최신 지시의 고개 변화 때문에 눈선 이동은 의도된 변화입니다.
- 원인 노동=두일꾼+삽, 권리=접힌인장문서, 접근=막힌길. 목표열기=문+화살표, 도움말=원형물음표. 직접망치·방향두루마리·도움책촛불 및 기타셀은 보존합니다.
- 물음표는 이번 의뢰서가 명시한 기호이며 기존 일반 ‘문자 미포함’ 규칙의 지정 예외입니다.

## 확인과 기록

[개별 이미지 갤러리](index.html) · [CSV](assets.csv)

`proofs/`의 확인판3장은 틀8종 이름가림 비교, 초상96px무작위비교, 아이콘교정비교입니다. 정답키와 첫 판정을 `records/`에 따로 보존합니다. 블라인드 판정은 정답표를 먼저 읽지 않은 AI 시각 검수이며 사람 대상 인지실험이 아닙니다.

`records/preservation.json`은43개 전체 이전/이후SHA, `records/untouched-cell-check.json`은시트의 변경대상5셀/유지9셀 비교입니다. `records/previous-assets.csv`는 이전 납품의 생성기록으로, 변경없이 유지하는 자산의 출처입니다. `sources/`에는 이번 편집의 원본, `records/`에는 전체 실제프롬프트·참조·후처리·검수기록이 있습니다. 제공되지 않은 모델버전·seed는 만들지 않았습니다.

실제게임입력·DPR·반응형·성능은 검증범위가 아닙니다. 이패키지는 이미지후보입니다.

## 최종 검수

- 납품 PNG 14장, CSV 14행, 확인 그림 3장.
- 이름 가린 틀 역할 판정 8/8, 최종 96px 무작위 초상 판정 3/3. 모두 AI 독립 검수이며 사용자 인지 시험과 구분합니다.
- 틀 8종은 200×80 / 600×400 출력에서 네 모서리 픽셀 동일.
- 지정 아이콘 5셀 변경, 나머지 9셀 RGBA 동일.
- 전체 43파일 중 변경 12, 유지 31. 유지 31에는 납품에 포함된 neutral·tooltip과 별도 보존 29개가 포함됩니다.
- 24px에서 막힌 길의 세부와 노동자의 삽은 식별력이 약합니다. 게임 안 적용·입력·가독성 검증은 하지 않았습니다.
