## A. 직업 확장

### A1. 핵심 결론
1. **직업은 60개, 플레이어가 관리하는 건물 종류는 60개가 아니다.** 직업은 가구가 스스로 고르고, 플레이어는 길·시장권·필지 크기·물 권리·임대료·화재·악취 규정·통행세·이민 장려금 같은 **조건**만 정한다 — 영주 모드 정체성과 정확히 같은 방향.
2. **작업장 원형 12개**로 압축: 거리 앞방 점포 · 주택 후면 공방 · 큰 뒷마당 · 더러운 뒷마당 · 외곽 냄새 마당 · 대장간 · 물가 공방 · 수력 시설 · 대형 창고상점 · 기관(교회·수도회) · 무점포 노동(방적·짐꾼) · 순회·희귀 전문직.
3. **위치는 버프가 아니라 경제지리**: `입지점수 = 원료 접근 + 고객 접근 + 친족 기술망 + 물·길 + 필지 크기 − 임대료 − 악취·화재 규제 − 경쟁`. 우리 자율 성장(LM-E1)의 **이유 점수와 같은 구조** — 무두장이는 "생가죽 +28(Butcher Row 3가구) · 하천 46m +23 · 값싼 긴 필지 +17 · 장인의 사위 +15 · 악취 규정 −8"로 영수증이 그대로 나온다.
4. **같은 직업이 모이면 거리 이름이 생긴다**(Salisbury Butcher Row 1380, Oxford Fish Street). 직업 60개를 목록으로 외우게 하지 말고 **지도가 카탈로그**가 되게.
5. **서비스 직업은 물건이 아니라 용량**: 이발사·치료사(병·부상 회복), 서기·공증인(계약 안전·법정 속도), 짐꾼·운송(물류 처리량 — **헛간 밀이 못 나가던 문제의 답**), 여관(상인 체류), 사제·탁발(구휼·안정).
6. **고정 비율 금지, 병목 하나만 보여 주기**: "무두 생산성 38% — 주원인: 나무껍질 부족(2일분)". Anno식 2:1:1 최적비 대신 용량 띠.
7. **계절 노동은 정책으로**("수확 우선", "겨울 가내 작업 허용") — 가구를 수동으로 옮기지 않음(Banished가 같은 이유로 윤작을 뺌).

### A2. 직업 풀 (빈도는 사료 직접값이 아니라 게임 교정 범위)
- **핵심(모든 시장도시)**: 제빵·양조(여성 가내 양조 포함)·푸줏간·방앗간지기·여관·재단·직조·대장·목수(인구 270명당 1)·구두장이·운송·상인
- **조건부 전문(땅·길·산업에 따라)**: 축융·염색·양모상·포목·무두·백혁(tawyer)·가죽 마무리·안장·통장이·수레장이·못장이·칼장이·기와·잡화·향료·포도주
- **희귀·기관·순회**: 백랍·놋쇠·자물쇠·유리·의사·공증인·탁발·은자 (도시 레벨 해금 아님 — 부유함·교회·이민·교역망 조건)
- **넣지 말 것**: 직업 편직공(1500 이후), 약사(향료상·치료사로 겹침)
- 사슬 7: 곡물·보리·에일 / 육류·가죽(→ 양초) / 양모·직물 / 철·금속 / 목재 / 건축 자재
- 변곡점: **축융공이 1350년대 뒤 크게 늘고**(Norwich 직물 노동자 중 13% → 22%), **1400 뒤 clothier**가 방적·직조·축융·염색 가구를 **계약망으로 묶는 조정자**로 등장(건물이 아니라 상인 가구의 전환), 건축은 1349 뒤 일시 감소 후 1400 뒤 회복.

### A3. 우리 게임 적용
- 엔진: 직업을 **데이터**(입력·출력/서비스 용량·작업장 원형·위치 점수 항목·계절성·등급·길드 묶음·등장 조건)로. 자율 성장의 행위자(가구)가 이 점수로 직업을 고름. 길드는 직업별 체크박스가 아니라 **도시 제도**(작은 도시는 가죽 업종 여럿이 한 단체).
- 렌더: 7개 경제 대분류 → 사슬 카드 → 가구, 병목 하나, 거리 이름 표시, "왜 여기에?" 영수증에 직업 선택 이유.
- 그림(Astra): 작업장 원형 12종(지금 집 그림에 붙는 후면 공방·마당 — Wave 36 교훈대로 **벽 부착이 아니라 땅에 서는 마당 구조물·소품**), 직업군 워커·짐, 집 앞 표지 확장(Wave 37 12종 → 30종 안팎), 거리 이름표.

## B. 영주의 무력

### B1. 핵심 결론
1. **향신의 무력은 상비군이 아니다.** 다섯 층: 가솔의 무장 핵심(3~12명) · 계약 가신(평소 자기 땅에 살다가 호출) · 넓은 연줄(대영주의 것) · 원정 때만 꾸리는 계약 부대 · 주(州)·도시의 공적 징집.
2. **규모**: 1415 계약 기준 작은 esquire 3~5명, 기사·향신 8~30명, 남작 60~120명, 백작 150명+. **향신 플레이어가 200명을 끌고 다니면 안 된다.** 플레이어가 이름으로 관리하는 가신은 초반 3~8명, 후반 10~15명, 큰 숫자는 "William + 따르는 자 3" 같은 하위 무리로.
3. **값**: 궁수 6d/일, 무장병 12d/일. 6개월 20명 부대 ≈ £105(기본급만). 가신 연금 10 marks(£6 13s 4d) ~ 40 marks. 군마 £5~15(감정가). 갑옷은 단일 가격 없음 → 등급(빈약·쓸 만함·좋음·고급) 자산.
4. **국왕 원정 = 계약 협상**(우리 협상 엔진 그대로): 요청 인원·급료·선금·기간·말 감정·전리품 몫. 직접 참가 / 장남을 대장으로 / 가신을 대신 / 더 보냄 / 최소 / 면제 청원. 전쟁 자체는 **원정 연대기 사건**(해협 횡단 → 질병·말 손실 → 전투 → 포위 → 겨울 숙영 → 귀환). **포로 몸값은 분산이 큰 복권**(궁수 Robert Sadler가 £58 13s 4d — 6개월 급료의 13배).
5. **사적 무력 = 점유의 정치**(Paston Gresham 1448): `청구 → 현 점유자 → 집행 시도 → 저항/퇴거 → 점유 변경 → 형사·민사·정치적 후과 → 소송 계속`. 상태 변수: 권원 강도·점유·지역 지지·후원·즉시 부를 사람·**확전 단계**(평화적 점유 → posse 5~15명 → 강제 진입 → 포위)·**법적 노출**(1381·1391·1429 강제 진입법). 이겨도 "두 명 사망 · 치안판사 소환 · 후원자가 손을 뗌"이 될 수 있다 — **우리 LM-E2 영지·소송 모델 위에 그대로 얹힌다.** 30명은 정복군이 아니라 문을 잠그고 몇 주 버티는 사람들.
6. **징집은 경제에서 실제 사람을 빼는 것**(Manor Lords 원리): "방앗간 일손 −25%, 수확 위험 낮음 → 높음, 대장간 일손 부족, 수레 −2" — 고정 % 페널티 금지, **소집된 가구의 직업이 생산에서 빠짐**. 국왕 징집(Royal Array, 주·도시 의무)과 내 부대(My Retinue, 계약)를 분리.
7. **해안 방어는 준비 게임**: 봉화는 전투 보너스가 아니라 **시간**(12~36시간 경보 — 게임 추정)을 사는 것 — 귀중품을 교회·길드홀로, 가축 대피, 성문 닫기, 민병 집결, 배를 상류로. 결과는 사건("집 11채 탐, 3명 죽고 7명 실종, 양 84마리 빼앗김, 동문은 지킴, 창고는 미리 옮겨 무사").
8. **영주관 방비는 단계가 아니라 선택**: 도랑·해자 / 튼튼한 문 / 문루 / 바깥 마당 / 담·탑 / 총안(15세기) — 보안·위엄·버티는 기간·비용이 각각 다름.
9. **궁술은 기술 버프가 아니라 정책**(일요·축일 활쏘기 — 1363 런던 시장 포고, 전국 단일 법령 아님): 활·화살 장인 수요↑, 훈련된 궁수 후보가 천천히 늚.
10. **징발(purveyance)은 경제로**: 곡물 → 빵값↑, 수레·말 → 운송 용량↓, 배 → 교역↓.
11. **보여 줄 것과 줄일 것**: 경제·가문으로 돌아오는 순간(집결, 일터가 비는 모습, 행군하는 작은 무리, 숙영, 포위 진영, 봉화·종·성문, 귀환하는 몇 명, 초상·가계도의 죽음과 포로)은 화면에. 전술 전투는 결과 사건으로.
- 성공 기준이 "몇 칸 정복"이 아니라 **"왕에게 12명을 제대로 데려가 신용을 얻었나, 겨울 전에 무사히 데려왔나, 포로 하나가 가문 재정을 바꿨나, 20명으로 영지를 차지했지만 더 큰 후원자를 적으로 만들진 않았나, 봉화 덕에 시장 재산을 벽 안으로 옮길 시간을 벌었나"**.

### B2. 우리 게임 적용
- 엔진: 가솔·가신(인물·계약·연금·장비·말·충성) / 소집(가구 직업이 생산에서 빠짐) / 국왕 원정 계약(협상 엔진) + 원정 연대기 사건 + 몸값 복권 / 사적 분쟁 네 단계(LM-E2 점유·소송 위에, 확전·법적 노출) / 해안 습격 준비 창(2장 봉화·습격 재설계) / 징발이 곡창·수레에 / 궁술 정책 / 영주관 방비 선택.
- 렌더: 화면 이름은 "무력"이 아니라 **"가솔과 봉사"**(Astra 시안 08과 일치), 소집 화면은 사람 목록과 경제 예측이 함께, 원정은 Wave 35 계약 틀, 세계에 집결·행군·숙영·포위·봉화·귀환.
- 그림(Astra): 가신·궁수·무장병 워커와 초상(혈통 세트 연결), 말·짐수레, 집결 군중, 숙영지, 포위 진영과 봉쇄, 문 앞 대치 장면, 원정 사건 삽화(해협·전투 전후·포로·귀환), 영주관 방비 부품(해자·문루·담), 깃발.

## C. 조사 품질 (Claude)
- ④는 사료 근거가 탄탄하고(1415 계약 500건+, Paston, Historic England), 근거 없는 수치(갑옷 가격·숙영세·Gresham 공격자 수)는 **만들지 않고 비워 두라**고 했다. Caister(1469)가 시대 밖이라는 것, "1363 궁술법"이 전국 단일 법령이 아니라는 정정도 정확하다.
- ③은 빈도가 **사료 직접값이 아니라 게임 교정 범위**라고 분명히 밝혔고(인두세 명부는 성인의 2%만 직업 기재, 여성·하인 과소기록), 직물 변곡점(축융·clothier)은 근거가 강하다. 다만 파일 끝이 길드 절 중간에서 끊겨 있다(내용상 큰 손실은 없음).
- 두 조사 모두 결론이 **영주 모드와 같은 방향**: 플레이어는 조건을 만들고, 사람·가구·계약이 반응하며, 결과는 이유와 함께 보인다. 새 체계를 따로 만드는 게 아니라 **자율 성장(LM-E1)·영지와 소송(LM-E2)·협상(LM-E3)·위임(LM-E4) 위에 얹힌다.**

## D. 순서 제안
1. 지금: 영주 모드 뼈대 마무리(엔진 LM-E4·E5, 렌더 LM-R1~R3) → **사용자 G-LM 플레이**
2. 그다음 **LM-E6 직업 확장**(데이터화 + 작업장 원형 + 서비스 용량 + 거리 이름) — 운송 용량이 지금의 헛간 물류 문제를 같이 푼다
3. **LM-E7 가솔과 봉사**(가신·소집·국왕 원정·사적 분쟁·해안 준비) — 사적 분쟁이 LM-E2 소송의 "점유 집행"을 완성
4. 그림은 각 단계 지시서가 나갈 때 같이 의뢰(미리 쌓지 않음)
