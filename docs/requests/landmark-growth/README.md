# LANDMARK-GROW: 랜드마크 44장 연결 자료

**렌더 B 데이터 준비 완료, 게임 설치 0장.** 엔진의 성장 단계와 넓어질 터가 정해진 뒤 이 자료로 런타임 계약을 만든다. `assets.prepared.json`은 설치 전 자료이며 현재 `ArtBundle`이 아니다. 필수 런타임 해시와 승인된 발판을 빈 값 대신 지어내지 않았고, 현재 로더는 이 자료를 거부한다.

정본은 `assets-inbox/landmarks/rework-20261003/records/manifest.csv`다. `source-manifest.csv`는 그 바이트 그대로다. 기존 확정 32장과 다리·길드홀 교정 12장, 모두 44장·여름/겨울 22쌍이다. 폐기된 교정 전 12장은 제외했다. 원본·현재 게임 그림·설치 장부를 변경하지 않았다.

## 단계와 발판

## 엔진이 정할 연결 계약

아래는 **요청하는 의미**이며 이미 있는 저장 필드명이 아니다. 렌더 B는 엔진의 규칙·저장을 수정하지 않는다.

1. 같은 장소의 같은 건물을 식별할 영속 id와 계열·현재 완료 단계. 청원 승인만으로 완성 그림을 보일지, 공사 완료 뒤 보일지는 엔진이 정한다. 취소·파괴·재건에도 단계의 의미가 남아야 한다.
2. 해당 단계에 실제 확보된 발판, 위치와 방향. 확장 구역이 집·길·강과 충돌하거나 아직 확보되지 않았으면 이전 그림을 유지한다. 그림의 요구 면적과 실제 점유가 맞지 않을 때 축별로 눌러 맞추지 않는다.
3. 같은 건물의 기준점이 다음 단계에도 움직이지 않도록 기준 타일과 문턱·문 통로·강 양안 기준을 제공한다. 출처의 `anchorKind`와 `expansionRule`은 그대로 보존했다. 이 기록만으로 점유 확장을 허가하지 않는다.
4. 문은 통행 구멍과 벽의 접속점, 다리는 양안과 축·수면 칸 수를 제공한다. 수면 3칸 외 길이에 이 그림을 늘이지 않는다. 다른 축에 대한 그림이나 회전·가림 검증 없이 적용하지 않는다.
5. 길드홀·여관이 기존 소품/집을 대신하는지 별도 대상으로 남는지 결정한다. 중복 그림을 방지할 원래 대상 id가 필요하다.

칙허·교회 증축·후원·혼인·부·장 전환 중 어떤 조건으로 어떤 단계를 여는지는 `LANDMARK-GROW` 엔진 작업이다. 이미 있는 사건 효과 하나를 임의로 성장의 충분조건으로 취급하지 않는다. 전환 중 파괴·취소·저장/불러오기와 같은 seed/명령의 결정론도 엔진 쪽 판정 대상이다.

## 런타임 그림 계약으로 옮길 때

| 준비 자료 | 기존 `LandmarkEntry` 대응 |
|---|---|
| `packId: core` | 묶음 `packId` |
| `id`, `family`, `growthStage`, `season` | 같은 이름의 값. 설치 때 충돌 없는 core id를 확정 |
| `imageDimensions`, `source.inboxFile` | 파생 설치 파일의 `image.width/height/url` |
| `source.sha256` | `provenance.sourceSha256`; 설치 파일을 만든 뒤 실제 `runtimeSha256` 기록 |
| `geometry.pivot/scale` | 같은 값, `allowMirror: false` |
| `geometry.sourceFootprint` | 엔진 점유 확인 뒤 `geometry.footprint.width/height`로 depth→height 매핑 |
| `engineFootprintApproval: unresolved` | 아직 `expansion`으로 바꾸지 않음. 확인되지 않은 `approved-footprint` 금지 |
| 빈 `rules` | 엔진 완료 단계·계절·대상 사실을 읽는 선택 규칙을 연결 때 추가 |

겨울판은 눈이 포함된 **완성 그림**이다. 기존 지붕 눈 층을 다시 얹지 않는다. 잎처럼 실루엣이 바뀌는 요소를 임의로 섞지 않는다. 단계와 계절 선택을 연결할 때 실제 본체·부착물·그림자·가림도 함께 확인한다.

기존 교정 증거는 `assets-inbox/landmarks/rework-20261003/records/GEOMETRY_AUDIT.md`와 `proofs/`에 있다. 다리 +26.565°·길드홀 −26.565°, 다리 양안 잔차 약 0~3 세계 픽셀(관측 불확실성 ±1~2)은 **과거 정적 합성 결과**다. 이번 준비가 실제 게임 통행·가림·성장 재생을 통과했다는 뜻이 아니다.

## 연결 시 검증할 장면

같은 저장·카메라, 여름/겨울과 줌 1.0/0.6에서 단계 직전·직후를 비교한다. 확장이 가능한 경우와 이웃 건물/길 때문에 불가능한 경우, 저장 후 다시 불러온 경우를 포함한다. 다리는 수면 3칸과 다른 길이, 두 축과 보행·수레의 진입/이탈, 문은 열림/닫힘·벽 접속·앞뒤 가림을 확인한다. 소스→설치 파일→계약→선택→로드→그리기→실제 캡처가 이어진 뒤에만 설치 장부를 채운다.
