# 2차 검수 기준

- 후보 초상92장: 256px와 실제96px로 얼굴·실루엣·손/소지품·머리쓰개와 의복을 확인.
- 노화: 같은 골격/눈 간격/코/입/귀, 청년·장년·노년 구별, 아이→성인의 턱·목·어깨 성장.
- 소지품: 계획값과 실제 관찰값을 각각 저장. 없음은 손에 들거나 인물 고유 식별용으로 제시하는 소지품 없음. 옷의 단추·여밈 브로치·머리쓰개는 복식으로 취급. 순례 배지는 지정된 소지품이며 기타에 포함. 빈손은 손이 화면 밖이어도 소지품이 보이지 않으면 해당.
- 책·두루마리: 32명 기준 대표단계와 전체92장 기준 둘 다25%이하. 동일 인물은 단계마다 지정된 소지품을 유지해집계. 실제 다른 물건이면 재검수·수정 또는메타데이터 정정.
- 기타: 인물별 서로다른20종. 모델이 추가책/서류를 끼워 넣으면 결함으로 수정.
- 계급: 물건에 기대지 않고 옷/모피/머리쓰개/자세로 읽히는지 확인. 단일 AI 자체평가는 사람 대상정확도 보장이 아님.
- 다양성: 승인1차 청년32 + 이번청년32=64명에서 가장닮은세쌍 명시. 파일럿36명비교도 확인그림2보조패널로 유지.
- 정량속성배정은 의도된분포이지 표정·머리쓰개에대한 객관적 식별 정확도가아님. 실제 관찰 한계는 별도기재.
- 문서·코드 검증과 시각검수, 실제 게임통합을 구분. 게임에 설치하지않음.
