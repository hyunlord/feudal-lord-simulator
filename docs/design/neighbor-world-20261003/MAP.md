원본 손그림 지도 위 거점18곳. 좌표는1600×1000 왼쪽 위 원점의 하단 중앙 접지점이다. `map-placement.jpg` 숫자는 h01~h18과 같다. 원본 지도는 수정하지 않았다. 원본 경로·SHA, 노드·연결선·경로는 `world/map.json`에 기록했다.

본류 중앙 여울을 북·남 사이의 기존 연결로 해석한다. 남쪽 지류를 넘는(770,455)→(810,465)다리는 **제안**이며 원본에 있던 구조물이라고 주장하지 않는다. 동부(1130,485)→(1130,540)나루도 **제안**이다. 지도에 없는 장원 진입로는 옅은 파선, 제안 도하점은 붉은 파선이다. 각 길의 실제 그려진 지형과 신규 설계 구분은 JSON kind에 보존했다.

정상 여울0–0.05일, 다리0–0.02일, 나루0.02–0.15일, 범람0.25–1일 지연은 모두 게임 추정이며 위 표에 더하지 않았다. 심한 홍수는 일수를 무한히 늘리는 대신 연결 폐쇄로 처리하고 그래프를 다시 계산한다. 다리와 나루가 승인·설치되지 않는 시작판에서는 해당 간선을 비활성화하고 중앙 여울 경유의 남부 연결 또는 별도 도하 허가를 설계해야 한다. 이번 후보 지도는 두 제안 도하점이 존재하는 구성이다.

북부는 구릉과 숲 가장자리, 중앙은 강·장터·농경지, 남부는 지류와 개간지로 묶인다. 해안·항구·배를 통한 본류 운송은 이 삽화에서 확정하지 않는다. 지도 마커는 기존 manor/market/abbey96px를40px로 균일 축소한 위치 확인용 조립이며 새 건물 그림을 생성하지 않았다.

13번 Miller의 자산에는 방앗간 권리가 있지만 기존 map_mill 그림은 물레바퀴를 그린다. 이를 곡물용 물방앗간으로 단정하거나 풍차로 재명명하지 않는다. 거점은 현재 중립적 시장 가옥 표식으로 표시한다. 축융용 수차시설의 개별 위치·물길과 곡물 풍차 표식은 별도 제안이며 이 지도에서 확인했다고 주장하지 않는다.
