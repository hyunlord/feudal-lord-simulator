# Wave15 소품·효과 자체 검수

상태: candidate. 게임 미설치. 담당12장 완료.

- 원본5종: 캔버스40×24,36×20,24×16,28×18유지. 네이티브 계절 편집을 원본의 유효 영역에 맞추고 유효 RGB 확장 후 원본 알파 복원. 원본 대비 알파 차이0이라 외곽·접지 위치 동일.
- 그루터기·돌 눈은 상부에만 얇게, 풀은 서리 낀 황갈/가을 황갈로. 원본 runtimeScale1 기준0.6에서도 밝은 윗면/황갈색 변화가 보임. 작은 풀 자체의 세부 식물학적 판독은 목적이 아님.
- 새 계절 데칼5장96×48RGBA, 사방8px알파 여백 위반0. 눈더미A는 왼쪽, B는 오른쪽 덩어리. 긴 원본 눈더미의 높이를 늘리지 않고 비율 유지 축소. 앵초4개/데이지5개 큰 꽃으로 모래 잡음 방지.
- 낙엽시트256×96:4프레임64×96. 네이티브 생성 네 그룹의 실제 낙하·회전 단계 유지. 각프레임 해시4종, 상단에서 하단으로 하강 육안 확인. 갈색·황갈·금빛, 원색빨강 없음.
- 눈시트512×128:4프레임128×128. 네이티브 생성 눈입자 그림을128px로 축소, 알파0.55배, 프레임마다3px우측/7px아래 순환 이동. 새 입자는 코드로 그리지 않음. 각프레임 해시4종, XY끝점RGBA최대차0. 옅은 눈, 폭설 없음.
- 검수그림 details-qa.png와 details-fx-qa.png에서 녹색 바탕 위 확인. 일반 소품 시트의 오른쪽0.6은 작은foliage 실제scale1기준이며, 새96px데칼의 게임scale0.5는 최종리더 장면에서 별도 확인 대상.
- 엔진 애니메이션 cadence/loop보간은 미설치로 미검증. 낙엽0→3은 낙하 구간이며 재시작 시 emitter이동/개별수명 설정 필요.
