# 남은 문제 7종

v4 정본 편집·정적 검증과 실제 게임 등록은 별개다. 아래는 삭제하거나 가짜 효과로 메우지 않은 제한이며, 모든200개 enabledInEngine=false를 유지한다. 사건별 상세는 MERGE.md와 records/DECISIONS.json이다.

| ID | 남은 문제 | 범위와 처리 |
|---|---|---|
| R1 | 등록 중간명세 평가·바인딩 어댑터 미구현 | A의 READ_MODEL·선택별 대상·명령 계약은 실행 엔진이 아니다. 등록기200개는 계속미설치. unsupportedFilters가 있는111개도 차단 유지. A가 쓰는 이름을 새 GameState 필드라고 주장하지 않는다. |
| R2 | 유효 소송 후보 조인·재탐색 의미 미정 | 009·032·033·053: suit/claim을 함께 연결하고 선택 가능한 증거가 있는 후순위 소송까지 찾는 계약 필요. `stable_first_after_required_predicates`가 이것을 보장하는지는 불명확하다. 독립 검수 IR-01이며 실행 중 결함을 실측한 것은 아니다. |
| R3 | ‘행동 하나+보류’와 실질선택2 정책 충돌 | 009·032·033·038·053 및075·143·153, 기존020·024 등의 단일 실효 선택 상황. 보류는 무명령·무결과로 남기고 A 최소2를 유지한다. 연도창은 열려도 마지막 선택 수 검사에서 숨겨질 수 있다. 정책 예외를 허용할지와 엔진 구현은 별도 결정이 필요하다. |
| R4 | 복합 명령의 실패·원자성 판정 | 004/c·030/divide·049/share 등17개 선택은 blocked_until_atomic_adapter. A의 기존 거절 경로 검토를 승계한다. 새 상태 참조가 생겼다는 이유만으로 명령 성공을 판단하면 안 되며, 일부 효과만 적용한 것을 전체 성공으로 처리하지 않는다. 이번에 실제 엔진 재현은 하지 않았다. |
| R5 | 실제 생활 맥락·효과·새 청원 수명주기 미지원 | 135 중재,161 사업 필요,166 급류/교량,181 후견 재산 수선·대여·관리인 권한 등 A의 기존 부채 보존. 057/058의 새 generic PetitionDef와011 R05 비교기 등도 계약만 있다. 154의 verifiedProblemCaseId는 검증된 맥락이 필요하다는 미구현 요구이며 현존 필드가 아니다. 전체182개 선택의 blocked_unsupported_effect를 보존했다. |
| R6 | 역사 출처·편년의 기존 유보 | 081·189·195에 대한 A R06 출처·편년 한계를 보존했다. 특히195의1440~1450은 창작 집필 창이지 편지 작성연도 확정이 아니다. 이전 사료 검토를 승계했으며 원전200편 재감수는 수행하지 않았다. |
| R7 | 실제 실행·빈도·저장·키 이전 검증 | 150년 노출 빈도, 클릭 직전 조건 재검사, 명령 성공/실패, 저장복원과 새 dedup 키 이전은 미검증. 새로운 실제 suit/case만 다시 후보가 되며 식별 못 한 옛 예약은 fail-closed로 보존해야 한다. 정적 경계77건 통과는 이 실행 검증의 대체가 아니다. |

독립 검수 IR-02(013 후임ID 연결 누락)는 정본에서 수정했다. 지원되는 replacementId를 이미 생존 검사한 후임에 연결했으며 새 효과를 만들지 않았다.
