# E10 — 지붕 눈·빈집 분리 후보

- 주택 원본 L0 153×153, L1 139×139, L2 137×137, L3 142×142, L4 161×161을 그대로 유지했다. 각 눈/판자 레이어는 원본과 같은 캔버스, 원본 위 (0,0) 위치에 그린다. PNG에는 피벗 메타데이터가 없으므로 임의의 피벗 숫자를 발명하지 않고 소비자의 원본 피벗을 상속한다.
- 내장 imagegen edit 10회. 매번 해당 집 원본을 입력했고 집 본체를 제외한 눈/판자만 요청했다. 생성 원본 10개와 최종 프롬프트 10개를 보존했다. 제공되지 않은 모델 버전/seed는 기록하지 않았다.
- 생성 결과의 좌표가 원본에 자동으로 맞았다고 가정하지 않았다. 원본에서 직접 잡은 지붕 능선/처마 선분과 문/창 구역을 `overlays-anchors.json`에 기록했다. 생성 재료 일부를 아핀 변환하여 각 구역에 등록하고 명시적 마스크로 잘랐다. `overlays-process.cjs`가 전체 처리와 실제 합성 검수판을 재현한다. 주택 본체는 최종 레이어에 포함되지 않는다.
- `sources/overlays/*-mask.png`는 좌표 마스크, `*-composite-4x.png`는 실제 원본+오버레이를 4배 확대, `*-scale-qa.png`는 원본 배율1/.6/.3이다. 캔버스 치수만으로 정렬을 주장하지 않고 실제 겹침을 시각 검수했다.
- L2 대표 두 장의 배율 검수 후 나머지 8개를 생성했다. 눈은 원본 .3에서도 선으로 식별되며 판자는 .3에서 결 차이가 줄어든다. 이 주택 원본은 이미 작은 런타임 해상도이므로 proof03은 주택1/.6, 신규소품.5/.3을 명시한다. 보편적 128px 원본과 동일 단위라고 해석하지 않는다.
- 마스크 밖 유효 알파 0픽셀, 10개 최종 RGBA 존재와 SHA256을 `overlays-verify.cjs`로 확인했다. 이 수치는 정한 구역 밖 픽셀 없음의 증거이며 미술적 정렬 승인이나 실제 게임 통합을 대신하지 않는다.
- `proofs/03-winter-street.png`는 겨울 거리 독립 합성: 눈5 + L2 판자1 + L1 지붕틈 약한연기1 + 서리3변형. 굴뚝 없음. 게임 코드/원본/설치 변경 없음. 후보 상태, 실제 게임 가림·DPR·동적 계절 검증 별도.
