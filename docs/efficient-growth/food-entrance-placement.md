# 생산시설보다 먼저 실제 운송 출입구를 비교

기준 `d4fff05`의 정상 기본 도시를 세 번째 방앗간 결정 직전인 239,640틱까지 재생했다. 가설은 ① 진입로 없는 가까운 필지 누락, ② 성벽·서비스 자리 제한, ③ 배치 뒤 도로 변화였다. 기존 후보와 접근로 투영 모두 (50,39)의 16칸 운송로를 골랐다. 가까운 필지도 이미 다른 쪽 도로가 있어 접근로 계획이 끝나버렸다. 따라서 단순한 미연결 필지 문제가 아니라 **어떤 출입구를 쓰는지 비교하지 않는 문제**였다.

같은 실제 상태에서 (41,38) 도로 한 칸과 (41,37) 방앗간은 정상 비용·공사 접근·성벽·서비스 검사를 통과했고, 밀과 빵 운송이 곡창과 같은 도로 칸을 사용했다. 두 변형을 같은 120틱 뒤 건설하고 조언자 없이 12,000틱 진행했다. 마지막 2,400틱의 기존 배치는 빵 생산180·식사180/192·원료 대기25%, 가까운 출입구 배치는 생산209·식사192/192·대기13.07%였다. 자원 주입·시설 수 증가·경제 변경은 없었다.

**변경.** 기존 곡창 둘레의 합법적인 미건설 출입구를 정상 도로 계획과 지불로 투영한다. 실제 원료가 있는 곡창까지의 경로를 생산 후보와 함께 비교하고, 공사·성벽·서비스·잔여 비용을 검증한다. 개선이 있으면 첫 도로만 건설하고 다음 결정에서 다시 평가한다. 후보 순서와 실제 건설은 같은 원료 공급원을 기준으로 한다. 별도 확장 보존 도로가 필요한 필지는 즉시 건설 근거에서 제외한다. 초기 원료가 없는 식량망은 기존 최소 초기화로 돌아간다. 새로운 거리 상한·경제 비율·운송 방식은 추가하지 않았다.

**검증.** 집중 회귀345개·TypeScript 통과. 7개 전용 검사는 정상 도로→유료 공사 재평가, 빈 두 번째 곡창, 무원료·무자금, 이미 최단인 출입구, 통로 보존 도로가 필요한 후보를 포함한다. 수정된 정상 조언자는 실제 239,640틱에 도로(41,37), 다음120틱에 방앗간(41,36)만 지었다. 추가12,000틱의 마지막 창은 빵208·식사192/192·원료 대기13.53%, 인구256이었다. 이는 저장 상태 후속 실행이며 처음부터의 엄격 합격이 아니다.

첫 새 기본 실행은 후보 정렬과 실제 건설 기준 불일치가 리뷰에서 확인돼 마지막 보고48,000틱에 중단했다. 원본 진행 기록을 보존하고 중단으로 표시했다. 정렬 일치와 확장 도로 제외 수정 후 위 회귀를 통과했다. 새 기본8필지 엄격 검증과5개 지도 검증은 같은 QA 담당자의 확정 커밋 실행으로 남는다.
