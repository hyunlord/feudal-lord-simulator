# 혈통 초상 본 제작 1차 — 후보 묶음

게임에 설치하지 않은 초상 후보다. 최종 검수 결과는 `REPORT.md`를 읽는다. `index.html`에서 전체 이미지를 열고, 개별 파일 링크는 `IMAGE_LINKS.md`를 사용한다.

## 구성
- L3 영주 가문 A, L4 양모·직물 상인 가문, L5 reeve 가문: 각38장, 합114장.
- 공통 풀: 아기14·걸음마12·어린이14, 합40장. 각 단계 남녀 반반.
- 추가 교정: 파일럿2 L1_203·204, L2_201·202·203·204의 `_baby-v2.png` 6장.
- 합160 PNG, 256×256. 공식 확인 그림4장과 CSV160행.

명시된 가족 구성을 합하면 각36장이다. 확인 그림2의 청년30명을 구성하기 위해 창시 부부 청년2장을 각 가문에 추가하여 각38장으로 맞췄다. 마지막 사용자 지시의 아기6장을 별도로 더했다. 추가 혈통이나 인물을 임의로 확장하지 않았다.

## 기록·재현 범위
- `assets.csv`, `records/assets.json`: 인물·부모·연령·혼인·복식·표식·실제 프롬프트와 참조·후처리.
- `TRAITS.md`: 가문 공통3개, 개인 차이3개 이상, 단계별 혼인과 복식.
- `raw/`: 채택 전 시도 포함 생성 원본. 최종 납품 수량에 넣지 않는다.
- `references/`: 프로젝트 자체 그림과 의뢰서, 생성에 사용한 참조 스냅샷.
- `records/*qa*`, `*review*`, `blind-results.json`: 기술 검사와 독립 시각 판정. 교정 전 실패는 이력으로 남긴다.
- `SHA256SUMS`: 파일 무결성 확인용. 동일 프롬프트의 재생성 결과가 같다는 보장은 아니다.

생성 도구가 제공하지 않은 모델 버전과 seed는 추정하지 않았다. 최종 PNG는 원본에서 균일 축소했으며 얼굴을 절차적으로 합성하거나 도형으로 대체하지 않았다. 나이·닮음·개인 구별은 시각적 추정이며 실제 사람 대상 인지 실험이 아니다. 정적 후보 검수는 게임 화면 통합·성능 검증을 대신하지 않는다.
