# 사건 선택 의미 감사 v4.2

기준: 본선 codex/phase15-organic-ground, HEAD 9181ce03394f8be064c131d1ddfae121249e9694 (2026-10-06).

현재 실행 지원 사건 **86개, 선택지 270개**를 원고·실제 명령·카드 표시 경로와 대조했다. **수정 30 / 유지 18 / 보류 권고 38**. 30개 중 명령·실행 조건까지 바꾼 것은 5개, 나머지25개는 카드 문구·효과 설명 수정이다.

## 읽는 순서

- EVENT_AUDIT.md·CSV: 사건별 현재 효과, 고민의 가시성, 판정.
- CHOICE_AUDIT.csv: 선택지270개 각각의 현행 결과·돈/관계 위주 여부·전후 대가.
- EVENT_AUDIT.json: 모든 선택의 수정 전/후 문구·효과·명령 대조. after=null은 미수정 또는 보류.
- events-v4.2.json: 변경 사건30개 전체 레코드만.
- registry-v4.2.json: 같은30개 ID의 등록기 짝. 25개는 실행 내용 그대로이며 출처 메타데이터만 갱신.
- HOLD_RECOMMENDATIONS.json: 보류 권고38개와 이유. **권고 문서이므로 현재 엔진에서 자동으로 꺼지지 않는다.** 카드 속 '미루기' 선택과도 다르다.
- proofs/CARD_COPY.md: 수정 카드의 실제 소비 필드 읽기판.
- proofs/: 최신 엔진 지원 목록, 독립 검수, 실행 검사 및 검증 기록.

## 적용 계약

v4 → v4.1 → v4.2 순서로 사건 ID를 대체한다. 각 delta의 event와 registry ID 집합은 같아야 한다(scripts/registryCanon.ts). 새 ID는 없다. 전체 정본은215개로 유지된다. 이 ZIP을 단순 복사해도 엔진에 자동 등록되지 않는다. 현재 CANON_RELEASES는 v4.1까지다. 설치 담당자가 v4.2 등록과 보류38개 편성 제외를 함께 판단해야 한다. 본 작업은 코드·본선 파일·등록 목록을 수정하지 않았으며 커밋·푸시하지 않았다.

## 판정 경계

돈을 쓰는 선택 자체를 얇다고 보지 않았다. 그 돈으로 어느 소송을 진행하고, 누구에게 맡기며, 언제 어떤 재료를 받는지가 실제 상태와 카드에서 이어지는지가 기준이다. 정책 가중치나 종류별 장려금만으로 특정 가구 구호·왕실 권리·임금 조정을 약속하면 보류했다. 장려금은 여러 사업의 가능성을 바꾸는 조건이며 완공 명령이 아니다.

세율 카드의 결과는 도시 전체 징수 기준이며 새 장날·좌판 입주를 뜻하지 않는다. 목재 카드는 공동 재고의 매입 과정이며 불탄 집에 자동 배분하지 않는다. 이들 경제 구조의 반복은 남아 있다. 다르게 느껴지는 사건인지와 재미 개선은 실제 플레이에서 다시 확인해야 한다.

LM-E9b 보고서70개는 v4.1 이전 기준이다. 최신 실제 평가기 지원86개를 감사했으며 옛3회 실행에서 관측된 고유40개만으로 범위를 줄이지 않았다. 관측40에는 invalid 제시 이력도 포함한다. 새로운125년 분포나 브라우저 플레이는 측정하지 않았다.
