# PC 정본과 모바일 제안의 충돌표

정본: 지정 가지 원격 커밋 843e52d18c0cadb272d9f54544788db723ee13dc의 docs/design/game-principles.md v0.2 및 extensibility.md. Downloads 원본과 비교했으며 승인 문구 외 규칙 본문 차이는 없었다. foundation/lord-mode/trades-and-force는 클론 시작 eeccc92a에서 읽었다. 아래는 원본 규칙 변경 승인이 아니라 **새 제품에서의 차이 제안**이다. 원본 파일은 수정하지 않는다.

| 정본 원칙 | 충돌/위험 | 모바일 제안 | 검증/남는 한계 |
|---|---|---|---|
| A1 조건을 만들고 반응 | 자동 전투가 직접 조작 게임이 되기 쉬움 | 목적·보급·태세만 지정, 가구가 건설·직업 선택 | 직접 건설/병사 드래그가 없어도 한 바퀴 가능한지 |
| A2 세계는 스스로 삶 | 접속 때만 생산이 생기는 클릭 보상 | 서버 시간 정산, 이웃도 같은 자원·명령 규칙 | 로컬 시제품은 서버 상시 세계 검증 아님 |
| A3 같은 규칙 | 결제·접속·봇 보너스가 승패를 조정 | 공통 규칙/공개 보호, 성능 상품 금지 | 봇과 사람 명령 횟수·시점 동일, 외형 flag 해시 시험 |
| A4/P-C1 이유와 대안 | 화면에 그럴듯한 원인을 나중에 붙임 | 실제 후보 점수와 지출·전투 경로 기록 | 로그에서 UI 이유 역추적 |
| A5 시간의 누적 | 시즌 경제 리셋이 도시 기억을 지움 | 경쟁판은 기한제, 가문·도시 기록은 보존 | PC 장기 경제 연속성과 다른 제품 규칙; 사용자 확정 전 제안 |
| A6 늘 옳은 답 없음 | 혼합이 모든 장점을 싸게 얻거나 단일 군사가 지배 | 지원 예산·노동·유지비·체감·수송 병목 | 홀드아웃 리그, 자유 혼합 도전자와 성장 시점별 분석 |
| A7/P-Y2 역사 | 모바일 수개월 시즌과 15분 성장 압축 | 가상 변경을 배경으로 역사 수치는 차용 범위 명시 | 압축 시간은 역사 시뮬레이션 정확도 주장 제외 |
| P-T1 한 해2~10 결정 | 짧은 접속마다 사건을 강요하면 밀도 폭증 | 모바일 시계/팩 별도로, 방문당 중요 결정1~2 | 원 PC의 연간 밀도 관문을 통과했다고 말하지 않음 |
| P-T2 결정에서 멈춤 | 여러 이용자가 공유하는 서버는 일시정지 불가 | 선례/대리인/응답 창, 도시는 계속 진행 | 기한·미응답 처리와 대가를 사전 공개 |
| P-T3 선례 | 편의 구독의 핵심 판매 대상으로 변질 | 반복 위임은 무료, 유료는 외형/기록 | 무료 사용자 동일 명령 처리 능력 |
| P-T5/T6 기간 설정·상한 | 서버 원장/죽은 인물/리플레이 무한 증가 | 규칙판·기간 설정, 보관/요약 정책 | 장기 저장·메모리 증명은 R03 추정과 후속 실측 구분 |
| P-D1/D3 동등 선택·대가 | 추천 버튼 하나가 정답처럼 보임 | 동등 버튼과 실제 비용, 예시 배분은 자유 수정 | 이름 가린 검수에서 이유 이해 확인 |
| P-D4 엔진 예측 | 화면의 축 설명이 계산과 달라짐 | 같은 모델을 상태 복사 실행 | UI/봇/전투 모델 중복 구현 금지 |
| P-E1/E4 보존·정수 | 과금/리플레이가 재고를 복제 | 원장·정수·중복 지급 방지 | 로컬 불변식과 서버 동시성 시험은 별개 |
| P-E2/E3/P-C4 물류·생존·가용량 | 예약 재고를 사용 가능으로 표시 | 생존/계약 비축 보호, 운송 부족이 거래 제한 | 약탈 예약·묶인 식량 제외 검사 |
| P-R1~3 위기·회복 | 오프라인 약탈로 복귀 불가 | 예고·누적 손실 한도·복구 경로 | 숨은 패자 지원은 금지, 같은 조건이면 같은 도움 |
| P-L1~3 권리·약속 | 성을 이기면 권리가 자동 이전 | 길목 점유와 계약상의 수입권을 구분 | 시제품 간략 권리만; PC 소송 전체 재현 아님 |
| P-H1~3 가문/죽음/상속 | 15분 프로토타입에 왕조를 다 넣기 어려움 | 인재 ID·가구 귀속 우선, 장기 왕조는 제품 후보 | 시제품에서 상속까지 구현했다고 주장하지 않음 |
| P-X1/X2 결정론·우연 표기 | 서버/클라이언트 버전·순서 차이 | 판·seed·명령·초기 상태 해시 고정 | 재실행/저장 왕복, 우연 선택 표기 |
| P-V1/V3 시각 흔적·실제 장면 | 정책색만 달라진 예쁜 도시 | 시설 구성·밀도·길·활동이 실제 상태 반영 | 이름 가린 동일 시작3방향 캡처 |
| P-M1/M2 데이터·배경무관 | 원 엔진이 이미 완전한 팩 구조라는 오인 | 시제품의 규칙/팩 분리, 원 엔진 재사용 범위 별도 | graft+실제 소스로 R03 판단 |
| P-S/P-U 가문·대영주 사다리 | 짧은 시즌 전쟁이 사람 중심을 대체 | 소수 청지기/계약 상대를 남기되 왕국 단계 제외 | PC를 대체하는 완전판이라고 부르지 않음 |
| P-G1 하나의 승리 없음 | 리그 승률과 시즌 순위가 유일 목표로 오인 | 시험 목적별 점수·개인 야망을 분리 | 군사 우승으로 신앙/학문의 모든 가치 판정 금지 |
| foundation4 전술/정복 제외 | 공간 전투·동맹 영토는 원래 범위 밖 | 모바일 별도 모델/제품, 본편 엔진 강제 변경 없음 | 별도 소스·리소스·일정. PC 개발 관문에 작업 추가하지 않음 |

가장 큰 충돌은 공유 서버의 멈출 수 없는 시간, 시즌 리셋, 전쟁 중심의 외적 목표다. 이 세 가지는 UI로 가릴 수 없으며 R05에서 차별점의 이익과 함께 비용으로 평가한다. 원칙을 어기는 기능을 원본 정본에 몰래 넣지 않는다.
