# 실패 사다리 3~4단과 장 이어하기 명세 (FAIL-3)

지시서: FAIL-3 실패 사다리 3~4단 + 장 이어하기(캠페인)(엔진 세션, 5시간). 근거:
- [플레이어 흐름 설계서](player-flow.md) 7절(실패 사다리 표)·8절(종반)
- [압력 명세](flow-pressure.md) FP-3(1~2단)
- [1장 명세](flow-chapter-one.md) FC-5(장 끝)
- 권리·정치 조사(첨부 `research_rights_politics.md`: 권리 등록부·회수 경로·원한 기록)

결정: [결정 목록](../decisions/README.md) FL1~FL10. 조항 번호(FL-*)는 시험 이름에 쓴다(`tests/failureLadder.test.ts` F1~F8).

실패는 끝까지 있다. 3단 쇠퇴는 권리를 잃고 칭호가 강등된다. 4단은 영주 가문이 물러나고 새 가문으로 이어진다. 게임 오버는 없다. 그리고 1장이 끝나면 같은 도시로 2장을 이어 간다.

## 영주의 권리와 칭호

- **FL-1 영주의 권리(권리 등록부)**: 영주는 세 가지 권리로 돈을 받는다(`lordRights(state)`). 권리마다 상태는 `held`(보유) · `suspended`(상위 영주 관리) · `seized`(상인 엘리트 인수)다.
  - `market`(시장 좌판세): 시장이 서 있을 때.
  - `tolls`(통행세): 목책·석벽의 성문이 있을 때.
  - `mill`(방앗간 사용료, suit of mill): 시나리오의 제분 독점이 켜져 있을 때.
  - 잃은 권리의 돈은 금고로 오지 않는다. 기간 마감이 그 수입을 올리지 않는다. 상인에게 준 시장권(FC-4 `rights[]`)은 따로 남는다.
- **FL-2 칭호**: 칭호는 시대에서 온다. 촌락은 장원 영주(`manor`), 목책 시장도시는 시장도시 영주(`market`), 석벽은 성읍 영주(`borough`)다(`lordTitle(state)`).
  - 강등 중에는 한 단계 아래로 부른다.
  - 장원 영주는 더 내려갈 곳이 없어 "몰락한 장원 영주"다(`demoted: true`).

## 3단 쇠퇴

- **FL-3 조건**: 계절이 시작될 때(표본 틱) 다음 둘 중 하나면 3단에 든다.
  - 황폐: 사는 집과 빈 집을 합친 집 가운데 황폐한 집(FP-3 2단 `abandonedTick`)이 30 %(`derelictPermille` 300) 이상이다. 집이 8채(`minHouses`) 이상일 때만 센다.
  - 미납 누적: 갚지 못한 유지비(미납 계정)가 서로 다른 4기간(`arrearsPeriods`) 이상에 걸쳐 있다.
  - 3단은 한 번에 하나다. 이미 3단이면 새로 들지 않는다.
- **FL-4 권리 상실**: 3단에 들면 권리 하나를 잃는다. 조사의 회수 경로 가운데 둘이다.
  - 미납이 원인이면 **위반에 따른 정지**(breach-based suspension)다. 상위 영주가 권리를 맡는다(`suspended`, `by: overlord`). 통행세 → 방앗간 사용료 → 시장 좌판세 순으로 보유한 첫 권리다.
  - 황폐가 원인이면 **일방 인수**(unilateral seizure)다. 상인 엘리트가 권리를 가져간다(`seized`, `by: merchants`). 시장 좌판세 → 방앗간 사용료 → 통행세 순이다.
  - 둘 다면 미납을 원인으로 본다.
  - 보유한 권리가 없으면 잃는 권리 없이 칭호만 강등된다.
- **FL-5 칭호 강등과 기록**
  - 3단에 들면 칭호가 강등된다.
  - 원장에 `decline.entered`(원인·잃은 권리·가져간 쪽)가 남는다.
  - 계절 결산에는 사건 `lordship_declined`가 남는다.
- **FL-6 회복(재협상 청원)**
  - 3단의 원인이 풀리면(황폐 < 30 %, 미납 < 4기간), 권리를 가져간 쪽이 **복원 청원**을 낸다(`restore_right`, 청원자 `overlord` 또는 `merchants`). 권리를 잃지 않았으면 청원자는 상인이다.
  - 수락: 복원금 100d(`restoreFee`)를 내고 권리와 칭호를 되찾는다. 3단이 끝난다(`decline.recovered`).
  - 값을 깎아 수락: 50d를 내고 권리만 되찾는다. 칭호는 한 해 뒤에 돌아온다.
  - 거절: 아무것도 내지 않는다. 권리는 잃은 채이고, 청원은 한 해 뒤에 다시 온다.
  - 금고가 모자라면 수락해도 낼 수 있는 만큼만 낸다. 모자란 몫은 미납에 넣지 않고, 권리는 되찾지 못한다.

## 4단 가문 교체

- **FL-7 조건과 결과**: 3단이 2년(8,000틱, `houseChangeTicks`) 끊김 없이 이어지면 영주 가문이 물러난다. 게임 오버는 없다.
  - 연대기·원장 `house.withdrew`("○○ 가문이 물러났다")와 `house.arrived`(새 가문)가 남는다.
  - 새 가문(`lordHouse(state)`): 순번 +1, 이름(seed 결정론, 잉글랜드 젠트리 성씨 목록), 문장 seed(`heraldrySeed`, seed와 순번의 해시).
  - 금고 절반을 잃는다(원장 `house_change`, 현금).
  - 원한 일부가 풀린다. 상인 게이지는 50 쪽으로 절반만큼 돌아온다.
  - 새 가문 보너스: 잃은 권리를 모두 되찾고, 칭호 강등과 3단이 끝난다. 미납 계정은 그대로다(빚은 도시에 남는다).
  - 물러난 가문은 `pastHouses`에 남는다(이름·문장 seed·기간).

## 장 이어하기

- **FL-8 1장 → 2장**: 캠페인에서 1장이 끝나면(FC-5 `chapterEnd{1}`) 같은 틱에 2장이 시작한다.
  - 같은 도시다. 원장·인물·권리·건물·금고는 그대로다. 1장의 요약은 `chapterEnds[0]`(연대기 쪽 포함)에 남는다.
  - 2장 상태: `politics.chapter = { number: 2, startTick, populationStart, peakPopulation }`. 2장의 달력은 1318–1347년(`CHAPTER_TWO`)이다. 1장이 1318년 전에 끝나도 2장은 그 틱에 시작하고, 1318년은 2장 사건(F2-A)의 기준 해다.
  - 준비도 재설정: 준비도는 저장값이 없고 시대마다 조건으로 센다. 그래서 장 단위 집계(시작 인구·최고 인구·연대기 창)만 새로 시작한다. 2장의 다음 시대(1337 전쟁)의 준비도는 F2-A가 채운다.
  - 2장 목표 카드: `chapterGoals(state)`가 2장의 목표(번영, FL-9)를 준다. F2-A가 석벽 대 상업 목표를 더한다.
  - 샌드박스에는 장이 없다. 1장 끝도 없고 이어하기도 없이 계속된다.
- **FL-9 승리 판정**
  - 번영(시나리오 승리 조건: 인구 140·L4 4필지·공급 90 %를 1,200틱)은 **장 목표**다.
    - 이정표 `settlement.milestones.prosperity`에 닿은 틱이 남는다.
    - `chapterGoals(state)`가 장마다 이룬 틱을 준다.
  - 캠페인 최종 승리(`settlement.outcome = "victory"`)는 5장 끝이다. 3~5장이 아직 없으므로 지금은 오지 않는다.
  - 성장 실행(가드레일)의 "승리 틱"은 번영 이정표로 잰다. 뜻은 예전과 같다.
- **FL-10 저장 v18 → v19**: `lordship`(가문·지난 가문·칭호 강등·권리 상태·3단 상태), 청원자 `overlord`, 청원 `restore_right`를 더한다.
  - v18 저장은 첫 가문(순번 1)·세 권리 보유·쇠퇴 없음으로 올린다.
  - 1장이 이미 끝난 v18 저장은 그 틱에 2장을 시작한 것으로 올린다.

## 봇

- **FL-11 3단 피하기**
  - 미납이 2기간 이상 쌓이면 봇은 유지비가 드는 새 시설(우물·시장·교회·방앗간·창고)을 짓지 않는다. 미납이 풀리면 다시 짓는다.
  - 황폐가 20 % 이상이면 새 집 대신 식량 단계를 먼저 본다(기존 식량 단계 순서, 재정착은 규칙이 한다).
  - 복원 청원에는 금고가 복원금을 낼 수 있으면 수락, 모자라면 값을 깎아 수락한다.
- **FL-12 장 이어하기 완주**: 봇은 2장에서도 같은 판단으로 이어 간다. naive 봇 변형(비축 조치 없음·우물 없음·유지비 무시)은 3단·4단에 닿는다(관문).

## 관문과의 대응

| 관문 | 판정 |
|---|---|
| F1 | 황폐 30 % → 상인 인수(시장 좌판세)·칭호 강등·기록 |
| F2 | 미납 4기간 → 상위 영주 관리(통행세 먼저)·칭호 강등 |
| F3 | 29 %·3기간은 3단이 아님, 집 8채 미만은 황폐를 세지 않음 |
| F4 | 복원 청원 수락·깎아 수락·거절 |
| F5 | 3단 2년 → 가문 교체(이름·문장·금고 절반·게이지·권리 복원) |
| F6 | 1장 끝 → 2장 상태, 샌드박스는 장 없음 |
| F7 | 1장 → 2장 저장 왕복, v18 → v19 이행 |
| F8 | 번영은 장 목표, 캠페인 승리는 5장 |
