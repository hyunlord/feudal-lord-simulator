## 1. 국왕 문장 — Wave 23 완성 채색 두 판(관문 ①)

## 2. 날씨(관문 ②)
- 엔진 날씨(`weatherAt`: normal·wet·dry·cold)마다 Wave 23 그림 층(`src/render/weatherLayers.ts`, 순수). 세계 캔버스에만 그리고 HUD(DOM)에는 없다. 땅 층(젖은 광택·웅덩이 물결·갈라진 땅)은 건물 아래, 하늘 층(색조·구름 그림자·안개·박무·먼지·비)은 물체 위.
- 한 픽셀에 쌓이는 알파 = "all" 층의 합 + max(물 층, 땅 층) ≤ 0.38(Astra 상한), 계절의 모든 틱에서(시험 `tests/weatherOverlay.test.ts`가 0–999 틱 전부 확인). 각 층은 그 그림의 `opacityMax` 이하. 움직이는 층에 먼저 배분했다.

| 날씨(틱) | 층(알파, ● 움직임) | 합 |
|---|---|---|
| wet 아침(200) | 흐림 0.06 · 이슬비 0.14 ● · 물가 안개 0.18 ● · 젖은 광택 0.05 · 웅덩이 물결 0.13 ● | 0.38 |
| wet 한창(575) | 흐림 0.08 · 폭우 0.26 ● · 광택 0.01 · 물결 0.03 ● | 0.38 |
| dry(200) | 먼지 바람 0.18 ● · 갈라진 땅 0.20 | 0.38 |
| cold(200) | 박무 0.16 ● · 높은 박무 0.12 ● · 서리 색조 0.10 | 0.38 |
| normal(200) | 구름 그림자 0.12 ● · 높은 구름 그림자 0.12 ● | 0.24 |

- wet: 계절 첫 4분의 1은 아침(물가 안개·이슬비), 450–700틱은 폭우(500–650 전부, 앞뒤 교차). 이전 Wave 9 비 겹침(알파 0.8)은 퇴역하고 비는 이 층이 그린다.
- 설정: 일시정지 메뉴 "날씨 효과(비·안개·먼지·서리·구름 그림자)" 스위치(`weatherFx`, 기본 켬). 끄면 층 0개 — 켬 대 끔 평균 차 2.85, 끔 대 날씨 없음 0.
- 캡처([weather/](weather/)): 같은 장면(seed 2 2장 상태, 호숫가와 마을), 다섯 날씨 × 줌 1.0·0.6, 그리고 줌 1.0 호숫가 원래 픽셀 잘라낸 것(품질 70). 날씨는 증거 훅(`&weather=<kind>&weather-tick=<t>`, 증거 모드만)으로 보여 주고 상태는 바꾸지 않는다.
- 판정 필요(1): 상한 안에서 비는 정지 화면에서 옅다. 이슬비 그림은 픽셀의 1.2 %, 폭우 그림은 6.7 %만 덮어서, 폭우 0.26에서 빗줄기 한 가닥이 약 22 % 보인다. 잘라낸 캡처에서 폭우·먼지·갈라진 땅·박무는 구별되지만, wet 아침과 normal은 움직임 없이 보면 차이가 작다(전체 평균 차 3 / 255). 게임에서는 비가 떨어지고 구름·안개·먼지가 흘러가서 더 잘 보인다. 선택지: 그대로 / 비 층만 상한 위로 / Astra에 더 촘촘한 비 그림 요청.

## 3. 마을 생활(관문 ③)
- `src/render/villageLife.ts`(순수, 결정론 — seed·건물 id 해시, `Math.random` 없음): 사는 집마다 가구(`householdId`)와 집 단계로 정한다.
  - 아이(14세 미만)가 있는 집 둘에 하나 놀잇감(공·굴렁쇠·나무칼), 겨울 여섯에 하나. 여자(14세 이상)가 있는 집 둘에 하나 빨랫줄, 겨울 없음. 문 앞: 노인(55세 이상)이 있으면 의자, 아니면 2단계 이상 집 셋에 하나 통. 우물마다 두레박.
  - 동물: 단계 1 닭 ×3 : 고양이, 단계 2 닭 ×2 : 고양이 : 개, 단계 3+ 닭 : 고양이 : 개 ×2. 비둘기는 2단계 이상 집 용마루, 나는 새(참새·까마귀, 겨울은 까마귀만).
  - 한 화면 동물 상한 여름 8·겨울 4(닭 무리는 마리마다 셈), 겨울은 집 둘에 하나만 동물이 밖에.
- 1.6배(`SMALL_ANIMAL_LEGIBILITY`)는 작은 동물만: 닭·고양이·개·참새·까마귀·비둘기. 소품은 Astra `displayScale` 그대로. 큰 동물은 이 묶음에 없다(ASSET-2 규칙 그대로).
- 캡처([life/](life/)): 2장 끝 마을 여름 줌 1.0(물건 16, 동물 6)·0.6·겨울 1.0(12, 4)·마당 확대 2.0. 종류별 수는 [captures.json](life/captures.json).
- 판정 필요(2): 소품 크기 — Astra 배율 그대로면 줌 1에서 2.5–6 px라 줌 2 확대에서도 겨우 보인다. 소품도 배율을 올릴지.
- 판정 필요(3): 새·동물은 표현 시계로 움직여서 일시정지 중에도 움직인다(물·연기와 같다). 멈출지.

## 4. 인물 상태 장식(관문 ④)
- `src/ui/persons/personStates.ts`(순수): 초상 틀 오른쪽 아래에 장식 하나(카드·전기·세력 쪽 96 px, 칩 48 px에 96을 2×로). 우선순위 사망 > 굶주림 > 병 > 부상 > 상중 > 아이를 얻음 > 임신 > 혼인 > 순례 > 청지기 > 집행관 > 마을 대표.
- 엔진에서 나오는 일곱: 사망(초상을 코드로 흑백 + 촛불), 굶주림(FP-3 가구 `foodShortSinceTick`), 상중(가구원의 죽음 한 계절), `child_born`(이번 계절 태어난 아이의 가구주와 배우자 — Astra `newborn`을 이름만 바꿔 설치), 혼인(원장 기록 한 계절), 청지기(직책), 마을 대표(태그).
- 엔진 자료가 없는 다섯: 병·부상·임신·순례·집행관(bailiff). 그림은 준비돼 있고 상태가 주어지면 그린다(갤러리에 열두 개 모두). 엔진에 넘긴다.
- 상태는 말로도: 칩의 줄과 버튼 이름, 카드의 "지금:" 줄, 전기와 세력 수장의 접근 이름.
- 캡처([ui/](ui/)): c01 열두 장식(96·48, 파생/엔진 자료 대기) · c03/c04 가구주와 배우자의 child_born(칩·인물 카드) · c05 사망자 전기(흑백·촛불).
