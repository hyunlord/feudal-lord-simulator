# Astra Wave8 UI P1 · 키아트 후보

## 제출 구성

의뢰서의 개별 목록 기준 **37 에셋 PNG + 확인 그림3 PNG**, `assets.csv` 37행·20열, 생성 이력·9-slice 계약·검수표를 포함합니다. 모두 `candidate`이며 게임에는 설치하지 않았습니다.

- A10: 새 화면 틀4, 이니셜 바탕3, 청원 인장3.
- B8: 계절 띠·핀·사건4·비네트·일시정지 바탕.
- C13: 오버레이 아이콘8, 지도·범례 틀2, 알림 종3. 의뢰서 C의 제목은12이나 실제 목록은13입니다.
- D6: 타이틀 배경·엠블럼·로딩3·모드 선택 배경.

## 디자인·사용 계약

첨부 UI P0 재작업본을 기준으로 따뜻한 양피지와 가는 갈색 선, 절제된 목재·인장을 사용했습니다. 새 에셋에는 텍스트·숫자를 넣지 않았습니다. 확인 그림의 기존 HUD 글자는 제공된 참조 캡처에 원래 포함된 내용입니다. 새 틀의 역할 비교에는 이름을 추가하지 않았습니다.

6개 틀은 지정 크기의9-slice 원본입니다. 장면 슬롯·초상 원·장식을 늘이지 않도록 비대칭 inset을 사용합니다. **원본보다 작게 줄이는9-slice는 지원하지 않으며**, 확대 시 고정 장식은 원래 위치를 유지하고 빈 공간이 증가합니다. 자동 균등 재배치·중앙 정렬을 뜻하지 않습니다. 슬롯·글자·표·목표 목록 등의 내용은 후속 UI 코드가 맡습니다. 최종 좌표·최소 크기는 `records/frames-contract.json`을 사용해야 합니다.

아이콘은96px 원본과24px 색상/검은 실루엣 비교로 검수했습니다. 종3종은 같은캔버스에서 크기·개수·외곽이 다릅니다. 작은 사건 아이콘은32px입니다. 계절띠는1024×48, 256px씩4구간이고 반복용이 아닙니다.

키아트의 배경5장은 불투명이며 엠블럼은 투명입니다. 문 표식·인장 체크·거절 교차 등은 의도된 기호이며 글자가 아닙니다. 로딩 화면은 사건의 분위기를 절제해서 묘사한 후보이며 새 게임 규칙이나 역사 정책을 승인하는 자료가 아닙니다.

## 기록·검증 범위

네이티브 image_gen 생성/편집과 실제 후처리를 CSV에 기록했습니다. 모델명·시드는 도구에서 노출되지 않았습니다. 원본 생성 PNG는 로컬 경로·SHA256으로 추적하고, 납품 PNG 수를 늘리지 않도록 추가 동봉하지 않았습니다. 모든 후보·거절 시도 프롬프트는 `records/generation-history.json`에 포함됩니다.

시각 검수·9-slice 오프라인 합성·크기/알파/해시 검증은 실제 게임 UI 배치·클릭·키보드 접근·해상도별 런타임 검증과 별개입니다. 판정과 남은 한계는 검수표를 확인해 주세요.
