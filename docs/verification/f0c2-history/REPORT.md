## 렌더(UI-4·CHRON-1)에 넘길 API (`src/engine/history.ts`)
- `history.query(state, {kinds?, severity?, actors?, range?})` → `HistoryRecord[]`(오래된 순). 기록 패널·가구 전기: `actors: [{type:"household", id: buildingId}]`. 장 연대기: `severity: 2`.
- `history.summary(record)` → 한국어 문장(`historyCopy.ko.ts` 템플릿) · `history.date(record, state)` → 연·계절·날.
- `history.snapshot(state, snapshotId)` → `{size: 128|256, tick, pixels: Uint8Array}`, 색인은 `SNAPSHOT_PALETTE`(풀·숲·물·바위·길·집·건물·공사·주거 구역·경작 구역·불탄 집·성벽·빈 집) — 색은 렌더가 정한다.
- `record.decision` = `{chosen, alternatives, predicted, actual?}` → 결정 카드 "그때 예상 / 실제". `record.place` → 지도로 이동. `record.cause`(SourceRef) → 원인 등록표.
- `chronicleEntry(state)`(FC-5)의 `events[].recordId`·`decisions[].recordId`가 원장 기록을 가리킨다.
