# 확장 회차 계획

1. 완료: 다른 QA 회차/땅의 실제 양성 각5건 이상과 정상 재고 대조를 독립 판독해 동결. 같은 결함 재촬영을 중복 양성으로 세지 않는다.
2. 완료: 합성된 그림의 통/수레 부분 분리를 구현하고 정상 재고 더미 의미 제외를 추가. 이전 도구는 baseline-tool에 보존. 회귀 시험부터 작성.
3. 완료: 같은 동결 시험지로 이전/개선 도구 실제 실행, 모든 채점 TP/FP/FN 검토. 서로 다른 QA 출처/땅과 독립 사례 수 명시.
4. 완료: 재현 CLI·JSON·대표JPEG·원본 메타데이터·정답 해시·한계를 정리, 테스트/타입/린트/깨끗한 게임 tracked diff 검증.
5. 완료: 30MB 이하 별도 ZIP 및 SHA256SUMS 검증, 소유 서버4470종료.

범위는 기존 독립클론 tools/vision-check와 report/expansion 및 ownworktrees뿐. 게임 코드 수정·commit·push·기존배포ZIP덮어쓰기 금지. 최신요청은 보조도구 납품이며 본선 설치 승인으로 추론하지 않는다. 기준목표 재현율70%/정밀도80%를 유지하며 미달을 숨기지 않는다.
