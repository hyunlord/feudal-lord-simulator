# 청지기 3표정 정렬·외형 확인

상태: candidate. 원본 1254×1254를 동일하게 전체 면적 192×192로 축소했다. 위치 보정·비선형 워프·다른 표정의 얼굴 합성은 하지 않았다. neutral을 만든 뒤 같은 원본을 각각 concern과 success의 편집 입력으로 사용했다.

좌표는 최종 192px에서 육안으로 지정한 근사값이다. 사람 얼굴의 눈꺼풀과 뺨은 표정에 따라 달라지므로 자동 검출 정밀 측정으로 해석하지 않는다. 판독 불확실성은 각 축 ±1px이며, 표에 같은 정수가 나오더라도 픽셀 동일성을 뜻하지 않는다. 어깨는 캔버스에 잘린 끝이 아니라 목선 옆 튜닉 경사 시작점을 기준으로 했다.

|표정|왼쪽 동공 x,y|오른쪽 동공 x,y|왼쪽 어깨 기준 x,y|오른쪽 어깨 기준 x,y|neutral 대비 관측 이동|
|---|---|---|---|---|---|
|neutral|69,59|92,57|55,106|128,107|기준|
|concern|69,59|92,57|55,106|128,107|육안 1px 이내; 픽셀 동일 주장 아님|
|success|69,59|92,57|55,106|128,107|육안 1px 이내; 픽셀 동일 주장 아님|

- 동일 인물: 얼굴 골격·코·머리선·수염·의상·지갑·열쇠·시선·카메라가 유지된다.
- neutral: 닫힌 입, 평상시 눈썹. concern: 눈썹 안쪽 상승 및 모임, 걱정스러운 눈. success: 닫힌 입의 작은 미소, 볼의 미세한 상승.
- 192px에서는 표정 차이를 읽을 수 있다. 작은 원형 슬롯에서 concern과 neutral의 차이는 은근하므로 UI 문구·상태색을 대체하는 유일한 신호로 사용하지 않는다.
- 역사/톤: 모자 없음, 단순 울 튜닉·리넨 목선·가죽 지갑·철제 열쇠. 새 문자·숫자·프레임 없음. P1의 저채도 인물 그림 화풍 참조.
- 배경은 P1과 같은 불투명 웜그레이. 런타임 원형 클리핑은 코드 작업이며 이번 후보에 설치하지 않았다.
- 생성 모델 버전과 seed는 도구에서 제공하지 않았으므로 null이다. 세 원본과 전체 프롬프트는 portraits.json에 기록했다.

검수용 나열: portraits-inspection.png. 이는 공식 확인 그림 3을 만드는 입력 검수판이다.
