# Wave13 독립 시각 검수

판정: 후보 제작 검수 통과, 축소 가독성 부분 제한. 에셋34개와 확인 그림4개를 실제 열람했다. 이 검수자는 사람 워커4개 제작자이므로 그4개는 자기검수이며 나머지30개는 제작하지 않은 시점에서 검수했다. 게임 설치·플레이·충돌·프레임 타이밍 검증은 아니다.

## 발견 후 수정 확인
- 외바퀴 수레 NE가 처음에는 SE에 가까운 방향이었다. 제작자가 NE를 개별 이미지 편집해 교정했고 최종4방향 확인.
- 짐수레 말과 기승 말이 처음에는 비슷하게 육중했다. 기승 말 재편집 후 가는 다리·발굽·가슴·몸통으로 분리됨을 확인.
- 수레 조립 SW/NW에서 동물이 채 옆으로 벗어나 보였다. 실제 채 끝점 중심 기반 위치와 앞쪽 채의 동일 원본 분리 가림을 적용한 최종 확인 그림02에서 틈 해소 확인.
- 자루와 양모 안장짐이 둥근 형태로 비슷했다. 최종 양모를 낮고 네모난 회색 꾸러미로 교정, 자루의 둥근 황갈색/직물의 어두운 두루마리와 구분 개선.

## 남는 한계
- 줌0.6에서 발 교대와 작은 도구/짐 내용이 항상 선명하다는 주장은 하지 않는다. 큰 동물의 움직임과 무리 종류가 우선 읽힌다.
- 조립에서 채 위치가 맞는 것과 완전한 역사적 마구가 있는 것은 다르다. 굴레·견인끈·멍에의 상세 메커니즘은 별도 그리지 않았다.
- 몰이꾼/손수레 사람의 원본 보행 손 자세 때문에 손잡이·고삐를 정확히 쥐는 장면은 검증 범위 밖. 기존 워커 자세 변경 금지를 유지했다.
- 원본 방향별 Wave7/3 적재물은 NE만 첨부됨. 다른 방향 적재물의 올바른 새 원근을 만들어 냈다고 주장하지 않는다.
- 실제 게임의 보행 보간·1px 흔들림·배율·깊이 정렬은 미설치. 본 후보의 조립 메타데이터와 합성 검사로만 검수했다.
