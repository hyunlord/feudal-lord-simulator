# Astra 의뢰: 게임 관찰 QA 루프 — 계속 돌려 보며 어색한 것을 찾고, 검토 항목을 키우고, 그 항목으로 시험한다

작성 2026-09-29 · 근거: 사용자가 실제 게임을 보고 "어색하고 이상해 보이는 게 굉장히 많다"고 판정했다 — 나무가 어색하게 왔다 갔다 함, 사람들 일부만 움직이고 일부는 멈춰 있음, 성벽이 끊겨 있음, 시험 중 길을 자꾸 한곳에 지음(무엇을 하는지 모르겠음), 사람이 건물 위에 올라감, 글상자가 네모이고 너비가 들쭉날쭉함(첨부 스크린샷). 지금까지는 개발 세션이 자기 작업의 캡처만 찍었고, **처음 보는 눈으로 게임을 계속 돌려 보며 어색함을 찾는 역할이 없었다.** Astra는 그림을 잘 보고 잘 판단하니 이 역할을 맡는다.

## 역할과 경계
- **보는 사람**: 게임 코드는 고치지 않는다. 찾고, 기록하고, 재현 방법을 남기고, 고쳐졌는지 다시 확인한다.
- 개발 세션(렌더·엔진)이 고친다. Claude가 발견 목록을 판정해 작업으로 나눈다.
- 이 Mac의 성능 측정과 겹치지 않게 **`/tmp/fls-perf-measure.lock`이 잡혀 있으면 기다린다**(QA는 성능을 재지 않지만 CPU를 쓴다).

## 준비 (한 번)
1. 저장소를 **읽기 전용으로 따로 받는다**: `git clone https://github.com/hyunlord/feudal-lord-simulator ~/fls-qa && cd ~/fls-qa && git checkout codex/phase15-organic-ground && npm ci` (개발 작업 폴더와 섞지 않음). 매 회차 시작에 `git pull`.
2. `npm run dev -- --port 4400`으로 띄우고 **증명 모드 없이**(`?phase10-proof=1` 금지 — 개발용 기록기가 붙음) 연다.
3. 장면 저장: 저장소의 고정 저장(`fixtures/perf-gate/ch4-1380.save.json.gz` 등)과 새 게임. 새 땅 다섯(시작 화면 땅 고르기, 또는 URL 인자 — 개발 세션에 물어 확인).
4. 관찰 도구: Playwright로 **같은 카메라에서 0.1초 간격 프레임 20장**(움직임 판정용), 줌 0.6·1.0·1.4, 1·3·5배속, 일시정지 전후. 프레임을 GIF/연속 판으로 묶어 본다(나무 흔들림·사람 멈춤은 정지 사진으론 안 보인다).

## 매 회차 (약 2~3시간)
1. **탐색**: 장면 여섯(새 게임 첫 10분, 1장 끝, 2장 1340, 3장 역병 도래, 4장 1380, 5장 1440) × 새 땅 하나씩 돌아가며. 줌·배속·일시정지·계절 전환·건물 배치·서랍·연대기를 직접 조작.
2. **발견 기록**(항목마다): `id`(QA-###), **분류**(아래), 심각도(막음/눈에 띔/사소), 설명 한 줄, **재현**(저장·연도·틱·카메라 좌표·줌·배속·조작 순서), **증거**(캡처·프레임 판·GIF), 처음 본 회차·커밋.
3. **검토 항목 키우기**: 발견이 새 종류면 `CHECKLIST.md`에 **다시 볼 수 있는 항목**으로 추가 — "무엇을, 어디서, 어떻게 보면, 무엇이면 실패". 예) "움직임-03: 1380 도시 5배속 10초 동안 화면 안 워커 중 한 번도 안 움직인 비율 — 5% 넘으면 실패(일하는 중·줄 서기 등 이유 표시가 없으면)".
4. **다시 확인**: 이전 회차의 발견 중 개발 세션이 "고침"이라고 한 것을 같은 재현으로 확인 → 닫힘/다시 열림.
5. **항목으로 시험**: 쌓인 CHECKLIST 전체를 한 번 훑는 **정기 시험**(회귀) — 통과/실패 표.

## 분류 (시작 목록, 계속 늘림)
가림·겹침(사람이 건물 위·소품이 벽 관통) · 움직임(흔들림 과함·멈춘 사람·순간이동·같은 길 반복) · 연결(성벽·울타리·길 끊김·물가 틈) · 반복(같은 집·같은 소품·같은 걸음) · 크기·비율(사람과 집·동물과 수레) · 빛·그림자 방향 · 계절 불일치(여름 나무에 눈 등) · 봇·자동 행동(무엇을 하는지 모를 반복 건설 — 이유가 화면에 보이는가) · UI 글상자(네모·너비 변화·잘림·겹침) · 문구(어색한 한국어·영어 남음·개발용 글자) · 고증(시대에 안 맞는 것) · 체감 성능(끊김이 눈에 띄는 순간)

## 제출 (회차마다)
경량 ZIP: `QA_ROUND_<nn>/FINDINGS.md`(이번 회차 발견) + `CHECKLIST.md`(누적) + `REGRESSION.md`(항목별 통과/실패) + `evidence/`(JPEG·GIF, 합계 30MB 이하) + `repro/`(저장·카메라 좌표). 게임 코드·저장소에 쓰지 않음(INBOX 세션이 받아 `docs/qa/`에 넣음).

## 1회차 특별 확인 (사용자가 본 것)
① 나무가 어색하게 왔다 갔다 함(흔들림 폭·주기·계절 섞임 깜빡임 중 무엇인지) ② 사람 일부만 움직이고 일부는 멈춤(멈춘 이유가 있는지 — 일·줄·길 없음·버그) ③ 성벽이 끊겨 있음(어디가 어떻게) ④ 시험 중 길을 자꾸 한곳에 지음(무엇이 짓는지 — 봇·튜토리얼·증명 모드 — 화면에서 이유를 알 수 있는지) ⑤ 사람이 건물 위(가림 순서) ⑥ 글상자 네모·너비 변화 ⑦ 석벽이 물 위를 지남
