# 날씨 14장 내부 검수

후보 14 PNG, 원본 생성 14회. 세계 그림 위의 합성 재료이며 게임 미설치.

- 규격: tint256², fog512×256 3종, rain1024×256(256²4셀)2종, sheen256×128, ripple256×32(64×32 4셀), dust256×1282종, cracked128×64, cloud512²2종.
- 모든 개별 그림과 비·파문 네 프레임을 목표 크기로 열람했다. 밝은/어두운 배경에서 얼굴·문자·건물 등 불필요한 그림 없음.
- 반복 5파일의 첫셀 XY 반대 경계 RGBA 최대 차이0. 3×3 합성 열람. tint 원본 노출 띠는 중앙 크롭+색 편차25%로 줄였다. 강도100%에서는 저주파 반복이 조금 남으므로 최종 적용 상한 준수.
- 알파가1~2/255인 생성 원본의 포화 파랑 hiddenRGB가 이미지 뷰어에서 보였다. 최종 alpha<=2/255 픽셀은 RGBA0으로 정리했다. 실제 그림과 검수 합성에 청색 테두리 없음.
- 모든 개별 상한을 같은 마을 일부 위에 합성해 지붕·길·나무가 읽힘을 확인(`weather-cap-check.png`). 원본 그림 alpha와 별개로 CSV `opacityMax`는 적용시 globalAlpha 상한이다.
- 동시 겹침은 같은 위치에서 적용 globalAlpha 합계0.38 이하. 가랑비와 폭우는 동시에 쓰지 않는다. 스트레스: 흐림.18 + 폭우.10 + 안개.10 =.38, 실제 합성 유효 alpha 상계 .3358; 원본 알파가 더 낮추므로 그림을 가리지 않는다. 모든 개별 상한을 동시에 합해 쓰라는 뜻이 아니다.
- 확인 그림1은 같은1280×800제공JPEG로 네 상태를 만들고 1.0/0.6로 나란히 놓은 오프라인 합성이다. 카메라를 실행한 검증이 아니다. HUD6영역은 원본 픽셀 복원했고 모든 상태 채널차이0.
- 날씨 차이는 의도적으로 절제했다. 젖은 날은 약한 어두움·비·강가 안개, 마른 날은 먼지·국소 균열, 추운 날은 밝고 찬 틴트다. 0.6에서는 개별 빗방울/균열은 약해지고 큰 조명 차이가 우선한다.
- 미검증: 런타임 애니메이션 속도/루프 느낌, 이동 카메라와 반복 위상, 실제 지형/건물 가림, DPR·성능. 적용시 sheen/균열은 지면에만 마스킹하고 HUD 전체는 제외해야 한다.
