# UI 파일럿 C안: 80% 기능 / 20% 시대 장식

독립 후보 아트·오프라인 합성용 계약이다. 제품 UI 구현이나 신규 기능 제안이 아니다.

- 색: parchment #E1D1AE, edge #B7A47F, ink #332D25, oak #514334, red #873F36. 상태에만 moss #687052 / ochre #A07143 / slate #586D73.
- 중앙 읽기 면은 단색. 장식은 모서리·상단 edge·작은 인장에 한정. 실제 양피지 타일은 검사판과 가장자리의 낮은 농도로만 사용.
- 원본의 한글 문구는 자산에 넣지 않는다. 확인판 임시 한글·숫자는 Canvas 글자 레이어로 분리한다. bar 내부 그림 없음.
- 오프라인 HUD1280×800: 자원 상단, 시간·속도·설정 상단 우측. 우측 목표카드2개, 좌측 inspector, 좌측 하단 advisor. 하단은 직접/구역/방향 층위 전환과 별도6건설분류.
- 타이포: 시스템 한글 산세리프, 확인판14/16/20px. 배포용 글꼴을 동봉하지 않음.
- 9slice: corners 고정, edge 한축늘림, center두축늘림. advisor원형슬롯은고정영역으로보호. 200×80/600×400에서독립검수.
- 검수는 최종PNG와합성판에서실시. 게임통합,반응형구현,조작,성능은이번범위밖.
