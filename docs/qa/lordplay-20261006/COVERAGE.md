# 요청한 체험의 범위

|---|---|---|
| 영주 모드 새 게임과 2~3시간 | 완료 | 약20년, 보수적 실플레이2시간26분47초. 단일 판이며 복구 재진행 있음 |
| 청원 판결 | 완료 | 손맷돌·좌판·경계·상속세·방목·후견 등. 비용 때문에 판결을 뒤집은 경험 포함 |
| 방침·장려금 | 완료 | 안정→성장→세입→안정, 곡창10d·시장20d·제재소30d 설정/회수 |
| 왜 여기에 영수증 따라가기 | 완료 | 우물·곡창·시장에 내 결정 연결. 후반 집에는 영향 없음 확인 |
| 사건 그림·이유·보류 | 완료 | 그림 있는 청원과 없는 세율 카드, 확률/조건 이유, 좌판 보류 만료 결과 |

| 이웃 혼인 협상 | 카드 경로 완료 | 1315년50d+정치지지 제안→계약→신부→상속. 조항 편집/역제안 전용 UI는 못 찾음 |
| 약속 | 기록 확인, 이행 미확인 | 연대기에는 있으나 기한·행동 찾기 실패 |
| 소송 | 제기·상태·증거 체험, 결말 미확인 | 1300년 어업권5s 지출. 판결·집행을 확인하지 못함 |

| 지역 지도 | 탐색했으나 진입 못함 | 도시 미니맵까지. 영지 상속 뒤에도 별도 지역/영지 화면 미확인 |
| 저장·불러오기 | 완료 | 초반과 최종 게임 내 저장/불러오기. 최종 HUD4항목 일치, 카메라 초기화 |
| 15분 일지 | 기록 | 0~150분 항목. 일부 복구로 작성 시각이 밀려 실제 UTC도 병기. 엄밀한 정시 타이머 표본 아님 |
| 원칙 P번호 대조 | 종료 뒤 완료 | 두 지정 문서만 읽음. 내부 규칙 준수는 추측하지 않음 |

## 평가에서 제외한 것

사용자 입력 혼재 구간의 개별 선택 인과, 브라우저/PTY 종료 원인의 게임 귀속, 엔진 불변식, 장기 성능, 결정론, 역사 정확성 전수검사, 다른 땅/seed의 일반화, 지정한5곳의 최종 영수증 성공률. 이번 보고서는 한 명의 첫 플레이에 가까운 관찰이며 사용자 G-LM의 통과를 대신 선언하지 않는다.
