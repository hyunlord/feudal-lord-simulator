# 완공 주택 철거

선택 모드에서 주택을 클릭하고 진단 카드의 **주택 철거**를 누른다. 주민 수와 자재·보관 식량이 반환되지 않는다는 안내가 버튼 위에 표시된다. 공사 중 건물은 기존 **공사 포기**를 사용한다.

- 완공된 `house`만 철거한다. 생산·보관·서비스 건물 철거는 지원하지 않는다.
- 해당 건물, 가구, 타일 점유를 제거한다. 도로와 지형은 보존한다.
- 주민은 마을을 떠난다. 남은 가구의 주민을 합산하고 건물 및 공사 노동을 즉시 재배분한다. 건설자 표시도 새 배정에 맞춰 재생성한다.
- 주택은 국고 목재 운반인의 출발점이 될 수 있다. 철거한 주택에서 출발한 운반인은 출발지 소멸 사유로 배송을 취소하고 공사 예약을 해제한다. 운반 중 국고 목재는 다음 운반 처리에서 국고로 회수하며, 공사 포기를 이어 실행해도 중복 환급하지 않는다. 다른 건물의 운반인, 배급자, 재고와 예약은 유지한다. 배급 대상 목록은 다음 tick에 남은 가구로 만들어진다.
- 자재와 식량을 환급하지 않는다. 이는 공사 포기의 환급 정책과 별개다.
- 없는 ID, 주택이 아닌 ID, 이미 철거한 ID는 상태를 변경하지 않는다.
- 선택 및 hover를 지워 오래된 주택 카드가 남지 않게 한다.

검증: `tests/houseDemolition.test.ts`에서 점유·인구·무환급, 노동 및 건설자 정합성, 다음 tick, 중복/잘못된 요청, reducer 연결, 실제 시뮬레이션으로 생성된 배송/배급자 보존, 마지막 가구 제거를 확인한다. `tests/houseDemolitionDelivery.test.ts`는 실제 도로와 국고 운반 생성기를 사용해 출발 주택 철거 후 목재 회수, 공사 포기 연속 실행의 무중복 환급, 배송 완료 후 다른 운반인의 예약 보존을 검증한다. UI 실제 클릭 검증은 이번 작업의 브라우저 QA 산출물에서 별도로 기록한다.
