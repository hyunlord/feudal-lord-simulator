# 출입구 개선은 관측된 방앗간 증설에만 적용

`b750578` 최종 전체 회귀는 2,107개 중 2,106개를 통과했지만, 기존 기본 도시 12,000틱 성장 검사가 실패했다. 해당 검사의 최대·최종 인구는99로, 변경하지 않은 최소100 조건을 충족하지 못했다. 8필지 장기·5개 지도 검증은 시작하지 않았다.

**원인.** 기존 경로 기준의 변화, 초기 도로 건설 지연, 농지 운송 문제를 비교했다. 별도 정상 조언자 추적에서는 첫 농장부터 출입구 도로를 먼저 건설했고, 첫 방앗간과 다음 농장에도 추가 도로 행동이 끼어들었다. 음식 생산 자체는 수요를 충족했지만 초기 주택 성장 시점이 늦어졌다. 별도 조언자 추적과 기존 회귀 검사는 무행동 시 재평가 주기가 다르므로 인구 수치를 서로 대체하지 않았다.

**수정.** 호출부에서 식량망이 완성되어 있고, 최근 실제 관측이 방앗간 생산 용량 부족으로 방앗간 증설을 결정한 경우에만 출입구 계획을 사용한다. 초기 최소 식량망과 농장 건설은 기존 배치에 맡긴다. 시대·시설 개수·새로운 거리 상한으로 조건을 바꾸지 않았으며 인구 기준·생산량·비용도 유지했다.

**검증.** 초기 식량망이 원래 농장 건설을 그대로 호출하는 통합 회귀를 먼저 실패시킨 뒤 통과시켰다. 출입구 전용8개와 기존 Phase12Part5 검사5개, 총13개 통과 및 TypeScript 통과. 기존12,000틱 인구 검사도 원래 조건 그대로 통과했다. 실제239,640틱 저장 상태에서 정상 조언자12,000틱을 다시 진행하면 도로 한 번→방앗간 한 번의 행동과 마지막 빵208·식사192/192·인구256이 유지된다. 이는 저장 상태의 후속 확인이며 새 기본 상태의 엄격 합격을 대신하지 않는다. 동일 QA 담당자의 확정 커밋 전체 회귀·8필지·5지도 검증이 남는다.
