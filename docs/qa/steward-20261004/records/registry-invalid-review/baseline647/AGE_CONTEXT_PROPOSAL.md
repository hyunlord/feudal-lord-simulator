현재 variants.ko.json은629개로 유지한다. 별도 [나이 문맥 후보20개](../records/age-context-copy-proposal/README.md)는6개 사건종의 기록 당시 나이를 사용하며, 기존 schema와 호환되지 않는 context/slot 확장 제안이다. 아직 누적판에 병합하거나 엔진에 설치하지 않았다.
