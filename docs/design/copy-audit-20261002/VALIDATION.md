## 산출물 검증

발견별 원문이 고정 SHA 파일의 정확한 줄과 일치하는지 확인했다. 모든 지적의 주 위치 52개와 수치가 있는 보조 위치를 확인했다. Markdown 표의 열 수, 심각도 집계, 파일 참조 존재 여부를 검사했다. ZIP에는 읽기용 문서와 검증 기록만 넣고 게임 소스·에셋·의존성은 넣지 않는다. SHA256SUMS는 자신을 제외한 ZIP 내 모든 파일을 포함한다. 압축 후 CRC와 각 파일의 SHA-256을 재검증한다.
