## 만든 것
1. **시나리오 `core:lord_slice`**(LS-1, 결정 LM8-1)
   - 직할 장원과 그 시장도시(seed마다 다른 강가 지도), 이웃 영지 셋(셋째: 63세·딸만·채무 6,400d), 1300년 시작이다.
   - 언제나 영주 모드다. 시나리오 방식은 샌드박스라 장 승리 조건이 없고, 사건과 청원은 그대로 온다.
   - 시작 화면 목록(`CORE_SCENARIOS`)에는 넣지 않았다. 지금 시작 화면은 목록을 돌며 버튼을 만들기 때문에, 넣으면 "샌드박스로 시작" 버튼이 하나 더 생긴다. 조각의 시작 화면은 렌더 LM-R3 몫이다.
   - **세력 4~5 지시와 게임 구조**: 세력은 아홉이다(대영주·국왕·이웃 둘·주교·상인 가문 둘·도시·평민). 이웃 둘은 이웃 영지 카드의 가문이고, 국왕은 사건만 낸다. 지우면 목격자·청원·영지 카드 규칙이 깨진다. 그래서 시작 데이터가 소개하는 세력을 다섯으로 했다(대영주·주교·상인 가문 둘·도시). 판단을 부탁한다.
   - 시작 데이터 `lordSliceStart`: 홈 영지 조각, 도시, 이웃 셋(이웃 1·2는 세력 수장이 영주라 첫 철에 정해짐: `factionId`), 세력 다섯, 목표 12~20년, 끝 조건.
2. **자동 일시정지 사유**(LS-2, 결정 LM8-2)
   - `pauseReasons(before, after)`: 사유 여덟이다(역제안·주요 인물 사망·상속·판결·권리 상실 위험 청원·영지급 위기·영지 획득·상실).
   - 그 틱(또는 명령과 틱)의 새 원장 줄과 새 청원에서 읽는다. 집 완공·상점 개업(자율 성장 착수)·화재·조각 하나의 점유는 멈추지 않는다.
   - 화면은 틱마다 한 번 멈춘다. 늙은 영주가 죽는 틱에는 사유가 넷(이웃 가장 사망·아버지 죽음·영지 획득·상속) 오지만 멈춤은 하나다.
3. **영주 모드 봇 전 기능**(LS-3, 결정 LM8-3): `lordBotCommands`. 청원·기근, 방침(성장 → 세입, 기근엔 안정), 장려금(곡창 → 시장 → 교회), 시장 부담(800 → 1,100‰), 혼인(청혼·역제안·약속·유언), 소송(시작판의 하사 청구), 위임(예외 규칙·청지기·감사 방식), 올라온 청원·감사 판정, 도시의 요청(칙허·성벽·목재).
4. **끝 조건과 결과 요약**(LS-5, 결정 LM8-5): 20년 또는 두 번째 영지 뒤 5년이다. 두 번째 영지의 때는 그 조각들의 점유 시작이라 저장에 더하지 않는다(저장 판 그대로).
