# R07 설치안 보강 — 영주관 연결

설치 실행 지시나 원화 재작업 요청이 아니다. INVENTORY.csv의 기존 두 Wave12 영주관 행, priority_stage=1, pending_existing_plan을 유지한다. 승인44장도 그대로 유지한다.

1350 자연 저장의 실제 창고 화면 세 곳에서 현재 영주관은 기본도형으로 보인다. 저장의 manor-house-34-41-0(34,41)과 카메라 투영·소스 기본도형의 높은 정합을 확인했다. 직접 클릭한 ID나 런타임 draw 분기 trace는 없으므로 정적 귀속 범위로 사용한다. 근거: ../records/storage-background-art-audit-r07/REPORT.md 및 PLAN_ROWS.json.

설치 담당에게 넘길 확인 사항:

1. 현재 engine 저장 발판2×2와 계획의 원화발판3×3 사이를 명시적으로 매핑한다. 그림에 맞춰 엔진 발판을 자동 변경하지 않는다.
2. 원화416×328의 A pivot(249,319), B(251,319)를 같은 세계 접점에 연결한다. 수평 중앙 정렬로 대신하지 않는다.
3. 현재 building ID와 seed로 A/B가 안정적으로 선택되는지, 실제 가문 점유·빈 영주관 상태 필드를 연결했는지 확인한다. 존재하지 않는 상태를 추측하여 연출하지 않는다.
4. 이번 증거의 세 카메라와 같은 위치에서 기본도형 대체·가림·접점을 확인한다. 겨울·다른 방향·직접 선택은 별도 확인이 필요하다.

이번 회차의 변경은 근거와 연결 조건 문서 보강뿐이다. 대상 파일 설치·renderer 변경·CSV 설치완료 승격은 하지 않았다. 새 그림 제작보다 확정 원화의 연결 검증을 우선한다.
