## 최근 QA의 상태를 소급 왜곡하지 않음

- QA16은 QA036을 사망한 청원자 후보로 발견했고 QA17 문서는 사용자 확정 엔진 열림으로 남겼다. FIX-12 이후 완료 여부는 본 감사에서 새 runtime 재현하지 않았으므로 `과거 열림 / 현재 재현 대기`이다. 원장에 id를 저장하고 읽을 때 이름을 푸는 것과, 지금 청원할 자격이 있는 생존 인물을 고르는 것은 다른 검사다.
- QA17 `5a15e62d`의 QA015/035는 지정 재현 닫힘, QA034 닫힘 유지. QA016은 과세 표본만 통과,1394길드 동일 재현은 미검증. 이 표본 제한을 유지한다.
- QA037(10배속 못찾음), QA038(강가seed1 고정)은 QA17의 당시 화면 관찰이다. 현재 `src/ui/landChoice.ts:42–72`에 무작위·직접seed 선택 모델이 있고 기존 FIX 후속이 있으므로 옛 캡처만으로 현재 열림 단정하지 않는다. 현 UI 클릭 재현이 필요하다.
- QA027 영주관, QA039 백악 절단, QA040 숲 직각 경계는 자산 설치 감사(C)의 실제 설치 대장과 함께 넘겨받아야 한다. 옛미관측을 해결 또는 현재 결함으로 자동 전환하지 않는다.

## 선택 깊이와 문구 감사의 한계 및 다음 검사

[코드] `lordBot.ts:62`는 대기근 relief, 청원 accept, 과세 pay를 기본으로 호출한다. 117–131은 비탐욕 고능력 청지기, 소작인 청원 수락, 돈 숨긴 감사 처벌로 고정 선택한다. 따라서 봇 장기 결과만으로 **어느 선택도 항상 정답이 아님**을 입증할 수 없다. 이는 지배전략 결함의 확정이 아니라 **시험 범위 공백**이다.

후속은 같은 seed·동일 직전 저장에서 최소한 수락/거절/미룸(지원될 때), 방침4종, 감사방식, 장려금유무를 비교한다. 비교축은 인구뿐 아니라 금고·권리 조각·기한 미이행·주의력·상대 기억·영지 수입이다. 새 정책을 보고서 작성자가 가장 좋은 것이라 정해 버리지 않는다.

과장 문구 감시: 기존 inspector의 ‘왜’가 사업착수 영수증이라고 소개되지 않게 한다(B03). 식량 일수가 모든 가구 접근 가능 일수처럼 소개되지 않게 한다(B04). LM-E8의 pause 집계가 실제 UI 정지나 사용자 의사결정 밀도로 발표되지 않게 한다(B05). ‘새 규칙은 세계에서 보인다’는 장면 증거가 있어야 통과한다. 이 감사에는 그런 새 장면이 없으므로 보이는지 통과 판정을 내리지 않았다.
