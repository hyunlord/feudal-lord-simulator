## 만든 것
- **Wave 8 설치**(`scripts/installWave8.py`): 37장을 설치했다(후보 36 + 흑사병 로딩 v2). 받은 바이트 = 런타임이다(caBX 없음).
  - 대장 37행과 프롬프트를 만들고, inbox `installed_by`를 UI-3으로 채웠다.
  - `src/ui/wave8ArtManifest.generated.ts`: 틀 9-slice·내용 칸은 `frames-contract.json`에서 왔다.
  - `verify:provenance` 누락 0, 해시 불일치 0.
- **계절 결산 카드**: Wave 8 두루마리, 머리 세 칸은 큰 변화 셋, 본문은 수입·지출·인구·재고·일어난 일, 다음 목표 단추다. 상태 기계 모달이라 시간이 멈춘다.
- **계절 띠**: 알약 날짜 아래 5px 띠(면적 0 추가)가 있고, 누르면 전체 띠와 다가오는 일 목록이 열린다.
- **배치 장부 한 줄**: "장부 기간마다 지대 +N · 유지비 −N · 일꾼 N".
- **집 압력**: 원인 그림과 inspector 첫 줄.
- **보릿고개 카드**와 청지기 걱정.
- **일시정지 비네트·표지**, **타이틀 키아트·엠블럼·모드 배경·장 화면**, 위기 아이콘 = **알림 종**.

## 과정에서 바로잡은 것 (UX-3)
- **청지기 말풍선:** UX-3부터 화면 밖에 있었다. 옛 조언 카드의 `top`/`left`가 도크 말풍선에도 걸렸기 때문이다. 이제 버튼 위에 한 줄로 8초 보이고 접힌다. 표시된 버튼을 누르면 전체 글과 [알겠습니다]가 나온다(UX3R 7절). 면적 관문은 이 일시 표시가 접힌 뒤의 평소 상태를 잰다.
- **목표 띠:** 한 장만 보인다. 보릿고개 카드가 가장 급하다.

## 결정
- **UI3-D1:** 계절 띠는 알약 날짜 칸 안의 5px 띠로 둔다. 전체 띠(300px)는 누를 때만 연다. 상시로 두면 평소 1280 예산 6 %를 넘는다(5.6 % + 1.2 %).
- **UI3-D2:** 결산 카드 "세계 장면 3칸"은 그림 + 부호 붙은 수로 한다. 지도 썸네일 캡처는 이번 범위 밖이다.
- **UI3-D3:** 1장 로딩은 타이틀 배경을 다시 쓰는 0.9초 화면이고 누름을 받지 않는다. 1315·1337·1348 화면은 등록만 했다.
- **UI3-D4:** 겹쳐보기 아이콘 8·미니맵 틀·목표 서랍 틀·연대기·청원 그림·info 종은 붙일 자리가 없어 등록만 했다. 겹쳐보기 단추는 글자만 있고, 청원·연대기 화면은 아직 없다.
- **UI3-D5:** 키아트 PNG는 받은 그대로 설치했다(장당 3~4.7MB). 그 화면에서만 읽는다. 웹용 작은 파생본은 따로 판단할 일이다.
- **UI3-D6:** 결산 카드의 전 계절 비교는 화살표 기호 대신 "(전 계절 +4)"처럼 글로 적는다(헌장: 기호 대신 그림·글).
- **UI3-D7:** 장날 표시는 시장이 생긴 뒤에만, 다음 한 번만 둔다(매달이라 열두 개가 된다). 장부 기간 마감은 2,400틱마다라 계절과 맞물리지 않는다.
- **UI3-D8:** 오두막 지대가 실제 장부와 같은지는 엔진 P1이 확인하므로 다시 돌리지 않는다. UI 테스트는 칩 = 예측, 방앗간 유지비 = 정산을 확인한다.

## 판정을 받을 선택지
- 알약의 "식량 N일"은 달력 날이다. "여름 말까지"처럼 도착점으로 적는 대안이 있다(UX-3 보고서와 같은 항목).
- 결산 카드의 기본값은 "켬"이다. 5배속으로 오래 돌리는 사람은 끌 수 있다.
