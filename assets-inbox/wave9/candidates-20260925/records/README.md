# ASTRA Wave 9 · 사건 연출 재료 · candidate

게임에 설치하지 않은 검토용 후보입니다. 첨부 주택과 워커만을 형태 기준으로 사용했습니다.

## 구성
- `assets/`: 후보 PNG **40개**. 의뢰서의 개별 ID 39개 전부 + 이탈 가족용 아이 소품 시트 1개.
- `checks/`: 실제 납품 PNG를 합성한 확인 그림 **3장**. 1.0과 0.6 배율을 표기했습니다.
- `assets.csv`: 40행. ID, 규격, 기준 참조, 실제 생성 프롬프트, 후처리, SHA256, 후보 상태.
- `inspection.csv`, `SELF_QA.md`: 파일별 기술검사와 시각 검수.
- `worker_overlay_table.csv`: 성인 워커 5종 × 8셀 = **40프레임**의 발·머리 겹치기 수치.
- `reference/`: 비교 기준으로 사용한 74×74 셀 정규화 템플릿 4장. 납품 후보 수에 포함하지 않습니다.
- `records/`: 전체 생성 기록·추가 소품 프롬프트·원본 해시·정렬 좌표·검증 JSON·파일 무결성 목록.
- `source/`: 제공받은 원본 참조 ZIP과 의뢰서. 게임 저장소 에셋을 대체하지 않습니다.

의뢰서 C의 소계는 6으로 적혀 있지만 관 NE/NW를 각각 파일로 세면 7입니다. A12+B8+C7+D6+E6=39이며, 아이 소품 1개로 총40개입니다.

## 주택 정렬 계약

첨부 L0~L4의 캔버스는 각각 **153,139,137,142,161px 정사각형**입니다. 원본 크기와 투명 여백을 유지했습니다. 모든 주택 오버레이는 원본과 같은 좌상단 `(0,0)`에 합성합니다. 첨부에 숫자로 된 피벗 메타데이터가 없으므로 피벗 값을 임의로 만들지 않았습니다. 사용하는 쪽에서 **첨부 원본과 정확히 같은 피벗**을 적용하면 정렬이 유지됩니다.

폐허·버려진 집은 생성 디테일을 원본 알파 윤곽에 맞춰 등록했습니다. 최종 알파는 첨부 원본과 픽셀 단위로 같습니다. 구멍은 어두운 내부와 골조로 표현하여 외곽 실루엣을 유지했습니다. 원본 실루엣 보존은 기술 검사, 내부 형태의 유사성은 시각 검사입니다.

역병 오버레이는 원본 창 다각형 안에만 덧창을 넣고 문 위치에 표식을 놓았습니다. 창·문 좌표는 `records/registration.json`에 있습니다.

## 워커: 파일럿 2 방식의 고정 자세 재스킨

원본 남성294×147, 여성312×156, 상인285×142는 먼저 **296×148**로 정규화했습니다. 셀은74×74, 4열×2행입니다. 비교는 `reference/template_*_74x74.png`와 수행했습니다. 원본 시트가 이미74×74였다고 주장하지 않습니다. 방위별 열 이름은 첨부에 없으므로 **원본 열0..3 순서**를 유지합니다. 임의로 NE/NW 등의 순서를 확정하지 않았습니다.

생성된 몸의 자세는 최종 시트에 사용하지 않았습니다. 정규화 템플릿의 몸 알파·프레임 좌표를 유지하고 생성 의복 색/질감만 내부에 옮겼습니다. 머리 상단17px와 발 하단7px는 기준 픽셀을 그대로 보존했습니다. 모자는 원래 손에, 등짐은 원래 등에 부착했습니다. 이 소품 때문에 손/등 주변 최종 알파는 늘어나지만 몸 알파를 제거하거나 팔·다리를 이동하지 않았습니다. 추가 소품 좌표와 생성 프롬프트는 `records/accessory_registration.json`에 기록했습니다.

- **성인 40프레임: 발0px, 머리0px.** 머리/발 보호 영역의 RGBA도 동일합니다.
- 장례: 한 사람 시트를 두 인스턴스로 배치하고 관을 별도 레이어로 사용합니다. `coffin_nw` 지지점 약(16,12)/(47,26)에 양쪽 어깨를 맞춥니다. 확인 그림은 관 → 두 사람 순으로 그렸습니다. 자세를 바꾸지 않고 어깨에 멘 표현입니다.
- 이탈: 어머니 시트에는 등짐이 포함됩니다. `prop/leaving_child_sheet-v1`는 같은 템플릿 계열을60%로 축소한 동행 소품입니다. 성인 비교표와 구분되는 별도 기준 시트가 있습니다. 확인 그림에서는 어머니 가까이에 동행시켰습니다.
- 청원자: 기존 손 위치에9×7px 모자를 부착했습니다. 손의 원래 픽셀을 앞에 다시 합성했습니다.
- 국왕 전령: 왕실색 타바드와 작은 금색 문장, 별도 두루마리입니다.

## FX·들판

- 검은 연기: **384×192**, 96×192 프레임4개, 가로 한 줄.
- 비: **256×128**, 64×128 프레임4개, 가로 한 줄. 각 셀 XY반복 경계가 일치하며 반투명입니다.
- 흉년A/B·침수: **512×64**, X반복. 생성 여백을 제거한 뒤 원본 휴경 토양으로 가장자리 알파를 채웠습니다. 16px 경계 혼합으로 좌우 경계가 일치합니다.
- NE/NW 관64×32, 두루마리32×32는 서로 다른 방향 파일입니다.

## 검토 범위

검수는 독립 PNG, 동일 캔버스 합성, 셀별 측정, 실제 PNG의0.6축소 확인, CSV 왕복 파싱 및 ZIP 무결성입니다. 게임 런타임, 실제 엔진 피벗 메타데이터, 지형/건물 뒤 가림, 시간 기반 애니메이션 재생과 성능은 게임 미설치 요청에 따라 시험하지 않았습니다.

확인 그림은 실제 에셋 합성 자료이며 게임 스크린샷은 아닙니다. 0.6에서 작은 문장·모자·문 표식 같은 세부는 축소됩니다. 사건은 연기/폐허, 실패한 들판/빈 곡창/대기줄, 닫힌 집/표식/장례, 등짐 가족, 군중/청원자/전령의 조합으로 읽도록 제작했습니다.

이미지는 내장 `image_gen`으로 생성/편집했습니다. 모델명은 도구가 노출하지 않아 임의로 특정하지 않았습니다. 수치 정렬·소품 합성·RGBA 보존·시트 정규화는 로컬 후처리이며 CSV에 구분했습니다.
