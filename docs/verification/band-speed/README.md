# 1배속·3배속 철 띠 판정 (2026-10-18)

화면 설계 v1 §6의 "1배속·3배속에서 띠가 너무 자주 뜨는지"(그동안 판정은 모두 10배속). 판정 실행: `render-VIS-band1x-757cf77`, `render-VIS-band3x-757cf77` (seed 1, 각 2년 = 철 8개, 화면 쪽만). 증빙: `~/fls-evidence/render-VIS-band{1,3}x-757cf77-757cf77`(DGX `_kept`). 하네스에 속도 옵션과 띠의 사라짐·상자·겹침 기록을 더했다(`scripts/visibleChangeRun.sh … <seed> <speed>`).

| 볼 것 | 1배속 | 3배속 |
|---|---|---|
| 띠가 나온 횟수 | 8 (철마다 한 번) | 8 |
| 띠 사이 실제 시간 | 중앙값 100.0초 (99.9–103.5) | 중앙값 33.3초 (33.3–36.1) |
| 띠가 떠 있는 시간 | 5.0–5.2초 (`SEASON_BAND_MS` 5,000ms, 실제 시간이라 배속과 무관) | 5.0–5.1초 |
| 화면에 떠 있는 몫 (첫 띠–끝 띠) | 4.4 % | 12.7 % |
| 나올 때 겹친 칩·카드·알림 | 0 | 0 |

띠 자리: 상태 띠 아래 왼쪽, 상자 x 64–470, y 75–119(글 길이에 따라 너비만 바뀜).

**"너무 자주"인가:** 아니다. 1배속에서 띠는 100초에 한 번 5초, 3배속에서 33초에 한 번 5초다. 그동안 받아들인 10배속은 10초에 한 번 5초(몫 약 50 %)였다. 느린 배속일수록 띠는 드물고 짧게 느껴진다.

**하나 본 것:** 해가 바뀌는 철 끝(4000)에는 띠가 뜬 뒤 1.6–1.7초 만에 연말 카드가 열려 띠를 거의 덮는다(왼쪽 끝 "인구 +24 · 새 집 1"만 보임, 1배속 멈춤 캡처 001). 연말 카드의 "마을의 한 해"가 같은 사실을 보여 주므로 잃는 것은 없다. 겹침 기록은 띠가 나올 때만 재므로 이 경우는 캡처로 확인했다.

한계: seed 1의 처음 2년(1300–1302)만 봤다. 띠의 글이 길어지는 뒤 해(정체 문구, 사망 까닭)는 10배속 판정에서 본 것과 같다.
