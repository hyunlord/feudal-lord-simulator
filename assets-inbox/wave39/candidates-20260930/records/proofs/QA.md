# 확인 그림 자체 검수

- **01 비 전후: 통과(오프라인 합성).** 사용자 원본과 동일한 도시 구도에서 큰 사선 격자 대신 작은 개별 비가 국소 영역에 내린다. 웅덩이·젖은 땅·지면 접촉 튐이 함께 있어 정지 화면에서도 비가 오는 지역을 읽을 수 있다. 전체 축소 그림의 지붕 튐은 매우 작고 미세하므로 1:1 부분 확인을 함께 제공한다. native clean plate 재구성이 원본보다 다소 선명하고 밝아 색상 비교나 런타임 효과의 증거로 쓰면 안 된다.
- **02 낙엽: 통과.** 공중 잎은 수관 부근에, 쌓인 잎은 나무 밑과 길 가장자리에 놓인다. 줌 0.6에서는 개별 잎 종보다 낙하 위치·황갈색 축적 영역이 주요 단서다. 바람 줄 데칼은 지면 층에 놓고 나무가 앞에서 가린다. 애니메이션의 자연스러움은 정지 그림으로 검증하지 않았다.
- **03 크기: 통과.** 비 12·튐 6·잎 12·바람 잎 2·눈 4 = 36 입자/시트 항목을 프레임 크기 1:1로 32px 사람과 나란히 놓았다. 실제 빗방울 길이 4·7·10px로 사람보다 작다. 투명 프레임 16×24는 빗방울 자체 크기가 아니다. 64×32 바람 시트도 여러 작은 입자의 집합이다.
- 입력 모두 프로젝트 소유 파일. 합성만 수행했고 게임에 설치하지 않았다.
- 정지 합성의 제한: 실제 월드 좌표 업데이트, 깊이 정렬, 건물 지붕 충돌, 입자 수명, 바람·프레임 타이밍, 성능은 검증 범위 밖이다.
