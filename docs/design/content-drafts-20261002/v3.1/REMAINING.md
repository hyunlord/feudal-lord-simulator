# 남은 문제

- **실제 빈도는 미측정.** 사용자가 보고한125년2건은 이번 작업의 출발점이다. 창 확대와 봇 세율 조건 검증을 했지만, 게임 코드를 설치하거나125년 재실행하지 않았으므로 출현 횟수가 개선되었다고 주장하지 않는다.
- **LM-E9 보고서·11개 목록:** 지정 본선을 갱신해도 `docs/verification/lm-e9/AMBIGUOUS.md`가 아직 없었다. 등록된11개가 정확히 무엇인지 확인하지 못했다. 추정해11개를 골라 검토하지 않고60개 전체를 검토했다. 최종 확인 HEAD/시각은 `records/source-snapshot.json`에 기록한다.
- **실제 대상은 필요.** 새 청구·소송의 시대별 생성은 엔진 작업이다. 콘텐츠가 소송·감사·영지·후임·길드를 생성하지 않는다. 기존 대상이 없으면 해당 콘텐츠는 여전히 나오지 않는다.
- **소송 방어:** 현 명령은 이웃이 원고인 소송의 방어 효과를 표현하지 않는다. 영주 원고 조건 및 실제 증거/집행 단계를 유지한다. 다른 단계도 같은 선택으로 처리하는 것은 허용하지 않는다.
- **초기 장려금 설정:**004 등 현재0 조건은 그대로인 곳이 있다. 이미 설정된 약속을 덮거나 철회하는 다른 이야기를 만들지 않고 기존 선택의 의미를 보존했다. 실제 사업 후보·금고·수요가 필요하다.042는 장려금 가용성이 세율 선택을 막지 않도록 분리했다.
- **중복·쿨다운:** 일반 초안의 기존 반복 간격은 유지했다. 소송 변주는 새 suitId마다 재검토하되 같은 소송에서 카드4개를 연달아 내지 않는다.013·052도 같은 auditId를 재상신하지 않는다. 이 중복 억제·저장/복원 처리는 등록기 담당자가 검증해야 한다.
- **통합 검증:** 클릭 직전 현재 세율·금고·소송 단계·감사 기한·후임 생존을 재검사해야 한다. 복합 명령은 기존 비원자 절차이며 새 원자 명령이라고 하지 않는다.125년 판은 등록기 적용 후 사건별 '창 제외/대상 없음/조건 실패/중복 억제/출현' 수를 나누어 확인하는 것이 필요하다.

전체회귀·빌드·개발 서버 검증은 코드 수정이 없는 콘텐츠 작업이라 실행하지 않았다.
