실행 위치: Mac, 별도 읽기 전용 클론. 기준 HEAD `ce67158a7f2d24bf8d02cab45deb9b7209ed68e1`.

- 장부 조건 1,984행 = 게임용803 + 제외1,181. 교집합0, 누락0. 원본803개 SHA/규격 실측 일치.
- 실제 미설치744 = 가37 + 나425 + 다282. 설치된 동일 그림59는 public 원본/C2PA 제거 바이트를 대조하여 장부정리로 분리.
- 수령 묶음38 / 실행 계약47. INVENTORY 전 행에 대상·분류·사양 연결. 대상 경로 충돌0.
- 가37은 별도 읽기 전용 검수자가 현재 소스의 선택→그리기 경로와 크기·기준점을 대조. 기존 제외 스크립트까지 대조한 결과 강가 봄 grass1과 문장 bordure1은 나로 이동. 이 분류는 카탈로그에 항목이 있다는 사실만으로 정하지 않았다.
- TypeScript 카탈로그 조각은 삽입될 객체/배열 문맥에서 구문 검사: 3파일, 27블록, 이미지 항목35. 나머지 가2는 rock 전체 JSON 항목과 seal_slot 직접 CSS URL의 바이트 교체다. 전체 게임 typecheck/build는 설치하지 않는 범위이므로 미실행. [구문 검사](FRAGMENTS.json).
- 기존 대상 파일이 있는 가25장은 동일 캔버스 교체이며 title은 JPEG 경로에 PNG를 놓지 않고 새 PNG URL을 지정했다.
- 코드·inbox·장부·public 수정 없음. git status --porcelain 출력 없음. 커밋·푸시 없음.
- ZIP 내부 산출물 참조는 패키징 검사에서 확인하고, repo 경로는 기준 checkout 외부 근거로 명시한다. SHA256SUMS는 자기 자신을 제외한 모든 납품 파일을 포함한다.

## 남은 실제 설치 위험

Wave44 이미지와 HomePetitionKind는 마지막 종류가 일치하지 않는다. 장원 법정/숲 침범을 pannage/chancel_repair로 임의 치환하지 않는다. Wave41 바위의 미술 교체는 clipping 문제를 해결하지 않는다. 새 지역 지도·새 사건·시설/운송 표현은 그림 복사만으로 활성화되지 않는다. 피벗·계절 상태·새 콘텐츠 계약 미확정 부분은 해당 사양에 명시했으며 실화면 성공으로 보고하지 않는다.

브라우저 디코드·GPU 메모리·움직이는 가림·사람 판독·성능은 미검증이다. 예상 인시는 계획 추정이다. 이번 그림 조사에는 새 이미지 생성이나 그림 재승인·전수 육안 QA를 포함하지 않는다.
