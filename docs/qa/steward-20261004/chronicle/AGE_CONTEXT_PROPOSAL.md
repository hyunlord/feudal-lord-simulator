# 별도 나이 문맥 확장안

현재 variants.ko.json은650개로 유지한다. 아래 원고·검증은 R05의629개 기준에서 작성한 동결 자료를 바이트 동일하게 승계했다. 과거 검사수를 R06 재실행 결과로 세지 않는다. 별도 [나이 문맥 후보20개](../records/age-context-copy-proposal/README.md)는6개 사건종의 기록 당시 나이를 사용하며, 기존 schema와 호환되지 않는 context/slot 확장 제안이다. 아직 누적판에 병합하거나 엔진에 설치하지 않았다.

기록 읽기 adapter45검사·자연기록2개, adapter→문장선택→렌더69검사·자연기록20분기를 확인했다. 실제 엔진 formatter/UI 검증과는 구별한다. 일반 missing fallback과 가구 사건 거부를 유지했다.

R06에서 누락된 상대경로를 복원했다. 원고20개·어댑터·나이계약 세 폴더를 동결 R05와 SHA 대조했으며 출처·검증 기준은 원본 그대로다. 재현 스크립트는 당시 기준본·저장 입력을 요구할 수 있다. 정본650이나 별도 문맥 카탈로그에 중복 병합하지 않는다.
