# A 재생 부품 검수

범위: 통나무 2, 어린나무 2단계, 어린숲 2구성 × 여름·겨울 = 12 후보. 게임 미설치.

원본 project oak small/large를 스타일 참조로 사용했다. 여름마다 독립 내장 생성, 각 겨울은 대응 여름 원본을 참조한 계절 편집이다. 좌우 반전·회전은 사용하지 않는다. 통나무 A는 쌓인 참나무, B는 낮게 펼친 물푸레 통나무이며 그림 개수와 배치가 다르다.

통나무 캔버스 128×128, 피벗 (64,108). 식생 캔버스 128×192, 피벗 (64,172). 여름·겨울 한 쌍은 같은 캔버스·피벗·단계별 표시 크기를 사용한다. 생성 편집이 원시 프레이밍을 바꿔 합집합 크롭에서 겨울이 커지는 것을 발견했으므로, 각 원시의 알파 경계를 동일 단계 목표 크기에 정규화했다. 픽셀 동일 골격은 아니다. 지면 논리 발판 1칸(제작128×64), H 제작비교35.2px. 묘목 목표높이 24px / 36px, 어린숲은 약104~110px로 성숙 참나무 5~8H보다 작다.

검수 증거: regrowth-light.png / regrowth-dark.png는 확대 없는 실제 PNG 배치이다. 생성기 결과 해상도와 알파·경계·SHA는 regrowth-metrics.json, 정확한 프롬프트 및 입력SHA는 regrowth-generations.json에 기록한다. model/seed는 도구에서 공개하지 않아 null이다.

이 검수는 오프라인 후보 그림 검수다. 엔진의 줌·차폐·클릭 판정·계절 전환 렌더는 미설치 범위에서 검증하지 않았다. 생성 편집은 픽셀 동일 골격의 수작업 마스크 편집이 아니므로 계절 미세 형태 차이는 비교판에서 확인한다.

최종 판정: 실제 크기 밝은/어두운 배경에서 12개 시각 확인, 초록 묘목 두 단계와 잎 떨어진 겨울 대응 식별 가능. 여름/겨울 통나무 배열 유지, 어린숲 A/B 서로 다른 구성. RGBA 12개 모두 alpha 0~255, 바깥 경계alpha 0. 후보 오프라인 PASS.
