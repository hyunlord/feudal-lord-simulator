# Wave 22 upland 소품 자체 검수

상태: candidate. 게임 설치 없음. 검수 대상 10 PNG, 네이티브 생성 10회(각 1후보), 프로젝트 ZIP 참조 4장만 사용.

| 기준 | 판정 | 근거 |
|---|---|---|
| 출력 크기 | 통과 | 백악·돌담·고사리 128×96, 가시금작화 96×64 |
| 실제 RGBA·투명 여백 | 통과 | 모든 이미지 사방 최소 8px 완전 투명, 하단 접지 기준 pivot=(W/2,H-8). upland-validation.json |
| 변형은 구조 차이 | 통과 | 백악: 큰 판 / 분리된 두 봉우리 / 낮은 쐐기. 돌담: 직선 높낮이 / 낮고 무너진 반대 방향. 고사리: 왼쪽 높은 군락 / 두 관 / 낮은 방사형. 금작화: 왼쪽 높은 가지 / 오른쪽 높은 두 덩어리 |
| 줌 1.0·0.6에서 유형 | 통과 | upland-qa.png의 0.5·0.3배에서 밝은 백악, 선형 돌담, 부채꼴 고사리, 어두운 가시 관목을 실루엣으로 구분 가능 |
| 색·광원 | 통과 | 풀·숲 가장자리의 올리브 녹색, 따뜻한 회색 돌. 금작화 꽃은 드문 탁한 황색. 긴 투사 그림자 없음 |
| 세부 표현 | 조건부 | 핵심 형태는 큰 덩어리로 유지. 일부 돌 붓결·고사리 소엽·가시 끝은 작은 보조 디테일로 남아 있어 0.3배에서는 합쳐짐. 타입 식별은 이 미세 디테일에 의존하지 않음 |
| 반복 | 해당 없음 | decal은 반복 텍스처가 아님. 인접 같은 변형을 피하는 배치는 게임 코드 책임 |
| 실게임 통합 | 미검수 | 요청에 따라 후보 파일만 제작. 실제 지형 렌더·클릭·DPR·성능 미검수 |

접지 위치 주의: 하단 중앙은 캔버스 기준 anchor이다. 대각 돌담의 가까운 끝이 하단 경계를 이루므로, 중앙 x±4px의 실제 발밑은 y=78로 anchor y=88보다 10px 위에 있다. 그 외 소품은 중앙 접지와 anchor 간격 1–4px. 돌담을 경계선에 정확히 붙이는 설치 단계에서는 이 등각 발자국 차이를 반영해야 한다.

기계 후처리: 생성된 알파를 보존해 투명 캔버스만 크롭하고 한 번 비례 축소, 정확한 캔버스에 하단 중앙 정렬. 새 형태를 절차적으로 그리거나 색만 바꾼 변형을 만들지 않음. 각 실제 프롬프트·참조·네이티브 경로·생성 시각·후처리는 upland-sources.json에 기록.
