- 과거 실패 증거: [바인딩·맥락 원인](../eb-freq/binding-context-causes-2485af4.md), [나머지 원인](../eb-freq/other-causes-2485af4.md), [033 가중 경쟁 확정과 시대 제외](../eb-freq/classification40-2485af4.md), [147 외부 호출 누락](../eb-freq/outer147-2485af4.md). 과거 집계가 어느 개별 술어에서 실패했는지 기록하지 않았다면 미기록으로 유지한다.
- [조건34 감사](../eb-freq/condition-review.md)는 075 수정과 추가 좁힘 결함 미입증33을 구분한다. 이는 33개가 반드시 자연 도달한다는 보증이 아니다. 별도 [048 사실 생산 요청](../../requests/engine-B-freq-facts.md)은 이 30건의 누락 생산자 증거로 차용하지 않는다.

기존 원본에서 적격 상태를 찾고 정상 시간 진행으로 실제 제안을 포착하는 경로만 자연 입력으로 센다. 저장에 offer·인물·청원·연도·확률을 채우거나 실패 집계에서 과거 상태를 역산하지 않는다. 정상 UI로 조건을 만든 경로도 초기 상태와 행동을 보존하고 기본 봇 표본과 구별한다. 실제 제안을 확보하지 못한 항목은 `NO_AUTHENTIC_OFFER_INPUT`과 관측 범위를 남긴다. 준비 fixture의 성공, 후보 통과, 읽기 모델 결과는 실제 카드 포착을 대신하지 않는다.
