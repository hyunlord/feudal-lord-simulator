# 커밋된 season-core 독립 원본 시각 검토

판정: 준비 장면 10개에서 새 시각 회귀 없음. 실제 커밋 `208c622222b2d2a2b7d0aa883d6a598984b25ca4`, 실행 `astra-season-core-committed-208c622`의 개별 원본 PNG 10개를 모두 열었다. JPEG나 연락판으로 대체하지 않았다. 원본 경로·SHA와 기준/결과의 별도 식별정보는 `committed-runtime.json`에 있다.

| 계절/배율 | 관찰 | 판정 |
|---|---|---|
| 봄 1.0 / 0.6 / 1.4 | 흰 과수원 꽃, 주변 활엽수, 숲과 강 가장자리 확인. 0.6에서도 과수원 군집 식별 가능 | 새 회귀 없음 |
| 여름 1.0 / 0.6 | 녹색 과수원과 주변 나무의 배치·크기·지면 연결 유지 | 새 회귀 없음 |
| 가을 1.0 / 0.6 | 주황 수목과 녹색 과수원, 지면의 큰 색 패치·가느다란 대각선이 보임 | 기존 모습 유지 |
| 겨울 1.0 / 0.6 / 1.4 | 잎 없는 과수원과 주변 나무, 작은 눈·얼음 패치 확인. 0.6 과수원 대비는 낮음 | 기존 모습 유지 |

확대 1.4 화면 하단에서 과수원 일부가 잘리는 것은 카메라 프레임이다. 나무 자체의 새 직사각형 잘림·검은 배경·누락·피벗 이동은 보이지 않았다. 가을·겨울 지면의 거친 패치와 겨울 과수원의 낮은 대비를 품질 개선 완료로 간주하지 않는다. 기준과 결과 원본 PNG SHA가 10개 모두 같고 RGBA도 같으므로 이 모습은 이번 계약 이전의 새 회귀가 아니다.

독립 재확인: 10개 전체 identity(expectedRequests 포함) 동일, PNG SHA 동일, RGBA 동일, A/A 통과, 오류 0. 실제 결과 JPEG 7개와 실제 기준 JPEG 7개를 바이트 비교 후 각 쌍이 공유한다. 과거 재인코딩 JPEG 7개와는 바이트가 달라 별도 보존했다. before/after 논리 기록은 별개다. 원격 4,137개 입력 대조는 실행 소유자의 해시 영수증을 참조하며 이번 검토에서 원격을 재실행하지 않았다.

한계: 준비된 장면·고정 시각·단일 Chromium·1280×800 DPR1의 정지 화면이다. 자연 플레이, 계절 전환 애니메이션, 다른 GPU/브라우저/DPR, 모든 가림 조합을 증명하지 않는다. 본선 최종 게시 및 통합 관문은 별도다. 역사 detached 검토와 원본 파일은 보존했다.
