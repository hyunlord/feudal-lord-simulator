# 청원 군중의 사람 크기 맞추기 — RB-HEIGHT-CROWD

제품 `e75f2bab`. 새 PNG는 0장이다. 기존 청원 군중 그림 1장의 배율을 개별 인물의 높이에 맞췄다. 일반 성인·개별 청원인·운구인의 17.6px 기준과 군중의 발생 조건, 위치, 그림 자체는 유지했다. 문 23종과 운구대 접점은 별도 작업으로 계속하며 이 보고서로 전체 HEIGHT 작업을 끝냈다고 보지 않는다.

## 무엇이 달라졌나

원본에서 눈으로 구분한 13개 인물 실루엣의 머리/두건 끝부터 발 또는 치마 옷단까지는 42~47px, 중앙값은 43px다. 기존 배율 0.55에서는 중앙값이 세계 좌표 23.65px로 옆 성인보다 컸다. 이제 공통 성인 높이 17.6을 중앙값으로 나눈 약 0.4093을 사용한다. 등록된 인물별 결과는 약 17.19~19.24px다. 원본을 다시 그리지 않았으며 13은 그림 속 관찰값이지 엔진 인구가 아니다. 가려진 발과 옷단은 ±2 원본 픽셀의 수동 측정 불확실성을 갖는다.

`src/render/storyCrowdScale.ts`가 원본 좌표를 보존하고 `storyWorldProps.ts`의 기존 군중 그리기에서만 배율을 쓴다. 원본 SHA256은 `4702bfbc032f2c8d0b7ad94503fe4381704890122a64a699011997cf104939d1`이다.

## 실제 장면

기존 CART 정상 겨울 저장의 tick 23450에서 현재 엔진 `advanceTick`과 표준 advisor 명령으로 1,550틱을 진행했다. tick 25000에서 시장 칙허 청원이 실제로 발생하자 응답 전에 멈췄다. 건물·날짜·청원 필드를 직접 만들거나 수정하지 않았다. 이때 예배당 `construction-site-000009`이 기존 군중 소비 조건을 만족한다.

같은 저장과 카메라에서 줌 1.0·0.6·3.0 전후 3쌍을 캡처했다. 자동으로 열린 별도 청원 창 두 개는 일반 ‘나중에 정한다’ 버튼으로 닫았다. 6뷰 모두 엔진 상태 SHA256은 `a525587b8ff9b4771c1094e5cc2273ad0ed0b55b062ebe3c82b610fef44584ed`로 입력 저장과 같았다. 전 화면은 동일 제품 소스의 군중 호출 배율만 기존 0.55로 되돌린 명시적 렌더 비교이며, 후 화면에는 그 되돌림이 없다. 엔진 사실은 양쪽 모두 같다.

- [줌 3 전](before-crowd-z3.jpg) / [후](after-crowd-z3.jpg): 군중이 옆 개별 청원인과 비슷한 크기로 줄었다. 기존 곡창의 가림은 남아 있다.
- [줌 1 전](before-crowd-z1.jpg) / [후](after-crowd-z1.jpg): 도시 안에서 군중의 과도한 크기가 줄었다.
- [줌 0.6 전](before-crowd-z0.6.jpg) / [후](after-crowd-z0.6.jpg): 군중 소비를 draw trace로 확인했다. 이 크기에서 개별 얼굴이나 전원 수를 육안 판독했다고 주장하지 않는다.

현재 표본은 1306년 여름 한 장면이다. 겨울과 모든 청원 장소·가림 조합을 실제 실행했다고 주장하지 않는다. 군중 이동·동물·새 인구·새 건물은 추가하지 않았다. 문 크기, 운구대 접점 및 기존 운구 직선 경로/깊이 문제는 이 변경의 해결 범위가 아니다.

## 검증과 실행 보존

관련 Mac 시험 10개, 타입 검사와 변경 파일 린트가 통과했다. 새 시험은 원본 등록 끝점의 불투명도와 각 인물 높이, 공통 17.6 기준을 확인한다. 독립 원본 검토도 군중 42~47px와 중앙값 43을 지지했다. 해당 원본 검토에 포함된 운구 측정은 별도 미해결 범위의 참고 자료다.

판정에 사용한 공식 DGX 실행:

- `astra-HEIGHT-crowd-prepare-2b6d820`: 정상 진행 저장 준비, 실행 17.6초.
- `astra-HEIGHT-crowd-compare-before-41761f0`: 전 3뷰, 실행 29.5초.
- `astra-HEIGHT-crowd-after-41761f0`: 후 3뷰, 실행 34.0초.

위 작업은 한 브라우저의 순차 3뷰와 1,550틱의 짧은 준비로 제한한 공식 `--light --keep` 경로다. 성능 실험·장기 회귀를 light로 우회하지 않았다. 원본 PNG·전체 draw trace·재현 하네스는 보고 ZIP에, 경량 JPEG·정량 비교·정상 저장은 이 폴더에 보존한다. 게시 관문 결과는 `publication-gates.json`에 기록한다.
