# 아이콘 후보 검수

- 대상: 자원 6, 건설 분류 6, 층위 3, 상태 8, 커서 4. 납품은 가로 시트 5장이다.
- 모든 셀 순서는 의뢰서와 같다. info는 문자 i 대신 두 점이 든 청회색 말풍선이다. ok/block의 체크·교차는 상태 그림이며 문자가 아니다.
- 원본 생성 시 건설 도로와 길 커서에 섞였던 초록 식생을 별도 이미지 편집으로 황토색으로 수정했다. 생활 집의 굴뚝과 저장 아이콘의 잔소품도 이미지 편집으로 제거했다. 수정 전 원본과 전체 프롬프트를 보존했다.
- 96/32/24px 확인판을 실제 픽셀 크기로 확인했다. 주요 실루엣은 구별된다. 생활의 우물, 저장의 자루, 생업의 낫 같은 이차 요소는 24px에서 읽는 힘이 약해진다. 사용자 대상 무표시 의미 인지 시험을 통과했다고 주장하지 않는다.
- 프레임·텍스트·숫자·진행 bar·선택 사각형을 에셋에 넣지 않았다. 3크기 확인 그림의 라벨은 검수판에만 있다.
- 후처리는 원본 알파 경계 분리, 셀별 비례 축소와 중심 정렬, 작은 분리 알파 잡점 제거다. 프로그램으로 새 아이콘 도형을 그리지 않았다. 변환 수치는 icons.json에 기록했다.
- 커서의 화살표 방향은 모두 좌상향이다. 셀별 중심 정렬 후 끝점은 완전히 같지 않으므로 실제 적용 때 셀별 hotspot 확인이 필요하다. 게임에는 설치하지 않았다.
