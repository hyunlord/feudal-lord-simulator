# A″ 핵심 루프 마찰 정리

AI의 화면 기반 플레이는 사람의 조작 속도·인내·재미 판단을 대표하지 않는다. 실제 플레이, 준비된 UI 상태, 엔진 자동 진행을 아래에서 구분한다. 기준은 A′ `dc49d0e`; 제품 브랜치 `codex/phase15-organic-ground`. 배포·main 병합은 하지 않았다.

**현재 판정:** 원문 효율 조건을 엄격하게 다시 적용하면 seed 1·2·4·5는 유휴 일꾼 상한(일부는 밀 0 방앗간 비율도)을 넘겨 실패한다. seed 3은 120만 틱에서 교회 범위 밖 11가구가 남아 성장·안정 판정 자체를 통과하지 못했다. 따라서 5개 중 4개 이상 통과 조건은 달성하지 못했다. 새 게임 60분 재플레이도 목책 0/12로 끝나 A″-8 관문에 실패했다. 기능 회귀·UI 검수의 통과와 제품 목표의 미달을 구분한다.
