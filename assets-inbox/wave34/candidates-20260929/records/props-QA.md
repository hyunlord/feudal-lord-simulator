# Wave 34 소품 후보 6장 자체 검수

- 상태: candidate. 게임 설치 없음. 프로젝트 첨부 그림만 참조.
- native image_gen 호출 6회, 각각 별개 후보 1개. 실제 프롬프트·참조 파일·원본 경로는 props-sources.json.
- 배수 공사 4종: 수레 128×96 / 흙더미 96×64 / 수문 128×96 / 널다리 128×64.
- 여울 물튀김 A/B 각 96×64. A는 왼쪽 높은 짧은 초승달 물결, B는 낮고 긴 두 갈래 물결로 실루엣이 다름.
- 모든 PNG 알파 8px 여백 위반 0, 피벗 (폭/2, 높이−8), 반복 없음. 네이티브 RGBA를 보존.
- 기계적 후처리: alpha>24 영역 기준으로 여백을 자르고 비율 유지 1회 축소, 아래 중앙 정렬, 사방 8px 완전 투명 보장. 그림 재구성·색 교체 없음.
