# 워커 겹치기 검수

원본 템플릿의 각 셀에서 머리 상단23%와 양쪽 다리·신발 전체가 포함되는 하단35%를 원본 RGBA 그대로 보존했다. 발판 최하점만 비교하지 않고 이 영역의 모든 원본 비투명 픽셀 RGBA 및 전체 알파를 비교했다. 따라서 양발 위치·걷기 교대·머리 위치는 원본과 동일하다. 생성한 옷은23%~65% 몸통 영역에 한정해 원본 실루엣 내부에 등록했다.

축융공은 예외적으로 종아리 옷도 생성본에서 등록했다. 앞발 하단12%와 반대쪽 뒤꿈치가 들어가는 측면 하단30%를 넉넉한 신발 보호 마스크로 고정해 양쪽 신발은 RGBA 완전 동일하다. 머리와 실루엣도 원본 그대로다. 이는 원본 발 위치 유지의 직접 픽셀 증거이며 단순 바운딩박스 비교가 아니다.
