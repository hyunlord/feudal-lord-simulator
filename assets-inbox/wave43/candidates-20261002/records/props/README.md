# Wave43 봄 소품 6종 — candidate

게임 미설치. 프로젝트 소유 참조 5장을 실제 확인한 뒤 내장 image_gen.imagegen으로 6회 개별 생성했다. 원본은 raw, 실제 PNG는 assets, 전 프롬프트와 SHA-256은 records/provenance.json에 있다. 모델 식별자와 seed는 도구가 공개하지 않아 null이다.

manifest.json은 6종의 크기, 알파 경계, 하단 중심 피벗, 제안 월드 너비를 담는다. 캔버스 크기는 월드 크기가 아니다. 성인 H=17.6 기준 양은 작은 가축, 둥지 새는 작은 환경 소품으로 배치해야 한다. 빨래 기둥 높이가 사람보다 과도하게 커지지 않도록 월드 너비 40을 제안했다. 실제 엔진 설치 검증은 수행하지 않았다.

모두 신규 봄 전용 주제이므로 여름·겨울 대응 그림은 null이다. 스타일 참조인 기존 양 떼·여름 산울타리·물가·직조 마당·비둘기를 계절 대응 원본으로 오인하지 않는다. 비교 장면에서 여름·겨울은 해당 소품 부재로 표시한다.

검수: proofs/actual-size-bright.jpg 및 actual-size-dark.jpg의 1:1 PNG 크기 배치와 detail-2x.jpg를 실제 열어 확인했다. 어미 1+어린양 1씩 두 자세, 개울가 1, 흰 꽃띠 1, 새 1+알 2 둥지 1, 빨랫줄 1+나무통 1+바구니 1을 확인했다. 좌상광·자연스러운 양모/목재/린넨·무검정 외곽선·밝고 어두운 배경에서 테두리 오염 없음으로 통과했다. 꽃띠의 3회 반복 proof도 확인했다.

산사 띠는 AI 원본의 투명 여백을 수직으로 잘라 512×64로 맞춘 뒤 양끝 16열을 대칭 혼합해 X 경계 RGBA 최대차를 0으로 만들었다. 새 꽃이나 구조를 합성하지 않았다. 다른 5장은 비율 유지 축소만 했다. 전체 PNG의 alpha=0 RGB는 0이다. records/verification.json은 저장된 최종 PNG를 다시 읽은 실측 결과다.

상한: 생성 시점은 2:1 등각을 지시했지만 소품별 유기적 형태의 카메라 투영을 수학적으로 증명하는 검사는 아니다. 원본 raw는 고해상도 보존용이며 경량 ZIP에는 제외하고 별도 로컬 보존할 수 있다.
