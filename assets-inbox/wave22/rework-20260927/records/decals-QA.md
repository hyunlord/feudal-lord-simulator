# 새 지면 특징 데칼 15장 자체 검수

상태: candidate. 게임 설치 없음. 기존 통과 소품 20장과 별개이며 원본을 변경하지 않았다.

## 제작·규격

- 5유형 × 3장, 각각 개별 native `image_gen.imagegen` 호출. 15개 실제 프롬프트·원본 경로·참조·생성 시각은 `decals-sources.json`에 기록.
- A 64×48 / B 96×64 / C 128×96, RGBA, 사방 완전 투명 8px. 피벗 `(width/2,height-8)`.
- 생성된 알파 경계를 자르고 한 번 축소, 아래 가운데에 정렬. 8px 여백 강제 및 투명 픽셀 RGB 2px 확장만 수행. 색 재작성·코드 그림·임의 소품 합성 없음.
- 데칼은 반복 텍스처가 아니므로 XY 반복 조건 없음. 불규칙한 위치에 결정론적으로 배치하는 합성은 확인 그림 담당 영역.

## 검수 범위와 한계

`decals-qa.png`에서 원본·0.5·0.3을 직접 비교했다. B/C를 중심으로 A를 보조 배치하는 것이 적절하다. 15장 전체는 계절 공용의 중립 색조이며 겨울 눈 피복을 자체 포함하지 않는다. 실제 게임에서의 계절별 가시성·배치 밀도·가림은 설치하지 않았으므로 미검증이다. 가장 작은 자국의 세부는 축소 시 의도적으로 통합되며, 개별 자연물 식별보다 지면 유형의 보조 단서 역할이다.
