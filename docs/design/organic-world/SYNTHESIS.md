# 유기적인 땅 — 설계 3종 통합안 (2026-09-24)

대상: **Fable 설계안 v1**(`c26f9af`, 원칙·0단계·에셋 규격) · **설계 v3-A**(Claude Code, `c26f9af`+`dd19986`, 탐침 5종으로 수치 근거) · **설계 v3-B**(Codex 세션 `astra-v3`, `cc20def`+`dd19986`, 저장·편집 계약 상세)
원칙: 셋 다 (나) "판정은 격자, 곡선은 파생"으로 수렴. 차이는 **무엇을 저장하느냐**와 **1단계 범위**.

## 1. 세 설계가 일치한 것 → 확정

| 항목 | 내용 |
|---|---|
| 구조 | (나) 격자 판정 + 곡선 표면. 자유 좌표(다) 기각 |
| 도로 그래프 | **4-연결 유지**, 이동 비용 맨해튼(대각 길은 보이는 길이의 약 1.4배 걸음). A 탐침: 8-연결 이득은 정확히 45°에서만 |
| 도로 렌더 | 도로 셀 체인에서 파생한 중심선 + 리본. 교차로·막다른 끝·성문·다리 경계는 **고정점**. 광장(2×2 이상)은 윤곽으로 |
| 성벽 | 논리 원본 = 기존 격자 모서리 경로. 곡선은 표시 전용. 성문 주변 직선 잠금. 벽 운반·공사 구간 무변경 |
| 지형 경계 | 셀에서 marching squares 계열 윤곽, 이웃이 **같은 선 하나를 공유**. 숲·물 의미 무변경 |
| 구역 | 원본 = 그린 형상, 판정 = 셀 소속(셀 중심 기준). frontage 필지는 도로를 따라 파생 |
| 렌더 성능 | Canvas 2D 유지, clip 없는 직접 채움, **지면 청크 래스터 캐시**, 기능 플래그 |
| 에셋 | 표시 크기 기준 제작(Astra 파일럿 교훈), 띠 경작지는 절차 띠 + 상태 재질, 텃밭은 큰 이랑 소품 |

## 2. 갈린 것 → 채택안

| 항목 | Fable | v3-A | v3-B | **채택** | 이유 |
|---|---|---|---|---|---|
| 저장하는 것 | 없음(구역은 3단계) | **`zones[]`만**(v2) | 도로 원본 곡선·소유자·제외 셀·폐기 ID·확정 필지·구역 | **A** | 저장이 늘수록 이주·결정론 부담이 커짐. B의 도로 원본 저장은 획 충실도가 부족할 때 2단계 선택지(A의 Q2)로 |
| 도로 스무딩 | Catmull-Rom, 지그재그 합치기 | **이동평균 5 + Chaikin 2**, 노드 고정 | 정수 flatten + cubic | **A** | 탐침 근거: 셀 중심 직접 스무딩은 계단이 뱀처럼 되살아남, A 방식은 리본 넘침 0 |

| 꼭짓점 변위 | hash ±0.12칸 | 없음(변 중점 통과) | 없음 | **없음으로 시작** | 무작위 흔들림 금지 원칙과 거리. 필요하면 아트 판단으로 추가 |
