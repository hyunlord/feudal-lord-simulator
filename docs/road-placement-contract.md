# 도로 드래그 계약

드래그가 지나는 기존 길과 정상 다리는 그대로 두고 새 칸에만 길을 놓고 비용을 매긴다. 여러 기존 다리를 지나도 새 물 칸이 없으면 각각의 완성된 다리를 재사용한다. 새 물 칸은 드래그 안에서 연속된 한 구간이어야 하며, 완성 후 그 구간의 모든 물 칸은 길이 있는 양쪽 육지 둑과 최대 8칸 제한을 만족해야 한다. 같은 드래그로 기존 물길의 빠진 육지 둑을 채우는 것도 완성 후 상태로 판정한다.

건물 점유와 지도 밖 칸은 선 전체를 거부한다. 새 칸이 없으면 자원과 상태를 바꾸지 않는다. 물 구간이 있는 드래그는 기존 성벽 통행 판정을 유지한다. 완공 성벽을 가로지르는 육지 길을 칠하더라도 새 성문을 만들지는 않으며 주민 통행은 계속 차단한다. 이 동작은 A⁵ 이전과 동일하다.
