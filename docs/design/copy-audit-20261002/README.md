# Astra 문구·고증 감사 패키지

- COPY_AUDIT.md: 발견 52건과 위치·수정안·근거.
- GLOSSARY.md: 용어·화폐·날짜·문체·청원 제목·이름 정본.
- SOURCES.md: 역사 자료와 저장소 기준, 확인 한계.
- DUPLICATES.md: 반복 후보 82묶음의 분류.
- VALIDATION.md: 범위·원문 대조·격리 함수 실행·무변경 검증.
- records/: 기계로 다시 확인할 수 있는 목록·원문 근거·검증값.
- SHA256SUMS: 문서와 기록의 SHA-256. 압축을 푼 폴더에서 `shasum -a 256 -c SHA256SUMS`로 확인.

게임 파일에 적용된 변경은 없다. 고정 SHA와 외부 출처의 확인일은 COPY_AUDIT.md와 SOURCES.md에 명시했다.
