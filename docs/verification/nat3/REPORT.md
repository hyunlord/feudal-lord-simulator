# NAT-3 세계 속 비와 쌓이는 낙엽

Wave 39 50장을 원본 바이트 그대로 설치했다. 비 재료 20장·낙하 낙엽 12장·낙엽 잔해 10장·물웅덩이 8장이다. 기존 Wave 7 낙엽 3장은 계약으로 옮겼으며 신규 설치 수에 더하지 않는다.

비는 화면 좌표 대신 세계 좌표에서 생기고, 진한 비 띠가 세계를 지나간다. 실제 활엽수에서 잎이 떨어지고 가을이 진행되며 바닥에 쌓였다가 겨울 초에 줄어든다. 현재 날씨 일정에 따른 젖음 표현이며 실제 토양 수분이나 과거 강우량을 새로 저장하지 않는다. 지붕 접촉은 등록된 집의 기존 눈 그림에서 얻은 보수적인 지붕 영역에만 적용한다.

- 구현: `fbdb5cddb441f4ffc40e34262fbba2ef3907df45`. 원본 50장 SHA256 일치. 새·관련 TypeScript 시험 53개, 생성기 시험 2개·타입 검사 통과.
- DGX 실행: `astra-NAT3-before-461dd5e`, `astra-NAT3-after-fbdb5cd`. 1280×800·DPR 1, 각각 71프레임. 원본과 캡처 도구는 해당 보존 실행에 남겨 두었다.
- 실제 게임: 설치 전 `461dd5e1`과 설치 후 `fbdb5cdd`의 11개 구도에서 초기 저장·디코딩 상태·틱·카메라가 모두 일치했다. 줌 1.0과 0.6에서 여름·겨울·가을 초·말·비 장면을 비교했다. 가을 초기 저장에서 엔진을 100·850틱 진행한 것이며 계절 값을 덮어쓰지 않았다.
- 설치 후 실제 그리기 호출에서 신규 41종을 관측했다. 호출은 화면 노출이나 모든 픽셀의 가시성을 보증하지 않으며, 50종 모두 각각 보였다고 주장하지 않는다.
- 비와 낙엽 연속 장면은 실제 재생 21프레임이다. MP4는 그 실제 캡처를 1fps로 묶은 검토용 슬라이드이며 매 렌더 프레임을 녹화한 영상은 아니다. 프레임별 틱과 캡처 종료 틱을 기록했으며 재생 중 캡처는 같은 순간의 픽셀 비교가 아니다. 비 줌 1.0에서 정지 틱 유지, 휠 줌 1.0→1.1, 중간 버튼 이동 80×30px, 재생 재개를 실제 입력으로 확인했다.
- 캡처 도구는 개발용 통계 POST 취소 때문에 전후 모두 종료값 1을 냈다(설치 전 13건·후 10건). 원본 오류를 보존한다. 게임 예외·그림 로딩 오류는 관측되지 않았지만 통계 취소의 원인은 확정하지 않았다. 이를 오류 0 또는 캡처 도구 전체 성공으로 바꾸어 쓰지 않는다.
- 눈송이·나무마다 계절 위상·첫서리·눈 쌓임은 다음 작업이다. NAT-3 전체 완료가 아니라 비·낙엽 묶음의 설치다.

통합본 `6685d294`의 DGX 깨끗한 클론 4,997/4,997·타입 검사·빌드 통과. 기하 감사 2,262조건·실패 0·미측정 0 통과. 실행은 `astra-NAT3-merged-clone-6685d294-6685d29`, `astra-NAT3-merged-geometry-6685d294-6685d29`이며 결과는 GATES.json에 있다. 최종 커밋의 check:merge·본선 해시는 배포 ZIP에 기록한다.

| 화면 판정 | 결과 | 근거와 한계 |
|---|---|---|
| 큰 화면 비 띠가 짧은 세계 입자로 바뀜 | 참 | 같은 비 저장의 전후 줌 1.0·0.6. 먼 줌의 가는 비는 약하게 보인다. |
| 가을 초보다 말에 나무 주변 낙엽이 늘어남 | 참 | 실제 진행 틱 22100·22850, 같은 숲 카메라. 초반부터 넓게 깔리던 옛 낙엽을 대체했다. |
| HUD를 비가 덮음 | 오탐 | 날씨는 세계 캔버스에만 그리며 전후 화면의 DOM HUD를 덮지 않는다. |
| 신규 50종 모두 개별 픽셀이 보임 | 불확실 | 그리기 호출 41종, 미관측 9종은 NOT_OBSERVED.json. |

그림: `before/after-autumn-early-z1.jpg`, `before/after-autumn-late-z1.jpg`, `before/after-rain-band-z1.jpg`, `before/after-rain-band-z0.6.jpg`. MP4 두 개는 원본 캡처를 960×600·1fps로 줄인 검토본이며 원본 프레임 해시는 runtime 기록에 있다.

첫 깨끗한 클론은 4,973/4,975 통과·출처 검사 2개 실패다. 코드 커밋에 새 50장의 출처 장부가 아직 들어 있지 않았다. 캡처 뒤 작성한 장부를 이 보고서와 함께 넣었고 Mac 출처 시험 5개가 통과했다. 첫 실패와 그 실행의 빌드·기하 미실행을 보존한다. 수정본의 전체 클론·빌드·기하는 위 결과대로 통과했다.

검사 도중 본선 `d041e9ff`에 사건 카드·연대기 UI가 들어왔다. 두 작업은 자동 병합으로 모두 보존했다. `astra-NAT3-fixed-clone-ba6b272`에서 `ba6b2726`의 수정 클론은 4,975/4,975·타입·빌드를 통과했다. 이전 UI 입력의 기하 실행 `astra-NAT3-geometry-ba6b272`는 본선 변경 때문에 중단했다(1,716개 측정까지의 부분 결과). 이를 통과로 재사용하지 않고 통합본에서 전체 클론·기하를 다시 통과했다. NAT-3 세계 렌더와 그림은 `fbdb5cdd` 캡처 뒤 바뀌지 않았다.

실행 `astra-NAT3-merged-smoke-6685d29`에서 통합본 `6685d294`의 실제 비·가을 장면 2개를 다시 확인했다. 기존 설치 후 캡처와 저장·디코딩 상태가 일치하며 오류 없이 종료했다. `merged-smoke.json`에 결과를 기록했고 실제 확인판은 배포 ZIP에 포함한다.
