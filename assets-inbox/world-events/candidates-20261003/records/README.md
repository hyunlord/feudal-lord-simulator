## 그림 사용

- 새 무리 24개는 **정지 1프레임 전체 그림**이다. 몸·팔·벽 조각을 새로 맞추는 방식이 아니다. 걷는 애니메이션이라고 주장하지 않는다.
- 기존 인물 시트는 296×148, NE/SE/SW/NW 4열 × 두 걸음 2행이다. 시트별 정확한 발 기준점과 인물 실높이는 manifest의 perFrameAnchors를 쓴다. 셀 아래 중앙으로 일괄 정렬하면 안 된다.

- 여름·겨울판은 같은 캔버스·발 기준점이다. 의복 윤곽까지 픽셀 일치하는 리스킨은 아니다. 기존 all 계절 그림은 원본 재사용이며, 새 겨울 워커를 그렸다고 세지 않는다. 망토는 지정 template에서만 쓴다.

- 기존 침수 이랑은 불투명 반복 **재료**다. 독립 투명 소품처럼 붙이지 말고 실제 밭 렌더러의 등각 변환·경계 자르기를 쓴다. 검증용 투명 flood-layer4개는 이 방식으로 뽑았다.

## 검증 범위

원래 저장 파일을 실제 개발 서버에서 불러온 후, 같은 도시의 계절과 카메라만 준비했다. 도시·눈·식생은 실제 렌더러다. 새 사건은 PNG를 **오프라인 합성**했다. 자연 플레이 사건 발생, 경로 탐색, 보행, 프레임 재생, 깊이 정렬, 가림 처리, 성능, 엔진 연결은 검증하지 않았다.

현재 장원은 placeholder여서 완성 법정 배경으로 사용하지 않았다. 판결은 서쪽 진입로의 임시 법정 탁자 제안이다. 겨울 홍수 역시 기존 자동 발동 조건이 아닌 제안이다. 벽 부착 문 표식은 복원하지 않고, 이번 요청에 맞춰 문 앞 독립 표지로 그렸다.
