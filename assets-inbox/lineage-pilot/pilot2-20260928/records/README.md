# 혈통 초상 파일럿 2

기존 파일럿의 실패한 세 형제 쌍, L1_203·204 / L2_201·202 / L2_203·204만 다시 제작한 후보입니다. 게임에 설치하지 않았습니다. 기존 초상은 그대로 보존했습니다.

## 구성

- 여섯 인물의 아기·어린이·청년·장년 24장, 256×256 PNG.
- 확인 그림: 익명 12쌍, 4단계 연령 사슬(256px·96px), 기존 청년 초상 대비.
- assets.csv: 각 초상의 가족 공통점, 개인 차이 표식, 나이, 복식, 실제 부모 참조, 프롬프트, 후처리, 검수.
- raw/: 생성 원본과 교정 이력. references/: 사용한 프로젝트 초상 참조.

## 새 제작 규칙

가족 공통점은 머리색·전체 얼굴형·눈썹 한 특징만 지정합니다. 코·턱을 특정 부모에게서 정확히 복사하는 규칙은 폐기합니다. 각 인물의 머리 길이와 모양, 눈 색, 어깨 폭, 주근깨 또는 점을 구분하고 연령 사슬 안에서 유지합니다. 상속은 예술적 식별 계약이며 생물학적 예측이 아닙니다.

형제의 어린이·청년·장년 단계는 같은 시점 비교에서 3살 차이입니다. 아기 단계는 각각의 유아기를 따로 그린 것으로 같은 시점의 나이 비교가 아닙니다. 영주 가문에는 고운 모직과 모피 깃, 미혼 소녀에는 베일 없는 복식을 적용합니다.

## 익명 판정 절차

형제 어린이 비교 3쌍 + 청년 비교 3쌍, 동일인 어린이·청년 비교 6쌍을 섞습니다. 쌍의 순서와 좌우를 결정론적으로 무작위화합니다. 제작에 참여하지 않은 새 검수 에이전트에게 번호만 있는 그림을 주고, 정답과 같은/다른 사람의 비율은 제공하지 않습니다. 12개 모두 일치해야 통과입니다.

이 검사는 에이전트의 시각 판정이며 사람 대상 시험이 아닙니다. 머리·복식·표식도 보이므로 순수 얼굴 형태만의 판정으로 해석하지 않습니다. 아기·장년은 연령 사슬 검수판으로 확인하며 12쌍 관문의 직접 평가 대상은 어린이·청년입니다.
