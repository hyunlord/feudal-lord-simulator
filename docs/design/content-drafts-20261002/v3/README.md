# 사건·청원 초안 v3 변경분

게임: **Charter & Kin / 인장과 가문**. 2026-10-03, 콘텐츠 검토용이며 게임에 설치하지 않았다.

`events-v3.json`은 v2의 배열/레코드 형식을 유지한 **변경분만**이다. 원본 60개를 이 15개로 덮어쓰면 안 된다. 통합 담당자는 `id`로 기존 초안을 찾아 교체하고 원본 번호를 유지한다. 등록기 예제의 배열 인덱스를 그대로 재사용하지 않는다.

- `CHANGES.md`: 초안별 수정 이유·숫자·엔진 근거.
- `REMAINING.md`: 엔진 바인딩과 확인하지 못한 범위.
- `events-v3.schema.json`: 같은 초안 형식의 JSON Schema Draft 2020-12.
- `VALIDATION.md`, `records/validation.json`: 수행한 검증과 한계.
- `records/THRESHOLDS.md`, `records/COMMANDS.md`, `records/FORMAT.md`: 필드·명령·문구의 상세 대조.
- `SHA256SUMS`: 이 파일을 제외한 납품 파일의 SHA-256.

v2의 `registry.schema.json`은 `proposalVersion/policy/entries` 객체인 **등록기 제안 예제**를 위한 스키마다. 초안 배열용 스키마와 다르다. 이번 스키마 통과는 초안 구조 검증이며 LM-E9 실행·노출 성공을 뜻하지 않는다. 조건 문자열의 식을 `eval`해서는 안 된다. 조건에 쓰인 파생 별칭은 통합 담당자를 위한 명세이며 새로운 GameState 필드가 아니다.

금액은 페니(d), 입력값은 콘텐츠 밸런스 결정이다. 장려금은 즉시 지급·건설하는 명령이 아니라 종류별 지속 설정이다. 이후 같은 종류 사업에도 지급될 수 있으므로 자동 만료나 누적 지출 상한으로 해석하지 않는다.

검증 환경: Mac, 문서/JSON의 오프라인 검증. 저장소 코드를 변경하지 않았고 커밋·푸시하지 않았다. 개발 서버도 실행하지 않았다.
