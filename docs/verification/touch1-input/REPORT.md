① 자세히:
- **기기 대응:**

| 마우스 단계 | 터치 동작 |
|---|---|
| 끌기 | 한 손가락 끌기 |
| 클릭 | 탭 |
| 길 끌기 중 우클릭 | 둘째 손가락(획 버림) |
| 가운데 버튼 끌기, Space+끌기 | 두 손가락 끌기 |
| 휠 1.1·1.1·0.9 | 같은 비율·같은 중심의 핀치 한 번(거리 100→110→121→108.9) |
| 공사 우클릭 | 그 자리 두 손가락 탭 |
| UI 버튼 클릭 | 버튼 탭 |

  - 키(Esc·Z·]·D 누름)는 그대로 둔다.
- **허용 오차:**
  - 핀치는 비율의 곱으로 휠과 같은 배율에 닿는다. CDP 터치 좌표가 단정밀도라 줌이 2.4×10⁻⁷ 다르고, 이것을 1×10⁻⁶ 안으로 판정했다.
  - D 누름(시간 적분)은 B9와 같은 규칙(마우스끼리 차이 또는 이동의 10%)이다. 0.40px 차이로, 이동은 379px였다.
  - 나머지 카메라 차이는 0.0002px 이하다.
- **재생에서 드러난 차이:** 구역 붓 단계에서 처음에는 터치가 28칸, 마우스가 18칸을 칠했다.
  - 원인: 앞 단계(가운데 끌기·확대)로 지도가 움직여, 붓 획 경로가 하단 건설 메뉴 아래로 지나간다. 마우스는 그 위의 움직임이 메뉴로 가서 획이 따라가지 않는다. 터치는 시작한 캔버스로 움직임이 계속 와서 메뉴 아래 칸까지 칠했다.
  - 고침: 터치도 마우스처럼, UI 위 한 손가락 움직임은 획에 넣지 않는다(DOM 적중 검사, 결정 IN4). 가려진 칸을 보이지 않게 칠하지 않는 것이 맞다고 보았다.
  - B9 본선 마우스 기록도 18칸이다.
- **마우스 회귀:** B9 재생(`scripts/inputReplayCompare.mjs`)으로 본선 대 이 빌드를 비교했다. 13/13 같다(`mouse-replay-vs-trunk.json`). 포커스 복귀도 마우스 결과를 바꾸지 않았다.

## 만든 것
- **터치 번역기(`src/input/touchTranslator.ts`):** 한 손가락은 마우스 번역기의 왼쪽 버튼을 그대로 부른다(같은 좌표 경로·4px 문턱·도구 규칙). 두 손가락은 이동·핀치, 400ms 길게 누르기는 `inspect`, 두 손가락 탭은 취소다.
  - 구역 붓 전용이던 `zoneTouchTranslator.ts`를 대신한다.
  - `inspect`는 지도 처리기가 마우스 호버와 같은 상세 카드로 보여 준다.
- **게임패드 번역기(`src/input/gamepadTranslator.ts`):** 지도 커서(왼쪽 스틱 데드존 0.2·가속, 방향 패드 한 칸, 가장자리 자동 이동), 오른쪽 스틱 이동, 트리거 확대, A/B/X/Y·LB/RB·Start/Back이다.
  - A는 커서 위치에서 마우스 왼쪽 버튼을 부른다.
  - 액션 표 `controllerActions.ts`의 게임패드 열이 실제 배정이다.
- **지도 커서(`src/render/mapCursor.ts`):** 커서 아래 칸의 금색 마름모와 커서 점이다. 게임패드가 마지막 장치일 때만 그린다.
- **포커스 복귀:** `domInputBindings.ts`에서 지도 mousedown·touchstart 때 포커스된 컨트롤(글자 입력칸 제외)의 포커스를 뗀다.
- **입력 장치 자동 감지(`src/input/inputDevice.ts`):** 하단 안내 줄과 구역 붓 문구가 마우스 / 터치 / 게임패드별로 바뀐다(`src/ui/inputHintCopy.ko.ts`).
- **회귀 재생 스크립트:**
  - `scripts/touchReplayCompare.mjs`(터치 대 마우스)
  - `scripts/gamepadReplay.mjs`(가상 패드)
  - `scripts/focusReturnCheck.mjs`(포커스)
  - `scripts/handcartEvidence.mjs`(손수레)
  - `openScene`에 `hasTouch`·`initScript` 선택지를 더했다.
- **단위 시험(`tests/touchGamepadInput.test.ts`, 7개):** 터치 끌기·탭 = 마우스 결과, 두 손가락, 길게 누르기·두 손가락 탭, 패드 커서·데드존·A 배치, X·A 누른 채 칠하기·B 취소.
