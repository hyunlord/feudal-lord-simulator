# seed3 성장·안정 방침 150년 완주 비교

같은 seed 3·open_field·lord 모드의 고정 growth/stability 두 실행을 비교했다. 두 판의 저장 시작 state는 agency.policy만 다르다. HEAD와 실행에서 검증한 9개 소스 해시, 프로토콜, dues 1000·subsidies [] 통제가 같고, 양쪽 모두 1450년 tick600000에서 정상 종료했다. 성장 988초, 안정 967초는 실행 시간이며 플레이 시간이나 성능 벤치마크가 아니다.

이 두 경로에서 안정은 금고가 많고 famine 사망이 적으며, 성장은 최종 도시 인구와 주택이 더 많다. **한 seed의 결정론적 정책쌍에서 관측한 결과**다. 같은 seed여도 인물 생성·사건 선택·혼인 시점·영지 취득이 갈리므로 전체 차이를 특정 정책 지렛대의 직접 효과로 분리할 수 없다. 여러 seed의 일반 효과·유의성·역사적 사실·게임 최적 전략이나 재미를 판정하지 않는다.

## 검증과 측정 단위

원본 양쪽 manifest 통과, 시작·최종·연간·명령·등록기·codec 기록을 읽었다. 각 150개 연간 행은 periodYear1300–1449에 연속한다. `year`는 1301–1450의 다음 연도 경계다. 아래 금고·인구·재고·주택은 경계 상태, 명령·사망은 표시된 기간 발생량이다. 원본 state의 정책 외 차이가 없음을 재귀 직렬화가 아닌 실제 JSON 구조 비교로 확인했다. 각 연말 사망 누계는 최종 ID의 deathYear로 150/150 재현했고, 성장 자료는 기존 성장 분석 ANNUAL과 정확히 같다.

## 인계와 남은 한계

DATA.json은 독립 run namespace 아래 원본 연간300행, 사망 ID, 최종 도시·영지·세력·직업·역병, 집별 용량, 명령 요약을 담는다. 경계 상태와 해당 기간 발생수는 units에 명시했다. INPUT_SHA256.json은 두 동결 입력 폴더, SOURCE_SHA256.json은 실행에서 검증된 소스 핀, SOURCE_FILES.json은 이번 해석의 코드와 기존 성장 분석 핀이다. VALIDATION.json과 SHA256SUMS로 검산한다.

자료의 정책쌍 비교 가능성은 확인됐다. 그러나 실제 정책의 국소 작동 경로, 사람별 위험 노출, 현금 흐름 전량, 자원 보존, 플레이어 재미와 최적 방침은 검증하지 않았다. 이번 범위를 넘어 엔진이나 동결 기록을 바꾸지 않았다.
