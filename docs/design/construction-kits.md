# 건물 계열별 공사 키트 (INSTALL-11, Wave 11)

근거: INSTALL-11 지시서와 Wave 11 55장(`assets-inbox/wave11/candidates-v1`, 판정표 confirmed).
코드: `scripts/installWave11.py` → `src/render/wave11ArtManifest.generated.ts`, `src/render/wave11Art.ts`(공용 `manifestArt.ts`), `src/render/constructionKits.ts`, `src/render/demolitionMoments.ts`, `scripts/buildWalkerSheetManifest.py`(목수·석공 시트, 톱·자귀·흙손).
규칙·저장 형식은 바꾸지 않는다. F0-V의 기준점·bar·더미·먼지·완공 연출은 그대로 두고, 단계 그림만 키트로 바꾼다.

## IK-1 계열·크기(`constructionKitFor`)
| 계열 | 건물 | 키트 | 기준 캔버스(그 그림의 rect·crop으로 그린다) |
|---|---|---|---|
| 목조 | 오두막, 벌목장 | 소 | L0 집 |
| 목조 | 헛간, 제재소, 방앗간 | 중 | L2 집 |
| 석조 | 석공소, 예배당 | 중 | 석공소 |
| 석조 | 창고, 곡창 | 대 | 창고(발판 맞춤, R0-2) |
| 공공 | 교회, 성채 | 전용 | 교회, 성채 |
| 방어 | 석벽 공사장 | 탑 | 모퉁이마다 |

- **폴백:** 우물은 전용 3단계를 쓴다. 장터·채석장·옛 밀밭과 목책은 공통 4단계 그림을 쓴다.
- **단계:** 공사 단계 25/55/85 % 경계에서 키트 그림 4장(터·기초·골조·지붕) 가운데 하나를 고른다.

## IK-2 공사장 소품(줌 1.0 이상, 발판 밖 가장자리 결정론 배치)
- **목조:** 들보 더미·눕혀 짠 벽 틀(기초), 톱 구덩이(골조·지붕).
- **석조:** 모르타르 통·석회 더미(기초부터).
- **공공:** 답차 기중기와 매단 돌(골조부터), 홍예틀(골조), 모르타르 통.

## IK-3 공사 워커
- **몸:** 키트가 있는 공사장의 건설 워커는 계열의 몸을 입는다. 목조는 목수, 석조·공공·방어는 석공이다.
- **도구:** 목수는 기초까지 자귀, 골조부터 톱을 든다. 석공은 흙손을 든다.
- **시트:** 시트 band는 `kit`이다. 어떤 직업 풀에도 들어가지 않는다.

## IK-4 철거 = 키트 역순
- **동작:** 완성 건물이 상태에서 사라지고 그 발판에 아무것도 서지 않으면 철거로 본다. 합쳐진 쌍집이나 재건축은 철거가 아니다.
  - 계열 키트가 지붕 → 골조 → 기초 → 터 순으로 1.2 s 돌고, 마지막 1/4에 흐려진다.
  - 5배속부터는 생략한다.
- **조건:** 이어지는 상태(틱이 0~60 진행, 한 번에 3채 이하 사라짐)에서만 본다. 불러오기·새 장면은 철거로 보지 않는다.
- **기억:** 표현 기억이다(사라진 건물과 시작 시각, 시계가 뒤로 가면 초기화).
