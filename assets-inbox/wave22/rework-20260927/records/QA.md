# Wave22 수정본 자체 검수

범위: 후보 PNG와 오프라인 합성. 게임 미설치, 게임 코드 미변경.

## 수정 내용

1. 이전 fill 15장을 제외하고 유형·계절마다 a/b 2장씩 총 30장으로 교체했다. 큰 백악 얼룩·물웅덩이·덤불·모래 패치를 fill에서 제거했다.
2. 지면은 기존 grass.png 수준의 잘고 대비 낮은 붓결을 가진 바탕이다. 백악은 건조한 올리브, 히스는 어두운 갈올리브, 습지는 회녹색, 해안은 모래빛 올리브, 숲은 회갈색으로 구분한다.
3. 유형 특징은 새 데칼 15장으로 분리했다. 유형당 소·중·대 3개이며 실제 형상도 서로 다르다.
4. 모래 해안 A의 같은 간격 물결을 비대칭 만입·길이가 다른 해안 구간으로 수정했다.
5. 사용자 통과본 35장은 원본과 동일하게 보존했다.

## 판정 기준

| 검사 | 기준·근거 |
|---|---|
| fill 단독 반복 | 각각 4×4를 기존 풀밭 4×4 옆에 배치, 원본 0.5/0.3 배율에서 큰 얼룩·격자·접합선 확인 |
| fill a/b 혼합 | 같은 계절 a/b 교대 배열 및 장면의 좌표 해시 혼합. 끝점 픽셀 일치와 평균색 차이를 함께 확인 |
| 유형 장면 | 같은 기존 주택·나무 위치에 바탕과 새 특징 데칼만 변경. 데칼을 빼도 바탕에 큰 모티프가 남지 않도록 구성 |
| 해안 A | 3회 X 반복과 기존 B·물가를 병렬 비교. 같은 간격의 정현파처럼 보이는지 확인 |
| 결정론 | 같은 시드 재실행, 후보 순서 역전, 이웃 셀 추가, 선택된 데칼의 비중복 검사 |
| 데이터 | 81개 ID/크기, 실제 알파, 데칼8px여백, fill XY·strip X 접합, CSV81행20열·프롬프트 재읽기, 통과본35개 해시 |

## 관찰과 제한

- 각 fill의 단독·a/b 혼합 4×4에서 이전의 큰 얼룩 격자는 관찰되지 않았다. 저주파 명도 측정과 실제 비교 그림은 각 fill 검수 기록에 있다. 끝점 수치 0만으로 시각 검수를 대체하지 않았다.
- a/b의 평균색은 동일 계절끼리 맞추고 경계의 좁은 띠만 공유했다. 전역 블러로 무늬를 숨기지 않았다. 생성·색조 정리·접합 후처리를 CSV에 기록했다.
- 가장 작은 64×48 데칼은 줌 0.6에서 보조 흔적으로 읽힌다. 유형의 주요 특징은 중·대형 데칼과 함께 판단한다. 특히 작은 웅덩이는 단독으로 물이라고 식별하기 어렵다.
- 새 데칼은 중립적인 자연색 기본형 15장이다. 이번 범위에서 별도 계절별 데칼 세트는 추가하지 않았다.
- 같은 이미지의 수학적 반복은 남지만, 큰 특징 모티프를 바탕에서 제거해 반복 도장 인상을 줄였다. 작은 붓결의 반복이 어떤 배율에서도 절대로 인지되지 않는다는 보장은 하지 않는다.
- 지면 비교는 기존 grass 256×256 전체를 새 fill과 같은 256×128 UV로 정규화했다. 자르지 않았으며 동일 반복 밀도 비교다. 실제 엔진 UV 검증은 아니다.
- 데칼 배치는 확인 그림용 코드로 검증했다. 실제 게임의 저장·경계 마스크·가림·충돌·DPR·성능 검증은 포함하지 않는다.

최종 확인 그림 판정은 `records/proofs-QA.md`, 크기·접합·보존 검증은 `records/asset-validation.json`, `mixed-ab-validation.json`, `preserved35.json`을 참조한다.

## 최종 결과

81개 에셋의 크기·알파·역할별 반복 규격, a/b 15쌍의 상호 XY 끝점 일치, 통과본 35장 SHA-256 동일, CSV 81행×20열의 실제 프롬프트 재읽기 검증 통과. 최종 유형 장면의 a/b 경계 및 중·대형 특징 가독성은 직접 검수와 독립 시각 검수 모두 통과했다.
