## 증거를 읽는 방법

사진은 실제 제품 화면이다. 원본 저장은 정상 화면 플레이에서 나온 파일 또는 출처가 기록된 기존 원본을 바이트 그대로 사용하고 일반 이어하기로 열었다. 저장 payload를 분석·편집하지 않았다. 원본 저장을 사용한 장면을 이번 새 게임에서 처음부터 도달한 것처럼 표현하지 않는다. 자동 발전을 실제 UI로 켠 구간은 기록에 따로 명시했다.

움직임에는 GIF와 전체 프레임 펼침 JPEG를 함께 제공한다. 목표 촬영 간격은 100ms이며 실제 시각은 대응 JSON에 있다. 고정 재생 간격 GIF를 실제 촬영 시간 또는 성능 측정으로 해석하지 않는다. 배속·계절 결산 자동 정지·카메라 이동·루프 마지막→처음·교차 개체를 판정에서 구분한다. 정지 30장 지면 표본은 움직임 검증이 아니다.

QA 화면의 틱·줌·카메라·칸·선택 ID를 우선 사용한다. JPEG 직후 DOM 수치는 미세한 시차가 있을 수 있다. 클릭 직후 이전 화면이 찍힌 root10-063/064는 정착 후 root10-072/073으로 대체했다. DOM에 존재하지만 사진에서 잘린 문장을 ‘화면에 읽힌 정보’로 세지 않는다. 미재현은 수정 완료가 아니며, 현재 상태에서 볼 수 없었던 동물 걸음·새 땅은 통과로 바꾸지 않는다.

경량 패키지는 JPEG의 크기를 유지하고 품질을 낮추며, GIF는 축소·감색하되 프레임 수·각 지연·루프를 유지한다. 원본 파일은 `/tmp/QA_ROUND_10/`에 보존한다. 원본 프레임 폴더는 ZIP에서 제외하고 전체 펼침판과 GIF를 포함한다. `repro/package-validation-draft.json`은 변환별 SHA와 검증 기록이며 최종 ZIP CRC/SHA는 바깥 검증 JSON에 둔다.
