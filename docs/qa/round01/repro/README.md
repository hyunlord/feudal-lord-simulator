## 독립 재현 하네스

`replay-capture.cjs`는 저장 원본 하나를 새 브라우저 프로필에서 불러와 초기 카메라로20프레임을 찍는다. 이는 재현 보조이며 이번 회차의 모든 조작을 자동 재생하는 스크립트는 아니다. 대상 dev 서버는 먼저 실행해야 한다.

```sh
PLAYWRIGHT_MODULE=/Users/rexxa/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright node replay-capture.cjs saves/ch4-1380.save.json.gz /tmp/fls-qa-recapture 5
```

다른 Mac에서는 기존 Playwright 설치 경로를 지정한다. 제품 저장소에 패키지를 설치할 필요는 없다. 도구는 `/tmp/fls-perf-measure.lock`이 있으면 중단한다.

## 프레임/이미지의 의미

- 원본 촬영20장, 목표 간격100ms. 실제 시작 시각은 대응 JSON의 times에 기록했다. GIF는10fps이고 무한 반복하므로 마지막→처음 점프는 게임 순간이동 증거가 아니다.
- 경량 GIF는 전체 화면 축소 또는 숲 ROI 잘라내기이며 색상64색이다. 자세한 글자·가림 판정은1600px JPEG를 사용한다. 원본 촬영은 모두1600×1100.
- 연속 판의 순서: actors-10second-sheet는 첫 버스트00/19가 위,10초 대기 뒤 버스트00/19가 아래. 정적 앵커 주변의 작은 몸 흔들림과 실제 이동을 구분한다.
- JPEG 차이 측정은 압축된 캡처의 픽셀 차이이며 원본 렌더 버퍼 diff가 아니다. 프레임 주기는 성능 측정값이 아니다.
- 중복·중간 캡처와 오표기 파일은 패키지 밖 `/tmp/fls-qa-raw-round01/`에 보존. 제외 목록과 하네스 정정 기록을 함께 제공한다.
- 모니터링용 DOM 텍스트는 날짜/모달 확인용. 미술 판정은 실제 캡처를 보고 했으며 DOM에만 있는 숨은 문구를 화면 관측으로 세지 않았다.
