# Charter & Kin · 인장과 가문 — 손그림 화풍 지역 지도 20장

2026-10-03. 지형 조각을 합성하지 않고 **지도 한 장 전체를 생성한 그림20장**, 장원·마을·시장·수도원 후보 **415곳**을 제공한다. 각1600×1000 JPEG92, 같은 땅4장씩 총5종. 건물·거점·깃발·문자는 바탕 지도에 그리지 않았다. 작은 다리·여울 같은 도하 요소는 풍경에 포함된다.

제작은 내장 image_gen을 사용한 손그림 **화풍의 생성 이미지**다. 사람이 붓으로 직접 그렸다는 뜻이 아니다. 이전 키트의 지형·밭 스탬프와 조립기는 사용하지 않았다. 생성 도구의 실제 원본 크기는20장 모두1586×992이며, 최종 규격1600×1000으로 한 번 약0.9% 확대 정규화했다. 네이티브1600×1000 생성이라고 표기하지 않는다. 생성 원본 PNG는 로컬 `~/fls-astra-region-atlas/masters/`에 보존하며 경량 ZIP은 JPEG 파생본을 담는다.

## 좌표를 쓰는 방법

좌상단(0,0), 오른쪽+x·아래+y, 원본1600×1000 기준. `x,y`는 **오버레이 하단 중앙 접지점**이다. `clearance.width/height`는 그 점에서 좌우 절반, 위쪽 높이만큼의 허용 직사각형이다. 표시 축척s라면 좌표·크기를 모두s배 한다. `allowedKinds`는 후보 용도이며 이 자리의 확정 건물이나 가문이 아니다.

작은 자리60×45, 넓은 자리는100×60~70 등으로 차이가 있다. 시장/수도원 후보라도 작은clearance가 있으면 지역지도용 아이콘을 그 안에 맞춰야 한다. 대형 실제 건물 이미지가 자동으로 들어간다는 보장은 없다. 깃발은 `overlays/manifest.json`의 **pole pivot**을 사용한다. 이름띠와 경계선은 지형 레이어와 분리한다.

`landmarks`에는 실제로 관찰한 도하·길 갈림을 기록했다. `landmarkRefs`는 주변 맥락 참조로, 슬롯에서 해당 지점으로 가는 확정 통행 간선이 아니다. 일부 제안 도하는 `proposed_ford` 등으로 구분했다. 이동거리·고도·홍수·통행권·수역 충돌마스크는 이JSON에 들어 있지 않다.

## 이웃18영지 예시

open_field-01의22슬롯 중18곳에 원본 가문ID·영지ID·이름·종류를 유지해 배치했다. 바탕 지도에는 건물을 넣지 않고 별도 합성판에 깃발과h01~h18 이름띠만 표시했다. 이름과 전체 대응은 `proofs/neighbor-18.json`에 있다. h01은 직할, 나머지는 이웃 표시이며 적대관계나 새 영토 경계를 임의로 정하지 않았다.

지도 지형이 바뀌었으므로 **좌표는 새 슬롯으로 재배정**했다. 기존39간선·거리·travelDays는 새 지도에 유효하다고 주장하지 않으며 옮기지 않았다. `sourceAnchor`를 함께 기록해 변경을 추적할 수 있다.

## 검증/재실행

Node와 기존sharp가 있는 환경에서 패키지 최상위 기준:

```sh
node tools/validate.cjs
node tools/render-neighbor.cjs
node tools/overlay-proof.cjs
shasum -a 256 -c SHA256SUMS
```

sharp는 기본 모듈 경로 또는 `MAPKIT_SHARP`로 제공한다. 이번 환경 Node25.8.2/sharp0.34.5. 새 의존성을 설치하지 않았고 바이너리는 ZIP에 포함하지 않는다. 순수 지도·JSON·PNG를 사용하는 데 Node는 필요 없다.

20개 치수,415개 슬롯 수·유일ID·경계·간격·상호 비중첩,18영지 호환 배치,표지6개 원본해시를 검사했다. 육안으로 고른 빈 자리는 **픽셀 단위 충돌마스크가 아니다**. 작은 관목이나 생울타리 붓터치가 가장자리에 남는 경우가 있어 실제 거점 레이어 채택 시 해당 이미지 크기로 최종 접지를 확인해야 한다.

저장소 `~/fls-astra-mapkit`는 수정하지 않았고 커밋·푸시·게임 설치도 하지 않았다. 전체 그림과 좌표는 candidate 상태다. 이번 세션에서는 새로운 눈가림 맞힘률을 측정하지 않았다.
