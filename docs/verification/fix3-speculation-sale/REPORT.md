## 원인
- 예측(`bigDecision`)이 투기 금고를 `지금 + 지난 계절 수입 ÷ 2`로 셌다. 투기가 실제로 버는 것(곡창 곡물 판매)과 상관이 없어, 수입이 0이면 "그대로"였고 수입 1,200이면 곡창이 비어도 +600이었다.
- 실제(`fillActuals`)는 두 계절 뒤 금고를 그대로 읽어 다른 돈 흐름이 섞였다.
