## 항목별
1. **물 둘레 성벽**(FX15-1, WP-1·WP-3)
   - 성벽 고리가 물 위를 지나는 칸은 물이 경계라 쌓지 않는다. 공사장은 땅 칸의 연속 구간에만, 성문은 땅 칸에만 선다.
   - 물 구간은 통행을 막지 않는다(성벽은 완성된 구간만 막음). 다리·여울은 성문 없이 지난다.
   - 확장도 물 구간을 쌓지 않는다. 옛 시험("호수를 지나는 확장은 성벽이 아니다")을 새 규칙으로 고쳤다.
2. **땅이 먼저, 물은 마지막**(FX15-2, WP-2)
   - 처음에는 각 제안 함수가 실패 끝에 물 고리를 바로 내게 했다. 그러자 상태별 제안이 둘레가 더 짧은 물 고리를 땅 고리보다 먼저 골라, 땅 성벽이 있던 판(시험 셋)이 바뀌었다.
   - 그래서 물 단계를 상태별 제안의 맨 끝으로 옮겼다. 땅 고리를 모두 찾아 실패할 때만 쓴다. 땅 고리가 있는 판의 봇 결정은 그대로다.
3. **칙허 전 상인 목재**(FX15-3, TT-5)
   - 촌락 창고 배달은 27d(시장 18d의 1.5배)이고, 장날마다 하나(시장 둘)씩 오고, 한 번 주문은 60까지(시장 400)다.
