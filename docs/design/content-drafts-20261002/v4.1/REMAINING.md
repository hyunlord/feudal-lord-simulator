# 남은 경계

## 이번 실행 데이터에 넣지 않은 소재

| 소재 | 없는 것 / 보류 이유 | 분류 |
|---|---|---|
| 새 홍수마다 구호·책임 | 현재 EventKind는 fire/dearth. flood 발생 ID·피해 상태가 없음 | R5/발생기 확장 필요 |
| 1381 뒤 매번 새로운 역병 | plague.first/second는 1348/1361 전용. 일반 재유행 발생기가 아님 | R5/발생기 확장 필요 |
| 새 가구마다 정착 조건 | House에 독립 householdId/정착 시점 계약 없음. buildingId와 seed를 새 가구 발생으로 단정하지 않음 | 읽기·가구 생애 계약 필요 |
| 길드 수장 교체 | 별도 guild faction kind 없음. 도시·상인 가문과 동일시하지 않음 | 실제 길드 읽기 계약 필요 |
| 직접 임금 상한/인상·개별 식량 지급·제방 수리·왕실 헌장 재발급 | 이번 R1–R4 명령에는 해당 효과 없음 | R5 명령·대가 필요 |

이 표는 명령·상태를 구현한 제안서가 아니다. 위 소재는 실행 추가 15건과 분포 계산에서 제외했다.

## 통합 및 분포에서 확인할 것

- 원격에 LM-E9b가 병합된 뒤 같은 소스인지 비교하고, v4와 delta를 ID 병합해 기존 생성기를 실행해야 한다. 이 묶음은 설치하지 않았다.
- 실제 125년 판의 목표 달성은 아직 측정하지 않았다. 후보의 수가 늘어도 상태 압력·예산·우선순위·플레이어 정책 때문에 최종 노출 수는 달라진다.
- 실제 주택/재해 후보는 최신 발생부터 고른다. 현 엔진은 첫 바인딩을 뽑은 뒤 과거 맥락을 검사하므로 이미 처리한 최신 항목이 있으면 더 오래된 미처리 항목은 그려지지 않을 수 있다. 새로 도래한 더 최신 맥락이 굶지 않는 것은 검증한다. **모든 과거 미처리 재해/가구를 순회 제공하는 계약은 아니다.**
- 수장별 협의는 현재 보이는 수장을 첫 대상으로 삼는다. 저장 시작 시의 수장을 방금 취임했다고 서술하지 않는다. 같은 인물이 다시 직책을 맡아도 같은 leaderId이면 재발동하지 않는다.
- 계절 카드의 키는 해당 계절 값이다. 계절이 넘어가면 기존 카드 대상의 고정 재바인딩은 실패할 수 있다. 기존 등록기가 만료/비활성화 처리하며 오래된 계절 카드를 새 계절에 억지 적용하지 않는다.
- 새 효과 없이 쓸 수 있는 선택이 정책·세율·목재·장려금에 집중되어 있다. 이번 편집은 없는 차별 효과를 암시하지 않는다. 더 깊은 개별 분쟁 해결은 R5 다음 범위다.
- 그림은 장면 설명만 제공한다. 새 15건의 그림 파일 제작·설치·그림 경로 연결은 이번 작업에 포함되지 않는다.
