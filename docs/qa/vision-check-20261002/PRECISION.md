## 실행 범위와 판정

본선 36장면 = 다섯 땅 × 여름·겨울 × 0.6/1.0/1.4 + ch4-1380 큰 도시 × 같은 여섯 조건. 각 20프레임, 총 720프레임. 모두 화면 중심 칸 (32,32), 1600×1000, 일반 게임. 별도 지도 번호 2의 숲 6장면·120프레임도 수집했다. 처음의 탐색 카메라 36장면은 보정에만 사용했으며 본선 동일 카메라 수집과 구분했다.

정밀도는 **후보 단위 TP/(TP+FP)**. 각 후보를 assistant가 실제 캡처와 확대 crop으로 직접 판정했다. 인간 외부 평가자의 검증은 아니다. 같은 경계를 계절·줌별로 다시 센 상관 표본이 있으므로 독립 표본 정밀도나 모집단 신뢰구간을 주장하지 않는다. 본선도 보정에 사용했으므로 엄격한 holdout은 지도 번호 2의 숲뿐이다. 그 숲은 최종 각도 문턱을 정한 뒤에 분석·열람했다.

## 오탐 보정의 증거

`report/calibration-before/`의 직접 판정 25건: 경계 11TP/6FP = 64.7%, 크기 7TP/1FP = 87.5%. 등각 각도 오차를 1.5°에서 0.12°로 좁힌 최종 본선은 21건: 경계 11TP/2FP = 84.6%. 숲의 화면 수평·수직 절단도 따로 검출한다. 매우 엄격한 각도 문턱은 자연 곡선 오탐을 줄이지만 작거나 흔들리는 절단을 놓친다.

이보다 앞선 탐색에서는 물가·울타리, 수레 바퀴 허브, 창/선반 기둥, 가려진 소품이 오탐이었다. 물/인공 구조 마스크, 경계 양쪽 3px와 12px 대비, 바퀴 바깥 타원, 지면에 닿는 문 조건, 실제 화면과 원본 alpha 비교를 추가했다. 정확한 storehouse/house_l4_wing/수레 원본 회귀 fixture를 테스트에 넣었다. 이 초기 탐색 전체의 정밀도를 계산했다고 주장하지 않는다.

잔존 오탐: 해안의 완만한 식생 경계 2건, 겨울 도시에서 다른 물체에 가려진 통 1건. 통 alpha에는 울타리도 들어 있어 표시된 약 1.6H는 통 단독 실측값이 아니다. 참 판정은 확대 화면에서 실제 통 몸체도 성인 키에 가까워 바이블 통 규격을 넘는지 확인했다.

## 알려진 누락·보류

- QA17의 바위 마름모 절단과 작은 검은 점은 본선 화면에도 보이지만 최종 설정에서 자동 검출하지 못했다. 특히 백악 장면 0건은 정상 판정이 아니다. 아래 대표 해안 화면에도 바위 절단이 보인다. 검출 민감도와 재현율을 별도로 개선해야 한다.
- 타일 이음새는 칸 간격의 1차원 띠/2차원 반복 상관을 찾는다. 불규칙 바위 절단·국부 이음새는 주기성이 약해 놓친다.
- 사람은 20프레임 모두 식별되고 게임이 18틱 이상 진행한 궤적만 측정한다. 큰 도시의 관측 가능 인원은 장면별 10~23명, 멈춤 비율은 모두 0%. 총 인구의 0%라는 뜻이 아니다. 정상 대기/작업자는 결함 경보에서 제외한다. 1.9초 관측은 간헐적·장기 멈춤을 보장하지 않는다.
- 지붕은 따뜻한 색의 상부 연결 영역과 그 위에서 실제 변한 사람 픽셀·그리기 순서를 함께 사용한다. 회색·눈 덮인 지붕, 문/창이 지붕으로 오인되는 경우, 완전 가림은 검증 범위 밖이다.
- 문은 지면에 닿는 어두운 개구부만, 바퀴는 외곽 타원이 확실한 경우만 측정한다. 닫힌 목문과 작은 바퀴는 보류한다. 사람 기준이 3명 미만이거나 대상 높이가 6px 미만이면 비율 판정을 생략한다.
- 비 자동 마스크는 20프레임의 밝은 가는 낙하 궤적을 요구하고 지면 외 영역을 제외한다. 실제 비 장면은 확보하지 못했다. 비/눈/낙하 파편 구분과 비 크기 정밀도는 미입증이다.
- 반복 밀도는 동일 자산 provenance와 실제 픽셀 유사도, 반경 4칸 안 6개 이상을 함께 요구한다. 밀집하지 않은 반복, 다른 파일에 저장된 같은 그림, 계절 overlay는 놓칠 수 있다.
- Canvas/React 내부 관측 어댑터는 해당 HEAD에 맞춘 것으로 새 커밋에서 구조 변경 시 재검증해야 한다. 회전·전단 변환과 복잡한 합성 모드의 정확한 silhouette 재현은 지원하지 않는다.

## 시간·환경

macOS 로컬 Chromium headless, CPU 이미지 분석. 본선 첫 capture.json부터 마지막까지 784.8초(13.1분); 최초 로딩·첫 장면 진행 시간은 이 구간에 포함되지 않는다. 순수 36장면 프레임 저장 구간 합은 238.1초. 최종 본선 분석은 46.0초, 별도 숲 분석 8.1초. 머신·브라우저·게임 규모에 따라 달라진다.

프레임 간 100ms는 Playwright 브라우저/시뮬레이션 시계이며 20장 범위는 1.9초다. PNG 직렬화 때문에 실제 벽시계 간격은 더 길다. 실제 10FPS·GPU 성능을 측정한 자료가 아니다. DGX에서 원리상 Linux headless CPU 실행 가능하지만 실제 DGX 실행은 하지 않았다.
