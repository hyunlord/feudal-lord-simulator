성벽 안 빈 땅은 **서비스 가능한 주택 확장을 우선 검증**하는 방향을 권한다. 다만 이번 도시는 목책 시대이므로 석벽 도시의 빈 땅 문제가 해결됐다고 할 수 없다. 경관 배치 조건 완화는 식량·운송·서비스 문제를 고치지 못하며 건설 여유를 침범하지 않아야 한다. 성벽 제안 크기 축소는 사용자가 원한 넉넉한 공간을 줄이므로 별도 선택 사항이다. 세 방법 모두 미구현이다.

다음 진단 범위는 입주 주택 빵0과 도시 빵 재고의 차이, 시장 배치·도달 범위, 석재 누적/소비 흐름이다. 관측된 성장 제동을 먼저 설명한 뒤 최소 변경안을 제시한다. 이번 데이터만으로 식량 생산량·배급량·비용·일꾼 수를 바꾸지 않는다.

- 측정: C의 세 동일 최종 상태가 근거다. 다른 seed나 실제32/48채까지 일반화하지 않는다.
- 테스트: 설계안 문서만 작성. 승인된 규모에서 D의 seed1~5를 실행하기 전 현재 결과를 다중 seed 성공으로 표현하지 않는다.
- 확인 못 한 것: 확대 시 승리 가능성·수용량 과부하 자동 회복·후기 빈 땅 변화.
- 사용자 결정 필요: **기본8·현재 수용량을 유지하고, 다음 단계에서 식량 전달/시장 배치/석재 정체를 먼저 진단·교정한 후24필지를 재검증할지**, 또는 바로24/무제한을 목표 기본값으로 정할지 선택. 변경 수치와 구현 범위는 승인 후 확정한다.
