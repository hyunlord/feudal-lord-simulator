# 계절 경계의 나무와 지붕 시점 수정

한겨울에도 남던 주황 단풍을 없애고, 눈 층이 있는 지붕은 겨울 초반에 쌓임을 마치도록 시점 분포를 좁혔다. 나무별 차이는 늦가을부터 초겨울 사이에, 지붕별 차이는 초겨울 안에 남긴다. 새 그림 설치는 0장이다.

## 실제 게임 화면

기준은 `2e03f3174ac4bb6c1f11f5be8e4cc720b78b62ef`, 수정판은 `c8587663e8c52ca066df44b42b361f27c0800737`이다. 본 폴더의 전후 20장은 마을 지붕 카메라의 늦가을·초겨울·한겨울·초봄·여름 각각 줌 1.0과 0.6이다. 원래 1280×800을 유지하며 JPEG 품질 30으로 다시 압축했다. 자르거나 그림을 합성하지 않았다.

- 늦가을(tick 22920): 일부 나무가 먼저 앙상해지고 다른 나무는 단풍을 유지한다.
- 초겨울(23080): 활엽수는 앙상하고 지붕 눈은 막 쌓이기 시작한다.
- 한겨울(23450): 수정 전의 주황 단풍과 희미한 눈 대신 앙상한 활엽수와 뚜렷한 지붕 눈이 보인다.
- 초봄(24080): 새잎과 앙상한 나무가 섞이고 지붕의 잔설이 녹는 중이다.
- 여름(21000): 나무는 녹색이며 지붕 눈과 땅 서리는 보이지 않는다.

숲·지붕 카메라를 합친 전후 20쌍은 저장 해시, 투영된 상태 해시, tick, 카메라 타일, 줌이 모두 일치했다. 모든 정지 화면의 시작·종료 tick도 일치한다(`identity.json`). 눈 그림이 없는 일부 붉은 지붕까지 덮인다는 뜻은 아니다.

## 시점 분포와 회귀 기준

`distribution.json`은 실제 저장의 나무 730개, 지붕 36개, 서리 대상 130개의 모델 질의 결과다. 화면에서 세어 얻은 수치가 아니다. 한겨울 질의에서 나무 730개가 잎을 떨군 상태이고 지붕 36개의 눈 강도가 1이다. 단풍 변화는 가을 안에 유지하며, 낙엽은 늦가을부터 초겨울에 끝나고 지붕 눈은 겨울 진행도 0.34까지 쌓인다.

원격 C25 반복 그리기는 두 번 동일했고 기존 기준 16개 중 겨울 하나만 달랐다. 실제 겨울 화면 검토 후 그 항목만 `30f525ff…`에서 `22a995b9…`로 갱신했다. 다른 15개 기준과 검사 코드는 바꾸지 않았다.

## 실행과 검증

판정에 사용한 실행은 `astra-SEASON-BOUNDARY-before-2e03f31`, `astra-SEASON-BOUNDARY-after-c858766`이며 RR15 보존 대상이다. 전후 정지 캡처 모두 첫 늦가을 숲 장면의 텔레메트리 전송 중단 1건을 기록했다. 원본 오류를 삭제하거나 실행 전체를 무오류로 판정하지 않는다.

본선 봄 8장과 통합한 구현 `494fb0d1`에서 `astra-SEASON-BOUNDARY-integrated-494fb0d` 영향 시험 180파일·1,204개 중 1,203개가 통과했다. 한겨울에도 눈 알파가 부분 값이라고 가정하던 집 계약 시험 하나가 실패했다. 해당 시험을 초겨울의 부분 적설과 한겨울의 완전 적설 두 경우로 나누고, 로딩·좌표·호출자 알파 복원 검사는 유지했다. 이후 Mac에서 `test:changed --base 494fb0d1 --run`이 고른 해당 파일 13개가 모두 통과했다. 초기 실패 실행은 그대로 보존하며, 전체 1,205개를 한 번에 재실행했다는 뜻은 아니다. 제품 소스는 이 시험 보정 뒤 바뀌지 않았다.

UI·입력 파일 변경은 없다. 기존 `astra-SPRING-geometry-bankfix-3929f8b` 기하 2,262조건 실패 0·미개방 0의 범위를 유지한다. 사용자 재지시와 RR16에 따라 전체 클론 대기는 게시 관문이 아니다. 최종 `check:merge`는 Mac에서 통과했고, 보호 푸시에서도 다시 검사한다. 보고 ZIP에 원문 로그를 넣는다. 기존 캡처의 기준·수정 해시는 그대로 보존하고 통합 과정에서 봄 생울타리 연결도 유지했다.

연속 캡처 214장의 PNG·JPEG 해시를 검증하고 보고 ZIP에 MP4 6개(숲·지붕·비 각각 줌 1.0·0.6)로 묶었다. 초당 4장으로 시간 간격을 압축한 기록이며 프레임 보간은 없다. 시작 저장은 줌별로 같고 이후 실제 진행 상태 차이는 기록에 있다. 표본 프레임에서 낙엽·겨울 적설·봄 새잎을 확인했다. 비 시퀀스는 wetness 모델 0→1을 기록하지만 비 띠가 지나간 자리의 국소 젖음까지 시각 통과로 판정하지 않는다. 텔레메트리 요청 취소 76건도 보존했다.

원칙 점검: 기존 계절 사실이 세계에서 읽히게 고쳤으며(A4), 눈 층 없는 지붕·모델 젖음·캡처 한계를 구분한다(과장하지 않기).
