# Wave 7 독립 시각 검수

판정: **candidate 유지 — 줌 0.6 의미 판독 조건부**. 실제 게임 설치·동작·사람 대상 블라인드 테스트 결과가 아니다.

## 검수 범위

WORK_ORDER.md 및 ASSET_PIPELINE_SPEC_v1.md를 읽고 확인 그림 01–03, snow/boards L0–L4의 실제 주택 합성 확대 이미지 10장을 직접 확인했다. 04는 최초 확인 시 대표 더미 4종만 있는 중간본이었으므로 최종본 재검수가 필요하다. 원본이나 후보 PNG를 수정하지 않았다.

## 확인한 사항

- 01: 기둥풍차와 부속 화덕이다. 물레방아가 보이지 않는다. 주택 연기는 굴뚝 없이 지붕에서 나온다. 볏단은 밭 바깥에 분리되어 있다. 아래 엄격 원본 ×0.3 소품 표본도 표시된다.
- 01의 장면은 첨부 작은 런타임 집·수레·사람 원본을 ×2 정규화하며 적재물·손 소품도 부착 비율에 맞춰 ×2 사용한다. 장면만으로 이 두 종류의 엄격 원본 ×0.3 판독을 통과시켜서는 안 된다. 다른 새 소품은 ×0.5/×0.3이다.
- 02: 두 축과 손수레·소수레 조합에서 적재물의 받침 위치가 수레 짐칸에 맞고 큰 부유·축 뒤집힘은 보이지 않는다. 줌 0.6인 원본 ×0.3에서 밝은 각재석과 어두운 원석은 잘 구분된다. 판재/통나무, 곡물 자루/빵은 작은 축약 실루엣에 세부가 뭉치므로 전 항목을 형태만으로 즉시 구분한다고 보증할 수 없다. ×0.5 및 확대본의 판독은 더 좋다.
- 03: 눈이 얇은 흰 처마·용마루 띠로 보이고 약한 연기가 지붕에서 나온다. 서리도 지면에 분리되어 있다. 작은 L2 판자는 문·창이 더 어둡고 빽빽해 보이지만 기존 목골조 색과 유사해 빈집 의미가 즉시 명확하지는 않다.
- 눈 합성 L0–L4 5장: 각 주택의 실제 용마루·처마·박공 윤곽에 붙어 있다. 건물 전체 이동, 벽이나 지면에 뜬 눈, 굴뚝 추가는 관찰하지 못했다. L3는 앞 박공의 꺾인 윤곽도 따른다.
- 판자 합성 L0–L4 5장: 실제 창·문·열린 가게 전면에 덧대어져 있다. 판자 끝이 주변 틀에 걸치는 것은 못박는 구조로 해석 가능하며 전체 캔버스나 피벗 오정렬의 증거는 아니다. 육안 합성 검토는 정량적 픽셀 오차 0 인증과 다르다.

## 의미 판독 한계

| 항목 | 엄격 원본 ×0.3 판단 | 분류 |
|---|---|---|
| 수레 적재물 | 석재 두 종류는 명료, 목재/통나무 및 빵/자루 즉시 구분은 제한 | 수락 조건 미완전 충족 |
| 지붕 눈 | 얇은 눈 가장자리로 읽힘 | 시각 통과 |
| 판자 빈집 | 부착 위치 적합, 축소 시 빈집 의미는 약함 | 소규모 판독 제한 |
| 빗장·가족 등짐 | 32px 캔버스가 9.6px로 줄어 작은 갈색/붉은 점에 가까움 | 의미 판독 제한 |
| 발자국 점선 | 방향 있는 경로 표식은 읽힘, 끊긴 길이라는 원인은 맥락 필요 | 게임 맥락 필요 |

현 검토에서 명백한 기술적 합성 파손은 찾지 못했다. 위 작은 소품의 판독 제한은 숨기지 않고 최종 검수표에 유지해야 한다. 후보 제작 완료와 엄격 줌 판독 합격, 런타임 적용 완료를 구분한다.

## 최종 04 재검수

루트의 최종본 통보 후 6개 기표와 12개 더미, 총 18항목을 다시 직접 확인했다. 위 중간본 대기 상태는 이 절로 해소한다. 확인 SHA256: `f2c608d1f102733240e3ee32ea17e14eeef490e4a94e3396767e884067586888`.

- 더미 네 계열은 바구니의 둥근 빵, 각진 상자, 매듭 자루, 세운 볏단으로 분리된다. 볏단은 황금색 수직 실루엣이며 사각 현대식 베일이 아니다.
- 각 계열의 1→2→3은 수량·점유가 늘어 보인다. 원본 ×0.3에서 작은 1단계의 내부 모티프는 약하다. 특히 빵1과 자루1은 라벨 없는 즉시 의미 식별을 보증하지 않는다. 확대판을 축소판 검수 대신 사용하지 않았다.
- 빈 좌판의 비어 있는 상판, 풀 필지, 두 축 점선의 방향은 확인된다. 빗장·등짐의 의미 판독 제한은 그대로 남는다.

03은 서리 원본 규격 교정 뒤 재생성이 예정되어 있다고 전달받았다. 이 보고서의 03 평가는 SHA `3c0949a7c2c1cc4846325597bc01872d8779065be893549a525f218fec7e5048` 시점의 눈·판자·연기 합성 검토다. 이후 서리 배치판은 루트의 최종 재검수가 필요하다. PNG 총수·최종 치수·최종 패키지 무결성은 이 시각 검수의 인증 범위가 아니다.
