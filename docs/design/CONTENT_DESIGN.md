## 0. 왜 단조로운가, 무엇이 다양성을 만드는가

지금 게임은 사슬 하나(밀→방앗간→빵), 건물마다 그림 한 장, 땅은 "도시 타일/농업 타일" 둘뿐이다. 조사 결론은 분명하다: **다양성은 건물 수가 아니라 다음 다섯 가지에서 온다.**

| 원천 | 내용 | 조사 근거 |
|---|---|---|
| **토지의 기능 분화** | 집 뒤 croft, 성밖 open field·hay meadow·common pasture·woodland, 물가 mill·fulling·tannery, 점토·석회 산지 kiln | 확정 |
| **집이 생산시설이라는 사실** | 14세기 양조는 여성 가내생산, 방적은 가내노동. "공장" 대신 집 뒤뜰이 일한다 | 확정 |
| **사슬이 지도·노동·모양·시대를 함께 바꿈** | 양을 넣으면 목초지가 필요하고, 양모가 방적을 만들고, 직기가 집 변형을, 축융기가 물가 경쟁을, 텐터야드가 도시 윤곽을 바꾼다 | 확정 |
| **입지 archetype** | 같은 건물 목록으로 자원 배치만 달리하면 농업 평야 / 하천 직물 / 해안 항구 / 숲·철 도시가 나온다 | 확정 기반 가설 |
| **시간의 파동** | 시장일·정기시·축일·계절에 따라 도시가 붐비고 비고, 같은 주민이 여름엔 수확, 겨울엔 방적 | 확정 |

원칙 한 문장: **"자원을 늘리는 대신 땅과 집과 시간을 나눈다."**

## 1. 150년 시대 아크 [권고]

시대는 **건물 테크트리가 아니다.** 시대가 바뀌어도 풍차·에일·경작은 사라지지 않는다. 바뀌는 것은 **상대 수익성, 노동 요구량, 시장 규모, 집행력**이다. 시대 진행은 연도(달력 사건) + 지역 상태(시장·수력·노동·양모 조건)의 혼합.

| 시대 | 연도 | 플레이어의 문제 | 중요해지는 것 | 약해지는 것 | 대표 사건 |
|---|---:|---|---|---|---|
| **1 포화** | 1300–1314 | 사람은 많고 땅이 부족 | open field 집약, 방앗간, 시장, 작은 필지, 가내 산업 | 넓은 빈 땅 | 높은 식량·지대 압력 |
| **2 기근과 취약** | 1315–1336 | 비축·종자·가축을 얼마나 지킬 것인가 | 곡창의 가치, 소 재건, 구호·수입 곡물 | 한계지 경작 | 대기근 1315–17(2~3년 연쇄), 가축 역병 1319–20(소 약 62% 사망) |
| **3 전쟁 동원** | 1337–1347 | 세금·징발·해안 안보와 성장의 양립 | 해안 감시, 수레·말·선박 부담, 방어 프로젝트 | 안전한 장거리 교역 가정 | 백년전쟁, 남안 습격(Southampton 1338) |
| **4 인구 붕괴와 노동 반전** | 1348–1379 | 땅은 남는데 사람이 없다 | 빈 필지, 이주민 유치, 임금 교섭, 필지 합필, 목초지 선택지 | 값싼 연중 노동, 강한 노동 의무 | 흑사병(사망률 약 50% 견해), 재발 1361·1369, 노동자 법령 1351 |
| **5 재편과 전문화** | 1380–1450 | 어느 산업·교역망으로 살아남나 | 직물 전문화, 목축 선택, 큰 소작농, 상업 가옥, 항구·경로 분화 | 한계 경작지, 옛 중심지의 시장 우위 | 1381 이후, 반복 역병, 15세기 직물 성장 |

**병목의 이동**: 1300은 토지와 식량, 1350은 사람, 1400은 시장과 전문화. 후반 승리는 "인구를 원래대로"가 아니라 **"더 적은 사람으로 더 높은 전문화·교역·생활수준"** 또는 **"이주민을 끌어 새 중심지가 되기"**.

**규칙으로 옮길 때**
- 흑사병 후 목축화는 **스크립트로 전환하지 않는다.** `노동↓, 임금↑, 빈 땅↑, 곡물 수요↓, 지대 압력↓`이 생기면 플레이어가 스스로 밭을 초지로 돌릴 유인이 생기게 한다.
- 노동자 법령은 시장 임금을 덮어쓰지 않는다. 단속·벌금·원한을 만든다.
- 기근은 1회 수확 감소가 아니라 **창고 → 가격 → 건강 → 종자 재고**의 2~3년 연쇄.
- 소빙기는 시대 버튼이 아니다. `wet spring / wet harvest / summer drought / cold winter` 날씨 상태가 작물·초지·가축에 다르게 작용하고, 역사 시나리오는 그 연속 확률을 높인다.
- 재발 역병은 낮은 강도의 반복 풀.

## 2. 자원과 공정 모델 [권고]

**[확정 K2] 직물 사슬의 중간재는 전부 자원으로 노출한다.** 사용자 결정. 이에 맞춰 원칙을 "중간재는 숨긴다"에서 **"중간재는 보이되, 창고와 UI를 그 폭에 맞게 설계한다"**로 바꾼다. 곡물·에일도 같은 원칙(보리 → 말트 → 에일 3단계 노출)으로 일관성을 맞춘다. 석회·도기 소성 같은 건축 공정만 modifier로 남긴다.

**7단계 노출의 비용과 대응** (이 결정으로 필요해진 설계)
| 비용 | 대응 |
|---|---|
| 자원 수 7 → 약 20 | **자원 분류 체계**: 곡물·식량 / 직물 계열 / 가죽·동물 / 건축 자재 / 연료. 자원바는 분류 대표값, 상세는 장부·창고 화면 |
| 창고 용량·운송 부담 | **가내 공정은 창고를 거치지 않는다.** 양모 → 실 → 직물은 **집 안 재고**로 흐르고, 창고·시장에는 완성 단계만 나간다. 집과 집 사이는 `공정 배달`(행상·도제 심부름) 한 종류로 추상 |
| 자원마다 가격·판매 | 시장 판매 목록은 분류별 접기, 공사 자재 판매 제외 규칙(R-6) 적용 |
| 저장 형식 | 자원 ID는 `namespace:id`, 스키마 v3 마이그레이션 |
| 에셋 | 자원 아이콘 +13, 염색 공방·전모 공방·염료 추가 (Wave 3 확대) |

| 층 | v1 노출 자원 | 비고 |
|---|---|---|
| 기존 | 밀(→**식량곡**), 빵, 원목, 목재, 원석, 석재, 돈 | 밀은 "식량곡(wheat/rye)"으로 의미 확장 |
| 신규 T1 | **보리(양조·사료곡)**, **에일**, **양모**, **미가공 직물**, **완성 직물** | 첫 시제품 |
| 신규 T2 | 생가죽, 가죽, 생선, 염장 생선, 장작/숯 | E단계 |
| 신규 T3 | 과일, 꿀, 밀랍, 아마 | 지역 특성 |
| 공정 상태(비노출) | 말트, 실, 축융 중, 석회, 도기 소성 | 건물·가구 안에서만 진행 |

**곡물 세분**: 식량곡 + 보리 두 종류로 시작 [권고]. 귀리·호밀은 지역 modifier. 전국 고정 비율은 쓰지 않고 **작물 구성을 지도 정체성**으로.

**부산물 연결**: 도살 → 고기 + 생가죽 + 기름(양초) 처럼 자원 5종을 새로 만들지 않고 사슬끼리 부산물로 잇는다.

**첫 시제품 = 에일 + 직물** [권고]. 에일은 기존 곡물·주택·시장·가내노동 위에 얹는 저비용 사슬이고, 직물은 목초지·가축·가내노동·수력·수출·후기 변화를 한꺼번에 여는 기함 사슬.

**직물 세분도 [확정 K2: 7단계]**: 모든 중간재가 자원. 단, 가내 단계(양모→실→직물)는 창고를 거치지 않는 집 안 재고. 염색은 염료 자원과 염색 공방을 요구하므로 C5에서 **양모→축융 직물까지 먼저**, 염색·마감은 C5-2로 이어서(같은 데이터 모델, 콘텐츠만 뒤).

**가내 생산은 실제 소량 재고를 만든다** [권고]. 그래야 "집이 경제시설"로 보인다.

## 4. 땅의 어휘 [권고]

세 층으로 나눈다. 열 종류를 한 UI에 쏟지 않는다.

| 층 | 어휘 | UI |
|---|---|---|
| **플레이어가 칠하는 구역** | 필지(burgage), 경작지(arable), 목초지(pasture), **건초지(hay meadow)**, **숲·공유림**, 과수원 | 구역 브러시 |
| **영주 특수 토지(estate)** | 양어지, 토끼 사육지, 비둘기장, 사슴 공원, 직영지·grange | 영주 메뉴, 위신·특권과 연결 |
| **자원 입지 오버레이(지도가 정함)** | 물레방아 수로(mill stream), 부두, 점토 구덩이, 채석·백악, 광석 | 지도 생성·시나리오 |
| **공동 이용 상태** | common pasture, common wood/pannage | 별도 지형이 아니라 **필지 위 `common-right` 상태**(권리 시스템과 일치) |
| **도시 내부 sub-use** | 텃밭·croft, 공방 마당, 가축 우리, 창고 | 독립 구역이 아니라 **필지 변형/슬롯** |

**성벽 안팎 규칙**: 성내는 필지·시장·교회·상점·공방·작은 텃밭·작은 우리·창고. 대규모 경작지·건초지·목초지·숲·채석·숯·사슴 공원은 기본적으로 밖. 무두질·가마는 금지가 아니라 **밀집·화재·악취 페널티**로 가장자리로 밀림. 물레방아·축융기는 성벽보다 **물길이 우선**.

**지역 archetype**: open-field/chalk형(핵화촌, 넓은 공동 경작)과 Weald형(분산 취락, 울타리 친 작은 밭)을 구분. 3포 윤작을 전 지도에 강제하지 않는다.

**건초지가 병목**: 가축 수용력은 겨울 사료(건초)가 정한다. 여름 수확 후 방목 가능.

## 5. 건물 카탈로그 v1

### 5.1 주택: 등급 × 변형
등급(L0–L4, 부유도)은 유지. **같은 등급 안에서 외관이 달라지는 축**을 둔다. 변형은 `직업 + 뒤뜰 용도 + 지역 재료 + 필지 폭 + 증축 이력`을 seed로 결정론적으로 고른다.

| 변형축 | 화면 | 경제 |
|---|---|---|
| **직업형** | 앞 상점 + 뒤 공방 / 양조 통 / 직기 / 제화 작업대 | 가내 공예 슬롯 |
| **저장·상업형** | 큰 문, 지하실·undercroft, 뒤채 창고 | 상인 저장, 여관, 직물·곡물 재고 |
| **생계농업형** | 텃밭, 과수 한 그루, 돼지·닭 우리, 헛간 | 식량 보충, 소규모 가축 |
| **합필형(상위)** | 넓은 전면 또는 인접 필지 통합, 뒤 날개·안뜰 | 큰 가구·하인·저장 |
| **빈곤·주변형** | 작은 단칸, 주변부, 값싼 재료 | 낮은 지대, 가내 노동 의존 |
| **재료형** | 초가/기와, 목골조, 석조 기단 | 화재 위험·유지비·위신 |

등급마다 **기본 3변형**(cottage / artisan / merchant-storage)으로 시작, 상위 등급에 합필형 추가. 직업이 사라져도 외형 일부가 남아 도시가 자기 경제사를 축적한다.

### 5.2 농장: 토지 전략 변형
`경작형(헛간·쟁기·소)` / `혼합형(젖소·건초더미·작은 밭)` / `목축형(양 우리·넓은 초지)`. "L3 농장"은 같은 생산량의 새 그림이 아니라 **같은 부유도의 다른 토지 전략**.

### 5.3 공방: 세 형태
`거리 공방`(제화·재단·소형 대장간) / `뒤뜰·가장자리 더러운 공정`(무두질·가마) / `물가 동력 공정`(축융기).

### 5.4 시설 (필수도는 역사적 보편성, 밸런스 조건 아님)

| 필수도 | 시설 |
|---|---|
| **매우 높음** | 교구 교회, 시장 광장, 우물(여러 소형 수원 가능) |
| 높음 | 여관(숙박·마구간), 에일 판매 가구/brewhouse, 화덕, 도랑·구덩이, 물레방아(수로 있으면), 다리·나루(입지) |
| 중간 | 예배당·chantry, 시장 십자가(모든 소도시에 석조는 아님), 정육 좌판·도살장, 풍차, 창고·지하실, 구빈원·병원(의료기관 아님) |
| 낮음·시나리오 | 수도원 분원, 순례 성소, 다리 예배당, 길드홀·tolbooth(자치 발달 도시), 도수관(conduit), 성채, tithe barn(교회·장원 맥락), 텐터야드(직물 도시), 부두(항구) |
| 제외 | 공중 목욕탕(소도시 기본 시설 근거 약함) |

**성벽 [보류, 권고: 선택 프로젝트]**: "인구가 늘면 목책, 더 늘면 석벽"은 역사적 일반 법칙이 아니다. 해안 위협·전략 도로·왕실/영주 지원·재원이 있는 지도에서만 정당화되는 대형 프로젝트로 두고, 방어가 덜 필요한 시장도시는 1450까지 길·도랑·통제점만으로 성장할 수 있게 한다. 현재 `촌락→목책→석조 도시`는 `촌락→조밀한 시장도시→[조건부] 요새 석조 도시`로. 석재는 성벽 없이도 교회·다리·고급 주택·토대에 수요가 있어 가치가 유지된다.

### 5.5 가축 (규모는 소유 계층 밴드로)
`cottager / mixed smallholder / substantial tenant / demesne flock`. 가구당 평균 수치를 전국 고정하지 않는다.

| 가축 | 역할 | 화면 |
|---|---|---|
| 양 | 양모·고기·거름·가죽 | 무리, 양치기, 우리, 털깎기 |
| 소·황소 | 견인·수레·젖·고기·가죽·거름(1319–20 역병에 특히 취약) | 소 쟁기 팀, 초지의 소, 수레 |
| 말 | 빠른 수송·기승(농가마다 한 필은 아님) | 짐말, 기승자 |
| 돼지 | 고기·기름, 숲 방목 | 숲으로 몰아가는 돼지, 뒤뜰 우리 |
| 닭·거위 | 알·고기·깃털 | 뒤뜰, 공유지 |
| 비둘기·연못 물고기 | 영주·수도원 시설, 위신 | 비둘기장, 연못 |

## 6. 사람·시간·생활

**주민은 직업 슬롯의 합이 아니다.** 소규모 가구(소매·작은 craft·텃밭·계절 농업), 전문 장인, 상인·클로시어, 일용 노동자, 하인·도제, 여성 가내 생산자, 과부 가구주, 성직자, 빈민·유랑, 농촌 방문객. `가내 공예 + 일용 노동 + 계절 농업` 순환 모델(C3)과 일치.

**파동**: 시장일에 주변 촌락 사람·짐말·수레가 몰리고 여관이 붐빈다. 정기시는 더 길고 넓다. 평일과 시장일을 같은 밀도로 그리지 않는다.

**계절 애니메이션(별도 콘텐츠 없이 다양성)**: 봄 쟁기·파종·새끼 양, 초여름 털깎기·건초, 여름 공사철, 가을 수확 대량 노동·탈곡·맥아·양조·도살·돼지 숲 방목·장작, 겨울 실내 방적·수리. 같은 주민이 계절마다 다른 일을 한다.

**화면 요소 카탈로그**(시설이 아니라 소품·동작): 시장 자루·달걀 바구니·가금 우리·생선·양모 뭉치·직물 두루마리·차양·저울, 큰길의 짐말·수레·가축 몰이·행상, 뒤뜰의 방적·양조 통·맥아 말리기·장작 패기, 직물 구역의 양모 세척·직기·젖은 직물·텐터 틀, 무두질의 걸린 가죽·구덩이, 물레방아의 자루·수로·수레 줄, 숲의 저목·돼지·숯가마 연기, 공사장의 석공·목수·석회 소성, 부두의 통·그물·소금 자루, 교회의 행렬·종·구호, 재난 후의 판자 친 빈집·웃자란 필지·재건 비계.

## 7. 지도 archetype (같은 건물 목록, 다른 도시)

| archetype | 자원 패키지 | 산업 조합 | 사례 |
|---|---|---|---|
| 농업 평야(chalk·open field) | 넓은 경작지, 방앗간, 시장 | 식량곡·보리·에일, 정육·가죽 | 일반 시장도시 |
| 하천 직물 | 수로(mill stream), 양모 배후지 | 축융기·염색·클로시어·텐터야드 | Romsey(수도원 영주 + 수로), Salisbury(상한), Newbury(15c 성장) |
| 해안 항구 | 부두, 어장, 수입 소금 | 어업·염장·교역 + 습격 위험 | Rye |
| 숲·철(Weald) | 숲, 철광석, 점토 | 숯·철·공구·도기 | Weald fringe |
| + 오버레이 | 순례로, 수도원 영주 | 성소·구호·소비 | 다섯째 archetype |

기본은 합성 도시, 위 archetype을 시나리오 seed로. 실제 도시 재현 캠페인은 후속.
