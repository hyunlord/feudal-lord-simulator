## 배수 재현
새게임→습지 지도1→목표형→일시정지→줌0.565 pan(728,-125)→건설/생업/습지 배수→화면(1226,617), 실제 클릭칸(55,27).
- t0:9칸·목재45·일꾼4명이면 약1계절 예측. 클릭 뒤 ‘이미 공사 중인 물’ 안내.17-036/037.
- Esc로 도구·건설창 닫고 같은 지점에서 확대. 줌1.101 pan(255,-829).
- t299/768: 수면 둘레 나무 구조와 수레.17-039/041.
- t1004: 추가 공사 구조가 보이고 물은 남음.17-042.
- t1573: 물이 제거되고 마른 땅과 배수로 외형.17-043. **완공 순간 정확한 틱은 표본1004~1573 사이로만 한정**.
- t3002: 겨울에도 마른 중심과 배수로 유지.17-044.
클릭만으로 공사 상세 진척 수치를 찾지는 못했다. 화면 외형의 단계 전개 관측과 내부 단계명/완공플래그 검증을 구분한다.

## 미검증을 남긴 범위
전체 정기시험을 반복한 회차가 아니라 새땅·변경면 집중 회차다. 계절 전환 순간의 기존012 동일 실패, 수레026 장기보행, 성벽003/005, 청원036,1~5장 전체 도시, 장기 무작위지도 품질은 이번 미검증. 미검증은 기존 닫힘/열림을 바꾸지 않는다. 1024미만은 사용자 지원범위 밖. FPS·프레임시간·성능 게이트를 측정하지 않았다.
