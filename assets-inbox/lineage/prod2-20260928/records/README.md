# 혈통 초상 본 제작 2차 후보

L6 백작 가문, L7 인접 기사 가문, L8 방앗간 가문. 가문마다 창시 부부·자녀4·외부 배우자2·손자4, 12명과38단계 초상이다. 전체36명·114장, 확인 그림4장, CSV114행, TRAITS.md와 검수 기록을 납품한다. 게임 설치와 제품 코드 변경은 하지 않는다.

## 기존 인물과 연결

| 혈통 인물 | 승인된 풀3 인물 | 재사용 단계 |
|---|---|---|
| L6_101 | I101 백작 | 청년·장년·노년 |
| L6_102 | I102 백작부인 | 청년·장년·노년 |
| L6_201 | I103 후계자 | 청년·장년 |
| L7_101 | I107 인접 기사 | 청년·장년·노년 |
| L7_102 | I108 기사 부인 | 청년·장년·노년 |

이미 노년 원본이 있어 중복 생성하지 않았다. 위14장은 원본 바이트를 그대로 보존한다. 새 제작은100장이다. 재사용 원본은24→45→70세이므로 +21년 장년 간격을 그대로 기록한다. 신규 인물 장년은 청년+20년이다. I103의 기존 짙은 금발, I102의 기존 녹색 옷처럼 원본에 이미 있는 형질·복식은 변경하지 않았다.

## 제작 규칙

- 자녀·손자 생성에는 실제 부모 두 초상을 입력한다. 연령 편집에는 해당 인물 청년도 함께 사용한다. 기존 I103 재사용은 새 부모 참조 생성으로 표현하지 않는다.
- 가족 공통은 머리색 범위·얼굴형·특징 하나, 형제별 차이는3개 이상 지정한다. 코·턱을 정밀 복제하지 않는다.
- 아기는0~2세 포대기·아기 모자, 어린이는6~9세. 기혼 성인 여성은 머리를 가리고 미혼은 드러낸 머리를 유지한다.
- 담비 모피는L6만. L7은다람쥐·여우 모피 젠트리. L8은튼튼한 모직·가죽 앞치마·밀가루 자국으로 구분한다. 피부색·체형을 신분이나 도덕성과 연결하지 않는다.

## 확인 그림과 판정

1. 세 가문 가계도. 실제96px 초상.
2. 세 가문 청년30명 익명 가족 묶기. 의뢰 기준80% 이상.
3. 형제9쌍·동일인9쌍. 청년↔장년 포함. 96px 보조판도 제공.
4. 1차L3·L4·L5와 이번L6·L7·L8에서 청년5명씩, 옷만 보이는30칸. L3와L7은 같은 젠트리 계급으로 채점한다.

독립 시각 판정 결과·오판·한계는 REPORT.md와 records/에 기록한다. 메타데이터나 해시 검사를 시각적 판독 통과로 대신하지 않는다.
