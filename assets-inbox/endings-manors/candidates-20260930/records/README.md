# 캠페인 결말·빈 영주관 후보

상태: candidate. 게임 미설치. 프로젝트 소유 Wave21 캠페인 끝·Wave31 장 시작과 Wave12 영주관만 이미지 참조로 사용했습니다.

## 내용

- `assets/endings/`: 결말 6장, 각 1920×1080 JPEG(품질92). 가벼운 납품을 위해 불투명 삽화는 JPEG를 사용했습니다.
- `assets/manors/`: 빈 영주관 2장, 각 416×328 투명 PNG. 원본 피벗 A=(249,319), B=(251,319).
- `checks/01-six-endings.jpg`: 여섯 장면 구분 비교.
- `checks/02-manor-alignment.png`: 원본·빈 영주관·50% 겹치기 및 피벗 표시.
- `assets.csv`: 8행 생성 기록. `records/`에 실제 프롬프트·출처·편집·검증 기록.

## 검수 범위

에셋 그림에는 글자를 넣지 않았습니다. 확인 그림의 라벨은 검토용입니다. 빈 영주관은 캔버스·피벗이 같고 큰 윤곽은 유지하지만 생성 편집 특성상 모든 건축선의 픽셀 동일성은 보장하지 않습니다(외곽 alpha IoU 약99%). 새 후보이며 게임 런타임 검증·설치는 수행하지 않았습니다. 고해상도 생성 중간본과 참조 원본 중복은 ZIP에서 제외했습니다.
