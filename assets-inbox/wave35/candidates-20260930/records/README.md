# Wave 35 · 영주 모드 UI 후보

게임 미설치. 승인된 기존 파일은 변경하지 않았다. 확인 그림은 납품 PNG를 오프라인에서 조립한 모의 화면이며 실제 게임 화면이 아니다.

## 구성
- 의뢰서 기본 항목 43장: A9 + B10 + C8 + D12 + E4.
- 직책 32px 파생본 5장, 9-slice 조립 보조 레이어 2장(협상 중앙선·장부 접힘)을 더해 **PNG 50장 / CSV 50행**.
- 확인 그림 2장: 협상 1280×800, 영지·약속·영수증 1280×800.
- assets.csv: 규격·9-slice L/T/R/B·용도·생성 기록·SHA256.
- index.html: 모든 파일 개별 링크. qa/assets-contact.jpg: 전체 검수용 축소판.

## 사용 계약
- assets/에는 글자·숫자를 그려 넣지 않았다. 확인 그림의 한글만 임시 조립 텍스트다.
- 모든 PNG는 RGBA. 삽화 9장은 불투명 사각 그림이며 UI 부품은 바깥이 투명하다.
- treaty_frame에는 treaty_divider를 중앙 고정 폭16px로 조립한다. ledger_book에는 ledger_spine을 중앙 고정 폭24px로 조립한다. 배경만 늘리고 중앙 장식을 가로로 늘리지 않는다.
- 9-slice 수치는 records/nine-slice.json과 CSV에 동일하게 기록했다. 영수증 상단190px·하단110px은 그림 자리·장식선을 보호한다.
- acceptance_scale은640×128, 왼쪽부터128×128 다섯 셀이다. 제품에서는 한 상태를 골라 사용한다. 확인 그림은 비교를 위해 다섯 상태를 함께 보인다.
- 프레임 중앙선/접힘은 9-slice 기본 그림 밖의 보조 레이어다. 위 조립 계약을 지켜야 의뢰서의 완성 형태가 된다.

## 제작·보존
프로젝트 제공 참고 그림만 사용했다. 정확한 생성/교정 프롬프트와 참조 방식은 prompts/와 records/에 있다. 제공되지 않은 모델 버전·seed는 기록하지 않았다.
고해상도 생성 원본과 반려 이력은 이 폴더의 raw/ 및 도구 생성 위치에 보존했다. **경량 ZIP은 raw/를 제외**하고 RAW_INDEX.json에 경로·크기·SHA를 싣는다.
Sharp는 크기 맞춤·투명 여백·투명 RGB 정리·명시된 확인 그림 조립에만 사용했다. 게임 코드·경제·UI 런타임에는 설치하지 않았다.

## 확인 범위와 한계
납품 크기 시각 검수, 부품 조립, PNG/CSV 대조, 알파 검사, 9-slice18건 및 ZIP CRC를 확인했다. 게임 적용·터치 영역·DPR·동적 상태 연결은 미검증이다.
쇠락 영지는 외곽 방치와 남은 정원으로 구분하지만 교정 중 지붕 손상이 줄어, 가난한 영지보다 쇠락 표현이 완만하다. 실제 역할 구분은 문구와 함께 검수해야 한다.
