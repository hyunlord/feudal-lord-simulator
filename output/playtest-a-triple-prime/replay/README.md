# A‴ 새 게임 화면 플레이 검증 — 유효 시도

AI의 화면 플레이는 사람의 재미나 사용성 판단을 대표하지 않는다. 이 기록은 화면만 보고 조작한 AI가 실제 60분 안에 목책을 완공할 수 있었는지만 판정한다.

- 제품 HEAD: 부모가 동결한 `518c64a`.
- `npm run play -- --port 4173`의 프로덕션 빌드에서 새 게임 시작. Chrome 1600×1100.
- 브라우저 준비: 2026-09-23 11:18:02.992 UTC. 실제 60분 종료선: 12:18:02.992 UTC.
- 플레이 중에는 화면 픽셀과 마우스·키보드만 사용했다. DOM·콘솔·소스·저장 상태·주입 상태·자동 발전 버튼은 사용하지 않았다. 증빙 JPG는 12장이다. 화면 관찰용 PNG는 한 파일을 덮어썼다.
- 앞선 중단 시도는 이 폴더의 `invalidated-*` 하위 디렉터리에 보관했고 이 판정에서 제외했다.
- 게임 시간은 화면에 독립된 시계가 보이지 않아 기록할 수 없었다. 아래 `2395틱`은 화면의 자원 회계 구간 표시이며 현재 게임 시각으로 해석하지 않는다. `~` 표시가 붙은 실제 시간은 독립 입력 로그가 없어 근사 구간이다.

**판정: 실패.** 실제 60분 안에 목책을 완공하지 못했다. 선포는 한 번도 하지 못했고, 첫 목책 자재 도착도 없으며, 완공 시각도 없다. 최종 증빙은 [12-final.jpg](./12-final.jpg)다.

선포 전 목표 패널에 길 없는 목책 구간이 13개 표시됐고 이후 약 16개까지 보였다. 목책을 선포하지 못해 그 구간의 강조 길 안내와 한 칸 길 설치 효과는 실제로 시험하지 못했다. 이것은 창고 경고와 별개의 문제다.

첫 추가 창고는 카메라 이동 전 대략 화면 (500,430), 최종 화면에서는 (400,470)에 있다. 최종 화면의 창고 북쪽 (400–500,420) 부근에 옅은 길/길 같은 표면이 지나고, 동쪽에서 접근하는 길도 여러 칸 시도했지만 “창고에서 길이 이어지지 않음” 경고는 사라지지 않았다. **창고용으로 강조된 누락 타일이나 점선 추천 연결은 보지 못했다.** 보인 것은 일반 길 그래픽과 경고 문구다. 어느 정확한 한 칸을 연결해야 하는지는 화면에서 찾지 못했다. 마지막 연결 창고는 화면 (920,438)에 미리보기 “도로 연결 ✓”가 직접 표시되어 그 자리에 놓았다. 그 뒤 가용 목재가 다시 늘었다.

이 결과는 AI의 한 차례 플레이에서 관찰한 진행 실패다. 늦은 저장 공간 발견과 연결 안 된 첫 창고 설치는 플레이어의 판단이 개입된 결과이므로, 이것만으로 제품 결함이라고 단정하지 않는다.
