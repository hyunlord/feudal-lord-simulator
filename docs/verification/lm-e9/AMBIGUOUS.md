## 겹치는 초안(사용자 확인 요청 ②)
- **031 「누구의 손에 장부를 맡길까」(1366–1368)와 059 「누구의 손에 장부를 맡길 것인가」(1439–1445)**: 제목이 거의 같고 선택도 "능력 높은 후보 / 충성 높은 후보 / 직접 감독"으로 같다. 다른 것은 출발 상태뿐이다 — 031은 **이미 위임 중**(현직을 바꿀지), 059는 **직접 감독 중**(처음 맡길지).
  - 제안(엔진 쪽 권고): **서로 다르게** — 031은 "청지기를 갈아야 할 때"(현직 교체: 능력 높은 후임 / 충성 높은 후임 / 거두어 직접 감독), 059는 "직접 감독을 내려놓을 때"(처음 위임: 능력 높은 후보 / 충성 높은 후보 / 계속 직접). 제목·본문·첫 문장에서 출발 상태를 드러낸다. 하나로 합치면 한 항목이 두 출발 상태에 따라 다른 선택을 내야 해 등록기 항목이 복잡해진다.
- **019 「새 영지의 열쇠를 누구에게」(1322–1347)도 059와 겹친다**: 둘 다 직접 감독에서 위임으로. 019는 소작인 친화 / 상인 친화 후보(성향), 059는 능력 / 충성(자질)으로 비교 축이 다르다 — 겹침을 피하려면 059의 축을 "자질"로, 019의 축을 "성향"으로 본문에 밝혀 주면 된다.
- 같은 틀의 묶음(문제 아님, 참고): 005·024·042(좌판세), 015·035·046(목재 주문), 013·025·052(감사 처분, 등록기에서 한 묶음 `steward_audit`으로 동시 제시를 막음).
