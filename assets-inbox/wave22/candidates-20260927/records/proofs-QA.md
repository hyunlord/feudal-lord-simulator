# Wave 22 확인 그림 자체 검수

검수 대상: `checks/01-fill-seasons.png`, `02-archetype-scenes.png`, `03-coastal-comparison.png`.
범위: 실제 후보 PNG와 프로젝트 기존 그림의 오프라인 합성. 게임 설치·실행·엔진 UV 동일성은 검증하지 않았다.

## 합성 기준

- 01: 15개 fill 각각 원본으로 3×3 합성한 뒤 한 번만 0.5 / 0.3 축소. 소수 좌표의 개별 타일 축소가 만드는 가짜 접합 틈을 피했다.
- 02: 5개 장면에 동일한 기존 주택·참나무·자작나무 배치. 기존 풀은 위, 신규 지면은 아래, 전이 띠는 중간. 지면/띠만 2:1 아핀 변환, 오브젝트는 원래 등각 스프라이트 사용.
- fill UV는 한 장당 2×2 논리 칸을 가정한다. 이는 검토용 합성 가정이며 실제 엔진 UV와 동일하다고 주장하지 않는다.
- 주택은 `historicalHouseSpriteRect`의 줌1 폭 56.32px 및 alphaBounds 하단 중심 접지를 적용. 나무는 기존 manifest의 renderScale/anchor를 적용했다. 신규 데칼은 원본 아래 중앙 8px 위를 접지로 잡았다.
- 03: 기존 풀/물 위에 기존 shoreline_a와 신규 해안 6장을 각 3회 반복. 접합 표시선은 그림 바깥에 둠. 위=육지, 아래=물.
- 원본 경로/배치/축척은 `proofs-provenance.json`, 재현 스크립트는 `proofs.cjs`.

## 관찰 판정

| 항목 | 판정 | 근거/제한 |
|---|---|---|
| 기존 집·나무·풀과 색 연결 | 통과(오프라인) | 새 땅과 소품이 같은 올리브·황갈·청회 팔레트로 이어지고 기존 오브젝트와 과도한 채도 충돌 없음. |
| 줌0.6 유형 구분 | 통과(장면 조합) | 백악은 밝은 노출/돌, 히스는 고사리·탁한 초지, 습지는 청회색 웅덩이/갈대, 해안은 모래·유목, 숲은 갈색 낙엽/쓰러진 나무. 유형별 소품을 포함한 장면 기준. |
| fill 3×3 접합 단절 | 시각 통과 | 0.5/0.3에서 직선 이음 틈은 보이지 않음. 별도의 픽셀 검증 결과와 함께 판단할 것. |
| fill 반복 리듬 숨김 | 조건부 | 백악·해안 6장 재수정 후 길게 이어지던 사선 줄은 짧고 흩어진 얼룩으로 개선됨. 3×3에서는 얼룩의 반복 주기와 사선 배열이 일부 남음(히스·해안). 이음새가 없다는 것과 반복이 전혀 안 보인다는 것은 별개. 큰 단일 면의 자연스러움은 게임 배치에서 추가 검토 필요. |
| 여름·가을·겨울 구분 | 통과(3계절 병렬) | 동일 얼룩 구성이 유지되고 여름 올리브, 가을 황갈, 겨울 회색·얇은 흰 흔적이 구별됨. 겨울 유형끼리는 색 차이가 줄어듦. 해안 겨울은 밝은 회백색 서리/모래 면적이 넓고, 두툼한 적설 윤곽은 없지만 다른 겨울 fill보다 밝다. |
| 해안 3유형 줌0.6 구분 | 통과 | 모래는 밝은 연속 띠, 자갈은 회갈색 돌 덩어리, 염습지는 올리브 돌출·진흙 물길. |
| 해안 기존 물가 톤 | 통과 | 기존 shoreline_a와 채도/명암 연속. salt_marsh_b는 a보다 일반 물가와 비슷해 유형 특성이 약함. |
| 소품 저배율 의미 | 조건부 통과 | 큰 고사리/돌/유목/갈대는 읽힘. 작은 버섯은 줌0.6에서 갈색 점 덩어리로 보여 종류 판별이 약함. 확대 상세와 함께 검토. |
| 실제 게임 통합 | 미검증 | 후보 제작 범위에 따라 게임 미설치. 충돌/렌더 캐시/프레임 성능 검증 없음. |

최종 갱신: 백악·해안 6장 사선 반복 감소본으로 01/02를 다시 생성하고 직접 재검수했다. 03은 이전 검수본 그대로 유지했다.
