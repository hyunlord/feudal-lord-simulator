# 집 벽에 거는 그림 계약

`building-attachment`는 본체와 따로 그리되 실제로 그린 본체의 좌표를 기준으로 붙이는 그림이다. 첫 사용은 승인된 시대 간판 8장이다. 새 묶음은 `packId: core`로 귀속하며, 옛 묶음의 생략값은 core다. 저장 형식의 팩 지원까지 구현했다는 뜻은 아니다.

## 입력과 좌표

| 필드 | 의미 |
|---|---|
| `kind` | `building-attachment` |
| `role` | 이 묶음은 `trade-sign` |
| `occupations` | 실제 가구 직업 id 목록 |
| `minZoom` | 이 묶음은 1.0. 먼 줌 0.6에서는 숨긴다 |
| `mounts[].bodyId` | 계약에 등록된 본체 id |
| `mounts[].point` | 그 본체 원본 이미지의 부착점. 크롭 전 픽셀 좌표 |
| `geometry.pivot` | 부착 그림 원본에서 벽에 맞출 점 |
| `geometry.scale` | 균일 배율. 가로·세로를 따로 늘리지 않는다 |
| 선택 사실 | `bodyId`, `occupation`, `calendarYear`, `season`, `role` |

좌표는 `target.x + (point.x - source.x) * target.width / source.width`와 같은 식으로 본체의 실제 draw 영수증에서 변환한다. 캔버스 중심이나 타일 모서리를 벽으로 간주하지 않는다. 존재하지 않는 본체·크롭 밖 부착점·중복 본체 등록은 계약 검증에서 거부한다.

첫 등록은 Wave 20의 `house_l2_1350_a-v2`, `house_l2_1350_b-v2`, `house_l2_1400_a-v2`, `house_l2_1400_b-v2` 네 본체다. 옛 집·합필 집·다른 등급은 좌표가 없어 새 간판을 생략한다. 지원 본체 추가는 그림을 보고 `mounts`와 선택 규칙에 등록한다.

## 선택과 그리는 순서

영주 모드에서 실제 거주 중인 단일 필지 집의 제빵·양조·대장·직조 가구에만 붙인다. 비어 있거나 버림·화재·굶주림·떠나는 중이면 숨긴다. 물을 끼얹은 화재도 실제 진화 시점 전까지 숨긴다. 일반 지도 화면에서 집 본체와 상태 층을 그린 다음, 그 집과 같은 깊이 순서로 그린다. 기존 길가 작업 소품은 유지한다.

1399년까지는 `_1300`, 1400~1450년에는 `_1420` 그림을 선택한다. 파일의 연도는 그림 계열 이름이며 발명 연도가 아니다. 실제 달력과 직업을 매번 읽어 연도가 바뀐 다음 그리기에서 선택을 갱신한다. 게임 상태를 고치거나 달력을 별도 캐시에 보관하지 않는다. 그림이 아직 준비되지 않았으면 해당 프레임에서 생략한다.

## 검증 범위

계약·선택·크롭 좌표·화재 및 빈집 배제·먼 줌 생략·그림 지연 로딩은 단위 시험으로 확인한다. 실제 벽 부착은 같은 저장과 카메라의 전후 캡처로 따로 판정한다. 캡처 자료는 기존 저장에서 네 집의 등급·건강 상태와 날짜를 고정하고, 기존 구두장이 한 가구를 직조공으로 바꾼 통제 시험 장면이다. 자연 플레이의 직업 분포나 발생 빈도를 증명하지 않는다.
