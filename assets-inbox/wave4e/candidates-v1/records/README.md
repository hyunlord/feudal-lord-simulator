## 제작·검수 범위

규격은 동봉한 `records/ASSET_PIPELINE_SPEC_v1.md`를 따릅니다. 모듈은 먼저 목표 접점과 점유 마스크를 만들고 참조 이미지 편집으로 제작했습니다. 부품·건물·가축을 단순 반전해 변형으로 세지 않았습니다. 소지품은 독립 방향 편집본이며 손잡이 좌표는 잠정값입니다.

원본 생성 이미지, 정확한 프롬프트·입력 참조, 후처리, SHA256, 후보 판정을 동봉했습니다. 모델 버전·seed가 도구에서 제공되지 않으면 null로 기록했습니다. 출처에 프로젝트 밖 상용 이미지나 외부 작가 그림을 추가하지 않았습니다.

워커는 기존 남녀 시트의 입력 편집이며 자유 인물 생성이 아닙니다. 셀별 등록·보호 마스크 적용 후 56셀 모두 하체 알파가 템플릿과 같습니다. 머리 외곽 중심 대리지표 최대 차이는 최종 74px 셀 기준 **0.769px**입니다. 이 값은 해부학적 머리 위치까지 2px 이내라는 독립 인증이 아닙니다. 원시 편집본과 보호 후 결과를 구분했습니다.

## 남는 한계

- 모듈 소켓과 135° 접점은 후보 기하·배치 규격입니다. 게임 통행·충돌·연결 전체 경우를 검증한 결과가 아닙니다.
- 띠의 양끝 픽셀 일치와 실제 장면에서 반복감이 없는 것은 별개입니다. 확인 그림은 합성 검사판입니다.
- 워커 옷 주름의 애니메이션 연속성, 외투와 소지품의 손 부착, 모든 기존 옷과 외투의 호환은 미검증입니다.
- 소지품은 방향별 그림을 만들었지만 엄밀한 3D 회전 정합까지 보증하지 않습니다.
- 겨울 헛간은 원래 피벗을 유지하지만 새 그림의 지붕 실루엣까지 원본 픽셀과 동일하지는 않습니다.

파일 수·치수·투명도·CSV 해시는 `records/package-validation.json`, 전체 파일 해시는 `SHA256SUMS.txt`에서 확인할 수 있습니다. 이번 ZIP은 아트 후보 납품이며 게임 적용 완료 또는 사용자 미적 승인을 뜻하지 않습니다.
