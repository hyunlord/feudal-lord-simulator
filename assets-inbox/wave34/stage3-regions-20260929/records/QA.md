# 자체 검수

## 구조·출처

- PNG 4장: 5×5 두 계절 640×320, 3×3 두 계절 384×192. 중앙 피벗 고정.
- 전체 영역 한 번 표시 계약. XY 반복 에셋이 아니므로 반복 이음 검사는 적용하지 않음.
- 픽셀 중심 기준 마름모 밖 알파 0, 내부 완전 투명 구멍 0.
- CSV 4행·27열을 저장 후 다시 읽어 전체 문자열 일치 확인.
- 기존 Wave 34 26장과 v2 2장 SHA-256 일치 확인. 게임 설치 없음.

정량 결과는 `records/asset-validation.json`과 `records/pixel-validation.json`에 있습니다.

## 확인 그림 판정

확인 그림 제작자의 판정(`records/proofs-QA.md`)에 따르면 타일 복제 도장과 녹색 격자 구멍이 보이지 않으며, 젖은 진흙·잘린 갈대·말라가는 웅덩이 흔적으로 공사 중 땅이 읽힙니다. 여름·겨울과 단계2→3→완료의 상태 구분은 줌 0.6에서도 유지됩니다.

단계2와 단계3은 방향과 두 줄 구조를 비교한 것이며 픽셀별 선 위치가 완전히 일치하지 않습니다. 3×3 줌 0.6에서 개별 새 풀 잎·미세 균열은 군집 질감으로 읽힙니다. 오프라인 합성 검수이며 엔진 배치·성능·입력 판정 검증은 수행하지 않았습니다. 독립 시각 검수는 별도 기록을 따릅니다.
