# Astra 의뢰: Wave 18 — 최소 HUD(UX-3 수정본)용 아이콘·패턴 · 약 40파일

작성 2026-09-26 · 근거: 첨부 `UX3_수정본_지시서.md`(조사 15 반영) — 상시 UI를 **상태 알약 4항목·속도·층위 전환·행동 도크 3**으로 줄이고, 배치 피드백을 **색+패턴+이유 아이콘**으로. 지금 렌더 세션이 이 작업을 하며, 여기에 필요한 그림이 없다.
규격: UI P0 아이콘과 같은 톤(얇은 외곽선·저채도·손그림), 96px 원본, 24/32/48px에서 실루엣 구분, 투명, 글자 없음. 첨부 기존 아이콘 시트와 **중복 모티프 금지**(망치=직접, 두루마리=방향, 인장 문서=권리, 일꾼 둘=노동).

## A. 행동 도크 (3) — 48px 버튼 위 주 아이콘
`dock_build`(건설: 자와 끌 또는 들보), `dock_ledger`(장부: 펼친 장부와 깃펜), `dock_steward`(청지기: 열쇠 꾸러미 — 초상 대신 아이콘, 말할 게 있으면 코드가 점 표시)

## B. 상태 알약 (4)
`pill_season_{spring,summer,autumn,winter}`는 기존 계절 아이콘 재사용 가능 — **새로 만들 것**: `pill_food_days`(빵+모래시계), `pill_population`(기존 인구 아이콘보다 단순한 2인 실루엣), `pill_money`(동전 주머니)

## C. 배치 불가 이유 아이콘 (8) — 칸 중앙·칩에 24px로
나무(벌목 필요) · 도로 없음(끊긴 길) · 건물 겹침 · 물 · 경사·바위 · 성벽 안 금지 · 구역 금지(다른 구역) · 자재 부족(빈 수레)

## D. 배치 패턴 텍스처 (4) — 칸 위에 곱해 쓰는 반복 타일 64×32(등각 칸 모양), 투명
`pattern_ok`(옅은 점 격자), `pattern_blocked_hatch`(45° 사선), `pattern_blocked_cross`(교차 사선), `pattern_service_range_edge`(서비스 범위 원 가장자리용 점선 띠 128×16 반복)

## E. 구역 도구 (8)
붓 · 다각형 · 지우개 · 되돌리기 · 다시 · 붓 크기(작은·큰 두 장) · 구역 칠하기 금지 표식

## F. 위기 아이콘 (6) — 36/48px, 우상단 스택
식량 부족 · 공사장 막힘 · 저장소 가득 · 떠날 준비 가구 · 화재 · 유지비 미납

## G. 시간·기타 (4)
`hud_hide`(HUD 숨김 토글), `layer_lock_badge`(층위 자물쇠 작은 배지), `pulse_ring`(해금 맥박 링, 투명 원 3프레임), `confirm_check_touch`·`cancel_touch`(태블릿 ✓·✕ 큰 버튼 아이콘) — 합 5

## H. 확인 그림 (3)
1. 전체 아이콘 24/32/48px 나열(기존 UI P0 아이콘과 한 줄로 — 중복·혼동 없는지)
2. 현재 첫 화면 위에 UX-3 수정본 평소 HUD(알약·속도·층위·도크)를 얹은 합성 1280×800, 태블릿 1180×820
3. 배치 모드 합성: 오두막 고스트 + 발판 칸 초록 점 격자 / 불가 칸 사선 + 이유 아이콘, **흑백 변환본도 함께**(색 없이 구분되는지)

## 제출물
약 40 PNG + 확인 3 + CSV + 검수표. 기준: 24px 실루엣 구분, 기존 아이콘과 모티프 중복 0, 흑백에서 가능/불가 구분.
