관문: 제품·접합 검증 완료, 게시 전 정확한 트리의 변경 시험·병합 검사 결과는 전달 ZIP의 최종 receipt에 기록한다.

제품 `d2ba0656`, 공용 계약 교정 `e9c0f51b`·`4a343353`, WASH `abcbf898` 통합 `feb106c9`. 최종 시트 4장과 손 소품 16장만 설치했다. 템플릿·마스터 68장은 설치하지 않았다. 원본 20장은 SHA-256이 같은 런타임 PNG로 보존됐으며 C2PA 청크가 없어 제거 작업도 없다. 새 그림 생성·엔진·저장·UI-A·감사/실행기 규칙 변경은 없다.

## 실제 연결과 공용 계약

P1은 기존 남성 상인, P4/P5는 남녀 노동 계층, P6은 실제 여성 노년층에 ID/seed 기반으로 선택된다. P6 파일명의 `widow`는 새 직업이나 혼인 상태를 만들지 않는다. 기존 도구·운반물·업무 표시가 우선이다. 바구니는 기존 분배자, 자루는 실제 봄 밭 일손의 파종 자루 문맥, 지팡이는 실제 노년 주민의 빈손 장식이다. 주머니는 허용된 실제 시장 방문객의 개인 소지품이며 세금·돈 액수·징수 업무를 뜻하지 않는다. 기존 `coin_carter` 경로는 coins의 storage:none 및 운반 생성/수령의 비저장 자원 제외 때문에 현재 비활성이다.

`walker-body`와 `walker-held-prop`가 공용 schema→registry→selector→composer adapter로 들어간다. `packId:core`도 같은 검증을 받으며 비코어 팩 시험도 같은 경로를 사용한다. 잘못된 팩·중복 id/슬롯·빠진 방향·손 좌표·높이/크기 오류는 기존 선택을 보존하며 원자적으로 거절한다. 미로딩 그림은 기존 fallback을 유지한다. 별도 private 명세에서 직접 그림을 넣던 경로를 없애고 생성기는 보존한 등록 자료로 공용 catalog를 만든다. CART/HERDS/LOGS/FENCE/WASH 및 UI 계약의 기존 27개 bundle은 의미상 그대로 보존했다.

## 등록과 화면 증거

이전 납품표의 템플릿 발점은 최종 그림과 달라 그대로 쓰지 않았다. 실제 FINAL PNG의 32셀마다 발·높이·양손을 재등록했고 손 위치 수동 판독 오차는 약 1 native px다. 16방향 소품의 원래 grip과 연결했다. 숫자상 같은 접점만으로 시각 판정을 대신하지 않았다. 실제 브라우저 합성으로 P1/주머니, P4/바구니, P5/자루, P6/지팡이의 여름·겨울 32셀과 모든16 grips을 펼쳐 봤다. 0.6/1/1.4배 및 12배 진단 확대를 남겼다.

사람 키 17.6 world px, flip 금지, 기존 망토와 가림 순서를 유지한다. 32셀의 망토 등록은 직접 겹쳐 본 뒤 기존 (0,0,1)을 유지했다. P6 지팡이는 16.1574 world px로 방향마다 크기가 같고 실제 허용8셀의 지면 관통은 0, 발점 대비 아래끝 간극은 0–약1.76 world px다. NW에서는 망토가 아래 지팡이를 가린다. 보이게 만들려고 늘리거나 망토를 끄지 않았다. P1/지팡이 SE gait1의 반사실적 조합은 0.5574 native px 관통이 있지만 실제 지팡이 선택 대상이 아니다.

최종 통합 실행 `astra-WALKER-integrated-feb106c`는 WASH 기준판과 같은 chapter-five 도시 저장을 여름/겨울, 줌1/0.6에서 4쌍 비교했고 exit0으로 끝났다. 같은 저장·카메라4쌍, 정상20파일의 정확한 집합과160합성의 decoded/encoded 동일성을 raw 결과에서 재확인했다. 원본 chapter-five 저장을 정식 migration으로 읽고 실제 tick 진행으로 얻은 상태를 사용했으며 보행자/ID/seed를 삽입·변경하지 않았다. 실행 중에는 일시정지해 같은 저장·카메라를 고정했다. 1280×800, DPR1. 소품 파일 사용을 증명하는 20개 정상 장면을 먼저 기록한 뒤 접합 보드를 만들었다. DOM+Offscreen draw 추적은 최종 PNG→합성/mip canvas→세계 canvas의 실제 호출을 잇는다.

**증거 한계:** 정상 장면의 20파일 사용은 장면들을 합친 witness union이다. 곡선 도로 정렬 때문에 옛 논리 방향으로 붙인 표본 이름과 실제 렌더 방향이 다르다. NE 주머니·NW 지팡이는 이웃의 실제 보행자 호출을 포함한다. 카메라 대상 20건은 네 몸체 공용 계약을 확인하고 소품 대상16건은14고유방향이다. 모든 파일이 각각 표적 인물의 가려지지 않은 최종 픽셀로 보인다는 주장은 하지 않는다. 지붕·벽의 가림은 유지되며 0.6배에서 주머니·자루의 작은 세부는 1–3px여서 판독이 제한된다.

공용 계약 교정 전후 **160개 worker composite의 decoded RGBA와 encoded SHA만** 같음이 확인됐다. 전체 화면은 물 애니메이션·HUD/폰트·툴팁 등의 차이가 관찰됐으며 원인 전부를 귀속하지 못했다. 전체 장면 픽셀 동일성은 통과로 주장하지 않는다. 접합 보드의 모든 몸체/소품 조합은 등록 검사이며 전부 실제 업무 조합이라는 뜻이 아니다.
