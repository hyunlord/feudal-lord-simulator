# 단계 비교판 검수

두 비교판 모두 여름·겨울 2행, 실제 납품 크기 PNG/JPEG와 2배 확대 JPEG를 만든다. 납품 자산 변경 없음. Sharp 합성만 사용하며 반전·회전 없음.

- `01-abandonment-timeline-native`: 1349 버려진 밭이랑+울타리 → 1352 풀 → 1360 덤불 → 1375 덤불 속 어린나무. 모두 같은 128×64 1칸 지면 중심과 기록된 (64,120) 피벗. 연도는 사용자가 요청한 미술 비교 연출이며 엔진 단계 임계년도가 아님을 판 안에 명시.
- `02-forest-recovery-native`: 그루터기 → 묘목 1–3년 → 어린나무 4–8년 → 어린숲 → 기존 성숙참나무. 각 납품 피벗을 같은 지면 중심에 놓았다. 앞 네 단계는 원본 납품 크기, 마지막 기존 참나무만 바이블 비교 H=35.2px의 최소5H로 배치했다. 작은 기존 원본의 확대임을 캡션·출처 기록에 명시하므로 신규 납품 아트나 실제 런타임 크기로 오인하지 않는다.
- 기존 project grass/겨울fill을 128×64 비교용 다이아몬드 마스크로 합성했다. 이는 아트 납품 파일이 아닌 프루프 배경이다.
- 각 계절에서 접지와 방향이 일관되고, 풀·덤불·어린나무의 밀도 및 키 차이가 판독된다. 어린숲은 성숙참나무보다 낮다. 실제크기에서 묘목이 작게 보이는 것은 의도한 H=0.68/1.02 비율이다.
- 원본크기 두 판을 시각검수했다. 겹치던 행 캡션은 간격을 수정하고 다시 렌더·검수했다.
- 엔진 미설치, 현재 지형 상태/시간 흐름/줌/클릭/차폐 검증이 아니다.

정확한 파일 해시와 합성 위치는 `stage-proofs-sources.json`, 재현 코드는 `stage-proofs.cjs`.
