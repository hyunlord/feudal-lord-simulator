## 관문 결과

### seed 3 1,200,000틱 (DGX, [seed3-1200000.json](seed3-1200000.json))
봇이 안정 뒤에도 멈추지 않고 1,200,000틱까지 돈다(`additionalAcceptance: () => false`). 같은 실행에서 덧붙은 기록·축소판을 모두 따로 모은 "접지 않은 원장"과 비교했다.

| | 접은 원장(게임) | 접지 않은 원장 |
|---|---|---|
| 크기(JSON) | **846,916 B** | 2,753,817 B |
| 기록 | 1,359(요약 1,192) | 3,378 |
| 축소판 | 312(256² 6) | 1,206 |

- 요약으로 바뀐 기록 3,211건은 모두 일상(심각도 0)이고 8계절 넘게 지났다. 요약의 `count` 합이 3,211과 같다.
- 영구: 심각도 1 이상 128건 = 접기 전 128건, 입주 23건.
- `history.query` 10종(전부 · 심각도 1·2 · 결정 · 사건+시대 · 가구 생애 · 이정표+결산 · 가구 행위자 · 앞 100,000틱 · 최근 8계절): 요약을 빼면 접기 전과 **모두 같다**.
- 저장: v15, 왕복 원장 동일. 저장 지문 테스트(`saveSchemaFingerprint`) 통과 — 스키마 번호·지문 무변경.

BOT-2 뒤 seed 3은 정상 도시다. 가구가 굶기·다시 먹기를 되풀이하지 않아, 접지 않아도 2.75 MB다. 그래서 지시서가 든 경우(F0-C2 가드레일 seed 3, 멈춘 도시 1,200,000틱)에도 같은 접기를 적용했다([f0c2-stalled-seed3.json](f0c2-stalled-seed3.json)).
- 크기: 8,841,562 B → **1,541,239 B**.
- 기록: 30,836 → 4,274(요약 1,192).
- 축소판: 1,206 → 312.
- 조회 4종 동일, 건수 일치.

접기는 계절 창이 고정이라, 한 번에 접어도 계절마다 접은 것과 같다.
