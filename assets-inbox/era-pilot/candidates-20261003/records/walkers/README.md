# 워커 시대판 제작·검증

상태: `candidate`, 게임 설치 없음. 4역할 × 4시점 = 16시트, 시트마다 296×148 RGBA, 74×74 셀 8개. 원본과 같은 NE / SE / SW / NW 열, 걸음 0 / 1 행이다. 1300 농민 남녀 2개는 프로젝트 원본을 바이트 그대로 보존했다. 나머지 14개는 built-in image_gen으로 완성 시트를 편집했다. 얼굴·옷·팔다리 부품 조립을 하지 않았다.

## 후처리

생성 출력은 1776×888이었다. 각 셀에서 alpha≥8 최대 연결 성분의 **완성 인물 전체** 경계상자를 구하고, 해당 원본 셀 경계상자로 CoreGraphics 기하 등록했다. 얼굴이나 손발을 개별 이동·교체하지 않았다. 이 과정의 모든 crop/target은 `register_*.json`에 있다. 일부 생성 이미지의 다음 행 머리 끝 1px가 이전 행으로 넘어온 경우는 최대 연결 성분 경계 계산으로 제외했다. 그림 재채색·절단 마스크·원본 알파 덮어씌우기는 없다.

## 실측

- 새 112프레임 모두 원본 bbox 동일, 캔버스·셀·방향·걸음 수 동일.
- alpha≥8 실루엣 IoU 평균 0.918672, 최저 0.85830. 알파 픽셀이 완전히 같지는 않다.
- 최하단 불투명 행 접지 y 차이 0px, 그 행의 x 중심 차이 최대 2.5px.
- 하단 15% alpha 가중 중심 x 차이 최대 1.786px, y 차이 최대 0.470px. 기존 프레임별 manifest pivot은 변경하지 않았다. 발 모양이 수학적으로 완전히 동일하다는 뜻은 아니다.
- 16시트의 방향별 두 걸음 프레임은 모두 바이트 중복이 아니다. 전개판에서 팔과 다리의 두 상태를 확인했으나, 엔진 속 걷기·접지·지터·장비 부착은 미검증이다.
- 가장 낮은 실루엣 IoU는 농민 남성 1380 SE 걸음 0. `worst_silhouette_reference_left.png` 왼쪽 원본 / 오른쪽 후보를 6배 확대한 비교다. 다리 각도와 가운 둘레의 소폭 변화가 남는다. 정밀 실루엣 일치가 추가 게이트라면 재작업 대상이다.

## 시각 검토

`gait_<role>.png`는 위에서 아래로 1300, 1340, 1380, 1420이며, 가로는 NE0 NE1 SE0 SE1 SW0 SW1 NW0 NW1이다. 2배 확대, 투명 배경이다. 농민은 실용 복식의 연속성을 유지하므로 74px에서 연도 구분이 약하다. 상인은 단추·몸통 재단에서 주름 가운으로, 향신 여성은 허리·소매·주름으로 변화를 준다. 같은 역할 색상과 머리덮개 윤곽을 유지했다. 시대 판별률은 별도 거리 눈가림 검수에 맡긴다.

재생성 1회는 남성 농민 1420 SE 발 위치 교정 목적이었다. 등에도 앞여밈 단추가 생겨 채택하지 않았다. `rejected_retry.json`은 재시도 원본 경로와 전체 프롬프트를 보존한다. 최종 생성물은 `generation.json`의 14개이며 원본 고해상도는 생성 도구 경로에 보존, 경량 ZIP에는 포함하지 않는다.

`generation.json`에는 전체 프롬프트·입력·생성 원본 해시가, `pilot/walkers/manifest.csv`에는 16개 최종 PNG 해시와 규격이, `frame_qa.csv`에는 128프레임 측정이 있다.

## 2차: 초기 복식 가독성 교정

1차 거리 눈가림에서 1300과1380의 구분이 약해, 1300 상인 남성과 향신 여성만 각각 한 번씩 재생성했다. 상인은 벨트와 짧은 재단선이 약한 느슨한 긴 튜닉의 큰 면, 향신 여성은 긴 속소매 위 넉넉한 무소매 서코트로 교정했다. 초기형을 색 변경만으로 구분하지 않았다. 총높이·머리높이·발노출·셀 bbox는 유지했다. 두 시트의 새16프레임 IoU 최저0.89156. 전체생성112프레임 IoU 최저0.85830는 기존1380 농민남성이다. 다른14PNG는 1차 파일과 바이트 동일함을 확인했다. 이전1300 원본2장은 외부작업폴더 walkers-round1에 보존했고 round2_generation.json에 새입력·프롬프트·해시를 기록했다. 큰면의 차이는 늘었으나 원본실루엣 제약 때문에 무릎 아래 길이와 서코트 부피 변화는 절제되었다. 재시험 시대 판별은 별도 검수 결과를 따른다.

경량 묶음의 확인 그림 정본은 `proofs/`에 있다. 같은 그림의 records 사본은 중복 용량을 줄이기 위해 묶음에서 제외했다.
