# Wave 7 — 보이는 시뮬레이션 재료 후보

게임에는 설치하지 않았습니다. 첨부 의뢰서의 상세 목록을 기준으로 제작합니다. 요약의 ‘약 60파일’과 달리 A12+B5+C20+D12+E10+F8+G6+H4의 합계는 **77 PNG**입니다. 확인 그림은 별도 4장, CSV는 자산당 한 행입니다.

모두 후보 PNG를 직접 합성한 검사판이며 실제 게임 실행 화면이 아닙니다. 배경과 배치는 검수용입니다. 이미지 안의 캡션은 검사판에만 있으며 자산 PNG에는 글자가 없습니다. `plus_float`의 +는 의뢰서가 요청한 기호입니다.

## 중요한 계약

- 집 연기는 용마루·초가 틈에서 시작합니다. 굴뚝을 추가하지 않았습니다.
- 사슬 확인판은 프로젝트의 기둥풍차와 빵 화덕 원본을 사용합니다. 물레방아가 아닙니다.
- 주택 눈·판자는 첨부 원본과 동일한 캔버스입니다. 원본과 같은 피벗을 상속하여 (0,0) 오프셋으로 겹칩니다. 원본 PNG에 수치 피벗 정보가 없어 새 좌표를 임의로 발명하지 않았습니다.
- 눈/판자는 원본 지붕·문·창 좌표에 등록한 마스크 안으로 한정합니다. 실제 원본 합성 그림과 마스크, 처리 좌표를 `sources/overlays/`와 `records/overlays-anchors.json`에 보존했습니다.
- 신규 소품의 줌 1.0/0.6 표시는 원본의 0.5/0.3배입니다. 첨부 주택·워커·수레는 이미 작은 런타임 그림이므로 사슬/겨울 합성에서 배율을 따로 명시합니다. 사슬 아래에는 새 레이어의 엄격한 원본 0.3배도 표시했습니다.

## 기록과 한계

`records/`에 전체 실제 프롬프트, 참조, 생성 원본 경로, 후처리, 치수·알파 검사와 판독 한계를 기록합니다. `sources/`는 생성 원본·등록 마스크·확인 자료, `references/`는 프로젝트 참조 이미지입니다. 제공되지 않은 모델 버전과 seed는 추정하지 않았습니다. 모든 자산은 `candidate`이며 사용자 채택 여부는 미정입니다.

줌 0.6에서 모든 소품의 의미를 보장하지 않습니다. 특히 작은 수레 적재물의 세부, 손에 든 빵, 등짐·빗장은 상세 검수표를 보십시오. 정적 4프레임 시트는 실제 애니메이션 속도·부드러움·상태 연결을 보증하지 않습니다. 런타임 통합, 이동·가림·DPR·성능은 이번 제작 범위 밖입니다.

최종 기술 검사: 77/77 지정 치수·RGBA·투명 여백, CSV77행 재읽기 통과. 서리 B/C 원형 반복은 비대칭 조각으로 재편집하고 겨울 확인판을 다시 검수했습니다. 줌0.6 전체 종류 식별은 부분 미달 상태를 유지합니다.
