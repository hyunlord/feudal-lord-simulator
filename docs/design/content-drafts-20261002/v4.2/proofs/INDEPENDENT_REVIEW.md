## 판정 원칙

- `body`, 선택 `label`, `tradeoff`가 실제 카드에서 읽히므로 대가를 다른 기획 필드에만 쓰면 불충분하다. `src/ui/registryCardModel.ts:180`.
- 정책 가중치·종류별 보조 약정은 특정 가구 구호나 공사의 완공과 다르다. 관계·돈과 별개 설정이 있다는 이유만으로 구체적 대상 결과로 승인하지 않는다.
- 실제 소송·증거·점유·혼인 계약·청지기 교체는 상태가 남는 구체적 결과다. 승소와 점유, 제안과 혼인 성사는 구분한다.
- 목재 주문은 기존 미입고 주문을 교체한다. 납품 시 대금을 지급하며 공급 지점과 자금이 필요하다. 18d/단, 장터 없는 촌락 경로 27d/단. 특정 불탄 집으로 자동 배분하지 않는다. `src/engine/timberTrade.ts:19,42`.
- 보류 권고는 제작·설치 판단이다. 게임 안의 유료 보류 선택과 다르며 기존 사건을 자동으로 끄는 효과는 없다.

## 기록 경로를 확인한 정정

검수 초기에 `answerAudit` 직접 처리에서 세력 관계 감소가 없다고 지적했으나, 원고 작성자가 후속 기록 경로를 지적했다. `src/engine/history.ts:986`은 처벌 감사에 연결된 실제 세력이 있으면 관계 변동 기록을 만들고, `recordDecision`의 registry 경로(`history.ts:230`)가 `stewardshipDrafts`와 `withFactionRecords`를 실행한다. 따라서 처벌의 정치적 비용은 실제 외부 경로에 존재한다. 직접 처리 함수만 보고 삭제하라는 초기 권고를 철회했다.

## 남는 편집 한계

목재 주문을 다루는102·123·138·144 등은 세부 시대 배경이 달라도 같은 경제 선택 구조를 공유한다. 문구가 정직해졌다는 판정이지 서로 완전히 다른 플레이 경험을 검증한 것이 아니다. 세율 카드 또한 실재하는 도시 전체 규칙 변경이지만 주효과는 수입·상인의 여력이다. 특정 상인의 입주나 장날 신설을 보장하지 않는다.

현재 문서는 발견과 조치 기록이다. 최종 통합본에서 R1–R8 반영 여부를 다시 읽은 뒤 최종 판정을 추가한다.
