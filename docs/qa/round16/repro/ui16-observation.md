## QA034 — 동일 과세 결정 빈 본문 해소 확인

같은 원본에서 1384년 여름 tick 337151 과세 결정이 자동으로 열렸다. 제목 ‘국왕의 과세 요구’, 본문, 과세를 낸다/감면을 청원한다 선택지 두 개와 예측, ‘나중에 정하기’가 모두 실제 이미지에 보인다. 15회차처럼 양피지와 초상만 남는 빈 본문 현상은 이번 동일 조건에서 해소됐다.

- [1600×1100](../evidence/ui16-03-tax1600.jpg): zoom 2, pan (544,-2277)
- [1280×720](../evidence/ui16-04-tax1280.jpg): zoom 1.781, pan (412,-2166)
- [1024×768](../evidence/ui16-05-tax1024.jpg): zoom 1.620, pan (305,-1921)

각 화면은 정착 750ms 이상 후 캡처하고 원본 JPEG를 직접 열어 확인했다. 너비 변경은 실제 viewport resize이며 브라우저 확대라고 부르지 않는다. 1024에서는 QA 오버레이 일부가 결정 뒤에 가려지므로 메타데이터를 함께 보존한다. 실제 1600으로 복귀해 보이는 ‘과세를 낸다’를 클릭하고 5배속 정상 진행했다(`ui16-06-tax-paid`).

## QA016 — 동일 1394년 길드 결정 겹침 해소 확인

1384 원본에서 실제 정상 5배속으로 1394년 봄 tick 376157에 도달했다. [1600×1100](../evidence/ui16-16-guild1600.jpg), [1280×720](../evidence/ui16-17-guild1280.jpg), [1024×768](../evidence/ui16-18-guild1024.jpg)를 직접 열어 판독했다. 두 번째 선택지 아래 테두리와 ‘나중에 정하기’ 사이에 간격이 있으며, 버튼이 선택지 테두리에 걸치던 현상은 해소됐다. 옛 동일 사건 원본 /tmp/QA_ROUND_14/evidence/ui14-064-guild1600.jpg를 직접 열어 대조했다. 단순 과세 화면을 길드 증거로 대신하지 않았다.

1600에서 실제 ‘나중에 정하기’로 보류(19) → 사건 칩(20) → ‘결정하기’(21)로 다시 열었다. 재개 시 tick 376168이며 최초와 같은 tick이라고 하지 않는다. 이후 보이는 ‘길드 편을 든다’를 정상 선택하고 5배속 진행했다.

현재 청원자에는 ‘작은 토머스 밀러 ·82살’, ‘큰 페트로닐라 노스우드 ·55살’이 표시된다. 과거 같은 사건의 ‘젊은 토머스/나이 든 페트로닐라’ 대신 큰/작은 구분으로 바뀐 것을 확인했다. 이번 표본은 현재 청원자 이름이며, 역사 기록 문자열의 일괄 교정까지 증명하지 않는다.

본문과 두 선택지 및 금고 예측 £240 7s가 읽히며, QA034 빈 본문도 이 사건에서는 미재현이다.

진행 조작 기록: 과세 납부 뒤 tick 337296에 ‘국왕의 과세 사절’ 사건 칩이 나타나며 화면이 정지했다(`ui16-07-progress`). 실제 Esc 메뉴에서 사건 카드 일시정지를 끄고 5배속으로 재개했다. 이후 중요한 결정 카드가 열리면 화면으로 확인한다. 자동 발전 설정은 원본 그대로 유지했다.

## 교회 청원과 사건 그림 — 추가 표본

1396년 봄 tick 384153에 ‘교회 증축 청원’에 도달했다. [1600×1100](../evidence/ui16-25-church1600.jpg), [1280×720](../evidence/ui16-26-church1280.jpg), [1024×768](../evidence/ui16-27-church1024.jpg) 모두 제목·본문·두 선택지·예측과 보류 버튼이 보이며 빈 본문/선택지 겹침은 미재현이다. 각 원본 JPEG를 직접 열어 확인했다. 청원 비용 £1 5s, 현재 금고 £255 3s, 증축 선택 예측 £253 18s가 읽힌다.

길드 그림(16)은 거리에서 깃발을 든 군중 대립, 교회 그림(25)은 석조 교회·비계·공사 인물이다. 동일 사건쌍 QA011의 같은 삽화 현상은 이번에도 미재현이다. 사건 그림의 모든 종류를 검사한 것은 아니다.

**장 표기 구분:** 이번 원본 과세·길드·교회 화면의 HUD는 문자 그대로 ‘제5장 · 자치와 유산’이다. 막간 성격의 내용이지만 실제 제4장 화면으로 세지 않는다. 제4장 표본은 다른 담당자가 검사하며 이 보고서에서는 미검증이다.

양모 집산지 이전(14)은 결정 선택지가 없는 사건 기록 표본이다. 설명·직물 값 1.1배 효과·삽화가 보였으며, 결정 본문 검증 수에 포함하지 않는다.

## QA015 — 같은 국왕 빈 전기 재현

교회 관찰 뒤 같은 1384 원본 바이트로 다시 이어하기했다. 실제 사건 일시정지 켬/계절결산 끔/5배속으로 과세에 다시 도달(28, tick 337158) → 리처드 2세 클릭(29) → 전기 보기(30).

[국왕 빈 전기 1600×1100](../evidence/ui16-30-king-empty-bio1600.jpg)에서 ‘아직 남긴 기록이 없습니다’가 중앙 세로 장식선을 가로지른다. QA015는 같은 인물·같은 빈 기록 조건에서 재현이다. 본문은 실제 원본 이미지로 판독했다. 전기 전체 화면에서는 QA 오버레이가 시각적으로 가려지므로 직전 카드(29)와 대응 메타데이터의 정지 tick 337158, zoom 2, pan (544,-2277)을 함께 보존한다. 이번 추가 표본은 1600만이며 1280/1024 빈 전기는 재검사하지 않았다.
