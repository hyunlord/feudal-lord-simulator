# 습지 지도 4장 검수

원본 지역 지도를 스타일·시점 참고로 사용해 각 지도를 한 번의 전체 이미지 생성으로 그렸다. 조각 배치·반전·재사용한 지형은 없다. 1600×1000 JPEG92, 원본 생성 PNG는 masters에 보존했다. 지도에는 건물·깃발·문자·슬롯 표시가 없다. 슬롯 표시판은 proofs의 별도 JPEG다.

최종 PNG/JPEG를 직접 보고 슬롯을 지정했다. 첫 사각형 판에서 나무·습지 경계에 걸린 후보를 찾아 옮겼다. 색상 기반 위험 픽셀의 국소 검색으로 위치를 보조한 뒤 다시 눈으로 검토했으며, 마지막에는 숫자24를 맞추려고 빈 공간을 축소하지 않고 문제가 있는 후보를 삭제했다. 일반70×55, 대형100×70(04의 s20은100×60). 좌표는 오버레이 아래쪽 중앙 기준이다. 슬롯 ID의 중간 번호 누락은 삭제 흔적이며 오류가 아니다.

최소 슬롯 중심 거리는 각 판 모두90px 이상이다. 시장도시/수도원 후보가 매판4개 있다. 도하와 갈림은 별도 landmark로 주석했다. 길이 자연 제방과 능선을 따라가는지는 육안으로 확인했으나 실제 고도·홍수·경로 탐색 모델은 없다. 풀이 난 들판과 가벼운 밭결은 빈 정착 후보로 간주했다. 큰 나무·수면·주도로는 피했지만 미세한 관목 붓터치가 사각형 가장자리에 남을 수 있으며 자동 픽셀 충돌 마스크를 주장하지 않는다.

습지30%는 생성 지시의 구성 목표이며 실측 수면율은 아니다. 모든 판에 구릉과 건조지가 있어 현대 평탄한 간척지 묘사와는 다르다. 양피지/올리브/푸른 회색 수로, 높은 사시점, 좌상광은 원본과 비교해 같은 계열로 판정했다. 사람 손으로 실제 그린 작품이라는 출처 주장은 하지 않는다; 이미지 생성 도구로 만든 손그림 화풍 후보다.

통합 검증에서 01의 s08/s09 사각형 가장자리 중첩을 발견해 s09를 삭제했다. 최종 총87슬롯.
