## 만든 것
1. **협상 엔진**(NG-2~NG-5)
   - 조항 묶음이다. 영주가 주는 것 다섯, 상대가 주는 것 다섯.
   - 수락 점수는 이름 붙은 이유의 합이다. σ((A−25)/4)를 5단계로 보이고, 큰 이유 3~5개를 함께 보인다.
   - 돈으로 넘지 못하는 하한이 있다(물질 35점 상한, 강등·상속녀 위험·어긴 약속·레드라인).
   - 역제안은 수락선 바로 위의 최소 묶음이다(상대가 원하는 차례, 욕심, 바뀐 조항만 차이로).
2. **약속 장부**(NG-6)
   - 기한까지 하면 지킴, 아니면 어김이다. 거짓말 버튼은 없다.
   - 어김은 관계, 다음 협상의 하한, 목격 세력의 원장 줄로 남는다.
3. **혼인 계약**(NG-7·NG-8)
   - 계약금·약속·관계 +10, 그리고 LM-E2 청구(혼인)가 생긴다.
   - 중간 사건: 신부 이주 → 첫아이 → 처남 출생(30%) → 병 → 유언 변경 시도(50%: 호의·지원 약속·그대로 둠) → 죽음 → 상속. 상속은 아들, 조카와의 소송, 아내를 통한 영주 가운데 하나로 끝난다.
4. **영주 모드 봇**의 한 번 시도(NG-9).
5. **저장 v40**. `diplomacy`는 첫 제안 전에는 없다. 그래서 샌드박스·캠페인의 상태가 바뀌지 않는다.

## 다음 후보
- 역제안의 채무 인수가 영주가 1년 안에 갚을 수 있는 크기를 넘는다(660~720d). 그래서 사람 경로 배치 1·4와 봇이 그 약속을 어겼다. 상대가 영주의 지급 능력을 보고 요구할지, 분할 약속으로 쪼갤지 판정이 필요하다.
- 이웃 가문 사람의 노화·사망은 혼인 경로의 사건으로만 움직인다. 혼인하지 않은 판에서도 늙게 할지 정해야 한다.
- 딸만 있는 시작 배치(3·5)의 혼인: 영주의 딸을 상대의 아들과 맺는 방향은 상대가 아들이 없어 지금은 없다.
