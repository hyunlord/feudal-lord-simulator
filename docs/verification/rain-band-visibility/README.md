## 실제 관찰

줌 1.0·0.6 원본 PNG와 영상에서 뽑은 무증폭·원배율 연속판을 직접 확인했다. 잔디 위 고밀도 구간은 왼쪽에서 가운데, 오른쪽으로 위치가 달라진다. 화면 전체를 가리는 흰 커튼은 없다. 다만 전체 마을에서 즉시 넓은 띠로 인지되는 정도는 약하며, 어두운 지도 밖에서는 더 잘 보인다. 원본 영상을 첨부했으나 이번 시각 판정은 원본 정지 프레임·연속판을 직접 확인한 범위이며 전체 영상을 실시간 시청했다고 주장하지 않는다. '전면의 강한 띠 가독성 통과'로 기록하지 않는다.

## 변경과 원인

세계 좌표·후보 셀·수명·이동속도·시간축은 그대로다. 비 강도에 따라 띠 중심의 실제 입자 출생 확률과 alpha를 늘리고 주변부를 줄였다. 기존 strong/faint 12장을 카탈로그 조건 두 그룹으로 선택한다. 파일 이름 치환·새 그림·화면 가짜 마스크는 없다.

strong 원본도 최대 alpha 175/255이며 불투명 환산 면적은 1.34~4.25 native px²뿐이다. 0.6줌에서 약0.48~1.53 px², 높이1.8~6px로 줄고 실제 draw alpha≤.9가 다시 곱해진다. 잔디 질감에 작은 입자가 묻히는 것이 전체 화면 인지성의 한계다. 띠 위치 차이는 확인되므로 불투명 폭우가 될 때까지 강도를 반복해서 올리지 않았다.

## 동일 조건과 검증

기존 seed1 tick5000 저장을 현 codec으로 다시 연 뒤 정상1배속 진행. 카메라 tile43,37, 1280×800 DPR1. 줌1은 tick5307까지, .6은5308까지 약31초. 실제 인코딩 FPS는 각각27.156(839프레임),17.970(558프레임)이다. 요청30fps와 구분한다. 실제 draw 기록은289682/473125, 진단 overflow0. 공유 DGX의 서로 다른 부하이므로 이전 실행 FPS와 성능 개선 비교하지 않는다.

13개 집중 회귀, typecheck, 해당 파일 ESLint 통과. 카메라 겹치는 세계 입자 동일, 무강수0, 강도 단조, 유한 후보 상한과 카탈로그 검증을 포함한다. 실제 브라우저 오류 배열은 비었지만 telemetry/sample 요청7개의 ERR_ABORTED가 있어 네트워크 전체 통과로 주장하지 않는다. 실행 뒤 port4302 닫힘 확인.

`z1.webm`, `z0.6.webm`: 실제 world canvas 영상. `*-key*.png`: 실제 전체화면. `*-band-sequence.png`: 영상 7초 간격 native crop4행, 대비 변경 없음. `*-draws.json`: 실제 rain draw 목적지·alpha·transform. `video-fps.json`: 인코딩 PTS로 측정. `VERDICT.json`: 소스 및 픽셀 측정. v1·v2 실패/약한 버전은 이웃 output 폴더에 보존.

## 게시 준비와 원칙 점검

현재 문서는 로컬 작업 커밋 준비 시점의 기록이다. 최종 본선 병합 뒤 `test:changed`·`check:merge`·해당 화면 줄 기하 감사는 아직 실행 전이며, 이전 light 캡처를 이 관문의 통과로 대신하지 않는다. Wave2와 lateL2가 게시된 뒤 최신 본선을 양쪽 보존 병합하고 관문을 실행한다. RR22 대상인 실행기·공용 관문·기준선·예외 목록은 변경하지 않았다.

A3·EXT-D1: 같은 세계 위치의 입자는 카메라와 줌에 따라 달라지지 않으며 그림 선택은 기존 core 카탈로그가 결정한다. A4: 실제 비 밀도 차이가 세계 좌표에서 움직인다. 과장 금지 원칙: 제한적 가시성과 영상 시청 범위·텔레메트리 실패를 공개한다. 엔진의 강수·저장 규칙, 공용 그림 로더, 다른 자연 효과는 바꾸지 않는다.

원본 캡처는 `/tmp/astra-rain-band-visibility/output/rain-band/`, 이전 v1/v2는 이웃 `rain-band-v1/`·`rain-band-v2/`, 재현 하네스·원본 저장·입력 패치는 `/tmp/astra-rain-band-visibility-capture-inputs/`에 보존한다. 보고 저장소에는 바이너리를 추가하지 않고 원본 SHA와 실행 이름을 남긴다. `capture-SHA256SUMS`는 해당 원본 캡처 폴더 기준이며 이 문서 폴더의 파일 목록이 아니다.
