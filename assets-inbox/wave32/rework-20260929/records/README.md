# Wave32 B 눈·판자 교정

B 눈은 기와 줄눈을 덮는 불규칙한 눈 더미와 노출 기와 틈으로, B 판자는 문을 가로지르는 X자로 교정했다. 나머지24 PNG는 이전 납품과 SHA256 동일하다. 전체26장 포함, CSV26행에서 교정2·유지24 구분.

건물·상태160×144, 피벗(80,128), 기본형/접지 불변. 오버레이 RGBA 분리. 게임 미설치 후보다. 이전 v1 폴더와 ZIP은 보존했다.

확인 그림1: A·B·C 눈/판자, 원래 크기와0.6배. 생성 원본은 astra-raw/wave32-rework-20260929에 보관하고 경량 ZIP은 최종PNG·증빙·기록·측정마스크를 포함한다. 실제게임 가독성·가림 검증은 별도다.
