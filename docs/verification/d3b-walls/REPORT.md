- **영향**:
  - C1e 이랑 띠와 D3a 물가 띠: a|b 이음마다 80~96px가 투명했다(이랑 밑 흙, 물가 밑 얕은 물이 비쳐 눈에 덜 띄었다).

- **수정**: 마스크를 따로 그려 한 번에 적용한다(`stripJoin.maskX`, `drawRoadRibbons.mask`).
- **증빙**: `seams-browser-baseline-d3a.json`(수정 전 7/7 띠에 구멍) → `seams-browser.json`(0/7).
- **C1e 이음 검사가 이를 놓친 이유**: 불투명 행만 비교해서다. D3b 검사는 원본 이미지의 몸통 행을 기준으로 이음 구간의 불투명도를 센다.
