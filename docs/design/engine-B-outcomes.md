# Engine B 선택별 결과 계약

[JSON 계약](engine-B-outcomes.json)은 현재 실행 가능한 **56개 사건·163개 선택·323개 결과 기대**를 다룬다. 현재 `registryV4Support`/`v4Entry`의 지원 선택, 명령 인자와 선택 조건 AST를 그대로 보존한다. 실행 결과나 UI 통과 인증서가 아니다. 영주 여부는 응답 직전 `weighOffer`로 결정하며, 조건부 청지기 사건도 권리·고액 조건에서 영주 판단이 될 수 있으므로 제외하지 않았다. 기존 편집 층은 변경하지 않았다.

각 선택은 실제 명령과 바인딩, 조건 AST, 즉시 상태 정산과 조건부 후속 결과를 분리한다. `target.path`는 엔진 상태의 논리 경로이고 `binding`/`traceTarget`은 구체화할 대상 표기다. JSONPath 실행기나 sparse history의 필드 경로라고 해석하면 안 된다. `requiredProbe`는 원본 전후 상태·바인딩·조건 증거가 필요함을 표시하며, 관측 완료를 뜻하지 않는다. 자동 판정 가능한 `evidenceMatcher`는 아직 제공하지 않는다.

`withinSeasons: 0`은 즉시 설정/거절/취소 정산이다. `null`은 후속 발생 조건이 필요하고 소스가 계절 상한을 보장하지 않는다는 뜻이다. 별도의 `displayExpectation`은 모든 결과에 유한한 **설계 표시 기한**을 지정한다. 설정·거절·취소·hold 정산은 `answer_committed +0철`, 조건부 결과는 필요한 실제 전이가 일어난 `domain_transition +0철`에 해당 대상·결과·직접 연결을 표시해야 한다. 예를 들어 감사가 실제 생성된 뒤 다음 철까지 표시를 미루지 않는다. 감사 자체가 다음 철에 반드시 발생한다고 약속하지는 않는다. 모든 표시 계약은 `desired_not_observed`이며 실제 UI 이행은 별도 검증한다. **기존 80% 지표의 정확한 own-answer-ID 미래 조인과 성숙 기간은 그대로다.** 즉시 결과와 null 조건부 기간은 이 지표를 통과시키거나 성숙한 답변을 분모에서 제외하지 않는다. 대상·조건·첫 직접 원인 검증은 별도 엄격 감사다.

`expectedResultTemplates`는 실제 history template 이름이다. `expectedResultKeys`는 `consequence`의 `params.key`이고, `expectedBecauseKeys`는 별개의 `because.key`다. `faction.act`에는 `params.key`가 없다. `registry.answered`는 접수 기록이며 자체 because가 없어 전후 효과나 원하는 직접 연결을 대신 증명하지 못한다. `primaryDirectDecisionLink`는 성공 답변의 정확한 history ID를 요구하는 **목표 계약**이다. 현재 엔진이 이 연결을 모두 구현했다고 주장하지 않는다. 명명한 화면 역시 실제 가시성 증거가 아니다.

| 사건·선택 | 반드시 구별할 결과와 알려진 공백 |
| --- | --- |
| 083 a / c | a는 목재 주문, c는 장세 설정이다. 사건 전체 선택을 읽어 만든 장세 trace를 a의 효과로 인정하지 않는다. |
| 061 b/c, 077 a/b/c, 130 a | 전역 예외 규칙의 실제 변경. `changedTargets`의 규칙 누락이 있다. 영지의 예외 매치·직영·standing policy·고액 조건과 본거지 recurring 경로를 구별한다. |
| 038 enforce / defer | 집행의 성공·실패 모두 `estate.possession_enforced`의 succeeded 값으로 구분한다. 실패한 명령 시도와 비용을 낸 성공 응답을 혼동하지 않는다. defer의 claim 약화는 바닥에서 차이가 없을 수 있다. |

| 092 / 211 | 장세 변화와 다른 성장 정책·hold를 구분한다. 늦은 답변의 보관 창 안에 장세 결과가 없다는 사실은 수입 부재를 증명하지 않는다. 211 c는 merchant 관계 hold다. |
| 046 cancel, 209 c | 목재 0은 속성 삭제로 정규화한다. 취소 후 다른 재주문 배송을 취소의 미래 효과로 세지 않는다. |

프로비넌스는 작성 시 소스 revision과 실제 파일 SHA-256을 담는다. 소스가 바뀌면 계약을 다시 검토해야 한다. 조건 AST·명령 인자는 실행 의미 보존용이며, 미래 조건의 자연어를 임의의 실행 술어로 변환하지 않았다. 비registry 답변은 이 계약의 범위 밖이지만 기존 전체 답변 지표에서 제거하지 않는다.

검증: JSON이 없을 때 계약 테스트 7개 실패를 확인한 뒤 작성했다. 현재 집중 테스트는 9개이며 56/163 정확한 집합, 현재 명령/AST 일치, 필수 필드, 취소·거절, 알려진 공백, 잘못된 결과 네임스페이스를 검사한다. 엔진 시간 진행·원격 실행·브라우저 관측은 수행하지 않았다.

표시 기한은 원인 발생 대기시간과 다르다. 다음은 지정 사건의 구체적 표시 요구다.

`requiredFacts`는 각 결과의 실제 대상·명령·전이별 증거를 나열한다. `observableTarget`은 그 결과의 상태 경로, 실제 template/key 네임스페이스, 화면 및 구체적 변화를 보존한다. 표시 기한은 현재 생산 주기의 보장값이 아니라 새로운 설계 요구이므로, 일어나지 않은 자연 사건을 강제로 만들거나 기존 80% 분모를 줄이는 근거가 아니다.
