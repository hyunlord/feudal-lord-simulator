## 확인하지 못한 것

10배속 UI는 찾지 못해 5배속에서 연말 자동정지를 확인했다. 정확한 ‘도시의 요청’ 제목은 1320년 봄까지 보지 못했다. 상속 다툼은 열고 소송을 제기했다. 다른 seed, 게임 내부 원인, 모든 사건·모든 위임 정책, 모든 시설의 실제 생산 효과는 검증하지 않았다. 단일 원인 추정으로 인구 감소를 설명하지 않는다. 중단의 근본 원인도 미확정이다. 화면 전용 평가이므로 게임 유닛테스트·린트·타입체크를 실행하거나 코드 수정으로 문제를 해결하지 않았다.
