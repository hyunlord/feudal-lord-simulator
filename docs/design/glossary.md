# Feudal Lord Simulator 한국어 용어 정본

> 원본: Astra GLOSSARY.md(sha256 9558470c2f4ac872b9c5625d145ceece6181c4ca76a052c0b93ab14f4f39f22e, 문구·고증 감사 2026-10-02), 링크 경로만 저장소에 맞게 고침.

기준: 1300~1450년 잉글랜드 남부 시장도시, 2026-10-02 문구 감사. 이 문서는 앞으로의 문구 작성 기준이며 게임 파일에는 적용하지 않았다. ‘쓰지 말 표기’는 해당 개념을 가리킬 때의 제한이다. 다른 의미까지 전역 치환하면 안 된다. 역사 개념의 세부 관행은 지역·시기·권리 문서에 따라 달라질 수 있다. 근거는 [SOURCES.md](copy-audit-20261002/SOURCES.md)와 현재 콘텐츠 사전이다.

## 문장·금액·날짜·숫자 규칙

1. 청지기·안내는 ‘~합니다/~하십시오’, 선택 버튼은 플레이어 행동 ‘~한다’, 연대기는 ‘~했다’로 통일한다. 인물의 개별 말투는 허용하되 한 문장 안 주체를 분명히 쓴다.
2. 선택 결과는 `{청원 ID, 실제 선택}`으로 정한다. 저장값 `refuse`가 항상 거절은 아니다. 후계 후보·유산 방향처럼 실제 행위를 기록한다. 비용·수입·작업 시간·생산량은 명사를 생략하지 않는다.
3. 내부 돈은 정수 페니(d), 표시 기준은 **£1 = 20s = 240d, 1s = 12d**. 한국어는 ‘파운드·실링·페니’를 정본으로 쓰고 ‘펜스’는 영어 복수형을 설명할 때만 병기한다. £를 현대 십진 파운드로 환산하지 않는다. 마르크를 추가할 때는 별도 회계 단위로 설명하고 13s 4d 관계를 명시하며 모든 시기에 실물 동전으로 단정하지 않는다.
4. 정확한 금액: `£1 13s 3d`. 0인 구성요소는 생략하되 영은 `0d`. 증감은 `+£1`, `−7d`, `±0d`. 금액만 있는 숫자 `240` 금지. `240d` 병기는 허용한다. 기존 moneyShort의 절삭은 요약 화면에 한정하고 납부·계약·개별 장부에는 잔여 d까지 보인다.
5. 날짜는 `1351년 봄`, 생몰년은 `1300~1351년`, 생존자는 `1300년생`, 나이는 `51세`. 추정 도착점은 `올해 여름 말쯤`, `내년 봄 초쯤`. 내부 틱·게임초·분:초를 일반 게임 진행 안내에 쓰지 않는다. 저장 시각 등 실제 시간 메타데이터는 별도 맥락이다.
6. 인원 `12명`, 가구 `3가구`, 집 `4채`, 필지 `8필지`, 면적 격자 `6칸`, 사건 `2건`, 작업 시설 `4종`. 자원은 위 사전의 단위를 쓴다. 단위가 축·열 제목에 있으면 매 셀 반복은 생략 가능하다.
7. 숫자는 세 자리 구분 `1,200`, 비율 `70%`, 범위 `3~5가구`. 변화율과 배율 구별: `작업 시간 25% 단축`, `지대 1.25배`. `작업 ×¾`처럼 대상이 없는 배율을 쓰지 않는다.
8. 받침에 따라 조사 선택 함수를 사용하거나 조사를 피한 제목을 쓴다. ‘창고가/창고로’, ‘곡창이/곡창으로’. 사람 이름·금액·시설명을 고정 조사와 결합하지 않는다.
9. 같은 사건명·상태명은 반복 표시해도 된다. 중복 정의는 한 사전에서 관리하고, 실제로 반복 발생한 사건을 중복 문장이라는 이유로 삭제하지 않는다.
10. 1300년 기본형과 후기 예외는 art-bible의 구체적 규약을 따른다. 전 기간에 걸쳐 물건의 존재 자체를 부정하는 역사 명제로 프로젝트 금지 목록을 확대하지 않는다.
