# seed3 성장 방침 150년: 동결 자료 분석

검산 결과: `5fb1aebfe735592c1424c947e88388d4ffe21742`의 seed 3 / `core:open_field` / `fixed growth`가 1450년 tick 600000까지 완료되었다. 종료 코드 0, summary 실행 시간 988초(외부 runner COMMAND_S 990.5초). 원본 23파일을 해시로 고정했고 원본 SHA256SUMS의 22개 항목이 모두 일치했다. 150개 연간 행과 38개 저장·해독 정확 왕복 기록을 확인했다. 저장 검사는 이 판의 기록된 시점에 한하며 기존 SAVE01을 닫지 않는다.

분석은 Ruby로 기존 JSON만 읽었다. 엔진·브라우저·원격 실행, 코드·렌더 변경, SVG 작성은 하지 않았다. 진행 중인 seed3 stability와 비교하지 않는다. 기존 seed1 growth와 수치를 비교하더라도 다른 seed·단일 표본의 비인과 비교다. 이 보고서는 비교 수치를 추가하지 않았다.

## 시간과 집계 범위

`periodYear` 1300–1449는 집계 기간, `year` 1301–1450은 그 기간을 막 지난 저장 경계다. 표의 금고·물자·인구는 해당 경계의 상태이고 연중 최소·최대가 아니다. 사망은 최종 `persons.past`에 보존된 사망 인물 ID를 기준으로 한다. 가솔 및 과거 이주 뒤 죽은 사람도 이 집합에 포함되며 세력·영지 등 세계 전체 사망자 총계가 아니다.
