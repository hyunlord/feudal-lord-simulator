# Phase 20 — 성장 정체 교정·24필지 검증

- **범위:** 기본 상한 8필지·수용량 12/24/32 유지. 검증만 24필지·최대 1,200,000틱. 경제 수치·지형·저장 규격·아트는 유지했다.
- **커밋:** `61caf80`, `8138e33`, `8db5f70`, `2ddc3f6`, `19359e4`, `7c73709`, `96c3bf1`, `2306ab6`.
- **바뀐 것:** 실제 서비스에 닿는 시설 배치·연결 복구, 운송 거리와 배급 사거리를 반영한 식량 지원, 지도 경계 안의 검증된 목책 대안. 불법 초기 seed는 실행 전에 거부한다.
- **결과:** seed 1은 **1,118,480틱에 24필지 도달**. 1,200,000틱에 **24입주 주택·428명·목책 시대**, 시설 98개로 종료했다. 우물 6·곡창 3·밀밭 16·방앗간 62·시장 1(인력 0/3)이다. 물 24/24, 시장 0/24(범위 밖 17·인력 부족 7), 교회 미설치 24. 총 빵 704개지만 8주택은 빵 0이었다. **목표 규모만 달성했으며 L4·승리·24,000틱 안정·수용량 초과와 회복은 미충족**이다.
- **검증 범위:** 자연 실행 소스는 `96c3bf1`; 최종 `2306ab6`은 검증 스크립트·테스트만 달라 런타임 `src`가 동일하다. 실제 UI 도로 단절·복구에서 L3→L1→L3와 외형 유지를 확인했다. 성문·시장 인력 진단은 통제된 초기 상태 검사다.
- **성능:** Apple M4 Max·Chrome 153·1600×1100·위 도시에서 DPR2 진행 CPU 중앙값/p95는 렌더 **31.0/33.1ms**, 틱 **1.7/2.3ms**. DPR1 렌더는 22.1/23.6ms. 6조건 각각240프레임×3회 중 첫 회 폐기. rAF는 보조이며 이전 도시 대비 개선율이 아니다.
- **테스트:** 최종 `2306ab6` **1,584/1,584(Phase 9 포함)**·typecheck·build·diff 검사 통과. 번들 601.25 kB 권고 경고 유지. 중간 `2ddc3f6`의 1,570/1,571 실패(경계 진단 불일치)는 기록을 보존하고 `96c3bf1`에서 고쳤다.
- **남은 한계·결정:** 과도한 방앗간과 배급·인력 부족이 남는다. seed 2는 물 위 배치, 3–5는 벌목소 숲 인접 조건 위반으로 거부되며 자연 성장 실패로 집계하지 않는다. 합법적 초기 마을 위치 조정은 사용자 결정 대기다. main 병합·배포는 하지 않았다.

첫 후보 `8db5f70`은 같은 예산에서21필지·363명·촌락으로 끝난 실패 결과를 보존했다. 기존 석재 경로는 실제626,760틱에 시대 선포가 성립하여 별도 수정하지 않았다. 전체 시설·서비스·실패 이력·상태 SHA·재현 명령은 [요약 데이터](summary.json), 6조건 측정은 [실행기](run-benchmark.mjs)에 있다. 원시 저장 도시는 커밋하지 않고 자연 실행 명령으로 재생성한다.
