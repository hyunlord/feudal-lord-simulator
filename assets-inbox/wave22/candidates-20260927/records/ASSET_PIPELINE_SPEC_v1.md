# 유기적 땅 에셋 파이프라인 규격 v1

작성 2026-09-25 · 근거: 딥리서치 "유기적 2D 에셋 파이프라인 — 접합부 C 진단·적용 권고 F"(2026-09-24)와 보완 연구 "손그림 등각 2D 자유 형태 지형 에셋 방식"(2026-09-25), Fable 설계 5절, 곡선 통합안, Astra 파일럿·D1·Wave 2 교훈
적용: 이 문서가 `ASSET_PLAN.md` 1절(규격)을 대체한다. Wave 4 이후 모든 지면·경계·구조 에셋과 C1 렌더 설계의 기준.

## 0. 한 문장
**땅은 "그림"이 아니라 "역할이 다른 조각 + 규칙"으로 만든다.** 면은 마스크 + 조용한 반복 무늬, 선은 1축 반복 띠, 점(교차·다리·성문·탑·나루)은 소켓이 정확한 모듈, 흩어진 것은 결정론적 스캐터. 곡률은 코드가, 붓질은 그림이 맡는다.

## 1. 다섯 가지 에셋 역할

| 역할 | 무엇 | 반복 | 출력 | 코드가 하는 일 |
|---|---|---|---|---|
| **면 무늬(fill)** | 잔디·물·숲 바닥·과수원 바닥·목초지 | XY seamless | 256×128 (2×2칸) | 마스크로 자르고 세계좌표에 고정 |
| **띠(strip)** | 흙길·석재길·물가·성벽 면·이랑·베인 풀 | **X만** seamless, Y는 알파 페이드 | 512×64/96/128 (4칸 길이) | 중심선·경계선을 따라 짧은 조각으로 아핀 변환해 붙임(Canvas 2D는 UV 휘기 없음) |
| **데칼(decal)** | 풀덤·갈대·돌·고랑 도장·건초더미·낙엽 | 없음 | 64~128px, 투명 RGBA, 아래 가운데 접지 | 경계선·구역 축·거리장에 따라 결정론적 스캐터, 근거리 동일 변형 거부 |
| **모듈(module)** | 다리 교대·나루·성문·탑·벽 끝·코너·교차로 패치 | 없음 | 소켓·점유·통행 폭이 정확 | 위상 고정점에만 배치, 주변 0.5~1칸 직선 잠금 |
| **오브젝트(object)** | 건물·나무·가축·사람 | 없음 | 기존 규격(SW 고정) | 그대로. 발밑은 접지 AO만, 넓은 구운 그림자 금지 |

## 2. 크기 규칙 (표시 크기 기준)

원본 1칸 = 128×64px. 줌 1.0에서 0.5배, 줌 0.6에서 **0.3배**로 보인다.

| 요소 | 원본 최소 폭 | 줌 0.6에서 |
|---|---:|---:|
| 비의미 질감(흙 얼룩, 풀 덩어리) | 8~12px | 2.4~3.6px |
| 경계 실루엣(둑 요철, 잔디 술) | 12~16px | 3.6~4.8px |
| 의미 소품 핵심부(건초더미, 큰 이랑, 관목, 돌 덩어리) | 18~24px | 5.4~7.2px |
| 읽혀야 하는 선(바퀴 자국, 고랑) | 7~10px | 2~3px |

- **1~4px 풀잎·모래알·사진식 잡음 금지.** 파일럿(1024px 세부 → 8배 축소 붕괴)의 원인.
- 4K라도 원본을 키우지 않는다. 논리 타일이 화면에서 64×32px인 한 128×64 원본을 유지. 월드 자체를 2배로 그리는 별도 모드에서만 256×128 팩.
- 축소는 **승인 원본에서 목표 크기로 한 번만.**

## 3. 역할별 제작 계약 (모든 Astra 의뢰서 맨 위)
```
ROLE: <fill|strip|decal|module|object> / <어휘 이름>
SOURCE_SIZE: W×H
WORLD_SPAN: N tiles (strip·fill) / footprint (module·object)
REPEAT: XY | X only | none
ALPHA: none | Y-edge fade N px | transparent RGBA
MIN_MOTIF: N px
LIGHT: soft upper-left, no cast shadow (strip·fill·decal) / contact AO only (object)
PALETTE: project reference (첨부 게임 그림)
VARIANT_INDEX: k of N
NO_FOCAL_POINT: true
NO_MICRO_NOISE: true
SOCKET: (module만) 접점 좌표·통행 폭·점유 마스크
```

건초더미는 현대식 사각 베일 금지, 느슨한 haycock.

### 4.5 건물 주변 (첫 조사 F01~F13)
- 건물은 회전하지 않는다. **앞마당(apron)**: footprint에서 가장 긴 도로 접점 쪽으로 0.25~0.5칸 연결 polygon. **마당(yard)**: footprint 0.5칸 확장 → 도로 envelope·물·벽·이웃 순으로 잘라냄. 울타리·텃밭·통·장작은 마당 안 스캐터.
- 건물 그림에 **구워 넣은 텃밭·울타리·넓은 기단은 분리**해 `props_optional`로. Wave 2 변형(텃밭형·우리형 등)은 당분간 그대로 쓰되, C1 마당 시스템이 들어오면 소품을 떼어 스캐터로 옮긴다.
- 상점 전면(차양)은 가장 긴 유효 frontage가 SW 반공간일 때만 선택.
- 접지: 건물 본체 직하부 접지 AO만 object pass에서. 지면 캐시에는 넣지 않는다.

## 5. 생성·후처리 (Astra)
- 역할별로 생성 방법이 다르다: fill은 XY tile 생성 적합, strip은 **X만 반복**을 자연어로 지정하고 seam은 후처리, 전이 조각과 모듈은 **흑백 위상 마스크를 먼저 만들고 그 안만 편집**, 데칼은 진짜 투명 RGBA.
- 프롬프트 순서: 역할 → 세계·화풍 → 좌표·카메라(원근 없음) → 반복 계약 → 형태 크기 → 출력 → 금지(중앙 집중 얼룩, 테두리, 비네팅, 텍스트, 사진 질감, 미세 잡음, 흰 halo, 긴 그림자). 금지는 "대신 있어야 할 것"을 먼저 긍정으로.
- 후처리: 정확한 크기 크롭 → (XY) X/Y 50% offset seam 수정 · (strip) **X만** offset → 3×3 반복 검사 → 색·광원 통일 → 한 번 축소 → 줌 0.6/1.0/1.35 실제 장면 QA.
- 알파: 띠 옆 8~16px 페이드, 투명 바로 안쪽 RGB를 2~4px 확장(halo 방지).
- **반전(mirror)은 그림자 없는 풀덤·돌·얼룩에만.** 나무·건초더미·탑은 실제 변형.
- 노멀 맵 없음(현 런타임 무의미, 손그림 하이라이트를 높이로 오인).

## 6. 변형 수와 배치 규칙
| 유형 | 최소 | 권장 | 규칙 |
|---|---:|---:|---|
| 조용한 XY fill | 3 | 4 | 시작 offset까지 섞기 |
| 도로·물가·벽 strip | 3 | 4~6 | 인접 span 동일 변형 금지 |
| 가장자리 decal | 6 | 8~12 | 회전 제한, 크기 ±10~15% |
| 큰 나무 | 6 | 8~12 | 수관 실루엣 근거리 중복 금지 |
| 건초더미·덤불 | 4 | 6~8 | 한 화면 동일 실루엣 연속 금지 |
| 코너·끝 모듈 | 상태당 2 | 2~3 | 위상 우선 |
| 성문·탑 | 1 | 2~3 | 드물어 과다 제작 불필요 |
**결정론적 근거리 거부**(반경 3~4칸 안에서 방금 쓴 변형 제외)를 쓰면 4~6장이 단순 무작위 10장보다 낫다. 변형 이미지 수와 배치 조합 수를 따로 본다.

## 7. 검수 매트릭스 (에셋·렌더 공통)
결정론(같은 상태 → 같은 SHA) · 순서 무관 · strip 4~8회 반복 seam 0 · **주기성**(seam과 별개: 특이 얼룩 하나로 바둑판) · portal(성문·다리 앵커 허용구간) · 도로 중심선 0.25칸 · 성벽 차단·운반 동치 · 가림(캐시 지면이 건물 위로 0픽셀) · frontage(문·차양 앞 apron 존재 또는 명시적 "없음") · 밭 상태 변경 전후 외곽선 동일 · 반복(같은 변형 4칸 이내 없음) · **줌 0.6에서 종류 자체가 구분** · 줌 0.6/1.0/1.35 · DPR 1/2 · 성능(중앙값 악화 없음, p95 잠정 +10%) · 캐시 무효화.

승인 질문 하나: **"줌 0.6에서 이 에셋이 무엇인지 한눈에 읽히면서, 같은 것이 반복된다는 사실은 눈에 띄지 않는가?"**

## 8. 제작 순서 (family 대표 → 검증 → 변형 채우기)
Wave마다 각 family 대표 1~2장을 먼저 만들고 **12×12 합성 검사 장면**에서 줌 0.6을 통과시킨 뒤 변형을 채운다. 잘못 정의된 family를 12장 양산한 뒤 다시 만드는 비용이 가장 크다.
