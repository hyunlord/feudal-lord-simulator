# D1b 독립 시각 검수

검수일: 2026-09-24 · 판정 대상: 후보(candidate) PNG와 오프라인 확인 그림 · 게임 설치 및 런타임 검증 없음.

## 방법

최종 에셋 2장과 확인 그림 2장을 직접 열어 확인했다. 첨부 ZIP에서 추출한 참조 7장도 직접 열어 비교했다. 최종 PNG를 별도로 읽어 크기, 알파 영역, 투명 여백, 석재 스트립 외곽 열 접합을 계산했다. 기술 기록의 `alphaBounds`는 `[x, y, width, height]`이다. 아래 시각 판정은 정지 확인 그림의 지정 크기에 한정한다.

## 결과

| 기준 | 판정 | 관찰 근거 |
|---|---|---|
| 석재길 3장 접합 | 통과 | 표시된 두 접합 지점에서 빈 틈이나 세로 이음선이 눈에 띄지 않는다. 최종 좌우 외곽 열의 RGBA 최대 차이는 0이다. 이 수치와 별개로 실제 3장 배열도 확인했다. |
| 줌 0.6에서 돌길 식별 | 통과 | 돌 사이의 불규칙한 분할이 길 표면의 주요 조직으로 남는다. 흙길의 길게 이어진 두 바퀴 자국 및 상대적으로 평탄한 표면과 구별된다. 개별 작은 돌의 모양까지 유지되는 것은 아니다. |
| 흙길과 폭·톤 연결 | 통과 | 같은 512×64 캔버스에서 차지하는 길 폭과 상하 가장자리 처리가 가깝다. 따뜻한 회갈색 석재와 갈색 흙이 자연색 범위 안에서 연결된다. 직접 접합은 재질이 바뀌는 선이 보이지만 폭이나 색이 갑자기 튀지 않는다. 곡선 예시는 교차 합성을 적용했으므로 별도 전환 에셋의 품질을 증명하는 자료는 아니다. |
| C의 낮고 넓은 형태 | 통과 | A·B의 키 큰 고사리 덩어리와 달리 낮은 풀덤 약 4개가 가로로 흩어져 있고 낙엽 바탕이 연결한다. 최종 불투명 내용 높이 24px로 A·B보다 낮다. |
| A·C·B·C·A·B·C 리듬 | 통과, 지정 배열 한정 | C가 큰 덩어리 사이를 낮추고 A·B가 연속되는 구간이 들어가 일정한 높은 덩어리 교대 리듬을 끊는다. A/B만 교대한 경우보다 반복이 덜 두드러진다. 동일 C가 세 번 재사용되므로 동일 형태 자체가 없어지는 것은 아니며, 더 긴 경계에서 반복이 감춰진다는 판정은 하지 않는다. |
| C의 줌 1.0 및 0.6 가독성 | 통과 | 줌 1.0에서는 작은 풀덤과 낮은 낙엽 띠가 보인다. 줌 0.6에서는 잎의 세부가 줄어들지만 낮은 풀덤 윤곽은 남고 A/B의 높은 덩어리와 구별된다. 풀덤 개별 잎을 읽을 수 있다는 의미는 아니다. |
| C의 색·붓질 | 통과 | 올리브 녹색, 황갈색 잎, 갈색 바탕이 A·B와 이어진다. C는 저상 형태여서 낙엽 비중이 높지만 별개의 아트 스타일로 튀지 않는다. |
| 알파 규격 | 통과 | 석재길 상하 8px에 알파가 있는 픽셀 0개. C 사방 8px에 알파가 있는 픽셀 0개. 석재길 좌우 여백 예외를 적용했다. |
| 지정 표시 크기에서 직접 생성 | 미달, 제작 방식 한계 | 생성 도구가 석재길 2172×724, C 1774×887 원본을 반환했다. 최종본은 크롭·축소·알파 정리를 거쳤다. C는 최종 112×24 내용 영역으로 비균일 크기 조정을 했다. 최종 픽셀 크기는 정확하나 지정 크기에서 직접 생성했다는 조건은 충족하지 않는다. |

## 별도 계산한 최종 파일 값

| 파일 | 크기 | 알파 영역 `[left,top,right,bottom]` (끝 좌표 제외) | 규격 여백 위반 |
|---|---|---|---|
| `road/stone_strip-v1.png` | 512×64 | `[0,8,512,55]` | 0 |
| `boundary/forest_fringe_c-v1.png` | 128×96 | `[8,64,120,88]` | 0 |

석재길 좌우 외곽 열 최대 RGBA 차이: **0**. C의 접지 피벗 `(64,88)`은 알파 영역 아래 경계에 놓인다.

## 결론

최종 두 에셋은 요청된 확인 그림에서 후보 검토에 필요한 형태·색·접합·알파 조건을 충족한다. 즉시 고쳐야 할 시각 결함은 발견하지 못했다. 제작 도구의 원본 크기 한계와 후처리 내역을 공개한 `candidate` 납품이 적절하다. 게임 곡선 변형, 배치 밀도, 실제 화면 스케일에서의 장기 반복 및 런타임 품질은 이번 검수에 포함되지 않는다.
