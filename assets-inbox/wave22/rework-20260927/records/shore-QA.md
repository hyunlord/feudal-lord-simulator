# 모래 해안 A v2 검수

기존 A의 반복되는 같은 크기 물결을 비대칭으로 수정했다. 긴 완만한 구간, 짧은 만입, 좁은 모래 돌출이 서로 다른 간격으로 나타난다. 통과한 B는 변경하지 않았다.

- 512×96, X만 반복, 위아래 8px 투명 여백. X 양끝 RGBA 차이 0.
- 가로 3회 반복을 0.5배에서 확인했다. 수직 접합선은 보이지 않으며, 원래 A의 동일 주기 파형 인상은 줄었다. 한 장을 반복하므로 전체 윤곽의 장거리 주기 자체가 없어지는 것은 아니다.
- 올리브 육지·따뜻한 모래·청회색 물과 위쪽 육지/아래쪽 물 방향을 유지했다.
- 후처리: 생성 알파 기준 Y 크롭, 목표 높이로 한 번 축소, Y8px 여백 및 안쪽8px 페이드, X24px 접합 혼합. 모든 실제 프롬프트·참조는 shore-sources.json.
- 게임 코드·원본 B 미변경, 후보만 제작.
