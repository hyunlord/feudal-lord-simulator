## 생성과 실패 보존

이미지는 모두 내장 imagegen으로 생성/편집했다. `prompts/`에 정확한 프롬프트, `raw/`에 모든 성공·실패 원본, `records/`에 등록·측정 기록을 보존했다. 아래 실패는 삭제하지 않았다.

- body-v1/v2: 문 실제 높이가 목표보다 낮음. 최종 body-v3에서 벽/문을 다시 그림.
- snow-v1: 눈 아래 주황 지붕 픽셀이 남음. 눈만 분리한 v2는 수동 영역 약 82.1%로 높아 v3에서 약 65.1%로 밀도를 낮춤.
- boarded-v1/v2: 판자가 크거나 위치가 벌어짐. 완성 집을 참고해 재생성하고 추출. 최종 추출 층 전체만 등방 등록.
- vacant-v1: 덧문이 낮고 흔적이 과함. 내장 도구로 재생성한 v2 사용.
- plague-full-v1: 도구가 전체 집을 돌려줌. 원본을 보존하고 추가 판자만 내장 도구로 추출.

등록·QA 스크립트는 Pillow로 완성 그림 전체에 균일한 크기 조정/이동 및 확인판 합성만 한다. 그림 부품을 재조립하지 않는다. 최종 제품 코드는 건드리지 않았다.
