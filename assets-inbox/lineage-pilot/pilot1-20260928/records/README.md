# 혈통 초상 파일럿

게임 미설치 후보입니다. 얼굴 없는 아기 자리 그림은 제작하지 않았습니다.

## 구성

가문별 34 PNG: 창시 부부 장년·노년 4장, 자녀 4명의 아기·어린이·청년·장년 16장, 손자 4명의 아기·어린이·청년 12장, 외부 배우자 2명의 청년 2장입니다. 두 가문 68장에 평민 공통 풀 12장을 더해 총 80 PNG입니다. 의뢰서의 대략 62장 대신 명시된 단계와 부모 참조를 충족하는 수량을 사용했습니다.

20명 섞기 검사는 원래 핵심 인물 20명만 사용합니다. 창시자 4명은 요청 목록에 청년 단계가 없어 장년으로 대체했습니다. 외부 배우자 4명과 공통 풀 12명은 검사에서 제외됩니다. 손자는 자녀01 남성+외부 여성 배우자, 자녀03 여성+외부 남성 배우자 두 부부에서 각각 2명씩입니다.

## 자료

- assets/: 256×256 개별 초상 80장.
- assets.csv: PNG당 1행. identity·lineage·세대·부모 identity·나이·복식·항목별 상속·관찰 QA·생성 프롬프트/참조·SHA.
- proofs/: 공식 확인 그림 4장. records/: 96px 검사판·정답·판독 실험 원자료·기술 QA.
- raw/: 생성 원본과 교정 전후. references/: 제공 참조 원본. 모델/seed 미제공 값은 null.
- IMAGE_LINKS.md, index.html: 개별 파일 링크와 갤러리.

## 평가 해석

형질은 미술 제작 규칙이며 생물학적 유전 모델 검증이 아닙니다. 두 부모 참조를 실제로 입력했는지, 그림이 지정 형질을 따랐는지, 가족이 묶이는지는 서로 다른 검사 항목입니다.

익명 그룹 검수 에이전트는 제작에 참여하지 않았고 정답표를 받지 않았습니다. 전체 초상과 얼굴 중심 잘라보기는 서로 다른 검수자가 분류했습니다. 맞힘률은 두 집단 라벨 교환을 허용한 최대 일치수/20입니다. 같은 계열 모델·작은 표본의 시각 판단이므로 실제 사람 사용성 검사로 해석하지 않습니다. 최종 결과는 REPORT.md에 기록합니다. 실패한 형질·개인 구별과 연령 판독 한계를 보존했습니다.
