## 0. 세 조사가 일치한 것 (설계 원칙)
1. **흐름이 끊긴 원인은 콘텐츠 부족이 아니라 "대가·압력·목표 위계"의 부재**다(D-01, G-015, P-02). 봇이 실패 없이 24필지까지 가는 것은 "잘못 둘 방법이 없다"는 증거.
2. **위기는 새 수업이 아니라 이미 배운 루프의 시험**이며, 예고 → 도래 → 회복의 톱니 곡선이어야 한다(G-004, P-20, D-24).
3. **실패는 게임 오버가 아니라 손실과 회복의 사다리**(세 조사 모두 B 권고).
4. **역사 연도와 플레이어 준비도를 분리**: 1315가 달력에 왔다고 대기근이 터지면 5배속 플레이어는 10분 만에 맞는다(G-012). 시대 진입 = 연도 + 상태 조건(B2에 이미 자리 있음).
5. **다음 몇 주는 새 시스템이 아니라 기존 시스템이 서로 청구서를 보내게 만드는 데** 쓴다(D-15). 로드맵에서 사건·압력이 에일·직물보다 앞이다(D-12, G-009).
6. **결정의 단위가 커져야 진행이다**: 20분 "필지를 어디에?" → 50분 "어느 규모를 유지할 수 있나?" → 70분 "누가 통행세 권리를 쥐나?"(G-114). 이게 세부→구역→방향 층위의 실제 의미.
7. **계절 끝 결산이 5분 층과 2시간 층을 잇는 접착제**(D-04, P-75).

## 8. 종반·재플레이
- 번영 승리만으로는 종반이 없다(D-10). **번영이 쌓이면 더 큰 청구서**(국왕 과세·자치 요구)가 오는 구조로 5장 종반.
- 재플레이 축: archetype 지도 4+1, 장별 시나리오, 대기근 강도·흑사병 시점 변주, 가문 유산 3종.
- 연대기: 장 끝마다 한 쪽 자동 작성, 플레이어 결정 3개 인용.
