## 무엇을 멈추고 무엇을 먼저 연결할 것인가

1. **확정44장 및 이미 쌓인 후보 재제작을 멈춘다.** 기존 ID·원본·피벗을 보존한다. 새 제작은 현재 후보로 해결할 수 없는 요구가 확인될 때 별도 판단한다.
2. **영주관 기존 Wave12 A/B 연결을 먼저 검토한다.** R07 실제 화면의 무질감 도형은 저장 manor-house-34-41-0와 기본도형 투영에 정합한다. catalog의 manor_house 연결 공백과 설치계획 pending_existing_plan을 근거로 한 우선순위다. 런타임 분기 직접계측이나 현행 새 촬영은 아니다. [기존 화면·소스 감사](records/storage-background-art-audit-r07/REPORT.md).
3. **설치 전 발판·피벗·점유 상태 계약을 정한다.** 엔진2×2와 원화3×3 사양을 같다고 가정하지 않는다. A/B native pivot은(249,319)/(251,319)이며 상태별 그림 선택·가문 점유 표시를 함께 정한다. 기존 priority_stage=1을 유지한다. 여기서 엔진 발판 변경을 승인하지 않는다.
4. **직업·가구 변형과 세계 상태의 연결을 확인한다.** 직업마당 그림 존재를 실제 직업 선택 연결로 세지 않는다. AS03의 수정 확인은 별도로 남는다. 장부 정리는 렌더의 stable variant·점유 상태·세계 접점 검사보다 앞서 완료됐다고 제품을 완성하지 않는다.

## 배율 계약의 남은 판단

AS01은 기존 R01/R05의 바이블 성인17.6px·저줌0.8과 코드16px·0.65 불일치다. 이번 회차 새 픽셀 측정으로 재현한 것이 아니다. 제안은 원화를 다시 그리지 않고 바이블의 현행 코드 설명을16/0.65로 맞추고, 목표 문 높이1.15–1.40H와 실제 문 개구부 측정을 구분하는 것이다. 코드 배율 변경 승인이나 설치 지시가 아니다.

승계식16×max(zoom,0.65)에서는 줌0.6이10.4px, 줌1.0이16px다. 이는 식의 계산이며 렌더 실측값이 아니다. 설치 담당은 선택한 배율 계약으로 사람과 문을 같은 줌에서 확인해야 한다.

현재 전략의 담당은 렌더·미술 기준/설치 세션이다. 감독관은 우선순위와 충돌을 보고하며 엔진·렌더·원화를 직접 고치지 않는다.
