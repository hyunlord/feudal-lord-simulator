# 공유 소품 검수

- built-in imagegen을 소품별 1회씩 총 5회 호출했다. CLI/API 대체 경로는 쓰지 않았다.
- barn.png와 farmstead.png를 육안 확인하여 목재·삼베 색과 조명을 지시했다. 참조 파일을 생성 도구에 직접 제출하지 않았으며 records의 referenceUse에 구분했다.
- 각각 독립 원본과 정확한 최종 프롬프트를 native/props에 보존했다. 모델 버전·seed는 제공되지 않아 null이다.
- 원본 5장의 투명 알파 경계를 잘라 비율을 유지한 Lanczos3 축소 후 요청 캔버스에 배치했다. 알파를 별도 마스킹하거나 색상 키로 제거하지 않았다.
- 요청 크기 64×64, 32×64, 32×32, 64×48, 64×64 및 RGBA 알파 최솟값 0·최댓값 255를 확인했다.
- native/props/actual-size-review.png를 실제 픽셀 크기로 육안 확인했다. 보/바퀴, 세로 밧줄/갈고리, 낱개, 작은 3개 더미, 큰 8개 더미가 구별된다. 자루 개수는 원본에서 1/3/8개를 확인했다.
- 굴뚝·인물·글자·건물·바닥이 없는 독립 소품이다. 모든 피벗은 캔버스 하단 중앙이며 barn 접지와의 정합을 주장하지 않는다.
- 상태는 candidate이며 게임 미설치다. 실제 도르래 조립점, 건물별 설치·가림·런타임 배치는 후속 검증이다.
