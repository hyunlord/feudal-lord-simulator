# Wave42 v2 묘목 4개 재작업 검수

기존 v1과 승인된 나머지 파일은 수정하지 않았다. 동일 ID의 신규 후보 4개만 별도 v2 경로에 기록했다.

여름 2개는 각각 내장 imagegen 독립 신규 생성이고 겨울 2개는 대응 여름 원본을 참조한 계절 편집이다. v1 묘목 및 기존 oak 스타일 참조를 직접 확인한 뒤 단독 막대형을 여러 묘목·키큰풀·고사리 군집으로 교체했다. 원시는 모두 별도 보존했다. 추가 회화 내용을 코드로 그리지 않았다.

- 캔버스: 4개 모두 128×192 RGBA, pivot (64,172).
- 1–3년: visible 80×30, left24/top142. 낮은 여러 묘목과 풀·고사리의 무릎 높이 군집.
- 4–8년: visible 80×56, left24/top116. 여러 어린나무 수관·줄기와 하부 풀·고사리. 표시 높이는 지면 깊이를 포함한다.
- 여름·겨울 한 쌍은 표시 폭·높이·하단·pivot을 동일하게 고정했다. 계절 편집의 미세 골격 차이는 존재하므로 픽셀동일 오버레이라고 주장하지 않는다.
- 4개 alpha 0–255, 바깥 경계 alpha0. Sharp 1회 최종 축소, flip/rotate 사용 없음. 입력 SHA·원시 경로·출력 SHA·정확 프롬프트는 regrowth-generations.json, 구조 실측은 regrowth-metrics.json. 도구가 모델·seed를 공개하지 않아 null.

## 직접 시각 판정

regrowth-grass-native-060.png / light / dark 3판을 열어 검수했다. 각 판 위 행은 실제 PNG 크기, 아래 행은 0.6 크기(최종 정수픽셀 반올림)이며 열은 1–3여름, 1–3겨울, 4–8여름, 4–8겨울 순서다. 잔디는 기존 프로젝트 terrain/grass.png 참조 합성이다.

원래 단독1–3묘목 폭15px,4–8묘목 폭30px에서 양쪽 모두80px로 넓어졌다. 0.6에서도 약48px 폭의 군집이 유지되어 하나의 막대로 사라지지 않는다. 여름은 겹친 잎·고사리 덩어리가, 겨울은 짙은 갈색 가지와 마른 풀의 덩어리가 배경 잔디와 구분된다. 겨울4–8에는 여러 수직줄기와 가지가 선명하게 남는다. 낮은1–3군집과 높은4–8군집의 단계 차이가 보인다. 오프라인 시각 PASS.

이 결과는 오프라인 합성 검수이며 게임 미설치 상태다. 실제 게임 줌·차폐·계절 전환·선택 판정은 검증하지 않았다.
