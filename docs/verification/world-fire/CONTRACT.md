# 화재 세계 연출 계약

core-world-fire는 기존 event-scene 계약 세 항목이다. 설치 원본은 world-events/candidates-20261003/assets/new의 bucket-brigade-summer, bucket-brigade-winter, fire-flicker-all이다. 원본 바이트를 그대로 복사하며 좌우 반전하지 않는다.

실제 events.burning의 ignitedTick ≤ 현재 tick < outTick인 집에만 불길을 놓는다. eventId에는 인스턴스 접미사가 붙을 수 있으므로 정의 id와 문자열 일치를 강요하지 않는다. 가구·사건 상태는 읽기만 한다. doused는 진화 완료가 아니라 엔진이 물을 공급하는 중이라는 사실이다.

물동이 무리는 가까운 우물 쪽 빈 잔디·길 공간에서만 나타난다. 건물 발판, 공사장, 생산 구역, 마당·직업·마을 소품, 벽 교차를 제외하고 그림 전체 발밑을 예약한다. 안전한 자리가 없거나 그림 로딩이 실패하면 기존 물통 둘 표시를 유지한다. 일반 화면에서 실제 대열에 들어간 무리만 같은 프레임 영수증을 전달해 기존 표시를 대체한다. 최대 다섯 무리이며 실제 인구 수를 늘리지 않는다.

| 항목 | 규격 |
|---|---|
| 물동이 무리 | 여름·겨울 각 320×240, 피벗(160,200), 배율0.352 |
| 사람 크기 | 원본50±5px, 세계17.6±1.76px. 정확히 모든 인물이17.6px라는 뜻은 아니다 |
| 발밑 검사 | 전체 그림 너비와 피벗 위12px부터 캔버스 아래까지 보수적으로 검사 |
| 불길 | 256×96, 가로64×96셀4개, 셀 피벗(32,88), 배율0.35,100ms/셀 |
| 위치·시간 | 집 앞 발판 모서리, 기존 세계 대열 깊이 순서, 렌더 nowMs로 움직임 |
| 계절 | 게임 달력 겨울은 겨울 무리, 다른 계절은 여름 무리 |

기존 지붕 불·연기는 유지한다. 새 작은 불길은 집 앞 발판에 붙고 지붕 크기에 맞춰 늘리지 않는다. 추가 장기 캐시는 없다. UI 문구·엔진·세이브 형식 변경이 없다.

무리의 기준점은 불타는 집 발판의 앞쪽 꼭짓점보다 뒤에 놓지 않는다. 빈 땅이어도 지붕 뒤로 숨는 최초 실제 장면을 고친 규칙이다. 앞쪽이며 우물 쪽인 안전한 자리가 없으면 무리를 생략한다. 다른 건물과 소품의 정상적인 깊이 가림은 유지한다.
