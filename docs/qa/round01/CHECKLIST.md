# QA ROUND 01 — 누적 검토 항목

**1회차 누적 검토 기준.** 항목별 관측 결과는 REGRESSION.md에 있다. 처음 등록한 기준이며, 비율·성능 임계값을 소급해 통과 수를 만들지 않는다.

아래 ‘실패’는 다음 검토에서도 같은 방식으로 판정하기 위한 관찰 기준이다. 원인 코드 수정 또는 엔진 규칙 변경을 지시하는 기준이 아니다.
