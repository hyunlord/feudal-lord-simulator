## 확인 플레이와 비용

가드레일 선행 조건이 실패했으므로 `npm run play` 새 게임 확인은 시작하지 않았다. 선포·도로 연결 횟수·완공·점유 충돌의 신규 플레이 측정값은 없다.

`WALL_CARRY_COST_FACTOR=2.0`: 벽 안쪽 한 칸 운반은 도로 두 칸의 이동 비용이다. 대각선 이동은 맨해튼 2칸으로 센다. T3의 마지막 완공 tick 94,608은 자재 생산·작업까지 포함한 전체 결과이며, 가중치 1.0 대비 완공 시간 차이로 해석하지 않는다. 경로 캐시 10만 번 미시 측정은 정규 키 전 26.55ms→후 22.21ms였으며 전체 프레임 성능은 측정하지 않았다.
