# A‴ 목책 공사 흐름 검증 보고

**관문: 실패 — 목책 0/12구간 완공 (실제 60분).** AI의 화면 플레이는 사람의 재미·인내·숙련도를 대표하지 않는다. 최종 제품 `89ce592`의 새 게임 화면을 실제 시계로 판정했다. 선포 **없음**, 첫 목책 자재 도착 **없음**, 전체 완공 **없음(완공 시각 없음)**이다. 자동 성장 필수 가드레일은 **3/5 통과(필수조건 미달)**로 화면 관문과 별도 판정한다. 배포와 `main` 병합은 하지 않았다.

## 제품 변경과 플레이 결과

도달 가능한 목책 구간은 성문 순서 안에서 병렬로 배송·시공하도록 바꿨다. 막힌 첫 구간 때문에 나머지 11구간이 대기하던 상태를 없애고, 목표판에서 완공·진행·경로 없음·대기를 구분했다. 고립된 첫 구간 fixture에서는 나머지 11구간이 각각 요구 작업 120틱에 도달했다. 선포 전에는 실제 자재 배송 경로로 고립 구간을 예고하고, 선포 후 선택한 현장에는 연결할 빈 도로 칸을 표시한다. 준비 상태 제품 UI 검사에서 한 칸 길 설치 후 경고가 해제됐다.

초반 안내는 첫 밀밭·방앗간→제재소→둘째 밀밭·곡창·연결 창고 순서로 정리했다. 착공 중 시설의 중복 안내를 없앴고, 건물 미리보기에서 인접 도로와 **창고에서 공사 자재를 운반할 경로**를 구별했다. 교회 자동 도로 계획은 가상 배치에 교회 객체 자체를 포함하도록 고쳐, seed 3의 L4 정체(13/24)를 24/24로 회복했다. A″의 도시 배치 변화가 기존 도로 계획 결함을 드러낸 것으로 확인했으며, 단일 커밋만의 원인으로 단정하지 않는다. 마지막 제품 보정: 초기 목재 120으로 제재소를 세우기 전 필수 시설 비용 125를 요구하던 안내 교착을 해소했다(`89ce592`).

## 자동 성장 가드레일과 제품 검증

이전 시뮬레이션 커밋 `c093d2f`의 seed 1~5는 24필지·최대 1,200,000틱에서 모두 L4 24/24, 승리, 24,000틱 안정 및 전체 서비스를 달성했다. 그러나 지정된 `7db9df85` 기준선의 밀 0 방앗간 비율 한계를 seed 1(2/9)과 5(3/9)가 넘어 **기존 가드레일은 3/5 통과**였다. 두 최종 상태의 SHA는 앞선 A″와 같아 당시 엔진 변경이 새로 만든 현상은 아니지만, 기준선을 바꾸거나 실패를 통과로 처리하지 않았다. 시뮬레이션 재실행 원본 `9b5b51c`의 결과는 **3/5 통과(필수조건 미달)**이다. seed 1은 2/9(22.2%), seed 5는 3/9(33.3%) 방앗간의 밀 재고가 0으로, 기준선 0%에서 허용 악화 +20%p를 넘었다. 두 실패 상태의 SHA는 A″ `689bda7`과 동일하다. `89ce592`는 `9b5b51c` 뒤 온보딩 UI·테스트 네 파일만 바꾸어 엔진 결과에는 영향을 주지 않았지만, seed JPEG를 `89ce592`의 정확한 화면이라고 부르지 않는다. 유휴 노동 5~25% 목표는 C3 후보로 남긴다.

최종 제품 `89ce592`에서 전체 테스트 2,241/2,241, Phase 9(목책 선포 후 1,238틱 완공), typecheck, build, diff check를 통과했다. 코드 리뷰 CLEAR/APPROVE, 차단 지적 0건. 실제 제품 UI 준비 상태에서 연결 방앗간의 배송 경로 ✓, 고립 방앗간의 ×, 브라우저 예외 0건을 확인했다. 성벽 선택→길 설치 시험은 합성 시작 상태이며 자연 플레이 증거와 구별한다.

## 후속 후보와 증거

목책 제안 불가의 실제 상태 원인과 수리 위치를 조사한다. 격리 후보 `ccda4c6`는 물가 굴곡의 합법적 둘레 fallback으로 focused 33개·build만 통과했으며 이번 플레이 배치에서 미검증이고 제품에는 미통합이다. 경제 구조·석벽·3D·저장 형식은 이번 범위에서 변경하지 않았다. 기록된 작업 시간은 **약 5시간 43분(첫 제품 커밋 10:35 UTC~보고서 검증 16:18 UTC)**이다. 화면 플레이, 중단 시도, 자동 성장, UI 검사의 원자료는 각 `replay*/`, `seeds/`, `ui-qa/`와 `food-preview-qa/`에 보존했다. 증거 ZIP은 상대 경로와 SHA-256 목록을 포함한다.
