# Astra 의뢰: 초상 풀 본 제작 1차 — 인물(identity) 32명 × 노화 단계 = 약 88장

작성 2026-09-26 · 판정: 방식 전환 파일럿 **통과**(36명이 서로 다른 사람, 체형·방향·나이 다양, 노화 사슬 4명 모두 같은 사람으로 읽힘). 이 방식으로 본 제작.
첨부 `astra-portrait-pool-reference-files.zip`: 파일럿 36명·노화 사슬 시트(통과 기준), 파일럿 CSV(프롬프트 양식), 계급 표현이 약했던 예 5장, 딥리서치 전문

## 0. 풀 구조 — "초상"이 아니라 "인물" 단위
게임의 인물은 수십 년을 살고 늙는다. 그래서 풀의 단위는 **인물(identity)**이고, 성인 인물마다 **청년·장년·노년 3단계**를 파일럿 노화 사슬 방식(같은 골격·코·눈·귀·흉터 유지, 옷·머리쓰개는 나이와 형편에 맞게 바뀌어도 됨)으로 만든다. 아이 인물은 **아이 1장 + 청년 1장**(자라서 어른이 됨). 전체 목표 약 100 성인 인물 + 24 아이 인물 ≈ 350장, 4차에 나눔. 이번 1차 = 성인 28 × 3 + 아이 4 × 2 = **92장**(수량이 넘치면 성인 26으로 줄여도 됨).

## 1. 파일럿에서 고칠 것 (전부 적용)
1. **계급이 옷으로 읽혀야 한다.** 파일럿의 젠트리(P19~P24)·일부 상인이 평민 옷(평직 모직·흰 베일)이라 계급이 안 보였다. 1300년 잉글랜드 기준:
   - **젠트리·관리**: 고운 모직의 **진홍(scarlet)·짙은 청·녹**, 모피 안감·깃(다람쥐 miniver·여우), 허리 장식띠, 브로치, 인장 반지. 남 = **coif + 모자** 또는 **chaperon(후드 두건)**, 여 = **barbette + fillet**(턱끈 + 머리띠, 1300년 귀부인 유행), 망(crespine).
   - **상인**: 좋은 모직(청·자주 계열, 채도는 젠트리보다 낮게), 모피 깃, 지갑·허리띠 장식, 남 = 펠트 모자·후드, 여 = 베일 + 윔플 또는 barbette.
   - **장인**: 가죽 앞치마·소매 걷음·손때, 직업 소지품(망치·실패·자) 살짝.
   - **노동·빈민**: 수선·바랜 옷, 거친 삼베, 맨머리 또는 두건.
   - **성직자**: 사제(tonsure, 수수한 성직복 — 현대 로만 칼라 금지), 수도사(검은 베네딕토 habit), 탁발승(회갈 프란치스코 habit·허리 끈), 수녀(흑+흰).
2. **여성 머리쓰개 다양화**: 파일럿은 흰 베일이 반복됐다. 흰 베일 / 베일+윔플 / barbette+fillet / coif / 색 머리수건(청·황토) / 후드 / 밀짚모자 / 과부 베일(회청·암갈) / 풀어 내린 미혼 머리를 고루.
3. **표정 다양화**: 대부분 굳은 무표정이었다. 무표정 50%, **살짝 웃음 20%, 피곤·근심 20%, 날카로움·의심 10%**. 과장 금지.
4. **남성 머리·수염 다양화**: 1300년엔 **귀 아래 기장·단발형**이 흔했다(현대 짧은 커트 금지). 수염 없음·짧은·갈라진 수염·콧수염.

## 3. 확인 그림 (4)
1. **이번 32 인물 × 단계 전부** 격자(256px·96px). 계급이 **옷만 보고** 맞혀지는지 스스로 판정(6계급 × 맞힘 수)
2. **파일럿 36명 + 이번 청년 단계 32명 = 68명**을 한 격자에 — 이번 것이 파일럿과 서로 겹치지 않는지, "가장 닮은 세 쌍"
3. 노화 사슬 전부(행 = 인물, 열 = 청·장·노)
4. 인물 카드 크기(96px) 8명 + 청원 카드 크기 4명
