# 합성 규칙과 후보 제한

게임에는 설치하지 않았습니다. 검수 판정은 QA_REPORT.md를 먼저 확인하세요.

1. adult/child 얼굴·머리·수염·머리쓰개 등급을 맞춥니다. 아이 머리폭은 성인 기준107px의88%에 가까운94px입니다.
2. 머리쓰개가 있으면 해당하는9종의 tucked 앞·뒤를 선택합니다. 챙모자 앞머리는256캔버스에서 y=-6px 추가 이동합니다.
3. 앞·뒤 머리를 모두 hairclip 알파로 곱합니다. 흰색은 허용영역입니다. 마스크는 덮개의 물리적 내부도 포함하고 불투명한 덮개가 최종적으로 그 위를 가립니다.
4. 합성 순서는 뒷머리→의복→얼굴→나이→앞머리→수염→머리쓰개입니다.
5. 어린이의 짧은 목에는 child-collar-fit.json으로 의복 중앙 깃을 올립니다. x≤45와x≥210의 어깨 주변 픽셀은 그대로 유지합니다. 처리된 시험용 레이어는 derived-composition-layers에도 포함합니다.
6. 후드(collar=hood)와 모피 깃(collar=fur)은 금지합니다. 무작위 어린이에는 수염·노화를 선택하지 않습니다. 36칸의 어린이5·6열은 요청된 기하학 스트레스 시험입니다.
7. 기본 얼굴은 같은 중간 피부톤입니다. 무작위48명은5피부톤을 의복·지위·도덕과 무관하게 배정합니다. 얼굴과 노화패치의 skinmask에 같은 목표색을 적용합니다.

## 재현

macOS arm64용 raster 실행파일과 Swift 원문을 함께 제공합니다. 압축해제한 폴더를 인수로 주어 확인 그림을 재생성할 수 있습니다:

```sh
node pipeline/proofs-v2.mjs "압축해제한_폴더의_절대경로"
```

provenance/generation-records는 선택된44개 생성 원본의 전체 프롬프트와 생성 당시 경로를 보존합니다. 실제 원본은 provenance/raw, 참고 그림은 provenance/references에 포함합니다. pipeline/build-v2.mjs는 이번 제작의 감사용 원문이며 이전 작업 경로를 참조하므로 이 ZIP만으로 원본 생성부터 다시 실행하는 도구는 아닙니다.

## 좌표 증거

CSV의6기준점은 결합을 위한 선언 좌표입니다. face-registration.json 및 qa/faces-measured.json에 눈·턱·정수리·목끝·아이폭 실측을 분리했습니다. 귀 중심과 이마선은 전20장 정밀 실측 완료로 표시하지 않았습니다.
