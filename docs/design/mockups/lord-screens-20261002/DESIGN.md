# 영주 화면 디자인 탐색 v1

## 1. 방향
인물 → 관계와 권리 → 도시의 결과. 사용자가 제공한 두 문서의 8화면 범위를 그대로 사용. 게임 미설치, 정적 검토용.
## 2. 색
현 프로젝트 palette.ts: ink #2A2118, timber #463625 / #5E4A33, parchment #DCD3C1, vellum #EFE8D8, vermilion #A83232, gold #C9A227, forest #405633, water #4D758A. 그림 내부색은 원본 유지.
## 3. 글자
한국어 명조: Noto Serif CJK KR, AppleMyungjo, serif. 제목 29–38px, 일반 본문 16–18px. 작은 판의 밀집 장부·계약은 12–14px, 카드 보조는 11–13px. 가계도·지도 범례는 최소 10–11px. 이는 정적 시안의 밀도 선택이며 제품 적용 시 글자 크기 재검토가 필요하다.
## 4. 배치
상단 76/64px, 좌측 88/72px 인물 중심 내비게이션. 24/16px 간격. 1920×1080, 1280×800은 별도 브라우저 렌더.
## 5. 부품
Wave25 초상 틀, Wave35 협상 종이와 조항, Wave38 버튼, Wave14 문장, Pool3 초상 재사용. 얇은 잉크 구분선과 참나무색 테두리. 둥근 현대 카드와 그라디언트 금지.
## 6. 작은 판
여백·풍경 높이·초상 크기를 줄이고 포트폴리오를 4열→2열로 전환. 상세 본문은 유지.
## 7. 검증
16장 치수/누락/넘침 검사, 두 해상도 직접 시각 검수, 원본 SHA 보존, ZIP CRC. 무력은 엔진 없음 표시.
