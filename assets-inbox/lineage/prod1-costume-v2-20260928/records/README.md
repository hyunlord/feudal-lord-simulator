# 혈통 본 제작 1차 복식 교정 후보

- 신규 후보 41장: L4 상인 가문 38장 + L5_102 청년·장년·노년 3장.
- L4는 기존 얼굴·머리·연령·표정·흉상 구도를 유지하는 개별 이미지 편집이다. 청·자주 고운 모직, 모피 깃과 후드/혼인 상태별 머리쓰개를 적용했다.
- 남성 후드는 기존 머리를 보존하기 위해 뒤로 내렸다. 허리띠·지갑은 원래 흉상 구도 밖이라 넣기 위해 화면을 넓히지 않았다.
- 기혼 성인 여성은 베일·윔플, 미혼 여성·소녀는 기존 드러난 머리를 유지한다. 아기는 포대기·아기 모자, 어린이는 기존 6~9세 단계다.
- L5_102는 올리브 모직과 황토빛 머리수건, 길어진 하안면·턱, 주근깨 제거로 구분했다. 다른 L5 인물은 바꾸지 않았다.
- 모든 결과는 256×256 RGBA. 생성 편집이므로 옷 밖 픽셀이 원본과 동일하다는 주장은 하지 않는다. 전후 시각 검수 결과와 한계는 QA.md에 기록한다.
