## 제작·참조 기록

생성 입력은 제공 ZIP의 프로젝트 그림 `grass.png`, `forest_floor.png`, `packed_earth_road.png`, `wheat_farm_ripe-v4.png`만 사용했다. 숲 A/B 수정에는 각각 프로젝트의 첫 후보를 크기·알파 정리한 이미지도 입력했다. 외부 작품·상용 게임 그림은 사용하지 않았다.

`image_gen` 7회: 흙길·고랑·잔디 각 1후보, 숲 A/B 각 2후보. 숲은 수정한 두 번째 후보를 선택했다. 도구가 실제 모델명과 시드를 노출하지 않아 `not exposed` / `not provided`로 기록했다. 생성 시각은 로컬 원본 파일의 수정 시각(UTC ISO 8601)을 기록했다.

**제작 방식 미달:** 프롬프트에는 정확한 작은 크기와 큰 단순 형태를 요구했으나, 도구는 1448–2172px 폭 원본을 반환했다. 최종 이미지는 이를 잘라 축소한 결과다. ‘처음부터 표시 크기에 맞춰 생성’했다거나 고해상도 축소 문제를 완전히 해결했다고 주장하지 않는다.

Canvas 2D로 수행한 수작업 처리:

1. 알파 >2 영역을 찾아 잘라 최종 크기에 맞춤. 데칼은 비율 유지·하단 정렬, 스트립은 512×48px 내부 영역에 맞춤.
2. 여백을 명시적으로 완전 투명 처리. 스트립 상하·데칼 좌우 안쪽에 8px 커버리지 전이 적용. 색을 번지게 하는 블러 필터는 사용하지 않음.
3. 스트립의 양 끝 16px에서 알파 가중 평균 색 프로필을 구해 양쪽 밴드를 일치시킴. 각 밴드 안쪽 24px에 선형 전이를 적용함. 원본이 그대로 완전 반복이었던 것은 아님.
4. 최종 납품 PNG와 기존 프로젝트 그림을 사용해 확인 그림 합성. 세부 좌표와 연산은 `records/processing-and-preview.html`에 보존.

## 확인 그림의 범위

줌 1.0은 에셋 0.5배, 줌 0.6은 0.3배다. 128×64px 타일 기준은 각각 64×32px, 38.4×19.2px다. 메인 장면 720×530px와 그 0.6배인 432×318px를 같은 PNG에 넣었다. 이미지 뷰어가 전체 확인 그림을 다시 축소하면 실제 배율보다 작아 보일 수 있으므로 100% 표시로 확인한다.

S자 도로는 작은 구간을 접선 방향으로 붙인 근사 합성이다. 최종 게임의 곡선 UV·가림·클릭·성능 검증은 아니다. 밀밭은 기존 그림 1장을 비교용 2×2셀에 배치했다. 실제 게임 캡처는 `corrected-screenshot-04-final-observation.png`를 사용했고, 촬영 줌 메타데이터는 확인되지 않았다. 캡처는 비교용으로만 사용했으며 생성 참조 입력은 아니다.

## 기록 파일

- `records/generation-history.json`: 미선택 후보까지 7회 실제 프롬프트와 원본 위치.
- `records/provenance-and-csv-validation.json`: 원본·참조·입력 ZIP·캡처 SHA-256, CSV 전문 왕복 검증 결과.
- `records/technical-qa.json`: 최종 크기, 여백, 접합 수치. bounds는 `[x,y,width,height]`.
- `records/independent-visual-review.md`: 별도 검수자가 실제 파일을 열어 확인한 결과.
- `records/final-validation.json`: 최종 PNG·CSV 파일을 다시 읽은 검증.
- `SHA256SUMS.txt`: 묶음 내부 파일 무결성 목록.

원본 생성 이미지와 참조 그림은 기록된 로컬 경로에 보존했다. 요청한 PNG 수를 유지하기 위해 ZIP에 원본·참조를 추가 복제하지 않았다. 합성 HTML은 수행 기록이며 참조·원본 HTTP 경로를 제공하는 실행 환경 없이 단독 실행되는 도구는 아니다.

## 결론

스트립 접합·최종 크기·알파 여백은 통과했다. **숲 A/B 반복 은폐, 잔디 경계의 줌 0.6 형태 가독성, 지정 크기 직접 생성은 미달**이다. 고랑 저배율 입체감과 색조 연결에는 조건이 남는다. 모든 파일은 `candidate`이며 본 제작·게임 설치 승인으로 취급하지 않는다.
