## 공통 규칙
- 단계는 게임의 4단계와 같다: **말뚝(0~25%) → 기초(25~55%) → 골조·벽(55~85%) → 지붕틀(85~100%)**. 완성 그림은 기존 것.
- 각 단계 그림은 **해당 계열 대표 완성 건물과 같은 캔버스·피벗**(첨부 기준 건물). 크기가 다른 건물은 코드가 발판 크기로 배율을 조정한다.
- 공사장에 사람은 넣지 않는다(워커가 온다). 자재 더미는 Wave 6 것을 코드가 얹는다 — 단계 그림에 더미를 그리지 말 것.
- 역사: 14세기 잉글랜드 목골조 건물은 **틀을 땅에서 짜 세우고(raising)**, 석조는 **목재 비계 + 모르타르 + 발판 경사로**, 대형 석조는 **답차 기중기(treadwheel crane)**. 아치는 **목재 홍예틀(centering)** 위에 쌓는다.

## G. 확인 그림 (4)

2. 교회 공사장 재구성: 기초 → 기중기·비계·홍예틀·모르타르·석회 더미 + 석공·목수 워커 배치
3. 석문 공사 3단계를 석벽 v2 띠 사이에(첨부 석문 v3 규격)
4. 기존 공통 4단계 vs 새 목조 키트 비교(오두막)
