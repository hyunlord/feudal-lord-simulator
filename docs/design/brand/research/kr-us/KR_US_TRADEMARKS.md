## 검색 방법과 범위

- [KIPRIS 공식 국내 상표검색](https://www.kipris.or.kr/khome/search/searchResult.do?tab=trademark): 상세검색의 상표명칭(TN)에 표기를 입력하고 완전일치 체크, 상품분류(TC)를 09/28/41로 각각 설정. 권리구분·유형·행정상태는 전체. 공식 UI가 띄어쓰기를 `*`로 정규화한 TNM 검색식을 화면에 표시했다. 검색식은 수정하지 않고 위 표에 그대로 기록했다.
- [USPTO 공식 Trademark Search](https://tmsearch.uspto.gov/): Wordmark 드롭다운을 `Field tag and Search builder`로 바꾸고 `CM:"표기" AND IC:분류` 검색. CM은 word/pseudo mark/translation을 함께 검색하는 필드다. Live/Dead를 제한하지 않았다. CM 구절 검색은 전체 표장 문자 일치(FM)와 다르므로 표기에 해당 구절이 있는 표장까지 포함하는 1차 선별이다.
- USPTO 기본 Wordmark 입력은 따옴표가 있어도 exact phrase 조회가 아니다. 따라서 최초 탐색 1,688건을 요청 표기의 동일상표 건수로 사용하지 않았다. [공식 시작 안내](https://www.uspto.gov/sites/default/files/documents/TM-FederalTrademarkSearching-GettingStarted-handout.pdf), [공식 연방상표 검색 설명](https://www.uspto.gov/trademarks/search/federal-trademark-searching), [공식 필드 태그 설명](https://www.uspto.gov/sites/default/files/documents/TM-Transitioning-from-TESS-handout.pdf).
- 9류는 내려받는/기록된 게임 소프트웨어, 28류는 보드게임·완구·일부 게임용 장치, 41류는 오락·온라인 게임 제공을 검토하는 출발점이다. 실제 지정상품/서비스와 관련 시장이 중요하며 분류 번호만으로 유사 여부를 결론내리지 않는다.
- 이번 요청의 문자 표기를 조회했다. 유형을 전체로 두었으므로 해당 문자색인과 연결된 도형복합 표장도 검색 범위에 들어갈 수 있지만, 신규 봉랍 인장 도형의 이미지 유사성·도형코드 검색을 완료했다는 뜻은 아니다. 도형 자체 선행상표 검토는 **확인 못 함**.

KIPRIS 확장 조건은 완전일치를 해제하고 영문 두 단어 조합, 한국어 부분어 조합, 차터/킨 음역, 띄어쓰기 제거를 탐색했다. 제한된 확장이며 모든 철자·발음·번역·상표군을 망라하지 않았다.

USPTO의 다음 확장 단계인 `(charter OR kin)` + game/games 상품조건, 한국어 공백 변형 조회는 선행 403 때문에 실행 완료하지 못했다. 새 브라우저 세션으로 홈부터 재시도했으나 Wordmark UI 로딩이 30초 제한을 넘어 실패했다. 이는 검색 0건이 아니라 **확인 못 함**이다. 최초 9개 CM+IC 조건은 각각 No results found 화면을 저장한 이후에 403이 발생했다.

## 접근·증거 메모

- 텍스트 web fetch에서 USPTO SPA가 빈 내용으로 보여 `omo:ultimate-browsing` 지침의 브라우저 상호작용 경로로 전환했다. 설치되어 있던 Playwright + Chrome의 새 공개 세션으로 본 조회를 완료했다. 로그인·유료 조회·출원·업로드는 하지 않았다.
- 결과 화면은 공개 UI를 직접 렌더한 스크린샷이다. `.txt`는 동일 페이지 body 텍스트이며, `.json`에 각 조회 UTC 시각과 URL, 검색어, 분류를 기록했다. URL은 세션 검색식을 보존하지 않을 수 있으므로 표의 검색식과 캡처를 함께 사용한다.
- 0건은 해당 문자/구절·분류·시점의 관찰 결과다. 미공개·지연 반영·음역·도형·타 분류의 관련 상품·미등록 상표 사용까지 부정하지 않는다. 이 자료는 예비 조사 기록이며 법률 의견이나 상표 사용 허가가 아니다.
