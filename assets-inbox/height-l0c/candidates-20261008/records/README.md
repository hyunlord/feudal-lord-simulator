# RB-HEIGHT-L0C 정적 후보 5장

이 폴더만 작성했다. 제품 설치, 코드 변경, 커밋, DGX 및 실게임 실행은 하지 않았다. `house_l0_c-*-candidate.png` 5장이 인계 대상이며 모두 153×153 RGBA다. 자세한 최종 수치와 SHA는 HANDOFF.json, 원본 위치·해시는 REFERENCES.json, 생성 도구의 원래 저장 경로는 GENERATED_PATHS.json에 있다. 정확한 생성 지시는 각 `*-prompt.txt`, 생성 원본은 `*-raw.png`로 남겼다.

## 몸체와 문

선택한 body-06은 원본 c의 긴 가파른 박공 초가, 따뜻한 회벽, 단순 기둥, 앞 작은 창 1개를 유지한다. 증축·현관·옆창은 없다. 성인용 문 높이를 만들려고 벽을 높이고 지붕 전체를 올렸다. 원본의 능선 절대 y를 유지하지 않아도 된다는 부모의 수정 지침을 적용했다. 따라서 원본과 실루엣이 픽셀 동일하지 않다. alpha>32 최상단은 y44→y3으로 약 41px 높아졌다.

등록된 닫힌 문잎은 동일 x63에서 y77→122 약45px, y98에서 x54→73 약19px다. 수동 치수 오차는 ±2px로 기록한다. 기존 배율 0.49957049486461247에서 높이21.48–23.48, 폭8.49–10.49 세계px 범위다. 닫힌 문잎은 개구부의 대용 측정일 뿐 실제 유효 개구부를 독립 측정한 것이 아니며, 성인과의 실게임 중첩 검증도 아니다.

발판은 1×1, 기존 바닥 피벗 (77.35406698564593,139.57894736842104)을 인계한다. 원본의 왼쪽/앞/오른쪽 바닥 점과 후보 점의 수동 잔차는 2.0/1.0/2.24px이며 좌표 오차 자체도 약±2px다. 정확히 일치한다고 주장하지 않는다.

## 등록과 네 상태층

몸체·fresh-01·weathered-02·boarded-01은 원시1254²를 ffmpeg Lanczos로149²에 한 번 균일 축소하고 153² 투명 캔버스에 (+3,-3) 전체 이동했다. snow-02는 생성 크기가 몸체 지붕보다 컸으므로 먼저 전체 등록을 진단한 뒤134² 균일 축소, (+8,-2) 전체 이동으로 맞췄다. 부위별 변형·그림 조립·도장·마스크 클리핑·Python 이미지 편집을 사용하지 않았다. Python은 픽셀/알파 측정과 JSON·해시 기록에만 썼다.

ffmpeg 등록 필터는 일반층 `format=rgba,scale=149:149:flags=lanczos,pad=153:159:3:3:color=black@0,crop=153:153:0:6`, 눈 `format=rgba,scale=134:134:flags=lanczos,pad=153:157:8:2:color=black@0,crop=153:153:0:4`다. crop은 투명 캔버스 전체 이동의 출력 창이며 개별 그림 부위를 잘라 숨기는 처리와 다르다. 이동으로 화면 밖에 나가는 원래 행의 알파를 별도 감사했다. 본체 PNG의 최상단 경계에는 최대 4/255의 희미한 알파가 남아 있다. 본체의 나머지 세 경계와 다른 네 PNG의 모든 경계는 알파 0이다. 이 경계 접촉과 별개로, 전체 등록 과정에서 화면 밖으로 나간 행의 비영 알파 픽셀은 다섯 이미지 모두 0이었다. 앞선 인계 설명의 “모든 경계 알파 0”은 잘못된 요약이므로 정정한다. PNG는 변경하지 않았다.

fresh는 세 군데 회벽 손질, weathered는 바닥 부근의 옅은 때, boarded는 실제 앞문·앞창에만 독립 판자를 올렸다. 판자 끝이 고정 지점인 문틀/주변 벽에 조금 겹친다. 눈은 지붕에만 불규칙하게 놓이며 수동 지붕 다각형에서 알파 가중70.78%, alpha>32 이진78.10%다. 지붕 경계 수동 오차 약1–2px 때문에 정밀한 물리 면적 비율은 아니다. 눈의 alpha>32 한 픽셀이 몸체 경계 밖이며 1px 팽창 안에는 모두 들어간다. 다른 세 층은 몸체 밖 alpha>32 픽셀0이다.

## 확인판과 실패 보존

`original-candidate-comparison.png`는 원본/후보 좌우 비교다. `proof-{fresh,weathered,boarded,snow}-backgrounds.png`는 왼쪽부터 어두운·밝은·초록·체커 배경 합성이다. 네 판 모두 직접 확인했다. 제품 PNG는 그대로이며 확인판만 최근접 확대했다. 네 층의 원시·등록본·합성판도 남겼다. 실제 게임 조명, 줌, 가림, DPR, 로더 선택은 아직 검증하지 않았다.

몸체01/02는 문이 짧음,03은 문 높이·폭 미달,04는 지나친 키와 발판 이동,05는 폭 개선 후 높이 미달로 탈락했다. weathered-01은 집 재료를 복사해 덮었고 snow-01은 초가까지 복사하고 위치가 달라 탈락했다. 실패물을 삭제하거나 일부만 잘라 결과에 재활용하지 않았다. BODY_MEASUREMENTS_PRELIMINARY.json은 등록 전 기록이며 최종 판정에는 HANDOFF.json을 사용한다.

SHA256SUMS는 자신을 제외한 폴더 안 모든 파일을 포함한다. 정적 후보 완성은 설치 승인이나 실행 검증을 뜻하지 않는다.
