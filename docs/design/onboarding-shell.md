# 온보딩 셸 — 튜토리얼 시퀀서·목표 카드·단계 해금·층위·조언자·경고 (UX-1)

근거: UX-1 지시서, 첨부 조사 `research_onboarding_ui.md` E절(첫 세션 대본·HUD·메뉴 재분류·카드 규격·경고), UX-0 콜드 스타트 감사(원인 A~H).
코드: `src/ui/tutorial/`(모델·기록·컨트롤러·셸), `src/ui/BuildMenu.tsx`(층위·분류·잠김), `src/ui/AlertStackView.tsx`, `src/ui/InspectorView.tsx`, `src/App.tsx`(배선), `src/styles/tutorial.css`.
게임 규칙·경제·저장 형식은 바꾸지 않는다. 튜토리얼 기록은 저장 밖(플랫폼 설정)에 둔다.

## OS-1 대본 13단계
| # | id | 카드 | 완료 판정 | 열리는 것 |
|---|---|---|---|---|
| 1 | `greet` | 영지를 둘러보세요 · [시작하기](자동 재생) | 확인 | 생활·길 |
| 2 | `well` | 집 가까이에 우물 설치 0/1 | 새 우물(공사장 포함) ≥ 1 | |
| 3 | `well_done` | 결과를 먼저 보고 놓기 · 되돌리기 주의 | 확인 | |
| 4 | `road` | 길 한 칸 내기 0/1 | 오프닝 길 밖 길 칸 ≥ 1 | |
| 5 | `house` | 새 길가에 집 짓기 0/1 | 새 집 ≥ 1 | |
| 6 | `arable` | 식량 기반: 경작지 0/8 | 경작지 칸 ≥ 8 | 생업(경작지 카드) |
| 7 | `arable_limits` | 칠할 수 없는 땅 알아보기 | 확인 | |
| 8 | `food_chain` | 헛간과 방앗간 짓기 0/2 | 헛간·방앗간 각 ≥ 1 | 헛간·방앗간 |
| 9 | `granary` | 새 곡창 짓기 0/1 | 새 곡창 ≥ 1 | 저장·유통(곡창) |
| 10 | `zone_unlock` | 땅의 용도 정하기 · 배너 | 확인(구역 층위로 전환) | 구역 층위(필지만) |
| 11 | `burgage` | 첫 필지 구역 칠하기 0/1 | 필지 구역 칸 > 0 | |
| 12 | `burgage_done` | 사람들이 채우는 땅 | 확인 | |
| 13 | `wrap_up` | 다음: 시장과 예배당 | 확인 → 일반 모드 | 공공·신앙, 생업·저장의 나머지 |

- **설명하는 개념:** 직접 건설·도로 연결·예측/거부·생산→저장·구역, 다섯 가지뿐이다.
- **길과 집의 순서:** 조사 대본은 "집 → 길"이다. FIX-1이 `needs_road`를 배치 규칙으로 만들어 길 없는 집을 지을 수 없으므로, 길 한 칸을 먼저 내고 그 길가에 집을 짓는다(결정 UX1-4).
- **현재 단계:** 아직 참이 아닌 첫 단계다. 판정은 게임 상태 술어(오프닝 마을 대비 새 건물·공사장, 구역 칸 수)이고, 확인 단계는 기록의 `acks`로 닫는다.
- **나중 술어가 앞 확인을 닫는다:** 나중 단계의 술어가 참이면 그 앞의 확인 단계도 끝난 것으로 본다. 그래서 기록을 잃은 저장(다른 브라우저)도 뒤로 가지 않는다.

## OS-2 기록과 켜기
- **기록 위치:** 플랫폼 설정 `feudal-lord-simulator:tutorial:v1`에 둔다(`TutorialRecord`: `enabled`, `acks`, 이미 깜빡인 대상, 완료 기록). 저장 파일에는 넣지 않는다.
- **새 게임:** 환영 창의 "튜토리얼 켬/끔"(기본은 저장된 선택, 없으면 켬)으로 목표형 새 게임에서 시작한다. 샌드박스는 튜토리얼이 없다.
- **기록이 없을 때:** 새 게임(틱 0, 새 건물·공사장·구역 없음)에서만 켠다. 주입한 도시·옛 저장은 모두 열린 채다.
- **끄기·켜기:** 설정의 스위치로 언제든 끄고 켠다.
  - 끄면 모든 분류·도구·구역 층위가 열린다. 방향 층위는 늘 잠김이다(청원 이후, P2).
  - 켜면 같은 카드로 돌아온다.
- **저장·재개:** 단계가 상태 술어에서 나오므로 저장 → 불러오기 뒤에도 같은 카드다(테스트: 13단계 전부).

## OS-3 해금
- **튜토리얼 중(`tutorialAccess`):** OS-1 표대로 연다. 잠긴 분류·카드·층위는 숨기지 않고 🔒 배지와 이유를 단다. 누르면 이유 한 줄이 뜬다.
- **도구 의도도 잠김을 따른다:** 메뉴·Q/E·패드 X 모두 같다(App `toolSelect` 처리).
- **튜토리얼 뒤:** 방어만 목책 단계(선포 가능 또는 선포 후)까지 잠김이다.
- **시대 잠김:** 시대가 아직 열지 않은 건물(채석장·석공소·시장·교회·성채)도 숨기지 않고 "시장도시 이후"처럼 표시한다(UX-0 "해금 안내").
- **해금 배너:** 분류가 열리면 "새로 열림: 생업"을 3초 띄운다. 구역 층위가 열리면 "이제 땅의 용도를 정할 수 있습니다"다.

## OS-4 목표 카드
- **카드 구성:** 제목 18px, 진행 수와 막대, 이유 최대 2줄, 단추 1개, `위치 보기`, `?` 도움말이다.
- **개수:** 화면에는 최대 2장이다(방금 끝난 카드 1 + 현재 1). 서랍에 완료 기록과 도시 발전 조건(옛 목표판, 시대 선포)을 둔다.
- **완료 표시:** 1.5초 "완료 ✓"를 보인 뒤 접는다. 게임이 이미 만족한 단계는 "이미 갖춰짐 ✓"로 보인다(UX-0 G).
- **단추(CTA)는 두 번 누른다:**
  - 첫 누름: 정확한 도구를 연다. 메뉴를 그 분류로 열고, 도구를 두 번 깜빡이고(이미 깜빡인 대상은 다시 안 함), 지도에 제안 자리의 halo를 그린다.
  - 둘째 누름: 제안 자리에 놓는다.
  - 모두 입력 의도로 한다(`toolSelect`, `inspect` → `select`, 구역 `strokeBegin/Move/End`, `lookAt`, `speed`). 사람의 클릭과 같은 경로다.
- **첫 단추는 재생도 켠다:** 일시정지 중이면 1배속으로 바꾼다(UX-0 A).
- **제안 자리:** 오프닝 마을 중심에서 가까운 순으로 고른다. 배치 판정(`canPlaceBuildingWithZones`) 통과, 길 옆, 다른 건물과 한 칸 띄움이 조건이다.
  - 헛간은 경작지 옆, 방앗간은 헛간 6칸 안이다.
  - 구역은 길에 닿는 4×3 빈 땅(풀·숲)을 붓 한 줄로 칠하고, 게임의 칠하기 판정으로 칸 수를 확인한다.
- **일반 모드(튜토리얼 끔·끝남):** 도시 발전 목표 카드(첫 미충족 조건)와, 튜토리얼 뒤 "다음: 시장과 예배당"이다.

## OS-5 층위·메뉴
- **층위 전환:** `직접 / 구역 / 방향`이다. 구역은 분류에서 빠져 층위가 됐다. 구역 층위에서는 분류 줄을 숨기고 구역 카드(필지·경작지·목초지·과수원·지우개)를 보인다.
- **분류:** `생활(집·우물) / 길 / 생업(헛간·방앗간·벌목소·제재소·채석장·석공소, 경작지 붓) / 저장·유통(창고·곡창·시장) / 공공·신앙(예배당·교회) / 방어(성채·목책)`이다.
- **카드:** 이름·한 줄 설명·비용·잠김 이유를 보인다.
- **도구가 없을 때:** 하단 줄은 "도구를 고르세요"다(UX-0 D).
- **되돌리기:** 하단 왼쪽이다. 가장 최근 공사장을 취소한다. 우물 뒤 단계에서 깜빡인다.

## OS-6 HUD
- **상단 줄:** 오른쪽 한 덩어리에 날짜·속도·설정을 둔다. 자원 막대는 왼쪽으로 붙인다. 폭 1100px 이하에서는 막대 아래 오른쪽이다.
- **오른쪽:** 목표 카드 → 서랍 → 경고 스택(최대 3줄, ▲ 즉시 / ◆ 주의, 건물 수 집계, `[보기]`)이다.
- **`[보기]`:** 카메라를 그 건물로 옮기고 왼쪽 inspector에 원인과 조치를 보인다.
- **왼쪽:** 청지기(96px 초상 자리, 한 줄, 단추 1)와 inspector다.
- **아래 오른쪽:** 보기 계층(지도·오버레이)이다. 속도는 상단으로 옮겼다.
- **일시정지 표시:** 지도를 옅게 덮고 "일시정지 중 · Space"를 띄운다(UX-0 A).
- **시작 카메라:** 새 게임은 오두막 4채·우물·길 고리가 보이는 작업 구역이다(1280×800에서 확대 2).
- **카드가 안내를 가릴 때:** 튜토리얼 지도 안내가 오른쪽 카드 영역 밑에 들어가면 카드가 반투명해진다(UX-0 H).
- **상태 문구:** 재생 1초(20틱) 전에는 띄우지 않는다(틱 0의 공급 미계산).
