# Astra Wave5b 후보 제출

게임에 설치하지 않은 별도 후보 묶음이다. Wave4e 파일은 변경하지 않았다.

## A 아이·노인 몸 템플릿

- 시트3장, 확인 그림2장, 생성 기록 CSV3행, 방향 일관성표.
- 초기 생성·발 수정·프레임0 복제 후 발만 재생성한 시도의 입력/결과를 `A/attempts/`에 추가했다.
- 재사용 지팡이4방향은 `reused/`에 별도 보존했다.
- **보행 교대는 미달/미확인이다.** 아이4방향과 노인 남 앞2방향은 같은 앞다리 실루엣이 남는다. 노인 남 뒤2방향과 노인 여는 긴 옷 아래 좌우 다리 연결을 확정하지 못했다. 승인된 애니메이션으로 사용하면 안 된다.

## B 초상화 레이어 파일럿

- 256×256 레이어11장 + cloth1 색 마스크1장, 확인 그림4장, CSV12행.
- 눈선 y112·어깨 기준 y208, 동일 캔버스 좌표. 마스터 레이어를 위치 변경 없이 겹친다.
- 합성 순서: 배경 → 뒷머리 → 의복 → 얼굴 → 나이 → 앞머리 → 선택 수염 → 머리쓰개.
- 원본 재현에서는 수염을 제외한다. 노인 비교는 나이 overlay와 회색 앞·뒷머리, 상인 비교는 챙 모자와 gown으로 교체한다.
- 확인 그림마다256px·96px를 함께 표시했다. 색 마스크는 의복 주색만 파랑·황록으로 바꾸며 피부·후드·린넨·끈을 보호한다.
- 얼굴·후드 등 원본에 보이는 부분은 P4/P1 픽셀을 분리하고, 가려진 피부·머리·의복 부분은 생성하여 보완했다. 전체 원본을 단순히 여러 파일로 중복 저장한 방식이 아니다. 정확한 추출·정렬·마스크 처리는 제작 기록에 있다.
- P4의 하단 케이프 천을 논리적인 tunic 주색 영역으로 나눈 파일럿이므로 원복식의 재단 구조를 증명하는 자료는 아니다. 목선·머리의 일부 표현은 원본과 다르다.

## 검수와 기록

`records/`에는 모든 생성 프롬프트·시도·선택 이유, 정규화, 마스크·접지 수치, PNG 해시, 독립 시각 검수표를 포함했다. `A/assets.csv`는3행, `B/assets.csv`는12행이며 기존20열 양식을 따른다. 모델과 시드가 표시되지 않은 항목은 `not exposed`로 적었다.

에셋·확인 그림·재사용 소품·실패 증빙은 서로 구분했다. 모두 `candidate`이며 게임 입력·정렬·DPR·캐시·성능·애니메이션 재생의 런타임 검증은 수행하지 않았다.
