## 확인 그림

`checks/`의 네 그림을 100% 표시 크기에서 확인하십시오. 사계절 장면은 같은 배치·카메라·기준점을 사용하는 정적 합성입니다. 첨부 화면의 밭·길·수면·목책 구도를 참고한 검수 장면이며 게임 실행 캡처가 아닙니다.

- 같은 장면의 봄·여름·가을·겨울, 줌 1.0 및 0.6
- 자연물 12종의 원본·계절 변형 및 기준점
- 과수 9종의 봄·여름 원본·겨울
- Wave7 지붕 눈·서리와 이번 겨울 식생·지면을 함께 놓은 마을

기존 작은 자연물은 종류별 원래 렌더 배율을 사용합니다. 256×256 과수 8종은 원본 폭 43px로 표시되고 줌 0.6에서는 약 25.8px입니다. 초기 113×80 과수는 표시 폭 40px, 피벗 `(56.5, 74.4)`를 사용합니다. 따라서 모든 에셋에 일률적으로 0.3배를 적용하지 않습니다. 근거와 피벗 좌표는 `records/*runtime-anchors.json`에 있습니다.

## 파일 사용 계약

- 원본 계절 교체 에셋은 원본 캔버스·기준점을 유지합니다. 겨울 낙엽수는 잎이 사라지므로 알파 전체가 원본과 동일하지 않습니다. 가지 끝이 원래 수관 범위를 따르는지 별도로 검수합니다.
- 숲 가장자리 3종 원본은 128×96 데칼입니다. 가을·겨울도 같은 데칼이며 X 반복 스트립으로 바꾸지 않습니다.
- fill은 XY 반복, 휴경 띠는 X만 반복합니다. 각 역할의 알파·반복 검증은 `records/asset-validation.json`을 참조하십시오.
- 효과 시트는 가로 4프레임입니다. 낙엽 프레임은 64×96, 눈 프레임은 128×128입니다.

일반 풀밭 원본은 첨부 ZIP에 없어 기존 프로젝트의 `grass.png`를 사용했습니다. 이는 현재 프로젝트 `krill/public/assets/terrain/grass.png`와 SHA256이 같은 이전 Wave4 참조 원본입니다. 확인 장면의 비계절 주택·길·수면·목책도 이 프로젝트의 기존 그림만 사용하며 경로를 기록합니다.

`assets.csv`는 기존 20열 양식에 실제 사용 프롬프트 전문, 도구·표시 모델 정보, 참조 파일명, 후보·선택 이유, 크기·알파·접합 후처리를 기록합니다. `QA.md`에는 자체 검수와 제한을, `SHA256SUMS`에는 제출 파일 해시를 담습니다.
