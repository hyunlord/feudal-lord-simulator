The observer module imports no engine code. It synchronously invokes the producer thunk inside a protected call, checks that every value is scalar, passes a fresh record to the external callback, and retains neither thunk nor engine/candidate objects. Both serialization and callback exceptions increment a failure counter and return normally; evidence is unusable unless that counter remains zero. Callback mutation changes detached scalar records only.

`calendar` preserves the combined year/season branch. `once_or_pace` preserves the combined branch but reports existing `own.length` and `oneShotsOpen` scalars. `binding_or_context` does not distinguish internal bind-entry failures. The inline enabled-choice call remains byte-identical and runs only once: its discarded count is **not observed** (`enabledChoices:null`, `enabledChoicesObserved:false`), with `choiceEvaluationReached` explicit. Fields not reached are null. Selection ranges use only arithmetic over already-present frequency weights, never decision-weight recomputation; layer records separately serialize the actual existing decision weights.
