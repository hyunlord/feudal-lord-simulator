# RB-ERA-SIGNS: 직업·시대 간판 8장

관문: 변경 시험 1,478/1,478(DGX), 바뀐 화면 네 행 기하 80조건 실패 0(DGX), 실제 게임 전후 18쌍. 최종 병합 검사는 게시 시 실행하며 로그는 전달 ZIP에 포함한다. 구현 커밋 `f749fecc`, 기준 본선 `3841159b`.

제빵·양조·대장·직조 간판 각 두 장을 설치했다. 네 종류의 등록된 L2 집 벽에 실제 가구 직업과 달력으로 붙는다. 1399년까지는 1300 계열, 1400년부터는 1420 계열이다. 이는 그림 선택 기준이며 역사적 발명 연도가 아니다. 엔진·저장·UI 입력은 바꾸지 않았다. [계약](CONTRACT.md) · [부착점](registration.json) · [전후 대조](comparison.json) · [출처](provenance.json).

## 실제 장면에서 확인한 것

1399·1400·1420년 × 여름·겨울 × 줌 0.6·1.0·1.4, 모두 18쌍에서 저장 SHA·상태 SHA·정지 틱·카메라가 일치한다. 전부 기존 저장의 통제 장면이다. 네 집의 등급·건강 상태를 고정했고 기존 구두장이 하나를 직조공으로 바꿔 네 그림을 확인했다. 자연 플레이의 직업 분포·발생 빈도를 증명하는 캡처가 아니다.

8종 모두 축소 이미지 경로를 거쳐 실제 세계 캔버스에 그려졌고, 줌 0.6에서는 0회다. 실제 확대 화면에서 빵의 황갈색 판·양조의 녹색 다발 등 작은 벽 장식이 보이고 뚜렷한 공중 틈은 보이지 않았다. **문양이나 시대별 세공 차이를 플레이 크기에서 안정적으로 읽는다고 판정하지 않는다.** 갈색 간판은 목재 벽과 섞인다. 직업의 주된 단서는 기존 마당 소품과 함께 읽는다. 가까운 건물·세계 표시는 원래 깊이 순서로 간판을 가릴 수 있다. 등록하지 않은 본체·합필 집·다른 등급은 새 간판을 생략한다.

문서에는 여름·겨울 × 줌 0.6·1.0의 전후 8장과 확대 2장을 남겼다. 전체 전후 36장과 확대 48쌍·원본 PNG·캡처 입력은 전달 ZIP에 있다. 바람·물·연기는 벽시계에 따라 움직이므로 전후 픽셀 차이를 모두 간판의 변화로 세지 않는다. 줌 0.6의 픽셀 동일도 주장하지 않는다.

## 원칙 점검·판단

- P-V1: 실제 가구 직업·달력이 시각적 흔적을 고른다. 엔진에 없는 생산량을 만들지 않는다.
- P-V2: 가까운 거리의 작은 장식으로만 사용한다. 먼 줌 0.6에서는 숨긴다.
- P-V3: 실제 전후 장면과 확대판을 확인했다. 문양 판독 한계를 유지한다.
- P-M1·P-T5: 직업·연도 경계·부착점은 core 계약 데이터에 있다. 엔진 성장 조건을 추가하지 않았다.
- P-X1: 상태 불변 시험과 동일 저장·상태 SHA로 렌더가 시뮬레이션을 바꾸지 않음을 확인했다.

판단: 새 종류 `building-attachment`를 한 번 만들고 개별 간판·좌표·선택 조건은 데이터로 받는다. 팩 id는 core이고 옛 계약은 생략 시 core다. 원본에 caBX 청크가 없어 제거 수는 0이다. 원 기록에 없는 생성 모델·정확한 생성 시각은 추정하지 않았다. 다음은 랜드마크 44장의 성장 조건 없는 데이터 준비다.
