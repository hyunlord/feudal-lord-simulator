## 사용 계약
- 기본·선택 인물 틀176×216: 9-slice L/T/R/B =12/12/12/12px. 고인 틀은 십자 보존을 위해20/20/20/20px.
- 혈통 배너320×72:24/10/24/10px. 세대 라벨120×32:10/8/10/8px.
- 인물 틀의 원형 초상은 별도96px 마스크로 합성한다. 틀을 늘려도 얼굴은 늘리지 않는다. 원본176×216에는 초상·이름·숫자를 굽지 않았다. 초상 중심x88, 상단18px. 이름 두 줄은y130 이후.
- 인물 틀은 양피지 중앙이 불투명한 직사각 패널이다. RGBA 포맷이며 선택·고인 틀에 완전 투명 픽셀은 없다. 배경 전체가 투명한 테두리 전용 오버레이가 아니다. 그 외 버튼·선·장식은 투명 영역을 가진다.
- 가지선H64×8/V8×64를 반복하며 종단 일부만 잘라 쓴다. 코너16×16의 포트는 각 변 중앙8px. TL=오른쪽+아래, TR=왼쪽+아래, BL=오른쪽+위, BR=왼쪽+위. T=왼쪽+오른쪽+아래이며 방향 반전 가능.
- 선 7종은 생성된 잉크 획의 단면을 공통화한 기술적 파생본이다. 각기 자유 생성해 이음새가 어긋나는 방식을 쓰지 않았다. 실제 프롬프트·원본 경로·후처리는records에 남겼다. 모델 버전과seed는 도구 미제공으로 기록하지 않는다.

## 확인 그림
L3 창시 부부2명, 자녀4명, 바깥 배우자2명, 손자녀4명(총12명). L3_101 고인, L3_201 선택, L3_202 접힌 가지. 바깥 배우자는 문 표식. 201–205 및206–203 혼인 쌍과 두 자녀씩 연결한다. 확인용 이름·설명은 에셋에 포함하지 않는다. 접힌 가지는 UI 상태 시연이며 추가 인물이나 실제 부모 데이터를 생성하지 않았다.

초상10장은 첨부 `혈통초상_예.jpg` 첫 줄144px 영역에서, 바깥 배우자2장은 `혈통_가계도_구성예.jpg` 약65px 영역에서 추출했다. 배우자2명은96px로 확대되어 상대적으로 흐리다. 원본 얼굴 재생성 없음. 확인 그림에서는 틀을176×180으로9-slice 배치하여800px 화면에3세대를 넣었다.

## 경량 패키지
최종 PNG는 무손실, 원본 JPEG 참조 유지. 대형 생성 원본·중간 수정본은ZIP에 넣지 않고 `/Users/rexxa/feudal-lord-analysis/astra-raw/wave25-20260928/`에 별도 보존한다. `records/raw-inventory.json`에 해시·크기·보존 위치를 기록한다. ZIP에는 최종16부품·확인1·CSV·검수·계약·프롬프트·첨부참조·재현 스크립트가 들어간다. 재현은 원본 보존소와 명시된 로컬 도구 경로가 필요하다.

정적 합성·규격 검수이며 실제 엔진9-slice 구현, 클릭/접기 기능, 게임 성능 검증은 아니다.
