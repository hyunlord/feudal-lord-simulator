# Wave22 자체 검수

상태: **candidate**, 게임 미설치. 의뢰서 세부 표의 합계인 **51장**(15 fill + 16 strip + 20 decal)을 제작했다. 확인 그림은 3장이다.

## 검수 방법

- 실제 납품 PNG를 3×3(fill), 가로 3회(strip) 이어 붙이고 원본 0.5배·0.3배에서 확인했다.
- 확인 그림 02는 기존 집·나무의 위치와 배율을 고정하고 지면·전이·유형 소품을 바꾼 다섯 장면이다. 지면 UV는 2×2 논리 칸 가정이며 실제 엔진의 UV·곡선 변형과 동일하다는 검증은 아니다.
- 제작 담당 검수 외에 별도 검토자가 확인 그림 3장을 검토했다. 기계적인 접합 검사와 시각적인 반복 주기는 별도로 판정했다.

## 규격·기록

| 항목 | 판정 | 근거 |
|---|---|---|
| 수량·ID·크기 | 통과 | 명세 51개 ID와 PNG 일치. fill 256×128, 전이 512×64, 해안·갈대 띠 512×96. 데칼은 records/expected-assets.json의 크기 |
| fill XY 접합 | 통과 | 15장 모두 불투명, 양축 끝 RGBA 차이 0. 확인 그림 01에서 접합선 확인 |
| strip X 접합·알파 | 통과 | 16장 X 끝 RGBA 차이 0. 위아래 8px 완전 투명, 안쪽 알파 페이드. 세로 반복 대상 아님 |
| decal 알파 | 통과 | 20장 실제 RGBA, 사방 8px 투명 여백. 반복 대상 아님 |
| 생성 기록 | 통과 | CSV 51행·20열, 실제 프롬프트 전문과 채택/폐기 이력·참조·후처리. CSV 재읽기 문자열 일치 |
| 참조·원본 보존 | 통과 | 프로젝트 그림만 참조. 첨부에서 추출한 파일 24개 SHA-256 동일. records/reference-verification.json |

| 유형 | 줌 0.6의 식별 단서 | 기존 그림과의 톤 |
|---|---|---|
| 백악 언덕 | 짧은 풀 사이의 밝은 백악 노출과 낮은 흰 바위 | 따뜻한 백색·올리브 계열이 주택·나무와 연결 |
| 히스 | 어두운 고사리 덩어리와 거친 초지 | 탁한 녹색·갈색, 금작화의 황색은 작은 보조 요소 |
| 습지 | 청회색 물웅덩이와 큰 갈대 군락 | 낮은 채도의 물·젖은 흙이 기존 물가와 연결 |
| 해안 초지 | 넓은 모래 노출과 낮은 풀, 유목 | 따뜻한 모래색, 회갈색 나무가 기존 건물 톤과 연결 |
| 숲 바닥 | 어두운 갈색 낙엽·이끼와 쓰러진 나무 | 기존 숲 가장자리·나무를 배치해 연결 확인 |

## 해안과 소품

- 확인 그림 03에서 모래는 밝은 연속 면, 자갈은 둥근 회갈색 덩어리, 염습지는 진흙 돌출과 물길로 구별된다. 모래 B의 물은 원본보다 조금 더 청록색이며, 염습지 B는 A보다 일반 물가에 가까운 변형이다.
- 소품 변형은 별도 생성한 서로 다른 실루엣이다. 작은 버섯은 줌 0.6에서 개별 줄기보다 갓 군집으로 읽힌다. 나무껍질·돌 표면의 작은 보조 붓질은 축소 시 합쳐진다.
- 돌담의 캔버스 anchor는 하단 중앙이다. 대각 돌담의 중앙 돌 바닥은 anchor보다 10px 위에 있고 가까운 끝이 하단에 닿는다. 실제 경계선 배치 시 등각 발자국을 반영해야 한다.

## 시각 수정과 제한

초기 백악의 미세 입자는 폐기하고 큰 붓질로 재제작했다. 첫 장면 검수에서 백악·해안 fill의 대각 무늬가 경작 줄처럼 보이는 것을 발견하여 해당 여름·가을·겨울 6장을 다시 편집했다. 최종 확인 그림 01·02의 재검수에서 긴 평행 줄 인상은 해소되었고, 기존 주택·나무와 톤 연결 및 줌 0.6 장면별 유형 구분은 통과했다. 나머지 지면 9장은 SHA-256이 그대로다.

해안 겨울은 회백색 서리·모래 노출 때문에 다른 겨울 fill보다 밝다. 겨울 유형끼리는 여름보다 색 차이가 줄어든다. 작은 버섯은 저배율에서 종류 판별이 약하다. 이 항목들은 후보 검토 시 확인할 제한으로 남긴다.

동일 원본을 넓게 반복하면 무늬의 주기를 추적할 수 있다. 접합선이 없다는 판정을 '지도 전체에서 반복을 전혀 알아볼 수 없음'으로 확대하지 않는다. 띠의 A/B 교대는 각각의 자체 반복과 별개이며, A→B 연결과 곡선 워핑은 실제 통합 시 검증해야 한다.

게임 런타임의 DPR, 보간, 가림, 클릭, 성능, 계절 전환은 검증하지 않았다. 산출물은 후보 그림과 오프라인 합성 검수 자료이다.
