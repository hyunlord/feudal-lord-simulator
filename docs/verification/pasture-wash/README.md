# RB-PASTURE-WASH — 씻김 웅덩이 1장

완공 목축장이 돌보는 목초지의 물가에 씻김 웅덩이 PNG 한 장을 연결했다. 양 씻기 작업이나 생산량을 추가하지 않는 비경제 장식이다. 여름에는 조건을 만족하는 농장마다 최대 하나, 겨울에는 겨울 그림이 없어 숨긴다. 안전한 자리가 없으면 그리지 않는다.

제품 8d18d99f, 본선(FENCE be74a63c) 통합 c6a8fe65. 기존 stock-pile·farm-prop·UI 계약과 기존 양 떼·원목·폐울타리 소비 경로를 보존했다. facility-ground 선택 조건만 계약 합집합에 추가했다.

## 실제 화면 판정

공식 browser/light 실행 `astra-PASTURE-WASH-integrated-c6a8fe6`에서 같은 저장·상태·카메라로 전후 6쌍을 캡처했다. `before/`는 be74a63c, `after/`는 c6a8fe65다. 여름·겨울 각각 1.0·0.6배와 3배 근접 확대다. 3배는 시험 카메라 확대이며 정상 최대 줌 2배를 넘는다. 사용자가 쓰는 1.0·0.6배 판정과 구분한다.

12장을 직접 확인했다. 여름 웅덩이는 화면 중심의 풀밭 위에 놓이고 호수·양 떼·건물·길·울타리와 겹치지 않는다. 0.6배에서도 윤곽은 보이나 돌 표면 세부는 읽기 어렵다. 겨울 세 화면에는 웅덩이가 없다. 실제 drawImage→mip→세계 캔버스 기록에서 여름 각 뷰 목표 그림 소비를 확인했고(기록 상한 100회), 이전판 및 겨울은 0회다. 이미지 수와 그리기 횟수를 혼동하지 않는다. 눈·수면 애니메이션과 HUD 때문에 겨울 JPEG 전체는 픽셀 동일하지 않다. 원래 목축장 본체가 물가에 닿는 모습은 이전판에도 있으며 이번 변경이 해결한 것이 아니다.

`comparison.json`은 저장 SHA·상태 SHA·틱·카메라·농장 일치를 검사한 결과다. 시작 시 서버 준비 뒤 openScene이 성공했고 이후 브라우저 오류는 없었다. 기준판 public 파일은 이후판과 공유하므로 미사용 신규 PNG도 존재하지만 기준판 소스에는 소비 코드가 없다.

## 저장의 한계와 재현

이것은 seed 5의 기존 저장에 정상 reducer 명령 3개(목초지·도로·목축장)와 정상 advanceTick으로 공사를 마친 **준비 렌더 저장**이다. 임의 완공·물자·날짜 주입은 없다. `tests/fixtures/pasture-wash/`에 원본 결과·명령 기록이 있고, 추가 3,136틱 정상 진행으로 겨울 1601년과 여름 1602년 저장을 만들었다(3.243초 로컬). 본편 1300–1450년 자연 플레이 도달을 증명하지 않는다. 보고 ZIP에 계절 저장과 재현 스크립트를 함께 제공한다.

본편 자연 bot 저장 1380년·1382년도 읽기 전용으로 검사했다. 농장 네 곳이 가진 후보 213칸 모두 필요한 거리의 물가가 없어 선택 0개였다(`period-negative.json`). 이는 조건에 맞지 않는 정상 음성 사례이며 엔진 차단이나 양성 증거로 바꾸어 말하지 않는다.

## 배치·캐시·출처

목축장 완공·tending 양수, 가장 가까운 해당 농장 소유 목초지, 물까지 Chebyshev 거리 2, 전체 그림 캔버스를 역투영한 16칸의 육지 지지를 요구한다. 거리 1 물가와 이 엄격한 캔버스 지지는 양립하지 않아 임시 렌더 배치안을 거리 2로 정정했다. 기존 건물·공사·도로·앞마당·담·울타리·양 떼와 봄 동반 개체·원목·폐울타리 예약 영역을 피한다. 기존 물체를 옮기거나 삭제하지 않는다. 안정된 농장 ID와 해시로 자리를 정하고, 상태·그림 준비·ground scene 변경에 맞춰 캐시를 갱신한다. 그림 미준비 또는 안전한 후보 없음은 0개다.

PNG: `public/assets/wave3/pasture/wash_pool-v1.png`, 원본 `assets-inbox/wave3/candidates-20260926/assets/pasture/wash_pool-v1.png`. 두 SHA256은 `4c824dc6538aa379611c01575ee841412497fa7da43befd4dd4216803c3e821f`로 같으며 192×128, 피벗 (96,120), 균등 배율 1/3이다. 생성 당시 편집·참조·프롬프트는 `generation-record.json`에 그대로 보존했다. 설치 때 새 그림·색 변경·추가 겨울 이미지는 만들지 않았다.

## 검증과 원칙

통합 전 집중 시험 97개, 통합 후 계약·원본 가드·배치 시험 83개와 인접 기능 회귀 36개, TypeScript 검사 통과. 최종 정확한 트리의 변경 시험·병합 검사와 기하 결과는 최종 보고 receipt에 기록한다. 기하 판정 실행: `astra-PASTURE-WASH-geometry-c6a8fe6` (dirty=0, changed-row gate, 4줄 × 80조건 실패 0·미개방 0). 독립 선행 실행 `astra-PASTURE-WASH-independent2-8d18d99`도 성공했으며, 첫 `astra-PASTURE-WASH-independent-8d18d99`는 기준판 아카이브에서 Vite 보조 스크립트가 빠져 브라우저 시작 전 실패했다. 전체 scripts 아카이브로 고쳤고 제품 동작은 바꾸지 않았다.
