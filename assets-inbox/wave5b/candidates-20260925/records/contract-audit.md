## 워커 실제 기준

첨부 성인 남 원본294×147, 여312×156. Wave5a 남녀는296×148이다. 기존 파일럿2의 template-normalization.json도 전체시트4×2 비례정규화를 사용했다. `src/render/walkerPresentation.ts:WALKER_PRESENTATION_DIRECTIONS`는 NE/SE/SW/NW 순서를 명시한다.

실제 PNG를296×148로 전체 정규화한 뒤 alpha>128 픽셀이2개 이상 있는 마지막 행을 측정했다. 이미지 수정·저장은 하지 않았다.

| 성인 남 |66/67/66/66|66/66/66/66|

따라서 모든 기존 발 끝이 정확히 한 y에 있다는 주장은 성립하지 않는다. 새 A 공통 접지 기준선은 y67 경계(불투명 밑창 행66, ±1px 허용)를 채택하고, 발이 들린 프레임은 별도로 기록한다. 남성의 보이는 높이 약64–65px 대비 아이42±2px가0.6–0.7비례를 충족한다. 딥리서치의 초안 y62는 실측 전 가설이라 실제 PNG 기준보다 우선하지 않는다.

## 보행 판정

1. 각 프레임의 양쪽 엉덩이→무릎→발목→발끝을 추적해 해부학적 왼발/오른발을 식별한다. 화면 좌우와 해부학 좌우를 혼동하지 않는다.
2. 방향 투영벡터 NE=(2,-1), SE=(2,1), SW=(-2,1), NW=(-2,-1)을 기준으로 왼발과 오른발 위치차의 전진성분을 비교한다.
3. f0과f1에서 왼발-오른발의 전진성분 부호가 교대해야 한다. 단순 RGB차이, 양발 간격 변화, 전체 인물 이동, 좌우 반전은 통과 근거가 아니다.
4. 긴 gown이 다리 연결을 가려 발 정체성을 확정할 수 없으면 '확인 불가/미달'로 적는다. 추정 발 표시에는 불확실성을 표시한다.
5. 미달 방향은 f0을 편집 입력으로 삼아 f1의 발만 바꾸는 재시도를 실제 수행하고, 최초/수정 결과·실제 프롬프트·선택 여부를 모두 보존한다.
6. 머리쓰개·옷 길이·수염·몸 굽힘이 방향4개와 프레임2개에서 동일한 인물로 읽히는지 별도 검수한다.

## 초상화

P4 256²는 투명 레이어가 아닌 배경 포함 완성본이다. 눈 좌표 육안 추정은 약(81,112),(105,111)로 목표눈선112와 맞는다. 어깨208은 정렬 가이드이며 원본 그림에 직선 이음매를 그리라는 뜻이 아니다.

권고 합성순서: 동일 배경 → rear hair → garment → neck/face → age overlay → front hair → optional beard → hood/hat. 후드가 어깨·목 앞으로 내려오는 부위는 의복 위에 놓는다. P4는 별도 큰 수염이 없는 얼굴이므로 원본재현에서 수염은 생략한다.

마스크는 work tunic의 cloth1만 포함한다. 후드, 매듭, 린넨, 피부, 수염은 포함하지 않는다. RGB흰색과 알파 coverage로 cloth1 영역을 표시하며 마스크 밖은 완전투명. 색교체는 원본 명암을 유지하고 파랑/황록 두 결과를 검수한다. 네 확인 그림 각각256px 및96px 표시를 포함한다.
