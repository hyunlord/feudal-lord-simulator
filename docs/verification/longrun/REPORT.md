# 긴 판 시험 — 영주 모드 1300년부터 (P-T6)

사용자 지시(2026-10-06): 영주 모드를 1300→1600(가짜 끝 연도)으로 무인 실행해 50년마다 틱 시간·저장 크기·힙을 표로 만들고, 시간에 따라 쌓이는 것 가운데 무엇이 폭주하는지 찾는다. **고칠 것은 이 표를 보고 사용자가 정한다.**

- **실행**: DGX `engine-LONGRUN-549d959`(`scripts/longRunProbe.ts`, `node --expose-gc`, seed 1·2 동시, 무거운 칸).
- **멈춤**: seed 1은 1550년, seed 2는 1490년에서 멈췄다(2026-10-06 19:5x KST). 무거운 칸을 9시간 넘게 잡고 있었고 대기열에 다른 세션의 실행 8개가 서 있었다. 1400년부터 인구가 멈춰 있어 쌓이는 것의 추세는 이미 드러났다. 1600년까지 마저 재려면 다시 돌린다.
- **주의**:
  - 틱 ms는 공유 DGX의 부하를 함께 탄다(RR6). 판정에는 저장·배열 크기를 쓴다.
  - seed 2의 마지막 줄(1490)은 50년 경계가 아니라 저장·힙을 재지 않았다(0).

## 고칠 후보(사용자 판정용)
1. **연대기**: 오래된 사람·세력 줄을 해 단위 요약으로 접는다. 결정과 큰 사건, 결정이 원인으로 붙은 줄(`because`)은 남긴다. 지도 그림은 10년에 하나로 줄인다.
2. **경로 캐시**: 저장에서 빼거나(불러온 뒤 다시 계산), 지금 도로망의 키만 남긴다.
3. **죽은 사람**: 가문·혈통에 걸린 사람과 연대기가 부르는 사람만 남긴다. 나머지는 50년 뒤 이름과 해만 남긴 요약으로 줄인다.
4. **영지 청원·감사**: 답한 것은 10년 뒤 철 요약으로 접는다.
5. **세력 기억**: 3년(결과의 실이 보는 창)이나 최근 N개만 남기고, 나머지는 세력별 합으로 접는다.
