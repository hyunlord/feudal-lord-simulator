# 자동 검사 정의와 한계

이 문서는 실행 전 고정한 측정 정의다. `auto_measurements.csv`는 부품·조합별 원수치, `auto_summary.json`은 검사별 판정이다. `PROXY_PASS`는 해당 수식의 조건만 충족하며 사용자 요구의 물리적·지각적 사실을 입증하지 않는다. 미측정 값을 0이나 통과로 치환하지 않는다. `NOT_VERIFIED`가 하나라도 남으면 전체 자동 관문은 미통과다.

|번호|수식·관찰 대상|판정 조건 및 한계|
|---|---|---|
|1|24 PNG의 RGBA 배열 크기와 참조 원본 크기 비교|크기는 완전 동일. 원본 전체 좌표계 상속은 조립 기록으로 확인 가능하지만 엔진 pivot 메타데이터가 없어 실제 pivot은 NOT_VERIFIED.|
|2|참조 alpha>0의 구멍을 메운 독립 실루엣을2픽셀 침식하고 참조 alpha≥250인 픽셀만 남긴 내부에서 몸체 alpha+지붕 alpha<250인 픽셀 수|216조합 모두 0 필요. 자체 생성 마스크의 합집합으로 기대 영역을 만들지 않는다. 참조 실루엣 대비 누락 검사이며 새 몸체의 설계상 실루엣 차이도 실패로 나타날 수 있다. 그림자·덧붙임은 구멍을 숨기는 데 쓰지 않는다.|
|3|지붕 canonical 마스크 각 열의 최하단 윤곽 접선으로 계산한 법선 ±3px, 7표본에서 명도<70·alpha≥250의 분리된 어두운 run이 2개 이상인 위치 수|216개 실제 렌더 각각 기록. 국소 텍스처·처마 자체가 검출될 수 있는 이중선 대리 수치다. 명도70은 검출 정의이며 허용 임계값이 아니다. 사용자 허용 개수가 없고 실제 이중 윤곽선 픽셀 의미와도 같지 않아 NOT_VERIFIED.|
|4|alpha 1..250 중 alpha>0 support의 경계까지 EDT거리≤2px인 가장자리 픽셀과 가장 가까운 alpha≥251 픽셀의 Rec.709 가중 RGB 명도 차 절댓값>40의 비율|≤1%. 가장 가까운 불투명 픽셀 또는 경계 표본이 없으면 정의 불가. 숨겨진 투명 RGB는 제외. sRGB 값에서 계산하며 선형 광량은 아니다.|
|5|상태 alpha>0이 canonical 몸체/지붕 마스크 밖에 존재하는 픽셀 수|최종과 정렬 후 clipping 전 원본을 별도 기록. 각 0 필요. 최종만 0인 것을 생성 원본 정합으로 표현하지 않는다.|
|6|각 지붕 alpha>0 지지영역 중 눈 alpha>0인 영역 비율|지붕 3개 각 60..80%. 모든 nonzero alpha 비율과 유효 밝은 도색(alpha≥128 AND 명도≥180) 비율을 함께 기록한다. 후자의128/180은 이번 측정의 가시 도색 정의이며 사용자 제공 물리적 눈 판별 기준이 아니다. 두 수치 모두60..80% 여부를 기록하며 실제 눈 재질·깊이를 입증하지 않는다.|
|7|alpha≥250 영역을 2px 침식한 내부의 명도에 x,y,상수 최소제곱 평면 회귀. 밝아지는 방향 atan2(gy,gx) 및 모든 기본 부품 쌍의 최소 각도차|이미지 좌표 x오른쪽/y아래, 좌상향=-135°. 회귀 기울기≤1e-6이면 정의 불가. 부품간≤15°는 조건부 대리 비교. 재질·기하·무늬가 회귀를 지배할 수 있어 실제 광원 일치 PASS 불가. 상태 레이어도 개별 각도 기록, 기본 부품 쌍에서 상태·그림자는 제외.|
|8|불투명 픽셀 명도/HSV saturation 각32bin 정규화 histogram L1거리. 명도<70 영역 거리변환의 국소 능선에서 median(2d−1)로 어두운 선 폭 추정 후 쌍별 편차|Histogram 허용 임계값 미제공으로 원수치만 기록. 선폭 편차≤1px는 대리 조건으로 목골조 외 어두운 형태도 포함. 서로 다른 부품 재료의 히스토그램 차이가 곧 결함은 아니다.|
|9|몸체 원본3개 대비 각각의 벽색4개(white/ochre/pink/gray), 12개 실제 색변경 몸체 렌더. 이 12개가 216조합에 반복 사용된다. 벽 마스크2px 침식 내부에서 명도−Gaussian(sigma1)의 RMS 비율; 벽 마스크 밖 RGBA 변경 픽셀 수|RMS 비율≥0.8 및 비벽 변경0. 원본 RMS≤1e-6/유효 내부 없음은 정의 불가. 고주파 진폭 보존은 지각적 결의 동등성을 입증하지 않는다. 색마스크가 명도·채도로 만들어져 밝은 창을 벽으로 오분류할 수 있으므로 목골조·창의 의미상 보호는 별도 NOT_VERIFIED다.|
|10|기록된 실제 의미 부착점과 목표점의 Chebyshev 거리 max(abs(dx),abs(dy))|몸체3개×덧붙임5·간판5=30쌍, 각≤1px. 현재 수동 좌표 불확도는±2px로, 잔차+불확도≤1일 때만 PASS, 잔차−불확도>1이면 FAIL, 나머지는 NOT_VERIFIED다. 좌표는 준비 단계에서 의미를 보고 지정한 값이며 엔진 부착이나 자동 문 인식 검증이 아니다.|

추가로 자동 검사는 자연스러움, 도시 맥락, 눈가림 판별, 실제 게임 회전·가림·연결을 대신하지 않는다. 사용자가 지정한 경계값 이외의 통과 임계값을 임의로 만들지 않았다.

검증기 자체의 작은 합성 입력 검사: 정상 반투명 가장자리 비율0, 밝은 가장자리 비율1, 빈 alpha의 정의 불가, 수평 명도 기울기 각도0°/기울기4, 정규화 histogram 합1을 확인했다.

지붕 canonical 마스크는 3개 생성 지붕 alpha의 교집합으로 교정된 최종 윤곽이다. 따라서 최종 지붕들의 윤곽 일치는 생성 원본이 변형 없이 정합했다는 증거가 아니다. 기준 독립 영역은 참조 house_l2-v2에서 계산하며, 원래 기대 지붕 영역은 masks/roof_expected.png에 별도 보존된다.

측정 정의 교정 기록: 헤일로는 요구사항의 “가장자리”에 맞춰 support 경계2px 띠로 제한했다. 전 반투명 픽셀 비율은 DIAGNOSTIC으로만 보존하고 관문 집계에서 제외한다. 초기 gap98은 모두 참조 자체의 alpha246/248/249 픽셀이었으며 생성에 의해 새로 생긴 내부 틈이 아니었다. opaque hull fill 과정이 경계 antialias의 작은 빈 영역을 메웠기 때문에 발생했다. 최종 gap 영역은 참조 alpha≥250인 독립 내부로 제한했다. qa/auto_gap_pixels.csv에 이전98좌표×9몸체/지붕쌍과 최종129좌표를 함께 기록하고, 원본alpha, 외곽거리, 최종 검사영역 포함 여부를 보존한다.
