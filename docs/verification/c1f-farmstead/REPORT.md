- **원인:** D1a 안내 메모가 `GameState`의 모든 필드를 식별자로 비교했다. C1c-2 뒤로 틱마다 새 배열(건물·경작지 기록 등)이 생겨 매 프레임 메모를 놓쳤다. 놓칠 때마다 헛간 후보를 찾느라 지도 전체를 배치 판정으로 훑었다(약 198ms).
