# Wave 29 물 움직임 후보

14종 효과 시트(애니메이션 13종 + 정적 얼음 테 1종), 총 77프레임입니다. 대표 프레임 PNG 14장, 확인 그림 2장, 실제 시트로 만든 6초 반복 WebP, CSV와 검수 기록을 포함합니다. 후보만 제작했으며 게임에 설치하지 않았습니다.

## 시트 사용 규격
가로 한 줄, 좌→우 프레임, 여백 없음. 프레임 크기·FPS·반복 축·앵커는 assets.csv 기준입니다. source-over 합성. 잔물결의 낮은 알파는 PNG에 이미 반영되어 있으므로 다시 0.25를 곱하지 않습니다. recommended_alpha만 추가 적용합니다. UV는 각 프레임 안쪽으로 제한하여 옆 프레임 번짐을 방지해야 합니다.

물가 거품과 얼음은 X축만 반복합니다. 기존 shoreline_a 512×96 캔버스 기준 좌상단 (0,27)에 놓는 512×32 띠이며, 다른 지형의 물가에는 해당 경계 곡선에 맞춰 배치해야 합니다. 갈대는 기존 96×96 규격과 바닥 기준을 유지했습니다. 얕은 물은 깊이 마스크 안에만 쓰며, 전체 호수를 얕은 물 무늬로 채우지 않습니다.

일시정지 중에도 흐르도록 ambient real-time clock 사용을 CSV에 전달사항으로 기록했습니다. 실제 게임 연동·정지 동작은 구현/검증하지 않았습니다. 물고기 고리는 간헐적 1회 재생, 반짝임은 맑은 낮에 드문 배치, 얼음 테는 겨울, 급류는 수차 도랑용입니다. 곡물 풍차용이 아닙니다.

## 확인 그림
01: 제공 호수 캡처에 합성한 후보와 6개 연속 위상, 줌 1.0/0.6, 기존 물가 띠와 거품/얼음의 겹침.
02: 양축 반복 에셋의 4×4 타일 및 X전용 띠의 4회 반복, 첫/끝/차이 확대. 모든 프레임의 경계는 별도 수치 검사했습니다. 첫·끝 프레임은 서로 다른 시점이므로 같아야 하는 것이 아니라 마지막→처음 변화량이 다른 인접 전환과 비슷해야 합니다. 연속 시간 함수의 t=0/1 일치도 확인했습니다.

previews/all_effects_loop.webp는 CSV FPS 그대로 재생합니다. 대표 PNG는 물고기 고리만 잘 보이는 중간 프레임이며 CSV preview_frame에 기록했습니다. 원본 생성 대형 PNG는 경량화를 위해 ZIP에서 제외했고, 전체 프롬프트·소스 SHA256·가공 절차를 provenance에 남겼습니다. 가공 스크립트는 제작 환경 경로를 기록한 감사 자료로, 외부 환경에서 곧바로 실행되는 설치 도구는 아닙니다.
