# 제작 기록

20개의 개별 built-in image_gen 편집 출력과 전체 실제 프롬프트를 보존했습니다. 원화는 최종 게임 크기와 다르며, 설치 대상으로 쓰지 않습니다. assets/houses만 신규 후보입니다. references는 검수 기준, generated는 생성 증빙입니다.

후처리 스크립트는 실제 실행 기록으로 보존한 것이며 당시 로컬 경로와 기존 sharp 설치 경로를 포함합니다. 이 ZIP을 다른 경로에서 재실행하려면 lib.mjs의 W/D/R 및 sharp 경로를 조정해야 합니다. 원본 이미지/정합 다각형/캔버스/피벗/후처리 내역은 함께 제공됩니다.
