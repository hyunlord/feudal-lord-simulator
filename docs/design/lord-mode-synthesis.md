# 영주 모드 — 딥리서치 두 건 종합과 설계 방향 v1 (2026-09-30)

근거: GPT 딥리서치 ① 「간접 통치 + 확장의 루프를 어떻게 재미있게 만드는가」 ② 「잉글랜드 향신·영주는 1300–1450년에 실제로 어떻게 영지를 굴리고 넓혔나」, 기존 조사 「권리·영지·정치」「조작 층위와 유기적 구역」, 현재 본선 코드.

## 1. 두 조사가 같은 결론에 닿은 다섯 가지
1. **손맛의 단위는 건물이 아니라 인과 사슬이다.** "좌판세 3년 면제 → 상인 기대수익↑ → 빈 필지 입주 경쟁 → 가구가 대출 → 7개월 뒤 상점 완공 → 공동체 혼잡 불평 → 백작 대리인이 '특권 남용'으로 기억." 마지막 상점이 자동으로 지어져도 첫 원인이 플레이어이고 경로가 읽히면 "내 도시"다.(①)
2. **영지는 지도 칸이 아니라 권리 묶음이다.** 장원 = 토지·지대·법정·방앗간·어업권·교회추천권·생애권·잔여상속권이 겹친 것. 1432 Ermington 거래는 장원 대부분을 생애권으로 넘기면서 어업권만 떼어 뒀다.(②)
3. **확장은 "땅을 먹는 것"이 아니라 불완전한 권리를 안정된 영지로 바꾸는 긴 과정이다.** 청구 → 협상 → 문서 → 법적 권원 → 실제 점유 → 관리 → 감사 → 상속. Paston은 돈 주고 산 Gresham을 1448년 무력으로 빼앗겼다(권원 ≠ 점유).(②)
4. **혼인이 첫 확장 경로로 가장 좋다.** 매입은 돈 → 땅만 시험하지만, 혼인은 인물 → 관계 → 조건 협상 → 약속 → 혈통 → 시간 → 사망 → 상속 → 영지 → 연대기를 한 번에 시험한다(①). 역사로도 Paston–Mautby 혼인 하나로 장원 9개가 연결됐다(②).
5. **확장할수록 작은 결정이 늘면 실패다. 더 큰 결정으로 바뀌어야 한다.** 영지 1개의 청원 6개 × 영지 8개 = 48개는 콘텐츠가 아니라 같은 일의 반복(①). 역사적으로도 여러 장원은 청지기·집사·수입관리인에게 위임하고 1년에 한 번 감사했으며, **영주가 멀어지면 도시가 자유로워지는 게 아니라 대리인의 권력이 커졌다**(②).

## 3. 권하는 설계 방향
- **플레이어 = 조건을 만드는 사람.** 명령·정책·계약·협상·거래·소송·인사·투자 여덟 종류. 한 행동마다 "누가 / 무엇을 원함 / 무엇을 줌 / 언제 결과"의 같은 문법.
- **직접 배치는 핵심 루프에서 빼고 "명령 핀"만 남긴다**: 시장 확장 방향(구역 단위), 공공사업(교량·성문·시장 십자가·영주관)은 후보지 2~4곳 중 선택, 장려 투자 영역, 재난 시 폐쇄·대피. 일반 집·상점·작업장·창고·농가는 가구가 돈·직업·권리·접근성·기대수익·빈 필지로 짓는다.
- **협상은 Victoria 3 조약 초안 방식**: 왼쪽 "그들이 얻는 것", 오른쪽 "내가 얻는 것", 아래 **수락 이유 합계**(관계 −15, 현금 +20, 상속 위험 −12 …), 역제안은 바뀐 조항만 붉게. 확률은 숨기고 "거의 확실/유력/박빙/불리/불가능" + 상위 이유 3~5개. 첫 버전은 1:1만.
- **약속은 게임 객체**: 기한·대상·목격자·어기면 무엇이 깎이는지. "거짓말 버튼"은 없다 — 기한에 안 하면 어긴 것.
- **돈으로 전부 해결되지 않게**: 선례·신분·신뢰·세력 반발·상속 위험은 현금으로 완전히 상쇄 불가.
- **위임은 정치적 결정**: 세 번째 영지부터 관리 역량 부족 → 직접(청원 지연·장부 오류) 또는 청지기에게 위임(청지기의 성향이 결정을 기울임 — 상인 친화 청지기는 세입↑·농민 청원 기각↑). 영주의 **주의력**이 자원이고, 부패는 **연례 감사**에서 터진다.
- **시계 셋**: 도시(틱) · 정치(주~계절) · 왕조(해~세대). 자동 일시정지는 역제안·주요 인물 사망/상속·판결·권리 상실 위험 청원·영지급 위기·영지 획득/상실에만. 집 완공은 멈추지 않는다.
- **느린 결정은 중간 사건으로 쪼갠다**: 혼인 12년 = 협상 → 배우자 이주 → 첫 아이 → 처남 출생(기대권 하락) → 상대 영주 병 → 유언 변경 시도 → 소송·호의 결정 → 상속 판정.
- **가장 중요한 새 화면: 인과 영수증.** 건물·필지·가구를 누르면 "왜 여기에" 점수(장날 방문객 +32, 북문 접근 +18, 여관세 5년 면제 +16, 땅값 −11)와 **관련된 당신의 결정**(1333 여관세 면제 승인, 1334 북시장 성장 우선 지정).

## 4. 영지 데이터 모델 (②에서 바로 옮김)
`Estate`: 법적 명의자 · 실제 수익자 · 점유자 · 생애권자 · 잔여상속인 · 보호자(후원자) · 청지기 · 수입관리인 · 연간 가치 · 부담(채무·기존 지대·수선) · 청구자들 · 권원 강도. **장원 수와 연간 가치를 분리**(Paston 1444 유언은 장원을 "연 25 marks짜리 묶음"으로 나눴다). 권원 90·점유 20인 장원이 가능해야 한다.
협상 조항 후보: 대상 재산(장원 전체/방앗간/어업권) · 법적 형태(완전 소유/생애권/기한/잔여) · 일시금(지참금 — Elizabeth Paston £200) · **최소 연수입 보장**(연 £40) · 가족·후견인 승인 · 미성년 만기(21세) · 양육비 · 기존 채무 · 보증인(feoffee) · 담보 · 만기일 · **점유 인도일** · 분쟁 해결 수단 · 정치적 지원 약속.

## 5. 수직 조각 (조사 ①의 제안 + 우리 사정)
- **목표 하나만 검증**: 집을 하나도 직접 놓지 않고 12~20년 뒤 도시를 봤을 때 "이 모습은 내 결정 때문"이라고 느끼는가.
- **판**: 직할 장원 + 시장도시 1, 이웃 영지 3(지도 밖 카드), 세력 4~5(농민 공동체·상인 가문·교회·기사층·도시 공동체), 기존 가구·인물·혈통·권리·자동 성장·청원·연대기 재사용. **이웃 하나는 일부러 "늙은 영주, 딸만 있음, 비슷한 신분, 재정 곤란"** — 5~10년 안에 혼인 → 기대권 → 상속을 겪게 하는 시험용 장치.
- **행동 열**: 청원 판결 · 권리 확인 · 권리 회수 시도 · 영지 방침 지정 · 민간 사업 장려금 · 통행·시장 부담 조정 · 청지기 임명 · 장부 조사 · 권리 소송 · **혼인 계약(유일한 진짜 양방향 협상)**.
- **확장 경로 하나: 혼인**. 매입·하사·소송·정복은 나중.

## 7. 조사 품질 평가 (Claude)
- ②는 사료 한계를 정직하게 밝혔다: Plumpton 대부분·Cely 전부가 1450년 이후, 후견권 가격·토지 담보 사례는 못 찾음, **성공률은 역사 수치가 아니라 밸런스 추정**이라고 표시. 믿을 수 있는 수치는 £200 지참금·연 £40·21세 신탁·연 40 marks·£437 대부(보석 담보)·Stonor 9개 주.
- ①은 게임 사례의 구조 설명은 좋지만, 수락 점수 예시(+29 등)는 **설계 예시**이지 실제 게임 수치가 아니다(스스로 밝힘). HOI4는 참고 가치가 낮다고 정정했다.
- 둘 다 **"도시가 이유 있게 반응하는가"를 가장 큰 위험**으로 봤고, 우리 코드의 가장 큰 공백도 거기(자동 성장에 이유 점수가 없음)다.
