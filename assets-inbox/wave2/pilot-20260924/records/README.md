## 생성·수정 기록

양조3회, 직조2회, 생계4회, 농장·우물·시장 각1회 생성. 모델명과 seed는 도구에 표시되지 않아 추정하지 않았다. 생성일은 원본 파일 mtime의 UTC 기록이다.

도구가 최종 규격보다 큰 원본을 반환했다. 처음부터137px로 직접 생성했다고 주장하지 않는다. 이후 Canvas 2D로 alpha≤2의 미세 점을 제거하고 유효 알파 경계를 잘라 **균일 비율 축소**, 접지 등록, 여백 정리를 했다. 색 변경·흐림·샤프닝·비균일 늘이기는 하지 않았다. 원본 좌표와 해시는 기록에 보존했다. 원본 생성 이미지와 참조 PNG는 ZIP에 중복 수록하지 않아 납품 PNG는 정확히8장이다.

현재 농장 렌더는 흙·작물 분리층 및 구간별 변환을 사용하므로 이 평면 후보 PNG가 그대로 교체 설치된다고 보장하지 않는다. 설치 작업에서 별도 확인할 계약이며 이번에는 게임 파일을 변경하지 않았다.
