# Wave8 최종 시각 검수

판정: **candidate-pass-with-notes**. 필수 재제작 요청 없음.

## 범위와 독립성
- 최종 37개 에셋과 확인 그림 3개를 원본·연락표·실제 24px 행·9-slice 1.5배 그림으로 확인했다.
- 검수자는 `chronicle_initial_a/b/c`, `seal_petition_accept/reject/price` 6장을 제작했다. 이 6장은 자가 검수이며 나머지 31장은 제작에 참여하지 않은 검수다.
- 게임 설치·실행·클릭 판정·실제 UI 렌더 성능 검증은 하지 않았다. PNG 정지 합성과 선언된 9-slice 계약 범위의 검수다.

## 기준별 결과
| 기준 | 판정 | 관찰 근거 |
|---|---|---|
| P0와 같은 게임 | 통과 | P0의 따뜻한 크림 본문, 가는 갈색 규칙선, 어두운 갈색 윤곽을 유지한다. 목재 틀은 P0보다 재질감이 있지만 내부 대부분은 기능용 빈 영역이다. |
| 이름 없는 화면 역할 | 통과 | 결산은 양쪽 말림+상단 3장면, 연대기는 세로 페이지+왼쪽 덩굴, 청원은 접힌 문서+초상 원+붉은 인장, 목표는 좁고 긴 목재 서랍과 손잡이로 구별된다. 확인 그림01은 이름을 붙이지 않아도 이 구별이 남는다. |
| 9-slice | 조건 범위 통과 | 6종의 기본·1.5배 합성에서 초상 원, 인장, 손잡이, 나침반, 모서리 덩굴이 늘어나지 않았다. 계약과 제작 검증 기록의 고정 코너 채널 차이는 0이다. |
| 24px 아이콘 | 통과 | 원색 행과 검정 실루엣 행 모두 확인. 물방울/둥근 빵/바퀴와 수레채/다이아 필지/망치와 손/동전 더미/불꽃/문서가 구별된다. 종은 작은 직립 1개, 가로 2개, 기울어진 큰 종과 외곽 울림선으로 색 없이도 다르다. |
| 계절과 사건 | 통과 | 봄 가지·여름 해·가을 잎·겨울 가지의 4구간, 새싹/곡식/동전/좌판의 24px 형태를 확인했다. 핀은 원형 동전과 아래 뾰족점으로 차이가 있다. |
| 키아트 세계 화풍 | 통과 | 초가·갈색 목조·크림 미장·점토색 지붕과 넓은 올리브 지형이 첨부 주택 및 도시 재질군과 연결된다. 화면 규모가 달라 원본 게임 스프라이트보다 세부가 많으나 다른 판타지 화풍으로 바뀌지는 않는다. |
| 첫인상·장별 분위기 | 통과 | 최종 타이틀은 낮 장면에서 새벽의 차가운 하늘과 낮은 따뜻한 빛으로 수정됨을 확인했다. 목책·교회·시장·강·띠밭과 비어 있는 상단 중앙이 있다. 기근은 비와 쓰러진 곡식, 전쟁은 전령과 짐 운반 행렬, 역병은 빈 거리와 문 표식이며 과장된 공포·전투가 없다. |
| 텍스트·숫자 없음 | 육안 통과 | 새 에셋에 읽을 수 있는 글자·숫자·워터마크 없음. 역병의 문 십자와 인장의 체크/교차는 요청된 기호다. 확인 그림의 기존 HUD 텍스트는 참조 캡처에 원래 포함된 것으로 에셋에 구운 문자가 아니다. |
| 엠블럼 알파 | 통과 | 최종 PNG 512×512, 투명 픽셀 143622개를 직접 확인. 확인 그림03의 하늘 위 합성에서도 배경 사각판이 남지 않음. 방패·성벽탑·밀 이삭으로만 구성되어 글자가 없다. |

## 명시할 한계
1. 9-slice는 `frames-contract.json`의 최소 크기 및 insets를 사용한 경우만 검수했다. 더 작게 압축하거나 다른 insets를 적용하는 경우는 보장하지 않는다.
2. 결산 3장면 자리는 고정 코너에 속한다. 가로 확대 시 크기를 유지하며 왼쪽에 남고, 자동으로 3등분 재배치되지 않는다. 서랍 손잡이·나침반도 중앙 재정렬을 자동 제공하지 않는다.
3. 24px에서 의미를 전달하는 것은 큰 실루엣이다. 작은 목재결·곡식 알갱이·문서의 인장 세부까지 판독되는 것은 아니다. 영역 아이콘은 범례 없이 정확한 정책 의미를 가르치는 검증까지 한 것은 아니다.
4. 긴 확인 그림02가 뷰어에서 축소되면 아이콘이 실제24px보다 작아진다. 원본100% 또는 작업 폴더 `icons-qa.png`의 네이티브24px 행으로 판정했다.
5. 위 판정은 후보 미술 적합성 검수다. 역사학적 고증 감수, 접근성 사용자 시험, 실제 게임 런타임 적합성의 승인은 아니다.
