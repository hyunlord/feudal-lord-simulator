## 화면에서 확인한 사항

1. **영주관이 무채색 도형 대체물로 보임**: 0.5에서 마을 북서쪽 이름표 아래 작은 도형, 1.0·1.4에서 짙은 얇은 선+크림 면의 기하학적 집이 명백하다. 회화형 집·나무와 질감·외곽선이 극단적으로 다름. 이 장면의 `manor-house-34-41-0`에 해당한다. 이는 Wave30 원본 그림의 결함으로 판정하지 말고, 그림 연결/대체 렌더 문제로 분리. `src/render/` 검색상 manor 관련 연결은 Wave9 군중뿐이었다.
2. **숲 나무의 상대 크기**: 1.0·1.4에서 밀집 숲의 많은 나무가 2층 집보다 작고 가늘며, 풀밭 단독 고목은 상대적으로 크다. 실물 비율 문제를 원본 PNG 크기만으로 판단하면 안 됨. `treeLayout.ts:115`의 숲 가장자리 0.72/0.8, 같은 파일253의 0.80–1.15 개체 변이 및 TREE_STATURE와 런타임 renderScale 합성 결과다.
3. **눈 표현의 비일관성**: 같은 겨울 장면에서 주거지·곡창은 강한 흰 눈이 쌓이고 두 붉은 기와 창고는 붉은 지붕이 전면 노출된다. 시즌 적용 누락인지 의도된 녹음 차이인지는 이미지 한 장으로 확정 못 함. 계절 변형/바인딩 검사 대상으로 기록.
4. **저줌 판독**: 0.5에서는 지붕·숲의 세부가 점무늬로 합쳐지고 경고 핀/링이 지붕보다 두드러진다. 이는 원본의 해상도 문제와 UI 오버레이 크기를 구분해야 함. 1.0에서 목재/석회/붉은 지붕의 구별이 살아나고 1.4에서는 처마·외곽 검은선과 나무 가지의 세부가 보임.
5. **비가 없는 겨울 장면**: 세 줌 캡처 자체는 빗방울 크기를 실측하지 않는다. 날씨를 강제하지 않았으며 비는 코드 규칙만 감사했다.
