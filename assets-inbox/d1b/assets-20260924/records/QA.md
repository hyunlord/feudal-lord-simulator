# D1b 자체 검수표

검수일 2026-09-24. 최종 PNG를 직접 열어 확인하고, 별도 검수자가 참조 그림 및 최종 PNG를 다시 검사했다. 게임 설치는 하지 않았다.

| 기준 | 판정 | 근거·범위 |
|---|---|---|
| 석재길 3장 접합 | **통과** | 512px 전체를 3회 연결한 그림에 세로 틈·단차 없음. 최종 PNG 좌우 최외곽 RGBA 차이 0. 주기화 후처리를 거친 결과 |
| 줌 0.6에서도 돌길로 읽힘 | **통과** | 밝고 어두운 불규칙 돌 조직이 남고, 흙길의 평행 바퀴 자국과 구별됨. 원본의 개별 작은 돌 세부까지 유지한다는 뜻은 아님 |
| 흙길과 폭·톤 연결 | **통과, 전환 범위 명시** | 같은 512×64 캔버스·중심선·48px 내부 폭. 따뜻한 회갈색으로 연결. 돌이 조금 더 밝고 거친 재질임은 의도된 구분. 부드러운 곡선 전환에는 확인 그림의 교차 합성이 적용되며, 직접 접합 비교도 별도 표시 |
| 숲 C 낮고 넓은 3~4개 풀덤 | **통과** | 4개 작은 풀덤과 낮은 낙엽 띠. 그림 높이 24px로 A/B 큰 덩어리의 절반 이하. 큰 중앙 고사리·나무 줄기 없음 |
| A,C,B,C,A,B,C 배열의 리듬 반복 은폐 | **통과, 지정 배열 한정** | 낮은 C가 A/B의 큰 잎 덩어리 사이에 들어가 일정한 교대 물결을 끊음. C 동일 모양 자체는 세 번 재사용됨. 장거리 경계에서 반복이 전혀 없다는 보증은 아님 |
| 숲 C 줌 1.0·0.6 형태 유지 | **통과, 큰 형태 기준** | 낮은 풀덤·낙엽 띠가 유지됨. 0.6에서 가는 잎은 합쳐지므로 잎 한 장의 세부는 판정 대상이 아님 |
| 알파 규격 | **통과** | 석재길 상하 8px, C 사방 8px 완전 투명. 위반 픽셀 0. C 좌우 끝 커버리지 감쇠 |
| 흐림·번짐·텍스트·격자 금지 | **통과** | 에셋에는 글자·워터마크·격자·넓은 흐림 테두리 없음. 설명 문구는 확인 그림에만 있음 |
| 첨부 그림만 참조 | **통과** | 각 생성 입력 5개 모두 제공 ZIP 그림. 확인 그림 역시 새 납품 2장과 첨부 그림만 사용 |
| 최종 PNG 크기 | **통과** | 512×64 및 128×96 RGBA. 확인 그림 포함 총 4 PNG |
| 지정 크기 직접 생성 | **제작 방식 한계** | 도구가 더 큰 원본을 반환해 축소함. 최초 C 16px 비례축소 대신 24px 높이로 비균일 정리. 이력 공개 |
| 생성 기록 | **통과** | 지난 D1과 동일 20열, PNG별 4행, 실제 프롬프트 전문, 후보·후처리·도구·참조·상태 candidate 기록 |

## 확인 범위 밖

- 곡선 매핑·재질 전환·가림·클릭·성능 등 게임 런타임 동작.
- 긴 숲 경계, 다른 지형·조명, 다른 간격에서의 반복감.
- 사용자 최종 아트 승인. 기술·독립 검수 통과는 승인과 다르다.

상세 독립 관찰은 `records/independent-visual-review.md`, 파일 재검사 증거는 `records/final-validation.json`을 참조한다.
