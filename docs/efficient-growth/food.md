# 식량 자동 성장: 실제 흐름과 접근 가능한 공급

기준 `bbc0c523`, D24 미포함. 기본 8필지·경제·생산·인력·서비스 거리·저장 버전은 유지한다. 이 커밋은 식량 판단과 관측을 바꾸며, 5개 seed 합격이나 제품 반영을 주장하지 않는다.

## 변경
- 실제 생산·밀 소비·수출·주택 요청/소비·원료 부족 정지를 최근 2,400틱으로 집계한다. 기존 생산/시장/급식 실행 지점에서 기록한다. 불완전하거나 시간이 건너뛴 관측은 증설 근거가 아니다. 120개 단위의 불변 배열 묶음으로 최대 약 2,520개 누적 체크포인트를 보존한다.
- 이론 방앗간 목표 개수를 제거했다. 원료 부족·운송·인력·실제 빵 부족을 구분하고 필요한 조치 하나를 선택한다. 비어 있는 기존 방앗간이 있으면 새 방앗간을 막는다. 공사 중 시설까지 포함해 방앗간≤밀밭, 곡창≤ceil(필지/4)+1을 적용한다.
- 최초 최소 식량망과 재고가 충분한 초기 주택 성장은 보존한다. 완성 식량망의 추가 공사 이후에는 최소 2,400틱을 관찰한다. 저장된 과거의 짧은 관측만으로 새 시설을 허용하지 않는다.
- 성벽 이전에도 실제로 끊긴 식량 도로를 기존 합법 도로 계획/실행기로 복구한다. 독립된 정상 공급 지역을 무조건 한 곳에 연결하지 않는다. 다음 식사에 필요한 양과 해당 지역에서 접근 가능한 재고를 비교하여, 반대편의 빵 또는 소량의 지역 재고가 공급 부족을 숨기지 않게 한다. 같은 공급 시설의 재고는 지역을 합쳐 한 번만 센다.

## 검증과 제한
- 변경 전 실패: 관측 없는 완성 식량망이 방앗간을 추가함, 생산 시각 누락을 2,400틱으로 인정함, 성벽 이전 단절에 도로 복구 없음, 먼 빵 200개가 지역 재고 0/1개와 굶는 집의 부족을 가림. 새 회귀로 확인한 뒤 수정했다.
- 준비한 합법 재고·인력 상태의 실제 엔진 2,400틱: 빵 35개 생산, 밀 70개 소비, 급식 요청/소비 96/96, 가동 가능 방앗간 시간 2,400틱·원료 부족 1,348틱. 자연 성장 성공 증거가 아니다.
- 식량 관련 219개 시험 전부 통과(삭제·건너뛰기 없음), 타입 검사·diff 검사 통과. 독립된 두 정상 공급 지역 유지, 4가구/밀밭 1개에서 다섯째 주택 허용도 확인했다. 기존 이론 처리량/짧은 관측 시험은 변경된 계약에 맞춰 수정했고, 실제 생산·운송·예약·인력·관측 수명 시험은 유지했다. 전체 회귀·8필지/5개 지도 실행·캡처는 최종 검증 단위에서 한 번 수행한다.
- 생산량은 도시 전체 실제 집계이며 과거 생산을 지역별로 추정하지 않는다. 지역별 현재 급식 부족과 물리적 재고/경로를 별도 확인한다. 미래 수송 처리량 개선이나 최종 도시 효율은 장기 실행으로 확인해야 한다.
