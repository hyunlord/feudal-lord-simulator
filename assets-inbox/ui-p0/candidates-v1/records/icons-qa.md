# B·C 아이콘 / 커서 검수

- B 11시트, 57셀. 모든 셀은 96×96, 한 줄 좌→우. 최신 의뢰서 B 머리말을 파일럿 128px보다 우선했다.
- C 6개 개별 64×64 PNG. 실제 알파에서 좌상단 화살촉 픽셀을 측정한 hotspot은 icons.json에 있다. `icons-cursor-hotspots.png`의 작은 빨간 점은 검사용 합성으로 원본에는 없다.
- 17번 독립 최초 생성, 0절 팔레트 정합을 위한 5시트 편집. 전체 실제 프롬프트·참조·원본은 icons.json / sources/icons에 보존한다. 모델 버전과 seed는 도구가 제공하지 않아 null이다.
- 파일럿 대비 외곽선이 얇고 부드러우며 빵은 황토·갈색, 금화는 탁한 황토색이다. 계절은 봄 가지/여름 해/가을 잎/겨울 눈송이로 현대 달력이 없다.
- info는 세 점 말풍선, help는 책 그림으로 글자를 넣지 않았다. 2배/3배는 chevron 2개/3개로 숫자가 없다.
- `02-icons-24px.png`는 57개를 실제 24px로 그렸다. 내부 기록 `icons-32px.png`, `icons-48px.png`도 확인한다.
- 24px 한계: 생활의 우물, 생업의 낫, 저장유통의 자루, 방앗간 몸체, 목표 도움의 촛불 같은 부속은 약하게 읽힌다. 오두막/헛간은 주된 지붕 질량이 비슷해 실제 메뉴에서 이름 병기가 필요하다. 구역 붓/방향 두루마리의 작업 의미는 형태만으로 완전하게 전달되지 않아 코드 라벨이 필요하다.
- 정적 확인판 검수이며 클릭·접근성·실제 UI 상태 변화 검증은 하지 않았다. 게임 미설치 candidate다.
