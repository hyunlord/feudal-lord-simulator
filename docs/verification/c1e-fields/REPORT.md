## 0절·0-A
- **받은 편지함**: 모든 PNG의 SHA-256이 같은 폴더 대장의 `runtimeSha256`과 같다.
  - Wave 4b ZIP `(1)`의 PNG는 IDAT가 같고 C2PA `caBX` 청크(약 5.7KB)만 더 붙어 있다. 그래서 대장과 같은 첫 ZIP(03:16)의 바이트를 넣었다(`assets-inbox/README.md`).
  - D1·D1b 확인 그림 4장은 받은 적이 없다. "다음 후보"로 남긴다.
- **대장 53행**: Wave 4b 53장이 모두 `public/assets`에 들어가 `runtime`이다. 미설치 `candidate`는 0행이다.
  - 새 행 48개: 원본을 `docs/asset-evidence/runtime-sources/`(LFS)에 복사했고 SHA가 같다. 프롬프트는 `docs/provenance/prompts/`에 두었다.
  - 파일럿에서 승격된 5장(pasture_a·orchard_floor_a·haycock_a/b·orchard_apple_c)은 C1b가 설치한 바이트와 같다. 기존 행에 Wave 4b ID를 적었다.
  - 물가·얕은 물·목책 면·석벽 면·교대 15장은 `terrainVariantManifest`에 등록만 했다. 불러오지 않고, 렌더는 D3다.
  - 대장은 247행이고, 대장 검사 테스트 4개가 통과한다.
- **Z 키**: 구역 도구를 켠 상태에서 `zone_undo_stroke`를 보낸다. 칠하는 도중이면 Esc처럼 획만 버린다. 되돌릴 획이 없으면 "되돌릴 획이 없습니다"를 띄운다(테스트 2).
- **BG1**: 결정 목록에 확정으로 올렸다.
- **도로 접근**: 새 판정을 만들지 않았다. 띠 배치와 상태는 C1c `arableStripStates`에서 읽는다.

## ① 경작지 — 통과
- **장면**(`scene/`, 실제 입력만): C1d seed 2 구역 장면(C1b 자연 스냅숏 276,000틱 + C1d 실제 입력 오두막 3채, 305,973틱)에서 시작했다.
  - 경작지 다각형 도구로 성 밖 사각형(칸 x 47..56, y 49..60)을 칠했다. 118칸이고, 성 안 2칸은 C1c 규칙대로 빠졌다.
  - 5배속으로 돌리다가 네 상태가 모두 보이는 순간 일시정지했다(307,092틱). 스크립트는 증빙 포트를 읽기만 했다.
- **축**: 구역이 세로로 길어 띠가 y축을 따른다.

  | 띠(x) | 상태 | 따른 밀밭 |
  |---|---|---|
  | 47–48 | 성장 | 밀밭 056 |
  | 49–50 | 갈이 | 밀밭 053 |
  | 51–52 | 싹 | 밀밭 058 |
  | 53–56 | 휴경 | 없음 |

- **밀밭 footprint**: 띠를 그리지 않는다. 밀밭 스프라이트는 그대로다(테스트).
- **headland**: 0.2칸(허용 0.15~0.25)이다. 작물 사각형이 작물 없는 이웃 쪽 변에서 0.2칸 안쪽에 있는지 테스트로 확인했다.
- **캡처**: `captures/arable-z1.00.jpg`·`arable-z0.60.jpg`·`arable-z2.00-closeup.jpg`(걷는 사람 숨김, 저장 상태를 다시 열어 정확한 줌으로).
  - 줌 0.6에서 성장 금빛·갈이 짙은 흙·싹 연녹·휴경 올리브로 구분된다.
- **상태 색 덧칠(결정 FS2)**: 원화만으로는 갈이·싹·휴경 세 띠의 평균색이 102/71/44·111/80/45·108/82/51로 거의 같아, 줌 0.6에서 구분되지 않았다(첫 캡처). 그래서 줄마다 옅게 덧칠했다.
- 작물 칸 위의 풀덤·돌·관목(물체 패스 ground cover)은 그리지 않는다(테스트).

## ③ 텃밭·허들 — 통과
캡처: `captures/yard-z1.00.jpg`·`yard-z0.60.jpg`·`yard-z2.00-closeup.jpg`. C1d의 실제 입력 오두막 3채다.
- **허들**: 9조각(북쪽 코너 1)이 마당 사각형의 정수 격자 위에서 말뚝끼리 이어진다. 소켓은 (64,−32) = 1칸이고, +x 방향은 좌우 반전이다(테스트).
- **정렬**: 집 뒤 조각은 집보다 먼저, 앞 조각은 나중에 그린다.
- **텃밭**: 3개. 집 뒤 띠의 보이는 끝에 있고, 줌 0.6에서도 이랑 윤곽이 남는다(`yard-z0.60.jpg`).
- **Astra 4c 추가 의뢰 근거**(캡처의 표시 G·C·H, `captures.json`에 좌표). 이 장면에서 11곳이다.
  - **문 G 5곳**: 앞마당 쪽 변. 지금은 울타리를 끊었다.
  - **코너 C 3곳**: 동·남·서 꼭짓점. 지금은 직선 두 장이 말뚝을 겹친다. Wave 4b 코너는 "^" 한 모양뿐이다.
  - **반 칸 H 3곳**: 도로 envelope에 절반쯤 잘린 변. 지금은 울타리를 두지 않았다.
  - C1d가 요청한 말뚝 단품(48×96)은 직선 조각이 양끝 말뚝을 가져서 이번엔 필요 없었다. 반 칸 끝에는 필요해진다.
- **seed 1~5 도시**: 성 안은 마당이 거의 footprint뿐이라 소품이 적다(텃밭 합 10, 허들 10).

| family | 개수 | 4칸 안 같은 변형 쌍 |

## 엔진(C1c / C1c-2)에 넘길 것 — 밀밭 → 구역 띠 대체 때 필요한 상태 API
- `arableStripStates(zone, state)`의 띠 `id`(`zone:axis line:first`)가 안정적이어야 한다. 렌더는 청크 키와 띠 배치를 이 id로 묶는다.
- **단계 → 이랑 재질 대응**: 렌더에는 4종(ploughed·seedling·growing·fallow)이 있다.
  - C1c-2 단계 `sown` → seedling, `ripe` → growing으로 읽겠다.
  - `harvested`(그루터기)는 재질이 없다. 당분간 fallow로 읽는다. 그루터기 띠는 Astra 의뢰 후보다.
- 띠에 밀밭 footprint가 없어지면 렌더는 자동으로 띠 전체를 그린다(footprint 칸 제외 규칙은 건물 칸 기준).
- 단계 전이가 계절 단위면 청크 재래스터가 드물어진다. 단계 외에 렌더가 더 필요로 하는 값은 없다(`yieldEstimate`·`fertility`는 표시하지 않음).
- 헛간(farmstead)의 마당·울타리는 집과 같은 규칙으로 줄 수 있다. 헛간이 생기면 알려 주면 된다.
