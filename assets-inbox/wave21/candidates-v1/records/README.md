# Wave 21 — 3~5장 삽화 후보

게임에 설치하지 않은 후보입니다. 원본 및 승인된 기존 그림은 변경하지 않았습니다.

## 구성
- 3장 흑사병 19장: 사건 8 · 결정 4 · 연대기 6 · 장 끝 1
- 4장 재편 19장: 사건 8 · 결정 4 · 연대기 6 · 장 끝 1
- 5장 자치와 유산 20장: 사건 8 · 결정 4 · 연대기 6 · 장 끝 1 · 캠페인 끝 1
- 최종 PNG 58장, 확인 그림 3장, CSV 58행. 생성 원본·수정 이력·전체 프롬프트·참조·검수 기록 별도 포함.

확인 그림은 오프라인 카드 합성입니다. 실제 게임 화면이나 런타임 적용 증거가 아닙니다. 각 장의 사건 8장, 결정 4장, 연대기 6장을 같은 순서로 놓았습니다. 세 번째 확인 그림 하단에 세 장 끝을 나란히 놓고 캠페인 끝을 추가했습니다. 그림 자체에는 이름이나 설명을 넣지 않았으며, 배치 순서는 records/proof-layout.json에서 확인합니다.

## 제작 계약
사건 960×540, 결정 640×480, 연대기 384×384, 장 끝/캠페인 끝 1920×1080. 생성 원본과 납품 크기는 구별하며 원본 크기는 CSV generation_records에 기록합니다. 비례 리사이즈·크롭은 기록하고, 원본보다 큰 납품은 네이티브 생성 해상도라고 표현하지 않습니다.

Wave16·17 프로젝트 참조를 사용했습니다. 저채도 손그림 화풍, 연대기의 약한 채식 구성은 유지하되 양피지 색조는 코드가 입힐 수 있도록 그림에 별도 입히지 않았습니다. 흑사병은 문 표식 없이 빈 거리·닫힌 덧창·새 무덤·완전히 덮인 장례 들것으로, 1381 반란은 유혈 없이 징수원을 쫓는 장면으로 표현합니다. 책과 문서는 무문자입니다.

검수는 첨부 명세·프로젝트 역사 규칙과의 시각 비교이며 독립적인 사료 고증이나 게임 내 가독성·성능 검증이 아닙니다. 장면의 제도명·연도·정확한 선택 효과는 그림만으로 단정할 수 없고 게임 문맥이 필요합니다.

## 재현과 기록
assets/ 최종 후보, raw/ 생성·교정 원본, references/ 사용 참조, records/ 명세·메타데이터·검수, scripts/ 출력·합성·CSV 생성 스크립트.

이미지는 내장 image_gen.imagegen으로 제작했습니다. 도구에서 제공하지 않은 모델 버전과 seed는 null입니다. 생성 작업은 비결정적이며 scripts/는 보존한 생성 원본에서 납품 규격과 확인 그림을 재처리하는 도구입니다. 스크립트의 로컬 의존성 경로는 제작 환경 기준입니다.

## 최종 확인
58장 개별 시각 검수(독립 담당 48장 + 주 담당 10장), 확인 그림 3장 검수, 파일 검사 312건 및 CSV 58×12 셀 왕복 검사를 통과했습니다. 검수 대상 현재 해시 불일치와 미해결 지적은 0건입니다. 장 끝 도시들은 같은 세계의 변화를 표현한 별도 구도이며, 동일 지도 좌표를 재구성한 그림은 아닙니다.
