- 시간: 60+90+90+120+90+120+120+90+90+150+120+60 = 1,200초. 실측이 아닌 설계 예산.
- 흐름: 청원 판결 → 실제 도시 반응 또는 미착수 사유 → 건물/과거 사례의 왜 영수증 → 영지 방침 → 첫 혼인 제안 → 실제 상태에 맞는 장부.
- 금지된 건물 배치 지시 없음. 스킵으로 자동 판결·돈 사용·계약 수락 없음. 거절을 졸업 실패로 취급하지 않음. 혼인과 현재 점유 구분.
- 그림 12장 각각을 원래 1280×800 크기로 직접 열어 한국어·겹침·목표·대본 대응 검수. 이미지 전체는 불투명 RGB JPEG이며 원본 투명 자산을 새로 설치하지 않음.
- 텍스트 레이아웃 검사: 301개 기록, 캔버스 이탈/설정 폭 초과 0. 폰트 자체 글리프는 육안 검토로 별도 확인.
- 독립 검토 A(대본·계약): PASS. 독립 검토 B(CJK·시각): 첫 판 REVISE 1건 → 수정본 PASS. 두 검토자가 모두 본 10번의 U+2212 누락 글리프를 한국어 이유 문구로 교체했다. 12번 활성 내비도 장부로 맞췄다.

- 추적 파일 변경 0. 결과만 untracked `tutorial-delivery/`. 커밋·푸시 없음.
- 아카이브: 최종 ZIP을 다시 열어 CRC·내부 파일 목록·SHA256SUMS 전 항목을 대조한다. 구체 파일 수는 최종 실행 보고에 기재.

## 원본에서 물려받은 한계

도시 컷은 `docs/design/art-audit-20261002/evidence/zoom-1.0.jpg`의 일부다. 04~06은 새 실행의 전후 캡처가 아니라 동일 기존 컷을 카메라/선택/영수증 연출의 대용으로 쓴다. 존의 작업장이라는 표식은 새 역할 지정이며 그 원본 건물의 실제 소유/직업 주장이 아니다. 기존 게임 표식과 원본 화풍의 한계는 그대로 남는다. 가상의 새 건물 생성이나 게임 결과 합성을 실제 관찰로 보고하지 않는다.

풍경 카드와 도시 컷은 계절·스케일이 서로 다른 원본이다. 영지 카드=상징 풍경, 도시=관찰 대용으로 분리했다. 미술 바이블 H비율·실제 줌별 일관성을 새로 승인한 것이 아니다. 초상은 기존 시안의 승인 풀 파생본 그대로이며 얼굴/의상을 수정하지 않았다.

## 이번 작업에서 하지 않은 검증

게임 코드/클릭 UI를 만들지 않았으므로 빌드·LSP·엔진 테스트·브라우저 조작 테스트 대상이 없다. 실제 20분 플레이, 자연 첫 청원 발생, 실제 원장→건물 인과, 정책 효과, 협상 지급·저장 복귀, 반응형/컨트롤러·성능은 미검증이다. 이는 정적 대본·스토리보드 납품 관문과 구분한다. 직접 그림 열람이 이번 산출물의 대응 표면 검수다.

이전 기억에 있던 구 AB/첫 실험 경로는 이 clone에서 찾지 못했으며, 사용자 지정의 최신 `docs/design/art-bible.md`를 이번 기준으로 사용했다. 오래된 기억으로 최신 바이블의 예외를 덮어쓰지 않았다.
