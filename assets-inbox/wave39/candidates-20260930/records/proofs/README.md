# Wave39 확인 그림 합성 계약

- 확인1은 사용자 스크린샷의 세계 영역 `(46,137,1832,1005)`를 고정한 비교다. 위는 원본, 아래는 native imagegen으로 긴 빗줄기만 제거한 clean plate 위에 후보 PNG를 합성한다. 원본의 건물 배치와 도시 구도는 유지하지만 생성 재구성 때문에 미세한 건축·지면 차이가 있다. 런타임 캡처·물리 시뮬레이션 증거가 아니다.
- 새 비는 화면 격자로 복제하지 않는다. 고정 시드 39340930으로 제한된 타원형 비 띠 안에 개별 입자를 놓고, 따로 지정한 지면·지붕 접점에 튐을 둔다. 그림자·젖음·웅덩이는 같은 비 띠의 표면 단서다. UI 영역은 합성에서 제외한다.
- 입자는 원래 작은 픽셀 캔버스로 배치한다. 확인1 전체 그림은 축소되고 하단 부분 확인은 1:1이다. 확인3은 실제 크기 프레임과 32px 사람을 나란히 놓는다. 여러 입자가 들어 있는 바람 시트의 전체 프레임 폭을 단일 빗방울 크기로 해석하지 않는다.
- 확인2는 기존 프로젝트 가을 나무·집·풀·길과 후보 낙엽만 기계적으로 합성한다. 나무 밑 낙엽은 수관 아래, 바람 줄은 길가, 공중 잎은 수관 주변에서 지면 사이에 분포한다.
- 이 정지 합성은 공간적 배치와 크기 확인이며, 실제 움직임의 자연스러움·깊이 가림·수명·충돌 판정은 엔진 설치 후 검증 사항이다.
- 모든 이미지 참조는 프로젝트 소유 그림이다. `references.json`은 원본 경로와 SHA-256, `cleanplate.json`은 실제 편집 프롬프트, `placements.json`은 개별 후보 배치와 시드를 담는다.
