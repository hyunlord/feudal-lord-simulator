# S5 노동 배정 규칙 수정

## S5-F1 / R-2

목책 600틱·40%, 석조 900틱·50%의 기존 행사 기간과 비율은 유지한다. 예약 수는 `min(기존 비율 정수 인력, 자재 완비·활성·미완공 부지 수 × 3)`이다. 자재 대기 부지는 예약하지 않는다. 예약을 여러 준비된 부지에 실제 배정하므로 쓰이지 않는 예약 인력은 0이다. 목표판은 실제 성벽 건축 일꾼 합계를 표시한다.

R1 탐침 B에서 8명 예약·0명 배정, C에서 8명 예약·3명 배정, D에서 3명 예약·0명 배정을 재현했다. R-T3/4는 수정 전 각각 `3 != 0`, `8 != 6`으로 실패했다. 수정 후 자재 대기 예약 0, 준비 부지 2개 예약·배정 6을 검증한다. 저장 상태 필드는 변하지 않는다.

## S5-F2 / R-3

준비된 공사 부지가 있으면 `min(전체 가용 인력, 준비 부지 × 3, max(3, ceil(전체 가용 인력 × 0.2)))`를 건설에 먼저 배정한다. 행사 예약이 더 크면 행사 예약을 적용하며 중복 예약하지 않는다. 자재 대기·완공 부지는 이 수요에서 제외한다. 남은 인력은 핵심 식량 한 사슬을 먼저 채운다. R-T5의 명시적 벌목·제재 유지 조건에 따라 **준비된 공사가 있는 동안 핵심 벌목장·제재소 한 쌍을 중복 식량 시설보다 먼저** 배정한다. 그 밖의 기존 식량 우선 규칙과 인구당 노동력·시설당 요구 인력은 그대로다.

비주택 건물의 상세창에 44×44px 이상 가동 중지/재개 버튼을 제공한다. 중지 건물은 노동력 0, 생산·우물/시장/교회 서비스·시장 판매·곡창 배급 출발을 멈춘다. 진행 중인 배급은 빵을 보존하며 귀환하고, 이미 존재하는 다른 자재 배송 의무는 삭제하지 않는다. 원인 등록표 `operation_paused`와 `시설 가동 중지` 문구로 지도·상세에 알린다. 재개하면 다음 노동력 배정에서 원래 순서대로 복귀한다.

저장 v3: `Building.operationPaused?: boolean`, 누락은 가동 중이다. v2→v3은 기존 게임 상태를 변경하지 않고 봉투 버전만 올린다. 기존 v1/v2 fixture를 보존하고 v3 이전상태 fixture와 **자연 상태에서 농장 하나를 중지한 준비 상태** fixture를 추가했다. 최신 지문은 중지 상태를 포함한다. R-T5/6 수정 전 실패(공사 인력 0, 미지원 action), 수정 후 공사 3·식량 8·벌목/제재 5의 16명 보존과 저장 후 중지 지속·재개를 검증한다.
