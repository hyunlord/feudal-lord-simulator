# 저마다의 영지 — 시제품 화면 기준

## 1. 분위기와 정체성
작은 영지를 내려다보는 지도와 청지기의 짧은 보고. 건물 구입 목록 대신 주민이 선택한 모습이 화면 중심이다. 장부의 얇은 선과 풀빛 지도, 자원·원인·결정의 순서로 읽힌다. 장식보다 서로 다른 도시의 구조가 서명이 된다. 이름 가린 비교 모드도 실제 모델을 그린다.

## 3. 글자
시스템 sans-serif(-apple-system,BlinkMacSystemFont,"Apple SD Gothic Neo","Noto Sans KR",sans-serif). 제목에만 Georgia,serif 후보. 외부 폰트 다운로드 없음. 본문16px/1.55, 작은 설명14px/1.5, 섹션20px/1.3, 제목28px/1.2. 숫자는 tabular-nums. 본문14px 미만 금지.

## 4. 간격과 배치
기본4px. 토큰 --s1:4px,--s2:8px,--s3:12px,--s4:16px,--s6:24px,--s8:32px. 터치 최소44px. 한 영지 화면은 최대480px; 좁은 화면에서는100%. 9:16 viewport를 우선 검사하되 스크롤을 허용해 설명을 자르지 않는다. 비교 화면만 최대1280px,768px 이상3열,그 이하는1열. 하단 내비는 엄지 영역에 sticky, 콘텐츠를 덮지 않음. 지도 종횡비1:1; 독립 상태를 그리며 결과와 무관한 이미지로 대체하지 않음.

## 5. 구성 요소
- 정책 행: 축 이름,범위 입력,비중 숫자. 전체 예산100을 공유하며 초과 입력은 이유를 보여주고 적용하지 않음. 키보드/포커스 지원.
- 결정 버튼:44px 이상,기본/hover/active/focus/disabled 상태. 주 행동은 진한 녹색,그 밖에는 얇은 선. round4px,그림자 없음.
- 자원 장부: 네 재고와 인구,생산·소비 보고. 모자람은 색과 문장으로 함께 표시.
- 지도: 토지·도로·시설·이동 경로. 시설 탭은 실제 선택 이유. 보조 표로 건물 목록 제공.
- 사건 영수증: 시점/주체/결정/비용/이유 합계. 세부항목은 details로 열기.
- 도시/방침/이웃 내비:현재 위치 aria-current,탭 변경 뒤제목 포커스,페이지 상태 유지.

## 6. 움직임과 조작
버튼150ms opacity/transform. 실제 성장은 정산 단계를 순차 표시; 자동 진행 중 일시정지 가능. prefers-reduced-motion에서는 이동 보간 생략. 화면 갱신이 입력 포커스를 잃게 하지 않는다. 저장·재시작·정책 적용은 상태 변화 뒤 짧은 aria-live 보고.

## 7. 깊이
얇은1px 선만 사용,그림자 없음. 지도와 장부 간 여백으로 구분한다. 과한 카드 격자·유료 보상 팝업·가짜 알림 없음. 좁은 화면 가로 넘침은 실패. 본문 확대200%와 실제 브라우저 조작을 검증한다.

## 현재 검수 경계
첫 독립 AI 플레이는118초에 완료했지만 인간 잔존·과금 의사를 증명하지 않는다. 비교 그림은 축 이름과 SVG tooltip을 모두 숨긴다. 전체 정책 이름은 일반 플레이에만 표시한다. 결과 지도에서 경로는 --danger 색의 실제 전투 trace polyline이다. 좁은 화면에서 결과 제목으로 이동하고 키보드 포커스를 준다. 세부 전투 행동과 재고 이름은 한국어로 표시한다. 실제 브라우저390×693 및 너비375/768/1280에서 조작·저장·넘침 검사 진행, Lighthouse 점수는 아직 측정하지 않았다.

## 외형 비교 실험
기본 지도와 저녁 지도 선택은 UI의 CSS 필터 sepia(.25) brightness(.85)만 바꾼다. 무료 시제품 외형 전환이며 실제 결제 상품은 아니다. 모델 정책·명령·재고·전투 조건을 바꾸지 않는다. 이름 가린 세 도시 비교는 색감 차이가 단서가 되지 않도록 기본색을 유지한다. 배색이 실전 정보 가독성을 바꿀 수 있으므로 상태 동등성 시험만으로 상품 공정성 전체를 증명하지 않는다.
