# 검증 결과

**산출물 무결성 PASS / 시각 승인 FAIL / 눈가림 60% 목표 미달.**

- 16 PNG 모두 1024×768 RGBA. 캔버스 가장자리 클리핑 없음, 알파0 RGB 정리, 중복 파일 없음.
- 여름·겨울 8쌍의 바운딩박스 같음. 피벗 아래 픽셀 동일. 겨울 변경은 윗면의 기존 눈 조각이다.
- references 원본 8장의 SHA256이 저장소 원본과 같음. 실제 픽셀 입력 5장, 비교 참고 3장.
- 최종 실제 Chrome 캡처 20장: 방향 검수용 배치 16장 + 원래 성벽 경로 4장. 카메라 줌1.4, 1280×800, DPR1, 시뮬레이션 일시정지.
- 후보는 요청 인터셉트로 브라우저 메모리에서만 그렸다. src/public/package 파일 변경, 커밋, 푸시, 게임 설치 없음.
- 눈가림 이미지는 3배 최근접 확대한 중복 픽셀을 원래 크기로 되돌려 무손실 WebP로 저장했다. 다시 3배 최근접 확대하면 검수 PNG와 전 픽셀이 같다. 전체 장면 JPEG는 이 무손실 주장에 포함하지 않는다. ZIP 안 SHA256SUMS 검증 및 ZIP CRC 검사 수행.
- Python/Node 재현 스크립트 구문 검사. 게임 코드 변경이 없어 게임 단위 테스트·빌드는 이 미술 검수 범위에서 돌리지 않았다.

## 시각 검수

독립 검수 원문과 실패 회차를 보존했다. 최종 정답률78.125%, 비눈가림88점. 남아 있는 흉벽 간격·목책 회전부 밀집 때문에 자연스러움 요구를 완전히 충족했다고 보고하지 않는다.

## 한계

네 방향 배치가 건물과 겹치는 장면은 깊이 순서 확인용이며 배치 가능성을 증명하지 않는다. 추가 원래 경로 장면은 동일 seed의 한 위치다. 임의의 성벽 각도, U위상, 변형 a/b 전 조합, 모든 줌, 연속 애니메이션과 성능은 확인하지 않았다. 고정 조각의 끝에는 최대0.35타일 겹침과 알파 점감이 있어, 긴 직선 띠가 없으면 끝이 흐려 보이는 것은 의도된 연결 계약이다.
