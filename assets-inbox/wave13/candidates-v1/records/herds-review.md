# 무리 시트 제작·검수

- 6개 정지 cluster, 방향 NE·SE·SW·NW 가로 4셀. 보행 2프레임이 아닌 정지 소품이다.
- 해당 동물 보행 시트의 첫 프레임 셀을 정수 좌표로 합성한다. 원본 픽셀 배율·색·알파를 그대로 보존하며 미러링하지 않는다.
- 각 무리 멤버의 접지 y→x 순서로 깊이 정렬. 배치 내역은 metadata-herds.json sourceCells에 기록한다.
- 양 a 4마리, b 5마리. 돼지4·거위 a5/b4·소3. a/b는 단순 색 변경이 아니라 수와 배치가 다르다.
- 그림 안 지면·텍스트·몰이꾼·소지품은 없다. 장날 확인 그림에서만 별도 레이어를 조합한다.
- 셀 크기는 의뢰서에 고정값이 없는 cluster에 한해 잘림을 피하는 크기를 채택한다. 양 b와 소는 a/작은 가축보다 큰 셀이다.

## 최종 시각 판정
최종 동물 시트로 실제 조합·축소 검수를 완료했다. 아래는 관측 순서와 최종 판정이다.

작은 가축 5시트 먼저 확인: 원본 0.5배에서 양의 밝은 타원 몸·돼지의 어두운 길쭉한 몸·거위의 세운 목이 구분된다. 0.3배에서도 세 종류의 무리 색/실루엣은 구분 가능하나, 발·부리·눈의 세부나 프레임 변화는 이 정지 cluster로 판단하지 않는다. a/b의 개체 수·배치 차이는 유지된다. 다섯 시트 모두 외곽 불투명 픽셀 0, RGBA.

소 3마리 무리까지 최종 확인: 6시트 모두 RGBA·외곽 불투명 픽셀 0. 소는 몸집·흰 얼룩·가로로 긴 몸으로 작은 가축과 구별된다. SE/NW는 같은 진행 방향에서 일부 몸통이 깊이 순서로 겹치지만 3개의 머리/몸을 읽을 수 있다. 0.3배에서는 종/무리는 구분 가능하며 작은 다리 애니메이션이나 개체 표정 판독을 보증하지 않는다. `herds-contact.png`는 좌 0.5배·우 0.3배로 실제 표시 배율을 지킨 정지 검사판이다.

## 확인 그림 3: 장날 길

`proofs/03-market-road-zoom.png`는 하나의 대각선 도로에 짐말 3종·소 몰이·거위 떼·돼지치기·기승 상인을 함께 배치한 오프라인 합성이다. 실제 파일 원본의 0.5배와 0.3배를 그대로 사용했다. 몸/짐/인물은 별도 원본이며 각 레이어가 같은 접지를 사용한다. 교정된 가는 기승마와 네모난 회색 양모 적재물을 사용한다. 사용 파일 SHA256·셀·위치·배율은 `herds-market-proof.json`.

자체 판정: 1.0에서는 짐말 행렬, 얼룩 소3마리, 목 세운 작은 거위5마리, 어두운 돼지4마리, 말 위 사람의 구분이 가능하다. 0.6에서도 이 활동의 큰 종류/무리 실루엣은 유지된다. 짐말 세 종류는 황갈색 둥근 자루·밝은 회색 양모·적갈색 직물이라는 색/덩어리 구분은 남지만, 내용을 이름 없이 정확히 맞히는 판독이나 섬유·끈 세부는 보증하지 않는다. 사람 직종은 의복 색만으로 추정되므로 개별 직종 판독을 통과로 주장하지 않는다. 실제 도로 통행·게임 설치·움직이는 화면 검증은 하지 않았다.
