# Wave14 문장·상인 표식·도시 인장·권리 UI 후보

게임에 설치하지 않은 아트 후보입니다. 확인 그림은 오프라인 합성이며 게임 기능 구현·런타임 검증 증거가 아닙니다.

## 납품 구성

의뢰서의 명시 항목 합계는 71개입니다: 문장 34 + 상인 표식 14 + 도시 인장 6 + 권리 UI 17. `assets/`에 최종 PNG, `proofs/`에 확인 그림 4장, `assets.csv`에 자산별 생성·가공·검수 기록을 둡니다. `index.html`과 `IMAGE_LINKS.md`로 개별 파일을 열 수 있습니다.

## 마스크 조합 계약

- A 방패는 3파일입니다. 각 PNG의 흰 부분은 채움, 검은 부분은 외곽선, 알파는 전체 방패 실루엣입니다. 정규화한 휘도를 L, 알파를 A라 할 때 채움 커버리지는 A×L, 외곽선은 A−A×L입니다.
- A 분할·대분할·도형과 B 표식은 흰 RGB 및 알파 커버리지를 사용합니다. 색은 RGB를 원하는 색으로 교체한 뒤 합성합니다. 흰 그림을 반투명 색 위에 그대로 올리는 방식이 아닙니다.
- 분할의 반대쪽은 동일 커버리지의 `1−p`로 계산합니다. 별도 도형으로 다시 그려 이음새를 만들지 않습니다. 방패 바깥은 최종 실루엣으로 자릅니다.
- 상인 표식의 기둥과 가지는 공유 좌표를 사용하며 알파의 최댓값으로 합칩니다. 겹친 획이 진해지지 않습니다.
- 외곽 띠(bordure)의 방패별 적용과 9-slice 고정 영역은 해당 `records/` 제작·검수 기록을 따릅니다.
- 문장 조합은 금속(금·은)과 색의 대비를 지킵니다. 색과 모양의 구별 가능성은 제공한 24개 예시 범위에서 검사합니다. 모든 가능한 조합의 가독성을 보장하는 것은 아닙니다.

## 참조와 기록

첨부 P0·Wave8·프로젝트 자체 그림만 참조했습니다. 실존 가문 문장이나 도시 인장 이미지를 복사하지 않습니다. 역사 전체 문장 데이터베이스와의 우연한 일치 여부를 전수 조사한 것은 아닙니다.

그림 제작에는 builtin imagegen, 정확한 분할·기호에는 결정적 기하 제작을 사용합니다. 실제 프롬프트와 원본은 `raw/`·`records/metadata-*.json`에 보존하며 도구가 제공하지 않은 모델 버전이나 seed는 만들어 적지 않습니다. 조합용 난수 seed와 이미지 생성 모델 seed는 구분합니다.

## 확인 그림

1. 문장 24조합, 256px 및 96px.
2. 상인 표식 16조합, 128px 및 48px, 자루·문 적용 예시.
3. 도시 인장 4종 및 특허 문서에 매단 모습.
4. 첨부 HUD 위의 권리 UI, 1280×800. 설명 글자는 확인 그림에만 있습니다.
