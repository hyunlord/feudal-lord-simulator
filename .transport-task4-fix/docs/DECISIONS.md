# Settled decisions

1. The economic prototype has exactly two two-stage chains: wheat to bread and
   logs to timber. No third production stage is part of the initial experiment.
2. The world uses an isometric view with 64 by 32 screen-space tile diamonds.
3. Population is an abstract census value. Visible walkers are representative
   agents and are never coupled one-to-one with population.
4. Determinism is preserved for the headless balance harness. Presentation may
   use non-deterministic effects later and is not required to reproduce pixels.
5. Housing has four levels, represented by level values 0 through 3.
