# R04 — 자율 성장 모바일 시제품과 실제 무인 리그

실행: Node로 `cd prototype` 후 `node server.mjs`, 브라우저에서 http://127.0.0.1:4179 접속. 패키지 설치 불필요. 실제 검증 환경 Node25.8.2/macOS Chrome. 상세 RUN.md.

8축 자유 혼합 → 빠른 자율 성장 → 이웃 약탈/방어 → 결과와 이유 → 같은 시작 세 도시 비교가 가능한 로컬 세로 웹 시제품이다. PC 엔진을 이식한 제품이 아니라 별도 단순화 모델이다.

## 핵심 발견 셋

1. 같은 시작에서 도시 구성·입지·재고가 달라진다. 625도시 성장 실험과 나란히 캡처를 포함했다.
2. 밸런스 기준은 실패했다. 기본1:1 11,880경기에서 농업1,980전승, 다자19,800경기 중 출전6,600전승이다. 상위 엔트로피0.7925만으로 지배 전략 부재를 주장할 수 없다.
3. 경로·보급·경비 위치와 계약은 결과에 실제 영향을 준다. 그러나 리그 봇의 출정은 모두 양의 예측 수익 약탈에 치우쳤고 군사적 긴장과 맞수는 부족하다.

43개 자동 검사, 소스 식별자 검증, 전체 입력 집합·해시·점수 재검산을 수행했다. 인간 잔존율·실휴대폰 열/배터리·상용 서버는 검증하지 않았다. 무료 외형 상태 불변은 실제 구매상품의 검증이 아니다. 상세 원본 기본리그는 로컬 보존하고 ZIP에는 모든 경기의 압축 결과를 넣었다. 보충 원자료는 전부 포함한다.
