## 1. 만든 것
- **사건 순서**(PL-1, `src/engine/plague.ts`, 설정 `src/content/plagueConfig.ts`, 저장 `state.plague`)
  - 1348 붕괴 시대 → 여름 항구 열병 소문 → 가을 도래(강어귀 도시, 내륙은 겨울) → 교회 묘지·빈 거리 → 도래 +2계절 임금 요구 → 역병이 물러감·버려진 밭 → 1351 노동자 조례 → 1352 재정착 → 1361 두 번째 역병 → 1362~64 3장 끝.
  - F2-A처럼 제 순서이고, 단계 이름은 F0-B 사다리의 것이다(`plagueStage`, 결정 BD1).
- **사망**(PL-2): 인물 단위, 계절 사망일에 사람 층이 부른다.
  - 도래 때 사람의 42~48 %(seed), 계절 몫 20·35·30·15 %.
  - 무게: 노인·어린아이·붐비는 집·도시 안쪽. 가구 전체가 죽는 집이 사는 집의 15 %다(결정 BD3).
  - 영주 가솔도 같은 확률로 죽는다. 영주 가족이 끊기면 새 가문이 선다(BD7).
  - 원장은 `person.died`(원인 `plague`)이고 가계도에서는 고인이다(BD2).
- **빈 필지·회복**(PL-3): 도래부터 3장 끝까지 성장 규칙을 멈춘다(BD4).
  - 회복은 계절마다 도래 때 사람의 0.6 %와 재정착이다.
  - 빈 필지는 사다리가 채우지 않고 황폐에도 세지 않는다. 지대는 0이다.
- **경제**(PL-4): 노동이 줄고, 곡물값은 5분의 4, 장부 분류 넷(`wages`·`statute_fine`·`church_fee`·`entry_fine`)이 생겼다.
- **결정 넷**(PL-5~PL-8, 청원, Wave 21 카드와 1:1, 카드마다 답 둘 `PetitionDef.responses`)

| 결정(청원자) | 답 둘 |

- **3장 끝**(PL-10): 1362부터 도래 때의 70 %면 `resettled`, 늦어도 1364 `calendar`. 연대기 쪽 `stats.plague`, 장 목표 `resettled`, 4장이 시작한다.
