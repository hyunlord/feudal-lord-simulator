# 이전 미평가 369개 단순무작위 50개 판정

정밀도는 확정 하한 **36/50 = 72.0%**, 불명확9개가 모두 실제 결함이면 **45/50 = 90.0%**이다. 따라서 이 표본으로 80% 달성을 확정할 수 없다. 확정 판정만 남긴 36/41=87.8%는 선택된 조건부 수치이므로 대표 정밀도로 사용하지 않는다.

외부 사람이 인증한 결과가 아니라 **AI의 직접 시각 검토**이다. 50개 모두 실제 원본 프레임의 문맥을 보았으며, 사람 관련37개는 각20프레임을 접촉판으로 판독했다. static pixel 또는 코드상의 draw 분류만으로 결함을 선언하지 않았다. 보행 자세가 분명한 채 장시간 고정되거나 지붕/외벽/물 위 부적절한 위치에서 고정된 사람은 TP, 출입구·에일집·길에서 정상 대기인지 구분할 수 없는 파란옷9명은 uncertain으로 남겼다. 정상 대기라고 단정할 증거도 부족해 FP로 강제하지 않았다.

## 추출과 동결

- 모집단: expansion/enhanced-benchmark/MATCHES.json의 outcome=excluded 후보369개, 중복ID 없음.
- 후보ID 정렬 후 secrets.randbits(256)로 생성한 seed를 sample-protocol.json에 먼저 기록했다. 이후 random.Random(int(seed_decimal)).sample(sorted_ids, 50)을 정확1회 실행했다.
- score·유형·이미지 내용 기반 사전 필터/층화/재추출 없음. 호출 구조 확인 과정에서 입력의 첫 몇 행은 보았지만 선택에는 사용하지 않았다.
- sample-frozen.json은 추출 순서와 원래 finding 전체를 보존한다. sample-frozen.sha256으로 동결했다. 판정 뒤 동일 seed로 재현하여 50개 순서 일치 검증.
- 새 홀드아웃 정답 작업과 표본 이미지/판정을 공유하지 않았다. 도구/문턱/게임 코드 변경 없음.

## 단위와 중복

사용자가 요청한 기존 미평가 후보의 실제 정밀도이므로 **후보 단위**로 판단한다. 같은 실제 결함을 다른 카메라/커밋에서 지적한 경보도 그 위치에서 의미가 맞으면 TP지만 고유 결함 수에는 합산할 수 없다. 과거 benchmark의 one-to-one 매칭에서 동일 ROI 추가 경보를 FP로 세는 방식과 목적/분모가 다르다. reviews.json에 같은 도시·자산 원인 상관과 카메라 역변환 좌표가15world-px 이내인 후보 번호를 기록했다. 근접 번호는 중복 검토 힌트이며 자동 동일 인물 확정이 아니다. 이 표본의 TP36을 서로 독립인 새 결함36개로 해석하면 안 된다.

경계 오탐5개는 정상 울타리1, 성벽1, 수관 명암2, 수풀 가장자리1이다. 숲 직선 바닥4개와 백악 바위 절단1개는 참이다. 반복2개는 흰 실타래 복제 군집으로 통·장작·짐상자 정상 재고는 아니다. 정상 재고가 무작위50개에 없어서 그 하위 유형의 정밀도는 이번 추출에서 평가할 수 없다.

## 증거
