# Wave 7 재작업 후보

게임 미설치. 기존 승인본·원본을 덮어쓰지 않은 후보 묶음입니다.

## 수량
의뢰문의 합계는15지만 명시된 항목은 눈5+서리3+판자5+기표2+목재적재물2=17입니다. 누락 없이17개를 교정했습니다. 원본77개를 original-assets/에 바이트 그대로 보존했습니다. 기존64개 중 추가로 지정된 기표2·적재물2도 원본은 보존하고 v2후보만 추가했습니다. 새 후보를 전부 채택할 때 변경되지 않는 종류는60개입니다.

- assets/: 교정17 PNG, 모두 RGBA 분리 레이어, 텍스트 없음.
- proofs/: 오프라인 합성 확인 그림2개. 게임 실행 캡처가 아닙니다.
- assets.csv:17행, 전체 생성 프롬프트·참조·후처리·피벗·검수 기록.
- original-assets/:기존77 PNG 원본 보존.
- sources/·records/: 생성 원본, 정합 마스크, 처리 및 검사 기록.
- index.html: 개별 이미지 링크가 있는 갤러리.

## 확인 그림
1. proofs/01-winter-street.png: 원본 주택에 눈·판자를 제로 오프셋으로 합성. 주택 원본크기×1.0/×0.6; 서리 원본×0.5/×0.3.
2. proofs/02-signifiers-cargo-zoom06.png: 기존/새 기표와 목재 적재물, 실제0.6(소품 원본×0.3) 및 별도 확대 검사. 확대판을 실제줌으로 해석하지 않습니다.

## 검수
- 수작업으로 확인한 실제 지붕 마스크의 alpha>=128 피복률: L0 76.4%, L1 70.1%, L2 78.8%, L3 71.1%, L4 69.1%. 지붕 마스크 밖 픽셀0. 건물 원본불변.
- 눈은 불규칙한 틈으로 기존 초가·기와가 보입니다. 굴뚝 추가 없음.
- 판자5개는 기존 문·창에 두꺼운X. .6에서 엇갈린 막음 형태가 보이며 못·나뭇결은 읽기 어렵습니다.
- 서리3개는128×64, 최고알파128. 평면형태와 낮은 불투명도. 지면 자체를 포함하지 않습니다.
- 기표2개는48×48. 빗장과 보따리의 가로형/둥근형 차이를 우선했습니다.
- 목재2개는96×64, 기존수레 부착점 유지. 여러 판재의 층과 두께를 강조했습니다.

## 한계
피복률은 원본 지붕을 수작업으로 추적한 마스크 기준입니다. PNG에 별도 피벗 메타데이터가 없는 주택은 동일캔버스·오프셋0으로 원본피벗을 상속합니다. 실제 게임 설치·애니메이션·깊이정렬·모든 배경의 대비 검증은 하지 않았습니다. 작은 소품은0.6에서 세부재료보다 실루엣으로 구분됩니다. 미적 최종채택은 사용자 검수 대상입니다.
