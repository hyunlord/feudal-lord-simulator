# 랜드마크 성장 — 역사 근거와 제작 경계

작성·외부 자료 확인: 2026-10-03. 범위: 남부·남동부 잉글랜드, 1300–1450. 상태: 기획용 역사 검토, candidate, 설치 승인 아님.

## 기본 판정

아래 화살표는 한 공동체가 선택할 수 있는 투자·증축 시나리오다. 잉글랜드 모든 마을이 같은 연도에 밟는 보편적 발전사가 아니다. 1300년 이전에도 석조 교회, 탑, 유리창과 벽난로를 갖춘 부유한 장원이 있었다. 목재 건물은 후기에도 존속하고 새로 지어진다. 시작부터 석조 교회가 있는 정착지, 끝까지 성벽 없이 번성하는 시장도시도 허용해야 한다.

새 연대 도달보다 후원 재력, 교구 모금, 거래량, 시장·통행 관련 권리, 영주와 공동체의 합의, 교량 유지 조직을 성장 동기로 삼는다. 아래 동기는 역사 자료를 참고한 **게임 설계 제안**이지 당시 법률의 자동 조건표가 아니다.

현재 로컬 기준 `docs/design/art-bible.md`의 ART_BIBLE_v2(2026-10-02)를 우선했다. 참나무·따뜻한 석회칠·잡석·평기와, 정사영 2:1 등각, 좌상광, 과장된 검정 튜더 목골·흰 패널·푸른 반사 유리 금지를 유지한다. 교회 창과 부유한 장원의 굴뚝은 일반 오두막 금지를 기계적으로 적용하지 말고 건물별 예외로 기록한다. 이 문서는 현존 외부 건축물 사진을 생성 참조 이미지로 사용하도록 허가하지 않는다. 외부 링크는 텍스트 역사 근거이며 시각 참조는 프로젝트 소유 자료를 사용한다.

## 장면이 보존해야 할 것

증축 전후에 문 위치·주 홀 축·제단 쪽 몸체·교량 접속점 등 최소 두 기준점을 유지한다. 이것은 게임 가독성을 위한 미술 계약이며 역사적으로 모든 공사가 정확히 같은 필지를 유지했다는 주장은 아니다. 측랑·부엌·날개·문루가 붙는 방향과 단계별 영역 확대를 도면/메타데이터에 기록한다. 원래 목재가 전부 석재로 바뀌는 색상 교체만으로 성장시켜서는 안 된다.

교회 C4에서도 대성당 규모·16세기 과잉 장식 대신 작은 교구 교회 범위를 유지한다. 시장 M3와 길드홀 U3는 동일한 건물처럼 보이지 않게 기능 공간을 달리한다. 여관은 작은 술집과 구별되는 말 통로·숙박동이 읽혀야 한다. 해자 저택과 도시 성문은 병합하지 않는다.
