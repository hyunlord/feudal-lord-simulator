## Phase 18 — 후기 시대의 불필요한 목책 제안 계산 제거
- 커밋: 제품 `401e9d4` (2파일, 기준 `e05b46c`). 증빙 커밋은 Git 이력 참조.
- 바뀐 것: 목책 초기 제안 계산은 촌락 시대에만 수행한다. 목책·석조 시대는 쓰지 않는 제안을 null로 표현한다. 새로운 캐시·메모이제이션 없이 조건 하나로 계산 범위를 줄였다.
- 측정: 후기 시대의 제안·점유 계산이 모델100호출당100→0회, 촌락100회는 유지됐다. 동일 도시·기기에서 DPR1 진행 중앙값33.3→16.7ms, DPR2 진행50→33.3ms. DPR2 정지는33.3ms로 동일하며60FPS를 보장하지 않는다. 전체6조건은 performance.md 참조.
- 테스트: typecheck / 전체 회귀1525/1525(Phase9 포함, 실패·생략0) / build 통과. dist 18,666,012바이트. 실제 UI5개 시나리오 기준·후보 동일. LSP는 설치되지 않아 실행하지 않았으며 실제 TypeScript 타입검사는 통과했다.
- 확인 못 한 것: 촌락에서 숨겨진 제안 계산까지 생략하지 않는다. 시뮬레이션·목책 기하·배치 규칙·이미지·렌더러는 변경하지 않았다. 기존 JS500KB 권고 경고와 작은 UI 글씨·하단 잘림은 남는다.
- 사용자 결정 필요: 없음. 개발 브랜치만 반영하며 main 병합·Pages 배포는 하지 않는다.

변경 파일은 `src/ui/EraConsole.tsx`, `tests/eraConsoleModel.test.ts`다. 촌락의 실패 이유·편집·선택 구간·확정·취소를 유지하고, 후기 시대의 화면에 표시되지 않는 제안 텍스트만 빈 값으로 표현한다. 이후 시대에 목책 초기 제안이 다시 필요해지면 이 조건을 검토해야 한다.
