# Wave41 추가분 — 숲 가장자리와 폭1 여울

상태: candidate, ART_BIBLE_v2 기준. 승인된 영주화면 부품40장 및 기존 Wave41 재작업29장은 수정하지 않았다.

- 숲 바닥↔풀밭 전이띠: 여름·겨울2PNG,512×64 RGBA. 위 풀밭/아래 숲바닥. X방향512px(제작4칸) 반복. Y양끝8px 투명+안쪽8px페이드. 피벗(256,32). Wave22 boundary 규격을 계승했다.
- 폭1 여울: NE/NW × 여름/겨울4PNG,512×256 RGBA. 피벗(256,128), 제작타일128×64. `w1`은 건너는 수면구간1칸이며 횡단 통행폭도 기존 Wave34와 같이 약1칸. 반복 자산이 아니다.

## 사용 및 검토
전이띠는 기존 두 지면 경계 위에 합성한다. `proofs/strip-*-repeat-composite.jpg`의 위쪽은 기존 지면 직접접합, 아래쪽은 같은 지면에 후보3회 반복 합성이다. 원본 지면의 입자감 자체는 본 작업범위가 아니다. 동일 띠를 긴 거리에서 반복하면 낙엽 군집의 리듬이 보일 수 있다.

여울은 해당 방향별 파일을 사용하고 좌우반전으로 광원을 뒤집지 않는다. 열린 얕은 물·자갈·짧은 양안접속을 유지한다. 엔진 소켓 연결, 실제 수면 셰이더/흐름 및 줌/DPR 성능은 게임에 설치하지 않아 미검증이다.

## 제작 출처
내장 image_gen.imagegen을 사용했다. 입력은 프로젝트 자체 Wave22·34 자산이며 실제 프롬프트/입력해시/생성경로와 후처리는 records에 기록했다. 모델 이름과 seed는 도구 미제공으로 null이다. 생성 원본은 raw에 보존하고 경량ZIP에서는 제외한다. 기존 원본 파일 및 게임 코드는 변경하지 않았다.
