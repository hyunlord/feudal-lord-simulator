결과 관측이 없으면 정본 조건 미충족/관측 범위와 구분한다. 도구가 다른 실질 결정을 만난 경우 자동으로 답하거나 화면 결함으로 분류하지 않는다. 실제 효과 증거 부족과 화면 노출 실패도 별도로 분류한다. 결과 카드 자동 열림은 요구하지 않고 수동 열기와 자동 칩 집계를 구분한다.
