# 독립 시각 검수 — 후보 검수 통과

직접 제작한 3장 결정·연대기 10장을 제외한 48장을 각각 납품 해상도로 열어 확인했다. 해당 10장은 주 담당자가 별도로 검수했다. 최종 수정본과 확인 그림 3장까지 재확인했으며 현재 미해결 시각 지적은 없다. 모든 파일의 검수 시점 SHA-256은 independent-review.json에 기록했다.

## 관찰

- 빈 거리·장례 들것·새 무덤, 노동자 이동·청원·비폭력 추격, 도시 인장·후계·봉인된 기록은 서로 다른 행동과 구도로 읽힌다.
- 1381 장면은 징수원이 달아나는 모습이며 접촉 폭력·피·시체 노출이 없다. 종이·책·표식에 읽히는 문자나 숫자는 발견하지 못했다.
- 지붕 굴뚝 교정본을 다시 확인했다. 3장 재정착의 중간 수정본은 질감 손상으로 반려했으며 원본에서 새로 수정한 v6에서 해결했다.
- 확인 그림은 사건 8·결정 4·연대기 6을 줄별로 구분한다. 마지막 판에는 장 끝 3종과 캠페인 종료 그림이 함께 있어 정서 변화를 비교할 수 있다.

## 한계

- 법령의 정확한 이름·연도와 협상/청원의 법적 차이는 게임 문맥이 필요하다. 그림만으로 역사 사실을 증명하지 않는다.
- 육안 검수 판단이며 OCR 검사나 외부 역사 전문가 감정은 아니다.
- 장 끝 도시들은 연속성을 암시하지만 같은 지도 좌표를 재현한 측량적 장면은 아니다.
- 오프라인 후보 검수이며 게임 설치·DPR·실제 플레이 가독성 검증은 하지 않았다.
