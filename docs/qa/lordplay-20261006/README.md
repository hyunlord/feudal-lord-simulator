## 파일 구성

JPEG는 보고서에 연결한 대표47장만 포함한다. 원본1600×1100 캡처이며 그림 편집·합성·재압축 없이 복사했다. 번호는 촬영 순서이고 일부 이름의 연도는 예상으로 붙였으므로 **실제 연도는 화면 HUD와 본문**을 기준으로 한다. 112번은 캡처 실패로 없으며 번호 연속성은 보장하지 않는다. 전체 원시 캡처·작업 메모는 로컬 작업 폴더에 보존하고 이 경량 ZIP에는 넣지 않았다. 문서가 링크하는 증거 그림은 모두 포함했다.

저장은 gzip 압축한 브라우저 저장 묶음7개와 각 묶음의 최신 슬롯7개다. `SHA256SUMS`는 자기 자신을 제외한 모든 파일을 다룬다. SHA 목록의 정확한 파일 집합·압축 CRC·깨끗한 재압축 해제 후 해시·문서 상대 링크를 확인한다. 개발 서버와 이번 브라우저는 종료했다.
