# Wave23 독립 검수

판정: **후보 제작 범위 통과, 91점. 축소 의미 판독 한계 명시.**

검수자는 새 4종을 제작했으므로 새는 독립 검수 범위에서 제외하고 총괄이 검토한다. 다른 담당자의 **78 PNG**와 확인 그림 4장을 열람했다. 최종 파일별 SHA256과 독립 재계산은 `independent-review.json`에 있다.

- 날씨 14종: 밝고 어두운 바탕, 비·파문 4프레임, 3×3 반복, 같은 마을 네 상태를 확인했다. 개별 불투명도 상한 14종과 합계 0.38 스트레스 합성에서도 건물·길·숲·UI를 읽을 수 있다. 모든 상한을 동시에 쓰는 것은 금지다. 낮은 강도에서는 반복이 두드러지지 않으며, 원본 강도에서는 약한 주기성이 남는다.
- 마을 생활: 지상 동물 8장과 소품 8장 원본·확대·마을 합성을 확인했다. 닭·개 8방향쌍의 보호 영역 RGBA 차이를 직접 재계산하여 모두 0을 확인했다. 개 NE의 다리 마스크가 꼬리 아랫부분과 닿는 문제를 발견했고 보호 범위를 넓힌 수정본을 재검토했다. 현재 변경 픽셀은 다리·발에 남는다.
- 인물 상태: 서로 다른 초상 12명, 96/48 장식 24장을 확인했다. 보호 원 안의 알파가 24/24 모두 0이다. 얼굴을 다시 그리거나 흑백화하지 않았다. 96px에서는 직책 막대·단일 열쇠·열쇠 꾸러미가 구별된다.
- 왕실·패드: 두 문장의 256/96, 패드 10종의 48/32를 확인했다. 세 사자의 passant guardant와 프랑스 ancien 백합 다수 분포·4분할이 맞는다. 32px에서도 글자와 버튼 계열이 구분되며 브랜드 색·로고는 없다.

## 남는 한계

소 몸통 31.30px ×0.24와 같은 비례를 지키면 작은 동물·장난감은 줌0.6에서 종과 세부를 안정적으로 구별할 수 없다. 이를 가독성 통과라고 하지 않으며 세계 합성에서 임의 확대하지 않았다. 48px 초상 장식의 실제 모티프는 약14px라 요람이 작은 배처럼 읽힐 수 있고, 검은 상중 리본은 어두운 바탕에서 대비가 낮다. 정확한 상태명은 UI 문구를 병행하는 것이 좋다.

후보의 오프라인 검수이며 실제 게임 설치·카메라·애니메이션·성능 검증이 아니다. 확인 그림의 축소는 화면 리샘플링이다. 방패 형식은 heater지만 기존 마스크와 픽셀 동일 외곽을 주장하지 않는다. 미검토·대기 항목은 없다.
