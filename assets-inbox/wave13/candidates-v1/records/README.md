# Wave13 — 수레·짐말·기승자·가축 후보

게임에 설치하지 않은 후보 묶음. 의뢰서의 ‘약40’ 대신 명시된 ID를 모두 세어 **34 PNG**(동물8, 수레·짐·기승자8, 워커4+소지품8, 무리6), 확인 그림4장, CSV34행을 제작한다. 기존 Wave11 및 승인 원본은 변경하지 않는다.

## 파일과 레이어 계약

- `assets/animal_walk`: 방향 열 NE·SE·SW·NW, 위아래 두 다리 프레임. 종별 셀 크기는 의뢰서 그대로다. 몸통·머리·꼬리 보호 영역은 첫 프레임 픽셀을 복사하고 다리만 교정한 통제 합성이다. 자유 생성한 두 장이 우연히 일치했다는 주장이 아니다.
- `assets/cart`: 빈 몸체, 끄는 동물·몰이꾼·화물 미포함. 두 행은 바퀴 교대 프레임. 방향별 결합·화물 기준점은 `records/`의 수레 기록을 따른다.
- `assets/pack`, `assets/rider`: 말 셀96×80의 투명 오버레이. 정적인 두 행은 같은 픽셀로 유지하며 다리 움직임은 아래의 말 레이어가 맡는다.
- `assets/workers`: 74×74 셀, 4열×2행. 파일럿2 방식 의복 재스킨. 머리·손·다리·발과 원본 실루엣을 보존한다. 소지품은 별도 `assets/work`.
- `assets/herd`: 개별 동물의 첫 프레임을 깊이 순서로 배치한 정지 무리 4방향 시트. 보행 애니메이션 시트와 구분한다. 반전 없이 해당 방향 그림을 쓴다.

## 출처·검수

프로젝트 자체 참조만 사용했다. `references/`는 첨부 원본, `sources/`는 추가 프로젝트 템플릿, `raw/`는 실제 생성 결과다. 전체 실제 프롬프트·원본·후처리는 `assets.csv`와 계열별 metadata에 기록한다. 도구가 제공하지 않은 모델 버전·seed는 미제공으로 기록한다.

등각 손그림, 낮은 채도, 참나무 수레, 저채도 양모·린넨 복식이며 긴 그림자·텍스트·구운 지면은 후보 이미지에 넣지 않는다. 확인 그림의 설명 글자는 검사판에만 있다.

원본 크기의0.5배를 줌1.0,0.3배를 줌0.6으로 검사한다. 확대 비교판과 실제 축소 판독을 구분한다. 실제 제품의 이동·충돌·캐시·가림·DPR·성능은 이번 후보 제작 범위가 아니다.
