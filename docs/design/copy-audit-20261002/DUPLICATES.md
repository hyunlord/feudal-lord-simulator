# 반복 문구 후보와 판정

Korean 글자가 6개 이상인 단일 행 따옴표·템플릿 리터럴의 정확 일치를 기계 추출한 **82묶음**이다. 템플릿 중첩을 완전히 파싱한 문장 수가 아니므로 분류 전 후보 수를 결함 수로 쓰지 않는다. 한국어 전체 행 읽기와 수동 대조를 함께 수행했다. 나머지 짧은 공통 버튼·명사는 용어 통일 대상으로 다뤘다.

CA-049~051의 세 묶음은 별도 수정 권고로 집계했다. 다른 반복은 같은 사건·상태의 일관된 재사용 또는 메타데이터이며, 화면마다 다른 문장을 만들 필요가 없다.
