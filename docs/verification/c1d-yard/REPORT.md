# C1d 앞마당·마당 적응층 + 구역 조작 마찰 — 보고서

작업: Claude Code(렌더 세션). 브랜치 `claude/c1d-yard`, 기준 본선 `dd75d33`.
엔진 파일(`src/engine`·`src/state`·`src/save`·`src/content`·`src/zones`)은 한 줄도 바꾸지 않았다. 규칙 함수는 읽기만 한다(`buildingRoadAccessTiles`).
명세는 [건물 주변 땅](../../design/building-ground.md), 결정은 [결정 목록 BG1~BG4](../../decisions/README.md)에 있다.

## 만든 것
- **앞마당**: 건물(밀밭 제외)마다 도로 접점이 가장 많은 변 하나에 둔다. footprint 안 0.1칸에서 시작해 리본의 보이는 가장자리(중심선 ± 0.325칸)를 지나 0.12칸 더 들어간다.
  - 흙길 v1의 불투명 띠 밑이라, 리본 자체의 부드러운 가장자리가 이음이 된다.
  - 색은 리본의 crown 무늬(흙/석재는 접점 칸을 따름)를 75%로 칠하고, 밑에 흙 30%를 깐다.
  - 리본 어깨 풀덤은 앞마당 0.3칸 안에 두지 않는다.
- **마당**: footprint를 0.5칸 키우고 모서리를 0.35로 둥글린다. 1/8칸 부분칸 집합으로, 도로 envelope·물·바위·숲·다른 footprint·성벽(다른 쪽 또는 0.15칸 안)·먼저 차지한 마당을 뺀다.
  - 차지 순서는 건물 목록 순(완공 순)이다.
  - 마당 안에서는 구역 채움(필지 톤)을 잘라내고, 흙 20% 톤과 8~12px 흙·풀 얼룩을 그린다.
  - 소품(울타리·텃밭·통·장작)은 Wave 4c 뒤로 미뤘다.
- **접지 그림자**: 곡선 지면에서 건물 접지는 물체 패스의 타원 하나다(footprint 마름모 반폭의 0.5배, 건물 바로 앞에 그림). 지면 청크에는 넣지 않는다.
  - 옛 지면 패스 앞길·기단 그림자는 곡선 지면 끔(V1)에서만 남는다.
- **조작 마찰**
  - 휠은 항상 확대다. 붓 크기는 `[` `]`와 붓 1/2/3칸 버튼으로 바꾼다. 안내 문구도 고쳤다.
  - 도구만 켜면 커서 원만 보이고, 칸 미리보기·예측 문구는 드래그(또는 다각형) 중에만 나온다.
  - 경작지 획은 도로 접근이 없는 칸을 옅은 빗금으로 표시하고 "도로 접근 없는 칸 N" 예측 줄을 띄운다.
  - 성벽에 걸친 획은 성 안 칸만 붉다(거부는 엔진 그대로).
- **획 끝 프레임**
  - 구역만 바뀌면 장면 재계산을 한 실시간 프레임 미룬다.
  - 구역만 바뀐 청크는 프레임 예산(래스터 4ms·프레임 8ms)을 넘으면 한 프레임 더 옛 그림을 쓴다. 3프레임 기다린 청크는 한 프레임에 하나씩 반드시 다시 그린다.
  - 구역 준비 비트는 구역을 그리는 청크에만 붙고, 도로 청크에는 붙지 않는다.
- **장면 키**: 건물 서명을 넣었다. 공사 현장은 놓일 때 이미 타일을 가지므로, 완공 때는 건물 목록만 바뀐다. 이 결함은 실제 입력 장면에서 찾았다.

## 엔진(C1c)에 넘길 것
1. **종류별 규칙 활성화**(C1b에서 이어짐): `src/zones/zonePlacement.ts:57`·`:68`.
2. **획 되돌리기 액션**: 렌더는 Z 키에 연결만 하면 된다.
3. **성벽에 걸친 경작지 획**: 지금은 획 전체를 거부한다. 성 밖 부분만 받는 규칙은 엔진 몫이다(표시는 이미 성 안만 붉다).
4. **경작지 도로 접근**: 미리보기는 "그 칸을 덮는 2×2 밀밭 자리 중 도로 접근이 있는 곳이 있는가"로 센다. 경작지 구역 자체의 진단(원인 등록표)이 생기면 그 판정으로 바꾼다.
5. **자동 진행 반복 시도**(C1b에서 이어짐): 구역 있는 도시에서 자동 진행의 집 배치가 거부를 되풀이할 수 있다.
6. **공사 현장과 타일**: 현장이 놓일 때 타일의 `buildingId`가 바뀌고 완공 때는 그대로다. 렌더는 건물 서명으로 대응했다. 엔진이 완공 때 타일 배열을 바꾸도록 바꾸면 이 서명은 없어도 된다(바꾸지 않아도 된다).

## Wave 4c 울타리 조각 규격 요청(마당 둘레용)
마당 윤곽은 칸 축에 나란한 직선이 대부분이다(1/8칸 격자, 모서리 반지름 0.35칸이 45° 계단으로 근사됨). 그래서 곡선 strip보다 축 방향 모듈이 맞다.
```
ROLE: object / 마당 울타리(엮은 울 wattle, 말뚝 울 paling 두 계열)
SOURCE_SIZE: 직선 판 1칸 128×96, 반 칸 64×96, 모서리·끝 말뚝 48×96, 문(틈) 128×96
```
