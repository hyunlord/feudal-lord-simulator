# 습지·개방지 seed3 성장 방침 150년 비교

**습지는 최종 인구가298명 적고 금고가425,610페니 많았다. 기근 코드 사망은261명 더 많았다.** 이는 동일 seed3의 두 경로에서 관측한 차이다. 습지가 직접 사망을 늘렸거나 금고를 개선했다는 인과 판정이 아니다. 실제 영지 취득·명령·세력·직업 경로도 서로 달라졌다.

두 판 모두 HEAD5fb1aeb, fixed growth, dues1000, subsidies[]를 유지하며1450/t600000에 도달했다. 습지 코드 종료0, 자체시간1184초·공식COMMAND_S1187초다. 각150행·38개 codec 검사 기록을 읽어 확인했고 명령 연간 합계 및 tick별 분류가 원시 commands와 일치했다. 엔진·SSH를 새로 실행하지 않았다.

## 관측 단위와 검증 범위

periodYear1300–1449는 명령·역사 집계의 반개구간이다. 인구·금고·재고는 다음 해 경계1301–1450의 스냅숏이다. `ANNUAL.csv/json`150행과 `BLOCKS25.csv/json`6행은 이를 두 열로 분리하고 차이를 **습지−개방지**로 기록한다. 사전 `records/fen-comparison-design/CONTRACT.json`의 기준을 유지했다. 음수 사망 누계 차분은 두 판 모두0건이다.

습지 manifest25개는 모두 실제 파일 SHA가 일치했다. 개방지 승계판은 경량화되어 옛 manifest22개 중13개만 현 경로에서 확인되며 latest/progress/runner-unit·중간 저장6개는 제외돼 있다. 분석에 사용한 years/commands/start/final/summary 등은 존재하고 SHA가 맞는다. 제외된 파일까지 이번에 다시 검증했다고 쓰지 않았다. 엔진 소스9개 metadata SHA는 두 판이 같고, 현재 로컬 probe 소스 SHA도 사전 설계와 일치한다. metadata에는 원격 probe 전체 SHA가 없으므로 원격 실행기 바이트 동일성은 부모의 전송 증거를 함께 봐야 한다.

## 영지·세력·직업

두 판 모두 영지4개가 관측됐다. 홈과 이웃1·2의 최종 명의/점유는 같지만 neighbour3는 개방지 person:est-000004, 습지 lord다. 부모 원장 분석과 연결할 실질적 경로 차이이며 지형만의 재정효과로 환원할 수 없다. 권리 조각별 상태와 최초/최종 관측은 SURFACES.json에 보존했다. 연말 표본은 연중 일시 이전을 완전히 열거하지 않는다.

세력9개를 같은 ID로 대조했다. 최종 overlord 관계 −40/−50, merchant_house_1 −97/−100이며 crown30·bishop100·town100 등 같은 끝값도 있다. 관측 수장 수는 merchant_house_1의19/17, merchant_house_2의21/19다. 수장 교체의 모든 순간이나 관계 변화의 원인은 이 표본으로 확정하지 않는다.

관측 직업은 개방지15종·습지17종이며 습지는 spicer(1363경계)·vintner(1364경계)가 추가 관측됐다. 이는 trades.households의 가구 분류다. 최종 제분 직업 가구는 두 판 모두1이며 방앗간 건물 수13/26과 같은 개념이 아니다. 최종 수·최소/최대·첫 관측 경계는 SURFACES.json에 있다. 도시 전체 종사자 분포·생산량은 아니다.
