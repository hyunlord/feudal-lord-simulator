## B. 청지기 3표정 — 같은 얼굴 (3장)
첨부 `검토_청지기_3표정_같음.png`. 96px에서 구별돼야 한다.
- neutral: 유지
- **concern**: 눈썹 안쪽 올라감 + 미간 주름 + 입 다물고 아래로 + 시선 살짝 아래 + 고개 약간 숙임
- **success**: 눈 살짝 가늘어짐 + **입이 분명히 벌어진 웃음** + 고개 약간 듦
얼굴형·옷·틀 동일. 확인 그림: 96px 세 장을 무작위 순서로 섞어 놓고 스스로 맞힐 수 있는지 판정. **통과 기준: 섞어도 맞힘.**

## C. 아이콘 중복·불명확 (5장, 해당 시트 재출력)
같은 모티프가 다른 뜻에 쓰였다:
| 문제 | 바꿀 것 |
|---|---|
| 망치 손 ×3: 층위 `직접`, 원인 `노동`, 목표 행동 `열기` | `직접`은 유지. 원인 `노동` → **일꾼 두 명 실루엣 + 삽**. 목표 행동 `열기` → **열린 문 + 화살표** |
| 두루마리 ×2: 층위 `방향`, 원인 `권리` | `방향` 유지. 원인 `권리` → **인장 찍힌 서류(접힌 문서)** |
| 책 ×2: 목표 행동 `도움`, 잠김·새로움 `도움말` | 목표 `도움` 유지(책+촛불). `도움말` → **물음표 배지(원형)** |
| 원인 `접근`이 읽히지 않음(튜닉? 교차로?) | → **길 위 수레 바퀴 자국 + 화살표** 또는 **막힌 길(통나무 가로막음)** |
재출력: `icon_cause_family_sheet` v2(노동·권리·접근 교체), `icon_objective_action_sheet` v2(열기 교체), `icon_lock_new_sheet` v2(도움말 교체). 나머지 셀은 그대로.
