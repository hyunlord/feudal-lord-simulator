# 판자 재작업 내부 검수

기존 얇은 가로 살 대신 각 문·창에 굵은 X자 두 판자를 생성했다. built-in imagegen으로 원본 주택 5장을 각각 편집 입력했고, 원본 생성 PNG·전체 프롬프트를 보존했다. L2 대표를 먼저 등록·합성·검수한 후 나머지 4종을 진행했다.

문·창 좌표는 baseline 기록의 native opening rectangles를 사용하고 원본과 대조했다. 생성된 연결 성분을 개별 crop으로 추출해 각 개구부에 맞추었고 판자가 창틀보다 1px 바깥으로 나가도록 등록했다. 그림을 절차형 판자로 대체하지 않았다. 생성된 RGBA를 보존하며 각 조각에 비균등 크기 맞춤이 들어간다. 원본 주택과 최종 오버레이는 같은 캔버스, 원점 (0,0)이다.

L0–L4 합성판을 실제 native 크기 및 native×0.6으로 확인했다. 작은 크기에서 X자 폐쇄 표식은 뚜렷하며, 못·나뭇결 상세는 약해진다. 밝은 참나무 판자는 기존 갈색 목골조와 구별된다. 건물 밖·지붕 위에 뜬 판자는 없다. 원본 주택은 수정하지 않았다.

5개 RGBA의 투명 테두리와 등록 마스크 밖 alpha 0을 측정했다. 상세 좌표·crop·해시·검수는 boards.json, 확인판은 boards-l0-composite.png~boards-l4-composite.png에 있다. 고정 방향 정적 후보이며 게임 설치·실제 줌 UI·가림 검증은 하지 않았다.
