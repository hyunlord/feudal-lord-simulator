# 시설 10종 독립 시각 검수

검수 대상: 최종 assets의 시설 PNG 10장, 첨부 기준 well/storehouse/mill-v2/market_active-v2/market_quiet-v2/chapel-v2, 최종 checks/03-farms-facilities.png. 실제 이미지를 열어 비교했다. 합필 생성 담당자가 시설 생성과 분리하여 검수했다.

## 판정

후보 제출 시각 검수 통과. 같은 SW 등각 시점과 프로젝트 재료·색 계열을 유지한다. 장식 색만 바꾼 변형은 없으며, 지붕·부속물·좌판 구성의 차이가 보인다. 게임 실행 검증은 수행하지 않았다.

## 축소와 역사 표현

- 확인 그림의 시설 원본 크기 패널 및 0.6배 복제에서 주요 실루엣 구별이 남는다. 작은 물통의 개별 판자, 저울 추, 상품 세부까지 읽힌다는 뜻은 아니다.
- 기준 그림 자체가 이미 풍차 형태이며, 새 windmill은 이를 더 분명한 독립 기둥 풍차로 변형했다. 기준을 물레방아라고 관찰한 것은 아니다.
- 지붕은 작은 평평한 직사각 기와의 겹침으로 읽힌다. 굴뚝 통·유리 판·현대 보도나 금속 울타리·S기와의 명백한 표현은 보이지 않는다.
- chapel_stone은 다른 예배당보다 종걸이와 처마가 약간 낮으며, 기본 석조 교회 실루엣을 공유한다. 구별은 버팀벽과 현관 부재에 의존한다.

## 파일 규격 확인

Pillow 읽기 전용 검사로 시설 10장의 RGBA 알파 바운딩 박스를 확인했다. 우물 72×80, 창고 160×136, 풍차 142×142, 시장 224×224, 예배당 133×133 모두 요청 치수이며 사방 완전 투명 여백 8px 이상이다. 피벗은 PNG 외부 데이터 계약 사항으로 부모 작업의 technical-qa 검증 대상이다.

## 범위의 한계

검토한 축소 패널은 오프라인 합성이다. 게임 내 실제 렌더 스케일·가림·배치·피벗 적용을 실행해서 검증한 결과가 아니다. 모든 에셋은 candidate이며 설치 승인이나 런타임 검증을 대신하지 않는다.
