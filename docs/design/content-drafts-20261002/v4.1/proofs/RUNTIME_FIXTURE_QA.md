# v4.1 실제 엔진 단위 검증

실행 위치: Mac. 125년 장기 판·세계 tick 전진·분포 측정 없음. 실제 v49 저장 fixture를 읽고 연도와 압력 상태를 지정한 합성 단위 fixture이다. 엔진은 HEAD813b31f 스냅샷 그대로, generated 콘텐츠 두 모듈만 외부 JSON을 가리키는 메모리 로더로 연결했다. 저장소 코드 변경·커밋·푸시 없음.

## 한계

합성 fixture의 사건·수장 변경은 반복 계약을 검증하기 위해 만든 상태이며, 125년 판에서 그 맥락이 몇 번 발생하는지 증명하지 않는다. 조합된 협상 fixture는 수락·거절·기한 보류 명령 경로를 검증하며, 혼인 후보 생성기의 별도 타당성 시험은 아니다. 표면 검증에서 제안 객체를 구성했으므로 무작위 전체 스케줄러가 그 사건을 선택하는 비율을 측정한 결과가 아니다. 실제 후보 함수의 추첨 조건은 별도 seed 탐색으로 통과했다.

실측 분포 목표 달성 여부는 확인하지 않았다. 콘텐츠 원고·사료·JSON Schema는 부모 편집자의 별도 검증 범위이다.

증거: FINAL_SUMMARY.json, fixture-results.json, recurrence-results.json, missing-results.json, surface-results.json, dues-results.json. 입력 해시는 FINAL_SUMMARY.json에 기록.
