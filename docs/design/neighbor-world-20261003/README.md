## 데이터 경계

기준: `hyunlord/feudal-lord-simulator`, `codex/phase15-organic-ground`, commit `618c5ec28b2c191e85e0b448da7e0739660ad88a`.

`records/`에 원본 문서 해시, 엔진 계약·JSON Schema, 초상 원본 ID·경로·SHA256, 검증 스크립트와 결과를 넣었다. 원본 PNG를 ZIP에 복제하지 않아 가볍게 유지했다. 원본과 대조하는 스크립트는 현재 전용 클론 경로 `/Users/rexxa/fls-astra-world`를 사용한다. 다른 환경은 경로를 바꾸어야 한다. 기록용 생성기는 검수 기록이며 게임 코드가 아니다.
