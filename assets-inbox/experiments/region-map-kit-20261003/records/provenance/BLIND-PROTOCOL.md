# 사전 고정 눈가림 절차

2026-10-03. 최종 출력 전에 고정한 절차.

- 표본은 지정된 5유형×seed17/83/241와 이웃18영지판, 총16개 전부다. 보기 좋은 표본을 골라 제외하지 않는다.

- 각 쌍의 좌우는 사전 정한 결정론적 무작위 순서로 배정하고 정답 키는 검수자에게 주지 않는다.

- 질문은 ‘연속된 한 장의 그림과 키트 조립 그림 중 어느 것이 조립본인가’. 선택·확신·시각적 근거를 답하게 한다. 70% 목표를 알려주지 않는다.
