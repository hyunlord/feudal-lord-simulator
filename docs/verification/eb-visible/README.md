# EB-WEIGHT 실제 저장 장면 화면 검증

판정: **수동 연대기 연결 4쌍 확인, 전체 가시성 기준 미충족**. DGX의 실제 자동 성장 관측 저장을 불러온 캡처이며 자연 사람 플레이가 아니다. UI·엔진 코어 수정 없이 기존 화면을 검사했다.

## 출처와 검증 범위

- 실행 `render-EB-visible-smoke-be2c05f`, 깨끗한 화면 소스 `be2c05f3bb555697bc6c750290c6abe2f151c754`, DGX 종료0·명령149.1초.
- 저장 소스 `2485af40046793f1856829fa1161dc4431942aa7`, seed1·15년 실제 관측. [저장/검증](../eb-weight/checkpoint15/validation.json), [원본 manifest](source-manifest.json). 저장 입력 manifest SHA-256 `20afdb37bf07735499d25fc5c59a82c527097b06267b3ec17e4a7553a426cd9e`.
- 1280×800, `run=false`, 11사례·PNG46장. 모든 사례 errors=[], tick 불변, 불러온 직후와 탐색 종료 시 history/trace가 원본과 동일하다. **전체 GameState 동일성은 11건 모두 false**다. 도우미는 welcome/Escape·카메라를 조작하며 튜토리얼은 GameState 밖에서 끈다. 필드별 차이를 기록하지 않았으므로 차이의 전부가 카메라라고 단정하지 않는다.
- 공식 decodeSave로 저장 checksum과 원본 state의 무이행 동일성을 먼저 검사한다. 이는 브라우저 로드 후 전체 상태가 동일하다는 주장과 별개다.
- [results.json](results.json)은 실제 조작·선택자·텍스트·경계 상자·검증값이다. [capture-manifest.json](capture-manifest.json)에 PNG 원본46장과 JSON의 SHA-256, 보존된 JPEG6장의 해시를 기록했다. PNG는 해당 DGX 실행 폴더와 로컬 `.remote-runs/`에 보존했다. JPEG는 Mac sips quality85 변환이며 원래1280×800을 유지한다.

## 자동 노출과 시각 판정

- 005·092·211 결과 저장에는 일반 decision_trace 칩이 보이고, 201 결과에는 보이지 않았다. 칩 선택자는 특정 결정 ID를 고르지 않는다. 따라서 칩 존재만으로 각 사건의 자동 노출을 판정하지 않는다.
- 연말 결산 모달은11사례 모두 보이지 않았다. 마지막은 [일시정지 세계 화면](final-year-review-initial.jpg)이다. 실제 연도 경계 통과나10배속 플레이가 아니므로 결산 결함 또는 정상 완료로 판정하지 않는다.
- [image-diff.json](image-diff.json)은 응답/결과의 연대기 화면4쌍을 비교한다. 치수 일치·alpha 보존, 변경 비율40.91–41.81%. 다른 시점·스크롤·결과 행의 변화 탐지이며 승인된 동일 상태 기준선에 대한 회귀 검사가 아니다.
- 독립 검토 A는 제한된 수동 기능 PASS, B는 CJK 줄바꿈 REVISE. 종합 **NEEDS WORK**: 211의 “양보한/다”, 092 원인 링크의 “낮춘/다”, 038의 “시/도한다” 등 단어 분리. 5개 결정 화면의 빈 ‘예측과 실제’ 칸과092 제목 반복도 렌더 인계한다. 글리프 누락·심각한 겹침은 검토한14장에서는 발견하지 않았다.

남은 검증: 56건/선택별 미발생·다른 답, 최신125년3seed, 청지기 실제 화면, 자동 소식의 정확한 사건 ID, 조용한 해/연도 전환·10배속, 다른 화면 크기. 이 자료로 EB-WEIGHT(c) 전수 완료를 선언하지 않는다.
