# Charter & Kin — 150년의 변화 미술 파일럿

**판정: 시대 판독 관문 미달, 양산 보류.** 두 차례 독립 AI 눈가림에서 각각4/6(66.7%),목표75%에 못 미쳤다. 초상6명과 집3채는 모두같은 사람·같은 집으로 판정됐다. 결과와 수정 이력은 `proofs/VERDICT.md`에서 먼저 확인한다.

## 내용

- `ERA_GUIDE.md`:1300·1340·1380·1420,남녀×농민·장인·상인·향신·종교인,건축·수직고딕·간판·도구와 점진적 확산안.
- `SOURCES.md`:25개 출처,지역·시기·직접 근거와 해석 한계.
- `pilot/`:48PNG와CSV. 워커16시트(총128프레임),초상18,집6,간판8.43개새완성그림과5개보존기본형이다.
- `proofs/`:같은 거리1.0/0.6 비교,초상256/96 비교,워커 걸음 펼침,집·간판 비교,두 차례 눈가림 원본·정답·응답.
- `PLAN.md`:활성소스 인벤토리에 근거한 전면 제작 상한·우선순위·조건부 일정. 현재 시작하지 않는다.
- `records/`:전문프롬프트·해시·참조PNG·규격·피벗·실루엣 측정·미검증 항목. `pilot/MANIFEST.csv`가48개 납품 분모의 정본이다.
- `SHA256SUMS`:자기 자신을 제외한 묶음 내 모든 파일의SHA256.

## 핵심 한계

캔버스·프레임·피벗 수치·경계상자는 유지했지만 알파 실루엣 픽셀 전부가 같은 것은 아니다. 새 워커 하단15% 중심차는최대x1.786px/y0.470px이다. 그림별 실제수치를 기록했다. 집의 지붕외곽 굴뚝돌출은수정했으며 독립 재검수에서해소 판정됐다.

현재 거리 표시크기에서는1300과1380의 옷 재단 차이가 충분히 읽히지 않았다.1420도굳이답을고른low확신도였다. 전체원본에서는변화가보인다는이유로작은거리판독성공을선언하지않는다.

거리 그림은요청한 정적합성이며 엔진캡처가아니다. 소스클론의코드·설치그림·저장파일을수정하지않았고commit/push하지않았다. 신규그림은candidate상태다. 생성고해상도원본은해시·로컬경로만기록하고경량묶음에서제외했다.
