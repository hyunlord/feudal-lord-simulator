# Wave7 계절 데칼·세계 기표 후보 검수

- 산출물: F8 + G6 =14 PNG, 초기 독립 built-in imagegen 호출14회 +서리B/C 표적 편집2회, 총16회. 게임 설치 없음.
- 생성 원본16장과 실제 전체 프롬프트, 참조 사용 방식은 `world-generation.json`/`world.json`에 보존했다. 프로젝트 이랑·시장 PNG를 대화에서 열어 화풍 문맥으로 사용했으며, 생성 호출에 경로 첨부는 하지 않았다. 모델 버전·seed는 제공되지 않았다.
- 원본 알파를 유지한 trim +1회 균일 축소 +투명 패딩. 반전·새 배경·도형 대체 없음.
-14/14 정확한 규격·RGBA 및 완전투명/불투명 픽셀 확인. 원본과 최종 PNG는 별도 보존.
- frost/leaves/drygrass 대표를12×12 합성 필드에서 원본0.3배(줌0.6)로 먼저 검사하고 변형을 생성했다. 풀덤 대표도 같은 검사판에서 확인했다. `world-*-representative.png`는 실제 게임이 아니다.
- `world-season-inspection.png`:8데칼의 원본 표시와 실제0.3배. 흙 받침·지면 사각형·문자 없음. 눈은 얇은 흩어진 덩어리이며 낙엽과 마른 풀의 세부는 축소 시 뭉친다.
- 세계 기표: 빈 좌판·긴 풀·양축 발자국/점선은 형태 구별 가능. 발자국과 점선은 의뢰서가 지정한 표현이다.
- **줌0.6 제한**: 등짐과 빗장은32px원본이9.6px가 된다. 서로 다른 실루엣은 남지만 ‘떠나는 가족’/‘가동중지’의 의미를 맥락 없이 확실히 판독한다고 인증하지 않는다. 확대 검사판은 이 관문을 대신하지 않는다.
- 초기 서리B/C의 원형 배열을 반려하고, 별도 표적 이미지 편집으로 구멍 없는 비대칭 고체 조각3/4개로 교정했다. 이전 원본·입력PNG·프롬프트 이력은 보존했다. 동일 변형 근접 반복을 피하는 변형 혼합 규칙은 계속 필요하다. fill/strip이 아니므로 XY seam검사는 비해당이다.
- DPR·캐시·성능·실제 게임 접지/가림·설치 검증은 미진행이다.

## 최종 규격 교정
초기 sharp extend가 리사이즈 뒤 적용되어 규격이4px 커진 오류를 루트 검수에서 발견했다.14개 모두 원본에서 한 번 축소한 뒤 별도 정확한 캔버스에 합성하여 교정했다. 의뢰서 기대값과 실제 크기를 직접 비교해14/14 통과했고, 확인판·12×12판·SHA를 갱신했다. 겨울판 담당자에게 서리 재합성을 요청했다.

확인그림04는 최종 기표6+더미12=18개를 포함한다. 각 항목의0.3배와 검수용1.0배를 별도로 표시했다. 확대 그림은 줌0.6 관문 통과 근거가 아니다.
