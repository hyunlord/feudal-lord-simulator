# Wave34 단계3 v3 전체 영역 확인 그림 계약

- 확인 그림 PNG 한 판에 5×5 여름·겨울, 3×3 여름·겨울의 네 행을 배치한다. 각 행은 단계1→단계2→신규3→완료이며 줌1.0·0.6을 함께 보인다.
- 단계3은 5×5용640×320, 3×3용384×192 파일을 각각 영역 중심에 단 한 번 배치한다. 타일 반복·부분 재사용·재색·블러·빈칸 마스크·특징 삭제 없이 원본 전체를 보인다.
- 단계1·2·완료는 이전 승인 원본을 참조한다. 새 단계3의 희미한 도랑 자국 방향과 연결하기 위해 단계2의 승인 타일은 합성에서 좌우 반전하여 +0.5 기울기의 두 도랑으로 놓는다. 승인 파일 자체는 변경하지 않는다.
- 단계3은 중심 피벗: 5×5(320,160), 3×3(192,96). 2:1 투영의 타일 원본128×64, 줌1.0 표시는64×32이다.
- 전체 장면을 원본크기로 합성한 뒤 각각0.5·0.3배로 축소한다. 크기 차이를 숨기기 위해3×3을 확대하지 않는다.
- 승인 Wave22 fen 바탕을 쓰며 완료만 기존 grass로 바뀐다. 웅덩이 감소는 기존 데칼 수5→3→0으로 합성한다. 이는 오프라인 상태 재구성이며 엔진 실행 검증이 아니다.
- 그림 상단에 offline reconstruction 표시를 넣는다. 입력 경로와SHA256은 provenance에 기록하며 경량 패키지를 위해 기존 참고PNG를 중복 복사하지 않는다.
