# Accepted art installed in the playable game

24 assets replace the old runtime PNGs: houses L0/L1/L2/L4, well, granary (barn), storehouse, logging camp, sawmill, 12 foliage/ground-cover sprites (including the new leafless dead oak), and grass/forest-floor/dirt textures.

`integration.json` records each source path, SHA-256, original and installed hashes, alpha crop bounds, uniform fitting ratio, canvas destination, unchanged anchor/footprint/renderScale, and terrain seam metrics. `before/` retains original PNGs and the manifest. Sources live in the sibling `feudal-lord-simulator/output` directory; source-integrity verification requires those originals. This is intentionally not claimed to be a standalone portable release bundle.

Run `./node_modules/.bin/tsx scripts/installAcceptedArt.mjs [source-output-directory]` to reproduce. The environment's existing Sharp installation is used; `SHARP_MODULE_PATH` can select an existing installation. No dependency is added. Parser validation restricts destination paths to the exact runtime asset contract before writes. The installer does not alter game rules or the generated runtime geometry. If runtime projection fields change, regenerate with the existing `writeRuntimeWorldAssetManifest` helper.

Native sprite crop bounds exclude alpha values <=8 when determining the fit rectangle, because generated originals contain near-invisible distant pixels. Alpha and colour within the crop remain untouched before Lanczos resampling. No palette quantization or new outline is applied. Antialiased thin grass needs an alpha-weighted coverage criterion rather than a majority of fully opaque pixels: verification requires nonempty visible content, at least one near-opaque pixel, at least 30% mean alpha coverage among visible pixels, transparent canvas borders, and no pixels below the anchor baseline.

All runtime dimensions, anchors, logical footprints and render scales are unchanged. House L3 remains because the old sprite manifest declares 2x2 while both the accepted level-3 artwork and actual house gameplay footprint are 1x1. This pre-existing metadata mismatch is deferred, not a claim that level-3 gameplay occupies 2x2. Mill, water, rock, and remaining civic/fortification assets retain their prior bytes. Accepted-art verification pins every untouched asset to the captured manifest, retains legacy sprite validation and checks opacity/seams on all terrain. The unchanged mill already belongs to the older phase13 accepted release; it uses that release's transparency/baseline contract rather than the older pre-phase13 promoted-height limit (90px visible versus old 71px cap). The immutable baseline hash protects it from silent changes. Original verification modes remain unchanged.

Verification: `./node_modules/.bin/tsx scripts/verifyWorldAssets.ts . public/assets/buildings/candidates_v2 --accepted-art`. Native-source provenance is explicit; no old generator seed/candidate is retained for new art. The legacy phase13 preparation pipeline rejects accepted-art sources to avoid rewriting their provenance.
