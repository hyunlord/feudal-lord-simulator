# 검증 결과

- 최종 PNG 정확히 8개, RGBA. 기존 캔버스·피벗 8/8 일치.
- 네 모서리만이 아니라 전체 외곽 1px 알파 0 확인. 전 자산 불투명/투명 범위 0–255.
- 최종 해시 8/8 메트릭 일치, 이전 8개와 각각 다름.
- 기존 50개 자산 해시 50/50 보존. 승인된 42개 불변.
- 생성 원본 9개와 입력 참조 9개 해시 검증. 최종 납품 8개, 거절 후보 1개.
- 부모 직접 시각검수 + 별도 읽기 전용 검수: 실제 크기·0.6에서 두 묘목 높이 단계 및 겨울 가지 무리 식별 PASS. 밝은 씨앗풀과 어두운 솟은 가시덤불 구분 PASS.
- 0.6에서 개별 고사리와 잔가지는 군집으로 합쳐짐. 단계 구분을 우선한 의도된 결과.
- 묘목 총 가시영역은 낮은 군집 80×30, 높은 군집 80×56. 바닥의 투영 깊이를 포함하므로 총높이가 식물의 수직 키를 뜻하지 않음. 무릎/사람 키는 미술상 상대 단계이며 사람 실루엣과의 절대 높이 대조는 이번 판에서 미검증.
- 런타임 설치·카메라·겹침·엔진 축소 필터는 미검증. 이 패키지는 오프라인 검수용 candidate.
