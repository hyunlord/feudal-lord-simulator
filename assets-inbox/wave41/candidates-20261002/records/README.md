## 보존 방식과 한계

생성기 출력만으로 픽셀 정합을 보장하지 않았다. 재질을 편집한 뒤 원본 알파·좌표를 복원하거나, 구조선·얇은 부품을 원본에서 선택 보존했다. 해당 변환을 자산별 기록에 남겼다. 최종 29개 모두 캔버스와 alpha>0 점유 경계가 같다. 28개는 알파 전체가 원본과 같고, 연기 1개만 요청대로 농도를 줄였다. 기존 앵커·렌더 설정은 변경하지 않았다. 내부 재료 픽셀 전체가 원본과 같다는 뜻은 아니다.

타이틀은 도구 원시 출력 1672×941을 1920×1080으로 한 번 리샘플했다. 원본보다 석양이 조금 따뜻하며, 보존해야 할 큰집 굴뚝과 기념물은 원위치 패치로 복원했다. 농가의 얇은 구조선과 좁은 부위에는 원본의 미세 질감이 일부 남는다.

실제 게임 설치·DPR·엔진 세 줌·접합 소켓 동작 검증은 하지 않았다. 이 묶음은 오프라인 검수가 끝난 `candidate`다. 코드 문제와 승인된 Pool3는 변경하지 않았다.
