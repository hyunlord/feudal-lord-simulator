## 적용과 검수 주의

A: 첨부 파생 템플릿 편집으로 생성한 표면을 셀별 등록하고 원본 알파 및 하체/발 영역을 복원했습니다. 자유 생성 시트를 그대로 납품하지 않았습니다. 보행 원본은 생성기의 픽셀 고정 성능이 아닌 보호 영역 복원으로 유지했습니다. 머리 0px는 알파 실루엣 기준이며 얼굴 특징점의 동일성을 뜻하지 않습니다. 노인 남성의 옷 길이는 원본 외곽선에 제한되어 긴 gown 항목 부분 충족입니다.

B: 각 축을 별도 생성했습니다. PNG 512×384, 통로 수평 폭 204 source px(표시102px). 높이 제한112 source px는 각 지점의 로컬 지면에서 수직으로 잰 건축 높이입니다. 등각 지면의 기울기를 포함한 전체 이미지 bbox 높이와 다릅니다. 전체 PNG를 높이56px로 강제 축소하거나 통로에 맞춰 다시 가로로 늘이면 안 됩니다. 피벗·통로·벽 접점은 records/gates-geometry.json 참조. 실제 게임 소켓 검증은 별도입니다.

C: 기존1774×887 캔버스와 몸체 bbox로 등록했습니다. 좌우 버트리스는 별도 그림이나 정확한135° 역투영과 엔진 소켓 접속은 미검증입니다.

D: 256×128 불투명 XY 반복. deep_a와의 평균색 CIE76 ΔE는 d1.61/e1.59(기존 shallow_a8.19). 의뢰서의 경계링 표본 ΔE11과는 측정법이 다르므로 런타임 링 제거를 증명하지 않습니다.

생성 원본은 기록된 로컬 경로·해시로 추적하며 추가 PNG로 동봉하지 않았습니다. 실제 모든 프롬프트와 거절 시도는 CSV 및 generation-history.json에 있습니다.
