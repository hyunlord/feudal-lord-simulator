# Wave22 B 전이·해안 띠 자체 검수

- 후보 16장: boundary 10, shore 6. native imagegen 18회(백악 A/B 최초 후보 각각 1회 재편집), 외부 그림 미사용. 게임 미설치.
- 512×64 8장, 512×96 8장. 전부 RGBA. **strip은 X만 반복**하며 fill의 XY 규칙을 적용하지 않음.
- Y 양끝 8px 완전 투명 + 안쪽 8px 알파 페이드. 좌우 여백 없음. X24px 접합부 보정 후 좌우 끝 RGBA 최대차 0, Y8px 알파 최대0. 개별 수치는 strips-validation.json.
- 전이 방향: 위 일반 풀밭, 아래 해당 유형. 해안 위 육지·아래 물. 갈대 위 건조한 둑·아래 젖은 흙/물. 반대 경계 방향은 런타임에서 방향 변환해야 함.

| 항목 | 판정 | 근거·제한 |
|---|---|---|
| X 이어붙이기 | 통과 | 3회 반복 시 수직 접합선 없음. strips-qa.png 육안 확인 및 endpoint 계측. |
| Y 알파 | 통과 | 사방 여백이 아니라 Y8px 규칙. 내부 페이드가 기존 지면·물과 겹침을 전제함. |
| 원본 물가 톤 | 통과 | strips-shore-compare.png에서 원본 shoreline_a와 비교. 올리브 둑·회갈색 흙·청회색 물 연속. 모래 B 물은 원본보다 약간 청록이지만 저채도 범위. |
| 유형 가독성 | 통과 | 실제 native 0.3(줌0.6)에서 백악의 밝은 노출, 히스 갈색, 습지의 물, 해안 모래띠 구분. 해안 모래/자갈/염습지의 경계 구조 구분. |
| A/B 차이 | 통과 | 다른 native 생성. 모래 A 짧은 둥근 해안선/B 길게 뻗은 모래, 염습지 A 수로·섬/B 연속 둑, 갈대 A 빽빽/B 큰 빈 구간. 색 교체 아님. |
| 미세 잡음 | 통과(주요 형태 기준) | 백악 최초 후보의 사진식 입자를 native 재편집으로 제거. 나머지 broad painterly 지시로 생성. 지면 의미 형태는 넓은 면/둑이며 1–4px 개별 모래알을 사용하지 않음. 갈대의 접힌 잎 명암 일부는 작지만 군락 전체가 가독성 단위. |
| 반복 리듬 | 조건부 | 동일 변형만 장거리 반복하면 해안 굴곡과 갈대 군락 위치를 알아볼 수 있음. A/B 교대와 세계좌표 offset은 필요하며 연결부가 없다는 판정과 별개. |
| 실제 게임 | 미검증 | 사용자 요청대로 후보 파일만 제작. 곡선 워핑·DPR·실제 캐시 성능은 설치하지 않아 확인하지 않음. |

후처리: 생성 알파의 유효 Y영역을 잘라 목표 크기에 한 번 축소, Y 여백/페이드 및 X 접합부 평균 혼합. 코드로 지형을 새로 그리지 않음. 프롬프트·참조·선택·수정 이력 전문은 strips-sources.json.
