# perf:gate — 부드러움 관문 1단계

사용자 판정(2026-09-29, SMOOTH-1 근거): 렌더·엔진의 뜨거운 경로(그리기·틱·저장)를 건드리는 병합은 이 관문을 통과해야 한다. 2단계(p99 ≤ 12 ms, 최대 ≤ 33 ms, 50 ms 초과 0)는 SMOOTH-2가 끝난 뒤의 목표다.

## 돌리는 법

```sh
PLAYWRIGHT_MODULE=/abs/path/playwright-core/index.mjs npm run perf:gate
# 일부만: npm run perf:gate -- --only big-town-x5,season-x1   (결과는 "통과(일부 장면)"이고 병합 판정이 아니다)
```

- **어디서**: 이 Mac의 실제 Chrome 창(120 Hz)에서만 판정한다. DGX 헤드리스(소프트웨어 래스터)는 판정하지 않는다(종료 코드 2).
- **동안**: 약 15분 동안 화면에 Chrome 창이 뜬다. 창을 가리거나 다른 무거운 일을 돌리지 않는다. rAF p50이 8.3 ms에서 벗어나거나, 어느 10초 구간이든 기계 CPU가 절반 넘게 쓰이면(다른 세션의 시험 등) 그 실행은 무효다.
- **입력**: 제품 빌드(`vite build --minify false`)를 플레이어가 받는 그대로 연다. 추적은 켜지 않는다(추적은 끊김을 1.6~3.8배 부풀린다). 증명 포트(`?phase10-proof=1`)도 켜지 않는다(그리기 경로에 기록기를 단다). 계절 전환은 HUD 날짜의 계절 낱말로 안다.
- **한 번에 하나**(Mac 전체): 게이트·`hitchAudit`·`memoryHolders`는 `/tmp/fls-perf-measure.lock`을 잡는다.
  - 다른 세션이 잡고 있으면 게이트는 `--lock-wait` 분(기본 30) 기다린다. 그래도 안 풀리면 "판정 아님"으로 끝나고, 누가 잡았는지(pid·폴더·시작 시각)를 적는다.
  - 죽은 프로세스의 잠금은 넘겨받는다.
- **창**
  - 장면마다 창을 앞으로 가져온 뒤, 창이 보이고 초점이 있고 그려질 때(0.5초에 rAF 20번 이상)만 시작한다. `--focus-wait` 초(기본 120)를 넘기면 그 장면은 "판정 아님"이다. 기다리는 동안 터미널에 "측정용 Chrome 창을 앞으로 가져와 클릭해 주세요"가 뜬다.
  - 도중에 창이 가려지거나(`visibilitychange`) 그려지지 않으면(250 ms 감시가 두 번 연속 500 ms 넘게 rAF를 못 봄: 화면 잠김·디스플레이 잠·다른 데스크톱) 그 실행은 "판정 아님"이다.
  - 긴 작업 하나로는 걸리지 않는다. 작업이 끝나면 다음 감시 전에 rAF가 온다.
  - 게이트 동안 `caffeinate -d -i`로 디스플레이가 잠들지 않게 한다.
  - Playwright의 Chrome은 앱 숨기기·창 최소화에도 계속 그린다. 이것은 판정을 흐리지 않아 막지 않는다.
- **종료 코드**: 0 통과 · 1 실패 · 2 판정 아님(기계·주사율·페이지 오류·끝나지 않은 실행·다른 일 CPU·잠금·창).

## 기준(실행마다 모두)

- p99 ≤ 16.7 ms
- 최대 ≤ 100 ms
- 50 ms 초과 ≤ 1/분
- 33 ms 초과 ≤ 3/분
- **순간**: 모든 실행을 합쳐, 계절 전환과 자동 저장 뒤 1초 안에 긴 프레임(> 33 ms)이 나온 비율이 아무 1.25초 구간에 긴 프레임이 든 비율보다 높지 않아야 한다.
  - 창은 순간 250 ms 전부터 1초 뒤까지다.
  - 비율이 높더라도 우연으로 설명되면(단측 이항 검정 p ≥ 0.05) 통과다.

## 회귀 없음 관문(사용자 판정 2026-09-29, 결정 SG4)

1단계 전체 통과는 렌더 SMOOTH-2R 병합 뒤에 다시 잰다. 그때까지 뜨거운 경로(그리기·틱·저장)를 건드리는 병합은 이 관문으로 판정한다.

- **비교**: 같은 Mac에서 본선 머리와 병합할 브랜치를 번갈아 돌린다. 판정에는 유효한 실행(판정 아님이 아닌 장면)만 쓴다. 장면마다 본선의 유효 실행이 최소 세 번 있어야 한다.
- **나빠지지 않음**: 모든 장면에서 브랜치가 본선보다 나쁘지 않아야 한다.
  - 대상은 p99·최대·50 ms 초과/분·33 ms 초과/분이다.
  - **같음의 폭**(사용자 판정 2026-09-30, FIX-10): 브랜치 값이 본선이 제 실행끼리 보인 범위(최소 세 번) 안이면 같다. 한 번의 3분 실행은 흔들린다. 최대 프레임은 GC 한 번에 좌우되고, 본선끼리도 50 ms 초과가 0.6~2.8/분, 최대가 162~1,813 ms로 갈렸다.
  - 처음(2026-09-29)의 "본선 값의 1.25배(최대 1.5배)"는 이것으로 바꿨다.
- **자기가 맡은 순간은 1단계 수치 통과**:
  - 엔진은 자동 저장과 틱을 맡는다. 자동 저장 뒤 1초 안의 긴 프레임 비율이 아무 1.25초 구간보다 높지 않아야 한다(단측 이항 5 %).
  - 렌더는 계절 전환 그리기·배치 끌기를 맡는다.
