## 파일럿 승격과 보완

직조형·생계형·우물 B·시장 B는 ID와 파일명만 바꿨다. 표에서 승격을 지정한 **목축형 여름도 원본 그대로** 복사했다. 따라서 총 **5장**이 첨부 파일럿 및 이전 납품과 PNG 바이트까지 같다. 의뢰서의 “4장”과 열거 수 차이는 이 방식으로 처리했다.

양조형은 기존 파일럿을 편집해 **낮고 길쭉한 마루 통풍구**를 추가했다. 첫 보완본의 검은 개구부가 축소 시 약해 한 차례 더 수정했다. 굴뚝 통은 추가하지 않았다. 네이티브 편집 특성상 지붕 외 픽셀이 모두 원본과 동일한 패치라고 주장하지 않는다.

## 규격·피벗

첨부 게임 그림 19장은 기준 저장소의 원본과 SHA-256이 일치했다. 기준 코드 HEAD는 `07257643958ffac19af2881d6a8d7163e5b086e3`이다. 파일별 원본 크롭·피벗·화면 배율과 `파일:함수` 근거는 `records/render-contract.json`에 있다.

주택·합필은 좌우·상단8px, 하단4px 투명 여백. 농장·시설은 사방8px다. 피벗 좌표는 바꾸지 않았다. L2는 `(70.9581339713,132.0837320574)`이다. PNG 자체는 게임 피벗 등록을 하지 않으므로 별도 계약 파일을 사용해야 한다.

일부 기준은 피벗이 지정 하단 여백 안에 있다. 피벗을 이동하는 대신 그림을 여백 경계에서 정리했다. 이로 인한 피벗까지의 간격은 주택·합필에서 최대 **0.943 화면 px**, 예배당에서 약 **0.551 화면 px**다. 거리 그림은 기준과 변형에 동일 크롭·피벗·배율을 적용한다. 색 면적이나 본채의 실제 외곽 치수까지 같다는 뜻은 아니다.

## 채택 기준과 남은 한계

규격·투명 여백·승격본 보존·피벗 계약은 통과했다. 색만 바꾸는 방식은 사용하지 않았다. 양조 통풍구, L4 뒤 날개형의 본채 크기, 어린 싹 식별은 최종 검수 후 수정했다.

**주택 시각 기준은 일부 부분 충족이다.** L1 기준 자체가 이미 초가로 읽혀 초가 변형은 처마·마루 형태 차이에 의존한다. L4 뒤 날개와 합필 L3 세로·L4 가로는 구조는 달라졌지만 검정 외곽만으로 강하게 구분되는 변형은 아니다. 작은 공구·통풍구·간판 등은 줌0.6에서 각각 판독하기 어렵다. L1 생계형 등 일부 본채는 부속 공간 때문에 기준보다 작게 읽힌다. 이를 전면 합격으로 표시하지 않았다.

농장·시설의 주요 형태는 정적 비교에서 구분된다. 혼합형 4상태는 **x≥207 영역의 RGBA가 완전히 동일**하여 소2·헛간·건초를 고정했다. 어린 싹은 짧은 초록 점열, 성장기는 큰 녹색 줄, 익음은 황금빛 밀, 작업 후는 맨흙이다. 봄·여름·겨울 목초지 외곽에는 최대4px 차이가 있으며 공통 캔버스·피벗은 유지된다.

농장·시설 확인 그림은 비교를 위한 원본 배율이며 실제 게임 줌이라고 표시하지 않았다. 주택 거리 두 장만 코드 배율의 줌1.0/0.6이다. 농장 현재 렌더는 층 분리·세로 구간별 변환, 풍차는 별도 애니메이션 등록을 사용하므로 V1 설치 시 별도 확인이 필요하다.

## 제작 기록

신규·편집 선택본30장과 원본 승격5장. 네이티브 이미지 생성은 재시도 포함35회다. 모델명과 seed는 도구에서 제공되지 않았다. 제공된 게임19장·파일럿6장과 이 작업의 편집 대상 후보 외에 외부 작품은 참조하지 않았다.

도구가 최종 규격보다 큰 원본을 반환하여 Canvas 2D로 알파 미세점 정리, 크롭, 균일 축소, 피벗 등록, 여백 처리를 했다. 혼합형 작업 후 상태는 생성 과정에서 지면 크기가 달라져 기본 장면의 경계로 정렬한 뒤 목축 쪽 픽셀을 복원했다. 실제 변환은 기록에 남겼다. 고해상도 원본을 납품 크기로 직접 생성했다고 주장하지 않는다.

원본 생성 파일과 참조 PNG는 해시·경로로 기록하고 ZIP에 중복 수록하지 않았다. 따라서 ZIP의 PNG는 정확히 **39장**이다. 압축 무결성과 `SHA256SUMS.txt`를 검사했다.
