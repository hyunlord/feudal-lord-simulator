# 동일 도시 랜드마크 성장 — 정적 합성·눈가림 평가 규약

이 그림들은 실제 엔진 캡처가 아닌 **고정 정적 합성**이다. 배경은 프로젝트 소유 PNG를 반복 배치하고 길·물의 마스크만 기하 도형으로 만든다. 생성된 랜드마크는 완성 RGBA 캔버스 전체를 균일 축소·이동해 배치하며, 조각으로 잘라 재조립하지 않는다. z-order·충돌·DPR·성능·실제 계절 전환은 검증하지 않는다.

## 재현 실행

프로젝트 소스는 `/Users/rexxa/fls-astra-landmarks` 읽기 전용. 설치된 Pillow만 사용하며 새 의존성을 설치하지 않는다.

```sh
python3 records/tools/compose_city.py /tmp/astra-landmark-growth-20261003-work
```

`--background-only`를 붙이면 배경참조만 갱신하며 최종 도시나 눈가림 파일을 만들지 않는다. 복제한 참조 PNG가 있으면 이를 우선 사용하므로 배포 패키지 내에서 재현 가능하다. 최초 복제 소스만 `SOURCE_ROOT` 환경변수로 변경할 수 있다. 최종 생성 재실행은 눈가림 ID를 다시 섞으므로 **평가 시작 후 재실행 금지**. 필요시 새 평가 회차로 취급한다.

## CSV 인터페이스와 축척

`assets/manifest.csv` 필수 열: `filename,family,stage,season,canvas_width,canvas_height,pivot_x,pivot_y,world_scale`.

- `filename`: manifest가 들어 있는 `assets/` 기준 상대경로 또는 절대경로.
- `family`: `church,market,gate,bridge,manor,guildhall,inn`.
- `stage`: 정수 또는 `C1/M1/G1/B1/L1/U1/I1` 형태. 교회 1–4, 나머지 1–3.
- `season`: `summer` 또는 `winter`.
- `canvas_width,height,pivot_x,y`: 원본 PNG 픽셀 단위; pivot은 캔버스 기준 위치.
- `world_scale`: 원본 1px당 world px. 확대 금지, 0 초과 1 이하.
- 각 계열의 모든 단계·계절에서 캔버스, pivot, world_scale이 같아야 한다. 실제 PNG 크기·RGBA 모드와 CSV 불일치, 44개 조합의 누락·중복, 잘린 불투명 영역은 오류로 중단한다.

원본 캔버스는 `round(canvas × world_scale)`로 균일 리샘플링한다. 성인 opaque 높이 목표 17.6 world px, 일반집 opaque 높이 목표 56.32 world px. 정수 픽셀 출력에 따른 반올림 오차는 남는다. 겨울 집은 기존 주택 원본에 해당 지붕 눈 오버레이를 원본 좌표 그대로 겹친다. 보행자는 프로젝트 소유 4×2 시트의 첫 프레임을 사용한다. 참조 파일 SHA-256·경로와 좌표는 `references/city-layout.json`에 기록한다.

## 눈가림 시대 판별 — 사전 고정

1. 생성기는 12장 순서를 OS 난수로 섞어 `proofs/blind/R01.png`–`R12.png`로 복사한다. PNG에는 연도·단계 글자나 별도 판별 라벨을 넣지 않는다. 파일명-정답 대응은 `proofs/answer-key.csv`에만 둔다.
2. **서로 독립된 AI 평가자 2명**에게 오직 `proofs/blind/`의 12개 이미지와 동일한 아래 질문을 제공한다. 제작에 참여한 평가자, 정답키·manifest·원래 파일명·제작 설명에 접근한 평가자는 교체한다. 평가자끼리 답변을 공유하지 않는다.
3. 평가자 질문: “각 이미지의 도시가 1300, 1380, 1450 중 어느 시나리오에 가장 가까운지 하나를 선택하라. 이미지 ID, 선택 연도, 신뢰도(낮음/중간/높음), 보이는 건축 특징 근거를 기록하라. 선택하지 못하면 `unknown`으로 답하라. 정답 분포를 가정하지 말라.” 각 이미지가 모든 평가자의 제출에 정확히 한 번씩 있어야 한다.
4. 두 평가자의 응답을 파일로 고정한 다음 정답키를 연다. `unknown`은 오답. 교정·재응답으로 점수를 올리지 않는다.
5. **일차 기준은 두 평가자 합계 24개 판정 중 ≥18개(75%)**. 줌별로 12개 판정 중 ≥9개(75%)도 각각 충족해야 전체 `PASS`로 기록한다. 한 조건이라도 미달이면 `FAIL`. 평가자별 전체 점수(각 12개), 평가자별 줌 점수(각 6개), 계절별 점수도 함께 보고한다. 표본이 작은 6개 묶음에서는 4/6=66.7%, 5/6=83.3%이므로 반올림해 통과시키지 않는다.
6. 전체 및 줌별 `실제 시대 × 예측 시대` 3×3 혼동표와 `unknown` 열을 작성한다. 특히 1300→1380, 1380→1450 등의 방향과 반복 혼동을 기록한다.
7. 이미지/평가자 반복은 독립 인간 표본이 아니다. 12장도 한 도시의 계절·줌 반복이므로 **표본 비독립**이며 일반 도시나 영국 전역 연대 판별 정확도로 확장 해석하지 않는다. 연도는 이 풍요로운 도시 시나리오의 선택된 단계이지 건축 양식의 발명 연도가 아니다.

## 같은 건물의 성장 판정 — 시대 판정 고정 후

시대 판정 응답과 점수를 고정한 뒤에만, 두 평가자에게 계열별 모든 단계의 동일 축척 전체 캔버스를 순서대로 공개한다. 도시에서 생략된 교회 2단계도 포함한다. 여름과 겨울을 각각 보고 계절 일치도 함께 확인한다.

각 평가자는 7계열 각각에 대해 `같은 건물의 증축/교체로 읽힘: yes/no/uncertain`, 보존된 핵심(입구·홀/본당·지붕축·기초·주요 벽체), 바뀐 부분, 다른 건물처럼 보이는 단계 전이를 구체적으로 적는다. 시장의 빈 장터→건물은 같은 부지의 성장으로 평가한다. 돌다리·문루 등 합리적 재건은 재건으로 명시하되 임의 위치·시점 변경은 성장 연속성으로 인정하지 않는다.

같은 건물성은 7계열×2평가자=14개 결과를 그대로 보고하며, 두 평가자가 모두 `yes`인 계열만 확정 통과로 센다. `uncertain`을 성공으로 치환하지 않는다. 시대 점수와 별도 축으로 기록한다. 인물 크기, 입구 높이, 불투명 외곽, core pivot 정합 등 객관 검사는 별도 QA와 대조한다.

## 알려진 한계

- 정적 합성의 길·강은 단순 마스크이며 실제 월드 지형과 길찾기가 아니다.
- 일반집·인물을 먼저 배치하고 랜드마크를 앵커 y 순서로 합성하므로 실제 엔진 깊이 정렬의 증거가 아니다.
- 잘림·등록·크기 검사 성공은 역사 정확성이나 시각 판독 성공을 뜻하지 않는다.
- 랜드마크끼리/일반집과의 부적절한 겹침은 최종 12장 육안 검사로 확인해야 한다.
- 실제 게임 설치, runtime 카메라, moving capture, 가림·충돌·성능은 미검증이다.

## 도구 검증 기록 (Mac, 후보 생성 전)

1536×1536 RGBA 임시 도형 fixture와 pivot(640,1100), world_scale 0.25의 44개 조합 manifest로 CLI 전체 경로를 실행했다. 임시 디렉터리는 종료 시 제거했고 최종 후보/평가 결과로 사용하지 않았다. 12개 출력과 눈가림 12개가 모두 1280×800임, 키의 각 사본이 원래 PNG와 바이트 동일함, zoom 0.6의 중앙 `(256,160,1024,640)`가 zoom 1.0을 768×480으로 축소한 픽셀과 동일함, 44조합 누락 시 중단함을 확인했다. `py_compile` 통과. `ruff`와 `basedpyright`는 설치되어 있지 않아 실행하지 않았다. 최종 아트의 시각 QA·눈가림 점수는 별도 평가 결과가 있어야 확정한다.

## 연속성 보드 자동 산출

최종 합성 실행은 `proofs/identity/{family}_{summer,winter}.png` 총 14장도 생성한다. 각 단계 열 폭은 900px이며 위쪽 중앙에 **450×300 실제 CSV world_scale 셀**, 아래쪽에 같은 셀을 **정확히 2배로 확대한 900×600 보조 셀**을 둔다. 전체 높이는 936px, 폭은 단계수×900px. 단계 라벨은 S1–S4만 쓰며 시대는 표시하지 않는다.

같은 계열의 모든 단계·계절 불투명 영역의 합집합 중심을 표시 창 중심에 고정한다. 이는 보드 안의 카메라 이동이며 원본 등록이나 축척을 바꾸지 않는다. bbox에 맞춰 그림 크기를 조절하지 않는다. 합집합이 450×300에 들어가지 않으면 조용히 자르거나 축소하지 않고 실패한다. 연속성 보드는 눈가림 폴더에 넣지 않으며, **시대 응답 고정 후에만 평가자에게 공개**한다.

2048×2048, pivot(768,1536), world_scale 0.25 임시 fixture 44행으로 후속 전체 경로를 검증했다. 12개 도시와 14개 보드 출력, 각 보드 치수, 하단 셀이 상단 셀의 정확한 2배 리샘플 픽셀임, 표시 창 초과시 중단함을 확인했다. 최초 높이 과대 fixture는 영주관의 도시 상단 잘림으로 정상 중단했고, core 위 210px fixture로 전체 검증을 통과했다. 실제 후보의 영주관이 core 위 220px를 넘으면 현재 도시 앵커에서 잘릴 수 있어 최종 입력으로 확인해야 한다.


## 실제 후보 배치 수정 (블라인드 시작 전)
