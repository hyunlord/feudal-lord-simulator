## 공개 API / 비용

`simulateBattle(attacker, defender, command)`은 두 도시를 복제하고 `{attacker,defender,command,trace,route,objective,success,loot,attackerLosses,defenderLosses,steps,reason,deployed}`를 반환한다. 입력을 수정하지 않는다. command는 seed, raid/siege, north/east/south/west, 선택 soldiers/supply. 외부 저장·명령 검증은 상위 경계의 책임이다.

출정 인원 상한은 살아 있는 인구25%에서 기존 동원자를 뺀 값. 식량과 공구는 실제 원장으로 빠지고, 미소비 식량은 실제 귀환 때 정수 단위로 반환한다. 군대 식사는 단계당 인원×0.025, 소수 잔량은 반환 시 내림하여 총 소비를 올림한다. raid 장비 ceil(병력/3), siege 장비 병력 수까지 실제 보유량 한도. 숫자는 역사 수치가 아닌 공개 게임 추정이다.

생존한 동원자와 방어 경비는 다음 경제1단계 동안 생산 일손에서 빠진다. `advanceCity`가 단계 말 mobilized를0으로 지운다. 사상자/미귀환자는 가구 인구에서 한 번 제거하고 시설 일손을 상한 조정한다. 상세 부상·포로 석방 경제는 없다. 256단계 또는 보급 고갈로 귀환하지 못한 생존자는 실종/포로 손실로 단순 처리하며 이유문에 표시한다.

## 인과

21×21 실제 지형에서 최단비용 경로를 찾는다. 물은 길(교량)이 없으면 불통, 도로는1·비도로2에 표고와 관문 지연을 더한다. 경비 위치3칸 내 노출 비용까지 공개 경로 비용에 포함한다. 매 단계의 좌표/단계종류/식량/생존병/노출/손실을 기록한다. 매 판 승자를 미리 계산하지 않는다.

군사시설은 이 축약 시제품의 경비초소 겸 강화 관문이다. 독립 성벽 선분/폐쇄 성곽은 아직 없다. raid는 관문 월담 지연(hp/5), siege는 도구 돌파 지연(hp/15)을 기본 이동비에 더하며 siege가 관문 실제hp를 깎는다. 공성은 관문 파괴+귀환이 목적이며 약탈 재고를 주지 않는다. 군사시설이 없으면 중앙 거점 점령으로 취급한다. 군사 이름/방침 자체는 전투 보너스를 주지 않는다. 실제 유급 훈련 서비스만 접촉 시 공격 효율에 최대2배 한도로 작용한다.

창고는 첫 trade/craft 시설 위치, 없으면 중앙(10,10). 별도 창고 역할의 자율 선택은 아직 축약되어 있다. raid는 도달+귀환 때 인구2식 분량 식량을 보호하고 남은 자유재고의 각10% 이내, 전체 병력×2 적재 한도로 이체한다. 현재 순서는 식량→자재→공구→은화이며 UI에 숨겨선 안 된다. 계약 escrow는 이미 도시stock 밖으로 옮겨져야 보호된다. 동시 서버 예약/30분 만료/중복 청구 원자성은 이 로컬 함수가 증명하지 않는다.

보급이55% 미만 또는110단계가 되면 목적지 전이라도 지나온 경로로 돌아선다. 물·초소·도로를 무시하고 순간 귀환하지 않는다. 미귀환시 노획물을 지급하지 않는다. 공격 시드만으로 접촉 난수를 재현하며 Math.random/시계/네트워크를 쓰지 않는다.
