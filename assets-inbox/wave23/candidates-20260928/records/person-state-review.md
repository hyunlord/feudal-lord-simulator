# 인물 상태 장식 검수

- 제작 범위: 상중·병·임신·새로 태어남·사망·굶주림·부상·순례·혼인·reeve·bailiff·청지기, 각 96/48px. 인물 초상 새 생성 및 얼굴 보정 없음.
- 배치 계약: 96px 캔버스 오른쪽 아래에 최대 29px 장식. 얼굴 보호 원은 중심 (47.5,47.5), 반경31px. 48px는 같은 배치의 축소 파생본이며 보호 원을 다시 비운다. 완성된 원형 틀 자체를 그린 파일이 아니라 기존 틀에 올리는 장식 레이어다.
- 얼굴 보존 검사는 `person-state-face-qa.json`에 인물별 원본 경로·SHA256·복사본 SHA256·중앙 픽셀 차이를 기록한다. 기존 96px 초상은 직접 사용하고 기존 256px 초상은 확인판에서 96px로 한 번만 축소한다. 같은 크기의 장식 합성 전후를 비교한다. 원본256과 축소96이 픽셀 동일하다는 주장이 아니다.
- 확인판은 프로젝트의 서로 다른 12명(P1~P6, I039/I041/I042/I047/I056/I068)을 사용한 합성 UI 검사다. 상태와 인물의 연결은 검사용이며 실제 인물의 사건·나이를 나타내지 않는다. 죽음 상태에서도 얼굴 흑백화는 하지 않았다.
- 96px에서 가리비·반지·빈 그릇·십자 촛불·요람·포대기 등 큰 형태로 구별된다. 병은 약초가 붙은 붕대, 부상은 약초 없는 붕대로 구분한다. 직책은 막대 / 큰 열쇠 하나 / 작은 열쇠 꾸러미로 분리한다.
- 축소 한계: 48px 캔버스 안의 실제 장식은 약14px다. 요람은 정확한 의미를 모르면 작은 배로도 읽힐 수 있다. 검은 상중 리본은 어두운 배경에서 대비가 낮다. 48px에서는 정확한 상태명 문구와 병행하는 것이 안전하다. 이를 모든 크기에서 글 없이 의미 판독 통과라고 주장하지 않는다.
- 게임 설치·런타임 상태 연결은 하지 않았다. 원본 초상과 이전 승인 자산은 수정하지 않았다.
