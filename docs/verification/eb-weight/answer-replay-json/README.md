# 답변 재현의 JSON 비교 오류

`engineB-answer-replay-59d42d0-59d42d0`은 seed1의500000틱 뒤 종료1했다.28개 중간 저장과 최종 전체 상태 SHA/체크섬은 원본과 같지만, `Original collector mismatch: history`로 실패했다. seed2·3과 계절 UI는 실행되지 않았다. 원격 scope inactive와 원래 프로세스 부재를 확인했다.

보관된 `audit-snapshot.json.gz`를 읽으면8개 수집 항목 전부가 원본과 deepEqual이다. 원본 소스의 수입 전용 영수증은 지출 합0에 음수를 붙여 `expense:-0`을 만든다. JSON은 이를0으로 저장하지만 메모리 엄격 비교는 둘을 구분한다. 실제 `h-002666`의 수입20·지출0을 [근거 JSON](failure-evidence.json)에 보존했다.

수집기와 후보 관측 자료를 원본과 같은 JSON 표현으로 비교한다. 중간 저장·최종 상태 바이트 비교, 명령 수, 원본 해시, 관측 실패 수와 사건 답변 집합 검증은 유지한다. 회귀 시험은 `-0`, 생략되는 undefined를 허용하고 실제 수입·선택·ID·개수·null 차이는 계속 거부한다. 수정 전 회귀 실패, 수정 후 관련25시험과 lint 통과를 확인했다.

실패 실행을 사후 통과로 바꾸지 않는다. 수정 도구의 전체 DGX 재현은 아직 미완료이며, 이 자료는 연간 답변 수나 계절 화면 통과 근거가 아니다.
