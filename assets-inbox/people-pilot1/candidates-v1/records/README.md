# 인물 파일럿 — 후보, 게임 미설치

**판정: 96px 초상 구별 가능 · 초상↔워커 의미 서명6/6 연결 · AI 4방향 보행 시트 본 제작 사용은 불통과.**

자동 생성이 방향·보행 일관성을 유지하는지 시험한 결과입니다. 파일 크기 검증 통과를 워커 품질 통과로 해석하지 않습니다. 미흡한 시트도 숨기지 않고 원본과 함께 전달합니다. 신규 인물은 요청한6명이며 본 제작150/75세트로 확대하지 않았습니다.

## 파일

- `assets.csv`: 생성 기록12행. 전체 실제 프롬프트·참조·후보수·선택·수정·SHA.

## 결과와 한계

초상은 같은 왼쪽3/4 방향, 단색 회갈 배경, 눈선112±4·어깨208±8에 등록했습니다. 수작업으로 원본 눈·어깨 지점을 읽어 전체 인물에 같은 비율의 확대/이동을 적용했습니다. 얼굴 부위별 변형이나 반전은 없습니다. 96px에서 여섯 역할이 보이지만 블라인드 사용자 인지 시험은 수행하지 않았습니다.

계급·머리쓰개·주색은6쌍 모두 연결됩니다. 상인의 모자/베일, 사제의 삭발, 노동자의 후드/코이프, 과부의 윔플로 분리했습니다. 사제 정면 삭발은 일반 탈모처럼 읽힐 수 있고 실제 화면17.6px에서는 얼굴·나이·삭발보다 큰 색면과 머리쓰개가 먼저 보입니다.

방향 일관성 **확정 X4/96항목**: P1 NE/SW 지갑 측, P4 SW 자루 손, P5 NE 바구니 손. P2 SW 지갑 비노출은 먼 쪽 가림 가능성이 있어 별도 보류1건입니다. 뒤쪽 수염처럼 보이지 않는 부분의 O는 동일함을 증명했다는 뜻이 아닙니다.

두 프레임의 교대 보행은 **24방향쌍 모두 X**입니다. 이미지 픽셀은 다르지만 왼발/오른발 지지의 명확한 교대를 입증하지 못했습니다. 이를 걷기 애니메이션 완성이라고 부르지 않습니다. 추가로 P4 옷은 의뢰의 무릎 길이보다 짧으며 수선 패치의 어깨 이동이 의심됩니다. 원형 제작에는 쓸 수 있으나 그대로 런타임 승격하기에는 부적합합니다.

## 원본과의 규격 차이

첨부5시트는 모두4×2이지만 실제 파일 크기는 서로 다릅니다. 제품의 방향 순서와 프레임별 접점을 읽기 전용으로 확인했습니다. 74셀로 정규화한 기존 발 y중앙값67.2841을 바탕으로 후보 공통 발 피벗(37,67), 마스터(74,134)를 사용했습니다. 기존 모든 프레임의 피벗이 같다는 뜻은 아닙니다.

제품 줌1에서 주민 본체 높이는32×0.55=17.6px입니다. 거리 합성은 이 값을 사용하며 첨부 캡처 자체의 당시 카메라 줌은 확인하지 못했습니다. 아래 비교띠에 기존 주민5종도 같은17.6px로 별도 배치했습니다. 원래 캡처에서 식별되지 않는 주민을 비교 근거로 삼지 않았습니다.

## 제작 및 후속 판단

image_gen 사용. 모델 세부 버전·seed는 도구가 제공하지 않아 미제공으로 기록했습니다. 모든 참조는 사용자 제공/이 프로젝트 생성물입니다. CSV의 generatedAt은 원본 파일 수정 시각입니다. 과부 초상은 최초 배경이 단색이 아니어서 image_gen으로 투명 배경 수정 후 공통 단색에 합성했습니다. 최초 원본·수정 프롬프트 모두 보존했습니다.

본 제작은 승인된 방향 원형/리깅에 소지품의 해부학적 좌우와 패치 위치를 고정하고, 실제 교대 보행 자세를 만든 뒤 재검수하는 경로를 권고합니다. 이번에는 그 본 제작이나 게임 설치를 하지 않았습니다. 역사 검수는 첨부 딥리서치와 이번 금지 목록 대조이며 독립 전문 역사 감수는 아닙니다.
