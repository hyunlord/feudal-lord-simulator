# 초상 18장 제작 검수

2026-10-03 · candidate · 제작자 자체 검수이며 독립 눈가림 판정과 구분한다.

## 규격과 제작

- 원본은 Pool1 mature 6명, 각 256×256 불투명 초상이다. 동일 인물의 나이는 고정했다.
- 18장 모두 원본을 직접 참조한 imagegen identity-preserve 편집이다. 얼굴·몸 부품을 오려 붙이지 않았다.
- 생성 원본은 1254×1254이며 각 전체 그림을 Lanczos로 한 번 256×256으로 축소했다. 96px 검수판은 납품 256px에서 파생했다. 원본 생성 파일은 경량 ZIP 밖에 보존하고 경로·해시를 generation.json에 기록했다.
- PNG 18장, 6명×1300/1380/1420, 중복 경로 없음. 소스·생성 원본·출력 SHA256과 전체 프롬프트를 보존했다.
- 원본과 결과 모두 불투명 캔버스다. 알파 경계 보존을 인물 외곽선 보존의 증거로 사용하지 않는다. 얼굴 픽셀 동일성이나 외곽선 완전 일치를 주장하지 않는다. UI 초상은 256×256 캔버스의 기존 배치 계약을 유지한다.

좌상광·회갈색 배경·온화한 회화형 가장자리는 세 판에서 일관된다. 96px에서도 여섯 인물은 서로 구별되며, 같은 인물의 세 판은 동일인으로 읽힌다. 원본보다 얼굴이 미세하게 다시 그려졌으므로 생체 인식·픽셀 동일 검증 결과가 아니다.

## 고증 적용의 범위

1420 샤프롱·작은 머리망은 시대·계층별 정확한 보급률을 입증한 것으로 취급하지 않고 연구 문서의 게임 채택 제안과 연결한다. 여성 원뿔 헤닌·과장된 뿔·현대 성직자 칼라·담비 꼬리점은 넣지 않았다. 장인과 성직자에게 억지로 향신 패션을 입히지 않았다. 기존 승인 초상을 교체하거나 원본을 수정하지 않았다.

독립 눈가림 시대 맞힘률과 동일인 판정은 상위 proofs 결과가 최종 기록이다. 이 제작자 검수표를 독립 검수 점수에 섞지 않는다.

경량 묶음의 확인 그림 정본은 `proofs/`에 있다. 같은 그림의 records 사본은 중복 용량을 줄이기 위해 묶음에서 제외했다.
