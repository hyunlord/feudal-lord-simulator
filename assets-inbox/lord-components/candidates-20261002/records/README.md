# 영주 화면 부품 후보

채택된 인물 중심 영주 화면 방향을 위한 신규 부품 묶음이다. P0·P1 26종과 왼쪽 메뉴 8종, 총 **34종·40개 PNG**를 대상으로 한다. 성격 특성 6종은 각각 48px와 24px 두 크기다. 모든 부품은 `candidate`이며 게임에 설치하지 않는다.

| 분류 | 내용 | 종수 | 출력 크기 | PNG 수 |
|---|---|---:|---|---:|
| 성격 특성 | 신중·검소·야심·명예·상인 친화·농민 친화 | 6 | 48×48 및 24×24 | 12 |
| 지역 지도 바탕 | 강·숲·언덕·길이 있는 가상의 잉글랜드 남부 한 고을 | 1 | 1600×1000 | 1 |
| 지도 거점 | 장원·시장도시·수도원·방앗간 | 4 | 96×96 | 4 |
| 지도 깃발 받침 | 직할·위임·이웃용 빈 깃발 | 3 | 64×96 | 3 |
| 직책 표식 | 청지기·집사·reeve·서기·가신 대장 | 5 | 40×40 | 5 |
| 알림 종류 | 긴급·권리 위기·기한 임박·일반 소식 | 4 | 32×32 | 4 |
| 건강 상태 | 건강 양호·질병·부상 | 3 | 32×32 | 3 |
| 왼쪽 메뉴 | 인물·가문·지역·영지·평의회·혼인·청원·무력 | 8 | 40×40 | 8 |

성격 특성과 메뉴는 문장 방패와 구별되는 도상을 사용한다. 지도 거점은 같은 시점과 밀도로 맞추며, 깃발 받침은 기존 문장을 조립할 수 있도록 문장 없는 부품으로 제작한다. 지도는 특정 실제 지명이나 확정된 실제 지리를 나타내지 않는다.

## 묶음 구성과 범위

- `assets/`: 사용 크기로 정리한 PNG 후보.
- `proofs/`: 실제 사용 크기 및 조립 검토용 이미지.
- `prompts/`, `records/`: 정확한 생성 프롬프트, 원본 출처 경로, 변환·검수 및 해시 기록.
- `records/NEXT_SCREEN_DIRECTION.md`: 다음 화면 개정 때 적용할 초상과 화면 방향.

경량 ZIP에는 최종 사용 크기 자산과 검토·출처 기록을 담는다. 대용량 생성 원본은 로컬에 보존하고 ZIP에서 제외한다. 실제 원본 위치는 생성 기록을 따른다.

이번 범위는 부품 제작이다. 전체 화면 시안 재제작, 제품 설치, 무력 부품 P2 제작은 포함하지 않는다. 메뉴의 무력 아이콘은 이번에 별도 요청된 탐색 아이콘이며 P2 병종·장비 부품 제작을 뜻하지 않는다. 오프라인 이미지 검수는 게임 내 가독성·클릭 영역·렌더링·성능 검증을 대신하지 않는다.
