## 사용 좌표와 검토 범위

석벽은 정면을 먼저 그리고 윗면을 겹칩니다. 권고 좌표는 윗면 Y=0, 정면 Y=32로 16px 겹침입니다. 최종 접합과 개별 처리 수치는 `records/normalization.json`을 확인하세요. Strip은 X축만 반복하고 fill만 XY축으로 반복합니다. 벽의 몸체·하단은 불투명이며 물가용 알파 페이드를 벽에 적용하지 않습니다.

석탑은 기존 목책 탑 원본과 같은 1774×887 캔버스입니다. 기존 탑은 예약 에셋으로 런타임 등록점을 확인하지 못했습니다. 따라서 동봉한 탑 피벗·접점은 **후보 좌표**이며 기존 게임 피벗 검증 완료라는 뜻이 아닙니다.

확인 그림은 오프라인 합성입니다. 소형 strip/decal의 줌 1.0은 원본 ×0.5, 줌 0.6은 ×0.3입니다. 별도 크기로 배치한 비교 이미지는 해당 표기를 따릅니다. 실제 게임의 곡선 변형·정렬·통행·클릭·운반·DPR·캐시·성능 검증은 수행하지 않았습니다.

생성 도구의 출력 크기에서 최종 표시 규격으로 정규화했습니다. 도구가 정확한 소켓 좌표·반복 경계를 직접 보장하지 않아 기하 정합·반복 경계·알파·투명 픽셀 RGB 정리를 적용했으며 해당 처리는 기록에 포함했습니다. 외곽 픽셀 일치는 반복 무늬의 시각적 비반복성이나 엔진 통합을 증명하지 않습니다.
