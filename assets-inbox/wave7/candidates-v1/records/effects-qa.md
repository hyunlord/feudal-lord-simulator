# Wave 7 B/H 검수

- 상태: 후보 9 PNG, 게임 미설치. 각 PNG당 builtin imagegen 1회, 총 9회. 원본은 sources/effects에 보존했다.
- B 5종: 4프레임 가로 연기/먼지 시트 4개와 + 표식 1개. 시트는 생성 원본을 4등분한 후 알파 범위에서 공통 배율로 한 번 축소하고 아래 가운데 발원점을 정렬했다. 원본 프레임별 형태 차이를 유지한다.
- 지정 크기, RGBA, 각 셀 좌우/전체 외곽 경계 알파 0 확인. 건물·굴뚝·화덕 본체는 연기 PNG에 없다. 집 연기는 지붕 틈 좌표에 코드로 배치할 분리 레이어다.
- 0.3배 대표 검수: effects-representative-03.png의 약한 옅은 연기와 진한 화덕 연기 구별 가능. 지붕틀 소형은 effects-frame-representative-03.png에서 삼각 목구조로 읽힘. 이후 변형 제작. 전체 축소 검수는 effects-all-03.png.
- 일반 집 연기는 흰색/회색, 약한 연기는 더 가늘고 옅고, 화덕 연기는 짙은 회색이다. 먼지는 낮은 흙빛 퍼짐. + 표식에는 숫자를 넣지 않았다.
- 연기 프레임 간 평균 알파 차이(0~255, 1→2/2→3/3→4/4→1): 약한 집 17.17/14.99/24.09/4.18, 일반 집 30.28/33.41/41.30/1.09, 화덕 36.06/34.65/24.19/15.30. 루프 접합의 차이가 내부 변화보다 작지만 실제 프레임 속도·합성 애니메이션의 자연스러움은 미검증이며 완전한 애니메이션 정합으로 주장하지 않는다.
- 공사 크기 수치는 의뢰에 없어 기존 512×256 목구조 참조를 확인한 뒤 소128×96·중192×144·대256×192·석조대256×224로 결정했다. 크기별 새 생성본이며 소형의 확대 복제가 아니다.
- 석조대는 석조 건물용 아치 동바리·수직 버팀·목재 지붕구조를 사용한다. 건물 본체·돌벽은 포함하지 않는다. 실제 건물 소켓별 배치·가림 검증은 코드 통합 단계에 남는다.
- 구조물 틈의 투명도와 각 시트의 투명 간격 확인. 최종 상세 프롬프트/원본 경로/처리는 effects.json에 기록했다. 모델 세부버전·seed는 제공되지 않아 미기재로 기록.
