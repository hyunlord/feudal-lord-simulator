## 원칙 점검

P-V1·P-M1: 엔진에 없는 성장 상태를 만들지 않는다. P-T5: 연도·장만으로 단계를 열지 않는다. P-V3: 과거 정적 합성과 이번 자료 검증을 실제 게임 검증과 구분한다. P-X1: 엔진·저장을 변경하지 않았다.

판단: 그림 계약의 `runtimeSha256`와 `approved-footprint`를 꾸며 채우는 대신 설치 전 자료로 넘긴다. 엔진이 조건을 제공하면 기존 landmark 계약 종류에 연결한다. `LANDMARK-GROW` 전체 완료가 아니라 렌더 자료 준비 완료다.
