# RB-MUSTER1 — 징집 수락 뒤 빈 과녁 공터 1장

실제 징집 청원을 수락하고 `war.conscripts.men > 0`인 동안, 원래 초지의 안전한 한 곳에 기존 과녁 공터 PNG 한 장을 그린다. 사람이 없는 장식 장면이다. 경제 건물·군대 위치·병사 수·군사 행동은 추가하지 않았다. 제품은 `04f1fd7a`, 기본 관목·돌·풀 포기 예약 보완은 `c33184cd`, 통합 기준은 `2b6d820c`다.

## 실제 게임 화면

저장소에는 활성 장면 전후4장을 대표로 남긴다. 전체16장(8쌍)과 아래 결과 JSON이 가리키는 모든 그림은 전달 ZIP의 같은 `report/before/`, `report/after/` 경로에 들어 있다. 저장소의 증거 폴더3MB 제한에 따른 분리이며 원본 캡처는 삭제하지 않았다.

`before/`는 본선 `2b6d820c`, `after/`는 이번 제품을 사용한다. 1338년 봄의 같은 저장·상태·카메라로 4시점 × 줌1.0·0.6, 전후8쌍을 캡처했다. 양쪽 상태 SHA256·저장 SHA256·틱·카메라가 모두 일치한다(`comparison.json`). 수락 전152000틱에는 없고, 정상 수락 직후152000틱과152249틱에는 보이며,152250틱에 사라진다. 표시 중 위치는(41,53)으로 같다. 세계 캔버스의 실제 drawImage 소비 추적은 활성4뷰에서 양성(기록 상한100회), 이전판·수락 전·만료 뒤는0회다. 100회는 PNG 개수가 아니다.

과녁·짧은 울타리·깃대가 성벽 밖 풀밭에서 읽히고 이웃 나무와 성벽에 육안 겹침이 없다. 0.6배에서 개별 무기 종류까지 읽힌다고 주장하지 않는다. 겨울에는 단일 잔디 그림을 숨긴다. 초봄 그림 면에 국소 서리를 다시 그리지는 않으며, 별도 겨울 PNG 설치나 겨울 자연 플레이 캡처를 주장하지 않는다. 생김·사라짐은 단계 전환이고 등장 애니메이션은 추가하지 않았다.

사진은 사용자 지시에 따라 Mac의 순차적 짧은 실제 Chrome 캡처로 만들었다. DGX 성능 수치로 사용하지 않는다. 두 개발 서버와 브라우저는 캡처 뒤 종료한다. 자세한 실행 경로는 `reproduction/`에 있고, `FLS_MUSTER_REPO`, `FLS_MUSTER_PROOF`, `PLAYWRIGHT_MODULE`을 자신의 경로로 지정한다. 상태는 `states/*.save.json.gz`를 풀어 같은 이름으로 둔다. 원본 캡처 당시 브라우저 오류0건이다.

## 자연 저장과 엔진 사실

원본은 `docs/qa/round02/repro/saves/chapter2-before-war1336.json.gz`(seed1, tick144135, 정상 UI 진행 저장), SHA256 `f3796585260fe0d2f963809236a34f52e9ef0b6b0124711b497c421ee189f5a8`다. 현재 codec으로 읽은 뒤 정상 자동 결정과 advanceTick으로152000의 열린 청원까지 진행했다. 공식 보존 실행은 **`astra-MUSTER-natural-prep-dbf6027`**이다. 정상 `petition_response:accept` 명령이14명을 징집했고, 뒤249+1틱도 정상 진행이다. 날짜·인원·건물·점유 필드를 강제로 바꾸지 않았다. 초기 준비 실행은 이전 배치 정책으로 음성이었고, 자연 저장 자체를 최종 정책으로 재사용했다.

`levy_response`의 accept만 허용한다. 거절·면제금·만료·0명·귀환·응답 시각 없음은 숨김이다. `0 <= tick - respondedTick < 250`은 렌더 연출 시간이며 역사적 훈련 기간이나 엔진 군사 사실이 아니다. 귀환 시점이 먼저 오면 즉시 끝난다. 저장 재불러오기나 되감기는 저장된 tick을 그대로 따른다.

## 고정 위치와 공간 안전

출신 주택 ID들은 위치 단서일 뿐 군대의 현재 위치가 아니다. 첫 출신 주택으로부터24칸 범위에서 저장된 모든 출신 주택의 외곽을 벗어난 원래 초지를 찾는다. **그림 전체를 역투영한 지지 범위의 최소 지형 여유가 가장 큰 공터**를 고르고, 같은 여유는 첫 주택과의 거리→ty→tx로 정한다. 원래 물은 `drainage.drained`를 통해 복원하므로 간척이 새 후보를 만들지 않는다. 벌목은 terrain 대신 `forestHarvests` 기록을 바꾼다. 출신 주택 하나라도 없어지면 숨긴다.

후보 선택은 현재 건물·도로·시골 장식 점유를 읽지 않는다. 고른 한 곳이 점유되면 숨기며 차순위로 이동하지 않는다. 그리기 직전 전체 래스터 지지 범위, 도로·건물·공사·성벽·구역·수목3칸 여유, 기존 건물/마당/울타리/농장/시골 소품/계절 및 화재 장면의 보수적인 그림 사각형을 검사한다. 화면·줌·그림 디코딩 순서가 위치를 고르지 않는다. 캐시는 동일 입력 계산을 재사용할 뿐 위치 이력을 저장하지 않는다.

진단 당시 단순 최근접 정책은 seed1의 지형 후보182개 중 실제 비는10개를 놓쳤다. 구 codec seed2의 정적 참고 검사도484개 중59개가 비었지만 첫 후보는 겹쳤다. 그 seed2는 현재 codec이 거부하므로 자연 양성/플레이 증거에 포함하지 않았다. 외곽 여유 수치를 늘리거나 점유를 보고 재선택하는 대신 그림 전체의 지형 여유로 일반 정책을 바꿨다. `placement-policy-diagnostics.json`의 과거 후보/중간 pivot 중심 비교와 최종 전후 화면을 구분한다. 단 한 유효 자연 저장의 성공은 모든 지도에서 보임을 뜻하지 않는다.
