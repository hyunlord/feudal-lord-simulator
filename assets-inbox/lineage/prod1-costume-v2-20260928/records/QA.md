# 검수 결과

## 시각 검수

- L4 38장: 원본과 교정본을 실제 96px로 나란히 확인했다. 얼굴, 머리 모양, 표정, 연령 단계와 흉상 구도의 뚜렷한 변화는 보이지 않았다. 생성 편집의 미세한 붓질·픽셀 변화는 있으며 원본 얼굴의 픽셀 동일성을 주장하지 않는다.
- 성인 남성 11장: 청·자주 모직, 갈색 모피 깃, 머리 뒤에 내린 후드. 기존 머리 모양 보존을 우선해 머리 위 모자는 추가하지 않았다.
- 성인 여성 11장: 기혼 8장은 베일·윔플, 미혼 3장은 드러난 머리 유지. 청·자주 모직과 모피 깃 적용.
- 아기·어린이 16장: 포대기·보닛 또는 기존 어린이 비례와 머리를 유지한다. 아기에게 성인 모자·지갑·허리띠를 붙이지 않았다. 아기와 어린이의 모피 장식은 성인보다 약하다.
- L5_102 3장: 올리브 옷과 황토빛 머리수건, 길어진 하안면·턱으로 L4_102와 구별된다. 청년·장년의 차이는 96px에서 미묘하며 노년 변화는 뚜렷하다. 다른 L5 인물을 다시 생성하지 않았다.
- 허리띠·지갑은 기존 흉상 범위 밖이라 대부분 보이지 않는다. 이 부분은 요청한 복식 요소 중 표현하지 못한 항목이다. 구도를 확대하거나 팔·소품을 새로 그리지 않았다.

## 옷만 보고 계급 맞히기

독립 검수 에이전트에 이름·정답·다른 비교판을 주지 않고 30개의 번호와 옷 부분만 제시했다. 얼굴·피부색·머리·체형은 판단에 사용하지 않았다. 가문당 인원 할당도 알려주지 않았다.

| 분류 | 정답 |
|---|---:|
| 영주 가문 L3 | 10/10 |
| 상인 가문 L4 | 10/10 |
| reeve 가문 L5 | 10/10 |

검수자는 넓고 밝은 모피·금색 테두리와 상인의 갈색 깃·앞여밈, reeve의 평복을 구별했다. 다만 영주와 부유한 상인은 역사적으로 복식이 겹칠 수 있고, 이 검사도 영주·상인 분류 확신이 상대적으로 낮았다. 30/30은 이 그림 묶음의 시각 분류 결과이며 모든 플레이어의 판독이나 역사적 신분 증명을 뜻하지 않는다. 하단 옷 크롭이므로 모자·머리쓰개 구별은 이 검사에 포함하지 않았다.

## 파일 검증

- 신규 41장 고유 ID, 256×256 RGBA 확인.
- L4 38장 내보내기에서 누락된 불투명 알파 채널을 추가했다. 변환 전후 디코딩 RGB는 동일하며 재생성하지 않았다.
- 원본 본 제작 160장 SHA256 불변.
- 실제 입력 참조·생성 원본 경로 존재, 출처 SHA 일치.
- CSV 41행·19열, 전체 셀 재읽기 일치. 생성 도구가 공개하지 않은 모델·seed는 미제공으로 기록.
- 확인 그림 4장 생성·열람. 압축 후 CRC 및 SHA256SUMS 전체 대조는 delivery-validation.json에 기록.
- 게임 설치·런타임 검수 없음. 기존 승인 원본은 보존하고 신규 결과는 candidate로 납품한다.
