# Wave 7 제작·검수 계획

사용자 첨부 의뢰서 상세 목록 A12+B5+C20+D12+E10+F8+G6+H4=77 PNG. 요약의 약60보다 상세목록을 우선하여 누락 없이 제작한다. 확인 그림4장, CSV77행, 검수표. 게임 미설치 candidate.

1. 첨부 규격·프로젝트 원본 확인.
2. 여섯 독립 제작 범위에서 family 대표1–2개 → 12×12 합성/0.6줌 판독 → 나머지 변형 제작.
3. 주택 눈/판자는 원본 캔버스에 등록된 영역 마스크로 한정, 원본 집 픽셀 불변. 단순 크기 일치를 정합 증거로 사용하지 않음.
4. 루트는 밀→빵→집 합성 및 네 확인 그림 통합검수. 방앗간 참조는 프로젝트의 기존 기둥풍차·화덕만 사용. 집 연기 기준점은 지붕 틈, 굴뚝을 추가하지 않음.
5. 기술 검사: PNG 치수·RGBA·알파·파일수·출처·전체 프롬프트·CSV 재읽기·SHA256·ZIP CRC.
6. 0.6줌=새소품 원본0.3배. 첨부 주택/워커는 별도의 작은 런타임 캔버스이므로 합성에서 배율을 따로 명시. 읽히지 않는 종류·방향·양단계를 검수표에 명시한다.

제품 코드·경제·상태·실제 런타임 검증은 범위 밖. 생성 원본과 실제 처리 기록을 보존한다.
