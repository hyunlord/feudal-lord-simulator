# Wave23 후보 제작 계약

사용자가 승인한 의뢰서를 그대로 실행한다. 설치·제품 코드·이전 납품 변경 없음. 14 날씨 + 20 생활 + 24 상태(12종×96/48) + 4 왕실(2종×256/96) + 20 패드(10시트×48/32) = 최종 PNG82, 확인 그림4. 크기 파생본은 별도 파일로 기록한다.

## 표현
- 프로젝트 참조의 손그림·저채도·좌상단 광원. 생활은 2:1 등각·접촉 AO·투명 RGBA. UI는 P0의 잉크/양피지/절제된 목재 색.
- 날씨는 RGB 그림과 적용 blend/opacity 계약을 분리. 불투명도 상한은 실제 확인 합성에 사용하고 CSV에 기록한다. 같은 화면의 UI 영역은 날씨 효과에서 제외한다.
- 동물 비례는 cattle_pair 원본128×96에 배율0.24 적용한 기준. 한 소의 몸통 길이를 직접 표기·측정하고 신종의 몸통 길이 비율·표시배율 기록. 머리/꼬리 포함 외곽 폭을 몸통 길이라 부르지 않는다.
- 걷는 닭·개는 방향별2프레임, 몸통/머리/꼬리의 보호 픽셀 동일. 날아가는 새의4프레임은 날개 동작이며 다리 제한과 분리.
- 상태 장식은96×96/48×48 투명 외곽, 가운데 얼굴 보존 영역을 침범하지 않는다. 죽음의 얼굴 흑백화는 미제작. 12명 확인판은 기존 초상 그대로 합성.
- 왕실은 heater 형태, 완성 채색. 1340 이후 프랑스 ancien의 semy fleur-de-lis(세송이 moderne 아님),1/4분면; 잉글랜드2/3. 사자는세로3마리 passant guardant.
- 패드는 중립 단색 양피지/잉크, 브랜드 로고·브랜드별색 없음. A/B/X/Y4,Dpad1,shoulderL/R쌍1,triggerL/R쌍1,stickpress1,menu1,view1. 쌍시트는2셀가로배치.32/48은셀크기.
