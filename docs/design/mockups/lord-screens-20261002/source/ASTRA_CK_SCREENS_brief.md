# Astra 의뢰: 크루세이더 킹즈식 영주 화면 시안 (디자인 탐색 · 1920×1080 시안 8장)

근거: 게임이 **영주 모드**(건물 대신 권리·약속·사람·돈)로 바뀌었다(첨부 설계서). 사용자 — "크킹 같은 게임을 시각적으로 보여 줘야 하니 크킹식 화면도 필요하다." 코드로 만들기 전에 **어떤 모습이어야 하는지** 시안으로 먼저 정한다. 지금 있는 그림(초상 풀·혈통·가계도 부품 Wave 25·협상 틀 Wave 35·영지 카드·버튼 Wave 38·문장 Wave 14)을 최대한 써서 조립하고, 없는 부분만 새로 그려. 임시 글자는 시안에만(한국어).

## 시안 8장
1. **인물 창**(크킹의 캐릭터 창): 큰 초상, 이름·나이·직책, **성격 특성 아이콘 줄**, 능력(관리·외교·무력·학식) 막대, 건강·상태, 가문 문장, 배우자·자녀 얼굴 줄, "나에 대한 생각" 수치와 이유
2. **가문(왕조) 창**: 가문 문장·창시자·세대·영지 목록·명성, 가계도 축약
3. **지역 지도**: 손그림 지도 위에 내 영지·이웃 영지(장원 아이콘·문장 깃발·길·강·시장도시), 영지를 누르면 영지 카드
4. **영지 포트폴리오**: 영지마다 카드 — 연간 가치·권원/점유 상태·청지기·위임·분기 요약
5. **가신·관리인 회의**(크킹 의회): 청지기·집사·reeve·서기·가신 대장 자리, 각 얼굴·능력·충성·하는 일
6. **협상·혼인**(Wave 35 틀 활용): 혼인 조항과 이유 칩, 상대 가문 초상
7. **도시의 요청·결정 알림 흐름**: 오른쪽 알림 열(크킹 알림), 우선순위·기한
8. **무력 창**(시안만): 가신단·징집 가능 인원·국왕 원정 소집 요청 카드·사적 분쟁 진행 — 아직 엔진에 없음, **모습만 탐색**

## 판정 기준(확인 그림에서 스스로)
- 크킹처럼 **인물이 중심**이고, 정보가 많아도 **위계가 읽히는가**(크게 → 작게)
- 지금 게임 화풍(양피지·oak·저채도 손그림)과 같은 세계로 보이는가
- 1920×1080과 1280×800 두 판

## 제출
시안 8장(두 해상도) + 새로 필요한 부품 목록(아이콘·틀 — 다음 Wave 후보) + 설명 문서. 경량 ZIP. 게임 미설치.
