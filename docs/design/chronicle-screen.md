# 연대기 화면 명세 — CHRON-1

기준: [기록·연대기 설계 v1](CHRONICLE_DESIGN.md) 2절, 원장 [history-ledger.md](history-ledger.md) HL-1~HL-10, 인물 [persons.md](persons.md) PS-7. 화면 코드 `src/ui/chronicle/`, 문구 `chronicleScreenCopy.ko.ts`.

## CH 규칙

| 번호 | 규칙 |
|---|---|
| CH-1 | 연대기는 상태 기계의 `history` 모달이다(전체 화면, 모달이 떠 있는 동안 시간 정지). 장부 서랍의 [연대기] 탭, 단축키 C(모달이 없을 때 열고, 연대기 위에서 다시 누르면 닫음), 장 끝 페이지의 [전체 연대기 보기]로 연다. Esc는 연 곳으로 돌아간다. |
| CH-2 | 연대 띠는 Wave 19 `timeline_strip_base`다. 색 다섯 칸은 시나리오의 다섯 시대이고 칸마다 같은 폭, 칸 안은 시간에 비례한다. 들어선 시대는 들어선 틱에서, 아직 안 온 시대는 그 해(지났으면 지금 다음)에서 시작하고, 마지막 칸은 1450년에 끝난다. 장은 띠 아래 막대다. |
| CH-3 | 띠의 표식은 다섯 종(결정·시대·사건·이정표·인물)이다. 띠를 48칸으로 나눠 칸마다 가장 무거운 기록 하나(심각도, 같으면 시대 > 사건 > 결정 > 이정표 > 인물, 같으면 나중 것). `timeline_pin_now`는 지금, `timeline_pin_select`는 고른 때다. 띠를 누르면 그때로 가고, [계절 보기]는 고른 때 둘레 16계절 자(계절마다 기록 수와 표식)를 연다. |
| CH-4 | 기록 카드는 새 것이 위다. 틀은 종류별 Wave 19 여섯(`frame_record_*`), 그림은 Wave 16 연대기 삽화(`chronicleIllustration`), 석벽 선포·완성은 Wave 17, 인물 기록은 그 해 나이의 초상, 결산·계절 손길은 그림 없음. 한 줄은 원장 문장(`history.summary`)이고, 인물 기록은 이름을, 집 기록은 "…의 집"을 앞에 붙인다. |
| CH-5 | 한 계절의 일상 결정 줄(`decision.bundle`, 종류별)은 카드 하나 "이번 계절의 손길"로 묶는다. 접힌 계절 요약(`ledger.rollup`, HL-10)은 집계만 보인다 — 원본이 지워졌으므로 펼치기가 없다. |
| CH-6 | 거르기: 종류 여섯 칩, 중요도(모든 기록 · 이정표·큰 결정 이상(처음) · 사건 이상 · 시대만), 부터·까지 해, 인물(원장에 이름이 나온 사람, 기록 많은 순). 인물을 고르면 중요도는 "모든 기록"이 된다(한 사람의 줄은 대개 일상이다). |
| CH-7 | [위치로]는 연대기를 닫고 지금 지도의 카메라를 기록의 자리로 옮긴다(`lookAt` 의도). [그때 지도]는 기록의 축소판, 없으면 한 계절 안에 뒤따르는 계절 마감의 축소판, 그것도 없으면 바로 앞의 것을 보인다. |
| CH-8 | 그때 지도는 `history.snapshot`의 색 번호를 `palette.ts` 색으로 칠해 `frame_snapshot_map_320` 안에 둔다. 마을이 지은 칸(길·집·시설·공사·구역·불탄 집·빈 집·성벽)을 둘러싼 정사각형(한 변의 1.5배, 최소 지도 1/4)만 확대한다. [지금과 나란히]는 지금 지도를 같은 크기로 래스터해 같은 정사각형으로 `frame_snapshot_map_160` 두 장을 나란히 둔다. |
| CH-9 | 결정 기록은 `frame_decision_compare` 세 칸: 고른 길(삽화), 다른 길, 예측과 실제(`icon_predicted`·`icon_actual`, 실제가 크면 `icon_delta_up`, 작으면 `icon_delta_down`). 실제가 아직이면 "실제는 <달력>에 적힙니다". 큰 결정은 카드마다, 배치류는 CH-5 계절 묶음. 결정 카드의 상세는 결정 기록이 먼저이고 [그때 지도]로 지도를 본다. |
| CH-10 | 인물 전기는 `frame_biography` 한 쪽(원화 640×800, 한 배율): 큰 원에 지금 나이의 초상과 매칭 표시(정체성·단계, "성별·나이대·계층 일치" 또는 "가장 가까운 그림"), 작은 원에 배우자(또는 가구주), 오른쪽 위 이름·생몰·역할·직업·집·맡은 일, 오른쪽 줄에 생애(`biography_life_dot`, 죽음·떠남은 `biography_life_end`), 아래 띠 둘에 관계(가족 칩 → 그 사람의 전기, 떠난 뒤에는 "남은 식구")와 함께 남긴 큰 기록(칩 → 그 사람의 모든 기록 속 그 기록). 방패 칸은 UI-5의 문장 자리다. |
| CH-11 | 세력 페이지 `frame_faction_page`는 틀만 등록한다(`FactionPage`, 칸 여덟: 수장 초상·문장·이름·관계 척도·요구·약속·우리와의 사건·그 세력의 사건). E단계 세력이 생기기 전에는 여는 곳이 없다. |
| CH-12 | 성능: 목록은 가상 스크롤(카드 112 px + 간격 8 px, 보이는 줄 ± 3만 만든다). 원장 3만 건을 열어 첫 카드가 그려지기까지 200 ms 미만. 모델 계산은 원장·거르기가 바뀔 때만 한다(연대기가 떠 있는 동안 시간은 멈춰 있다). |

## 초상 풀 설치

PERSON-0 `portraitPool.ts`의 232장(파일럿 36 + 노화 사슬 12, 1차 92, 2차 92 = I037~I100)이 `scripts/installChronicleArt.py`로 설치된다. 받은 PNG(256×256, 불투명, eXIf 덩이)는 `assets-inbox`에 두고, 빌드 때 256 px와 96 px(면적 평균) 기준선 JPEG을 만든다(`scripts/keyartDerivatives.ts`, 품질 82, 약 10.8 KB·2.5 KB). 작은 칸(≤ 96 px)은 96을 1x, 256을 2x로 쓴다. 대장 `docs/provenance/assets.csv`에 한 장씩(`portrait/<id>`), 받은함 대장의 `installed_by`는 CHRON-1. 2차 92장의 받은함 상태는 `candidate — 판정 전` 그대로다(지시서가 설치를 지시, 판정은 사용자 몫).
