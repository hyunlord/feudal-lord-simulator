# RB-PHASE2 통합 증거 준비본

실제 게임 17개 장면을 같은 저장·카메라·시각으로 비교했습니다. 전후 각각 17개 장면의 반복 촬영은 픽셀이 같았습니다. 전후 비교에서는 봄 지역 지면 4개 장면만 예정대로 달라졌고 나머지 13개 장면은 전체 RGBA가 같았습니다. 독립 검수자는 원본 PNG 34개를 모두 열어 봄 4개 장면의 변화가 읽히고 새 파손·가림은 관찰되지 않는다고 판정했습니다. 현재 UI를 포함한 전체 기하 감사는 2,202조건에서 실패·미개방·재시도0으로 끝났습니다. 최종 HEAD 검사·깨끗한 클론·본선 게시 관문은 아직 완료하지 않았습니다. 이 폴더는 게시 완료 보고서가 아닙니다.

## 무엇이 달라졌나

## 어떻게 확인했나

비교 기준은 BEFORE `38be7e4a80001b05bc883ec770e9b7be2d1421a8`, AFTER 세계 실행 `718dce4b60c5cb0c5be0178284034ed49bfc67f7`입니다. 현재 UI를 병합한 `2fdbb11d55ccc2d7206798002554e1b3117bd79a`의 전체 런타임 검증으로 바꾸어 말하지 않습니다. 그 입력에 대한 전체 기하 감사는 완료했으며 최종 HEAD 검사·깨끗한 클론·본선 게시 확인은 별도 관문입니다.

`RAW_INDEX.json`은 전후·최초·반복 PNG/JPEG 136개 원본의 절대 경로, SHA256, 크기와 해상도를 기록합니다. 원본은 외부 실행 폴더에 보존했습니다. `SELECTED_IMAGES.json`에 적은 18개 JPEG만 `images/`에 바이트 그대로 복사했습니다. 그림을 재생성·편집·재압축하지 않았습니다. 지역 8개 장면의 전후 16장과 사람 키 관찰 장면의 AFTER 2장입니다. 모든 원본 파일의 해시·바이트 수·이미지 형식과 PNG 68개의 청크 CRC를 확인했습니다. 압축 ZIP은 아직 만들지 않았으므로 ZIP CRC 검증 결과는 없습니다.

`PAIR_RESULT.json`은 수치 비교 결과의 원본 사본입니다. 봄 4개의 `pixels.pass=false`는 예정된 변화가 검출됐다는 뜻이며, 전체 비교 판정은 `pass=true`입니다. 독립 원본 검토는 `NATIVE_REVIEW.md/json`에 따로 보존했습니다. 구름 그림자의 충분한 가시성·이동과 사람 해부·문 대비 키는 여전히 불확실합니다. 수치 영수증의 `nativeReview=PENDING`은 당시 상태를 보존한 것이며 후속 독립 검토가 이를 보완합니다.

판단: 준비본에는 확인된 수치·원본 연결과 제한된 17쌍 독립 시각 검토를 담고 현재 기하 결과까지 담고 최종 게시 결과는 보류합니다. 작업 장부와 STATUS/ROADMAP의 담당 행도 같은 검증 상태로 맞췄습니다.

## 별도 보존한 이전 전체 기하 감사

세계 실행 `718dce4b`·입력 해시 `acb0a3ef`의 공식 전체 기하 감사가 완료됐습니다. 122행의 도달 가능 조건 2,202개에서 실패0·재시도0이며, 경고693개와 도달 불가4행/60조건은 그대로 보존합니다. 소스 불변 확인과 최종 영수증 해시를 `HISTORICAL_718_GEOMETRY.json`에 기록했습니다. 이는 이전718 입력의 역사 증거이며 현재 UI를 합친 `2fdbb11d`의 별도 전체 기하 감사나 최종 클론·게시 관문을 통과했다는 뜻이 아닙니다. 현재 입력의 기하 결과는 아래에 별도로 기록합니다.
