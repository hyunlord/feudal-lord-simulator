# 성벽·목책 띠 접합 모서리 후보

2026-10-03 / **시각 승인 실패·눈가림 목표 미달** / `candidate` / 게임 파일 설치·수정·커밋 없음.

기존 매끈한 기둥을 재색칠하는 대신 현재 게임의 잡석 벽면, 흉벽 윗면, 목책 벽면·윗줄 PNG를 절단하고 등각 투영해 모서리를 만들었다. 새 그림 생성, 인페인팅, 수작업 돌무늬 추가는 하지 않았다. 겨울의 작은 눈 조각도 저장소의 기존 겨울 담장 그림에서 잘랐다.

## 구성

- `assets/`: 4방향 × 석벽·목책 × 여름·겨울 = **16 RGBA PNG**.
- `manifest.json`, `manifest.csv`: ID, 1024×768 캔버스, 피벗 (512,544), 월드 배율 0.125, SHA256.
- `proofs/final-*.jpg`: 재료·계절별 네 방향 확대판 4장과 원래 저장 상태의 모서리 확대판 1장.
- `proofs/scenes/`: 최종 실제 브라우저 캡처의 경량 JPEG 확인판 20장. 확대판은 원 캡처의 (480,265)–(800,445)를 2배 최근접 확대했다.
- `blind/`: 눈가림 자극·정답·독립 검수자의 고정 답안. 1차와 2차 실패도 기록에 보존한다. 최종 수치와 한계는 `BLIND_REVIEW.md`.
- `records/`: 원본 위치, 재현 스크립트, 캡처 조건, PNG 검사, 수정 전후 검수.
- `SHA256SUMS`: 압축 내부의 모든 파일에 대한 해시(자기 자신 제외).

## 방향

| 이름 | 모서리에서 나가는 타일 축 두 방향 | 화면에서 읽히는 꺾임 |
|---|---|---|
| north | +X, +Y | 위 꼭짓점, 안쪽 면 |
| south | −X, −Y | 아래 꼭짓점, 바깥쪽 면 |
| east | −X, +Y | 오른쪽 꼭짓점, 한쪽 안면·한쪽 바깥면 |
| west | +X, −Y | 왼쪽 꼭짓점, 반대쪽 안면·바깥면 |

각 후보는 두 팔을 한 장에 가진 90도 접합이다. 네 방향을 단순 회전한 것이 아니라 각 방향의 면·그림자·겹침을 다시 투영했다. 45도·135도 꺾임과 임의 각도는 이 16장의 범위 밖이다.

## 게임 확인의 범위

최종 그림은 화면 위에 사후로 붙인 합성이 아니다. Playwright가 Vite 응답을 메모리에서만 바꾸어 기존 모서리 모듈의 그리기 위치에서 후보 PNG를 그렸고, Chrome의 실제 게임 화면을 캡처했다. 연결될 양쪽 띠는 각각 0.65타일 비우고 후보의 1타일 팔과 0.35타일 겹쳤다. 후보 뒤에 다시 그려지던 기존 단면도 이 임시 프리뷰에서 생략했다. 이 처리가 없는 단순 덮어쓰기는 올바른 적용 방법이 아니다.

네 방향 검수는 실제 seed2 저장 상태에서 벽 경로만 사각형으로 바꾼 **검수용 배치**다. (39,29), (61,29), (61,47), (39,47)의 숲·건물·경작지 배경을 이용했다. 건물을 통과하는 배치는 플레이 가능한 도시 배치의 증거가 아니다. 추가 4장은 원래 저장 상태의 성벽 경로를 유지한 (64,26) 모서리에서 재료와 계절만 바꿔 촬영했다. 총 5개 위치, 20개 장면이다.

정식 렌더러 통합, 임의 UV 위상·벽 변형 전체 조합, 모든 줌/DPR, 움직이는 가림, 충돌·경로·성능은 검증하지 않았다. 승인된 창고 눈 3장은 이번 산출물과 별개이며 수정하지 않았다.

## 남는 제약

원본 목책 띠의 상단에는 벽체와 떨어져 보이는 두 번째 말뚝줄이 있다. 같은 원본을 쓰되 뒤쪽 목재 면으로 틈을 받쳤다. 두 줄의 회전부 밀집은 남는다. 이를 원본 전체까지 자연스럽게 고치는 일은 모서리 조각만으로 해결되지 않는다. 원본 직선 벽에는 계절용 눈 띠가 없어 겨울 후보의 눈은 작은 부분 적설로 제한했다. 겨울 전체 성벽의 적설을 완성한 패키지가 아니다.

정식 적용 시 고정 PNG의 양 끝과 절차적 띠의 텍스처 위상이 모든 길이에서 자동으로 일치하지 않는다. 현재 검수에서 사용한 겹침과 단면 생략을 유지하거나 `ASSEMBLY.md`의 같은 접합 규칙으로 런타임 위상에 맞춰 절단해야 한다. 무조건 설치 가능한 완성품으로 표시하지 않는다.
