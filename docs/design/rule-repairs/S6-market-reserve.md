# S6-F1 공사 자재 판매 제외 (R-6)

R1 S6-F1의 재현값: S0 본선에서 성채 수요 석재150, 창고100일 때 시장30주기 후 석재70/금화240. 기존 civicConstructionReserve는 교회만 보호하여 성채 수요를 제외한다.

- S6-F1.1 모든 진행·예약 공사장의 미배송 수요(required - delivered - reserved)를 자원별 합산해 판매 후보에서 보호한다. 운송 중인 화물을 다시 세지 않는다.
- S6-F1.2 기존 미배치 교회 예산 보호와 목책 시대 석재400 보호는 유지한다. 교회 공사장 수요는 한 번만 센다.
- S6-F1.3 시장은 실제 연결 창고의 출고 예약을 뺀 재고가 보호량을 초과할 때만 초과분을 판매한다. 여러 시장도 앞선 판매를 반영한다.
- S6-F1.4 비용·생산량·판매 가격·저장 형식은 바꾸지 않는다. 판매 품목 선택은 C2 범위다.
