# RB-PASTURE-FACILITIES — 목장의 작업 울타리와 빈 우리

제품 `41d857b2`는 확정 원본 I0417 양털 작업 울타리와 I0418 빈 양우리 2장을 설치한다. 실제 목축 농장과 소유 목초지가 있어야 하며, 농장에 fleece 재고가 양수이면 양털 더미가 있는 작업 울타리를, 그렇지 않으면 빈 우리를 고른다. 농장마다 이 묶음은 최대 하나다. 그림이 새 가축·일자리·생산을 만들지 않는다.

계약의 `pastureYard`에는 묶음·우선순위·필요한 양수 재고 키를 적는다. 자리는 기존 목초지 소유와 결정론적 해시 순서를 따르고, 그림 전체의 발판과 기존 농장·동물·Wave28 울타리 예약을 함께 검사한다. 자리가 없으면 생략한다. 기존 세척 연못은 먼저 배치하므로 기존 위치와 물 근접 조건, 겨울 숨김이 유지된다. 새 두 그림은 정본 메타데이터의 all-season을 따라 겨울에도 보인다.

## 실제 저장과 비교 방법

자연 성장 원본은 v46 chapter-five-town(1382년, 농장88 fleece124)과 v30 ch4-1380(농장 두 곳 fleece0)이다. 정본 저장 로더로 이주한 뒤 여름·겨울 시점을 tick만 바꾼 정지 QA 사본을 만든다. 새 재고·씨앗·농장·가축·보행자는 넣지 않는다. 원본→이주→준비 전체 값과 변경 필드는 ZIP에 보존한다. 이는 계절 동안 엔진이 실제 진행한 경제를 증명하는 자료가 아니다.

물가 회귀는 기존 `tests/fixtures/pasture-wash/seed5.json.gz`의 준비된 1601년 상태를 현재 코덱으로 감싸고 다시 검증한 별도 표본이다. 이 파일을 구형 bare-save로 이주하면 과거 이주 규칙이 달라져 기존 연못 표본이 사라졌으므로 첫 준비 시도는 실패로 보존했다. 이 표본은 시대 내 자연 성장 자료로 세지 않는다.

6개 같은 상태를 전후 각각 줌1·0.6·1.4에서 비교한다. 여름/겨울의 양털 작업장, 빈 우리, 물가 연못을 본다. 카메라·seed·tick·실제 상태·실제 보행자 동일 여부와 실제 draw URL/위치/alpha를 기록한다.

## 원본과 크기의 한계

두 PNG는 256×192, pivot(128,184), uniform scale0.25로 원본 바이트 그대로다. 캔버스 전체 높이48세계px에는 바닥 깊이가 포함되므로 울타리 키로 해석하지 않는다. 원본에서 수직 말뚝의 대략적 높이는 빈 우리 약30px, 작업 울타리 약45–50px, 작업 통로의 높은 기둥은 약60px이다(수동 식별 오차와 가림 존재). 세계 약7.5·11–12.5·15px이며 성인17.6px 기준과 실제 플레이 줌에서 함께 판정한다. 유효 문 개구부나 정밀 건축 실측 인증은 아니다.

겨울 전용 눈 그림은 없다. 그림 자체의 황갈색 바닥·잔디가 겨울 주변 땅과 다르게 보일 수 있다. 완전한 눈 덮임을 주장하지 않는다. 전체 사각형 예약은 보수적이라 좁은 목초지는 배치가 생략될 수 있고, 움직이는 보행자가 시설 곁을 지나는 모든 순간을 충돌 없이 증명하지 않는다.

회귀18개는 기존 연못 좌표·id, 물가/겨울 조건, 양수 재고 선택, 건조 목초지, 농장당 하나, 공유 예약과 상태 불변을 확인했다. 타입 검사와 대상 린트를 통과했다. 원격 캡처·기하·최종 트리 변경 시험·병합 검사의 실행 이름과 결과는 게이트 영수증/ZIP에 기록한다.
