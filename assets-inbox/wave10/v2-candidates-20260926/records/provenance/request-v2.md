## 1. 결합 규격 v2 (모든 레이어에 적용)
- **기준점 6개** 고정(256 캔버스): 눈선 y=112, 어깨 y=208(기존) + **정수리 y=40±3, 이마선 y=70±3, 귀 중심 (x=150, y=120)±3, 턱 끝 y=168±4**. 얼굴 20장 모두 이 여섯 점에 맞춘다. 두개골 크기 차이는 이 안에서만.
- **머리 크기 등급 2**: `adult`, `child`(정수리 y=56, 턱 끝 y=160, 머리 폭 88%). 머리·수염·머리쓰개는 등급별로(아이용은 어른 것을 88% 축소 후 보정 — 수량은 아래).
- **가림 마스크**: 머리쓰개마다 `*_hairclip` 마스크(흰색 = 머리카락이 **보여도 되는** 영역)를 함께 낸다. 합성 시 머리·뒷머리는 이 마스크로 잘린다. 후드는 얼굴 둘레 좁은 틈만, 챙 모자는 챙 아래·귀 뒤·목덜미만.
- **"덮개 아래" 머리 변형**: 긴 머리·풍성한 머리(f_01·f_02·f_03·f_07·f_08·m_01·m_03·m_08·m_09)는 `_tucked` 변형(후드·베일 속으로 눌린 모양, 앞머리 조금만) 1장씩 추가.
- **가장자리**: 모든 레이어 알파 가장자리 defringe(가장자리 1~2px의 색을 안쪽 색으로 확장, 밝은 테두리 0). 검사: 짙은 배경(#202020)과 밝은 배경(#E8E2D4) 양쪽에서 테두리 없는지.
- **호환 표시**: 의복 레이어에 `collar: fur|plain|hood` 태그를 CSV에 적는다(후드 망토는 모피 깃과 함께 쓰지 않는다 — 코드 규칙용).

## 3. 확인 그림 (필수, 전부 256px과 96px 두 크기)
1. 얼굴 20장 나열 + 기준점 6개 표시선
2. **결합 시험 격자**: 행 = 얼굴 6개(f 2, m 2, c 2), 열 = [맨머리, 긴 머리, 긴 머리+후드(tucked), 짧은 머리+챙 모자, 회색 머리+나이 old, 수염+후드] → 36칸. **머리카락이 모자 위·후드 밖으로 나온 칸 0, 밝은 테두리 0**
3. 나이 전후(m_01·m_05·f_01·f_05, old + 회색 머리)
4. **무작위 48명**(24 → 48로 늘림), 256px과 96px. 결함 표 0절 1~5가 한 칸도 없는지 스스로 판정하고, 있으면 번호와 칸을 적어 줘
5. 짙은 배경·밝은 배경 가장자리 검사 각 1장
