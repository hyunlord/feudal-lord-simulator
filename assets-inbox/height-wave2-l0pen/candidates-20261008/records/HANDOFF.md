# RB-HEIGHT-WAVE2-L0PEN — 설치 전 후보 6장

`manifest.json`의 body03, snow03, boarded01, strained01, neglected01, vacant01을 인계한다. 제품 파일·커밋·DGX 실행은 없다. 실제 게임의 17.6px 성인과 문 비교, 상태 선택·계절 혼합은 설치 담당자가 확인해야 한다.

전부 153×185이며 scale 0.4995704948646126, pivot (77.35406698564593,171.57894736842104)이다. 기존 153²에서 위 여백32를 추가했으므로 pivot도 +32다. 생성 본체는 전체 +13Y로 등록했다. 층은 최종 본체 공간에 생성했으며 선택 층의 추가 이동은 없다. 예전 condition inset을 다시 적용하면 안 된다.

문잎 중앙 추정은 43×20native = 21.48×9.99world. 문틀 바깥이 아닌 닫힌 문잎이며, 열린 개구부를 직접 측정한 것은 아니다. 길이 ±2native 오차를 따로 기록했다. 원본 문은 약25×11이었다. 철물띠 사이만 재지 않고 띠 위아래 실제 나무를 포함했다.

집 전체를 확대하지 않았다. 벽과 지붕을 위로 늘린 완성 그림을 생성해 지붕 정상은 원본+32 기준 약46native 높아졌다. 우진각 지붕 경사가 가팔라졌고 정밀한 원형 동일성을 주장하지 않는다. 발판 세 점 잔차는 2.24/5.10/3.61native(수동 좌표 ±2)다. 오른쪽 우리, 돼지 한 마리, 새 두 마리, 울타리와 문은 본체 그림 속 장식으로 남는다. 독립 엔진 동물이 아니다.

상태 구분: strained는 작은 회벽 손상, neglected는 지붕 마모와 더 큰 회벽 손상, vacant는 닫힌 창 덧문과 지붕·회벽 마모다. vacant를 abandoned와 혼동하지 않는다. boarded는 문·창의 교차 판자다. 다섯 단독 합성과 vacant+boarded+snow 합성을 직접 보았다.

눈은 목표 예외가 남는다. 수동 지붕 ROI에서 가중 알파80.22%, binary87.07%다. 가중60–80 범위를 0.22%p 넘으므로 정확 통과라고 쓰지 않는다. ROI ±2native 오차와 가장자리 눈 처짐·잔차가 있다. 본체 alpha32 바깥 눈110px, ROI 바깥357px를 숨기거나 잘라내지 않았다. snow01은 갈색 지붕 바탕까지 생성돼 제외했고, snow02는 전체 등록 후 가중56.66%로 부족했다. 모두 보존했다.

선택 6장의 캔버스 테두리 비투명 픽셀은0. 본체 +13Y 등록에서 잘려 나간 비투명 픽셀도0이며 서로 다른 검사다. 상태층·판자는 본체 alpha32 밖 픽셀0. 우리 내부 대략ROI(x≥90,y≥145)에 상태층·눈·판자 픽셀0. 이는 실제 게임 겹침·가림 검증을 대체하지 않는다.

원본·정확 프롬프트·실패·등록 전후를 남겼다. GENERATIONS.json은 10회 생성과 선택 여부, manifest.json은 파일·원본·프롬프트 SHA 및 변환을 기록한다. SHA256SUMS로 전체 파일을 확인할 수 있다. PNG 변경은 builtin imagegen과 전체 균등 리사이즈/이동만 사용했으며 부품 조립·워프·마스크 잘라내기는 하지 않았다. proofs는 확인용 합성이다.
