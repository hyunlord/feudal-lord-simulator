# 직업 스물과 작업장 원형의 그림 목록 (LM-E6a 넘김 → 렌더·Astra)

엔진이 깐 것: [직업과 작업장 명세](../design/trades.md) TR-1~TR-9. 데이터는 `src/content/trades.ts`, 이름은 `src/content/trades.ko.ts`, 상태는 `GameState.trades`(영주 모드에서만).
그림 원칙: Wave 36 교훈대로 **집 벽에 붙이지 않고 땅에 서는 마당 구조물·소품**으로. 금지 목록(홉 맥주, 원색 염료, 문 표식, 집 굴뚝 등)을 지킨다. 그림은 이 목록을 렌더가 Astra 의뢰로 바꿀 때 만든다(미리 쌓지 않음).

## 거리 이름표
- 같은 직업 가구 셋 이상이 모이면 거리 이름이 생긴다(`trades.streets`, `streetName`). 거리 이름표 그림 한 종(지도 위 글자 띠)과, 렌더가 줌 0.6에서 읽히는지 판정.
