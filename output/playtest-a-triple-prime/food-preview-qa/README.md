# A‴ 식량 시설 자재 경로 미리보기 UI 검사

제품 커밋 `df6c20d`의 빌드 결과를 별도 로컬 미리보기 서버에서 Chrome 1600×1100으로 열어 검사했다. 이 화면은 **합성 준비 상태**이며 새 게임 플레이나 60분 관문 증거가 아니다. `harness/`는 실제 제품 `GameCanvas`와 `PredictionPanel`을 사용하고, `capture.mjs`는 마우스 입력과 캡처만 수행한다. 실제 플레이 서버 4173에는 접근하지 않았다.

준비 상태에는 목재 100개를 가진 창고 `(3,4)`, 이어진 도로 `y=5`, 떨어진 길 한 칸 `(6,9)`이 있다. 방앗간 후보 `(6,4)`는 창고에서 자재를 운반할 수 있고, 후보 `(6,10)`은 바로 옆에 길이 있지만 창고 도로망에서 끊겨 있다.

| 장면 | 실제 제품 미리보기 | 캡처 |
| --- | --- | --- |
| 창고 연결 후보 | `✓ 도로 연결`, `✓ 자재`, `✓ 공사 자재 배송 경로` | [연결된 방앗간](connected-mill-preview-df6c20d.jpg) |
| 고립된 길 옆 후보 | `✓ 도로 연결`, `✓ 자재`, `× 공사 자재 배송 경로 (창고와 길을 이으세요)` | [고립된 방앗간](island-mill-preview-df6c20d.jpg) |

[캡처 판정 데이터](capture-model.json)에 실제 DOM 줄별 색조 클래스와 패널 표시 상태를 기록했다. 두 패널은 `display:block`, `visibility:visible`, 불투명도 1이고 브라우저 예외는 0개였다. 화면 원본을 직접 확인했으며 문구가 잘리거나 색에만 의존하지 않았다. 2장 JPEG와 JSON 합계는 약 344KB다. 실제 공사 완료나 생산까지는 이 검사 범위에 포함하지 않는다.
