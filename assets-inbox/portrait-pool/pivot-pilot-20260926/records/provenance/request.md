# Astra 의뢰: 초상화 방식 전환 파일럿 — 레이어 합성 중단, **완성 초상 풀(pool) + 같은 인물 노화 사슬**

작성 2026-09-26 · 판정: Wave 10 레이어 합성(v1·v2)은 **기술 결함을 고쳐도 "한 얼굴을 조금씩 바꾼 것"처럼 보이고 어색하다.** 원인은 방식이다. 레이어 합성은 정렬을 위해 **한 방향·한 두개골 틀·한 체형**을 강제하고, 손그림 사실풍은 레이어 이음과 광원 불일치를 숨기지 못한다. 반대로 **인물 파일럿 1의 완성 초상 6장은 자연스러웠다**(첨부 기준 이미지).
그래서 방식을 바꾼다: **한 사람을 한 장의 완성 초상으로 통째로 그린다.** 조합은 레이어가 아니라 **속성으로 골라 쓰는 풀**에서 한다. **Wave 10b 의뢰는 취소**(진행 중이면 멈춰도 됨).
첨부 `astra-portrait-pivot-reference-files.zip`: 파일럿 1 초상 6장(자연스러움 기준), 청지기 초상(화풍), 반려된 레이어 합성 48명, 딥리서치 전문

## 1. 풀의 축
| 축 | 값 |
|---|---|
| 성별 | 남·여 |
| 나이대 | 아이(8~13) · 청년(16~30) · 장년(30~50) · 노년(55+) |
| 계급·직업군 | 노동·농민 / 장인·소매 / 상인 / 젠트리·관리 / 성직자·수도자 / 빈민·하인 |
| 체형 | **마른 / 보통 / 살찐** — 얼굴·목·어깨에서 드러나게(볼살·턱살·광대·목 굵기) |
| 방향 | **왼쪽 3/4 · 오른쪽 3/4 · 거의 정면** 섞어서(좌우는 그림마다 다르게, 좌우반전 금지 — 코·머리 가르마·단추 비대칭 때문) |
| 피부·머리·눈 | 잉글랜드 남부 1300년 인구에 맞게 **대부분 밝은 피부이되 톤이 서로 다르게**(붉은기·누런기·주근깨·햇볕 탄 노동자·창백한 서기), 머리색 흑갈·갈·적갈·금갈·회색 다양 |
| 개성 | 이목구비를 **과감하게** 다르게: 매부리코·들창코·뭉툭코, 넓은/좁은 얼굴, 두꺼운/얇은 입술, 처진/올라간 눈, 이 빠짐, 흉터, 사팔눈, 큰 귀, 대머리·숱 적음, 수염 모양 — **"같은 배우의 다른 분장"이 아니라 "다른 사람"** |

## 2. 파일럿 (36장 + 노화 사슬 12장)
### A. 완성 초상 36장
위 축을 섞어 36명: 성별 반반, 나이대 아이 4·청년 10·장년 12·노년 10, 계급 6군 각 6명, 체형 마른 12·보통 12·살찐 12, 방향 왼 3/4·오른 3/4·정면 12씩. 각 인물은 **계급에 맞는 옷·머리쓰개·소지품까지 한 장에 통째로**(딥리서치 색·염료 규칙, 기혼·과부 여성 머리쓰개, 성직자 복장 규칙 그대로).
규격: 256×256, 흉상, 배경 단색(저채도 회갈), 좌상단 광원, 파일럿 1·청지기 화풍. **눈높이는 대략 캔버스 40~48% 사이면 됨**(엄격한 기준점 불필요 — 합성하지 않으니까).
### B. 같은 인물 노화 사슬 4명 × 3단계 = 12장
주요 인물은 수십 년을 산다. 같은 사람이 청년 → 장년 → 노년으로 늙는 3장을 **같은 사람으로 알아볼 수 있게**(A의 청년 4명을 골라 원본을 참조 이미지로 써서 늙게). 방향·옷은 바뀌어도 됨, **얼굴 골격·코·눈·귀·흉터·특징은 유지**.

## 3. 확인 그림 (3)
1. **36명 격자 256px·96px**: 이름 없이 봐도 36명이 서로 다른 사람인지, 체형·나이·계급이 읽히는지, 방향이 섞였는지. 스스로 "가장 닮은 두 쌍"을 골라 적어 줘
2. **노화 사슬 4줄**: 같은 사람으로 읽히는지 자체 판정
3. **UI 크기 시험**: 36명 중 8명을 청원 카드·인물 카드 크기(96px)로 — 얼굴 판독

## 4. 금지
좌우 반전으로 방향 만들기, 같은 얼굴 틀에 머리·옷만 바꾸기, 과장된 캐리커처(자연스러운 사실풍 유지), 원색 옷, 현대 헤어스타일, 역사 오류(홉·문 표식 같은 것).

## 5. 이 파일럿이 통과하면
본 제작은 **풀 약 300장**(축 조합을 채움) + 주요 인물 노화 사슬. 게임은 인물 속성(성별·나이·계급·체형·머리색)에 가장 맞는 초상을 풀에서 고르고, 이름 있는 주요 인물만 노화 사슬을 갖는다. 상태(병·상중)는 작은 오버레이(얼굴 위가 아니라 **초상 틀 장식**: 검은 리본·붕대 아이콘)로 처리한다.
