# Wave 15 확인 그림 자체 검수

최종 후보 파일로 네 장을 다시 합성한 뒤 직접 열어 확인했다. 합성은 프로젝트 PNG의 배치·아핀 변환·마스크·축소와 검수용 글자/피벗/윤곽 표시만 사용했다. 새 장면 그림 생성이나 게임 설치는 하지 않았다.

| 확인 | 판정 | 관찰 |
|---|---|---|
| 01 같은 장소 사계절 | 통과 | 길·목책·물·주택·밭 및 나무 위치를 고정했다. 봄의 밝은 꽃 수관, 여름의 녹색 잎, 가을의 황갈 지면/갈색 참나무/노란 자작, 겨울의 빈 가지와 서리·지붕 눈이 줌 0.6에서 서로 구별된다. 가을·겨울 지면의 초기 큰 얼룩 대비는 최종 조용한 fill로 수정되어 수관보다 먼저 눈을 끌지 않는다. |
| 02 자연 12종 계절 격자 | 통과, 윤곽은 시각 검수 | 여름 알파 윤곽을 청록색으로 겹치고 기존 피벗을 주황 십자로 표시했다. 수관의 대표적인 좌우 높낮이와 줄기 접지가 이어진다. 겨울 가지 내부 빈 공간과 일부 상단 1~2px 차이는 허용한 계절 표현이다. 픽셀 단위 알파 동일 판정이 아니다. |
| 03 과수 9종 | 통과 | 원본 여름·봄·겨울을 같은 피벗으로 나란히 배치했다. 원본의 낮고 넓은 사과/자두와 세로로 긴 배 수형이 이어진다. 실제 표시 폭 43px(기존 phase16은40px)에 줌 0.6을 적용한 작은 표본에서도 꽃 수관/녹색 수관/빈 가지가 구별된다. 확대 표본은 detail로 따로 표시했다. |
| 04 겨울 마을 | 통과 | 기존 Wave7 지붕 눈·서리와 겨울 수목/지면이 함께 사용되며, 새 눈 재질이 온 지면을 두껍게 덮지 않는다. 소나무의 녹색 몸체가 남는다. |
| 이미지 레이아웃 | 통과 | 제목·배율·그림 겹침 없음. 01 하단의 이전 잘린 문구를 제거했고, 03 각 배율 표시는 해당 나무 밑에 맞췄다. |

## 배율과 출처

- foliage 12종: 기존 worldAssetManifest의 각 renderScale × zoom과 source anchor 사용.
- 새 과수 8종: zoneAssetManifest의 displayWidth43/256 × zoom, 개별 anchorX/Y 사용.
- phase16 과수: 40/113 × zoom, anchor(56.5,74.4).
- 지면/경계·Wave7 소품: 파이프라인 기준 0.5 × zoom. 확인 그림03의 detail 확대는 게임 배율과 분리 표시.
- 여름 잔디는 `/tmp/astra-wave4-work-20260925/astra-wave4-reference-files/grass.png`. 현재 첨부 화면의 구도를 중앙 마름모 밭·뒤쪽 물/목책·가로변 주택으로 재구성한 검수 장면이며, 실행 중 게임 캡처를 교체했다고 주장하지 않는다.
- 모든 실제 참조 파일 경로와 고정 배치는 `proofs-sceneplacements.json`에 기록했다.

한계: 본 검수는 PNG 합성에서 계절 가독성과 고정 배치/피벗을 확인한 것이다. 런타임 크로스페이드·지형 캐시·성능·충돌 판정은 게임 미설치 범위이므로 검사하지 않았다.
