# 영주 모드 두 번째 첫 플레이 보고

빌드 `e35c547c12d8647e103fd859ccbeab328a0b9d79`, seed `115500`, 강가 시장도시, 1920×1080. 1300년 봄부터 1320년 봄까지 화면으로 관찰했다. 원 진행은 1315년 여름에 중단됐고, 1306년 봄 저장을 복구해 이어 갔다. R 접두 캡처는 복구 가지, V 접두는 저장 검증이다. 관찰 세션은 약 **2시간 28분**(재진행 약 22분 포함), 재진행을 제외하면 약 **2시간 5분**이다. 중단·진단·복구 준비 약 35분과 최종 납품 검증 시간은 제외했다. 재진행을 독립 표본으로 세지 않는다. [상세 시간](logs/TIMING.json), [복구 기록](RECOVERY.md).

- [PLAY_DIARY.md](PLAY_DIARY.md): 약 15분 간격 일지와 복구·완료 기록.
- [THREE_CHECKS.md](THREE_CHECKS.md): 선택 설명 **일부**, 작은 일 위임 **고쳐졌다**, 결과 연결 **일부**.
- [TOP10_FRICTION.md](TOP10_FRICTION.md), [TOP5_FUN.md](TOP5_FUN.md): 근거 링크와 작은 개선 제안.
- [saves/README.md](saves/README.md): 최종 저장과 검증한 복원 방법.
- captures/: 보고서 인용 JPEG 원본과 동시 수집 화면 텍스트. 관련 없는 중복 캡처는 경량화를 위해 제외했다. TXT는 스크롤 영역 밖의 렌더된 텍스트도 포함할 수 있어, JPG에 전부 보인다고 간주하지 않는다. 캡처 합성이나 그림 재생성은 하지 않았다.
- logs/: 시작·끝·시간·행동·메모·자동 체크포인트·저장 검증. 설치 중 누락 이미지 오류는 첫 게임 전 준비 오류이며 런타임 결함으로 세지 않았다.

‘상속 다툼’은 열람·캡처·소송 제기까지 했다. 정확히 ‘도시의 요청’이라는 제목은 관측하지 못했다. 10배속은 UI에 없어 5배속으로 연말 자동정지를 확인했으며 10배속 자체는 미검증이다.

게임 코드·게임 설명 문서는 읽지 않았다. 화면과 UI 텍스트로 플레이했고, 브라우저 자동화는 클릭·스크롤·캡처·저장 복원에만 사용했다. 엔진 상태를 주입하거나 게임 시간을 코드로 건너뛰지 않았다. 코드 수정·커밋·푸시는 없고, 종료 검증은 [QA.md](QA.md)에 남긴다.

SHA256SUMS는 자신을 제외한 납품 파일 전체의 SHA-256이다. 압축을 푼 폴더에서 shasum -a 256 -c SHA256SUMS로 확인할 수 있다.
