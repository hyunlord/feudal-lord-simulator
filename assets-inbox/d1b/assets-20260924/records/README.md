## 배치 계약

- 석재길: 캔버스 전체 512px가 반복 주기. 좌우 투명 여백 없음. 상하 각 8px 완전 투명, 그 안쪽에 8px 커버리지 전이. 중심선 `(256,32)`.
- 숲 C: 사방 8px 완전 투명. 접지 피벗 `(64,88)`. 그림 영역은 폭 112px·높이 24px로 정리하여 A/B의 큰 덩어리보다 낮게 유지.
- 좌표 원점은 PNG 왼쪽 위. 피벗은 설치 제안값이며 게임에 설정한 값이 아니다.
- 줌 1.0은 에셋 0.5배, 줌 0.6은 0.3배. 확인 그림을 뷰어에서 100%로 열어 읽는다.

## 생성과 수정

`image_gen`으로 각 1후보, 총 2장을 생성했다. 실제 모델명과 시드는 도구에 표시되지 않아 추측하지 않았다. 처음 요청한 참조 7개는 도구의 최대 5개 제한으로 생성 전에 거절되었다. 성공한 각 호출에는 첨부 ZIP에서 고른 5개만 입력했다. 해당 제한은 참조 종류를 줄인 것이며 외부 그림을 추가한 것이 아니다.

석재길 입력: `earth_strip-v1.png`, `packed_earth_road.png`, `grass.png`, `forest_floor.png`, `forest_fringe_a-v1.png`.

숲 C 입력: `earth_strip-v1.png`, `forest_fringe_a-v1.png`, `forest_fringe_b-v1.png`, `grass.png`, `forest_floor.png`.

**해상도 한계:** 프롬프트는 정확한 작은 크기를 요청했지만 도구는 석재길 2172×724, C 1774×887 원본을 반환했다. 최종 파일은 잘라 축소한 결과다. 처음부터 512×64/128×96에서 직접 생성했다고 주장하지 않는다. 최종 표시 크기에서 검수했다.

Canvas 2D 후처리:

1. 알파 >2의 그림 영역을 잘라 규격 내부에 배치. 완전 투명 여백을 명시적으로 정리.
2. 석재길은 그림을 512×48 내부 영역에 맞추고 상하 커버리지를 감쇠. 48px 알파 가중 중첩으로 464px 주기를 만들고 232px 이동 후 512px로 정규화. 마지막으로 좌우 최외곽 한 열의 RGBA를 평균하여 일치시킴. 좌우 16px 전체를 같은 띠로 평탄화하지 않았다.
3. 숲 C의 첫 비례 축소는 그림 높이 16px로 너무 낮아, 동일 생성 원본을 **112×24px로 비균일 크기 조정**했다. 좌우 안쪽 8px 알파 감쇠. 새 풀을 그리거나 A/B를 변형하지 않았다.
4. 블러·샤프닝·노이즈 추가 필터는 사용하지 않았다. 축소 리샘플링과 알파/접합 보정은 기록에 명시했다.

전체 실제 프롬프트는 `assets.csv` 및 `records/generation-requests.json`에 있다. 원본·참조 ZIP·참조 파일의 SHA-256은 `records/provenance.json`에 있다. 생성일시는 원본 로컬 파일의 수정 시각을 UTC ISO 8601로 기록했다.

## 확인 그림 해석

석재길 확인 그림은 전체 PNG 3장 접합과 두 배율을 보여 준다. 곡선 예시는 약 70 화면px 구간에서 흙과 돌을 교차 합성했다. **이 전환은 확인 그림 안의 합성 처리이며 새 전환 에셋이나 게임 구현이 아니다.** 보정 없는 직접 접합도 함께 넣어 색·폭 차이를 확인할 수 있다.

숲 배열은 요청 순서 그대로, 줌 1.0에서 64px 동일 간격이다. 무작위 이동·회전·색 변화를 주지 않았다. C가 반복 사용된다는 사실은 남지만, 지정된 짧은 배열에서는 이전 A/B 교대 높낮이의 일정한 리듬이 완화된다. 긴 경계·다른 배치 전체에 대한 무반복 보증은 아니다.

원본 생성 PNG와 입력 그림은 `provenance.json`의 로컬 경로에 보존하고, ZIP에는 요청된 PNG 4장만 넣었다. `records/processing-and-preview.html`은 실제 후처리·합성식 기록이며, 원본 HTTP 경로를 제공하는 환경 없이는 단독 실행되지 않는다.

**검수 결론:** 지정된 오프라인 확인 범위에서 크기·알파·접합·돌길 구분·C의 리듬 변화가 통과했다. 생성 원본 해상도 한계와 게임 미설치는 남아 있다. 모두 승인 전 `candidate`다.
