## 비교판

`proofs/same-scene-z1.0.jpg`, `proofs/same-scene-z0.6.jpg`: 같은 배치의 **겨울 → 봄 → 여름**. 일반나무 manifest 배율, 과수 canvas 표시너비43, 소품 제안월드너비를 적용한 오프라인 재료·배치 비교다. 직사각형 구역은 재료 대조용이며 실제 엔진 지형 마스크/청크 렌더가 아니다. 각 그룹의 `proofs/`에는 개별 계절판·반복판·밝고 어두운 배경판이 있다.

봄 전용 신규소품은 대응 겨울·여름판을 따로 만들지 않았으므로 두 계절에서는 미배치했다. 그림에 겨울/여름 자산이 존재한다고 꾸미지 않았다. 고사목은 죽은 상태를 지켜 잎을 붙이지 않고 젖은 목질만 바꿨다.

벚나무의 전용 여름/겨울 원본은 없다. `plum_j`를 **기하 템플릿**으로 사용한 신규 벚꽃판이며 pivot(128,242)을 물려받았다. 비교판의 해당 겨울·여름은 자두형태 proxy임을 명시한다. 사과/배/자두는 사용자 승인 Wave41 여름 과수 기준이다. 강가 여름 grass는256×256 재질참조이고, 이번 봄은 요청된256×128 계절fill 규격이다. 밭의 겨울판은 같은작물상태가 아닌 기존 겨울휴경 참조다.

## 검수와 기록

- `assets.csv`, `records/asset-catalog.json`:24장 ID·경로·규격·피벗·참조·SHA.
- `records/package-QA.json`: 나무·과수10장 여름 alpha 전체일치, 반복축 경계, 투명RGB검사.
- `records/independent-review.md`: 생성 담당과 별개로 최종 실물을 본 판정.
- 각 그룹 `manifest.json`, `records/`: 전체 프롬프트·내장 image_gen 사용·참조 해시·원시 경로/해시·후처리. 공개되지 않은 model/seed는 추정하지 않는다.
- `SHA256SUMS`: ZIP내 최종파일 해시. `records/scene-layout.json`: 비교판 배치·배율.

기하 고정을 위해 생성 RGB를 원본 위치에 정합하고 여름 alpha를 적용했다. 줄기/목재 보호와 이음/투명RGB 정리를 포함한 후처리는 각기 기록했다. 단순 색변환만으로 생성했다고 표시하지 않으며 실제 생성 시도와 수정기록을 보존한다.

경량 ZIP은 고해상도 raw를 제외한다. raw는 작업 폴더 `output/astra-wave43-spring-20261002/{그룹}/raw/`와 생성기록 경로에 남아 있다. PNG·참조·전체 프롬프트·검수증거는 ZIP 안에 포함된다.
