## 제작과 검증

사람은 첨부 템플릿을 입력한 이미지 편집으로만 제작했습니다. 592×296 마스터에서 최종 296×148로 축소했으며, 셀은 74×74, NE·SE·SW·NW 4방향 × 2프레임입니다. 편집 원본과 셀 등록·보호 마스크 적용 후 결과를 함께 보존했습니다. 소지품은 별도 32×32 RGBA이며 손잡이 좌표는 `records/props.json`에 있습니다.

232셀 모두 하체 영역(마스터 셀 y100–147)의 알파가 원본과 바이트 단위로 같습니다. 들어 올린 발도 포함합니다. 머리 외곽 중심 대리지표의 최대 차이는 최종 해상도 기준 **1.259px**입니다. 다만 알파 보존과 이 대리지표만으로 해부학적 머리 중심·팔 자세까지 2px 이내라고 인증할 수는 없습니다. 엄격한 자세 고정 검수는 **부분 확인**이며, 전체 통과로 표시하지 않았습니다.

독립 검수에서 28종의 정적 방향·색·머리쓰개 구분을 확인했습니다. 상인 여성의 짧은 캡/긴 베일·윔플, 직물 여성의 머릿수건은 추가 편집으로 구분을 보강했습니다. 여성 변형끼리 옷길이 차이는 약합니다. 겨울 외투는 기본 남녀 템플릿에만 합성했으며, 얼굴 개구부가 좁고 28종 전체 호환은 검증하지 않았습니다.

소지품은 방향별 별도 생성·편집 원본을 보존했지만 일부 앞뒤 쌍의 차이가 약합니다. 특히 물병은 NE/SE/SW에서 손잡이가 같은 쪽에 남아 정확한 4면 회전 정합을 통과했다고 볼 수 없습니다. 소지품은 게임 내 손 부착 검증 전 후보입니다.

## 수량 결정과 출처

의뢰서 직업별 표의 29종을 모두 제작하라는 사용자 최종 지시에 따라 하인·도제 남성02를 복원했습니다. 하인 남2·여2이며 사제·수도사·수녀도 각1종입니다. 30번째는 만들지 않았습니다. 상세 기록은 `records/decisions.md`에 있습니다.

Wave5a ZIP에는 거리 캡처가 없어 원래 딥리서치 ZIP의 03 게임 화면을 사용했습니다. 확인 2는 그 위에 후보를 합성한 검사판이며 실제 설치 화면이 아닙니다. 주민 높이는 현 제품의 줌 1.0 기준 17.6px를 적용했으나, 배경 캡처의 줌 정보가 없어 배경과 완전한 축척 일치는 미확인입니다.

전체 프롬프트·참조·편집 이력·후처리·SHA256은 CSV 및 `records/`에, 생성 원본은 `sources/`에 있습니다. 도구가 공개하지 않은 모델 버전·seed는 null로 기록했습니다. `SHA256SUMS.txt`와 `records/package-validation.json`으로 파일 무결성·수량·치수·알파 검사를 확인할 수 있습니다.
