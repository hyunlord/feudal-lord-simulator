# C5 보고서 — 직물 사슬

지시: C5 직물 사슬(사용자 지시 2026-09-28, 6시간). 명세 [cloth-chain.md](../../design/cloth-chain.md) CL-1~CL-11, 결정 CL1~CL10. 검증 DGX.

## 1. 만든 것
- **자원 일곱**(RES-REG 목록 줄): 양털·실·생베·축융한 베·염료·물들인 베·완성 직물. 모두 창고에 둔다.
- **건물 다섯**(BLD-REG 목록 줄, 시장도시에서 해금)
  - 목축 농장: 목초지를 돌보고 초여름에 털을 깎는다.
  - 직조공 집: 베틀로 실 4 → 생베 1.
  - 축융 방앗간: 물레방아, 물가에만. 영주 사용료 3d가 붙는다.
  - 염색집: 물가에만. 염료는 상인이 계절마다 들여온다.
  - 텐터 틀: 물들인 베를 펴 말려 완성 직물로 만든다.
- **실잣기**: L3·L4 집 여성의 둘째 가내 슬롯이다(첫 슬롯은 에일 그대로). 잣은 실은 직조공 집으로 곧장 간다.
- **흑사병 뒤 목축 유리**: 목초지는 20칸에 일손 한 명이다(경작지는 칸마다 한 명). 노동 규칙의 밭일꾼 층에 들어간다.
- **시장**: 완성 직물이 가장 먼저 팔린다(30d, 주인의 몫). 직물 검인관의 인장세 4d가 금고에 든다. 상인은 텐터 틀에서도 산다.
- **양털 수치 다시 정함**(CL1): 1칸 = 양 2, 양 1 = 한 해 1뭉치, 뭉치 5d.
- **양모 공납 현물**(CL5): FIX-7의 목초지 셈을 없애고, 저장소 재고(창고 → 목축 농장 마당)에서 가져간다.
- **베는 손에서 손으로**(CL6): 중간재는 다음 단계 건물로 곧장 간다. 봇 도시의 창고는 목재로 가득해, 창고를 거치게 한 첫 탐침에서 텐터 틀에 10필이 쌓인 채 한 필도 팔리지 않았다.
- **봇**(CL7, CL11): 3장이 끝난 뒤 목초지 60칸(6×6 붓질), 목축 농장, 직조공 집, 축융 방앗간, 염색집, 텐터 틀을 차례로 세운다.
  - 물가 건물은 봇의 해안 여유 검사에서 뺐다. 이 검사 때문에 첫 탐침에서 축융 방앗간 자리가 0곳이었다.
- **저장**: 형식이 바뀌지 않았다(v26 지문 그대로). 4장 도시 저장 묶음 `chapter-four-town`(F3-A 가드레일 seed 1의 최종 상태)을 더했다.

## 4. 다음 후보
- 수치(CL1)는 가설이다. 봇 도시(72칸)에서 해마다 약 30필이고 금고 수입은 약 210d다. 4장 금고(약 3만 d)에 비해 작다. 4장 재편 때 조정한다.
- 양모 공납 현물 경로는 봇으로는 여전히 시험되지 않는다. 공납은 1337년(2장)이고 봇의 목초지는 4장이다(CL7). 지시의 "가드레일에서 처음 시험"은 이 순서로는 되지 않는다. E21이 시험한다.
- 지시의 "4장 진입 전 완성 직물": 코드에서는 3장 끝과 4장 시작이 같은 틱이다. "3장 끝 뒤 4장 초입"으로 읽었다(1~3장 무변화와 함께 지키려고, CL7).
- 목축 농장 그림 판정(Wave 2 `farm_pastoral` 3장)은 사용자·INBOX 몫이다.
