# 제작 범위와 해석 기록

이번 의뢰는 초상 풀 3차만이다. Wave21 삽화와 게임 설치는 포함하지 않는다. 승인된 1·2차 및 파일럿 원본은 변경하지 않았다.

## 수량 불일치 처리

의뢰서 제목은 24명이나 역할표를 합하면 22명이다. 총 24명·72장을 맞추기 위해 I123 백작 가문 집사와 I124 도시 평의회 서기를 보충했다. 이는 제작자가 알린 작업 가정이며 사용자가 별도로 지명한 인물은 아니다. 상인 후계 I118은 여성으로 배정하여 여성 머리쓰개 분포를 확보했다.

1차 32명 + 2차 32명 + 3차 24명은 88명이다. 승인 파일럿 CSV에는 청년 고유 인물이 10명뿐이다. 확인 그림 2는 본제작 청년 88명 + 파일럿 청년 P01·P08·P09·P13·P14·P20·P25·P26·P31·P32 10명 + 파일럿 장년 P33(35세)·P21(37세) 2명, 총100명으로 구성한다. 청년100명 조건은 원본 부족으로 미충족이며 마지막 두 칸을 장년 예외로 표시한다. 파일럿 12명은 비교 자료이며 이번 신규 제작 수량에 포함하지 않는다. 이 산술 해석을 그림 제목과 CSV 외 보고서에 명시했다.

## 시대 및 복식

청년·장년·노년은 각각 1305·1325·1350년 전후의 24·45·70세 예시다. 게임 연도와 실제 생년을 확정하는 역사 인물 데이터가 아니다. 1300년대 후반 이후에만 허용된 비단은 전 단계에서 사용하지 않았다.

담비는 I101·I102·I103에만 배정했다. I123은 가신단 소속이지만 백작의 혈족이 아니므로 다람쥐 모피를 사용했다. 상인 가문은 고급 모직·다람쥐 모피·인장으로 구분하고 자주색과 진홍색은 배제했다.

I106 노년 1장에만 1340년 이후 왕실 4분할 문장을 배정했다. 청년·장년 2장은 붉은 바탕 금 사자 셋이다. 4분할 프랑스 부분은 금 백합을 흩뿌린 옛 문장으로 해석했다. 자세한 근거는 HERALDRY_NOTES.md에 기록한다.

## 확인 그림 3

실제 Wave19 세력 페이지 틀에 장년 수장 초상과 첨부 창작 문장 견본을 배치했다. 문장은 예시 배정이며 확정된 세력 문장이나 실제 왕실 문장이 아니다. 실행 중 게임 화면이 아닌 오프라인 배치 검수다.

## 해석의 한계

권위·나이·동일인 인식·인물 간 유사성은 육안 판단이다. 피부 톤이나 체형으로 계급 또는 도덕성을 판단하지 않았다. 권위는 시선과 자세, 복식에서 읽히도록 했으며 얼굴 인식 모델이나 사용자 플레이 테스트를 통과했다는 뜻이 아니다.
