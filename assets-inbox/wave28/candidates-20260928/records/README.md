## 배치 계약

경계 띠는512×64, X축 반복이다. 지면 기준축만 기울이는 shear로 등각 방향에 배치하고 세로축을 유지했다. 최종 좌우 RGBA가 동일하도록 가장자리를 기술적으로 연결했다. 합성에서는 512px 전체를 짧게 압축하지 않고, 0.5배 텍스처의 일부 구간을 잘라 사용해 경계 높이를 유지했다. 이는 곡선 경계·모서리 접합·양면 회전이 모두 해결되었다는 뜻은 아니다.

점 소품과 들판의 크기는 첨부에 숫자 규격이 없으므로 제작 규격으로 정했다. 참나무192×224, 버드나무160×192, 십자가64×96, 건초더미128×112, 양 우리160×112, 벌통96×64, 경계석48×64, 들판128×64/256×128. 각 가족은 세 계절에 같은 캔버스와 기준점을 사용한다. 피벗은 PNG 좌상단 원점 픽셀 좌표이며 CSV에 있다. 계절 편집의 세부 실루엣이 픽셀 동일하다고 주장하지 않는다.

측정은 새 레이어의 **알파가0보다 큰 픽셀의 합집합 / 성벽 밖 빈 땅의 보수적인 마스크 면적**이다. 겹친 소품은 한 번만 센다. 숲·물·도시·UI를 분모에서 제외했다. 전체 화면 기준 수치도 따로 기록한다. 레이어 투명도를 낮춰 면적을 속이지 않았다. 마스크 밖 알파가 없는 픽셀의 원본 색 보존도 검사했다.

## 경량판과 원본

최종PNG는 손실 없는 RGBA다. 경량 ZIP에는 큰 생성 원본을 넣지 않고 프롬프트와 원본 SHA 목록을 넣었다. 생성 원본은 로컬 `/Users/rexxa/feudal-lord-analysis/astra-raw/wave28-20260928/`에 보존한다. `records/raw-inventory.json`이 대응표다. 소품 초기 다중시트 시도는 폐기된 콘셉트로 보존했으며 최종6종은 각각 별도 호출로 만들었다. 모델 버전·seed는 도구가 공개하지 않아 미제공으로 기록했다.

`SHA256SUMS` 및 ZIP CRC 검증은 무결성 검사다. 실제 게임 배치·가림·계절 전환·성능 검증이나 사용자 미적 승인으로 설명하지 않는다.
