# 엔딩 6종·빈 장원 2종 검수

**판정: 후보 통과. 차단할 시각 문제 없음.**

## 직접 확인

엔딩 JPEG 6장과 장원 PNG 2장을 개별 열람하고, 확인 그림 2장 및 기존 Wave21·31 그림과 비교했다.

| 대상 | 판정 | 구별되는 장면 |
|---|---|---|
| 스스로 다스리는 도시 | 통과 | 시민들이 모인 길드홀 앞 공공 탁자와 도시 인장. |
| 이름이 남은 가문 | 통과 | 교회 안 무덤과 세대가 다른 가족의 추모. |
| 상인들의 기도처 | 통과 | 강변 창고 곁 작은 독립 예배당, 기도와 화물 노동. |
| 가문의 도시 | 통과 | 장원 난간의 두 세대와 같은 가문 깃발이 선 도시 전경. |
| 영주의 도시 | 통과 | 장원 대청에서 앉은 영주와 서 있는 청원자들의 재판. |
| 순례자의 도시 | 통과 | 교회 입장 행렬과 순례 배지 좌판. |
| 장원 A/B | 통과 | 기존 건축 배치 유지, 닫힌 창·빗장·마당 잡초, 접지선과 주요 윤곽 정렬. |

- 엔딩 6장은 제목을 가려도 장소와 행동이 구분된다. 읽히는 글자·숫자·워터마크는 발견하지 못했다.
- 기존 그림의 따뜻한 석재·목재·양모 질감, 절제된 붉은색과 올리브색, 사실적인 회화 표현과 연결된다.
- 빈 장원은 붕괴한 폐허가 아니라 문과 창을 닫은 비거주 상태로 읽힌다. 원본/변형 50% 겹침 판에서 접지와 주요 윤곽을 비교했다.

## 한계

- 장원 지붕색은 원본보다 다소 선명하다. 외곽과 건축선이 모든 픽셀에서 동일하지는 않으며, 제공된 실루엣 IoU는 약 0.99다. 캔버스/피벗 수치는 별도 asset-validation 기록에 따른다.
- 시각 검수이며 역사 자료 전수 대조나 실제 게임 설치·렌더 검증은 수행하지 않았다.
