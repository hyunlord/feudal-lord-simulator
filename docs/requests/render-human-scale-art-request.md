# 성인 정본 키에 맞춘 L0·L1 출입문 수정 요청

상태: **저장소 아트 요청 · 제작/설치/런타임 검증 대기**. 작성일 2026-10-05. 이 문서는 저장소에 기록하는 수정 요청이며 외부 메시지를 발송했다는 뜻이 아니다. 요청 기록은 자산 교체·설치 승인을 뜻하지 않는다. 아래 내용은 PNG 관찰과 렌더 좌표 계산이며, 게임 실행 화면·통행·배치·가독성 검증 결과가 아니다. **게임플레이 HEIGHT 마일스톤은 미완료**다.

최초 소스 관찰 기준은 `ab67dcb8`로 보존한다. 이후 `a392694c3056b93812a0bcc3de767a387f2f3f3b`에서 원본/공개 PNG46개와 공유 레이어4개의 SHA·캔버스, 현재 배율·크롭·피벗 계산을 독립 재검증했다. 이는23개 문 경계의 새 시각 재측정이나 새 런타임 검증이 아니다. [독립 검토](render-human-scale-art-request-review.md)에 범위와 한계를 기록했다.

동반 목록은 [render-human-scale-art-request.json](render-human-scale-art-request.json)이다. 원본 및 공개 PNG 경로는 저장소 루트 기준이다.

## 요청 근거와 대상

[FND-3 결정](../decisions/README.md)의 정본은 성인 **17.6 world px**다. [아트 바이블 2절](../design/art-bible.md)은 모자·도구·그림자를 제외한 **맨발 정수리–발바닥**을 H로 정의하고, 일반 출입문 유효 높이를 1.15–1.40H, 폭을 0.45–0.65H로 정한다. 따라서 목표 개구부 높이는 **20.24–24.64 world px**, 폭은 **7.92–11.44 world px**다. 문틀 외곽 높이가 아니다. 바이블의 기준형 ±10%는 개별 근거가 기록된 예외로 다루며 전체 기준을 자동 완화하지 않는다.

현재 보행자 등록값 `32×scale`은 모자·신발이 포함될 수 있는 등록된 그림 높이이며 맨발 해부학적 높이의 실측 증명이 아니다. 아트 바이블의 ‘현재 코드’ 설명과 저줌 표는 목표 근거와 구별해야 한다. 제작 비교판에는 정본 인물의 정수리·발바닥 기준점을 명시하고, 실측할 수 없는 부분을 임의로 추정하지 않는다.

수정 검토 범위는 **23개 본체**로 한정한다: 기존 역사 주택 2, Wave20 시대별 A/B 8, Wave2 5, Wave26 8. L0 11개·L1 12개다. 선술집 전환, 상위 등급·합필·업그레이드, 폐허·화재 본체는 이 조사에서 제외한다. 새 본체나 엔진 단계 신설을 요청하지 않는다. 모든 23개 공개 PNG를 개별 관찰했으며, 이번 대상에서 같은 등급·시대 정체성을 지키는 기준 충족 대체 본체는 확인되지 않았다.

## 측정 결과와 불확실성

닫힌 문짝 뒤의 유효 개구부를 내측 문설주·상인방 아래·문턱 위로 추정했다. 경사진 문 상단과 하단은 **같은 x에서 세로 거리**를 비교한다. 외곽 상인방·기둥·계단은 제외한다. 기존 본체 2개와 Wave20 8개는 ±2 native px, 나머지 13개는 흐린 경계와 그림자를 고려해 ±3 native px 범위다. 실제 열린 문이나 자동 분할 결과라는 뜻은 아니다. Wave20 범위는 개별 관찰 후 보수적으로 부여한 등급별 구간이며 픽셀이 동일하다는 주장이 아니다.

## 배치 계약과 원본 보존

동반 JSON에 **23개별 원본/공개 경로·SHA-256·실제 캔버스·크롭·배율·피벗 또는 동등 접지점·측정 범위**를 기록했다. 이 목록을 교체 입력의 기준으로 삼는다. 기존 바이트와 ID는 비교 자료로 보존하고 후보 수정본에는 새 SHA·변경 영역·제작 근거를 첨부한다.

| 항목 | L0 | L1 |
|---|---|---|
| 기존 authored 프레임 | 1254×1254 | 1254×1254 |
| 기준 alpha crop x,y,w,h | 172,378,924,766 | 137,187,1019,949 |
| 공개 native 캔버스 | 153×153 | 139×139 |
| world/native px | 0.4995704948646125 | 0.4986217267599071 |
| 동등 native 접지 피벗 | 77.35406698564593,139.57894736842104 | 71.66148325358851,125.92025518341308 |

기존 역사 본체·Wave2 원본은 1254²이고 공개 파생본은 위 native 크기다. Wave26 받은 PNG는 이미 153²/139²이며 공개 파일과 동일 바이트다. Wave26의 1254²는 상속된 배치 프레임이지 실제 원본 해상도가 아니다. Wave26의 더 넓은 자체 crop은 같은 배율에서 그릴 영역을 늘릴 뿐 문을 확대하지 않는다. Wave20은 full-native crop과 명시적 피벗·배율을 사용한다.

계산은 `native 문 높이 × 56.32 / (기준 authored alpha 폭 × native 캔버스 폭 / 1254)`다. Wave20은 native 문 높이에 JSON의 scale을 직접 곱한다. **파생본 해상도 비율을 두 번 적용하지 않는다.** 높이 목표는 현재 배율에서 L0 약 40.51–49.32 native px, L1 약 40.59–49.42px다.

배치 근거: [historicalHouseAssets.ts](../../src/render/historicalHouseAssets.ts), [historicalHouseAssetManifest.generated.ts](../../src/render/historicalHouseAssetManifest.generated.ts), [runtimeAssetCoordinates.ts](../../src/render/runtimeAssetCoordinates.ts), [buildingVariantAssets.ts](../../src/render/buildingVariantAssets.ts), [wave26HouseArt.ts](../../src/render/wave26HouseArt.ts), [Wave26 manifest](../../src/render/wave26HouseManifest.generated.ts), [카탈로그](../../src/render/art/catalog.json).

실제 선택은 카탈로그 본체 우선, 준비된 Wave26, Wave2/기존 본체의 순서와 자산 준비 상태·집 상태에 따른다. Wave20 1350/1400 A/B는 해당 시대와 등급을 유지한다. Wave2 L1 tile은 완성된 보호 성벽 조건을 유지한다. ‘선택 가능’이 특정 세이브에서 실제 그려졌다는 뜻은 아니다. 상위 등급이나 다른 시대 그림을 대신 연결하지 않는다.

## 아트 수정·납품 조건

1. 각 본체의 시대·등급·A/B·재료 정체성과 1×1 필지, 캔버스, 피벗, 그리기 배율을 유지한다. 문·벽·처마의 국소 비례를 재구성한다. **건물 전체 확대는 해법으로 적용하지 않는다.** 기존 두 본체의 중앙 추정값을 단순 확대하면 최소 목표만 맞춰도 L0 약 1.76배, L1 약 1.93배로 폭이 56.32에서 약 99.21/108.86 world px가 된다.
2. 문이 현재 처마 아래에 자연스럽게 들어가지 않으면, 필요한 벽·처마·실루엣 수정 범위를 별도 제안하고 이웃 필지·지붕 겹침 증거를 첨부한다. 문짝을 지붕까지 늘이거나 임의 오프셋으로 접지를 숨기지 않는다.
3. 각 파일에 내측 위쪽 좌/우 모서리, 문턱 좌/우 모서리, 같은 문설주에서의 높이, 폭의 투영 관례, 측정 오차를 제공한다. native 원본과 현재 배율 비교판에 정본 인물 기준점을 함께 표시한다.
4. 본체와 레이어의 캔버스·crop·피벗·scale·대상 연결을 유지한다. Wave20의 등급별 `public/assets/wave7/overlay/boarded_l0-v2.png`/`boarded_l1-v2.png`와 `public/assets/wave7/season/roof_snow_l0-v2.png`/`roof_snow_l1-v2.png`는 각 등급의 시대/A-B 네 본체가 공유한다. 현재 네 레이어의 해시·캔버스는 JSON에 보존했다. 문 변경 시 판자 가림, 처마/지붕 변경 시 눈 레이어를 **모든 대상**에서 재검토한다.
5. Wave26의 fresh/weathered/boarded/snow, 기존 역사 본체의 불·탄화 등 관련 소비 경로도 수정 전에 확인한다. 이번 23개 본체 조사만으로 모든 레이어가 검수되었다고 간주하지 않는다. 공유 레이어를 유지하려면 모든 대상의 위치와 의미상 가림을 증명한다. 필요하다면 변형별 레이어/대상 매핑을 제안하며, 만능 대형 판자 덧칠로 차이를 덮지 않는다.
6. 납품에는 23개 대조 목록, 후보 PNG, 새 해시, 변경 영역, 유지/변경된 레이어 목록과 등록 좌표, 원본/수정본 비교판을 포함한다. 이 저장소 요청은 후보 제작 결과의 수락·자산 교체·설치를 뜻하지 않는다. 외부 발송은 수행하지 않았다.

## 후속 수락 기준 — 아직 미검증

후속 렌더 담당자는 소스→등록→선택→로딩→실제 그리기를 확인하고, 여름/겨울·입주/판자 가림·줌 1/.6에서 접지·이웃/처마 겹침·가림·인물/문 비율을 검수한다. 성인 보행자와 연출 무리의 정본 키 교정도 별도 검증해야 한다. 이 문서의 관찰은 그 완료를 대체하지 않으며, 후보 승인과 런타임 증거 확보 전까지 HEIGHT 완료 판정을 내리지 않는다.


## 독립 진행 가능한 렌더 교정

현재 a392의 `walkerComposer.ts`는 등록 인물 높이16px(`32×0.5`)를 사용하며 `drawWalkers.ts`는 줌.65 아래에서 최소 화면 크기를 보정한다. `storyWorldProps.ts`의 연출 인물 및 이를 사용하는 선술집 무리도 `WALKER_FIGURE_PX`를 소비한다. 문 아트 준비와 별도로17.6 정본 연결, 연출 인물별 높이 근거, 저줌·접지·가림 회귀 검증을 진행할 수 있다. 단일 배율을.55로 바꾸는 것만으로 모자·신발을 제외한 해부학적17.6 실측이나 HEIGHT 전체 완료가 되지는 않는다. 아트 후보와 렌더 교정 양쪽의 실제 world 검수 결과가 필요하다.
