# 생성·수정 기록

생성 도구: 내장 imagegen. 프로젝트 기존 삽화와 사건 원고를 확인한 뒤 각 장면을 독립 생성했다. 원본 PNG는 경량 납품에서 제외하며 경로·해시는 generation-history.json에 남겼다. prompts는 저장된 장면 생성 프롬프트다. 아래 수정 설명은 편집 요약이며 도구 요청 전문으로 표시하지 않는다.

- 201 v2: 전경 일반집 굴뚝 제거.
- 204 v2: 원경 굴뚝 제거 시도. v3: 해당 원경 집을 잎 진 과수원으로 대체, v2 미채택.
- 205 v2: 배경 일반집 굴뚝 제거.
- 206 v2: 높은 굴뚝 잔해를 낮은 무너진 벽으로 수정하고 배경 굴뚝 제거.
- 208 v2: 배경 일반집 굴뚝 제거.
- 209 v2: 기존 그림들과 겹치는 전경 받침대 둘 구도를 버리고 건물 측면·받침 하나로 새로 생성.
- 213 v2: 배경 도시의 일반집 굴뚝 제거.
- 213·214·215: 최초 생성 전에 비교 감사에 따라 각각 성문 가장자리 비대칭, 낮은 갈림길, 굽은 인물열로 계획 변경. 저장된 개별 prompts와 final-plan을 기준으로 한다.

출력: 최종 PNG마다 sips로 960×540 변환 후 JPG 품질88. 회화적 내용 수정은 imagegen으로만 수행했다. 모아보기는 최종 JPG를 HTML 격자에 배치하여 Chrome으로 캡처한 검수용 도판이다. 각 자산에는 제목이나 글자를 합성하지 않았다.
