# 새 효과 제안

아래 9개는 현재 선택 효과에 포함하지 않았다. NE10은 사용자 정정에 따라 신규 제안에서 철회했다. 단, 확인 HEAD83b06802에서 FIX-14 SW-12는 지도 밖 위임 영지에만 보이며 홈 청원은 직접 상신한다. 이 불일치는 효과 목록에 코드 근거와 함께 남겼다. 기존 명령의 새 문구 등록·카드 연결만 필요한 일과 새로운 상태 변화가 필요한 일을 구별한다. 관련 번호는 각 사건의 `newEffectLinks`에서 자동 집계한다.

<a id="ne01"></a>

## NE01. 사건별 조건·중복 억제·재등장 간격

새 카드의 상태 필터·연도창·대상별 1회 기록·대기열 상한을 함께 관리한다. 기존 엔진에 사건/계절 스케줄이 있지만 이 60개를 읽는 범용 등록기와 교차 중복 억제는 없다.

- 유용한 초안: 001, 002, 003, 004, 005, 006, 007, 008, 009, 010, 011, 012, 013, 014, 015, 016, 017, 018, 019, 020, 021, 022, 023, 024, 025, 026, 027, 028, 029, 030, 031, 032, 033, 034, 035, 036, 037, 038, 039, 040, 041, 042, 043, 044, 045, 046, 047, 048, 049, 050, 051, 052, 053, 054, 055, 056, 057, 058, 059, 060
- 구현 시 확인할 경계: 기존 state 조회와 새 저장 필드를 구분하고, 같은 실제 청원에 효과가 두 번 실행되지 않는지 확인한다.

<a id="ne02"></a>

## NE02. 목적별 수선·시설 상태

수선비 지출과 해당 제방·지붕·울타리의 수선 완료를 연결한다. 기존 repair의 지도 밖 연가치 감소와 home 비용/관계 효과를 실제 지도 수리로 오해하지 않게 한다.

- 유용한 초안: 003, 007, 015, 023, 035, 043, 046, 056
- 구현 시 확인할 경계: 재료·공사 기간·착수 주체를 명시하고 지출 즉시 완공하지 않는다.

<a id="ne03"></a>

## NE03. 기간 있는 감면·새 납기 약속

한 철 감면과 종료, 분할 납부, 재심 기한을 일반 청원에도 기록한다. 기존 혼인 약속과 영구 시장 좌판세 변경만으로 이를 흉내 내지 않는다.

- 유용한 초안: 005, 020, 024, 054, 055
- 구현 시 확인할 경계: 미래 지급 의무·금고 여력·실제 위반을 구분하고 저장/불러오기 때 중복 부과를 막는다.

<a id="ne04"></a>

## NE04. 목적별 생계 물자 지급

가구·교구·장원에 곡물·종자·연료를 실제 재고 범위 안에서 전달한다. 대기근 장의 구휼 경로와 목재 주문이 모든 자원을 지급하는 API는 아니다.

- 유용한 초안: 016, 017, 028
- 구현 시 확인할 경계: 물자 보존, 저장 위치, 수혜 대상, 운송과 소비를 확인한다. 질병 치유나 사망률 하락을 자동 보장하지 않는다.

<a id="ne05"></a>

## NE05. 후견·가구 이동·인물 상태 연결

후견 허가 기록과 실제 후견인/가구 관계 변경, 입주 승인과 실제 정착을 연결한다. 기존 인물·가구 시스템의 무조건 신규 효과라고 부르지 않고 청원에서의 범용 연결을 제안한다.

- 유용한 초안: 026
- 구현 시 확인할 경계: 빈집·물 서비스·생존·동의·기존 관계 확인. 이름 없는 사람을 즉시 생성해 수를 맞추지 않는다.

<a id="ne06"></a>

## NE06. 종교 후원과 지속 의무

추도미사나 자선 약정의 수입 부담과 이행 기록을 다룬다. 단순 주교 관계 변화는 정기 종교 의무를 만들지 않는다.

- 유용한 초안: 008, 060
- 구현 시 확인할 경계: 금액·기한·권리 범위를 분리하고 영적 효능을 수치 보상으로 확정하지 않는다.

<a id="ne07"></a>

## NE07. 한시 동원과 생업 공백

경비·호송·원정 복무의 인원, 기간, 생업 이탈을 연결한다. 기존 전쟁 장의 징집 효과를 매년 어느 사건에서나 호출하지 않는다.

- 유용한 초안: 014, 027, 056
- 구현 시 확인할 경계: 실제 인물과 기존 노동 배치를 보존하며 상비군·즉시 전투 승리로 축약하지 않는다.

<a id="ne08"></a>

## NE08. 권리 범위·관습 판결

방목 상한, 통행 구간, 제분 의무 등 문서상 범위와 실제 이용을 연결한다. 현재 청원 플래그·관계 수치와 권리 조각의 권원·점유를 분리한다.

- 유용한 초안: 001, 012, 036, 041, 044, 045, 048
- 구현 시 확인할 경계: 판결만으로 타인의 점유를 제거하지 않는다. 승소·집행·소득 변화는 별도 확인한다.

<a id="ne09"></a>

## NE09. 가문 내부 중재와 승계 준비

친족 간 중재, 후견·혼담·후계 준비를 반복 가능한 가족 사건으로 표현한다. 기존 한정된 혼인 진행과 legacy 후보 선택을 아무 시기에 재생성하지 않는다.

- 유용한 초안: 019, 025, 031, 037, 047, 053
- 구현 시 확인할 경계: 인물 생애와 승계 가능성, 기존 청구권·과부산을 보존한다. 관계 손실을 없는 수치로 꾸미지 않는다.


<a id="ne10"></a>

## NE10. 철회 이력

신규 효과 제안에서 제외. 기존 FIX-14 선례를 재사용하는 방향이며 홈 적용 범위는 ENGINE_EFFECTS.md의 코드 대조 결과를 따른다. 범용 새 사건 ID의 재등장·선례 키 연결은 NE01 등록기 과제다.
