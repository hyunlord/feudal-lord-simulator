# FAIL-3 실패 사다리 3~4단 + 장 이어하기 보고서

지시서: FAIL-3(사용자 지시 2026-09-27, 엔진 2장 작업 첫째, 5시간). 명세: [실패 사다리·장 이어하기](../../design/failure-ladder-campaign.md) FL-1~FL-12. 결정: FL1~FL13. 근거: 플레이어 흐름 설계서 7절, 권리·정치 조사(회수 경로). 엔진 세션, 렌더·UI 0줄, 검증 DGX.

## 만든 것
- **영주의 권리 등록부(FL-1)**: 시장 좌판세·통행세·방앗간 사용료. 상태는 보유 · 상위 영주 관리 · 상인 인수다. 잃은 권리의 수입은 기간 마감이 금고에 올리지 않는다. API `lordRights(state)`.
- **칭호(FL-2)**: 시대에서 온다(장원 · 시장도시 · 성읍 영주). 강등 중에는 한 단계 아래다. API `lordTitle(state)`.
- **3단 쇠퇴(FL-3~FL-5)**: 계절 시작에 따진다.
  - 조건: 집 8채 이상에서 황폐 ≥ 30 %, 또는 갚지 못한 유지비가 4기간 이상.
  - 결과: 권리 하나를 잃고 칭호가 강등된다.
    - 미납이 원인: 상위 영주의 위반에 따른 정지(통행세 → 방앗간 → 시장).
    - 황폐가 원인: 상인 엘리트의 일방 인수(시장 → 방앗간 → 통행세).
  - 기록: 원장 `decline.entered`, 계절 결산의 `lordship` 줄.
- **회복(FL-6)**: 원인이 풀리면 권리를 가진 쪽의 복원 청원(`restore_right`, 청원자 `overlord`·`merchants`)이 온다.
  - 100d: 권리와 칭호를 되찾는다.
  - 50d: 권리만 되찾고, 칭호는 한 해 뒤에 돌아온다.
  - 거절이나 금고 부족: 한 해 뒤에 청원이 다시 온다.
- **4단 가문 교체(FL-7)**: 3단이 2년 이어지면 가문이 바뀐다.
  - 새 가문: 이름(잉글랜드 젠트리 성씨 20)과 문장 seed. 첫 가문의 문장 seed는 게임 seed라 화면이 그대로다.
  - 금고 절반을 잃고, 상인 게이지는 50 쪽으로 절반 돌아오고, 권리는 모두 되찾는다.
  - 원장 `house.withdrew`("○○ 가문이 물러났다")·`house.arrived`. 게임 오버는 없다.
- **장 이어하기(FL-8)**: 캠페인에서 1장 끝(FC-5)과 같은 틱에 2장이 시작한다.
  - 같은 도시다. 원장·인물·권리·건물·금고는 그대로이고, 장 집계만 새로 센다.
  - 원장 `milestone.chapter_start`. API `chapterGoals(state)`. 샌드박스에는 장이 없다.
- **승리 판정(FL-9)**: 번영은 장 목표다(`milestones.prosperity`). 캠페인 승리(`outcome = victory`)는 5장 끝이다.
  - 성장 실행 스크립트 넷(`phase19NaturalGrowth`·`growthStateRecordWorker`·`phase16NaturalValidation`·`autoplaySustainabilityProof`)은 번영 이정표로 승리 틱을 잰다. 뜻은 예전과 같다.
- **저장 v19(FL-10)**: `lordship`, 청원자 `overlord`, 청원 `restore_right`.
  - v18 → v19: 없으면 첫 가문·권리 보유. 1장이 끝난 캠페인 저장은 그 틱에 2장이다.
  - 지문 `be930f47`, v19 저장 픽스처 9개.
- **봇(FL-11)**
  - 미납 2기간 이상이면 유지비 시설을 새로 짓지 않는다.
  - 황폐 20 % 이상이면 집보다 식량이다.
  - 복원 청원은 낼 수 있으면 수락하고, 반만 있으면 깎아 수락한다.
  - naive 변형 `naiveUpkeep`(FL-12)은 셋 다 하지 않는다.
- **시험·도구**
  - `tests/failureLadder.test.ts` F1~F8.
  - `scripts/failureLadderRun.ts`: seed별 3단·4단·2장 틱, 변형 선택지.

## 렌더가 넘겨받을 API
- **권리·칭호·가문**: `lordRights(state)`, `lordTitle(state)`, `lordHouse(state)`, `lordshipOf(state).pastHouses`.
  - 영주 문장은 `lordHouse(state).heraldrySeed`로 그린다. 지금 화면은 게임 seed를 쓰며, 첫 가문은 같은 값이다.
  - 한국어 이름: `LORD_HOUSE_NAMES_KO`, `LORD_RIGHT_NAMES`(`src/content/historyCopy.ko.ts`).
- **결산**: `SeasonLedger.lordship`(`declined{cause, right, by}` · `houseChanged{withdrew, arrived}`). 결산 카드의 사건 분기(`seasonLedgerCard.ts`)에 기본값이 없어 계절 사건 종류를 늘리지 않았다.
- **원장**: `decline.entered`·`decline.recovered`·`house.withdrew`·`house.arrived`·`milestone.chapter_start`(문구 있음).
- **복원 청원**: `restore_right`, 청원자 `overlord`·`merchants`. 결과의 `charterFee`는 음수(금고가 내는 값)다. 지금 청원 카드 문구는 시장권 전용이라 복원 문구가 필요하다.
- **장**: `chapterGoals(state)`, `politics.chapter.number`. `outcome = "victory"`는 이제 5장 끝에만 온다. 정착 판(`SettlementPanel`)의 승리 제목은 장 목표 표시로 바꿔야 한다.
