# Wave11 건물 계열별 공사 키트 후보

이 묶음은 게임에 설치하지 않은 이미지 후보입니다. 확인 그림은 실제 플레이가 아닌 오프라인 합성입니다.

## 범위·수량
의뢰서의 상세 ID를 모두 제작합니다: 목조9 + 석조8 + 방어8 + 대형공공8 + 현장소품8 + 워커2 + 방향별도구12 = **55 PNG**. 의뢰서의 ‘약45’보다 상세 목록을 우선했습니다. 확인그림4는 별도이며 생성 원본·검사판은 sources/·records/에 보존합니다.

4단계는 말뚝0–25% / 기초25–55% / 골조·벽55–85% / 지붕틀85–100% 그대로입니다. 경제·공사 규칙을 바꾸지 않습니다.

첨부 석문은 낮은 아치형 벽체입니다. 의뢰서의 양쪽탑은 첨부의 좌우 문기둥/벽체로 해석해 기존 문폭과 높이 성격을 유지합니다. 새로운 높은 쌍탑문을 만들지 않습니다. 석조medium도 기준 석공소의 목조 상부를 유지하는 혼합구조입니다.

## 워커
actor_civilian_man-v1 294×147을 우측2px·하단1px 투명패딩해296×148,74×74×4방향×2프레임으로 맞춥니다. 전체시트 확대/축소는 하지 않습니다. 생성한 옷 부분만 등록하고 머리·손·다리·발 및 원본실루엣을 보존합니다. 16셀 머리·발 위치와 픽셀차 검사를 records/workers-overlay-table.md 및 workers-measurements.json에 기록합니다.

## 계층과 역사 표현
단계PNG에는 사람·자재더미를 넣지 않습니다. 석조단계의 모르타르통은 의뢰서가 지정한 작업도구이며 느슨한 재고더미와 구분합니다. 독립 site/ 소품과 workers/는 코드가 따로 얹는 재료입니다.
목조 틀 세우기·바닥에 짠 틀, 석조 목재비계, 아치홍예틀, 대형공사의 목제답차 기중기를 표현합니다. 현대크레인·금속비계·굴뚝·현대장비를 추가하지 않습니다.

## 배율·한계
소품·512px모듈은 파이프라인 원본×0.5=줌1.0,×0.3=줌0.6을 사용합니다. 이미 작은 런타임 건물PNG는 native×1.0/×0.6으로 표기해 혼동을 막습니다. 워커·도구세부는 확대시확인용이며 줌0.6에서 세부직종/도구종류 식별을 보장하지 않습니다.
실제제품의 소켓·점유·충돌·통행·단계전환애니메이션·DPR·성능은 이번후보제작의 검증범위가 아닙니다. 정적인 같은캔버스 합성과 게임통합 완료는 다릅니다.
