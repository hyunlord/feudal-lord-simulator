# 고을 사회 패키지 작업 계획 · 완료

사용자 권한: 이 세션 전담. 지정 가지 전용 클론을 읽되 저장소 코드 수정·커밋·푸시 금지. 납품은 클론 밖 별도 폴더에 작성.

1. 완료: 지정 문서·역사 자료·타입·초상·지도 조사, 기준 HEAD와 파일 해시 고정.
2. 완료: 플레이어 + 이웃16개 + 백작,18집단. 혈연 가문16개·기관2개, 초기138명.
3. 완료: 초기 데이터와 기존 타입 레코드 투영, 제안 필드14범주 분리, 가계·권리·재정·관계·초상 참조 검증.
4. 완료: 연간 규칙14개와 출처/게임 추정 구분,150년 수동 예시32사건·후속186명 검증.
5. 완료: 기존 지도 위18거점·길·강·여행 시간과1600×1000확인 그림, 당주18명96px확인판.
6. 완료: 독립 역사 검수와 수정, 타입·연대기·패키지 검증 PASS, 클론 무변경 확인. SHA256SUMS와ZIP는 최종 압축 단계에서 대조.

기존 엔진 타입은 engine에, 새 연결은 proposals에 분리했다. 연대기를 실제 엔진 실행으로 주장하지 않는다. 확률은 조건부 게임 추정이며 역사 발생률이 아니다.1450에 마치고1455이후 전쟁을 앞당기지 않는다.
