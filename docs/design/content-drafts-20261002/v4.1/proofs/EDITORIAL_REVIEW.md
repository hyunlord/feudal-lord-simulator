# v4.1 독립 의미 검수

판정: **PARTIAL — 아래 수정 후 재검수 필요**. 2026-10-05 최초 검수. 대상은 수정 011 + 신규 201–215의 16개이며, 런타임 전체 실행 검수는 별도 담당이다. 저장소는 수정하지 않았다.

## 수정할 사항

1. **중요: 205의 장려금 선택이 대가 설명과 다르거나 실질 무변화일 수 있음.** a 선택은 기존 우물 장려금을 검사하지 않고 24d로 설정한다. 스냅샷 `townAgency.ts:80`의 `setProjectSubsidy`는 기존 같은 종류를 교체한다. 이미 24d면 ID만 새로 생기고 지원 조건은 그대로다. 48d면 24d로 줄어 다른 지원 여유가 커지는데 문구는 줄어든다고 말한다. 기존 우물 지원금(없으면0)이24보다 작은 경우에만 a를 제공하거나, 실제 증감액과 교체 성격을 문구에 반영할 것.
2. **중요: 같은 노동 맥락에서 중복 정책 질문.** 203과212는 여름/유휴 일손1이하, 같은 stability/growth/revenue 선택이다. 203은 T3,212는F2로 중복 그룹이 달라 같은 여름의 같은 부족 상태에 두 번 묻는다. 203을 봄으로 한정하거나 공통 노동계절 그룹·동일 의미 키로 교차 억제할 것. 209와214도 동일 봄/겨울 목재 부족에서 겹치며 검토 필요.
3. **중요: 자연 분포를 일반 공사 수요 재분류로 채우지 말 것.** 209는 목재 납품 부족만 읽고 실제 자연 상황을 읽지 않는다. 본문과 삽화도 폭풍·홍수 등 자연 상황이 아님을 명시한다. 도시/경제 사건으로 옮기고 자연 목표 추정에서 제외하거나, 실제 계절자연 상황과 다른 판단을 엮을 것. 208은 수확철 농업 노동으로 자연 범주를 방어할 수 있으나 자연재해 자체의 다양성으로 집계해서는 안 된다.
4. **중간: 반복 사건이 현 정책 유지 선택을 없애 정책 변경을 강요.** 202/203/207/210/212/215는 정확히 같은3정책 선택이고 현 정책에 해당하는 선택이 숨겨진다. 이미 stability인 영지에서 빈 식탁 청원을 받으면 growth/revenue로 바꾸는 것만 답변이 된다. 현재 정책을 유지하는 실제 보류 대가를 추가하면 이 역설을 피한다. 실제 holdCost가 sender faction 관계−2를 지원하는지 확인하여 추가할 것. 조건과 대가를 숨기지 말 것.
5. **경미: 211 보류 문법.** '첫째 상인 가문와의'를 '첫째 상인 가문과의'로 수정.

## 통과한 의미 기준

- 새 가구·홍수·역병·수장 신규 취임을 엔진에 없는데 있다고 서술하지 않는다. 202는 실제 주택 식량부족 시작 시점으로 대체했음을 명시한다.
- 206/210은 실제 기록 ID, 211/213은 실제 세력/수장 ID, 나머지는 실제 계절 키에 묶는다. 모든 키가 영속 엔진 중복 방지에 쓰이는지는 별도 실행 검수 대상이다.
- 정책 선택은 즉시 구호·치료·임금 변경·징병 효과라고 허위 약속하지 않는다. 기존 POLICY_WEIGHTS와 설명은 대체로 맞는다.
- 201/204/211은 도시 전체 시장 좌판세임을 명시하고 통행세·관세로 혼동하지 않는다.
- 206/209/214는 목재 주문의 총 잔량 교체 및 장날 지출임을 드러낸다.
- 역사 근거의 장소·시기 한계와 게임 각색을 대부분 분리하였다. 1399·1415 배경을 새 엔진 왕조/징발 상태라고 주장하지 않는다.
- 모든 신규 사건은 별도 그림 장면이 있고 문서 탁자 반복을 피한다.
- 011은 subtract를 operation으로 바꾸고 미정의 재산부담 증가 전제를 버린 후 제목·본문·효과를 실제 역제안 전체 수락으로 정렬했다. COUNTER_CASH의 실제 지원은 런타임 담당 확인 대상이다.
