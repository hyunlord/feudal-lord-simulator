2번의14~15픽셀은 깊은 내부 이음새 구멍이라고 부르지 않는다. `auto_gap_pixels.csv`는 9개 몸체·지붕쌍에 대해 현행검사129좌표와 이전 경계 진단882좌표를 함께 보존한다. 현행14픽셀은 지붕 경사 윤곽에서 reference alpha255 대비 final roof alpha248/249인 부족이며, square는 몸체 가장자리1픽셀이 추가된다. 이전98픽셀/쌍은 참조 자체 alpha246~249였으므로 최종 검사 영역에서 제외했다. 최종 조립 뒤 나타난14~15픽셀을 제거하려고 검사 정의를 다시 바꾸지 않았다.

5번 clipping 전 초과: 눈269, 이끼327, 새 지붕236, 그을음534, 판자122, 균열66, 비계495픽셀. 최종 교집합 clipping으로0이 된 사실과 생성 원본 정합을 구분한다. 지붕 공통 윤곽 역시3개 원본 alpha 교집합 처리 결과다.

9번 실패: curved_gray 0.754456547, square_gray 0.779015304, vertical_gray 0.757075724, vertical_ochre 0.797824949. 색마스크는 밝기·채도 분류이므로 창이 색마스크에 잘못 포함됐을 가능성을 숫자0만으로 배제하지 않았다.

검증기 확인: 합성 입력5개 시나리오 통과(`auto_test_results.json`), Python 구문 검사 통과, 실제 전체 입력 실행 성공. 이 파일은 독립 오프라인 수치 검사만 소유한다. 실제 엔진·설치·조명 물리성·지각적 자연스러움·눈가림 결과를 대신하지 않는다. 수치 대리값과 미정의 항목을 통과로 올리지 않았으므로 자동 관문은 미통과다.
