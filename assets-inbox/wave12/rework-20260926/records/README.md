## 설치 단계에서 사용할 발판
`footprint_x_tiles`, `footprint_y_tiles`가 의도한 점유 발판 칸 수입니다. 원본 전체 캔버스 크기를 발판으로 해석하지 마세요. 타일은 원본 기준128×64, 게임 줌1.0 기준64×32입니다. 표의 raw projected width/depth는 발판 마름모의 기하학적 외곽이며 건물 전체 높이/연기 여백과 다릅니다.

원래 의뢰서가 모듈 픽셀 크기만 지정한3종은 이번 설치용 계약에서 다음으로 정했습니다: 도랑1×1 반복모듈, 다리 예배당1×1(인접다리 제외), 부두2×2 외곽(256×128 원본모듈). CSV의 basis에 원 의뢰서 값과 새 의도값을 구분했습니다. 모든 기존 본체/캔버스/피벗은 그대로 유지했습니다.

## 재작업 내용
주거·집회시설은 굴뚝을 추가하지 않고 용마루 틈 연기와 밝게 열린 출입구를 사용했습니다. 길드홀은 본래 문 없는 아케이드이므로 구조를 유지한 개방부 불빛+상품·차양으로 처리했습니다. 무두질장은 두 통에서 큰 김과 큰 가죽, 대장간은 작업칸 안 큰 화염+지붕 틈 연기, 성소는7개 촛불+무릎 꿇은 순례자입니다. 두 예배당 문불빛, 시장 상품·차양, 부두 배·적재물, 헛간 문·볏단수레, 신발·옷감 좌판도 크게 보강했습니다.

모든 신규 그림은 built-in imagegen으로 만들었습니다. 개별 재료를 알파 crop/목표크기 축소 후 본체의 실제 위치에 등록했습니다. 본체를 다시 생성하지 않았으며 같은 캔버스와 offset(0,0) 합성을 사용합니다. 알파 경계2px RGB bleed가 있어 alpha0 픽셀의 RGB가0이 아닐 수 있습니다.

파일명은 교체 적용을 위해 기존 `-active-v1.png`를 유지했습니다. 내용의 revision은 CSV에서 `rework-v2`이며 이전 ZIP은 수정하지 않았습니다. 통과4종은 숯가마·석회가마·도기가마·공동화덕입니다.

PNG를100%로 보세요. 각 스프라이트가 원본의 절반 크기입니다. 전체 그림을 창에 맞춤으로 더 축소하면 검수 기준보다 작아집니다. 홀수137px 캔버스는69px로 반올림했습니다.
