# 반복 경고 후보의 별도 사람 판정

검출 후 추가 판정이다. 기존 `truth-objects-frozen.json` 및 해시는 변경하지 않았다. 각 원본 세계 PNG와 이 문서의 접촉판을 직접 대조했다. 접촉판은 해당 화면 영역 확대이며 주석이 없는 원본이 최종 판독 근거다. 판정 단위는 후보 군집이지, 그림 한 장의 복제 수가 아니다.

|---|---|---|---|---|
| prenat1-city | 1012,144,449,236 | ale_barrels_3 | FP | 넓은 주택 구역에 분산된 작은 갈색 재고 더미다. 출입구별 저장물로 읽히며 한곳에 몰린 복제판 같은 시각적 과밀은 아니다. 같은 자산 6개라는 사실만으로 어색함이 성립하지 않는다. |

## 고정 정답 통계와 의미상 판정의 차이

- 위 네 행은 후보를 본 뒤 수행한 **의미상 FP 판정**이다. 고정 시험지의 recall/precision 수치를 소급 변경하는 근거로 사용하지 않는다.
- 고정 정답의 판독 regions 밖에 있는 후보는 통계상 excluded이며, 표의 의미상 FP와 모순되지 않는다.
- 중앙 실타래 양성 ROI와 중앙 에일 통 경고의 상자가 서로 겹친다. `repeat_density`라는 같은 검출기 이름과 IoU만으로 대응하면, 실제 실타래 경고 대신 에일 통 경고가 TP에 배정될 가능성이 있다. 공간 대응의 TP/FP ID와 위 의미상 판정을 함께 보여야 한다. 이 차이를 숨기고 에일 통 검출 성공으로 해석하면 안 된다.
- 이번 검토를 이유로 에일 통 파일명만 예외 처리하지 않았다. 다음 개선은 재고의 역할·실제 시각적 두드러짐을 구분하는 일반 기준이 필요하다.

## 도구 소스 자체 검토 위험

1. `objects.py`의 원본 RGBA 대조는 픽셀로 복제의 존재를 확인하지만, 복제가 **과도한지**는 아직 판단하지 못한다. 동일 재고가 서로 다른 가구 앞에 있는 정상 사례에서 FP가 난다. 현재 반복 경고는 자동 커밋 차단보다 사람 검토 대기열로 쓰는 편이 근거에 맞다.
2. 크기 검사에서 옛 장면은 장식 인물 스프라이트의 알파 높이를 사람 기준으로 사용한다. 모자·그림자와 장식 인물 자체의 배율 오차가 분모에 영향을 준다. 또 합성 양조장 그림에 굽힌 통은 독립 물체로 분리되지 않아 FN이다. 전체 합성 그림을 통 높이로 재면 해결되는 문제가 아니다.

## 최종 재실행 정정

현재 장면은 `current-fixed` 원본을 다시 직접 판독했다. 앞선 `current` 임시 화면·좌표는 최종 근거에서 제외했고 현재 접촉판도 교체했다. `prenat2-fixed`의 본 장면·confirm, `current-fixed`의 본 장면·confirm·LOD를 각각 원본으로 다시 보았다. 해당 화면들의 작은 통 재고 군집도 같은 이유로 FP로 판정했다. 최종 JSON은 실제 enhanced/findings.json의 정확한 후보 ID·상자·결과 파일 해시를 기록하며, 옛 메타데이터 폴더의 ID 추정값은 쓰지 않았다.

JSON의 `rejected_ids`는 공간 대응의 자동 TP보다 앞서 적용할 수 있는 후보별 의미상 거절 목록이다. 이는 고정 양성 정답의 위치를 고친 것이 아니라, 잘못된 종류의 후보가 우연한 상자 겹침으로 정답을 가로채는 것을 방지한다. 평가자가 판독 영역 밖의 후보는 여전히 excluded로 유지할지, 이번 추가 검토를 별도 정밀도 표본으로 셀지는 표에 명시해야 한다.
