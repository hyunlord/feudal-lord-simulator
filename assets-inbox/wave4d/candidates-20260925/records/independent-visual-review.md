# Wave4d 독립 최종 시각 검수

**판정: 후보 검토용 적합, 재질 차이는 검토 의견으로 유지.** 22종 개별 PNG와 확인 그림 3장을 검수하고 마지막 윗면 32px 위상 수정 및 갤러리 정리본까지 다시 확인했다. 사용자 아트 승인이나 게임 통합 승인을 대신하지 않는다.

## 확인 결과

- 석벽 면은 회색 계열이며 윗면·흉벽과 합성했을 때 지면 포장이 아닌 벽으로 읽힌다. 성문 좌우 벽의 지면 접점은 수정 후 같은 지면 높이로 연결된다.
- 석벽 윗면 A/B 및 대각 윗면의 최종 32px 흉벽 리듬에서 앞서 보였던 밝은 겹침 얼룩과 좁은 반쪽 흉벽 이음은 사라졌다. 건축 요소 자체의 규칙적인 반복은 남아 있다.
- 목책 윗면 단면열은 몸체 끝에 연결된다. 처음 발생한 떠 있는 단면열은 수정본에서 해결되었다.
- 깊은 물 3종과 물가 E/F의 물쪽은 얕은 물과 같은 회청록 계열이며 깊은 물이 더 어둡다. 3×3 반복 확인 그림에서 강한 직선 이음은 발견하지 못했다.
- 갈대 A/B/C는 높은 가지형·낮게 퍼진 형태·수직 꽃이삭형으로 구분된다. 줌 0.6에서 덤불 종류와 높낮이가 읽힌다. 진흙 돌 A/B는 작은 돌 덩어리로 읽히고 넓이 차이가 있다.
- 석탑은 낮은 원통형과 흉벽으로 읽힌다. 교대는 화면 오른쪽 아래 육지와 왼쪽 위 수면 방향이 구별되며, 최종본의 기둥은 수직으로 유지된다.
- 확인 그림 03의 하단 배경, 중복 레이블, 반복된 탑은 마지막 갱신에서 정리되었다. 축소 갈대·돌 5종과 모듈 2종을 각각 확인할 수 있다.

## 남은 검토 의견

석벽의 회색 계열과 블록 표시 크기는 이전 파일럿보다 기존 성문에 가까워졌다. 다만 새 벽은 성문의 작은 잡석보다 더 매끈하고 규칙적으로 읽힌다. 완전히 동일한 붓질·불규칙성이라고 판정하지 않는다. 이 차이는 후보 아트 검토 항목으로 명시한다.

## 수정 확인 이력

떠 있는 목책 윗면, 성문의 벽 접지 불일치, 교대 전체 호모그래피로 찌그러진 기둥, 석벽 C 상단의 불투명 검정 여백, 윗면의 밝은 이음 얼룩 및 반쪽 흉벽, 확인 그림 하단 갤러리 오류를 발견해 전달했고 마지막 출력에서 해결을 확인했다.

## 범위와 한계

원본·개별 PNG·오프라인 확인 그림을 검수했다. 실제 게임 설치, DPR, 카메라 가림, 통행·성벽 운반 동치 또는 렌더 성능은 검증하지 않았다. 탑 피벗과 모듈 소켓은 후보 등록값이며 실제 런타임 계약 확인이 아니다. 모든 에셋은 candidate 상태를 유지한다.
