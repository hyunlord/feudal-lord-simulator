# 튜토리얼 스토리보드의 시각 계약

기준: docs/design/art-bible.md(ART_BIBLE_v2, 2026-10-02), docs/design/mockups/lord-screens-20261002/DESIGN.md.

- 용도: 정적 연출 검토용 candidate. 실제 조작 UI, 게임 캡처, 설치 자산이 아님.
- 색 토큰: ink #2A2118, timber #463625, timber-light #5E4A33, parchment #DCD3C1, vellum #EFE8D8, vermilion #A83232, gold #C9A227, forest #405633, water #4D758A. 원본 그림 내부색은 유지.
- 글자: 한국어 제목 AppleMyungjo 30px, 본문 Apple SD Gothic Neo 21/19px, 보조 16px, 제작자용 프레임 정보 14px. 실제 게임 최소 글자 크기를 확정하는 문서가 아니다.
- 화면: 1280×800, 상단 64px, 좌측 내비 72px. 내용 영역 x=92..1254, y=82..624. 집사 안내판 y=646..776. 간격 16/24px. 본문 한 패널 슬롯, 지도 뒤에 별도 상시 장부를 중첩하지 않음.
- 부품: 참나무색 주 버튼 / 양피지 보조 버튼. 목표 한 곳만 금색 선과 번호로 표시. 색 외에 문구로 선택·차단·진행 중을 구분. 버튼 높이 44px 이상.
- 재사용: 기존 시안에서 내비게이션·초상·가계·지도·영지 풍경을 crop. 기존 도시 검수 캡처에서 HUD 없는 도시 부분만 crop. 새 그림 생성 0회. 원본 색·인물 얼굴·의상 수정 없음.
- 도시 프레임: 이동/관찰/선택만 표현, 배치 유령·드래그 건축·격자 배치 지시 없음. 새 건물 확정으로 보이는 부분은 연출 예시임을 표시.
- 검수: 12장 각각 1280×800 직접 열람, 텍스트 bbox 화면 안, CJK 깨짐·잘림·금색 목표 확인. 모바일 반응형·클릭·렌더 성능·엔진 인과 검증은 대상 아님.
