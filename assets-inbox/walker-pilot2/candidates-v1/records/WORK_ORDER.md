## 0. 파일럿 1에서 확인된 것
- 방향·보행을 **자유 생성**하면 두 프레임의 발이 같은 위상에 머물고(교대 없음), 소지품이 방향마다 손을 바꾼다. 딥리서치가 예측한 그대로다.
- 그래서 방식을 바꾼다: **보행·방향은 이미 승인된 기존 시트의 자세를 그대로 쓰고, 그 위에 옷·머리쓰개만 다시 입힌다.** 소지품은 시트에 넣지 않고 **별도 작은 그림**으로 만든다(게임이 손 위치에 붙임).

## 2. 규칙
- **템플릿 자세 고정**: 셀마다 템플릿의 실루엣(발 위치·팔 각도·몸 기울기)을 유지. 옷 길이가 달라도 발 접점은 같음. 확인 방법: 템플릿과 결과를 반투명 겹치기 → 발·머리 위치 차이 ≤ 2px(마스터 148px 기준 4px).
- 방법: 템플릿 셀을 입력으로 부분 편집(inpaint/img2img 등)으로 옷·머리만 바꾼다. 자유 생성 금지.
- 규격: 셀 74×74, 4방향 × 2프레임, 방향 순서·발 접점 템플릿과 동일. 마스터 148 → 50% 축소.
- 색은 초상화의 주색과 일치. 그림자는 템플릿과 동일.

## 3. 확인 그림 (2장)
1. **겹치기 검사**: 4시트 × 8셀에 템플릿 실루엣을 50% 겹친 것. 발·머리 위치 차이 px 표시.
2. **보행 확인**: 각 시트의 방향별 프레임 0·1을 나란히 — 교대가 템플릿과 같은지(템플릿이 맞으면 결과도 맞아야 함).

## 4. 제출물
시트 4 + 소지품 16장(4종 × 4방향) + 확인 2 + CSV 20행 + 검수표(겹치기 차이, 방향 일관성표 재작성).

## 5. 검수 기준
- 발·머리 위치 차이 ≤ 2px(74px 기준) 32셀 전부
- 보행 교대 = 템플릿과 동일(24방향쌍 O)
- 초상↔워커 의미 서명 4/4
