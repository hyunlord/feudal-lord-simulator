# Wave8 틀 6종 검수

- 6장 모두 원본 프로젝트 P0 틀 3종·양피지 1종을 참조한 별도 native image_gen 생성. 모델 이름은 도구가 노출하지 않음.
- 정확한 납품 크기: 512×384, 512×640, 384×256, 256×512, 256×256, 192×256. RGBA PNG.
- 콘텐츠 배경은 P0 계열 #ddcfa7로 평탄화. 생성된 테두리·장식 그림은 유지. 청원 원형과 인장은 원본 생성 그림에서 추출·크기 정규화·재배치.
- 글자·숫자 없음. 원형은 초상 빈 자리, 붉은 원은 인장 빈 자리.
- 이름 없이 역할: 두루마리+3장면석 / 필사본잎+좌측덩굴 / 접힌서류+초상원형+인장 / 긴목재서랍 / 나침반지도틀 / 얇은범례틀.
- 1.5배 순수9-slice 합성, 6종 모든 모서리 RGBA 최대차 0. 원형·세슬롯·나침반·손잡이는 고정 모서리에 완전히 포함.
- 제약: 최소 크기보다 줄이지 않음. 비대칭 inset이므로 폭 확대시 장식이 중앙으로 자동 재배치되지 않음. 3개 장면석은 원본 상단 좌측의 위치·크기를 유지하며 새 빈 폭은 오른쪽에 추가됨.
- ledger의 좁은 수평 신장 회랑에서 잔여 잎무늬가 늘어나는 결함은 native 단색 단면 정리 후 재검수.
- 게임 미설치. 실제 런타임 9-slice 통합·입력 검수는 수행하지 않음.
