# 생성 및 선택 기록

네이티브 image_gen으로 각 인물을 한 장씩 통째로 생성했다. 첨부 파일럿1 및 청지기 그림은 화풍 참조로만 사용했다. 외부 인물 사진·기존 레이어·얼굴 합성·좌우반전은 사용하지 않았다. 모든 생성의 실제 전체 프롬프트, 참조 파일, 선택 원본 경로는 generation-records/에 남겼다. 도구가 모델 버전·seed를 노출하지 않아 임의로 기입하지 않았다.

최종 선택 원본은36명+노화8장=44장이다. 청년 사슬4장은풀에서 그대로복사해 납품48장이 된다. 생성 시도 총수와 선택원본 수는 다르다. 일부 생성 호출 실패는 재시도했고, 유사성/방향/노화의 개선을 위해 P08/P09/P15/P24/P30/P33/P14_old를 교체했다. 현재 records의 revision은 선택본 개정이며, 반려 시안을 후보 수량에 추가하지 않았다. 원래 생성 저장소의 이미지는 삭제하지 않았다.

선택 후 인물 픽셀 작업은 Swift/AppKit으로256×256 축소만 수행했다. 확인 그림은 동일 완성 PNG를256/96px로 배치한 정적 판독 시험이다. UI 그림은 실제게임 화면 캡처가 아니라청원/인물 카드 문맥의96px 오프라인시험이다. 피부톤과체형은각계급에교차배치했고도덕성태그는없다.

CSV의 age는 목표나이이며 실측나이가 아니다. age_group은풀선택분류다. 눈색·흉터등미세특징은96px에서항상읽히지않는다. hair_color는가려진머리에대해서는설정값이며,노화사슬에서는관찰한회색/백발을별도기록했다. 신분·직업은복식과소지품의맥락으로읽되인접6계급의완전한블라인드분류를보장하지않는다.

pipeline/raster.swift는축소·확인그림배치도구소스이며예전레이어도구기능도포함한다. 이번파일럿에서는resize와board만사용했다. proof-scenes JSON은이미지파일을상대경로로참조하여동봉PNG로확인그림을재구성할수있다.
