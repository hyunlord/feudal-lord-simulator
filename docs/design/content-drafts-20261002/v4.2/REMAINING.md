# 남은 문제

1. 보류 권고38개는 현재 계속 실행 가능하다. 이 산출물은 게임을 설치·수정하지 않았다. 사건 풀에서 제외하려면 설치 담당자의 등록 변경이 필요하다.
2. 정책8개(202·203·207·208·210·212·213·215)는 모두 가중치 전환뿐이다. 구호·임금·특권 등 실제 맥락별 결과 명령이 생기기 전 재상신하지 않는 편이 낫다. 다른 보류 항목별 부족 결과는 HOLD_RECOMMENDATIONS.json.
3. 보류38개를 모두 제외하면 현재 지원86개 중48개가 남는다. 이는 수량 계산일 뿐 출현 빈도 예측이 아니다. 종류별 밀도·빈 해·후반 시대 밀도 목표와 충돌할 수 있으므로 새 실행 측정이 필요하다. 얇은 카드를 수량 때문에 통과시키지는 않았다.
4. 같은 종류의 소송·목재·세율 선택 반복이 남는다. 이번 통과는 효과 진실성과 고민의 가시성 판정이며 장기 플레이 다양성 통과가 아니다.
5. 실제 대상 이름·세부 계약 조건을 더 잘 펼치는 UI 개선은 코드 작업 범위 밖이다. 새 플레이테스트·브라우저 조작·125년 실행은 하지 않았다.
6. Schema 검증은 구조와 계약을 증명한다. 엔진 주입 검사는 변경 명령의 동작을 증명한다. 재미나 실제 발생 빈도를 증명하지 않는다.
