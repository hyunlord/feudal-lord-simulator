# 혈통 초상 본 제작 1차

판정: 후보 제작 완료 — 가족 묶기 28/30(93.3%), 동일인 판정 18/18(96px·256px 모두). 판정자는 제작에 참여하지 않은 별도 AI 에이전트이며, 사람 대상 인지 실험은 아니다.

## 납품

혈통별 명시 구성36장에 창시 부부 청년2장을 더해 청년30명 검사를 구성했다. 공통 풀까지154장, 마지막 요청의 아기6장을 더해160장이다. 82인물의 단계 그림이며 160명이 아니다. 공통 풀4장은 파일럿1 승인본을 그대로 재사용했고, CSV에 출처·SHA를 표시했다.

## 적용한 교정

- 아기는 포대기·아기 모자와 짧은 하안부, 큰 머리 비율로 제작했다. 추가6장은 각각 대응하는 파일럿2 어린이 파일을 직접 참조했다. 연령 보조 참조와 정체성 참조의 역할을 구분했다.
- 어린이가 청소년처럼 보이던 시도를 교정했다. 반대로 너무 어려진6장도 학령기 비례로 다시 교정했다. 최종6장 재검수는 `final-child-refinement-qa.json`이 과거 판정을 대체한다.
- 장년24장은 모두 청년 나이+20년으로 기록했다. 특히 L3 102/203, L4 201/203, L5 203/205의 약한 노화를 추가 교정해 주름·눈밑·볼·목·흰머리 변화를 강화했다.
- 기혼 성인 여성은 머리를 가렸다. 204의 청년은 미혼, 장년은 기혼으로 단계별 기록했다. 미혼 어린 소녀·청년 소녀는 베일을 쓰지 않는다.
- 가족 공통은3개, 개인 차이는3개 이상 기록했다. 다른 가문과 거의 같았던 L5 외부 배우자206을 교정하고 그를 참조한 손자녀도 새 입력으로 다시 제작했다. 공통 아동02/06 유사성은06의 앞머리·땋은 머리·시선·이 빠진 웃음으로 교정했다.

## 한계

- 주관적 연령 추정에는 폭이 있다. 최종 공통 C_child_07은5–7세로 추정되어 목표 하한6–7세와 겹치는 수준이며, 명확한7–8세라고 단정하지 않는다. 일부 다른 어린이도5–7세 또는5–8세 추정 구간이다.
- 아기 모자 아래 머리숱이 적어 의도한 머리색5종의 정확한 시각적 수량은 확정하지 않았다. 머리색·피부 톤·개인 표식은 CSV와 검수 기록에 구분했다.
- 가족 묶기와 동일인 검사는 복식·머리·성별 단서가 보이는 그림으로 수행했다. 얼굴만으로 유전성을 검증한 결과가 아니다. 9번 어린이↔청년 쌍은 검수자가 상대적으로 불확실하다고 기록했다.
- 표식의 정확한 좌우·점 개수, 전160장 모든 쌍의 구별성을 보장하지 않는다. 작은 표식과 눈색은96px에서 약해질 수 있다.
- 게임 미설치. 실제 게임 렌더링·DPR·성능·상태 연결은 검증하지 않았다. 제공되지 않은 생성 모델 버전과 seed는 기록하지 않았다.
