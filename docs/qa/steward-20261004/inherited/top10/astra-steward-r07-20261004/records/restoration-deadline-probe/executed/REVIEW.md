# 권리복원 시간 경계 실측

공식 DGX runner 종료0,55.4초. seed1/t12001의 이전 합성 명령 결과에서 시계를 바꾸지 않고 공식 advanceTick을 두 경로 합9001회 진행했다. codec 재생 비교6회를 포함한 전체 advanceTick 호출9007회. 검사9046개·저장28개 SHA 확인, 실패0.

50d 납부 경로: t16000 강등 유지, t16001 작위 복귀·예약 제거, t16002 유지.

15d 부족 경로: t16001은 재청원 가능 하한이지만 계절 시작이 아니므로 청원 없음. 쇠퇴 원인이 해소되고 같은 가문이 유지된 이번 경로에서는 t17000 최초 계절 청원1개, t17001 중복 없음. 모든 상태에서 반드시17000에 온다는 보장은 아니다.

합성 쇠퇴 명령 fixture가 출발점이므로 자연 쇠퇴 발생 검증은 아니다. 진행 중 공식 장 사건 응답만 사용했으며 복원 재청원에는 응답하지 않았다. 입력불변·저장복원·기한경계는 검사했고 UI 설명·모든seed/쇠퇴원인은 미검증이다.
