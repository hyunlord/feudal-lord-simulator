# Wave 2 독립 시각 검수

- 검수일: 2026-09-24
- 검수 대상: 최종 에셋 PNG 6장, 확인 그림 2장, 첨부 게임 참조 PNG 7장. 모두 실제로 열어 비교했다.
- 게임 설치·런타임 검증은 하지 않았다. 확인 그림의 거리 배열은 오프라인 합성이다.
- 판정: **후보 제출 가능, 전체 검수 기준 무조건 통과 아님.** 실루엣 변형은 성립한다. 생계형 본채 크기감과 축소 시 작은 직업 소품의 판독성에는 제한이 있다.

## 핵심 판정

| 항목 | 판정 | 실제 관찰 |
|---|---|---|
| 단순 색상 변형 금지 | 통과 | 양조의 낮은 부속 지붕·통, 직조의 외부 틀, 생계의 나무·뒤뜰이 외곽선을 바꾼다. 확인 그림의 단색 실루엣에서도 차이가 남는다. |
| L2가 L3처럼 커지지 않을 것 | 통과 | 직조형이 셋 중 가장 높지만 기준 L2와 유사하다. L3 참조의 추가 큰 박공과 같은 상위 등급의 확장은 없다. |
| 기준과 같은 크기감 | 부분 충족 | 직조는 기준에 근접하고 양조는 다소 작다. 생계형은 본채가 더 작게 읽힌다. 전체 표시 높이도 기준 약 62.4px에 대해 양조 56.8px, 직조 61.8px, 생계 53.6px이다. 전체 높이만으로 본채 치수를 증명할 수 없으나 생계형의 시각적 축소는 관찰된다. |
| 줌 0.6에서 변형 차이 유지 | 부분 충족 | 직조의 오른쪽 틀, 생계의 오른쪽 녹색 나무, 양조의 낮은 옆 덩어리 차이는 남는다. 그러나 색을 제외한 저배율의 직업 식별은 약하다. 통 개수나 작은 텃밭·우리·헛간을 각각 알아볼 수 있다고 주장할 수 없다. |
| 기준 시점·톤 | 통과 | 목골조, 따뜻한 갈색 기와, 석회벽과 자연색이 참조 계열에 속한다. 본채의 두 입면 방향도 참조와 일치한다. |
| 굴뚝·유리·S자 기와 금지 | 시각상 통과 | 눈에 띄는 굴뚝이나 유리 반사는 없다. 지붕은 평평한 작은 기와 모듈로 읽히며 S자 물결 기와로 보이지 않는다. 작은 창의 재질을 픽셀만으로 확정할 수는 없다. |

## 에셋별 판독

### 양조형

- 낮은 옆 덧지붕과 나무 통 두 개가 원본 137×137에서 읽힌다.
- 기준 L2와 옆 실루엣이 다르다. 줌 1에서 부속 덩어리는 보이지만 통의 형태는 작다.
- **연기 구멍은 최종 137px 그림에서 확실히 확인되지 않는다.** 프롬프트 기재를 시각 증거로 대신하지 않았다.

### 직조형

- 큰 어두운 창 개구부와 옆쪽 외부 틀, 그 위에 걸린 밝은 실/직물 묶음이 보인다.
- 외부 틀이 다른 집보다 높은 옆 실루엣을 만들어 저배율에서도 일부 차이가 남는다.
- 유리 반사처럼 읽히는 요소는 없다. 외부 틀의 개별 줄이나 직물 종류는 줌 0.6에서 구분되지 않는다.

### 생계농업형

- 과수와 낮은 뒤뜰의 녹색 이랑, 울타리 형태가 보인다.
- 작은 부속 헛간과 우리로 해석할 요소는 있으나 원본에서도 밀집되어 있고, 거리 배율에서는 개별 용도를 확실하게 구분하기 어렵다.
- **본채는 기준과 같은 크기로 보인다는 조건을 충분히 충족하지 못한다.** 뒤뜰을 넣기 위해 집이 축소된 인상이 남는다.

### 목축형 농장

- 양 여러 마리, 허들 울타리, 건초더미 하나, 작은 초가 헛간이 모두 명확하다.
- 기존 밀밭과 같은 마름모 지면과 자연색 계열이며, 토지 이용의 차이는 즉시 읽힌다.
- 주택 거리 합성에 실제 배율로 배치된 것은 아니다. 확인 그림 하단은 원본 1:1 검토이므로 이 관찰을 농장 런타임 저배율 통과로 확대하지 않는다.

### 우물 B

- 지붕 없는 돌 테두리와 나무 두레박 지지 구조가 명확하다. 기존 지붕 우물과 외곽선이 다르다.
- 바닥 지름도 기존 우물과 비슷한 소규모 설비로 읽힌다.

### 시장 B

- 기존 세 좌판의 배열과 달리 두 좌판이 ㄱ자에 가깝게 배치되어 실루엣 변화가 크다.
- 긴 밝은 차양 아래 큰 양모/직물 덩어리와 다른 좌판의 낮은 바구니·쟁반이 보인다. 생선 바구니의 개별 생선은 작아 확실히 식별하기 어렵다.
- 상품 구분을 모두 독립적으로 저배율에서 읽을 수 있다는 판정은 하지 않았다.

## 알파·피벗·확인 그림

Pillow로 최종 PNG를 다시 읽어 크기와 가장자리 알파를 검사했다. 주택은 상단·좌우 8px 및 하단 4px, 나머지는 사방 8px 영역에 불투명 픽셀이 **0개**다.

| 에셋 | 픽셀 크기 | 알파 경계: 좌, 상, 우, 하 (우·하 미포함) |
|---|---:|---|
| 양조 | 137×137 | 14,18,127,132 |
| 직조 | 137×137 | 15,8,127,132 |
| 생계 | 137×137 | 14,24,127,132 |
| 목축 | 384×192 | 19,16,365,184 |
| 우물 | 72×80 | 19,17,53,64 |
| 시장 | 224×224 | 14,87,216,214 |

- 주택 3종의 가시 그림 하단은 모두 y=131픽셀까지이며 동일하다. 피벗 약 (70.9581, 132.0837) 바로 위에 놓인다.
- 피벗은 일반 PNG 자체에 들어 있는 게임 메타데이터가 아니다. `technical-qa.json`의 좌표와 확인 그림의 공통 선·십자 표시를 확인했다. 저장된 좌표 계약과 런타임 등록 검증은 구별한다.
- 두 확인 그림 모두 8채와 공통 접지선, 각 피벗 표시가 있으며 줌 1/0.6이라는 표시가 있다. 기준 L2와 후보의 접지 높이를 육안으로 비교할 수 있다.
- 생성 원본은 요청 최종 해상도보다 커서 정규화되었다. 이 검수는 최종 픽셀 결과에 대한 것이며 지정 크기 직접 생성의 증거가 아니다.

## 결론

**색만 바꾼 변형이라는 문제는 해결했다.** 다만 생계형 본채 크기와 저배율 직업 소품 판독, 양조 연기 구멍 확인에는 미달 또는 확인 불가 사항이 남는다. 이를 후보 검수 기록에 남기고 본 제작의 전면 승인 근거로 사용하지 않는다.
