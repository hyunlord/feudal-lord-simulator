## 내부 검수에서 수정한 항목

1. heater용 고정 외곽 띠가 좁은 방패에서 끊겼습니다. 방패 내부 좌표로 매핑하는 bordure 합성 계약을 추가하고 3종 모두 재검수했습니다.
2. 문장 확인 그림의 chief가 납품 마스크와 달랐습니다. 실제 `ordinary_chief.png`를 사용하도록 고쳤습니다.
3. 인물 카드의 원형 초상과 원한 기록부의 붉은 띠가 확대 중 늘어날 수 있었습니다. 고정 슬라이스 영역을 확장했습니다.
4. 양피지 내용 면의 낮은 알파로 HUD가 비쳤습니다. 내용 면의 알파를 교정했습니다.
5. 자유 보유지 아이콘의 굴뚝·유리는 builtin imagegen 편집으로 제거했습니다. 반려 원본과 편집 프롬프트를 보존했습니다.

## 적용 계약과 남는 한계

- `records/HERALDRY_COMPOSITION.md`의 채널·분할·bordure 합성 규칙을 지켜야 합니다. 임의의 이미지 편집기 레이어 겹치기와 동일한 결과를 보장하지 않습니다.
- 9-slice 가로 확대에서 등록부 중앙 접힘과 특허 끈은 중앙 패치와 함께 넓어집니다. 제공 확대 사례는 검사했으나 장식의 비율을 엄밀히 유지하려면 원본 종횡비 유지 또는 이후 런타임의 별도 장식 처리가 필요합니다.
- 문장 독수리·밀 다발의 세부는 96px에서 줄지만 실루엣은 구별됩니다. 모든 가능한 임의 조합을 전수 검사하지 않았습니다.
- 실존 문장 전체와의 우연한 중복을 전수 대조하지 않았습니다. 역사 자료를 복제하지 않고 프로젝트용 새 조합을 만들었습니다.
- 확인 그림 4는 첨부 HUD 위 오프라인 합성입니다. 인물 초상 자리는 비워 두었습니다. UI 상호작용·게임 성능·실제 설치는 검증하지 않았습니다.
- 생성 중 일시 401 오류는 동일 내장 도구 재시도로 해소했습니다. 외부 API 우회는 하지 않았습니다.
