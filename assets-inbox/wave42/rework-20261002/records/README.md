# Wave 42 — 중간 단계 8장 교체 후보 v2

기존 Wave 42 묘목·방치 단계 8장만 교체하는 경량 패키지입니다. 게임에는 설치하지 않았습니다.

- 묘목 1–3년: 여러 어린 나무와 풀·고사리가 모인 낮고 넓은 군집.
- 묘목 4–8년: 더 높고 조밀한 어린 나무 군집. 겨울 두 단계는 어두운 맨가지 유지.
- 방치 풀: 밝은 씨앗 이삭과 거친 키 큰 풀.
- 방치 덤불: 어둡고 솟은 가시나무 둔덕.

기존 asset ID·파일 경로·캔버스·피벗을 유지했습니다. 묘목은 128×192 / (64,172), 방치 자산은 128×160 / (64,120)입니다. 좌우 뒤집기는 사용하지 않았습니다. assets.csv에 이전·교체 SHA를 함께 기록했습니다. 승인된 나머지 42장은 이 ZIP에 포함하지 않으며 기존 원본 50장 모두 변경하지 않았습니다. 이전 길 접속 CSV는 그대로 사용합니다.

## 확인 그림

- proofs/01-regrowth-actual.jpg / 01-regrowth-zoom06.jpg: 그루터기 → 낮은 묘목 → 높은 묘목 → 어린 숲, 여름·겨울.
- proofs/02-abandoned-actual.jpg / 02-abandoned-zoom06.jpg: 보통 풀밭 → 씨앗풀 → 가시나무 → 어린나무, 여름·겨울.

actual은 납품 PNG의 1:1 픽셀, zoom06은 PNG에 0.6을 적용한 오프라인 합성입니다. 뷰어 자체 확대율은 별도입니다. 승인된 비교 자산은 확인 그림 안에만 포함됩니다. 개별 배경 점검판도 포함했습니다.

records에 정확한 생성 프롬프트·참조 해시·생성 원본 경로·최종 해시·기계검증·export 코드를 보관했습니다. 9회 생성 중 낮은 덤불 1회는 거절 기록이며 최종 자산은 정확히 8개입니다. 경량화를 위해 큰 생성 원본은 ZIP에서 제외했습니다. 재현 스크립트의 참조 경로는 제작 환경의 로컬 경로입니다.
