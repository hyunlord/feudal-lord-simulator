## 엔진(C3·E)에 넘길 것
- **걸어 다니는 직업:** 지금 걷는 사람은 builder · carter · distributor 세 종류다. 젠트리·사제·수도사·수녀·방문객·경비 시트는 설치했지만 걷는 직업이 없어 쓰이지 않는다. 교회·예배당 방문, 시장 방문, 경비 순찰이 걷는 사람이 되면, 직업 → 계급군 표(`OCCUPATION_BANDS`)에 한 줄씩 더하면 된다.
- **걷는 사람의 가구:** 걷는 사람의 `homeBuildingId`는 일터(방앗간·곡창·공사장)라서 `householdMembers`가 늘 null이다. 그래서 성별은 해시 50:50이다. 걷는 사람이 가구 구성원(집 id + 구성원 번호)을 가지면, `walkerSex`는 그 구성원의 성별·나이대를 바로 쓴다. 코드는 이미 그 경우를 읽는다(집이면 가구 어른 중 하나).
- **계급 속성:** 주민 계급이 생기면 직업 대신 계급으로 계급군을 고르고, 직업은 소지품에만 쓴다.
- **나이대:** 아이·노인 몸 그림이 없어서, 나이대가 와도 어른 몸을 쓴다.
