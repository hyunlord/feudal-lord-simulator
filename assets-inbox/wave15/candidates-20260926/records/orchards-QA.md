# Wave15 과수 자체 검수

- 범위: 과수 9종 × 봄·겨울 18장 + 꽃잎 데칼 1장 = 19장. 모두 candidate. 게임 설치 없음.
- 최초 ZIP에는 과수 8종만 존재. 사용자가 추가 제공한 `orchard_original_phase16.png`를 아홉째로 사용했다. 외부 그림 사용 없음.
- 기본 18장, 꽃잎 1장, apple_c 겨울 보완 1회로 native imagegen 총 20회. 보완 전·후 실제 프롬프트와 소스는 `orchards-sources.json` attempts에 기록했다.

| 항목 | 판정 | 근거 |
|---|---|---|
| 캔버스 | 통과 | 8종 256×256, 기존 phase16 113×80, 꽃잎 96×48 |
| 접지·피벗 | 통과(이미지 등록) | 원본 알파 하단 기준 Y 차이 18장 모두 0px. 하단 7행 알파 무게중심 X 차이 최대 0.498px. 실제 매니페스트 피벗 좌표는 변경하지 않음 |

## 처리와 한계

- native 편집 결과를 원본 알파 범위에 기계적으로 크기 맞춤 후, 하단 줄기 무게중심에 정렬했다. 그림 요소를 코드로 그리지 않았다.
- 수관 가로 범위는 줄기 정렬 때문에 원본 대비 최대 4px 이동한다(256px 기준, 게임 표시 폭43에서는 0.68px 이하). 줄기/가지의 모든 픽셀을 원본과 동일하게 복사한 것은 아니며 겨울 잔가지와 꽃은 새 편집 그림이다.
- 이미지 단독 투명 미리보기에서 보인 붉은 가장자리 표시는 실제 합성에서 나타나지 않았다. 중성 배경 비교 및 픽셀 확인으로 검수했다.
- 게임 런타임 크로스페이드·정렬 실행은 설치 금지 범위이므로 검증하지 않았다. `orchards-game-scale.png`는 실제 표시 폭을 적용한 정적 합성이다.
