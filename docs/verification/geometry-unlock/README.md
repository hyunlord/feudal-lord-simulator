# 기하 입력 복사본의 종료 뒤 권한 복원

사용자 요청에 따라 운영 래퍼 `.omo/evidence/integrated-geometry-prep.wrapper.mjs`를 수정했다. 실행 중 파일 0444·폴더 0555는 유지하고, 복사 시작부터 결과 검증까지를 감싼 `finally`에서 복사본에만 소유자 쓰기 권한을 더한다. 성공·실패·복사 중 실패를 모두 처리하며 원본과 심볼릭 링크 대상은 변경하지 않는다. 정리 오류도 실패로 남긴다.

Mac에서 `node --test docs/verification/geometry-unlock/owner-write-restoration.test.mjs`로 3개 시험을 실행할 수 있다. 실행 중 잠금, 종료 뒤 삭제, 원본 바이트·권한 보존을 확인했다. `mac-test.txt`에 결과를 남겼다. SIGKILL·전원 종료처럼 JavaScript 정리 코드 자체가 실행되지 않는 종료는 보장하지 않는다.

이 폴더의 래퍼 전문과 패치는 다음 커밋에 포함할 전달본이다. `.omo` 운영 래퍼는 이미 수정했다. 이전 실행의 고정 HEAD·자체 해시를 포함한 검증 명세를 재사용하지 않는다. 운영 래퍼를 그대로 추적 파일로 옮기면 기존 `tracked + own` 목록과 중복되므로 실행 시 파일 목록을 다시 구성해야 한다. 진행 중이거나 과거 DGX 실행 폴더를 직접 변경하지 않았다.
