## 2. 아트 감사 코드 몫
- **BLD-06(P1) 상태 층 이중선**: 그리기 코드는 이미 그림의 자르기·크기로 층을 그렸다. 원인은 층 파일 자체였다(상태 그림을 그림 모델이 1~6 px 크거나 작거나 밀리게 그림).
  - `scripts/registerStateLayers.py`가 층마다 그림에 맞춰 재고, 뚜렷이 어긋난 30장(Wave 30 합필 26·Wave 26 홑집 4)을 그림 위로 옮겨 다시 썼다.
  - 설치 스크립트가 복사 뒤 이를 부른다. 결정은 `docs/provenance/state-layer-registration.csv`에 남는다.
  - 눈 층 둘은 위치가 아니라 모양이 틀려 Astra에 다시 그리기를 요청한다.
- **BLD-01** 옛 평면 시설 그림 7장: 런타임에서 뺐다(은퇴 목록·두 목록에서 제거·assets-inbox/retired). 시설 그림을 불러오는 첫 몇 프레임에는 코드 그림 덩이를 그린다.
- **ENV-03** 옛 물: V1 물 질감을 새 물 표면으로 돌리고 water.png를 은퇴시켰다.
- **BLD-07** 문보다 큰 사람(N4-D2): 사람 크기 0.55 → 0.5(L0·L1 문/어른 ≈ 0.78), 먼 줌 바닥 0.8 → 0.65(줌 0.5에서 1.6배 → 1.3배). 줌 0.5·1.0·1.4 전후 캡처.
- **RUN-03** 나무 좌우 반전: 모든 나무가 왼쪽에서 빛을 받아 반전 허용 목록이 비었다. 이제 어떤 나무도 뒤집지 않는다.
- **RUN-02** 창고의 겨울 눈(N4-D3): 창고 눈 그림이 없다. 규칙("집·곡창은 눈, 시설은 아직 아님")을 `docs/design/seasonal-nature.md`에 적고, Astra에 창고 a·b·c 지붕 눈 층을 요청한다.

## 3. LAND-UI 판정 뒤의 셋 + 새로 온 것
- **땅 경계 띠**(LU-D11): 백악·해안·습지·히스 띠를 2.5배 넓히고 알파를 0.65 꼭대기 언덕 모양으로 부드럽게 했다(그림마다 한 번 굽고, 프레임당 일 없음). 선이 아니라 전이로 읽힌다. 강가 청크 42개 내용 키·픽셀 해시 그대로.
- **숲 가장자리 띠**(INBOX-2y·2z):
  - Wave 41 `woodland_edge_{a,b}`를 여름(봄·가을도)에 1,024 px 이음매 없는 반복으로 번갈아 그린다. 겨울은 `woodland_grass_edge_winter`.
  - 앞의 여름 띠(`woodland_grass_edge_summer`)는 깊은 숲 변형으로 설치만 했다.
- **폭 1 여울**: Wave 41 `ford_w1_{ne,nw}_{summer,winter}`를 쓴다(LU-D4의 "폭 2를 가운데에" 대체).
- **지도 번호**(LU-D7): kit 숫자 칸(1~999,999) + "무작위"(`randomNewGameSeed`), 강가도 아무 번호. 판이 안 서는 번호는 한국어 이유를 보이고 시작을 막는다. 증명 질의에서는 1로 연다(N4-D5, 장면 스크립트가 무작위 새 게임을 시작하지 않게).
- **HUD 면적 중앙값**(HUD-MEDIAN): `scripts/hudMedian.ts`가 세 번의 줄마다 중앙값과 판정을 쓴다. 규칙은 UI_STATE_DESIGN US-4.
- **FIX-13**:
  - 빠른 인장 하나(사용자 2026-10-02, N4-D6): 누를 때마다 5배속↔10배속, 모서리 표(12 px "×5"/"×10")가 지금 빠르기를 보인다. 키보드 5 → 5배속, 0 → 10배속을 각각 바로 고른다. 인장은 넷 그대로라 시간 묶음 폭이 예전과 같다.
  - HUD 면적 세 번 중앙값(`docs/verification/nat4/hud/`): 27줄 중 넘는 줄 0. 1280 보통·놓기·2장 성벽은 6.5/6.5, 태블릿 성벽 8/8로 예산에 딱 맞아 여유가 없다.
  - 속도 누름 단계가 10을 몰라 1배속으로 되던 것을 고쳤다.
  - 배수 3단계 구역은 `origin` 중심, 목재 부족에 "목재 X 필요 · 지금 Y".
- 환영 화면: 튜토리얼 줄 전체가 아니라 켜기 단추만 클릭을 받는다(화면 가운데가 다시 닫기 층에).
