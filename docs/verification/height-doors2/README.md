# RB-HEIGHT-DOORS2 — L1 세 집의 문과 전용 층

제품 `79d6f2ac`. Wave26 L1 c/e/f의 완성 몸체 3장과 각 집의 새집·풍화·판자·눈 12장, **새 게임 PNG 15장**을 기존 core 그림 계약에 연결했다. 성인 17.6px, 집 발판 1×1, 세계 픽셀 배율은 유지했다. 원래 문 23종 중 앞선 L0/L1d와 이번 3종까지 5종을 다룬 부분 작업이며, 나머지 18종까지 완료했다고 하지 않는다.

상단 공간이 부족한 원래 139² 캔버스에 새 집을 억지로 축소하지 않았다. 새 몸체와 그 전용층은 모두 139×155이며 바닥 피벗 y에도 16을 더했다. 그림이 커진 만큼 바닥 세계 좌표가 움직이는 방식이 아니다. 실제 접지 픽셀의 작은 차이는 별도 측정했다. 원본 그림과 기존 공유층은 덮어쓰지 않았다.

문틀·계단을 제외한 문 안쪽의 수동 끝점을 재며 각 끝점 오차는 ±1native다. 목표는 높이 20.24–24.64, 폭 7.92–11.44세계 px. 중앙값은 모두 범위 안이지만 e 높이 구간(19.94–21.94), f 폭 구간(6.98–8.98)은 하한을 걸친다. 전체 오차 구간까지 통과했다고 표현하지 않는다. 바닥 점 수동 오차는 ±2native이며, 픽셀 동일성이나 엄밀한 2:1 투영 통과를 주장하지 않는다.

## 상태층과 남은 시각 한계

원본 골조·지붕까지 복사한 첫 생성층은 버리고 투명 덧그림으로 다시 편집했다. 실패 원본도 보고 ZIP에 보존한다. 새집과 풍화는 기존 집 나이 조건대로 서로 배타적이며, 판자와 눈은 기존 조건에 따라 더해진다. c/e 판자·새집·풍화의 alpha>32 몸체 밖 픽셀은 0이다. c 눈의 처마 돌출 43px, f 눈의 작은 경계 돌출 44px는 남아 있다. e 눈의 몸체 밖 픽셀은 0이다.

수동 지붕 영역의 alpha 가중 눈 덮임은 c 80.10%, e 78.09%, f 72.21%다. 이진 alpha>32 덮임은 각각 88.07%, 86.52%, 80.34%로, 경계·부분 투명의 취급에 따라 다르다. c 가중값은 80% 상한 부근이며 수동 영역 오차 ±2native를 포함해 완전 범위 통과로 세지 않는다. 초가 띠를 따르는 눈·이끼 배치가 규칙적인 한계도 남는다.

## 계약과 출처

새 하드코딩 렌더 경로 없이 기존 `legacyBodyUrl` 조건과 공용 계약을 사용한다. 기존에 고른 c/e/f 변형만 바꾸며 1350년 이후 우선되는 시대 계약, 다른 변형, 준비 실패 시 기존 fallback을 유지한다. 등록한 지붕점과 몸체별 눈 마스크를 기존 연기·지붕 새·서리 소비자가 읽는다. 엔진·저장 형식·배우 키를 바꾸지 않았다.

앞선 HEIGHT-DOORS 8장의 계약은 생성 원본을 직접 `inboxFile`로 가리켜 오프라인 무손실 파일검사에 실패했다. 생성 원본과 기존 runtime 8장의 바이트를 보존하고 승인된 native 파생본을 정본 inbox로 추가했다. 이 8장은 새 게임 그림 수에 포함하지 않는다. 수정 전 8개 실패, 수정 후 기존 8+신규 15개 SHA·크기·RGBA 검사 오류 0. 검증기를 완화하지 않았다.

도구는 `image_gen.imagegen`, 모델·seed는 도구가 반환하지 않았다. 정확 프롬프트, 실제 생성 원본, 전체 그림 등록, 승인된 native, runtime SHA를 `source-chain.json`으로 연결한다. 기존 장부 원본 행을 지우지 않는다.

## 실제 화면과 게시 검사

확인한 39쌍은 정상 새집·풍화·초겨울 각 9쌍, 준비 한겨울 빈집 9쌍, 문이 보이는 정상 13000틱 f 집 3쌍이다. 정상 11000틱은 겨울 시작이라 지붕 눈 alpha=0인 음성 조건이며, 이를 눈 부착 양성으로 세지 않는다. 한겨울 준비본은 같은 원본에서 tick=11500과 대상 가구의 빈집 필드만 준비했다. 인구·가구 연대기·달력 진행을 재계산한 정상 시뮬레이션 결과가 아니다. 원래 11000틱의 빈집 before 9뷰는 짝이 없는 초기 조건 기록으로 보존하며 전후 쌍 수에서 뺐다.

정상 27쌍의 before는 신규 설치 전 빌드다. 준비 한겨울 9쌍의 before는 동일 빌드에서 c/e/f 신규 계약의 legacyBodyUrl 선택 조건만 끈 제어 기준이다. 정상 f 집 추가 3쌍도 같은 빌드에서 f 신규 선택 조건만 끈 제어 기준이다. 원래 9000틱 f 집에는 상태 아이콘·전경 가림이 있었고, 13000틱 확대에서는 문 전체와 길의 성인을 함께 확인했다. 세 기준을 구분한다. 준비 한겨울 after의 목표 집 몸체·판자·눈은 모두 기록한 globalAlpha=1이고 실제 화면에서도 보인다. 파일 요청·투명 draw만으로 설치 양성을 세지 않는다.

사용 저장의 출처·준비 필드, 렌더된 층과 오류 기록은 `pairs.json`을 기준으로 한다. 정상 저장과 빈집 렌더 확인용 복사본을 구분한다. 0.6줌은 마을 배치·실루엣의 증거이며 문 세부 판독의 증거가 아니다. 기존 상태 아이콘이나 앞집이 문을 가리는 장면은 가림을 제거한 것으로 꾸미지 않는다.

로컬 관련 시험 45개, 타입 검사, 저장소 소스 린트, 기존 8+신규 15장 파일검사를 통과했다. 최초 잘못 호출한 루트 ESLint는 설정을 찾지 못했고 저장소 전용 `tools/eslint` 명령으로 다시 확인했다. 게시 영수증은 `publication-gates.json`, 원본 JPEG 캡처·준비 상태·실행 기록은 보고 ZIP에 보존한다. 용량이 큰 세계 PNG는 원래 로컬 결과와 이름을 적은 DGX kept 실행에 보존하며, 원본 캡처 JSON의 SHA로 추적한다. ZIP 안에 없는 PNG까지 포함했다고 하지 않는다. 독립 관찰은 보강 증거이며 추가 승인 관문이 아니다.
